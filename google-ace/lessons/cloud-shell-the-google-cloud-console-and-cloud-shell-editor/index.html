Cloud Shell, the Google Cloud console and Cloud Shell Editor

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

The Google Cloud console is the web interface at the heart of daily work. You use the project picker at the top to choose a project, the navigation menu to reach each product, and the search bar to jump to a service or resource. Many console pages have an Equivalent code or command line link that shows the gcloud command or REST request for what you've configured, which is a great way to learn the CLI.

Cloud Shell is a free, browser-based terminal that runs on a temporary Compute Engine VM managed by Google. It's already authenticated as the user who opened it, and it comes with the Google Cloud CLI, kubectl, Terraform, Docker, git, language runtimes and editors preinstalled. You open it with the terminal icon in the console. Because it runs in the browser, it's ideal when you can't install software locally, or you need to run a quick command from any machine.

Each user gets a persistent home directory (a few gigabytes) that survives between sessions, so scripts and configuration files you keep in $HOME remain. Anything installed outside the home directory is lost when the VM is recycled. Sessions end after a period of inactivity, and if you don't use Cloud Shell for a long time, your home directory may be deleted, so don't treat it as long-term storage.

Cloud Shell Editor is a code editor based on the open source Code OSS project, opened with the Open Editor button. It lets you edit files in your Cloud Shell home directory, work with git, and use Cloud Code extensions to deploy to Cloud Run or GKE. For heavier or long-running development, Google also offers Cloud Workstations, which are managed development environments that you pay for.

The console's other everyday tools include the Activity view of recent actions, the Notifications panel, the Marketplace, and Cloud Shell's web preview, which lets you open a web server running in Cloud Shell on a port such as 8080 in a browser tab.

Key terms

Cloud Shell
A free, preauthenticated browser terminal on a temporary VM with Google Cloud tools preinstalled.
Cloud Shell Editor
A browser-based code editor built on Code OSS that works on the Cloud Shell home directory.
Persistent home directory
Cloud Shell storage that survives between sessions, unlike the rest of the VM.
Web preview
A Cloud Shell feature that opens a web server running in the session on a chosen port.
Real-world example

On a hotel business center PC, an on-call engineer signs in to the console, opens Cloud Shell and runs kubectl get pods and gcloud logging read to diagnose an incident, without installing anything. Her helper scripts are in her Cloud Shell home directory from last week.

Exam tip: 'Can't install software locally' or 'quickest way to run gcloud and kubectl' points to Cloud Shell. Remember only the home directory persists.

Check yourself

Which part of a Cloud Shell environment persists between sessions?

The home directory. Software installed elsewhere on the VM is lost when the session's VM is recycled.

How can you learn the gcloud command for something you configured in the console?

Use the Equivalent code or command line link shown on many console creation pages.
