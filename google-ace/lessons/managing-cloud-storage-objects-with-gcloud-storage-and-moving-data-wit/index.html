Managing Cloud Storage objects with gcloud storage and moving data with Storage Transfer Service

▶ Watch the overview video

Last reviewed September 25, 2026

The gcloud storage command group is the current CLI for Cloud Storage and replaces most uses of the older gsutil. Buckets and objects are addressed with gs:// URLs. Common commands: gcloud storage ls gs://my-bucket lists objects; gcloud storage cp report.csv gs://my-bucket/reports/ uploads; gcloud storage cp -r ./site gs://my-bucket copies a folder; gcloud storage mv moves or renames; gcloud storage rm gs://my-bucket/old/** deletes; and gcloud storage rsync synchronizes a directory with a bucket prefix. Large transfers are parallelized automatically.

You can change an object's storage class by rewriting it, for example gcloud storage objects update gs://my-bucket/file --storage-class=COLDLINE, but for many objects a lifecycle rule is better. Bucket settings are managed with gcloud storage buckets update, for example to change the default storage class, add labels, or enable versioning with --versioning. Changing a bucket's default class affects only new objects.

Remember that Cloud Storage has no real folders; names such as reports/2026/jan.csv just contain slashes, and the console displays them as folders. Objects are immutable: an update writes a new object (or a new version if versioning is on).

For large or recurring transfers, use Storage Transfer Service. It's a managed service that copies data into Cloud Storage from other clouds (Amazon S3, Azure Blob Storage), from HTTP/HTTPS URL lists, from other Cloud Storage buckets, and from on-premises file systems using agents you install. Jobs can run once or on a schedule, copy only changed files, delete source files after transfer, and report progress and errors. That makes it the right choice for moving terabytes from another cloud or keeping two buckets in sync nightly.

For very large datasets with limited network bandwidth, Transfer Appliance is a physical storage device that Google ships to you; you load data onto it and ship it back. As a rough guide, if uploading over your network would take weeks, consider the appliance. BigQuery Data Transfer Service is different again: it loads data into BigQuery from sources such as SaaS apps and scheduled queries.

Key terms

gcloud storage
The current gcloud command group for managing buckets and objects.
gcloud storage rsync
A command that makes a bucket prefix match a local directory or another location.
Storage Transfer Service
A managed service for copying data into Cloud Storage from other clouds, URLs, buckets or on-premises.
Transfer Appliance
A physical device shipped by Google for offline transfer of very large datasets.
Real-world example

A media company sets up a Storage Transfer Service job that copies new files from an Amazon S3 bucket to Cloud Storage every night at 01:00 and deletes nothing at the source. Their editors use gcloud storage rsync to push finished projects from a workstation to a bucket.

Exam tip: Other cloud to Cloud Storage, scheduled and managed: Storage Transfer Service. Hundreds of terabytes over a slow link: Transfer Appliance. Into BigQuery from SaaS: BigQuery Data Transfer Service.

Check yourself

Which command lists the objects in gs://logs-bucket?

gcloud storage ls gs://logs-bucket.

Does changing a bucket's default storage class change existing objects?

No. It applies to new objects; existing objects keep their class unless rewritten or changed by a lifecycle rule.
