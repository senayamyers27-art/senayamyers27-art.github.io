CompTIA CySA+ CS0-004

Frameworks de ataque: Cyber Kill Chain, Diamond Model, MITRE ATT&CK, OWASP Testing Guide, OSSTMM

Los frameworks de ataque dan a los analistas un vocabulario común para describir cómo se desarrollan los ataques y una estructura para encontrar brechas en las defensas. CySA+ espera que sepas qué modela cada framework y cuándo lo usarías.

La Cyber Kill Chain de Lockheed Martin describe una intrusión como siete fases secuenciales: reconocimiento (reconnaissance, investigar al objetivo), weaponization (combinar un exploit con un payload), entrega (delivery, enviarlo, por ejemplo por correo), explotación (exploitation, activar la vulnerabilidad), instalación (installation, establecer el malware o la persistencia), comando y control (command and control, un canal remoto hacia el atacante) y acciones sobre los objetivos (actions on objectives: robo de datos, destrucción, ransomware). La idea clave es que romper cualquier eslabón detiene el ataque, así que los defensores asignan controles a cada fase. Su limitación es que es lineal y está enfocada en intrusiones perimetrales basadas en malware, por lo que se ajusta peor a las amenazas internas y a los ataques en la nube.

El Diamond Model of Intrusion Analysis describe cada evento de intrusión con cuatro características centrales en las esquinas de un diamante: adversario, capacidad (herramientas y malware), infraestructura (IPs, dominios y servidores usados) y víctima. Las aristas conectan características relacionadas, así que si conoces la infraestructura puedes pivotar para encontrar otras víctimas o capacidades vinculadas a ella. Las metacaracterísticas incluyen la marca de tiempo, la fase, el resultado, la dirección y la metodología. Los analistas lo usan para enlazar eventos en hilos de actividad y para atribuir campañas.

MITRE ATT&CK (Adversarial Tactics, Techniques and Common Knowledge) es una base de conocimiento grande y actualizada con regularidad sobre el comportamiento real de los adversarios. Está organizada como una matriz: las columnas son tácticas (los objetivos del adversario, como initial access, execution, persistence, privilege escalation, defense evasion, credential access, discovery, lateral movement, collection, command and control, exfiltration e impact), y las celdas son técnicas y subtécnicas con IDs como T1053 para scheduled task/job. Cada entrada lista ejemplos de procedimientos, detecciones y mitigaciones. Los analistas usan ATT&CK para mapear las detecciones y encontrar brechas de cobertura, planificar cacerías de amenazas, describir incidentes con precisión y emular adversarios en las pruebas. Existen matrices separadas para enterprise, mobile e ICS.

La OWASP Web Security Testing Guide, producida por el Open Worldwide Application Security Project, es una metodología detallada para probar aplicaciones web. Agrupa las pruebas en áreas como recolección de información, configuración, gestión de identidades, autenticación, autorización, gestión de sesiones, validación de entradas, manejo de errores, criptografía, lógica de negocio y pruebas del lado del cliente. Úsala al planificar o evaluar una evaluación de una aplicación web.

El Open Source Security Testing Methodology Manual (OSSTMM), de ISECOM, es una metodología revisada por pares para probar la seguridad operacional en general, no solo las aplicaciones web. Cubre los canales humano, físico, inalámbrico, de telecomunicaciones y de redes de datos, y enfatiza resultados medibles y repetibles. Úsalo cuando necesites un enfoque amplio y científico de las pruebas de seguridad en toda una organización.

Términos clave

Cyber Kill Chain
Un modelo lineal de siete fases de una intrusión, desde el reconocimiento hasta las acciones sobre los objetivos.
Diamond Model
Un modelo de análisis de intrusiones que relaciona adversario, capacidad, infraestructura y víctima en cada evento.
MITRE ATT&CK
Una base de conocimiento de las tácticas y técnicas de los adversarios observadas en ataques reales, organizada como una matriz.
OWASP Testing Guide
Una metodología integral para probar la seguridad de las aplicaciones web.
OSSTMM
Open Source Security Testing Methodology Manual: una metodología para pruebas de seguridad medibles en muchos canales.
Ejemplo real

Después de un incidente de phishing, un analista lo mapea en ATT&CK: un adjunto de phishing para el acceso inicial, ejecución por parte del usuario, una Run key para la persistencia y HTTPS para el C2. Al comparar ese mapa con las reglas de detección del SIEM se ve que no hay cobertura para los cambios en Run keys, así que se agrega una nueva regla basada en Sysmon. Luego el Diamond Model vincula el dominio de C2 con dos eventos anteriores.

Consejo para el examen: Fases lineales significa Kill Chain; cuatro esquinas de adversario, capacidad, infraestructura y víctima significa Diamond Model; tácticas e IDs de técnicas significa ATT&CK. OWASP es para pruebas de aplicaciones web; OSSTMM es para pruebas amplias de seguridad operacional.

Comprueba lo que sabes

¿Cuáles son las cuatro características centrales del Diamond Model?

Adversario, capacidad, infraestructura y víctima.

En ATT&CK, ¿cuál es la diferencia entre una táctica y una técnica?

Una táctica es el objetivo del adversario (el porqué); una técnica es cómo lo logra.

¿Cuál es una crítica común a la Cyber Kill Chain?

Es lineal y está enfocada en el perímetro y el malware, así que modela mal los ataques internos y los basados en la nube.
