CompTIA CySA+ CS0-004

Herramientas: SIEM, SOAR, EDR, Wireshark/tcpdump, sandboxing, CyberChef, consultas de reputación y WHOIS

CySA+ evalúa si puedes elegir la herramienta correcta para una tarea e interpretar lo que muestra. No necesitas dominar cada producto, pero sí saber qué hace cada categoría y dónde están sus límites.

Un sistema de gestión de información y eventos de seguridad (SIEM) recolecta logs de todo el entorno, los normaliza, correlaciona eventos relacionados, genera alertas basadas en reglas y ofrece búsqueda para las investigaciones y retención a largo plazo para el cumplimiento. Algunos ejemplos son Splunk, Microsoft Sentinel, Elastic y el stack de código abierto Security Onion. Un SIEM es tan bueno como sus fuentes de datos y sus reglas de detección. La orquestación, automatización y respuesta de seguridad (SOAR) se apoya en las alertas ejecutando playbooks: enriquecer una alerta con inteligencia de amenazas, abrir un ticket, deshabilitar una cuenta o aislar un host automáticamente. El SIEM detecta y correlaciona; el SOAR automatiza la respuesta.

Los agentes de detección y respuesta de endpoints (EDR) registran actividad detallada en los hosts (procesos, archivos, registro, conexiones de red), detectan comportamientos maliciosos en lugar de solo firmas conocidas y permiten a los respondedores aislar una máquina, terminar procesos y recolectar archivos de forma remota. La detección y respuesta extendida (XDR) correlaciona los datos del EDR con la telemetría de red, correo y nube.

Wireshark es un analizador de paquetes gráfico, y tcpdump es una herramienta de captura de paquetes por línea de comandos común en Linux. Usa tcpdump para capturar en un servidor, por ejemplo tcpdump -i eth0 -w capture.pcap host 10.0.0.5, y luego abre el archivo en Wireshark. En Wireshark, los filtros de visualización como http.request, dns o ip.addr == 10.0.0.5 acotan la vista; Follow TCP Stream muestra una conversación; Statistics > Conversations y Endpoints resumen quién habló con quién. El tráfico cifrado limita lo que puedes ver a metadatos como IPs, puertos, nombres de servidor TLS y tiempos.

Un sandbox es un entorno aislado donde detonas un archivo o URL sospechoso y observas lo que hace: los archivos que deja, los cambios en el registro, las conexiones de red y los procesos que crea. Los sandboxes revelan el comportamiento de forma segura, pero algunos malware detectan los entornos virtuales y permanecen inactivos, así que un resultado limpio del sandbox no es prueba de que sea seguro.

CyberChef es una herramienta basada en el navegador para decodificar y transformar datos mediante recetas encadenadas: Base64, hexadecimal, decodificación de URL, XOR, descompresión, marcas de tiempo y más. Los analistas la usan para desempaquetar PowerShell ofuscado o payloads web codificados.

Las consultas de reputación verifican una IP, dominio, URL o hash de archivo contra servicios de inteligencia que registran si se ha visto en actividad maliciosa. Las consultas WHOIS muestran los datos de registro de un dominio, como el registrador, la fecha de creación y los servidores de nombres. Un dominio registrado hace dos días que aparece en un correo de phishing es una fuerte señal de advertencia, aunque los servicios de privacidad suelen ocultar la identidad del registrante.

Términos clave

SIEM
Security information and event management: recolección centralizada de logs, correlación, alertas y búsqueda.
SOAR
Security orchestration, automation and response: automatización del enriquecimiento y de las acciones de respuesta basada en playbooks.
EDR
Endpoint detection and response: agentes que registran la actividad del host, detectan amenazas por comportamiento y permiten la respuesta remota.
Sandbox (entorno aislado)
Un entorno aislado para ejecutar de forma segura archivos sospechosos y observar su comportamiento.
WHOIS
Un servicio de consulta que devuelve los datos de registro de un dominio, como el registrador y la fecha de creación.
Ejemplo real

En el SIEM se dispara una alerta por un proceso de PowerShell con un comando codificado largo. El analista lo decodifica en CyberChef, encuentra una URL de descarga, revisa el dominio en WHOIS (registrado ayer) y en un servicio de reputación (marcado como malicioso), y usa la consola del EDR para aislar el host. Luego un playbook de SOAR bloquea el dominio en el proxy.

Consejo para el examen: Si una pregunta pide qué herramienta automatiza pasos de respuesta entre productos, responde SOAR; cuál agrega y correlaciona logs, SIEM; cuál puede aislar una sola laptop infectada, EDR.

Comprueba lo que sabes

¿Cuál es la principal diferencia entre un SIEM y un SOAR?

Un SIEM recolecta y correlaciona logs para detectar eventos; un SOAR ejecuta playbooks automatizados para responder a ellos.

¿Por qué un sandbox podría reportar como limpio un archivo malicioso?

El malware puede detectar el entorno virtual, esperar la interacción del usuario o retrasar su ejecución, de modo que no muestra comportamiento malicioso durante el análisis.

¿Qué sugiere una fecha de creación WHOIS muy reciente sobre un dominio en un correo sospechoso?

Los dominios recién registrados se usan a menudo para phishing y malware, así que aumenta la sospecha.
