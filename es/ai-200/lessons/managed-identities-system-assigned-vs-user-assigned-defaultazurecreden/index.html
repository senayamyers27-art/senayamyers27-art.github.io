Identidades administradas: asignadas por el sistema vs asignadas por el usuario; DefaultAzureCredential en azure-identity

Las aplicaciones necesitan credenciales para llamar a los servicios de Azure, y cada secreto almacenado es algo que puede filtrarse, expirar u olvidarse en un repositorio. Una identidad administrada (managed identity) resuelve esto: Azure crea una identidad en Microsoft Entra ID para tu recurso y gestiona sus credenciales por ti. Tu código le pide un token al punto de conexión local de la plataforma y lo usa para llamar a cualquier servicio que admita la autenticación de Microsoft Entra, como Key Vault, Storage, Service Bus, Cosmos DB, Azure SQL y PostgreSQL.
