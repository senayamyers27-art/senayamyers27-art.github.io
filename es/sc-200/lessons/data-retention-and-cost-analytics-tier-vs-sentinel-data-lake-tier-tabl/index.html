Microsoft Certified: Security Operations Analyst Associate SC-200

Retención de datos y costos: nivel de análisis vs. nivel de data lake de Sentinel, planes de tabla, reglas de resumen, recomendaciones de SOC optimization

Sentinel se factura principalmente por los datos que ingieres y por cuánto tiempo los conservas, así que un analista de operaciones de seguridad tiene que pensar en el costo además de en la cobertura. No todos los registros merecen el mismo trato. Las señales de seguridad de alto valor que alimentan las detecciones deben poder consultarse rápido. Los registros de alto volumen y bajo valor, como el tráfico detallado de firewall o de proxy, a menudo se conservan principalmente para investigaciones y cumplimiento.
