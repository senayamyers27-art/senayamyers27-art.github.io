Microsoft Certified: Security Operations Analyst Associate SC-200

Respuesta de Defender for Endpoint: aislar el dispositivo, restringir la ejecución de aplicaciones, ejecutar análisis antivirus, recopilar el paquete de investigación, respuesta en vivo, detener y poner en cuarentena un archivo, indicadores de archivo, línea de tiempo del dispositivo

Cuando un endpoint está involucrado en un incidente, Defender for Endpoint te da acciones de respuesta en la página del dispositivo y en las páginas de archivos. Saber cuál se ajusta a la situación es una habilidad central del SC-200.

Isolate device (aislar el dispositivo) desconecta la máquina de la red pero mantiene su conexión con el servicio de Defender, así que puedes seguir investigando y ejecutando acciones. El aislamiento completo bloquea todo lo demás; el aislamiento selectivo permite que Outlook, Teams y aplicaciones similares sigan funcionando en algunas plataformas. El aislamiento detiene el movimiento lateral, el robo de datos y el comando y control. Restrict app execution (restringir la ejecución de aplicaciones) es diferente: el dispositivo sigue en la red, pero solo puede ejecutarse código firmado por Microsoft. Conviene cuando el usuario debe seguir trabajando y la amenaza es una herramienta sin firmar. Ambas acciones se pueden revertir desde la página del dispositivo.

Run antivirus scan inicia de forma remota un análisis rápido o completo de Microsoft Defender Antivirus. Collect investigation package reúne datos forenses en un archivo zip: procesos en ejecución, conexiones de red, tareas programadas, servicios, autoruns, programas instalados, registros de eventos de seguridad y más. Es una forma rápida de obtener una instantánea antes de reinstalar la imagen del dispositivo.

La respuesta en vivo (live response) abre una sesión de shell remota en el dispositivo desde el portal. La live response debe activarse en la configuración de funciones avanzadas (los servidores tienen un interruptor aparte). Los comandos básicos, que son de solo lectura, te permiten listar procesos, ver archivos y recopilar archivos con getfile. Los comandos avanzados, que requieren el permiso de advanced live response en tu rol, te permiten cargar archivos y scripts a la biblioteca con putfile, ejecutar scripts de la biblioteca con run y remediar archivos; ejecutar scripts sin firmar requiere una configuración aparte. Todos los comandos quedan registrados. Usa la live response cuando necesites un detalle que ninguna acción estándar te da, como extraer un registro específico.

Para un archivo malicioso, stop and quarantine file termina los procesos en ejecución y mueve el archivo a cuarentena en los dispositivos donde se vio. Add indicator crea un indicador de hash de archivo con una acción como block execution o block and remediate, para que el archivo no pueda ejecutarse en ningún lugar del tenant. También puedes descargar el archivo para analizarlo o enviarlo a un análisis profundo (deep analysis) en un sandbox. Para los indicadores de red, recuerda que la protección de red debe estar activada.

La línea de tiempo del dispositivo (device timeline) muestra los eventos del dispositivo en orden cronológico: inicios de procesos, conexiones de red, cambios de archivos, inicios de sesión y cambios en el registro, con las alertas marcadas. Puedes filtrar, buscar y marcar eventos de interés. Es donde reconstruyes lo que pasó antes y después de una alerta. Los mismos datos están en tablas de advanced hunting como DeviceProcessEvents, lo que ayuda cuando necesitas buscar en muchos dispositivos.

Las acciones que tomas aparecen en el Action center, para que puedan revisarse y deshacerse. El acceso a estas acciones depende de tu rol y del grupo de dispositivos, así que un analista de Nivel 1 podría ejecutar análisis pero no live response.

Términos clave

Isolate device (aislar el dispositivo)
Desconecta un dispositivo de la red, excepto la conexión con el servicio de Defender.
Restrict app execution (restringir la ejecución de aplicaciones)
Permite que solo se ejecute código firmado por Microsoft en un dispositivo mientras sigue conectado.
Investigation package (paquete de investigación)
Un zip de datos forenses (procesos, conexiones, autoruns, registros) recopilado de forma remota de un dispositivo.
Live response (respuesta en vivo)
Una sesión de shell remota en un dispositivo para recopilar archivos y ejecutar scripts aprobados.
Ejemplo real

Una laptop muestra cambios de nombre de archivos parecidos a los de un ransomware. El analista la aísla de inmediato, recopila un paquete de investigación, usa stop and quarantine file sobre el cifrador y agrega un indicador de hash block and remediate para que el archivo no pueda ejecutarse en otros dispositivos. La línea de tiempo del dispositivo muestra que el archivo llegó desde un adjunto de correo diez minutos antes de la alerta.

Consejo para el examen: Aislamiento frente a restringir la ejecución de aplicaciones es una pareja clásica: propagación activa o comando y control significa aislar; si el usuario debe seguir trabajando y la herramienta no está firmada, significa restringir la ejecución de aplicaciones. Un bloqueo a nivel de todo el tenant es un indicador de archivo, no la cuarentena en un solo dispositivo.

Comprueba lo que sabes

¿Qué acción mantiene un dispositivo en la red pero solo permite ejecutar código firmado por Microsoft?

Restrict app execution.

¿Qué debe estar habilitado para ejecutar tus propios scripts cargados en live response?

La live response activada en la configuración, un rol con permisos de advanced live response para cargar (putfile) y ejecutar scripts, y además la configuración de ejecución de scripts sin firmar si los scripts no están firmados.

¿Cómo impides que un archivo malicioso se ejecute en todos los dispositivos del tenant?

Crea un indicador de hash de archivo con block execution o block and remediate.
