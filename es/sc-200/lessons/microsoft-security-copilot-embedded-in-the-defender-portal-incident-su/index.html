Microsoft Certified: Security Operations Analyst Associate SC-200

Microsoft Security Copilot integrado en el portal de Defender: resúmenes de incidentes, respuesta guiada, análisis de scripts

Microsoft Security Copilot es un asistente de IA generativa para equipos de seguridad. Además de su portal independiente, está integrado directamente en el portal de Microsoft Defender, donde aparece en un panel lateral en las páginas de incidentes, alertas, dispositivos, usuarios y hunting. Funciona con la capacidad que tu organización aprovisiona, medida en unidades de cómputo de seguridad (SCU), y los usuarios necesitan el acceso adecuado tanto a Copilot como a los datos subyacentes de Defender. Copilot solo ve los datos que el usuario que inició sesión tiene permitido ver.

Los resúmenes de incidentes son la función más visible. Cuando abres un incidente, Copilot puede producir una narración breve: qué pasó, en qué orden, qué usuarios, dispositivos y buzones están involucrados, qué etapas del ataque (mapeadas a MITRE ATT&CK) se vieron y qué ya se remedió. Esto le ahorra a un analista de Nivel 1 el tiempo de leer cada alerta y ayuda en los traspasos entre turnos.

La respuesta guiada (guided response) da acciones recomendadas para el incidente, agrupadas en categorías como triaje, contención, investigación y remediación. Algunos ejemplos son clasificar el incidente, aislar un dispositivo, restablecer la contraseña de un usuario o revisar incidentes similares. Muchas recomendaciones tienen botones que ejecutan la acción directamente, con los permisos habituales. El analista sigue decidiendo; la respuesta guiada sugiere, no actúa por sí sola.

El análisis de scripts (script analysis) explica líneas de comandos y scripts sospechosos, como PowerShell ofuscado, archivos por lotes (batch) o bash, encontrados en la evidencia de una alerta. Decodifica y describe lo que el script intenta hacer, por ejemplo descargar un archivo, crear persistencia o deshabilitar herramientas de seguridad, y destaca indicadores como URL y direcciones IP. El análisis de archivos (file analysis) resume de forma similar las características de un archivo sospechoso. Estas funciones ayudan a los analistas que no son especialistas en malware a entender la evidencia rápidamente.

Otras capacidades integradas incluyen generar consultas KQL a partir de preguntas en lenguaje natural en advanced hunting, crear un informe del incidente que documenta las acciones y la línea de tiempo, y resumir información de dispositivos o identidades. Microsoft también está agregando agentes de Security Copilot que realizan tareas específicas de forma autónoma bajo permisos definidos, como hacer el triaje del phishing reportado por usuarios y explicar sus veredictos.

Usa Copilot con responsabilidad. Trata su resultado como un borrador útil: verifica los hechos contra la evidencia, revisa el KQL generado antes de usarlo en una detección y recuerda que la IA puede equivocarse o ser incompleta. El examen espera que sepas dónde ayuda Copilot (resúmenes, respuesta guiada, análisis de scripts y archivos, generación de consultas, informes) y que el analista sigue siendo responsable de las decisiones.

Términos clave

Security Copilot
El asistente de IA generativa de Microsoft para operaciones de seguridad, integrado en el portal de Defender.
Incident summary (resumen del incidente)
Una narración generada por Copilot de la línea de tiempo, las entidades, las etapas del ataque y el estado de un incidente.
Guided response (respuesta guiada)
Las acciones recomendadas por Copilot de triaje, contención, investigación y remediación para un incidente.
Security compute unit, SCU (unidad de cómputo de seguridad)
La unidad de capacidad que una organización aprovisiona para ejecutar Security Copilot.
Ejemplo real

Una analista nueva abre un incidente con nueve alertas y un comando de PowerShell ofuscado. El panel de Copilot resume el ataque como un correo de phishing que lleva a un descargador (downloader), el análisis de scripts decodifica el comando como la descarga de una segunda etapa (payload) desde una URL listada, y la respuesta guiada sugiere aislar el dispositivo y bloquear la URL. Ella verifica cada punto en la evidencia y toma las acciones.

Consejo para el examen: Relaciona la necesidad con la función: 'explica este comando ofuscado' es script analysis, 'qué debo hacer ahora' es guided response, 'informar al siguiente turno' es el resumen del incidente o el informe del incidente.

Comprueba lo que sabes

¿Qué función integrada de Copilot decodifica un comando de PowerShell ofuscado?

Script analysis (análisis de scripts).

¿La respuesta guiada toma acciones automáticamente?

No. Recomienda acciones; el analista elige si ejecutarlas.

¿Puede Copilot mostrarle a un usuario datos que no tiene permitido ver?

No. Trabaja dentro de los permisos del usuario que inició sesión.
