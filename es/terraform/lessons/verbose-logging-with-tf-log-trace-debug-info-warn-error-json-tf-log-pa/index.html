Registro detallado con `TF_LOG` (TRACE, DEBUG, INFO, WARN, ERROR, JSON), `TF_LOG_PATH`, `TF_LOG_CORE` y `TF_LOG_PROVIDER`

La salida normal de Terraform te dice qué planea y qué salió mal a alto nivel. Cuando necesitas ver lo que ocurre por debajo (qué llamadas a la API hace un provider, cómo recorre Terraform el grafo de dependencias, por qué falló un plugin), activas el registro (logging) detallado con variables de entorno. Ningún indicador de la línea de comandos hace esto; se controla por completo mediante el entorno.
