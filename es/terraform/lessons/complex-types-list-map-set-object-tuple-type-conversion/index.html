Tipos complejos: list, map, set, object, tuple; conversión de tipos

Además de los tipos primitivos string, number y bool, Terraform tiene tipos complejos que agrupan varios valores. Se dividen en dos familias, y saber a qué familia pertenece cada uno explica la mayoría de sus reglas.

Los tipos de colección contienen muchos valores que comparten un mismo tipo de elemento. Un list(T) es una secuencia ordenada, indexada desde cero, como list(string) con ["a", "b"], a la que se accede con var.zones[0]. Un map(T) es un conjunto de claves de tipo cadena que apuntan cada una a un valor de tipo T, como map(number), al que se accede con var.sizes["small"]. Un set(T) es una colección no ordenada de valores únicos; los duplicados se eliminan, no hay índice, y normalmente se recorre con un bucle o se convierte en lugar de elegir un elemento.

Los tipos estructurales permiten tipos distintos dentro de un mismo valor, con la forma fijada en el tipo. Un object({...}) tiene atributos con nombre, cada uno con su propio tipo, como object({ name = string, port = number }). Un tuple([...]) es una secuencia de longitud fija en la que cada posición tiene su propio tipo, como tuple([string, number, bool]).

variable "services" {
  type = map(object({
    port     = number
    public   = bool
    replicas = optional(number, 1)
  }))
}

El modificador optional() marca un atributo de objeto que quien llama puede omitir, con un default opcional como segundo argumento. La palabra clave especial any permite que Terraform deduzca el tipo a partir del valor, lo que es flexible pero ofrece una comprobación más débil.

La conversión de tipos ocurre automáticamente cada vez que un valor de un tipo se asigna donde se espera otro y existe una conversión segura. Las cadenas "5" y "true" se convierten en el número 5 y el bool true, y los números y bools se convierten en cadenas. Una tupla se convierte en lista si todos sus elementos pueden compartir un tipo, y un objeto se convierte en mapa de la misma manera. Una lista se convierte en set, perdiendo el orden y los duplicados. La sintaxis literal también importa: [...] en HCL es una tupla y {...} es un objeto, que Terraform luego convierte al tipo list o map declarado. Si no existe conversión, como de la cadena "hello" a un número, obtienes un error de tipo.

También puedes convertir explícitamente con funciones: tostring, tonumber, tobool, tolist, toset y tomap. El caso más común es toset(var.names), porque for_each acepta sets y maps, pero no listas. Por lo demás, la conversión explícita rara vez se necesita; HashiCorp sugiere confiar en la conversión automática y declarar los tipos en las variables.

Términos clave

Collection type (tipo de colección)
list, map o set: muchos valores que comparten el mismo tipo de elemento.
Structural type (tipo estructural)
object o tuple: una forma fija cuyos atributos o posiciones pueden tener tipos distintos.
set
Una colección no ordenada de valores únicos sin índice.
optional()
Modificador en un tipo object que hace que un atributo pueda omitirse, opcionalmente con un default.
Type conversion (conversión de tipos)
El cambio automático o mediante funciones de un valor a un tipo compatible, como toset() sobre una lista.
Ejemplo real

Un módulo recibe variable "subnets" { type = map(object({ cidr = string, az = string })) }. Quien lo llama pasa un mapa de subredes con nombre, y el módulo usa for_each = var.subnets para que cada subred se cree con una clave estable como "app" o "db".

Consejo para el examen: Las listas son ordenadas e indexadas; los sets son no ordenados y únicos; los maps tienen claves de tipo cadena. Objects y tuples son las versiones estructurales que permiten tipos mezclados. for_each necesita un map o un set, así que convierte las listas con toset().

Comprueba lo que sabes

¿Cuál es la diferencia entre list(string) y set(string)?

Una lista es ordenada y permite duplicados, y a sus elementos se accede por índice; un set es no ordenado, contiene valores únicos y no tiene índice.

¿Qué tipo permite atributos de distintos tipos con nombres fijos?

object({...}), un tipo estructural; un map requiere que todos los valores compartan un tipo.
