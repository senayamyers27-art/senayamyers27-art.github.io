Dependencias explícitas con `depends_on`; reglas de `lifecycle`: `create_before_destroy`, `prevent_destroy`, `ignore_changes`, `replace_triggered_by`

La mayoría de las dependencias son implícitas, creadas por referencias. A veces un recurso depende de otro sin usar ninguno de sus atributos. El ejemplo clásico es una instancia cuya aplicación, al arrancar, llama a una API de la nube usando un rol; la instancia debe esperar a que se adjunte la política de permisos del rol, pero sus argumentos nunca referencian la política. depends_on declara explícitamente esa dependencia oculta.
