Inspeccionar el estado: `terraform state list`, `terraform state show`, `terraform show` y `terraform output`

Nunca deberías abrir el archivo de estado en un editor de texto para averiguar qué gestiona Terraform. Terraform proporciona comandos de solo lectura que funcionan con cualquier backend, local o remoto, y muestran el estado de forma segura y legible. Saber qué comando responde a qué pregunta es un tema clásico del examen.

terraform state list muestra la dirección de cada recurso y data source en el estado, uno por línea, incluidos los que están dentro de módulos (module.network.aws_subnet.private[0]). Puedes filtrarlo pasando un prefijo de dirección, como terraform state list module.network, o por ID de recurso con -id=. Es la forma más rápida de responder "¿qué gestiona Terraform aquí?" y de encontrar las direcciones exactas para otros comandos.

terraform state show ADDRESS muestra todos los atributos de una sola instancia de recurso tal como Terraform los registró, en un formato legible similar a HCL. Úsalo para encontrar la dirección IP de una instancia, un ARN o el valor de un ajuste. Los atributos sensibles se ocultan en esta salida.

$ terraform state list
aws_instance.web
aws_security_group.web
module.network.aws_vpc.this

$ terraform state show aws_instance.web
# aws_instance.web:
resource "aws_instance" "web" {
    ami           = "ami-0abc..."
    instance_type = "t3.micro"
    ...
}

terraform show sin argumentos muestra todo el estado actual en forma legible, cada recurso con sus atributos, además de los outputs. Si le das un archivo de plan guardado (terraform show tfplan), muestra ese plan en su lugar. Agregar -json produce una salida legible por máquina para herramientas y verificaciones de políticas. Ten en cuenta que la forma JSON incluye los valores sensibles en texto plano, así que ten cuidado con dónde la envías.

terraform output muestra los valores de output del módulo raíz desde el estado. Con un nombre, terraform output db_endpoint muestra solo ese. Los outputs sensibles se muestran como <sensitive> en la vista de lista, pero pedir uno por su nombre, o usar -json o -raw, revela el valor. -raw muestra una cadena simple sin comillas, práctica en scripts de shell: ssh admin@$(terraform output -raw public_ip).

Ninguno de estos comandos cambia el estado ni la infraestructura. Para cambiar el estado hay un grupo separado (state mv, state rm, state push, state replace-provider, con state pull para exportar una copia), que debes usar con cuidado y, preferiblemente, reemplazar con bloques basados en la configuración como moved y removed.

Términos clave

terraform state list
Lista las direcciones de todos los recursos del estado, opcionalmente filtradas por un prefijo de dirección.
terraform state show
Muestra todos los atributos registrados de una instancia de recurso en el estado.
terraform show
Muestra todo el estado, o un archivo de plan guardado, en forma legible o en JSON.
terraform output
Muestra los valores de output del módulo raíz desde el estado, con las opciones -json y -raw para scripts.
Ejemplo real

Una ingeniera de guardia necesita la IP privada de un proxy de base de datos. Ejecuta terraform state list | grep proxy para encontrar la dirección module.db.aws_instance.proxy, luego terraform state show module.db.aws_instance.proxy para leer su atributo private_ip, todo sin tocar el archivo de estado.

Consejo para el examen: state list da direcciones, state show da los atributos de un recurso, show da todo (o un archivo de plan) y output da solo los outputs raíz.

Comprueba lo que sabes

¿Qué comando muestra los atributos de un solo recurso en el estado?

terraform state show ADDRESS.

¿Cómo muestras el valor de un output sin comillas para usarlo en un script de shell?

terraform output -raw NAME.

¿Qué hace terraform show tfplan?

Muestra en forma legible el contenido del archivo de plan guardado tfplan.
