Traducción de texto y documentos con Azure AI Translator y Custom Translator

Azure AI Translator traduce entre más de 100 idiomas usando traducción automática neuronal. Tiene tres partes que debes conocer: la traducción de texto para cadenas en tiempo real, la traducción de documentos para archivos completos y Custom Translator para entrenar modelos con tu propia terminología.

La traducción de texto es una llamada REST a la operación translate del endpoint de Translator con api-version=3.0, un parámetro from (opcional, ya que el idioma de origen se detecta automáticamente si se omite) y uno o más parámetros to. Enviar varios valores to traduce a todos esos idiomas en una sola solicitud. El cuerpo es un arreglo JSON de objetos con una propiedad Text. La autenticación usa el encabezado Ocp-Apim-Subscription-Key; cuando la clave pertenece a un recurso regional o multiservicio, también debes enviar Ocp-Apim-Subscription-Region con la región del recurso, o la llamada falla con 401.

curl -X POST "$TRANSLATOR_ENDPOINT/translate?api-version=3.0&to=fr&to=de" \
  -H "Ocp-Apim-Subscription-Key: $KEY" -H "Ocp-Apim-Subscription-Region: westeurope" \
  -H "Content-Type: application/json" -d '[{"Text": "Your order has shipped."}]'

Otras operaciones de texto incluyen detect (identificar el idioma), transliterate (convertir la escritura, como kanji japonés a letras latinas, sin traducir), dictionary/lookup (traducciones alternativas para una palabra) y breaksentence. Entre las opciones de translate están profanityAction (NoAction, Marked o Deleted), textType=html para preservar el marcado e includeAlignment. Para mantener términos específicos sin traducir o forzar una traducción, puedes usar marcado como el diccionario dinámico o marcar texto con una clase de no traducir.

La traducción de documentos traduce archivos completos, como Word, PDF, PowerPoint, Excel y HTML, conservando su estructura y formato. La versión por lotes es asíncrona: colocas los archivos de origen en un contenedor de Azure Blob Storage, creas un contenedor de destino, das acceso al recurso de Translator (tokens SAS o una identidad administrada con un rol de almacenamiento) y envías un trabajo que indica el origen, el destino y los idiomas. Luego consultas el estado del trabajo. Existe una opción síncrona de un solo documento para archivos pequeños. Un archivo de glosario puede imponer traducciones específicas de términos.

Custom Translator te permite entrenar un modelo de traducción con tus propios documentos paralelos: pares de oraciones alineadas en el idioma de origen y el de destino de tu dominio, como manuales de producto aprobados. Después de entrenarlo y publicarlo, el modelo tiene un ID de categoría, y tus solicitudes incluyen category=<id> para usarlo en lugar del modelo general. Úsalo cuando el modelo general traduce mal una y otra vez la terminología o el estilo de tu industria.

Términos clave

Text translation (traducción de texto)
Traducción en tiempo real de cadenas mediante la operación translate de Translator.
Document translation (traducción de documentos)
Traducción asíncrona de archivos completos en Blob Storage que conserva el formato.
Custom Translator
Un servicio para entrenar modelos de traducción con tus propios documentos paralelos, que se usan mediante un ID de categoría.
Transliteration (transliteración)
Convertir texto de una escritura a otra sin traducir su significado.
Ejemplo real

Un sitio de comercio electrónico traduce las reseñas de productos al inglés, francés y alemán con una llamada translate por reseña y tres parámetros to, usa la traducción de documentos para su manual de vendedores de 300 páginas y llama a un modelo de Custom Translator por ID de categoría para las descripciones técnicas de productos.

Consejo para el examen: Varios idiomas de destino en una llamada: varios parámetros to. 401 con una clave regional: agrega el encabezado Ocp-Apim-Subscription-Region. Archivos completos con formato: traducción de documentos. Terminología del dominio: Custom Translator con un ID de categoría.

Comprueba lo que sabes

¿Qué hace la transliteración?

Convierte texto de una escritura a otra, como del cirílico a letras latinas, sin traducir las palabras.

¿Qué necesita la traducción de documentos para acceder a tus archivos?

Contenedores de Blob Storage de origen y de destino, con acceso concedido mediante tokens SAS o una identidad administrada.
