Entrenamiento y evaluación de un modelo de Custom Vision: etiquetado de imágenes, iteraciones, precisión, recall y mAP

Entrenar un modelo de Custom Vision es un ciclo: reunir imágenes, etiquetarlas, entrenar, evaluar y mejorar los datos. La calidad del modelo depende mucho más de las imágenes que de cualquier configuración.

Carga imágenes mediante el portal de Custom Vision o el SDK de entrenamiento y asígnales etiquetas. En clasificación etiquetas imágenes completas; en detección de objetos dibujas un cuadro delimitador alrededor de cada objeto y lo etiquetas. Custom Vision exige un número mínimo pequeño de imágenes por etiqueta, pero los buenos modelos necesitan más: Microsoft sugiere aproximadamente 50 o más por etiqueta como punto de partida. Las imágenes deben variar como lo harán las reales: distintos ángulos, iluminación, fondos, tamaños y tipos de cámara. Mantén las etiquetas equilibradas; si una etiqueta tiene diez veces más imágenes que otra, el modelo se inclina hacia ella. En los proyectos de clasificación, se puede aplicar una etiqueta Negative a las imágenes que no contienen ninguna de tus etiquetas, para enseñarle al modelo cómo se ve 'ninguna'. En los proyectos de detección, el Smart Labeler puede sugerir cuadros después de un primer entrenamiento para agilizar el etiquetado.

Cada ejecución de entrenamiento produce una iteración, un modelo con versión que puedes comparar con los anteriores. El entrenamiento rápido (quick training) es veloz y suficiente para la mayoría de los proyectos; el entrenamiento avanzado (advanced training) te permite asignar un presupuesto de tiempo de proceso para problemas más difíciles y puede mejorar la precisión.

Después de entrenar, el portal muestra métricas calculadas sobre una parte reservada de tus imágenes. La precisión (precision) responde: de las predicciones que hizo el modelo para una etiqueta, ¿cuántas fueron correctas? El recall (exhaustividad) responde: de las imágenes (u objetos) que realmente tenían la etiqueta, ¿cuántas encontró el modelo? La precisión promedio (AP) resume la precisión y el recall a lo largo de distintos umbrales para cada etiqueta, y la media de la precisión promedio (mAP) promedia la AP de todas las etiquetas: un solo número para comparar iteraciones de detección de objetos.

El control deslizante del umbral de probabilidad cambia qué predicciones cuentan. Subirlo conserva solo las predicciones con confianza, lo que normalmente aumenta la precisión y reduce el recall; bajarlo hace lo contrario. Elige según el costo de los errores: una herramienta de detección médica puede querer un recall alto para que se escapen pocos casos, mientras que un etiquetador automático de productos puede preferir una precisión alta. En detección de objetos, un umbral de superposición define cuánto debe superponerse un cuadro predicho con el cuadro real (intersección sobre unión) para contar como correcto.

Para mejorar una etiqueta débil, revisa sus falsos positivos y falsos negativos con Quick Test y la pestaña Predictions, agrega imágenes variadas para los casos confusos, corrige las etiquetas incorrectas y vuelve a entrenar. Las imágenes que tu aplicación envía para predicción pueden revisarse y agregarse al entrenamiento más adelante.

Términos clave

Iteration (iteración)
Un modelo con versión producido por una ejecución de entrenamiento de Custom Vision.
Precision (precisión)
La fracción de las predicciones positivas del modelo para una etiqueta que fueron correctas.
Recall (exhaustividad)
La fracción de las instancias reales de una etiqueta que el modelo encontró.
mAP
Media de la precisión promedio (mean average precision): el promedio de la precisión promedio por etiqueta, que resume la calidad de la detección.
Ejemplo real

El clasificador de un vivero tiene 95% de precisión pero 70% de recall para 'hoja enferma', así que no detecta muchas plantas enfermas. El equipo baja el umbral de probabilidad, agrega 80 fotos más de hojas enfermas con distinta iluminación, vuelve a entrenar y la nueva iteración alcanza 88% de recall con una precisión aceptable.

Consejo para el examen: La precisión trata de cuántas predicciones fueron correctas; el recall trata de cuántos casos reales se encontraron. Subir el umbral cambia recall por precisión. mAP es la métrica principal para la detección de objetos.

Comprueba lo que sabes

¿Qué suele pasar con la precisión y el recall cuando subes el umbral de probabilidad?

La precisión sube porque solo quedan las predicciones con confianza, y el recall baja porque se escapan más casos reales.

¿Para qué se usa una etiqueta Negative?

Para marcar las imágenes de entrenamiento de clasificación que no contienen ninguna de las etiquetas del proyecto, para que el modelo aprenda cómo se ve 'ninguna de estas'.
