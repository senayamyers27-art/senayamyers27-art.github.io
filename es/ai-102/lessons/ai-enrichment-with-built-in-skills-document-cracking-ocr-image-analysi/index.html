Enriquecimiento con IA mediante skills integradas: document cracking, OCR, análisis de imágenes, entidades y frases clave en un skillset

El contenido sin procesar a menudo no se puede buscar tal como está: los PDF escaneados son imágenes, las fotos no tienen texto y los documentos largos esconden a las personas y los lugares que mencionan. El enriquecimiento con IA en Azure AI Search usa un skillset, asociado a un indexador, para ejecutar pasos de IA en cada documento durante la indexación y agregar los resultados como campos buscables nuevos.

La canalización tiene etapas. El document cracking lo realiza el indexador: abre archivos como PDF, documentos de Office y HTML, extrae su texto en un campo content y extrae los metadatos. Si estableces el imageAction del indexador en generateNormalizedImages, también extrae las imágenes incrustadas y las imágenes de las páginas, normalizadas para su análisis, en una colección normalized_images. Luego se ejecutan las skills, cada una leyendo entradas del árbol de enriquecimiento (una estructura de documento en memoria) y escribiendo sus salidas de vuelta en él, de modo que la salida de una skill puede alimentar a otra. Por último, las asignaciones de campos de salida (output field mappings) copian los valores enriquecidos del árbol a los campos del índice.

Las skills integradas cubren las necesidades comunes. La skill OCR lee texto impreso y manuscrito de las imágenes normalizadas, y la skill Merge vuelve a combinar ese texto con el contenido en el lugar correcto. La skill Image Analysis genera descripciones, etiquetas y objetos para las imágenes. La detección de idioma, la extracción de frases clave, el reconocimiento de entidades (personas, organizaciones, ubicaciones y más), la detección de PII y el sentimiento trabajan sobre el texto, y la skill Translation lo traduce. La skill Text Split divide los documentos en páginas o fragmentos, y la skill Azure OpenAI Embedding crea vectores para la búsqueda vectorial. Las skills de utilidad como Shaper (construir formas de salida complejas) y Conditional (elegir valores según una regla) organizan los datos.

Cada skill tiene un contexto, el nivel en el que se ejecuta, como /document para una vez por documento o /document/normalized_images/* para una vez por imagen, y entradas y salidas que se direccionan con rutas como /document/content. Las skills se facturan mediante un recurso multiservicio de Azure AI services asociado al skillset (por clave o identidad administrada). Sin él, solo se puede enriquecer gratis un número pequeño de documentos por indexador al día, lo cual basta para aprender pero no para cargas de trabajo reales.

El enriquecimiento incremental guarda en caché la salida enriquecida en una cuenta de almacenamiento para que, cuando edites un skillset, solo se vuelvan a ejecutar las skills afectadas, lo que ahorra tiempo y costos. Las sesiones de depuración (debug sessions) del portal te permiten inspeccionar el árbol de enriquecimiento de un solo documento y corregir las asignaciones de forma interactiva. El asistente Import data crea un origen de datos, un skillset, un índice y un indexador en pocos clics y es la forma más rápida de empezar.

Términos clave

Skillset
Una colección de skills de enriquecimiento con IA que un indexador ejecuta durante la indexación.
Document cracking
El paso del indexador que abre los archivos y extrae texto, metadatos e imágenes.
Enrichment tree (árbol de enriquecimiento)
La estructura en memoria que contiene los datos originales y enriquecidos de un documento mientras se ejecutan las skills.
Output field mapping (asignación de campos de salida)
Una asignación que copia los valores enriquecidos del árbol de enriquecimiento a los campos del índice.
Ejemplo real

Una empresa de ingeniería tiene 30 años de planos e informes escaneados. El indexador genera imágenes normalizadas, las skills OCR y Merge hacen buscable el texto escaneado, la skill de reconocimiento de entidades extrae organizaciones y ubicaciones a campos filtrables, y las frases clave alimentan una faceta para que los ingenieros puedan navegar por tema.

Consejo para el examen: El texto escaneado necesita imageAction generateNormalizedImages más la skill OCR. Enriquecer más de unos cuantos documentos requiere un recurso de Azure AI services asociado. Los valores enriquecidos llegan al índice mediante output field mappings.

Comprueba lo que sabes

¿Qué debe configurarse en el indexador para que la skill OCR reciba imágenes?

imageAction establecido en generateNormalizedImages (o generateNormalizedImagePerPage), para que las imágenes se extraigan y normalicen.

¿Qué ahorra el enriquecimiento incremental?

Volver a ejecutar skills sin cambios: la salida en caché permite que solo se vuelvan a ejecutar las skills afectadas por un cambio.
