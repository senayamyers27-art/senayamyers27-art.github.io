Comprensión del lenguaje conversacional (CLU): intenciones, entidades, expresiones, entrenamiento e implementación

La comprensión del lenguaje conversacional (CLU) es la función de Azure AI Language que interpreta lo que un usuario quiere a partir de un comando o una pregunta en lenguaje natural. Reemplazó al antiguo servicio Language Understanding (LUIS), que ya se retiró. Creas un proyecto de CLU en Language Studio (o en el portal de Foundry) o mediante la API REST de creación, entrenas un modelo personalizado con tus ejemplos, lo implementas y lo consultas desde aplicaciones y bots.

El modelo predice intenciones y extrae entidades. Una intención (intent) es lo que el usuario quiere hacer: BookFlight, CheckOrderStatus, CancelSubscription. Todo proyecto también tiene una intención None para las expresiones fuera del alcance de la aplicación; agregarle ejemplos variados fuera de alcance evita que el modelo fuerce entradas no relacionadas hacia una intención real. Una entidad es un dato que la aplicación necesita para actuar, como el destino, la fecha o el número de pedido.

CLU tiene varios tipos de componentes de entidad, que pueden combinarse. Las entidades aprendidas (learned) se aprenden de ejemplos etiquetados en contexto, para valores que varían, como una ciudad de destino en 'llévame a Lisboa la próxima semana'. Las entidades de lista (list) coinciden exactamente con un conjunto fijo de valores con sinónimos, como nombres de tiendas o tallas de producto con sus nombres alternativos. Las entidades precompiladas (prebuilt) reconocen tipos comunes como fecha y hora, números, correo electrónico y URL sin etiquetado. Las entidades de expresión regular (regex) coinciden con patrones como números de pedido del tipo ORD-12345.

Las expresiones (utterances) son oraciones de ejemplo para cada intención. Las agregas y etiquetas los fragmentos de entidades dentro de ellas. Los buenos datos tienen redacción, longitud y orden de palabras variados, números similares de expresiones entre intenciones y lenguaje realista de los usuarios, no solo oraciones de libro de texto. Después entrena el modelo. El entrenamiento estándar es más rápido y gratuito; el entrenamiento avanzado puede dar mejores resultados, y los proyectos multilingües permiten que un solo modelo entienda varios idiomas.

Después de entrenar, revisa los resultados de evaluación en un conjunto de prueba: precisión, recall y F1 score para cada intención y entidad, y una matriz de confusión que muestra qué intenciones se confunden. Corrige la confusión con ejemplos más claros o más variados. Luego implementa el modelo en una implementación con nombre (como production). Las aplicaciones consultan el endpoint de predicción con el nombre del proyecto, el nombre de la implementación y la expresión del usuario, y reciben la intención principal con una puntuación de confianza, las puntuaciones de las demás intenciones y las entidades extraídas. Tu aplicación decide qué hacer cuando la puntuación principal es baja, como pedirle al usuario que lo reformule.

CLU también puede formar parte de un proyecto de flujo de trabajo de orquestación (orchestration workflow), que enruta las expresiones a proyectos de CLU o a proyectos de respuesta a preguntas personalizada.

Términos clave

Intent (intención)
El objetivo o la acción que un usuario expresa en una expresión, como BookFlight.
Entity (entidad)
Un dato de una expresión que la aplicación necesita, como una fecha o un destino.
Utterance (expresión)
Una frase de ejemplo que un usuario podría decir, usada para entrenar y probar el modelo.
None intent (intención None)
La intención integrada que captura las expresiones fuera del alcance de la aplicación.
Ejemplo real

El proyecto de CLU de una cadena de pizzerías tiene las intenciones OrderPizza, TrackOrder y None, una entidad de lista para los tamaños con sinónimos (large, big, family), una entidad precompilada datetime para la hora de entrega y una entidad regex para los números de pedido. Después de que la matriz de confusión mostró que TrackOrder y OrderPizza se mezclaban, el equipo agregó 20 expresiones variadas de seguimiento y volvió a entrenar.

Consejo para el examen: Entradas fuera de alcance que caen en una intención real: agrega ejemplos a None. Un conjunto fijo de valores con sinónimos: entidad de lista. Patrones como códigos: entidad regex. Valores que varían según el contexto: entidad aprendida.

Comprueba lo que sabes

¿Qué devuelve una predicción de CLU?

La intención principal con su confianza, las puntuaciones de las demás intenciones y las entidades extraídas.

¿Por qué mantener equilibrado el número de expresiones entre intenciones?

Una intención con muchos más ejemplos puede sesgar las predicciones hacia ella y provocar que otras intenciones se clasifiquen mal.
