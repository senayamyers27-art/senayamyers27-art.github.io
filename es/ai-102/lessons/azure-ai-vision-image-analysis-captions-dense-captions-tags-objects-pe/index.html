Image Analysis de Azure AI Vision: captions, dense captions, etiquetas, objetos, personas y smart crops

La API Image Analysis de Azure AI Vision describe lo que hay en una imagen usando modelos precompilados entrenados por Microsoft, sin que tengas que entrenar nada. Envías una imagen (como URL o como datos binarios) y una lista de las características visuales que quieres, y el servicio devuelve JSON con los resultados y puntuaciones de confianza. La versión actual, Image Analysis 4.0, se llama en la ruta imageanalysis:analyze con un parámetro de consulta features, o mediante el ImageAnalysisClient de los SDK de Python y C#.

Cada característica responde a una pregunta distinta. Caption devuelve una oración legible que describe toda la imagen, como 'un hombre que anda en bicicleta por una calle de la ciudad'. Dense captions devuelve oraciones para varias regiones de la imagen (hasta diez) además de la imagen completa, cada una con un cuadro delimitador, lo que es útil para descripciones detalladas y accesibilidad. Tags devuelve palabras sueltas para objetos, seres vivos, paisajes y acciones, cada una con una puntuación de confianza, útil para búsqueda y catalogación. Objects detecta objetos físicos comunes y devuelve sus nombres y cuadros delimitadores, para que sepas dónde está cada objeto y cuántos hay. People detecta personas y devuelve sus cuadros delimitadores; no identifica quiénes son. Smart crops sugiere regiones de recorte que conservan la zona más importante de la imagen para las relaciones de aspecto que solicites, útil para miniaturas. Read extrae texto y se trata en la siguiente lección.

from azure.ai.vision.imageanalysis import ImageAnalysisClient
from azure.ai.vision.imageanalysis.models import VisualFeatures

client = ImageAnalysisClient(endpoint=endpoint, credential=AzureKeyCredential(key))
result = client.analyze(image_data=data,
    visual_features=[VisualFeatures.CAPTION, VisualFeatures.TAGS, VisualFeatures.OBJECTS],
    gender_neutral_caption=True)
print(result.caption.text, result.caption.confidence)
for obj in result.objects.list:
    print(obj.tags[0].name, obj.bounding_box)

Entre las opciones útiles están gender-neutral-caption (para que las descripciones digan 'persona' en lugar de 'hombre' o 'mujer'), language para etiquetas y descripciones en otros idiomas, y las relaciones de aspecto para smart crops. Caption y dense captions solo están disponibles en algunas regiones de Azure, así que revisa la compatibilidad por región antes de crear el recurso. Algunas funciones más antiguas de la versión 3.2, como la detección de marcas, los indicadores de contenido para adultos y las categorías de imagen, pertenecen a la API anterior; para moderación, usa Azure AI Content Safety.

Interpreta las puntuaciones de confianza con sensatez: define un umbral adecuado a tu uso, por ejemplo usa solo las etiquetas por encima de 0.8 para la catalogación automática y envía las más bajas a revisión humana. Recuerda lo que los modelos precompilados no pueden hacer: reconocen conceptos generales, no tus modelos de producto específicos ni tus tipos de defecto. Para eso necesitas un modelo personalizado, que se trata en las lecciones de Custom Vision.

Términos clave

Caption
Una característica de Image Analysis que devuelve una oración que describe toda la imagen.
Dense captions
Una característica de Image Analysis que devuelve descripciones con cuadros delimitadores para varias regiones de una imagen.
Tags (etiquetas)
Etiquetas de una sola palabra para el contenido de una imagen, cada una con una puntuación de confianza.
Smart crops (recortes inteligentes)
Regiones de recorte sugeridas que conservan la parte más importante de una imagen para relaciones de aspecto dadas.
Ejemplo real

Un sitio de noticias genera texto alternativo para cada foto con la característica caption (con género neutro), guarda las etiquetas con confianza superior a 0.8 para su búsqueda de fotos y usa smart crops en 1:1 y 16:9 para crear miniaturas que mantengan en el encuadre los rostros y los sujetos.

Consejo para el examen: Una oración para toda la imagen es caption; oraciones con cuadros para regiones es dense captions; palabras sueltas son tags; dónde están las cosas es objects; detectar personas no es identificarlas.

Comprueba lo que sabes

¿Qué característica te dice cuántos autos hay en una foto y dónde están?

Objects, que devuelve el nombre y el cuadro delimitador de cada objeto detectado.

Un sitio necesita miniaturas en varias relaciones de aspecto que conserven el sujeto principal. ¿Qué característica ayuda?

Smart crops con las relaciones de aspecto requeridas.
