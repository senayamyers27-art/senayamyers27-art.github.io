Análisis de texto con Azure AI Language: detección de idioma, frases clave, entidades, vinculación de entidades y sentimiento con minería de opiniones

Azure AI Language ofrece funciones precompiladas de procesamiento de lenguaje natural (NLP) que analizan texto sin ningún entrenamiento. Envías documentos (texto simple con un id y, opcionalmente, un código de idioma) y eliges el tipo de análisis. La llamada REST hace un POST a la ruta language/:analyze-text con un kind como LanguageDetection, KeyPhraseExtraction, EntityRecognition, EntityLinking o SentimentAnalysis; los SDK exponen métodos como detect_language y analyze_sentiment. Los resultados se devuelven por documento, con los errores informados por documento para que una entrada defectuosa no haga fallar el lote. Los trabajos más grandes, y la combinación de varios análisis en una solicitud, usan el endpoint asíncrono de trabajos analyze-text.

La detección de idioma devuelve el idioma de cada documento como nombre y código ISO 639-1 (por ejemplo 'fr') con una puntuación de confianza. A menudo es el primer paso de una canalización, para que las llamadas posteriores o la traducción usen el idioma correcto. El texto muy corto o con varios idiomas reduce la confianza, y puedes pasar una pista de país (country hint) para resolver ambigüedades.

La extracción de frases clave devuelve los puntos principales de un texto, como 'duración de la batería' y 'servicio al cliente', útil para etiquetar, resumir tendencias y buscar. El reconocimiento de entidades con nombre (NER) encuentra entidades y las clasifica en tipos como Person, Location, Organization, DateTime, Quantity, Email y URL, con subcategorías y puntuaciones de confianza. La vinculación de entidades (entity linking) va un paso más allá y desambigua las entidades vinculándolas a una entrada de una base de conocimiento (Wikipedia), de modo que 'Mars' en 'Mars lanzó una nueva barra de chocolate' se vincula a la empresa, no al planeta.

El análisis de sentimiento etiqueta cada documento y cada oración como positivo, negativo, neutral o mixto, con puntuaciones de confianza para positivo, neutral y negativo. Mixto significa que las oraciones no coinciden. La minería de opiniones (opinion mining, sentimiento basado en aspectos) agrega detalle: encuentra objetivos (aspectos como 'habitación' o 'desayuno') y las valoraciones sobre ellos ('amplia', 'frío'), cada uno con su propio sentimiento. Actívala con show_opinion_mining=True en el SDK o con el parámetro opinionMining en REST. Responde preguntas como '¿qué es exactamente lo que no les gusta a los clientes?'.

Otras funciones precompiladas incluyen el resumen (extractivo, que elige oraciones clave, y abstractivo, que redacta texto de resumen nuevo), Text Analytics for health (entidades y relaciones médicas) y la detección de PII, que se trata a continuación. Los documentos tienen límites de tamaño por solicitud, así que los textos largos se dividen. Muchas funciones también pueden ejecutarse en contenedores.

Términos clave

Language detection (detección de idioma)
Identificar el idioma de un texto, devuelto como nombre, código ISO y puntuación de confianza.
Named entity recognition (reconocimiento de entidades con nombre)
Encontrar entidades en un texto y clasificarlas en categorías como Person, Location y Organization.
Entity linking (vinculación de entidades)
Desambiguar una entidad vinculándola a una entrada específica de una base de conocimiento.
Opinion mining (minería de opiniones)
Sentimiento basado en aspectos que conecta el sentimiento con objetivos específicos mencionados en el texto.
Ejemplo real

Una cadena hotelera procesa 50,000 reseñas al mes con Language. La detección de idioma las enruta, las frases clave muestran los temas en tendencia y la minería de opiniones revela que 'Wi-Fi' es el objetivo negativo más frecuente en dos sedes, así que la cadena mejora primero la red en esos lugares.

Consejo para el examen: Positivo o negativo en general es sentimiento; qué aspecto gusta o disgusta es minería de opiniones. Clasificar entidades es NER; resolver a qué cosa real se refiere una entidad es vinculación de entidades.

Comprueba lo que sabes

¿Qué significa un resultado de sentimiento mixed?

El documento contiene oraciones con sentimientos distintos, por ejemplo algunas positivas y otras negativas.

¿Qué función distinguiría a París la ciudad de Paris la persona?

La vinculación de entidades, que vincula cada mención con una entrada específica de una base de conocimiento.
