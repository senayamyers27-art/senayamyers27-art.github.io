Custom Vision: clasificación de imágenes (multiclase frente a multietiqueta) frente a detección de objetos

Image Analysis precompilado conoce miles de conceptos generales, pero no los tuyos en particular: tu línea de productos, tus tipos de defectos, tus especies de plantas. Azure AI Custom Vision te permite entrenar tus propios modelos de imagen a partir de tus propias imágenes etiquetadas con pocos conocimientos de aprendizaje automático, usando un portal web o un SDK. Microsoft anunció un retiro futuro de Custom Vision y orienta los proyectos nuevos hacia otras opciones, así que revisa su estado actual, pero sigue formando parte de los objetivos de AI-102.

La primera decisión es el tipo de proyecto. La clasificación de imágenes asigna etiquetas (llamadas tags) a una imagen completa. Responde '¿de qué es esta imagen?', pero no '¿dónde?'. La detección de objetos encuentra instancias de objetos en una imagen y devuelve una etiqueta y un cuadro delimitador para cada una, así que responde '¿qué, dónde y cuántos?'.

La clasificación puede ser de dos tipos. Multiclase significa que cada imagen tiene exactamente una etiqueta del conjunto: una foto es de un gato, de un perro o de un conejo, nunca de dos. El modelo devuelve probabilidades para cada etiqueta y tomas la más alta. Multietiqueta significa que una imagen puede tener cualquier número de etiquetas a la vez: una foto de una calle podría etiquetarse con auto, bicicleta y semáforo. Elige según si tus categorías son mutuamente excluyentes.

La detección de objetos requiere más esfuerzo de etiquetado, porque dibujas un cuadro alrededor de cada instancia de cada objeto en cada imagen de entrenamiento. Se necesita cuando importan la ubicación o el conteo: encontrar cada rayón en un panel, contar productos en un estante, localizar un logotipo en un fotograma de video.

También eliges un dominio, que es el modelo base del que parte Custom Vision. Los dominios generales sirven para la mayoría de las tareas; existen dominios especializados para comida, lugares emblemáticos y comercio minorista (clasificación) o logotipos y productos en estantes (detección). Los dominios compactos producen modelos más pequeños que pueden exportarse para ejecutarse sin conexión en dispositivos, con cierto costo en precisión. No puedes exportar un modelo que no sea compacto, así que si el uso sin conexión es un requisito, elige un dominio compacto desde el principio (puedes cambiar de dominio más adelante y volver a entrenar).

Una solución de Custom Vision usa dos recursos: un recurso de entrenamiento donde cargas imágenes, las etiquetas y entrenas, y un recurso de predicción que aloja los modelos publicados para que tu aplicación los llame. Un solo recurso multiservicio o de Custom Vision puede cumplir ambos roles.

Términos clave

Multiclass classification (clasificación multiclase)
Un tipo de clasificación en el que cada imagen recibe exactamente una etiqueta.
Multilabel classification (clasificación multietiqueta)
Un tipo de clasificación en el que cada imagen puede tener cualquier número de etiquetas.
Object detection (detección de objetos)
Un tipo de modelo que devuelve una etiqueta y un cuadro delimitador para cada instancia de un objeto en una imagen.
Compact domain (dominio compacto)
Un modelo base de Custom Vision que produce modelos más pequeños y exportables para uso sin conexión y en el perímetro.
Ejemplo real

Una planta de reciclaje quiere clasificar los artículos en una banda transportadora. Cada fotograma de la cámara muestra varios artículos, y el brazo robótico necesita la posición y el material de cada uno. El equipo crea un proyecto de detección de objetos con las etiquetas plástico, vidrio y metal en un dominio compacto para que el modelo pueda ejecutarse en el dispositivo perimetral de la línea.

Consejo para el examen: Exactamente una etiqueta por imagen: multiclase. Varias etiquetas por imagen: multietiqueta. Ubicación o conteo: detección de objetos. Sin conexión o en el perímetro: dominio compacto.

Comprueba lo que sabes

La foto de un platillo debe etiquetarse con cada ingrediente visible. ¿Qué tipo de proyecto?

Clasificación multietiqueta, porque cada imagen puede tener varias etiquetas y no se necesitan ubicaciones.

¿Por qué elegirías un dominio compacto?

Para exportar el modelo y ejecutarlo sin conexión en dispositivos como teléfonos o hardware perimetral.
