Generación de imágenes y trabajo con modelos de chat multimodales que aceptan imágenes

La IA generativa no se limita al texto. En el examen aparecen dos capacidades: crear imágenes a partir de texto y enviar imágenes a un modelo de chat para que razone sobre ellas.

Los modelos de generación de imágenes como DALL-E 3, y los modelos de imagen GPT más recientes donde estén disponibles, crean imágenes nuevas a partir de un prompt en lenguaje natural. Implementas el modelo como cualquier otro y llamas a la API de imágenes con un prompt, el número de imágenes, un tamaño (DALL-E 3 admite formatos cuadrado, horizontal y vertical) y opciones como calidad y estilo. La respuesta devuelve una URL a la imagen generada, válida por un tiempo limitado, o la imagen codificada como datos base64. DALL-E 3 puede reescribir tu prompt para agregar detalle, y la respuesta incluye el prompt revisado. Los modelos de imagen aplican filtros de contenido tanto al prompt como a la imagen generada, y en muchos casos rechazan solicitudes de figuras públicas o personajes protegidos por derechos de autor. Los buenos prompts describen de forma explícita el sujeto, el entorno, el estilo, la iluminación y la composición.

Los modelos de chat multimodales, como GPT-4o y otros modelos con visión, aceptan imágenes como parte del mensaje del usuario. En lugar de una cadena simple, el contenido del mensaje es una lista de partes: una parte de texto con la pregunta y una o más partes de imagen que contienen una URL que el servicio puede descargar o una data URL en base64. El modelo puede describir la imagen, responder preguntas sobre ella, leer texto y gráficas que contenga, comparar varias imágenes o extraer información a JSON.

resp = client.chat.completions.create(
    model="vision-chat",
    messages=[{"role": "user", "content": [
        {"type": "text", "text": "What trend does this sales chart show?"},
        {"type": "image_url", "image_url": {"url": data_url}}
    ]}])

Las imágenes consumen tokens, y el costo depende del tamaño de la imagen y del ajuste de detalle: el detalle bajo procesa una versión pequeña por un costo fijo bajo, mientras que el detalle alto divide la imagen en mosaicos para mayor precisión con un costo más alto. Elige detalle bajo cuando baste con una comprensión general.

Debes saber cuándo usar cada herramienta. Un modelo multimodal es flexible y excelente para preguntas abiertas sobre una imagen, pero para tareas bien definidas y de gran volumen, como extraer campos de facturas o etiquetar millones de fotos, los servicios diseñados para ese fin como Document Intelligence y Azure AI Vision suelen ser más baratos, más rápidos y más coherentes. Generar imágenes nuevas siempre requiere un modelo de generación de imágenes; los modelos de chat describen imágenes pero no las dibujan.

Términos clave

Image generation model (modelo de generación de imágenes)
Un modelo como DALL-E 3 que crea imágenes nuevas a partir de un prompt de texto.
Multimodal model (modelo multimodal)
Un modelo que acepta más de un tipo de entrada, como texto e imágenes, en la misma solicitud.
Revised prompt (prompt revisado)
El prompt ampliado que DALL-E 3 realmente usó, que se devuelve junto con la imagen generada.
Detail setting (ajuste de detalle)
Una opción que controla cuánto de una imagen de entrada procesa el modelo, equilibrando costo y precisión.
Ejemplo real

Una aplicación de seguros permite a los clientes fotografiar los daños de su auto. Un modelo de chat con visión describe los daños visibles y llena un resumen de reclamación en JSON para que lo revise un ajustador, mientras que el equipo de marketing usa por separado DALL-E 3 para crear ilustraciones para la guía de reclamaciones.

Consejo para el examen: Crear imágenes significa un modelo de generación de imágenes; hacer preguntas sobre una imagen significa enviarla como parte de imagen a un modelo de chat con visión. Para extracción estructurada de gran volumen, prefiere Document Intelligence o Vision.

Comprueba lo que sabes

¿Cómo envías una imagen a un modelo de chat multimodal?

Haz que el contenido del mensaje del usuario sea una lista con una parte de texto y una parte image_url que contenga una URL o una data URL en base64.

¿Qué dos formas puede devolver una respuesta de generación de imágenes?

Una URL temporal a la imagen o la imagen como datos codificados en base64.
