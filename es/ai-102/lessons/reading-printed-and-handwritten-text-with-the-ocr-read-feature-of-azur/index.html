Lectura de texto impreso y manuscrito con la función OCR (Read) de Azure AI Vision

El reconocimiento óptico de caracteres (OCR) convierte el texto de las imágenes en texto legible por máquinas. Azure AI Vision lo ofrece mediante la función Read, que reconoce texto impreso y manuscrito en muchos idiomas en fotos, capturas de pantalla y escaneos: letreros de calles, etiquetas de productos, pizarras, carteles y notas escritas a mano.

En Image Analysis 4.0, Read es simplemente una de las características visuales: solicitas read junto con caption y tags, o en lugar de ellas, y la llamada devuelve el resultado de forma síncrona. El resultado se organiza en bloques, líneas y palabras. Cada línea tiene su texto y un polígono delimitador (cuatro puntos de esquina, para describir con precisión el texto girado), y cada palabra tiene su texto, su polígono y una puntuación de confianza. Tu código puede unir las líneas en una transcripción, buscar palabras específicas o usar las posiciones para entender el diseño, como qué texto aparece cerca de un logotipo.

result = client.analyze(image_data=data, visual_features=[VisualFeatures.READ])
for block in result.read.blocks:
    for line in block.lines:
        print(line.text)
        for word in line.words:
            if word.confidence < 0.8:
                print('  low confidence:', word.text)

Elige el servicio de OCR adecuado para cada trabajo. Vision Read está optimizado para imágenes generales que no son documentos: escenas, letreros, etiquetas y textos cortos. Para documentos como PDF de varias páginas, formularios, facturas e informes escaneados, Azure AI Document Intelligence es la mejor opción: su modelo read maneja documentos grandes de varias páginas, y sus modelos layout y precompilados agregan párrafos, tablas, marcas de selección y campos con nombre. La antigua API Read asíncrona de Computer Vision 3.2 (enviar, obtener un Operation-Location, consultar los resultados) es el origen del modelo read de Document Intelligence, y todavía puedes verla en código antiguo. El OCR también está disponible como skill integrada en Azure AI Search, para que los archivos escaneados puedan volverse buscables durante la indexación.

La calidad depende de la entrada. Usa buena resolución e iluminación, evita el desenfoque fuerte y los ángulos extremos, y revisa las puntuaciones de confianza de las palabras. El reconocimiento de escritura a mano funciona bien con letra clara, pero es menos fiable con letra desordenada, así que planifica una revisión humana de las palabras con baja confianza. Si solo necesitas números o campos específicos de un formulario conocido, un modelo de Document Intelligence da una salida estructurada en lugar de texto sin procesar que tendrías que analizar.

Términos clave

OCR
Reconocimiento óptico de caracteres: extraer texto legible por máquinas a partir de imágenes de texto.
Read feature (función Read)
La capacidad de Azure AI Vision que extrae texto impreso y manuscrito con posiciones y confianza.
Bounding polygon (polígono delimitador)
Los puntos de esquina que delimitan dónde aparece una línea o una palabra en la imagen, incluido el texto girado.
Line and word (línea y palabra)
Los niveles en los que Read devuelve el texto, cada uno con posición; las palabras también incluyen puntuaciones de confianza.
Ejemplo real

Una empresa de logística fotografía etiquetas de envío con escáneres de mano. Vision Read extrae las líneas de texto, la aplicación encuentra en ellas el patrón del número de seguimiento y marca las palabras con confianza inferior a 0.8 para que un trabajador las confirme, mientras que la documentación completa de entrega va a Document Intelligence.

Consejo para el examen: Texto en fotos y escenas apunta a Vision Read; documentos largos, tablas y campos de formulario apuntan a Document Intelligence. Read devuelve líneas y palabras con polígonos y la confianza de cada palabra.

Comprueba lo que sabes

¿Qué estructura devuelve Read?

Bloques que contienen líneas, cada una con texto y un polígono delimitador, y palabras con texto, polígono y una puntuación de confianza.

¿Por qué usar Document Intelligence en lugar de Vision Read para un contrato escaneado de 40 páginas?

Document Intelligence está diseñado para documentos de varias páginas y agrega estructura como párrafos y tablas, mientras que Vision Read está optimizado para imágenes generales.
