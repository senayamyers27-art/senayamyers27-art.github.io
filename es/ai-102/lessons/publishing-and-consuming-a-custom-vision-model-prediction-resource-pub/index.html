Publicación y consumo de un modelo de Custom Vision: recurso de predicción, iteraciones publicadas y exportación de modelos compactos

Una iteración entrenada todavía no está disponible para tu aplicación. La pones a disposición publicándola en un recurso de predicción o exportándola para ejecutarla en otro lugar. Conocer este paso explica un escenario clásico del examen: el modelo se volvió a entrenar, pero la aplicación sigue comportándose igual.

Publicar toma una iteración elegida y la implementa en un recurso de predicción con un nombre de publicación que eliges, como productModel. Tu aplicación llama al endpoint de predicción con el ID del proyecto y ese nombre de publicación, enviando una URL de imagen o los bytes de la imagen, con la clave del recurso de predicción en el encabezado Prediction-Key (o con el cliente de predicción del SDK). La respuesta lista cada etiqueta con su probabilidad en clasificación, o la etiqueta, la probabilidad y el cuadro delimitador de cada objeto detectado en detección. El cuadro delimitador se expresa como izquierda, arriba, ancho y alto en fracciones del tamaño de la imagen, así que multiplica por las dimensiones de la imagen para dibujarlo.

El nombre de publicación es un puntero estable. Cuando entrenas una iteración mejor, la aplicación sigue llamando al mismo nombre de publicación, así que debes publicar la nueva iteración con ese nombre (despublicando antes la anterior, o publicándola y moviendo el nombre). Hasta que lo hagas, el endpoint sirve el modelo anterior. Esto facilita la reversión: vuelve a publicar la iteración anterior con ese nombre. También puedes publicar varias iteraciones con nombres distintos para probarlas en paralelo.

Para ejecutar un modelo sin conexión o en el perímetro, expórtalo. La exportación solo está disponible para iteraciones entrenadas con un dominio compacto. Los formatos incluyen TensorFlow y TensorFlow Lite para Android y uso general, Core ML para iOS, ONNX para Windows ML y muchos entornos de ejecución, y Dockerfiles que construyen un contenedor para dispositivos Linux, Windows o ARM, como módulos de Azure IoT Edge. Los modelos exportados se ejecutan sin llamar a Azure, así que funcionan sin conectividad y no tienen cargo por predicción, pero tú debes volver a implementarlos cuando vuelvas a entrenar.

Mantén separados en tu mente los dos roles de recurso: el recurso y la clave de entrenamiento sirven para administrar proyectos, cargar imágenes y entrenar; el recurso y la clave de predicción sirven para llamar a los modelos publicados. Usar la clave de entrenamiento contra el endpoint de predicción, o llamar a una iteración no publicada, produce errores.

Términos clave

Publish name (nombre de publicación)
El nombre con el que una iteración se publica en un recurso de predicción y con el que la llaman las aplicaciones.
Prediction resource (recurso de predicción)
El recurso de Custom Vision que aloja las iteraciones publicadas y atiende las solicitudes de predicción.
Prediction-Key
El encabezado HTTP que lleva la clave del recurso de predicción al llamar a un modelo publicado.
Export (exportación)
Descargar un modelo de dominio compacto en un formato como ONNX, TensorFlow, Core ML o un contenedor Docker para uso sin conexión.
Ejemplo real

La aplicación de un minorista llama al nombre de publicación shelfModel. Después de entrenar la iteración 6 con nuevas imágenes de productos, los evaluadores no notan ninguna mejora. El ingeniero ve que la iteración 4 todavía tiene el nombre de publicación, publica la iteración 6 como shelfModel y la aplicación usa de inmediato el nuevo modelo sin cambios de código.

Consejo para el examen: Se volvió a entrenar pero la aplicación no cambia: la nueva iteración no se publicó con el nombre que llama la aplicación. Uso sin conexión: exportar, lo que requiere un dominio compacto.

Comprueba lo que sabes

¿Cómo se expresan los cuadros delimitadores de la detección de objetos en una respuesta de predicción?

Como valores de izquierda, arriba, ancho y alto normalizados como fracciones del ancho y el alto de la imagen.

¿Qué clave usa una aplicación para llamar a un modelo publicado de Custom Vision?

La clave del recurso de predicción, enviada en el encabezado Prediction-Key.
