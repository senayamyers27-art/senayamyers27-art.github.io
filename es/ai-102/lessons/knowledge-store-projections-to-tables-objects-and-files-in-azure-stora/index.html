Knowledge store: proyecciones a tablas, objetos y archivos en Azure Storage

El enriquecimiento con IA produce datos valiosos: entidades, frases clave, sentimiento, texto de OCR, etiquetas de imágenes. Un índice de búsqueda está hecho para consultas, no para análisis, ciencia de datos u otras aplicaciones. Un knowledge store guarda la salida enriquecida de un skillset en Azure Storage para que otras herramientas puedan usarla, de forma independiente del índice.

Defines un knowledge store en el skillset con una conexión a una cuenta de almacenamiento (una cadena de conexión o una identidad administrada) y una o más proyecciones. Las proyecciones describen qué datos guardar y con qué forma. Hay tres tipos. Las proyecciones de tabla escriben filas en Azure Table Storage, ideales para análisis en Power BI u otras herramientas que esperan datos tabulares; puedes proyectar tablas relacionadas, como una tabla Documents y una tabla KeyPhrases con una clave que vincula cada frase con su documento. Las proyecciones de objeto escriben documentos JSON en Blob Storage, conservando la estructura jerárquica, lo que es útil para canalizaciones de ciencia de datos o para cargar en otras bases de datos. Las proyecciones de archivo escriben archivos binarios, normalmente las imágenes normalizadas extraídas durante el document cracking, en Blob Storage.

Las proyecciones toman sus datos del árbol de enriquecimiento. Como el árbol puede ser complejo, a menudo usas primero la skill Shaper para construir una forma personalizada, un solo objeto con exactamente los campos que quieres, y proyectas esa forma. Como alternativa, el modelado en línea (inline shaping) define la forma dentro de la propia proyección. Cada proyección indica su ruta de origen, como /document/projectionShape, y un nombre de tabla o un contenedor.

Los grupos de proyección controlan las relaciones. Las proyecciones dentro del mismo grupo comparten una clave generada, de modo que las filas de tablas relacionadas pueden volver a unirse (por ejemplo, una fila de documento y sus filas de entidades). Las proyecciones en grupos distintos son copias independientes sin vínculo, lo que es útil cuando distintos consumidores quieren formas distintas de los mismos datos.

"knowledgeStore": { "storageConnectionString": "<connection>",
  "projections": [ { "tables": [
      { "tableName": "Docs", "source": "/document/projectionShape" },
      { "tableName": "KeyPhrases", "source": "/document/projectionShape/keyPhrases/*" } ],
    "objects": [ { "storageContainer": "enriched", "source": "/document/projectionShape" } ],
    "files": [] } ] }

El knowledge store se escribe cuando se ejecuta el indexador, llenes o no también un índice. Storage Browser en el portal o Storage Explorer te permiten inspeccionar las tablas y los blobs.

Términos clave

Knowledge store
La salida en Azure Storage de los datos enriquecidos de un skillset, guardada para usos más allá de la búsqueda.
Table projection (proyección de tabla)
Una proyección que escribe los datos enriquecidos como filas en Azure Table Storage.
Object projection (proyección de objeto)
Una proyección que escribe los datos enriquecidos como documentos JSON en Blob Storage.
Shaper skill
Una skill de utilidad que construye una forma de datos personalizada a partir del árbol de enriquecimiento para su proyección.
Ejemplo real

Una empresa de investigación de mercados enriquece 100,000 respuestas de encuestas con sentimiento y frases clave. Una skill Shaper construye una forma de respuesta, proyecciones de tabla en un mismo grupo escriben las tablas Responses y KeyPhrases vinculadas por clave, y los analistas crean un informe de Power BI con las principales frases de queja por región, mientras el mismo indexador también llena el índice de búsqueda.

Consejo para el examen: Análisis en Power BI: proyecciones de tabla. JSON jerárquico para otros sistemas: proyecciones de objeto. Imágenes extraídas: proyecciones de archivo. Tablas relacionadas que deben unirse: el mismo grupo de proyección.

Comprueba lo que sabes

¿Qué tipo de proyección usarías para guardar las imágenes normalizadas extraídas de los PDF?

Proyecciones de archivo, que escriben archivos binarios como imágenes en Blob Storage.

¿Por qué poner las proyecciones de tabla en el mismo grupo de proyección?

Para que compartan las claves generadas y las filas relacionadas puedan volver a unirse.
