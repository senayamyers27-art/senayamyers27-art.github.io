Endpoints, claves y SDK: cómo llamar a los servicios de Azure AI con REST y los SDK de Python y C#

En el fondo, todo servicio de Azure AI es una API REST. Tu aplicación envía una solicitud HTTPS al endpoint del recurso con una ruta para la operación, un parámetro de consulta api-version, una credencial y, por lo general, un cuerpo JSON. Los SDK para Python, C#, JavaScript y Java envuelven estas llamadas para que trabajes con objetos tipados en lugar de JSON sin procesar, pero conocer la forma de la llamada REST te ayuda a depurar y a responder preguntas del examen que muestran una solicitud.

Encuentras el endpoint y las claves en la página Keys and Endpoint del recurso en el portal o con la CLI. Con una clave, la mayoría de los servicios de Azure AI esperan el encabezado Ocp-Apim-Subscription-Key, mientras que Azure OpenAI usa un encabezado api-key. Con Microsoft Entra ID envías en su lugar Authorization: Bearer <token>. El endpoint global de Translator también necesita un encabezado Ocp-Apim-Subscription-Region cuando usas una clave regional o multiservicio. Los clientes del SDK de Speech se crean a partir de una clave y una región, o de un endpoint.

Una llamada típica a Language hace un POST a la ruta language/:analyze-text del endpoint con un cuerpo que indica el kind de análisis, como SentimentAnalysis, y una lista de documentos, cada uno con id, language y text. La respuesta devuelve resultados por id de documento más cualquier error, de modo que un documento defectuoso no hace fallar todo el lote. Muchas operaciones sobre entradas grandes, como el análisis de Document Intelligence, la transcripción por lotes o la traducción de documentos, son asíncronas: la primera solicitud devuelve 202 Accepted con un encabezado Operation-Location, y consultas esa ubicación periódicamente hasta que el estado sea succeeded.

from azure.ai.textanalytics import TextAnalyticsClient
from azure.core.credentials import AzureKeyCredential

client = TextAnalyticsClient(endpoint=endpoint, credential=AzureKeyCredential(key))
result = client.analyze_sentiment(["The room was lovely but breakfast was cold."], show_opinion_mining=True)
for doc in result:
    print(doc.sentiment, doc.confidence_scores)

En C# el patrón es el mismo: crea un cliente como TextAnalyticsClient con un Uri y un AzureKeyCredential o un DefaultAzureCredential, y luego llama a un método como AnalyzeSentimentAsync. DefaultAzureCredential, de la biblioteca Azure Identity, prueba varias fuentes en orden (variables de entorno, identidad administrada, tu inicio de sesión de desarrollador), así que el mismo código funciona en tu laptop y en Azure sin claves.

Lee los códigos de error con atención: 401 significa una credencial incorrecta o ausente, 403 a menudo significa que la identidad no tiene un rol o que la red te bloquea, 404 suele significar una ruta, un modelo o un nombre de implementación incorrectos, y 429 significa que estás siendo limitado por velocidad.

Términos clave

Endpoint
La URL base de un recurso de Azure AI a la que se envían todas las llamadas a la API.
Ocp-Apim-Subscription-Key
El encabezado HTTP que transporta la clave del recurso para la mayoría de los servicios de Azure AI.
DefaultAzureCredential
Una clase de Azure Identity que encuentra automáticamente una credencial de Microsoft Entra ID en el entorno, la identidad administrada o el inicio de sesión del desarrollador.
Operation-Location
El encabezado que devuelven las operaciones asíncronas y que apunta a la URL que consultas para obtener el resultado.
Ejemplo real

La llamada de una desarrolladora a Document Intelligence devuelve 202 y ningún dato. Al leer los encabezados de la respuesta encuentra Operation-Location, cambia al poller begin_analyze_document del SDK y ahora el código espera hasta que el análisis termine correctamente antes de leer los campos.

Consejo para el examen: Conoce los códigos de estado: 401 problema de credencial, 403 bloqueo por permisos o por red, 404 ruta o nombre de implementación incorrectos, 429 límite de velocidad, 202 operación asíncrona iniciada.

Comprueba lo que sabes

¿Qué encabezado lleva la clave para Azure AI Language y cuál para Azure OpenAI?

Ocp-Apim-Subscription-Key para Language (y la mayoría de los servicios de IA); api-key para Azure OpenAI.

¿Por qué es útil DefaultAzureCredential?

El mismo código se autentica con tu inicio de sesión de desarrollador en local y con una identidad administrada en Azure, así que no se necesita ninguna clave en el código ni en la configuración.
