Qué es un agente de IA: modelo, instrucciones y herramientas, y cuándo un agente encaja mejor que una simple aplicación de chat

Un agente de IA es software que usa un modelo de lenguaje para perseguir un objetivo en nombre de un usuario, decidiendo qué hacer a continuación y realizando acciones mediante herramientas. Una aplicación de chat simple envía un prompt y muestra la respuesta. Un agente ejecuta un ciclo: lee la solicitud, decide si necesita información o una acción, llama a una herramienta, revisa el resultado y repite hasta que puede dar una respuesta final o completar la tarea.

Todo agente tiene tres partes centrales. El modelo aporta la capacidad de razonamiento y de lenguaje; normalmente es un modelo de chat o de razonamiento implementado en tu proyecto de Foundry. Las instrucciones, como un mensaje del sistema, definen el rol del agente, sus objetivos, reglas, tono y cuándo pedir ayuda o transferir la conversación. Las herramientas son las manos del agente: funciones, API, índices de búsqueda, un intérprete de código u otros agentes a los que puede llamar. Las plataformas de agentes agregan estado, normalmente un hilo (thread) que guarda la conversación y los resultados de las herramientas, para que el agente pueda trabajar a lo largo de muchos turnos.

Los agentes encajan en tareas que requieren varios pasos, datos en vivo o acciones. 'Revisa el estado del pedido 1234 y, si se envió hace más de diez días, abre una reclamación y envíale al cliente una etiqueta por correo' requiere llamar a una API de pedidos, aplicar una regla, llamar a una API de reclamaciones y enviar un correo: esa es una tarea para un agente. Otros buenos casos son la investigación que combina varias fuentes, el análisis de datos en el que el agente escribe y ejecuta código, y los asistentes de TI o RR. HH. que pueden abrir tickets. Los agentes también son una buena forma de empaquetar una aplicación RAG, con la búsqueda como una herramienta entre otras.

Una chat completion simple es mejor cuando la tarea es una sola transformación de un texto que ya tienes: reescribe este párrafo, traduce esta oración, resume este documento, clasifica este ticket. Agregar un agente ahí solo añade latencia, costo y más formas de fallar. Lo mismo aplica a los flujos de trabajo fijos cuyos pasos nunca cambian; el código normal o un servicio de flujos de trabajo es más predecible que dejar que un modelo elija.

La autonomía trae riesgos. Un agente que puede enviar correos o emitir reembolsos puede causar daños si malinterpreta algo o si lo manipulan instrucciones inyectadas. Un buen diseño de agentes da la menor cantidad de herramientas con el mínimo privilegio, exige aprobación humana para las acciones importantes, valida las entradas de las herramientas y hace seguimiento de cada paso; son temas que se tratan más adelante en este dominio.

En Azure puedes crear agentes con Azure AI Foundry Agent Service, que los aloja por ti, o en código con frameworks como Semantic Kernel, AutoGen y Microsoft Agent Framework.

Términos clave

AI agent (agente de IA)
Software que usa un modelo para planificar y realizar acciones mediante herramientas en un ciclo para lograr un objetivo.
Tool (herramienta)
Una capacidad que un agente puede invocar, como una función, una API, un índice de búsqueda o un intérprete de código.
Instructions (instrucciones)
La guía a nivel de sistema del agente que define su rol, objetivos, reglas y comportamiento.
Thread (hilo)
El estado guardado de la conversación, incluidos los mensajes y los resultados de las herramientas, con el que trabaja un agente a lo largo de los turnos.
Ejemplo real

Una empresa de viajes creó primero un chatbot que respondía preguntas sobre políticas. Los clientes le pedían constantemente que cambiara sus reservas, así que la empresa creó un agente con herramientas para consultar reservas, revisar las reglas de tarifas y solicitar cambios, exigiendo que el cliente confirmara antes de enviar cualquier cambio.

Consejo para el examen: Las tareas de varios pasos que llaman a API o realizan acciones sugieren un agente. Las transformaciones de texto de una sola vez (reescribir, traducir, resumir un documento) sugieren una chat completion simple.

Comprueba lo que sabes

¿Cuáles son los tres componentes centrales de un agente?

Un modelo para razonar, instrucciones que definen su rol y reglas, y herramientas que puede llamar para obtener información o realizar acciones.

¿Por qué no usar un agente para traducir una oración?

Es una sola transformación de texto; un agente agrega latencia, costo y puntos de fallo sin ningún beneficio.
