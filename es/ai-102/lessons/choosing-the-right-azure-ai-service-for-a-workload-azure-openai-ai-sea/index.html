Microsoft Certified: Azure AI Engineer Associate AI-102

Cómo elegir el servicio de Azure AI adecuado para cada carga de trabajo: Azure OpenAI, AI Search, Vision, Language, Speech, Translator y Document Intelligence

La primera tarea de un ingeniero de Azure AI es elegir la herramienta correcta. Azure ofrece una familia de servicios de IA precompilados, cada uno entrenado por Microsoft para un tipo de problema, además de Azure OpenAI y el catálogo de modelos más amplio para IA generativa. Muchas preguntas de AI-102 describen una necesidad de negocio en una o dos oraciones y preguntan qué servicio encaja, así que necesitas un mapa mental claro de lo que hace cada uno y, igual de importante, de lo que no hace.

Azure OpenAI (al que se accede a través de Azure AI Foundry) aloja modelos de lenguaje grandes para chat, resúmenes, código, razonamiento y embeddings, además de modelos de generación de imágenes. Úsalo cuando el resultado sea contenido generado o cuando necesites razonamiento flexible sobre texto. Azure AI Search indexa tu contenido para búsqueda por palabras clave, vectorial e híbrida, y es la capa de recuperación habitual para la generación aumentada por recuperación (RAG). Azure AI Vision analiza imágenes: descripciones, etiquetas, objetos, personas y texto mediante su función Read (reconocimiento óptico de caracteres, OCR). Custom Vision entrena tus propios clasificadores de imágenes y detectores de objetos, y Azure AI Face detecta rostros y, con aprobación, identifica personas.

Azure AI Language abarca el análisis de texto (sentimiento, frases clave, entidades, detección de información de identificación personal), la comprensión del lenguaje conversacional (CLU), la respuesta a preguntas personalizada y la clasificación de texto personalizada. Azure AI Speech convierte voz en texto y texto en voz, traduce voz y reconoce palabras de activación. Azure AI Translator traduce texto y documentos completos. Azure AI Document Intelligence extrae texto, tablas y campos con nombre de formularios como facturas, recibos y documentos de identidad, y entrena modelos de extracción personalizados. Azure AI Content Understanding es un servicio más reciente que extrae campos de documentos, imágenes, audio y video con un solo esquema.

Al examen le encantan las opciones casi correctas. Leer el texto de la foto de un letrero es Vision Read, pero obtener el total y la fecha de vencimiento de una factura es Document Intelligence, porque quieres campos con nombre, no solo líneas de texto. Detectar que una reseña es negativa es el análisis de sentimiento de Language, pero decidir si una publicación contiene odio o violencia es Azure AI Content Safety. Traducir un mensaje de chat es Translator; traducir a alguien que habla en vivo es la traducción de Speech. Cuando una capacidad precompilada cubre la necesidad, prefiérela a entrenar un modelo personalizado o escribir un prompt, porque es más barata, más rápida y ya está evaluada.

Por último, recuerda la opción generativa. Un modelo de lenguaje grande a menudo también puede hacer análisis de sentimiento o extracción, pero un servicio diseñado para ese fin suele ser más barato, más predecible y más fácil de evaluar. Elige Azure OpenAI cuando la tarea requiera generación abierta, razonamiento o conversación.

Términos clave

Azure AI services (servicios de Azure AI)
La familia de API de IA precompiladas de Microsoft para visión, lenguaje, voz, traducción, documentos y seguridad de contenido, que se llaman mediante REST o SDK.
Azure OpenAI
Modelos de OpenAI alojados en Azure para chat, razonamiento, embeddings y generación de imágenes, implementados y administrados mediante Azure AI Foundry.
Document Intelligence
Un servicio que extrae texto, estructura y campos con nombre de documentos usando modelos precompilados o personalizados.
Content Safety
Un servicio que detecta texto e imágenes dañinos en las categorías de odio, contenido sexual, violencia y autolesiones.
Ejemplo real

Una aseguradora quiere procesar formularios de reclamaciones, permitir que los agentes busquen reclamaciones anteriores en lenguaje natural y leer resúmenes en voz alta al personal con discapacidad visual. El ingeniero usa Document Intelligence para extraer campos de los formularios, Azure AI Search con indexación vectorial y por palabras clave para la recuperación, Azure OpenAI para resumir las reclamaciones y la conversión de texto a voz de Speech para leer los resúmenes.

Consejo para el examen: Relaciona el resultado que pide el escenario: campos con nombre de formularios significa Document Intelligence, líneas de texto simple significa Vision Read, puntuaciones de contenido dañino significa Content Safety y prosa generada significa Azure OpenAI.

Comprueba lo que sabes

Una empresa quiere saber si las reseñas de sus clientes son positivas o negativas. ¿Qué servicio encaja de forma más directa?

El análisis de sentimiento de Azure AI Language. Está diseñado para eso, devuelve puntuaciones por oración y es más barato y predecible que darle un prompt a un modelo de lenguaje grande.

¿Qué servicio usarías para encontrar el texto de un letrero en una foto, y cuál para obtener el total de un recibo?

La función Read (OCR) de Azure AI Vision para el letrero; el modelo precompilado de recibos de Document Intelligence para el total del recibo, porque devuelve un campo con nombre.
