CompTIA Security+ SY0-701

VPN, IPsec, TLS, SD-WAN, SASE, jump servers y proxies

Las organizaciones necesitan conectar usuarios y sitios a través de redes no confiables como internet, y controlar cómo llega el tráfico a los sistemas sensibles. Esta lección cubre los componentes básicos para la conectividad segura y el acceso controlado.

Una red privada virtual (virtual private network, VPN) crea un túnel cifrado sobre una red no confiable. Una VPN site-to-site conecta dos redes, como una sucursal y la sede central, normalmente entre firewalls o routers. Una VPN de acceso remoto conecta el dispositivo de un usuario individual a la red corporativa. En una configuración full tunnel (túnel completo), todo el tráfico del usuario pasa por la VPN; en split tunnel (túnel dividido), solo pasa el tráfico corporativo, lo que ahorra ancho de banda pero significa que el tráfico de internet evita los controles de seguridad corporativos.

Internet Protocol Security (IPsec) es un conjunto de protocolos que protege el tráfico en la capa de red. Authentication Header (AH) proporciona integridad y autenticación, pero no cifrado. Encapsulating Security Payload (ESP) proporciona cifrado además de integridad. Internet Key Exchange (IKE) negocia las claves y las asociaciones de seguridad. El modo transporte (transport mode) protege solo la carga útil y se usa entre dos hosts; el modo túnel (tunnel mode) cifra todo el paquete original y lo envuelve en uno nuevo, lo cual es típico de las VPN site-to-site. Transport Layer Security (TLS) protege sesiones de aplicación individuales, como HTTPS, y también se puede usar para VPN que funcionan a través de un navegador web o por el puerto HTTPS estándar, que atraviesa fácilmente la mayoría de los firewalls.

La red de área amplia definida por software (software-defined wide area network, SD-WAN) reemplaza los costosos circuitos dedicados entre sitios con conexiones gestionadas de forma central sobre enlaces de internet comunes, eligiendo las rutas de forma inteligente. El secure access service edge (SASE) combina una red al estilo SD-WAN con servicios de seguridad entregados desde la nube, como secure web gateways, cloud access security brokers, firewall as a service y zero trust network access, para que los usuarios obtengan una protección consistente dondequiera que se conecten.

Un jump server (o jump box) es un sistema reforzado al que los administradores deben conectarse primero antes de llegar a los servidores sensibles. Reduce el acceso administrativo a un único punto de entrada monitoreado. Un servidor proxy hace solicitudes en nombre de los clientes. Un proxy directo (forward proxy) se ubica frente a los usuarios que salen a internet, donde puede filtrar contenido, almacenar en caché y registrar. Un proxy inverso (reverse proxy) se ubica frente a los servidores, recibe las solicitudes entrantes y las transmite, lo que oculta los servidores internos y permite el balanceo de carga y la descarga de TLS (TLS offloading).

Términos clave

IPsec
Un conjunto de protocolos que autentica y cifra paquetes IP, usando AH, ESP e IKE.
Tunnel mode (modo túnel)
Modo de IPsec que cifra todo el paquete original dentro de uno nuevo, típico de las VPN site-to-site.
SASE
Secure access service edge: servicios de red y de seguridad entregados desde la nube, combinados para usuarios en cualquier lugar.
Jump server
Un host reforzado y monitoreado que se usa como la única puerta de acceso administrativo a los sistemas sensibles.
Reverse proxy (proxy inverso)
Un servidor que recibe las solicitudes entrantes en nombre de los servidores internos y las reenvía.
Split tunnel (túnel dividido)
Una configuración de VPN que envía solo el tráfico corporativo a través del túnel.
Ejemplo real

Los administradores de un banco ya no pueden conectarse directamente a los servidores de bases de datos. Primero se conectan por la VPN, luego inician sesión con MFA en un jump server que graba cada sesión, y solo desde ahí pueden llegar a las bases de datos. Las reglas del firewall permiten el tráfico de administración de bases de datos únicamente desde la dirección del jump server.

Consejo para el examen: AH da integridad sin cifrado; ESP da cifrado. El proxy directo protege y controla a los clientes que salen; el proxy inverso atiende el tráfico entrante hacia los servidores.

Comprueba lo que sabes

¿Qué componente de IPsec proporciona confidencialidad?

Encapsulating Security Payload (ESP). AH solo proporciona integridad y autenticación.

¿Cuál es la desventaja de seguridad de una VPN con split tunnel?

El tráfico de internet del usuario evita la inspección y el filtrado corporativos, así que los controles de la empresa no ven las amenazas en esa ruta.

¿Cuál es el propósito de un jump server?

Proporcionar un único punto reforzado y monitoreado por el que debe pasar todo el acceso administrativo a los sistemas sensibles.
