CompTIA Security+ SY0-701

Ofuscación: esteganografía, tokenización y enmascaramiento de datos

La ofuscación significa hacer que los datos sean difíciles de entender o de encontrar sin necesariamente cifrarlos. Security+ agrupa tres técnicas bajo este encabezado: esteganografía, tokenización y enmascaramiento de datos. Resuelven problemas diferentes, y las preguntas del examen suelen describir un escenario y preguntar cuál se está usando.

La esteganografía (steganography) oculta la existencia de un mensaje dentro de algo ordinario, casi siempre un archivo de imagen, audio o video. Por ejemplo, los bits menos significativos de los píxeles de una foto se pueden alterar para transportar datos ocultos sin cambiar visiblemente la imagen. El objetivo es el ocultamiento: un observador ni siquiera se da cuenta de que hay un mensaje. El cifrado, en cambio, hace que un mensaje sea ilegible pero evidente. Los atacantes a veces usan esteganografía para sacar datos de una red a escondidas o para ocultar código malicioso dentro de archivos de apariencia inocente, por eso las herramientas de prevención de pérdida de datos y antimalware pueden analizar imágenes. La esteganografía se puede combinar con cifrado para mayor protección.

La tokenización (tokenization) reemplaza un valor sensible con un sustituto aleatorio llamado token, que no tiene ninguna relación matemática con el original. El valor real se guarda en una bóveda de tokens (token vault) segura, y solo la bóveda puede asociar el token con el valor original. Los sistemas de pago la usan mucho: un comercio guarda un token en lugar del número de tarjeta de crédito, así que una brecha en la base de datos del comercio solo expone tokens inútiles. Como el token no se deriva de los datos, no se puede descifrar; hay que consultar la bóveda. La tokenización también reduce la cantidad de sistemas que manejan los datos reales, lo que achica el alcance de cumplimiento.

El enmascaramiento de datos (data masking) oculta parte o la totalidad de un valor cuando se muestra o se copia, por ejemplo mostrando '****-****-****-1234' en un recibo o en una pantalla de soporte. El enmascaramiento estático reemplaza de forma permanente los valores reales por valores falsos realistas, lo cual es útil al crear copias de datos de producción para desarrolladores y testers. El enmascaramiento dinámico oculta los valores al momento según quién los esté viendo, de modo que un agente de servicio al cliente solo ve los últimos cuatro dígitos mientras el sistema de facturación sigue usando el número completo.

Compáralas con cuidado. El cifrado es reversible con una clave. El hashing es unidireccional y se usa para la integridad. La tokenización es reversible solo mediante la consulta a la bóveda. El enmascaramiento normalmente oculta los datos a quienes los ven, y el enmascaramiento estático no es reversible. La esteganografía oculta que los datos siquiera existen.

Estas técnicas apoyan las regulaciones de privacidad y el principio de minimización de datos: las personas y los sistemas solo deben ver los datos sensibles que realmente necesitan.

Términos clave

Steganography (esteganografía)
Ocultar datos dentro de otro archivo o medio para que su existencia quede oculta.
Tokenization (tokenización)
Reemplazar datos sensibles con un token aleatorio y guardar el original en una bóveda segura.
Data masking (enmascaramiento de datos)
Ocultar todo o parte de un valor, por ejemplo mostrar solo los últimos cuatro dígitos de un número de tarjeta.
Token vault (bóveda de tokens)
El sistema protegido que asocia los tokens con los valores sensibles originales.
Ejemplo real

Una tienda en línea nunca guarda números de tarjeta. Su proveedor de pagos devuelve un token por cada tarjeta, que la tienda guarda para compras repetidas. Cuando más tarde unos atacantes vulneran la base de datos de la tienda, solo encuentran tokens que no valen nada fuera de la bóveda del proveedor.

Consejo para el examen: Sin relación matemática con el original y con consulta a una bóveda significa tokenización. Mostrar solo los últimos cuatro dígitos significa enmascaramiento. Un mensaje oculto dentro de una imagen significa esteganografía.

Comprueba lo que sabes

¿Por qué no se puede descifrar un token robado?

Es un sustituto aleatorio sin vínculo matemático con el valor original; solo la bóveda de tokens puede asociarlo de vuelta.

Un desarrollador necesita datos de prueba realistas sin información real de clientes. ¿Qué técnica es la adecuada?

El enmascaramiento de datos estático, que reemplaza los valores reales con valores falsos realistas.

¿En qué se diferencia la esteganografía del cifrado?

La esteganografía oculta que un mensaje existe; el cifrado hace ilegible un mensaje visible.
