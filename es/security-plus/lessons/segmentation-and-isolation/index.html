CompTIA Security+ SY0-701

Segmentación y aislamiento

La segmentación divide una red en zonas más pequeñas y controla el tráfico entre ellas. Su propósito es la contención: si un atacante compromete un dispositivo, la segmentación limita hasta dónde puede moverse (movimiento lateral) y a qué puede llegar. Una red plana, en la que cada dispositivo puede comunicarse con todos los demás, permite que una sola laptop infectada llegue a la base de datos de nómina, a los respaldos y al sistema de control del edificio. Security+ trata la segmentación como una de las técnicas de mitigación centrales, junto con el aislamiento, que es la forma más fuerte de separación para sistemas de alto riesgo o comprometidos.

La segmentación se construye en capas. La segmentación física usa switches y cableado separados. Las redes de área local virtuales (VLAN) separan el tráfico de forma lógica en switches compartidos y colocan, por ejemplo, las estaciones de trabajo de los usuarios, los servidores, los teléfonos de voz y el Wi-Fi de invitados en dominios de difusión distintos. El tráfico entre VLAN debe pasar por un router o un firewall, donde las listas de control de acceso (ACL) y las reglas del firewall deciden qué se permite. Una subred filtrada (screened subnet, antes llamada DMZ) aloja los servidores expuestos a internet, como los servidores web y de correo, en su propia zona entre internet y la red interna, de modo que un servidor web comprometido no dé acceso directo al interior.

La microsegmentación lleva la idea hasta la carga de trabajo individual. En lugar de zonas amplias, las políticas se aplican por aplicación o incluso por máquina virtual o contenedor, a menudo mediante redes definidas por software o firewalls basados en host, de modo que el nivel web solo pueda comunicarse con el nivel de aplicación en un puerto, y el nivel de aplicación solo con la base de datos. Es un componente clave de zero trust. En los entornos de nube, los mismos conceptos aparecen como nubes privadas virtuales, subredes y grupos de seguridad. El tráfico a menudo se describe por su dirección: el tráfico norte-sur entra o sale del centro de datos, mientras que el tráfico este-oeste se mueve entre sistemas dentro de él. Los firewalls perimetrales tradicionales vigilan bien el tráfico norte-sur, pero los atacantes que se mueven lateralmente generan tráfico este-oeste, que es justamente lo que controla la microsegmentación.

El aislamiento separa un sistema por completo o casi por completo. Una red air-gapped (con brecha de aire) no tiene ninguna conexión con otras redes, y se usa para sistemas altamente sensibles, como algunos entornos de control industrial o clasificados; los datos solo se mueven mediante medios extraíbles cuidadosamente controlados. El aislamiento también es una acción de respuesta a incidentes: poner en cuarentena un host infectado moviéndolo a una VLAN de aislamiento o usando la función de contención de red del agente de EDR, que lo desconecta de todo excepto de las herramientas de seguridad. El sandboxing aísla código o archivos no confiables para que puedan ejecutarse o analizarse sin tocar el sistema real. Los navegadores, los gateways de seguridad de correo y los analistas de malware usan sandboxes, y la virtualización o los contenedores pueden ofrecer una separación similar para cargas de trabajo que no deben afectarse entre sí.

Veamos el diseño de segmentos para una empresa mediana. Los usuarios van en una VLAN, los servidores en otra, las impresoras y los dispositivos IoT en una tercera, los invitados en una red con acceso solo a internet y los sistemas de tarjetas de pago en una zona dedicada para reducir el alcance de la evaluación de PCI DSS. Las reglas del firewall entre zonas siguen el principio de denegar por defecto: los usuarios pueden llegar a los servidores en puertos de aplicación específicos; las impresoras pueden recibir trabajos de impresión, pero no iniciar conexiones hacia los servidores; los invitados solo pueden llegar a internet. Una regla podría verse así en pseudoconfiguración:

# allow users to the web app tier only
permit tcp 10.10.0.0/16 -> 10.20.5.0/24 port 443
# block IoT from initiating to servers
deny ip 10.30.0.0/16 -> 10.20.0.0/16
# default
deny ip any -> any log

La segmentación es tan buena como sus reglas y su monitoreo. Las reglas demasiado amplias, como 'cualquiera a cualquiera' entre zonas, anulan el beneficio, y las excepciones agregadas durante los proyectos tienden a quedarse para siempre si no se revisan. El tráfico entre segmentos también es un gran lugar para monitorear, porque el movimiento lateral tiene que cruzar esos límites. Errores comunes: suponer que las VLAN por sí solas brindan seguridad (sin filtrado entre ellas, el tráfico todavía puede enrutarse libremente); confundir la segmentación (comunicación controlada) con el aislamiento (poca o ninguna comunicación); y olvidar las interfaces de administración, que deberían estar en su propia red restringida.

Palabras clave del examen: 'limitar el movimiento lateral', 'contener una brecha' y 'separar el IoT de la red corporativa' apuntan a segmentación. 'Política por carga de trabajo' o 'tráfico este-oeste entre servidores' apunta a microsegmentación. 'Ninguna conexión de red' es un air gap. 'Poner en cuarentena un host infectado' es aislamiento o contención. 'Reducir el número de sistemas dentro del alcance de PCI DSS' apunta a segmentar el entorno de datos de titulares de tarjetas. Cuando no se puede aplicar parches a un sistema heredado, el aislamiento o la segmentación suelen ser el mejor control compensatorio.

Términos clave

Segmentación (segmentation)
Dividir una red en zonas y controlar el tráfico entre ellas para limitar el alcance de un atacante.
VLAN
Una LAN virtual que separa el tráfico de forma lógica en un hardware de switch compartido.
Subred filtrada (screened subnet)
Una zona entre internet y la red interna para servidores públicos; antes llamada DMZ.
Microsegmentación (microsegmentation)
Segmentación de grano fino que aplica políticas a cargas de trabajo o aplicaciones individuales.
Movimiento lateral (lateral movement)
Un atacante que se mueve de un sistema comprometido a otros dentro de una red.
Air gap (brecha de aire)
Aislamiento físico de un sistema o una red respecto de todas las demás redes.
Aislamiento (isolation)
Separar un sistema para que no pueda comunicarse, usado para sistemas de alto riesgo o durante la respuesta a incidentes.
Ejemplo real

La red de oficinas de un fabricante sufre un ataque de ransomware a través de un correo de phishing. Los servidores de archivos quedan cifrados, pero los sistemas de control de la fábrica siguen funcionando porque están en un segmento separado con una sola conexión estrictamente controlada hacia un servidor historiador, y esa conexión se bloquea automáticamente cuando el SOC aísla la VLAN de oficinas. La producción continúa mientras TI restaura los sistemas de oficina desde los respaldos.

Consejo para el examen: Las VLAN crean separación, pero los firewalls o las ACL entre ellas crean seguridad. Si una pregunta te pide cómo limitar el movimiento lateral o proteger un dispositivo al que no se pueden aplicar parches, la respuesta suele ser segmentación o aislamiento.

Comprueba lo que sabes

¿Por qué una red plana aumenta el impacto de una sola laptop comprometida?

Cada dispositivo puede llegar a todos los demás, así que el atacante puede moverse lateralmente hacia los servidores y los sistemas sensibles.

¿Cuál es la diferencia entre segmentación y aislamiento?

La segmentación controla y restringe la comunicación entre zonas; el aislamiento desconecta un sistema casi por completo.

¿Cómo puede la segmentación reducir el alcance de una evaluación de PCI DSS?

Colocar los sistemas de datos de titulares de tarjetas en un segmento estrictamente controlado significa que los sistemas externos a él quedan fuera del alcance si no pueden llegar a ese segmento.

¿Por qué la microsegmentación se asocia con zero trust?

Aplica políticas a cada carga de trabajo y elimina la confianza implícita entre sistemas de la misma zona de red.
