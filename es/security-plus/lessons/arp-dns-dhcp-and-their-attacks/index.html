CompTIA Security+ SY0-701

ARP, DNS, DHCP y sus ataques

Tres protocolos silenciosos hacen funcionar toda red, y los tres se diseñaron con muy poca seguridad integrada. El Protocolo de Resolución de Direcciones (ARP) encuentra la dirección de hardware de un dispositivo en la red local, el Sistema de Nombres de Dominio (DNS) convierte nombres en direcciones IP y el Protocolo de Configuración Dinámica de Host (DHCP) reparte la configuración de red. Cada uno confía en quien responda, así que un atacante que pueda responder primero, o responder con datos falsos, puede redirigir el tráfico. Entender cómo funcionan normalmente hace que sus ataques sean fáciles de reconocer, y Security+ te pide con frecuencia relacionar síntomas con el ataque correcto y la defensa correcta.
