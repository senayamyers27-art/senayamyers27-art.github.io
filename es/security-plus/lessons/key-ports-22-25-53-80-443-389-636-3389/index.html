CompTIA Security+ SY0-701

Puertos clave: 22, 25, 53, 80, 443, 389, 636 y 3389

Un número de puerto identifica qué servicio de un host debe recibir el tráfico de red. La dirección IP lleva un paquete a la máquina correcta; el puerto lo lleva al programa correcto. Los puertos bien conocidos (0 a 1023) están asignados a servicios comunes, y conocer los más importantes te permite leer reglas de firewall, entender resultados de escaneos y detectar tráfico sospechoso. Security+ espera que los reconozcas de memoria.

El puerto 22 (TCP) es SSH, que se usa para la administración remota cifrada y también para la transferencia de archivos SFTP y SCP. Como ofrece acceso administrativo, se escanea y se ataca por fuerza bruta intensamente en internet; restringe quién puede alcanzarlo y prefiere la autenticación basada en claves. El puerto 25 (TCP) es SMTP, que se usa para enviar correo entre servidores de correo. Muchas redes bloquean el puerto 25 saliente desde las estaciones de trabajo comunes, porque el malware que envía spam o exfiltra datos puede usarlo directamente. Los clientes de correo normalmente envían el correo por el puerto 587 con autenticación y TLS.

El puerto 53 es DNS. Usa UDP para la mayoría de las consultas y TCP para las transferencias de zona y las respuestas grandes. El tráfico DNS casi siempre está permitido en los firewalls, por eso los atacantes a veces abusan de él para hacer tunneling y sacar datos de una red. Vale la pena investigar hosts inesperados que ejecutan sus propios servidores DNS o volúmenes muy grandes de consultas DNS inusuales.

El puerto 80 (TCP) es HTTP, tráfico web sin cifrar, y el puerto 443 (TCP) es HTTPS, tráfico web protegido con TLS. La mayoría de los sitios redirigen el puerto 80 al 443. El puerto 443 también lo usan muchos otros servicios y VPN porque rara vez se bloquea, lo que de nuevo significa que a los atacantes les gusta esconderse ahí.

El puerto 389 es LDAP, que se usa para consultar servicios de directorio como Active Directory, y el puerto 636 es LDAPS, LDAP sobre TLS. El puerto 3389 (TCP) es el Remote Desktop Protocol (RDP), el protocolo gráfico de acceso remoto de Microsoft. Exponer RDP directamente a internet es una forma común en que los grupos de ransomware logran entrar, adivinando contraseñas o aprovechando vulnerabilidades sin parchear, así que debe estar detrás de una VPN o una puerta de enlace con MFA.

Vale la pena conocer algunos más aunque no estén en el título del tema: 21 (FTP), 23 (Telnet), 123 (NTP), 161 y 162 (SNMP), 445 (compartición de archivos SMB) y 1812 (RADIUS). En un laboratorio, un escaneo de puertos con una herramienta como Nmap produce una lista como '22/tcp open ssh, 3389/tcp open ms-wbt-server'; deberías saber de inmediato qué es cada servicio y si debería estar expuesto. Escanea solo sistemas que sean tuyos o que tengas autorización para probar.

Una buena forma de memorizarlos es emparejar las versiones inseguras con las seguras: 23 y 22, 80 y 443, 389 y 636.

Términos clave

Port (puerto)
Un número que identifica un servicio o una aplicación específica en un host para el tráfico TCP o UDP.
Port 3389 (puerto 3389)
El puerto predeterminado del Remote Desktop Protocol (RDP).
Port 53 (puerto 53)
El puerto de DNS, que usa UDP para las consultas y TCP para las transferencias de zona y las respuestas grandes.
Port 636 (puerto 636)
El puerto tradicional de LDAPS, LDAP protegido con TLS.
Ejemplo real

Una revisión del firewall encuentra una regla de entrada que permite que cualquier dirección de internet llegue al puerto 3389 de un servidor de archivos. El analista reconoce que es RDP expuesto a internet, elimina la regla y exige que el personal se conecte a través de la VPN con MFA antes de usar Escritorio remoto.

Consejo para el examen: Los pares ayudan: 22 SSH, 23 Telnet; 80 HTTP, 443 HTTPS; 389 LDAP, 636 LDAPS. El 25 es SMTP, el 53 es DNS y el 3389 es RDP.

Comprueba lo que sabes

¿Qué puerto y protocolo usa Escritorio remoto?

El puerto TCP 3389, RDP.

¿Por qué a un analista podría preocuparle que muchas estaciones de trabajo se conecten hacia afuera por el puerto 25?

El puerto 25 es SMTP; las estaciones de trabajo comunes no deberían enviar correo directamente, así que podría indicar malware que envía spam o exfiltración.

¿Cuándo usa DNS TCP en lugar de UDP?

Para las transferencias de zona y las respuestas demasiado grandes para una respuesta UDP normal.
