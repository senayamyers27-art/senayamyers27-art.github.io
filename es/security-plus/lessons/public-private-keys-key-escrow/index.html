CompTIA Security+ SY0-701

Claves públicas y privadas, y key escrow (custodia de claves)

La criptografía asimétrica depende de pares de claves. Las dos claves se generan juntas y están vinculadas matemáticamente, pero en la práctica no puedes derivar la clave privada a partir de la clave pública. La clave pública está pensada para compartirse abiertamente, a menudo dentro de un certificado digital. La clave privada debe permanecer bajo el control exclusivo de su dueño, porque cualquiera que la tenga puede hacerse pasar por él y leer los mensajes destinados a él.

La forma de usar las claves depende del objetivo. Para la confidencialidad, el remitente cifra con la clave pública del destinatario, y solo la clave privada del destinatario puede descifrar. Para la autenticidad y la integridad, el dueño firma con su propia clave privada, y cualquiera puede verificar la firma con la clave pública del dueño. Una ayuda útil para recordarlo: cifras para alguien con su clave pública; firmas como tú mismo con tu clave privada.

Como la clave privada es tan importante, protegerla es una parte central de la gestión de claves (key management). Las claves pueden almacenarse en almacenes de claves de software protegidos con una frase de contraseña, en tarjetas inteligentes, en un Trusted Platform Module (TPM) en una laptop o en un módulo de seguridad de hardware (HSM) para servidores y autoridades de certificación. La gestión de claves también abarca la generación con buena aleatoriedad, la distribución, la rotación (reemplazar las claves periódicamente), la revocación cuando una clave se ve comprometida y la destrucción segura al final de su vida útil.

El key escrow (custodia de claves) es un acuerdo en el que un tercero de confianza o una función interna designada guarda una copia de una clave de cifrado, para que los datos se puedan recuperar si la clave original se pierde o si existe una necesidad legítima, como un requisito legal o la salida de un empleado de la empresa. Sin escrow, los datos cifrados por alguien que luego se va o pierde su clave podrían quedar inaccesibles para siempre. Un ejemplo conocido es guardar las claves de recuperación de BitLocker en un directorio central para que la mesa de ayuda pueda desbloquear una laptop.

El escrow introduce su propio riesgo: las claves en custodia se convierten en un objetivo muy valioso. Por eso, los sistemas de escrow necesitan controles de acceso fuertes, auditoría y, a menudo, separación de funciones o aprobación de varias personas (a veces llamada control M of N), para que ningún administrador pueda recuperar una clave por su cuenta. También puedes ver el término relacionado key recovery agent (agente de recuperación de claves), un rol autorizado para recuperar claves.

Ten en cuenta que el escrow normalmente se aplica a las claves de cifrado, no a las claves de firma. Si otra persona tuviera una copia de tu clave de firma, podrías argumentar que fue ella quien firmó un documento, lo que debilitaría el no repudio.

Términos clave

Public key (clave pública)
La mitad compartible de un par de claves, que se usa para cifrar datos dirigidos a su dueño o para verificar las firmas del dueño.
Private key (clave privada)
La mitad secreta de un par de claves, que se usa para descifrar datos o crear firmas digitales; nunca debe compartirse.
Key escrow (custodia de claves)
Guardar una copia de una clave de cifrado con una parte de confianza para poder recuperar los datos cuando sea necesario.
Key management (gestión de claves)
El ciclo de vida de las claves: generación, almacenamiento, distribución, rotación, revocación y destrucción.
Ejemplo real

Un ingeniero que cifró archivos de diseño deja la empresa de forma inesperada. Como la organización mantenía en custodia las claves de cifrado en su sistema de gestión de claves, un agente de recuperación, con la aprobación de un segundo gerente, recupera la clave y restablece el acceso a los archivos.

Consejo para el examen: Para enviarle un secreto a alguien, usa su clave pública. Para firmar, usa tu propia clave privada. El escrow sirve para recuperar claves de cifrado y no debe aplicarse a las claves de firma que se usan para el no repudio.

Comprueba lo que sabes

Alice quiere enviarle a Bob un mensaje confidencial. ¿Con qué clave lo cifra?

Con la clave pública de Bob, para que solo la clave privada de Bob pueda descifrarlo.

¿Qué problema resuelve el key escrow?

Permite recuperar datos cifrados si una clave se pierde o su dueño no está disponible.

¿Qué riesgo introduce el key escrow y cómo se reduce?

El almacén de custodia se convierte en un objetivo de alto valor; se protege con controles de acceso fuertes, auditoría y aprobación de varias personas.
