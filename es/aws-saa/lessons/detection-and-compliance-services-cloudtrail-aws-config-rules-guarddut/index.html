AWS Certified Solutions Architect – Associate SAA-C03

Servicios de detección y cumplimiento: CloudTrail, reglas de AWS Config, GuardDuty, Inspector, Macie y Security Hub

AWS tiene varios servicios de detección con nombres parecidos, y las preguntas del examen a menudo describen una necesidad y preguntan qué servicio la satisface. El truco es recordar la única pregunta que responde cada servicio.

AWS CloudTrail responde quién hizo qué, cuándo y desde dónde. Registra las llamadas a la API hechas en tu cuenta, ya sea desde la consola, la CLI, los SDKs o servicios de AWS. El event history (historial de eventos) conserva 90 días de management events gratis; un trail entrega los eventos a un bucket de S3 para retención a largo plazo y puede enviarlos a CloudWatch Logs para crear alarmas. Un organization trail cubre todas las cuentas de AWS Organizations. Los data events, como las lecturas de objetos de S3 o las invocaciones de Lambda, no se registran por defecto y hay que habilitarlos. La log file validation (validación de archivos de log) te permite demostrar que los archivos no fueron alterados.

AWS Config responde cómo era este recurso y si cumple nuestras reglas. Registra los cambios de configuración de los recursos a lo largo del tiempo, así que puedes ver, por ejemplo, el historial de un security group. Las Config rules evalúan los recursos contra configuraciones deseadas, como que los buckets de S3 deben bloquear el acceso público o que los volúmenes EBS deben estar cifrados, usando reglas administradas por AWS o reglas personalizadas con Lambda. Los recursos no conformes se pueden corregir automáticamente con remediation actions (acciones de remediación) basadas en documentos de Systems Manager Automation. Los conformance packs agrupan reglas para marcos de cumplimiento.

Amazon GuardDuty responde si está ocurriendo algo malicioso. Es un servicio administrado de detección de amenazas que analiza eventos de CloudTrail, VPC Flow Logs y logs de DNS, además de fuentes opcionales como los data events de S3, los logs de auditoría de EKS y el runtime monitoring, usando inteligencia de amenazas y machine learning. Lo habilitas con un clic; no se requieren agentes ni configuración de logs para las fuentes básicas. Los hallazgos (findings) incluyen minería de criptomonedas, comunicación con IP maliciosas conocidas y llamadas a la API inusuales. Amazon Inspector responde cuáles de mis cargas de trabajo tienen vulnerabilidades de software o exposición de red no deseada, escaneando continuamente instancias EC2, imágenes de contenedores en Amazon ECR y funciones Lambda en busca de vulnerabilidades conocidas (CVEs). Amazon Macie responde dónde hay datos sensibles en S3, usando machine learning y coincidencia de patrones para descubrir información de identificación personal (PII) y otros datos sensibles, y señala los buckets públicos o sin cifrar.

AWS Security Hub lo une todo. Agrega los hallazgos de GuardDuty, Inspector, Macie, Config, IAM Access Analyzer y herramientas de socios en una sola vista con un formato estándar, y ejecuta verificaciones de estándares de seguridad como AWS Foundational Security Best Practices. Los hallazgos fluyen hacia Amazon EventBridge, donde las reglas pueden disparar notificaciones o respuestas automatizadas. Amazon Detective, un servicio relacionado, ayuda a investigar la causa raíz de los hallazgos.

Términos clave

CloudTrail
El servicio que registra la actividad de la API en las cuentas de AWS para auditoría e investigación.
AWS Config
El servicio que registra el historial de configuración de los recursos y evalúa el cumplimiento de reglas.
GuardDuty
Un servicio administrado de detección de amenazas que analiza logs para encontrar actividad maliciosa o no autorizada.
Macie
Un servicio que descubre y clasifica datos sensibles, como la PII, en Amazon S3.
Ejemplo real

Después de un incidente, un equipo de seguridad usa CloudTrail para averiguar qué rol eliminó una regla de un security group, usa AWS Config para ver el conjunto de reglas antes y después del cambio, y habilita una Config rule con remediación automática para que se corrija cualquier security group que abra SSH a 0.0.0.0/0. Los hallazgos de GuardDuty y Macie se agregan en Security Hub para revisarlos a diario.

Consejo para el examen: Historial de la API: CloudTrail. Historial de configuración y cumplimiento: Config. Amenazas: GuardDuty. Vulnerabilidades: Inspector. Datos sensibles en S3: Macie. Panel único de hallazgos: Security Hub.

Comprueba lo que sabes

¿Qué servicio detectaría una instancia EC2 comunicándose con un servidor de comando y control conocido?

Amazon GuardDuty, que analiza los VPC Flow Logs y los logs de DNS contra inteligencia de amenazas.

Necesitas conocer cada cambio hecho a las reglas de un security group durante el último mes y si cumple la política. ¿Qué servicio?

AWS Config, que registra el historial de configuración y evalúa reglas de cumplimiento.
