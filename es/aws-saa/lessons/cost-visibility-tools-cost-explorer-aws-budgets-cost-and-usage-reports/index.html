AWS Certified Solutions Architect – Associate SAA-C03

Herramientas de visibilidad de costos: Cost Explorer, AWS Budgets, Cost and Usage Reports, cost allocation tags y Trusted Advisor

No puedes optimizar lo que no puedes ver. AWS proporciona un conjunto de herramientas para ver a dónde va el dinero, atribuirlo a los equipos, alertar antes de gastar de más y encontrar ahorros. Las preguntas del examen suelen describir una necesidad, como alertar, analizar, reportar en detalle o recomendar, y preguntan qué herramienta encaja.

AWS Cost Explorer es la herramienta interactiva para visualizar y analizar costos y uso. Puedes ver los últimos 13 meses por defecto (con un historial más largo opcional), agrupar y filtrar por servicio, cuenta, Región, tipo de uso o etiqueta, y ver pronósticos del gasto futuro. También contiene recomendaciones de compra de Reserved Instances y Savings Plans basadas en tu uso, reportes sobre su utilización y cobertura, y recomendaciones de rightsizing. Úsalo para responder preguntas como qué servicio creció más el mes pasado.

AWS Budgets te permite definir presupuestos personalizados de costo, uso, utilización o cobertura de reservas y Savings Plans, y envía alertas por correo electrónico o SNS cuando los montos reales o pronosticados cruzan los umbrales. Las budget actions pueden ir más allá, por ejemplo aplicando una política de IAM o una SCP que impida lanzar nuevos recursos, o deteniendo instancias EC2 o RDS específicas, cuando se supera un presupuesto. Budgets es la respuesta para las alertas proactivas; Cost Explorer es para el análisis posterior. AWS Cost Anomaly Detection usa machine learning para detectar gastos inusuales y alertarte.

El AWS Cost and Usage Report (CUR), que ahora se entrega mediante AWS Data Exports, son los datos de facturación más detallados disponibles: partidas por cada recurso por hora o por día, con precios, reservas y etiquetas, entregadas a un bucket de S3. Está diseñado para consultarse con Athena, cargarse en Redshift o visualizarse en QuickSight, y es la respuesta cuando finanzas necesita los datos más granulares para reportes personalizados de refacturación (chargeback).

Las cost allocation tags (etiquetas de asignación de costos) conectan los costos con sus responsables. Etiquetas los recursos con claves como CostCenter o Project y luego activas esas etiquetas como cost allocation tags en la consola de Billing; solo después de activarlas aparecen en Cost Explorer y en el CUR, y solo para los costos a partir de ese momento. Las etiquetas generadas por AWS, como aws:createdBy, también se pueden activar. Las tag policies de Organizations ayudan a imponer un etiquetado consistente.

AWS Trusted Advisor inspecciona tu cuenta y recomienda mejoras en optimización de costos, rendimiento, seguridad, tolerancia a fallos, límites de servicio y excelencia operativa, como balanceadores de carga inactivos, instancias infrautilizadas, Elastic IPs no asociadas y security groups abiertos. Todos los clientes obtienen un conjunto básico de verificaciones; el conjunto completo requiere un plan Business Support o superior.

Términos clave

Cost Explorer
Una herramienta interactiva para analizar, visualizar y pronosticar los costos y el uso de AWS.
AWS Budgets
Un servicio que alerta, y puede tomar acciones, cuando los costos o el uso superan, o se pronostica que superarán, los umbrales.
Cost and Usage Report
El conjunto de datos de facturación de AWS más detallado, entregado a S3 para analizarlo con herramientas como Athena.
Cost allocation tag (etiqueta de asignación de costos)
Una etiqueta de recurso activada en la facturación para poder agrupar y filtrar los costos por ella.
Ejemplo real

Una empresa quiere que cada equipo de producto vea su propio gasto mensual y reciba avisos tempranos. Etiqueta cada recurso con Team, activa la etiqueta como cost allocation tag, crea un presupuesto por equipo filtrado por la etiqueta con alertas al 80 por ciento del pronóstico y da a finanzas el Cost and Usage Report en S3, consultado mediante Athena para la refacturación.

Consejo para el examen: Alertar antes de gastar de más: Budgets. Analizar tendencias y obtener recomendaciones de Savings Plans: Cost Explorer. Los datos más granulares para reportes personalizados: Cost and Usage Report. Costos por equipo o proyecto: activa las cost allocation tags. Verificaciones de buenas prácticas: Trusted Advisor.

Comprueba lo que sabes

Etiquetaste recursos con Project hace seis meses, pero la etiqueta no aparece en Cost Explorer. ¿Por qué?

La etiqueta no se ha activado como cost allocation tag en la consola de Billing; las etiquetas solo aparecen en las herramientas de costos después de activarse, y solo de ahí en adelante.

¿Qué herramienta puede detener instancias automáticamente cuando el gasto supera un umbral?

AWS Budgets, mediante budget actions.
