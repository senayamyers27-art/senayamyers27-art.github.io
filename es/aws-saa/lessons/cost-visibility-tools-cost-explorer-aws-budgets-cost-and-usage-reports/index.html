AWS Certified Solutions Architect – Associate SAA-C03

Herramientas de visibilidad de costos: Cost Explorer, AWS Budgets, Cost and Usage Reports, cost allocation tags y Trusted Advisor

No puedes optimizar lo que no puedes ver. AWS proporciona un conjunto de herramientas para ver a dónde va el dinero, atribuirlo a los equipos, alertar antes de gastar de más y encontrar ahorros. Se superponen un poco, y precisamente por eso le gustan al examen: una pregunta suele describir una necesidad, como alertar, analizar, informar en detalle, atribuir o recomendar, y pregunta qué herramienta encaja. Aprender el verbo propio de cada herramienta es la forma más fiable de responder.

AWS Cost Explorer es la herramienta interactiva para visualizar y analizar costos y uso. Puedes ver los últimos 13 meses de forma predeterminada, con un historial más largo opcional, agrupar y filtrar por servicio, cuenta vinculada, Región, tipo de uso o etiqueta, y ver pronósticos del gasto futuro. También incluye recomendaciones de compra de Reserved Instances y Savings Plans basadas en tu uso, informes sobre su utilización y cobertura, y recomendaciones de ajuste de tamaño. Úsala para responder preguntas como qué servicio creció más el mes pasado. Los mismos datos están disponibles de forma programática, por ejemplo aws ce get-cost-and-usage --time-period Start=2026-08-01,End=2026-09-01 --granularity MONTHLY --metrics UnblendedCost --group-by Type=DIMENSION,Key=SERVICE.

AWS Budgets te permite definir presupuestos personalizados de costo, uso, utilización o cobertura de reservas y Savings Plans, y envía alertas por correo electrónico o por Amazon Simple Notification Service (SNS) cuando los montos reales o pronosticados cruzan los umbrales. Las budget actions van más allá, por ejemplo aplicando una política de IAM o una service control policy (SCP) que impide lanzar recursos nuevos, o deteniendo instancias EC2 o RDS específicas, cuando se supera un presupuesto, ya sea automáticamente o después de una aprobación. Budgets es la respuesta para las alertas proactivas; Cost Explorer es para el análisis. AWS Cost Anomaly Detection usa machine learning para detectar gastos inusuales, como un salto repentino en un servicio, y alertarte sin umbrales fijos.

El AWS Cost and Usage Report (CUR), que ahora se entrega mediante AWS Data Exports, contiene los datos de facturación más detallados disponibles: partidas de cada recurso por hora o por día, con detalles de precios, reservas y Savings Plans y etiquetas, entregadas en un bucket de S3. Está diseñado para consultarse con Amazon Athena, cargarse en Amazon Redshift o visualizarse en Amazon QuickSight, y es la respuesta cuando finanzas necesita los datos más granulares para informes personalizados de chargeback o showback.

Las cost allocation tags vinculan los costos con sus responsables. Etiquetas los recursos con claves como CostCenter o Project, y luego activas esas etiquetas como cost allocation tags en la consola de Billing and Cost Management; solo después de activarlas aparecen en Cost Explorer y en el CUR, y solo para los costos a partir de ese momento. Las etiquetas generadas por AWS, como aws:createdBy, también pueden activarse. Las tag policies de AWS Organizations ayudan a imponer claves y valores de etiqueta consistentes, y AWS Cost Categories agrupa los costos mediante reglas, como asignar cuentas y etiquetas a unidades de negocio. AWS Trusted Advisor inspecciona tu cuenta y recomienda mejoras en optimización de costos, rendimiento, seguridad, tolerancia a fallas, límites de servicio y excelencia operativa, como balanceadores de carga inactivos, instancias infrautilizadas, direcciones Elastic IP no asociadas y grupos de seguridad demasiado abiertos. Todos los clientes obtienen un conjunto básico de comprobaciones; el conjunto completo requiere un plan Business Support o superior.

Veamos un ejemplo práctico. Una empresa quiere que cada equipo de producto vea su propio gasto mensual y reciba avisos con antelación. Etiqueta cada recurso con Team, impone la clave con una tag policy y la activa como cost allocation tag. Crea un presupuesto por equipo filtrado por la etiqueta, con alertas al topic de SNS de cada equipo al 80 por ciento del pronóstico y una budget action que aplica una política de denegación de lanzamientos de instancias nuevas en la cuenta sandbox al 100 por ciento. Finanzas recibe el Cost and Usage Report en S3 y lo consulta con Athena para el chargeback mensual, mientras que el equipo de plataforma revisa cada trimestre Trusted Advisor y las recomendaciones de Savings Plans de Cost Explorer.

Errores comunes: esperar que las etiquetas aparezcan en las herramientas de facturación sin activarlas; esperar que los costos históricos se reetiqueten después de la activación; elegir Cost Explorer cuando el requisito es una alerta o una acción automática (eso es Budgets); elegir Cost Explorer cuando finanzas necesita datos por partida y por hora (eso es el CUR); y suponer que todas las comprobaciones de Trusted Advisor están disponibles en el plan Basic Support. Otra trampa es confundir Budgets con Cost Anomaly Detection: los presupuestos usan umbrales que tú defines, mientras que la detección de anomalías aprende los patrones normales.

La redacción del examen se asocia con una herramienta cada vez. 'Alertar cuando se pronostica que el gasto superará' o 'detener recursos cuando se excede el presupuesto' apunta a AWS Budgets. 'Analizar tendencias', 'pronóstico', 'qué servicio aumentó' o 'recomendaciones de Savings Plans' apunta a Cost Explorer. 'Lo más granular', 'partidas por hora', 'informes personalizados con Athena' apunta al Cost and Usage Report. 'Costos por equipo o proyecto' apunta a cost allocation tags activadas. 'Pico inesperado sin definir umbrales' apunta a Cost Anomaly Detection. 'Comprobaciones de buenas prácticas, recursos inactivos, grupos de seguridad abiertos' apunta a Trusted Advisor.

Términos clave

Cost Explorer
Una herramienta interactiva para analizar, visualizar y pronosticar los costos y el uso de AWS, con recomendaciones de compromisos.
AWS Budgets
Un servicio que alerta, y puede tomar acciones, cuando los costos o el uso superan o se pronostica que superarán los umbrales.
Budget action
Una respuesta automática o aprobada ante un umbral de presupuesto, como aplicar una política restrictiva o detener instancias.
Cost and Usage Report
El conjunto de datos de facturación de AWS más detallado, entregado en S3 para analizarlo con herramientas como Athena.
Cost allocation tag
Una etiqueta de recurso activada en la facturación para poder agrupar y filtrar los costos por ella.
Cost Anomaly Detection
Un servicio que usa machine learning para detectar patrones de gasto inusuales y alertar sobre ellos.
AWS Trusted Advisor
Un servicio que compara las cuentas con las buenas prácticas de costos, rendimiento, seguridad, tolerancia a fallas y límites.
Ejemplo real

Una empresa quiere que cada equipo de producto vea su propio gasto mensual y reciba avisos con antelación. Etiqueta cada recurso con Team, activa la etiqueta como cost allocation tag, crea un presupuesto por equipo filtrado por la etiqueta con alertas al 80 por ciento del pronóstico, y entrega a finanzas el Cost and Usage Report en S3, consultado con Athena para el chargeback.

Consejo para el examen: Alertar antes de gastar de más: Budgets. Analizar tendencias y obtener recomendaciones de Savings Plans: Cost Explorer. Los datos más granulares para informes personalizados: Cost and Usage Report. Costos por equipo o proyecto: activa las cost allocation tags. Comprobaciones de buenas prácticas: Trusted Advisor.

Comprueba lo que sabes

Etiquetaste recursos con Project hace seis meses, pero la etiqueta no aparece en Cost Explorer. ¿Por qué?

La etiqueta no se ha activado como cost allocation tag en la consola de Billing; las etiquetas solo aparecen en las herramientas de costos después de activarlas, y solo de ahí en adelante.

¿Qué herramienta puede detener instancias automáticamente cuando el gasto supera un umbral?

AWS Budgets, mediante budget actions.

Finanzas necesita partidas de facturación por hora y por recurso para crear informes de chargeback personalizados. ¿Qué herramienta usas?

El AWS Cost and Usage Report, entregado en S3 mediante Data Exports y consultado con Athena o herramientas similares.

Un desarrollador quiere recibir alertas de picos de gasto inusuales sin elegir umbrales fijos. ¿Qué servicio usa?

AWS Cost Anomaly Detection, que aprende los patrones de gasto normales con machine learning.
