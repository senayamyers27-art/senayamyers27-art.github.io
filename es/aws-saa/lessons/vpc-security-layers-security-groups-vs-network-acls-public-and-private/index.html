AWS Certified Solutions Architect – Associate SAA-C03

Capas de seguridad de la VPC: security groups vs network ACLs, subredes públicas y privadas, NAT gateways, bastion hosts vs Session Manager

Una nube privada virtual (VPC) es tu propia red aislada en una región de AWS, definida por un bloque CIDR (Classless Inter-Domain Routing) IPv4 como 10.0.0.0/16. La divides en subredes, y cada subred vive en exactamente una zona de disponibilidad (AZ). La seguridad en una VPC se organiza en capas: hacia dónde puede enrutar una subred, qué firewalls están delante de cada recurso y cómo llegan los administradores a las máquinas. El examen espera que diseñes las tres de forma que solo el balanceador de carga quede expuesto a internet y todo lo demás permanezca privado.
