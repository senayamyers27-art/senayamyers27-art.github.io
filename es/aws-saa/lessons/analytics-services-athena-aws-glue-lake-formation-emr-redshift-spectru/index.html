Servicios de analítica: Athena, AWS Glue, Lake Formation, EMR, Redshift Spectrum y QuickSight

Un data lake (lago de datos) almacena datos en bruto y procesados de cualquier forma, normalmente en Amazon S3, y permite que muchas herramientas los analicen sin copiarlos antes a un sistema separado. AWS tiene un conjunto de servicios que catalogan, protegen, procesan, consultan y visualizan esos datos. El examen espera que conozcas la función de cada uno.

AWS Glue es un servicio serverless de integración de datos. Los Glue crawlers escanean los datos en S3 y otras fuentes, infieren los esquemas y crean tablas en el AWS Glue Data Catalog, un repositorio central de metadatos que usan Athena, Redshift Spectrum y EMR. Los Glue jobs ejecutan código de extracción, transformación y carga (ETL) sobre Apache Spark serverless, por ejemplo para convertir CSV a Parquet y particionarlo por fecha. Glue también ofrece creación visual de jobs y reglas de calidad de datos.

Amazon Athena es un servicio de consultas interactivas serverless: escribes SQL estándar sobre datos en S3, usando tablas definidas en el Data Catalog, y pagas por la cantidad de datos escaneados. No hay clústeres. Como el precio es por escaneo, almacenar los datos en formatos columnares comprimidos como Parquet u ORC y particionarlos, por ejemplo por año, mes y día, reduce el costo y acelera las consultas. Athena es la respuesta para consultas ad hoc sobre datos en S3, como analizar CloudTrail, VPC Flow Logs o logs del ALB, sin infraestructura.

AWS Lake Formation se basa en el Glue Data Catalog para configurar y proteger data lakes. Su función clave es el control de acceso centralizado y detallado: otorgar a un equipo acceso a bases de datos, tablas, columnas o filas específicas, y hacer que esos permisos se apliquen en Athena, Redshift Spectrum, EMR y Glue. Es la respuesta cuando una pregunta pide permisos a nivel de columna o de fila sobre un data lake administrados en un solo lugar.

Amazon EMR ejecuta frameworks de big data como Apache Spark, Hive, Presto, HBase y Flink en clústeres de instancias EC2, en EKS o de forma serverless. Se adapta al procesamiento a gran escala, la preparación para machine learning y las cargas que necesitan control a nivel de framework; los clústeres pueden usar instancias Spot para los task nodes y reducir costos. Amazon Redshift Spectrum permite que un clúster de Redshift consulte datos directamente en S3 y los combine (join) con tablas cargadas en Redshift, así que mantienes los datos calientes en el warehouse y el historial frío en el lago. Amazon QuickSight es el servicio serverless de inteligencia de negocios para tableros y visualizaciones, que se conecta a Athena, Redshift, RDS, S3 y otros, con precios por usuario.

Términos clave

AWS Glue Data Catalog
Un almacén central de metadatos con definiciones de tablas compartido por Athena, EMR, Redshift Spectrum y Glue.
Amazon Athena
Un servicio de consultas SQL serverless para datos en S3, con precio según los datos escaneados.
AWS Lake Formation
Un servicio para construir data lakes y administrar de forma centralizada el acceso detallado a ellos.
Redshift Spectrum
Una función de Redshift que consulta datos directamente en S3 y los combina con las tablas del warehouse.
Ejemplo real

Un minorista deposita archivos CSV de ventas en bruto en S3. Un Glue crawler los cataloga y un Glue job los convierte a Parquet particionado. Los analistas ejecutan SQL ad hoc con Athena, el área de finanzas ve solo las columnas sin PII gracias a los permisos de Lake Formation, y los directivos ven tableros de QuickSight construidos sobre los mismos datos.

Consejo para el examen: SQL ad hoc sobre S3 sin servidores: Athena. Descubrir esquemas y ETL: Glue. Permisos a nivel de columna o fila en varias herramientas de analítica: Lake Formation. Clústeres de Hadoop o Spark con control: EMR. Combinar tablas de Redshift con datos en S3: Redshift Spectrum. Tableros: QuickSight.

Comprueba lo que sabes

¿Cómo puedes reducir los costos de las consultas de Athena sobre un gran conjunto de datos de logs?

Convertir los datos a un formato columnar comprimido como Parquet y particionarlos para que las consultas escaneen menos datos.

¿Qué servicio crea tablas en el Data Catalog escaneando datos en S3?

Un AWS Glue crawler.
