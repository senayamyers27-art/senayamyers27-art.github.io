Dirección de red, dirección de broadcast, rango de hosts utilizables y cantidad de hosts para máscaras comunes

Para cualquier subred IPv4 debes poder encontrar cuatro cosas: la dirección de red (la primera dirección, que identifica a la propia subred), la dirección de broadcast (la última dirección), el rango de hosts utilizables (todo lo que hay en medio) y el número de hosts utilizables. Las direcciones de red y de broadcast no se pueden asignar a dispositivos.

La cantidad de hosts sale del número de bits de host, que es 32 menos la longitud de prefijo. El número total de direcciones es 2 elevado al número de bits de host, y los hosts utilizables son ese número menos 2. Así, /24 tiene 8 bits de host, 256 direcciones y 254 hosts utilizables. /25 tiene 128 direcciones y 126 hosts; /26 tiene 64 y 62; /27 tiene 32 y 30; /28 tiene 16 y 14; /29 tiene 8 y 6; /30 tiene 4 y 2, por eso /30 es común en los enlaces punto a punto entre routers. En el otro extremo, /16 tiene 65,536 direcciones y 65,534 hosts utilizables.

Un método rápido para las máscaras que terminan en el último octeto es el tamaño de bloque (block size): 256 menos el último octeto de la máscara. Para /26, la máscara termina en 192, así que el tamaño de bloque es 64, y las subredes empiezan en 0, 64, 128 y 192. Para encontrar la subred de 192.168.1.100/26, busca el bloque que contiene 100: cae entre 64 y 127. Así que la dirección de red es 192.168.1.64, la dirección de broadcast es 192.168.1.127, el rango utilizable es de 192.168.1.65 a 192.168.1.126 y hay 62 hosts utilizables.

Prueba otro: 10.0.0.37/29. La máscara termina en 248, así que el tamaño de bloque es 8 y las subredes empiezan en 0, 8, 16, 24, 32, 40 y así sucesivamente. 37 cae en el bloque de 32 a 39. La red es 10.0.0.32, el broadcast 10.0.0.39, los hosts utilizables de 10.0.0.33 a 10.0.0.38, seis en total. Para un /24 es más sencillo: 172.16.5.200/24 tiene la red 172.16.5.0, el broadcast 172.16.5.255 y el rango utilizable de .1 a .254.

El default gateway normalmente es una de las direcciones utilizables, a menudo la primera (.1) o la última utilizable. Cuando un dispositivo se configura con su propia dirección de red o de broadcast, o con un gateway fuera de su subred, no se comunicará correctamente. Practica estos cálculos hasta que puedas hacer de /24 a /30 mentalmente; las preguntas del examen a menudo dan una dirección y preguntan qué rango de hosts, broadcast o cantidad de hosts es correcto.

Términos clave

Network address (dirección de red)
La primera dirección de una subred, con todos los bits de host en 0; identifica la subred y no se puede asignar a un host.
Broadcast address (dirección de broadcast)
La última dirección de una subred, con todos los bits de host en 1; llega a todos los hosts de la subred.
Usable host range (rango de hosts utilizables)
Las direcciones entre la dirección de red y la de broadcast que se pueden asignar a dispositivos.
Block size (tamaño de bloque)
256 menos el último octeto de máscara distinto de 255; el espaciado entre los límites de las subredes.
Ejemplo real

Una sucursal pequeña necesita una subred para 25 dispositivos. Un /27 da 30 hosts utilizables, suficientes y con espacio para crecer, mientras que un /28 da solo 14. El equipo asigna 192.168.50.32/27: hosts de .33 a .62, gateway .33 y broadcast .63.

Consejo para el examen: Hosts utilizables = 2^(bits de host) menos 2. Recuerda la tabla: /24 254, /25 126, /26 62, /27 30, /28 14, /29 6, /30 2.

Comprueba lo que sabes

¿Cuáles son las direcciones de red y de broadcast de 192.168.1.130/25?

Red 192.168.1.128 y broadcast 192.168.1.255; los hosts utilizables van de .129 a .254.

¿Cuántos hosts utilizables ofrece un /28?

14 (16 direcciones menos la dirección de red y la de broadcast).

¿Se puede asignar 10.0.0.39/29 a un host?

No. Es la dirección de broadcast de la subred 10.0.0.32/29.
