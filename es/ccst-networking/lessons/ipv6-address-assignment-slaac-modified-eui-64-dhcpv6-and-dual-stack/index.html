Asignación de direcciones IPv6: SLAAC, EUI-64 modificado, DHCPv6 y dual stack

Los hosts IPv6 pueden obtener direcciones de varias formas, y una red puede usar más de una a la vez. Además de la configuración manual (estática), los métodos principales son SLAAC y DHCPv6, y ambos dependen de mensajes del router local.

Los routers envían periódicamente mensajes Router Advertisement (RA, anuncio de router), parte de ICMPv6 Neighbor Discovery, a la dirección multicast de todos los nodos ff02::1, y los hosts pueden pedir uno de inmediato con un Router Solicitation. Un RA lleva el prefijo de la subred (por ejemplo 2001:db8:acad:1::/64), la dirección link-local del router para usarla como default gateway y banderas (flags) que indican a los hosts cómo obtener direcciones y otras configuraciones.

SLAAC (Stateless Address Autoconfiguration, autoconfiguración de direcciones sin estado) permite que un host construya su propia dirección global sin servidor: toma el prefijo /64 del RA y le agrega su propio interface ID de 64 bits. 'Sin estado' (stateless) significa que nada lleva el registro de qué host tiene qué dirección. Luego el host usa Duplicate Address Detection (detección de direcciones duplicadas) para asegurarse de que nadie más tenga la misma dirección. El interface ID se puede crear de dos formas principales. El EUI-64 modificado (modified EUI-64) lo deriva de la dirección MAC de 48 bits: divide la MAC a la mitad, inserta fffe en medio e invierte el séptimo bit del primer byte (el bit universal/local). Para la MAC 00:1a:2b:3c:4d:5e, el primer byte 00 se convierte en 02, lo que da el interface ID 021a:2bff:fe3c:4d5e. Como esto revela la dirección de hardware, la mayoría de los sistemas operativos modernos usan en su lugar interface IDs generados aleatoriamente por privacidad, incluidas direcciones temporales que cambian con el tiempo.

DHCPv6 funciona como DHCP de IPv4, pero usa los puertos UDP 546 (cliente) y 547 (servidor). El DHCPv6 con estado (stateful) asigna direcciones y lleva su registro, lo que da a los administradores un historial de quién tuvo qué dirección. El DHCPv6 sin estado (stateless) se usa junto con SLAAC: el host construye su propia dirección, pero obtiene información adicional, como las direcciones de los servidores DNS, de un servidor DHCPv6. Ten en cuenta que un servidor DHCPv6 no proporciona el default gateway; eso siempre viene del RA del router.

Dual stack (doble pila) significa que un dispositivo o una red ejecuta IPv4 e IPv6 al mismo tiempo, cada uno con sus propias direcciones. Es la forma más común en que las organizaciones migran a IPv6, porque los hosts pueden llegar tanto a servicios solo IPv4 como a servicios compatibles con IPv6. Cuando ambos están disponibles, los sistemas operativos normalmente prefieren IPv6. En los routers Cisco, ipv6 unicast-routing habilita el enrutamiento IPv6 y los mensajes RA, e ipv6 address 2001:db8:acad:1::/64 eui-64 configura una interfaz con una dirección EUI-64.

Términos clave

SLAAC
Stateless Address Autoconfiguration: un host construye su dirección IPv6 a partir del prefijo anunciado por el router más su propio interface ID.
Router Advertisement (anuncio de router)
Un mensaje ICMPv6 de un router que anuncia el prefijo, el default gateway y el método de asignación de direcciones.
Modified EUI-64 (EUI-64 modificado)
Un método que construye un interface ID de 64 bits a partir de una dirección MAC insertando fffe e invirtiendo el séptimo bit.
DHCPv6
La versión IPv6 de DHCP; el modo stateful asigna direcciones y el modo stateless solo proporciona configuraciones adicionales como el DNS.
Dual stack (doble pila)
Ejecutar IPv4 e IPv6 simultáneamente en los mismos dispositivos y la misma red.
Ejemplo real

El router de una oficina anuncia 2001:db8:10:5::/64. Una laptop nueva usa SLAAC para crear direcciones del estilo 2001:db8:10:5:8c3a:12ff:fe00:9b1 (con un ID aleatorio en los sistemas modernos), obtiene los servidores DNS mediante DHCPv6 stateless y aun así recibe 192.168.5.40 del DHCP de IPv4, porque la oficina funciona con dual stack.

Consejo para el examen: En EUI-64, recuerda 'inserta fffe, invierte el séptimo bit'. Y el default gateway de IPv6 siempre viene del router advertisement, nunca de DHCPv6.

Comprueba lo que sabes

¿Qué significa 'stateless' (sin estado) en SLAAC?

Ningún servidor lleva el registro de qué host tiene qué dirección; los hosts construyen sus propias direcciones a partir del prefijo anunciado.

Usando EUI-64 modificado, ¿qué interface ID resulta de la MAC 00:1a:2b:3c:4d:5e?

021a:2bff:fe3c:4d5e.

¿Qué es dual stack?

Ejecutar IPv4 e IPv6 al mismo tiempo en los mismos hosts y la misma red.
