Encapsulamiento: datos, segmentos, paquetes, tramas y bits; direcciones MAC frente a direcciones IP

El encapsulamiento es la forma en que cada capa envuelve los datos que recibe de la capa superior con su propio encabezado (y a veces un tráiler) antes de pasarlos hacia abajo. En el lado receptor el proceso ocurre al revés, y se llama desencapsulamiento: cada capa lee y quita su propio encabezado y pasa el resto hacia arriba. Por eso una captura de paquetes muestra secciones anidadas, cada una perteneciente a una capa.

Cada etapa tiene un nombre, llamado PDU (protocol data unit, unidad de datos de protocolo). En las capas de aplicación son simplemente datos. La capa de Transporte agrega un encabezado TCP o UDP con los números de puerto de origen y destino, y el resultado es un segmento (con UDP, a menudo se llama datagrama). La capa de Red agrega un encabezado IP con las direcciones IP de origen y destino, formando un paquete. La capa de Enlace de datos agrega un encabezado con las direcciones MAC de origen y destino más un tráiler que contiene una Frame Check Sequence (secuencia de verificación de trama) usada para detectar errores, formando una trama. La capa Física transmite la trama como bits: voltajes en cobre, pulsos de luz en fibra u ondas de radio en Wi-Fi. Una regla mnemotécnica en inglés es 'Do Some People Fear Birthdays': data, segment, packet, frame, bits (datos, segmento, paquete, trama, bits).

Los dos tipos de dirección en esa pila hacen trabajos distintos. Una dirección MAC (Media Access Control) es una dirección de hardware de 48 bits grabada en una interfaz de red, escrita como 12 dígitos hexadecimales, por ejemplo 00:1A:2B:3C:4D:5E, o 001a.2b3c.4d5e en dispositivos Cisco. La primera mitad normalmente identifica al fabricante. Las direcciones MAC solo importan en el segmento de red local; los switches las usan para entregar tramas al puerto correcto. Una dirección IP es una dirección lógica asignada por configuración o por DHCP, e identifica tanto la red como el host, de modo que los routers pueden mover paquetes a través de muchas redes hasta el destino final.

Este es el comportamiento clave que le gusta al examen: a medida que un paquete cruza routers, las direcciones IP de origen y destino se mantienen iguales de extremo a extremo (a menos que NAT las cambie), pero las direcciones MAC se reescriben en cada salto. Cada router quita la trama entrante, mira el encabezado IP y construye una nueva trama dirigida desde la MAC de su propia interfaz de salida hacia la MAC del siguiente dispositivo. Para conocer la dirección MAC que corresponde a una dirección IP local, los hosts IPv4 usan ARP (Address Resolution Protocol); IPv6 usa Neighbor Discovery.

Puedes ver ambas direcciones por tu cuenta. En Windows, ipconfig /all muestra la Physical Address (MAC) y la dirección IPv4; en Linux, ip addr muestra las líneas link/ether e inet. arp -a lista las asociaciones de IP a MAC que tu computadora ha aprendido.

Términos clave

Encapsulation (encapsulamiento)
Agregar el encabezado (y tráiler) de una capa a los datos a medida que bajan por la pila antes de transmitirse.
PDU
Protocol data unit (unidad de datos de protocolo): el nombre de los datos en una capa determinada: datos, segmento, paquete, trama o bits.
MAC address (dirección MAC)
Dirección de hardware de 48 bits usada para entregar tramas en el segmento de red local.
IP address (dirección IP)
Dirección lógica que identifica a un host y su red, usada por los routers para reenviar paquetes entre redes.
ARP
Address Resolution Protocol: encuentra la dirección MAC que corresponde a una dirección IPv4 conocida en la red local.
Ejemplo real

Tu laptop en 192.168.1.20 carga una página web desde un servidor en internet. La trama que sale de tu laptop va dirigida a la dirección MAC de tu router doméstico, pero el paquete que va dentro está dirigido a la dirección IP del servidor web. En el router, la trama se reemplaza por una nueva para el siguiente enlace, mientras que el destino IP se mantiene igual.

Consejo para el examen: Si una pregunta te pide qué dirección cambia en cada salto de router, la respuesta es la dirección MAC. Las direcciones IP se mantienen iguales de extremo a extremo, a menos que intervenga NAT.

Comprueba lo que sabes

¿Cuál es la PDU de la capa de Transporte y qué información clave agrega su encabezado?

Un segmento, cuyo encabezado TCP o UDP agrega los números de puerto de origen y destino.

Cuando se envía una trama a un servidor en otra red, ¿de quién es la dirección MAC de destino?

La del default gateway (router), porque las direcciones MAC solo llegan hasta el siguiente salto en la red local.
