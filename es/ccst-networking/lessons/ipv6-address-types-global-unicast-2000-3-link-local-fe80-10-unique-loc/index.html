Cisco Certified Support Technician (CCST) Networking 100-150 v1.0

Tipos de direcciones IPv6: global unicast (2000::/3), link-local (fe80::/10), unique local (fc00::/7), multicast (ff00::/8), loopback ::1

IPv6 no tiene broadcast. En su lugar usa tres tipos de entrega: unicast (una interfaz), multicast (un grupo de interfaces) y anycast (la más cercana de varias interfaces que comparten una dirección). Dentro de unicast, varios tipos de direcciones tienen distintos alcances (scopes), es decir, hasta dónde son válidas. Una sola interfaz normalmente tiene más de una dirección IPv6 al mismo tiempo, así que debes reconocer cada tipo por sus primeros dígitos hexadecimales.

Las direcciones global unicast (GUA, unicast globales) son el equivalente IPv6 de las direcciones IPv4 públicas: únicas a nivel mundial y enrutables en internet. Provienen de 2000::/3, lo que significa que el primer hexteto está entre 2000 y 3fff. Así que una dirección que empieza con 2 o 3, como 2001:db8:acad::10 o 2600:..., es una dirección global unicast. (2001:db8::/32 está reservado para documentación y ejemplos.)

Las direcciones link-local (de enlace local) empiezan con fe80 (el bloque fe80::/10, en la práctica siempre fe80::/64). Cada interfaz con IPv6 habilitado crea una automáticamente, incluso cuando no existe ningún router ni servidor DHCP. Las direcciones link-local solo son válidas en el enlace local y nunca se enrutan. Se usan para Neighbor Discovery, los router advertisements y como dirección de siguiente salto en el enrutamiento, así que el default gateway que aparece en un host IPv6 a menudo es una dirección fe80. No la confundas con APIPA de IPv4: una dirección fe80 es normal y esperada, no una señal de falla.

Las direcciones unique local (ULA, locales únicas) provienen de fc00::/7. En la práctica empiezan con fd, porque la mitad fd00::/8 es la parte que se usa con un identificador aleatorio generado localmente. Son similares a las direcciones IPv4 privadas: se pueden usar dentro de una organización y se enrutan internamente, pero no se enrutan en internet.

Las direcciones multicast empiezan con ff (ff00::/8). Algunos ejemplos son ff02::1 (todos los nodos del enlace) y ff02::2 (todos los routers del enlace). Multicast reemplaza la mayoría de las tareas que hacía el broadcast en IPv4, como las direcciones multicast solicited-node de Neighbor Discovery (ff02::1:ffxx:xxxx) que reemplazan los broadcasts de ARP. La dirección de loopback es ::1, el equivalente de 127.0.0.1, y :: (todo ceros) es la dirección no especificada que un host usa antes de tener una dirección.

Una forma rápida de clasificar: 2 o 3 al inicio significa global unicast, fe80 significa link-local, fc o fd significa unique local, ff significa multicast y ::1 significa loopback.

Términos clave

Global unicast address (dirección global unicast)
Una dirección IPv6 enrutable a nivel mundial de 2000::/3, similar a una dirección IPv4 pública.
Link-local address (dirección link-local)
Una dirección fe80::/10 creada automáticamente, válida solo en el enlace local y nunca enrutada.
Unique local address (dirección unique local)
Una dirección fc00::/7 (en la práctica fd00::/8) para uso interno, similar a las direcciones IPv4 privadas.
Multicast address (dirección multicast)
Una dirección ff00::/8 que entrega el tráfico a un grupo de interfaces; IPv6 usa multicast en lugar de broadcast.
Ejemplo real

Al ejecutar ipconfig en una laptop se ven tres entradas IPv6: 2600:1700:5a0:3c10::45 (global unicast del proveedor), fd12:3456:789a:1::45 (una dirección unique local de la red de la oficina) y fe80::1c2b:3aff:fe4d:5e6f%12 (link-local). El default gateway aparece como fe80::1.

Consejo para el examen: IPv6 no tiene direcciones de broadcast; multicast (ff) hace ese trabajo. Y una dirección fe80 en una interfaz es normal, a diferencia de una dirección 169.254 en IPv4.

Comprueba lo que sabes

¿Qué tipo de dirección es fe80::a1b2:3c4d:5e6f:7a8b?

Una dirección link-local, válida solo en el enlace local.

¿Qué prefijo identifica a las direcciones multicast de IPv6?

ff00::/8, así que empiezan con ff.

¿Cuál es la dirección de loopback de IPv6?

::1.
