Cisco Certified Support Technician (CCST) Networking 100-150 v1.0

Comandos show: show running-config, show version, show ip interface brief, show interfaces, show interfaces status, show ip route, show mac address-table, show cdp neighbors, show inventory

Los comandos show muestran información sin cambiar nada, lo que los hace seguros para que los ejecuten los técnicos de soporte. Muchos funcionan en el modo EXEC de usuario, pero algunos, como show running-config, necesitan el modo EXEC privilegiado (el prompt #), así que lo más sencillo es ejecutarlos desde ahí. Saber qué comando responde qué pregunta se evalúa mucho y es exactamente lo que un ingeniero te pedirá ejecutar.

show running-config muestra la configuración activa en memoria: el hostname, la configuración de las interfaces, las asignaciones de VLAN, las direcciones IP, el enrutamiento y la configuración de seguridad. Los cambios tienen efecto aquí de inmediato, pero se pierden al reiniciar a menos que se guarden con copy running-config startup-config; show startup-config muestra la versión guardada. Trata esta salida como sensible, ya que puede contener hashes de contraseñas y claves. show version muestra la versión del software IOS, cuánto tiempo lleva encendido el dispositivo (uptime) y por qué se reinició la última vez, el modelo de hardware, la memoria, el número de serie y el registro de configuración (configuration register). Es el comando de referencia para '¿se reinició este switch?' y '¿qué software está ejecutando?'.

show ip interface brief da un resumen de una línea por interfaz: nombre, dirección IP, si se asignó manualmente o por DHCP, Status y Protocol. Status up y Protocol up es un estado sano. 'administratively down' significa que alguien la apagó con el comando shutdown. down/down normalmente significa un problema de Capa 1, como que no hay cable o el extremo remoto está apagado. up/down sugiere un problema de Capa 2, como un desajuste de keepalive o de encapsulamiento en un enlace WAN. show interfaces da el detalle completo de cada interfaz: estado, dirección MAC, MTU, velocidad y dúplex, tasas de entrada y salida, y contadores de errores como input errors, errores CRC, colisiones y descartes (drops). Los errores CRC en aumento apuntan al cableado o a interferencia; las colisiones tardías (late collisions) sugieren un desajuste de dúplex. show interfaces status en los switches lista cada puerto con su descripción, estado (connected, notconnect, err-disabled, disabled), VLAN, dúplex, velocidad y tipo de medio, y es la forma más rápida de averiguar qué puertos están en uso.

show ip route muestra la tabla de enrutamiento, con códigos para las rutas conectadas (C), locales (L), estáticas (S) y dinámicas como OSPF (O), además del gateway of last resort (la ruta por defecto). Úsalo para confirmar que un router sabe cómo llegar a una red. show mac address-table lista las direcciones MAC aprendidas con su VLAN y su puerto, lo que te permite ubicar un dispositivo en un switch.

show cdp neighbors usa CDP (Cisco Discovery Protocol), un protocolo de Capa 2 que los dispositivos Cisco usan para anunciarse a sus vecinos directamente conectados. Lista el ID de dispositivo (hostname) de cada vecino, tu interfaz local, el holdtime, las capacidades (R para router, S para switch, etc.), la plataforma (modelo) y el puerto del vecino. Agrega detail para ver las direcciones IP y las versiones de software de los vecinos. Es extremadamente útil para verificar el cableado y construir diagramas; LLDP es el equivalente independiente del fabricante. show inventory lista los componentes de hardware con sus product IDs y números de serie, incluidos el chasis, los módulos, las fuentes de alimentación y los transceptores SFP instalados, útil para casos de garantía y soporte o para confirmar que está instalado el módulo correcto.

Términos clave

show running-config
Muestra la configuración activa en memoria.
show version
Muestra la versión de IOS, el uptime, el motivo del último reinicio, el modelo, la memoria y el número de serie.
show ip interface brief
Resumen de una línea de la dirección IP, el estado (status) y el protocolo de cada interfaz.
show cdp neighbors
Lista los dispositivos Cisco directamente conectados, sus plataformas y los puertos que los conectan.
show inventory
Lista los componentes de hardware, los product IDs y los números de serie, incluidos los transceptores.
Ejemplo real

Los usuarios de un piso reportan una caída que terminó por sí sola. Un ingeniero te pide ejecutar show version, que muestra un uptime de 12 minutos y como motivo del último reinicio una falla de energía. Luego show cdp neighbors confirma que el uplink hacia el switch del núcleo volvió, y show interfaces status muestra los puertos de usuario conectados de nuevo.

Consejo para el examen: Relaciona la pregunta con el comando: uptime o versión de IOS, show version; IP y estado up/down, show ip interface brief; errores y dúplex, show interfaces; qué dispositivo está en el otro extremo, show cdp neighbors; números de serie y módulos, show inventory.

Comprueba lo que sabes

¿Qué comando te dice cuánto tiempo lleva funcionando un switch desde su último reinicio?

show version, que muestra el uptime y el motivo del último reinicio.

Una interfaz aparece como 'administratively down' en show ip interface brief. ¿Qué significa?

Que fue deshabilitada con el comando shutdown y debe habilitarse con no shutdown.

¿Qué comando muestra el hostname y el puerto del dispositivo conectado a cada interfaz?

show cdp neighbors (o sus equivalentes de LLDP).
