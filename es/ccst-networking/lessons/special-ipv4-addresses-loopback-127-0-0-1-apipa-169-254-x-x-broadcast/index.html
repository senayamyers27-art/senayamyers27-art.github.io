Direcciones IPv4 especiales: loopback 127.0.0.1, APIPA 169.254.x.x, broadcast

Algunas direcciones IPv4 están reservadas para tareas especiales. Reconocerlas a simple vista es una de las formas más rápidas de diagnosticar un problema a partir de una sola salida de ipconfig.

El rango de loopback es 127.0.0.0/8, y la dirección que usarás es 127.0.0.1, también conocida con el nombre localhost. El tráfico enviado a ella nunca sale de la computadora; el sistema operativo lo devuelve directamente. Hacer ping a 127.0.0.1 prueba si el software TCP/IP local funciona, y los desarrolladores la usan para llegar a servicios que se ejecutan en la misma máquina. Un ping exitoso al loopback no dice nada sobre la tarjeta de red ni el cable. En IPv6, la dirección de loopback es ::1.

APIPA (Automatic Private IP Addressing) usa el rango link-local 169.254.0.0/16. Cuando una computadora Windows, y la mayoría de los demás sistemas, está configurada para obtener una dirección automáticamente pero no puede llegar a un servidor DHCP, se asigna a sí misma una dirección aleatoria como 169.254.37.112 con máscara 255.255.0.0. Verifica con ARP que nadie más la esté usando. Los dispositivos con direcciones APIPA solo pueden hablar con otros dispositivos del mismo enlace que también tengan direcciones 169.254; no hay default gateway, así que no hay acceso a internet. La lección clave: una dirección 169.254.x.x significa que DHCP falló. Revisa el cable o la asociación Wi-Fi, el puerto del switch y la VLAN, y si el servidor DHCP o el router funcionan. Ejecutar ipconfig /release e ipconfig /renew después de corregir la causa debería obtener una dirección correcta.

Una dirección de broadcast llega a todos los hosts de un segmento de red. El broadcast limitado 255.255.255.255 va a todos los hosts de la red local y los routers nunca lo reenvían; un DHCP Discover se envía de esta forma porque el cliente todavía no conoce su propia red. Un broadcast dirigido es la última dirección de una subred, con todos los bits de host en 1, como 192.168.1.255 para 192.168.1.0/24. Como la dirección de red (todos los bits de host en 0) y la dirección de broadcast (todos los bits de host en 1) están reservadas, no puedes asignarlas a hosts. Los routers separan los dominios de broadcast, lo que evita que los broadcasts inunden toda una organización.

Dos más para reconocer: 0.0.0.0 significa 'este host, todavía sin dirección' o, en una tabla de enrutamiento, 'cualquier dirección' (0.0.0.0/0 es la ruta por defecto). Las direcciones multicast, de 224.0.0.0 a 239.255.255.255, entregan un solo flujo a un grupo de hosts interesados.

Términos clave

Loopback
El rango 127.0.0.0/8 (normalmente 127.0.0.1) que devuelve el tráfico al mismo host para probar la pila IP local.
APIPA
Automatic Private IP Addressing: una dirección 169.254.x.x autoasignada que se usa cuando DHCP falla.
Limited broadcast (broadcast limitado)
255.255.255.255, enviado a todos los hosts del segmento local y nunca enrutado.
Directed broadcast (broadcast dirigido)
La última dirección de una subred (todos los bits de host en 1), que llega a todos los hosts de esa subred.
Ejemplo real

Una impresora de repente muestra 169.254.88.3 en su página de estado y nadie puede imprimir. Durante un trabajo de recableado, el puerto del switch se movió a la VLAN equivocada, así que la impresora no pudo llegar a DHCP. Después de corregir el puerto y de que la impresora renueva su dirección, obtiene su dirección habitual 10.10.20.x.

Consejo para el examen: 169.254.x.x en una pregunta casi siempre significa 'el host no pudo llegar a un servidor DHCP'. No la confundas con una dirección privada del RFC 1918.

Comprueba lo que sabes

¿Qué te dice una dirección 169.254.x.x en una PC?

La PC está configurada para DHCP pero no pudo llegar a un servidor DHCP, así que se asignó una dirección APIPA.

¿Cuál es la dirección de broadcast de 192.168.5.0/24?

192.168.5.255, la dirección con todos los bits de host en 1.
