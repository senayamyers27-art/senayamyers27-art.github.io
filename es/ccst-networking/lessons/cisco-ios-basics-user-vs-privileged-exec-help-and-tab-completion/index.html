Fundamentos de Cisco IOS: EXEC de usuario frente a EXEC privilegiado, ayuda con `?` y autocompletado con Tab

Cisco IOS (Internetwork Operating System) y sus parientes cercanos, como IOS XE, funcionan en la mayoría de los routers y switches Cisco. Interactúas con él a través de una interfaz de línea de comandos (CLI) por consola, SSH o Telnet. La CLI está organizada en modos, cada uno indicado por un prompt distinto, y cada uno permite comandos distintos.

El modo EXEC de usuario (user EXEC mode) es donde llegas después de iniciar sesión. El prompt termina en >, como en Switch>. Solo permite comandos de monitoreo limitados, como algunos comandos show y ping, y no puedes cambiar la configuración ni ver la configuración en ejecución completa. El modo EXEC privilegiado (privileged EXEC mode), al que se entra con el comando enable (a menudo protegido por una contraseña enable secret), tiene un prompt que termina en #, como en Switch#. Desde aquí puedes ejecutar todos los comandos show y debug, copiar y guardar configuraciones con copy running-config startup-config, reiniciar el dispositivo y entrar al modo de configuración. Usa disable para regresar al EXEC de usuario y exit para cerrar sesión.

Al modo de configuración global (global configuration mode) se entra desde el EXEC privilegiado con configure terminal (comúnmente abreviado conf t), y el prompt cambia a Switch(config)#. Los comandos aquí cambian la configuración en ejecución de inmediato. Desde la configuración global puedes entrar a submodos, como la configuración de interfaz con interface gigabitethernet1/0/1, que da Switch(config-if)#, o la configuración de líneas con line vty 0 4. exit retrocede un nivel y end (o Ctrl+Z) regresa directamente al EXEC privilegiado. Como técnico de soporte, trabajarás sobre todo en el EXEC de usuario y el privilegiado, ejecutando comandos show.

La ayuda sensible al contexto viene integrada. Escribir ? en un prompt lista todos los comandos disponibles en el modo actual. Escribir parte de una palabra seguida inmediatamente de ?, como sh?, lista los comandos que empiezan con esas letras. Escribir un comando, un espacio y ?, como show ? o show ip ?, lista las opciones que pueden venir a continuación, y <cr> en la lista significa que puedes presionar Enter ya. Esta es la forma más rápida de explorar cuando no recuerdas la sintaxis exacta.

IOS acepta abreviaturas siempre que no sean ambiguas: sh ip int br funciona para show ip interface brief. Presionar Tab completa una palabra clave escrita parcialmente, lo que confirma que tu abreviatura es correcta. Si IOS no entiende, muestra mensajes como '% Invalid input detected at ^ marker', con un signo ^ que apunta al problema, '% Incomplete command' o '% Ambiguous command'. La flecha hacia arriba (o Ctrl+P) recupera los comandos anteriores. Los comandos introducidos en el modo de configuración afectan la configuración en ejecución en memoria; solo se guardan de forma permanente cuando se copian a la configuración de inicio (startup configuration).

Términos clave

User EXEC mode (modo EXEC de usuario)
El modo inicial y limitado de la CLI, con un prompt que termina en >.
Privileged EXEC mode (modo EXEC privilegiado)
El modo de acceso completo de la CLI al que se entra con enable, con un prompt que termina en #.
Global configuration mode (modo de configuración global)
El modo al que se entra con configure terminal, donde se hacen cambios a la configuración en ejecución.
Context-sensitive help (ayuda sensible al contexto)
Usar ? para listar los comandos disponibles o las siguientes opciones válidas en el modo actual.
Tab completion (autocompletado con Tab)
Presionar Tab para completar una palabra clave de IOS escrita parcialmente.
Ejemplo real

Por teléfono, un ingeniero te pide revisar el estado de las interfaces. Inicias sesión, ves SW-3F>, escribes enable y la contraseña para llegar a SW-3F#, luego escribes show ip int? para confirmar las opciones y ejecutas sh ip int br. Le lees los resultados al ingeniero.

Consejo para el examen: Un prompt que termina en > significa EXEC de usuario, # significa EXEC privilegiado y (config)# significa configuración global. enable sube del modo de usuario al privilegiado, y configure terminal entra a la configuración global.

Comprueba lo que sabes

¿Qué comando te lleva del EXEC de usuario al modo EXEC privilegiado?

enable.

¿Cuál es la diferencia entre sh? y show ??

sh? lista los comandos que empiezan con 'sh'; show ? (con un espacio) lista las palabras clave que pueden seguir al comando show.

¿Qué indica el prompt Router(config-if)#?

El modo de configuración de interfaz.
