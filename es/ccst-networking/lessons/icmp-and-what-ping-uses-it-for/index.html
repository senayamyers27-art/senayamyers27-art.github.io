ICMP y para qué lo usa ping

ICMP (Internet Control Message Protocol) es un protocolo auxiliar de la capa de Red que transporta mensajes de error y de diagnóstico sobre la entrega IP. No transporta datos de usuario y no usa números de puerto; en su lugar, cada mensaje tiene un tipo (type) y un código (code). Los routers y hosts envían mensajes ICMP para reportar problemas, como un destino inalcanzable, y los administradores usan ICMP para probar la alcanzabilidad. IPv6 tiene su propia versión, ICMPv6, que también maneja Neighbor Discovery y los anuncios de router (router advertisements), así que ahí es esencial y no opcional.

ping es la herramienta más común basada en ICMP. Envía mensajes ICMP Echo Request (tipo 8) a un destino, y un host alcanzable al que se le permite responder devuelve mensajes Echo Reply (tipo 0). Por cada respuesta, ping muestra el tiempo de ida y vuelta en milisegundos y el TTL (Time to Live) de la respuesta. Al final resume los paquetes enviados, recibidos y perdidos, además de los tiempos mínimo, promedio y máximo. Windows envía cuatro pings por defecto; Linux y macOS siguen enviando hasta que presionas Ctrl+C, a menos que agregues -c 4.

Otros mensajes ICMP que encontrarás incluyen Destination Unreachable (tipo 3), que tiene códigos para red inalcanzable, host inalcanzable, puerto inalcanzable y 'administratively prohibited' (prohibido administrativamente) cuando un filtro bloquea el tráfico; y Time Exceeded (tipo 11), que se envía cuando el TTL de un paquete llega a cero en un router. Traceroute depende de los mensajes Time Exceeded para descubrir cada salto de router a lo largo de una ruta. Los mensajes Redirect le indican a un host que hay un mejor gateway.

Leer la salida de ping es una habilidad fundamental. 'Reply from 8.8.8.8: bytes=32 time=14ms TTL=117' significa éxito. 'Request timed out' significa que no llegó ninguna respuesta a tiempo; el host podría estar apagado, podría faltar una ruta o un firewall podría estar descartando ICMP. 'Destination host unreachable' reportado por tu propio gateway o PC significa que no hay ruta o que no hay respuesta ARP en el segmento local. 'TTL expired in transit' puede indicar un bucle de enrutamiento. Los tiempos de espera agotados de forma constante hacia una dirección, con respuestas normales hacia otras, te ayudan a ubicar la falla.

Una buena secuencia de solución de problemas es hacer ping hacia afuera por pasos: tu propio loopback (127.0.0.1) para probar la pila IP, tu propia dirección IP, tu default gateway, una dirección IP remota como un servidor DNS público y, finalmente, un nombre como example.com para probar el DNS. El primer paso que falla te dice dónde buscar. Recuerda, sin embargo, que muchos hosts y firewalls bloquean ICMP, así que un ping fallido por sí solo no prueba que un servicio esté caído.

Términos clave

ICMP
Internet Control Message Protocol: protocolo de la capa de Red para el reporte de errores y el diagnóstico.
Echo Request / Echo Reply
Los tipos ICMP 8 y 0, los mensajes que ping envía y recibe.
Destination Unreachable
ICMP tipo 3: informa que un paquete no pudo entregarse, con un código que indica el motivo.
Time Exceeded
ICMP tipo 11: se envía cuando el TTL de un paquete llega a cero; traceroute depende de él.
Ejemplo real

Un usuario no puede llegar a internet. El ping a 127.0.0.1 y a la propia dirección de la PC funciona, el ping al gateway 192.168.10.1 funciona, pero el ping a 8.8.8.8 agota el tiempo de espera. El problema está más allá de la red local, así que revisas el enlace WAN del router y descubres que el circuito del proveedor está caído.

Consejo para el examen: ICMP no tiene puertos. Si una opción de respuesta dice 'ping usa el puerto TCP o UDP X', está mal. Además, 'Request timed out' no prueba que un host esté apagado; un firewall podría simplemente estar descartando ICMP.

Comprueba lo que sabes

¿Qué mensajes ICMP envía y recibe ping?

Envía Echo Request (tipo 8) y espera Echo Reply (tipo 0).

¿Qué prueba hacer ping a 127.0.0.1?

Que la pila TCP/IP local funciona en la propia computadora, sin usar la red.
