Cisco Certified Support Technician (CCST) Networking 100-150 v1.0

Protocolos y puertos comunes: FTP 20/21, SFTP/SSH 22, TFTP 69, HTTP 80, HTTPS 443, DNS 53, DHCP 67/68, NTP 123

Un número de puerto es un valor de 16 bits (0 a 65535) en el encabezado TCP o UDP que le dice al host receptor qué aplicación o servicio debe recibir los datos. Los servidores escuchan en puertos bien conocidos (well-known ports, 0 a 1023) para que los clientes sepan dónde conectarse, mientras que el cliente elige un puerto de origen temporal de número alto para cada conversación. Una dirección IP más un puerto, como 192.168.1.10:443, se llama socket. Tanto los firewalls como la solución de problemas dependen de saber qué puertos usa un servicio, así que memoriza esta lista.

FTP (File Transfer Protocol) usa TCP 21 para la conexión de control (iniciar sesión y enviar comandos) y TCP 20 para los datos en modo activo. FTP envía usuarios, contraseñas y archivos en texto claro, así que debe evitarse en redes no confiables. SSH (Secure Shell) usa TCP 22 para dar acceso remoto cifrado por línea de comandos a servidores y dispositivos de red. SFTP (SSH File Transfer Protocol) funciona dentro de SSH en el mismo puerto 22 y ofrece transferencia de archivos cifrada. No confundas SFTP con FTPS, que es FTP protegido con TLS. TFTP (Trivial File Transfer Protocol) usa UDP 69; no tiene autenticación ni listado de directorios, y se usa en redes confiables para tareas simples, como copiar archivos de configuración o imágenes del sistema operativo hacia y desde dispositivos de red y arrancar dispositivos por la red.

HTTP (Hypertext Transfer Protocol) usa TCP 80 para el tráfico web en texto claro. HTTPS es HTTP protegido por TLS (Transport Layer Security) y usa TCP 443; cifra el tráfico y permite que el navegador verifique el certificado del servidor. Hoy, la mayor parte del tráfico web y SaaS es HTTPS.

DNS (Domain Name System) usa el puerto 53, sobre UDP para las búsquedas normales y sobre TCP para respuestas grandes y transferencias de zona entre servidores DNS. Traduce nombres como www.example.com a direcciones IP. DHCP (Dynamic Host Configuration Protocol) usa UDP 67 en el servidor y UDP 68 en el cliente. Le da automáticamente a un dispositivo su dirección IP, máscara de subred, default gateway y servidores DNS mediante cuatro mensajes: Discover, Offer, Request y Acknowledge (DORA). NTP (Network Time Protocol) usa UDP 123 para mantener sincronizados los relojes de los dispositivos, lo cual importa para las marcas de tiempo de los logs, los certificados y los sistemas de autenticación.

Para ver los puertos en uso en una computadora, ejecuta netstat -an en Windows o ss -tuln en Linux; los servicios en escucha aparecen en estado LISTEN. En Wireshark, un filtro de visualización como tcp.port == 443 o udp.port == 53 aísla un servicio.

Términos clave

Port number (número de puerto)
Número de 16 bits en el encabezado TCP o UDP que identifica la aplicación o el servicio en un host.
Well-known ports (puertos bien conocidos)
Los puertos 0 a 1023, reservados para servicios estándar como HTTP (80) y HTTPS (443).
Socket
La combinación de una dirección IP, un protocolo de transporte y un puerto que identifica un extremo de una conversación.
DORA
Los cuatro mensajes de DHCP: Discover, Offer, Request, Acknowledge.
SFTP
SSH File Transfer Protocol: transferencia de archivos cifrada que funciona sobre SSH en TCP 22.
Ejemplo real

Los usuarios pueden navegar a sitios web por dirección IP, pero no por nombre. Revisas el registro de cambios del firewall y descubres que una regla nueva bloqueó el tráfico saliente UDP 53. Al restablecer el tráfico DNS hacia los servidores DNS de la empresa, la resolución de nombres vuelve a funcionar para todos.

Consejo para el examen: Conoce también el transporte: DHCP, TFTP, NTP y las consultas DNS normales usan UDP; FTP, SSH/SFTP, HTTP y HTTPS usan TCP. SFTP comparte el puerto 22 con SSH, no el puerto 21 con FTP.

Comprueba lo que sabes

¿Qué puertos usa DHCP y sobre qué transporte?

UDP 67 para el servidor y UDP 68 para el cliente.

¿Por qué se prefiere SSH sobre Telnet y SFTP sobre FTP?

SSH y SFTP cifran las credenciales y los datos, mientras que Telnet y FTP los envían en texto claro.

¿Qué protocolo usa UDP 69 y no tiene autenticación?

TFTP, el Trivial File Transfer Protocol.
