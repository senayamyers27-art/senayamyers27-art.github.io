Cisco Certified Support Technician (CCST) Networking 100-150 v1.0

Redes locales frente a remotas y cómo decide un router a dónde enviar un paquete

Un router conecta redes distintas y reenvía paquetes entre ellas. Cada interfaz del router pertenece a una subred distinta, y el router mantiene una tabla de enrutamiento (routing table): una lista de redes de destino conocidas y de cómo llegar a cada una. Cuando llega un paquete, el router examina la dirección IP de destino, encuentra la ruta que mejor coincide y envía el paquete por la interfaz correspondiente hacia el siguiente salto (next hop).
