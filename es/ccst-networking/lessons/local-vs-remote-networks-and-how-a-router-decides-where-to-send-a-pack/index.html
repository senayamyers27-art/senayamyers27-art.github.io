Redes locales frente a remotas y cómo decide un router a dónde enviar un paquete

Un router conecta redes distintas y reenvía paquetes entre ellas. Cada interfaz del router pertenece a una subred distinta, y el router mantiene una tabla de enrutamiento (routing table): una lista de redes de destino conocidas y de cómo llegar a cada una. Cuando llega un paquete, el router examina la dirección IP de destino, encuentra la ruta que mejor coincide y envía el paquete por la interfaz correspondiente hacia el siguiente salto (next hop).

Las rutas vienen de varias fuentes. Las rutas directamente conectadas se agregan automáticamente cuando una interfaz se configura con una dirección IP y está activa; el router sabe que puede llegar a esa subred directamente. En los routers Cisco aparecen con el código C, más una ruta local (L) para la dirección de la propia interfaz del router. Las rutas estáticas las introduce manualmente un administrador, con el código S. Las rutas dinámicas se aprenden de otros routers mediante protocolos de enrutamiento como OSPF (código O) o EIGRP (código D), que se adaptan automáticamente cuando los enlaces cambian. Una ruta por defecto (default route), 0.0.0.0/0, coincide con cualquier destino que no tenga una ruta más específica y normalmente apunta hacia internet; en Cisco aparece como S* o como el 'Gateway of last resort'.

Cuando varias rutas coinciden con un destino, el router elige la coincidencia de prefijo más largo (longest prefix match), la ruta con el prefijo más específico (más largo). Por ejemplo, con rutas a 10.0.0.0/8, 10.1.0.0/16 y 0.0.0.0/0, un paquete hacia 10.1.5.9 coincide con las tres, pero el router usa 10.1.0.0/16 porque es la más específica. Un paquete hacia 8.8.8.8 solo coincide con la ruta por defecto. Si ninguna ruta coincide y no hay ruta por defecto, el router descarta el paquete y puede enviar de vuelta al emisor un mensaje ICMP Destination Unreachable.

Después de elegir una ruta, el router reduce en uno el TTL (Time to Live) del paquete, y lo descarta si el TTL llega a cero, lo que evita que los paquetes den vueltas para siempre en un bucle. Luego construye una nueva trama de Capa 2 para el enlace de salida, dirigida al router del siguiente salto o, si el destino está directamente conectado, al propio host de destino, usando ARP para encontrar la dirección MAC.

Los hosts toman una versión más simple de esta decisión: los destinos locales se envían directamente y todo lo demás va al default gateway. Luego el router repite la búsqueda en cada salto hasta que el paquete llega al router que está directamente conectado a la red de destino. En un dispositivo Cisco, show ip route muestra la tabla de enrutamiento; leerla te dice si el router sabe siquiera cómo llegar a una red.

Términos clave

Routing table (tabla de enrutamiento)
La lista de un router con las redes conocidas y la interfaz o el siguiente salto que se usa para llegar a cada una.
Directly connected route (ruta directamente conectada)
Una ruta a una subred en una de las interfaces activas del propio router, agregada automáticamente.
Static route (ruta estática)
Una ruta configurada manualmente por un administrador.
Default route (ruta por defecto)
La ruta 0.0.0.0/0 que se usa cuando ninguna ruta más específica coincide, a menudo apuntando hacia internet.
Longest prefix match (coincidencia de prefijo más largo)
La regla según la cual gana la ruta coincidente más específica cuando varias coinciden.
Ejemplo real

El router de una sucursal tiene rutas conectadas para 192.168.10.0/24 y 192.168.20.0/24, una ruta estática para 10.0.0.0/8 a través de una VPN hacia la oficina central y una ruta por defecto hacia el proveedor de internet. Un paquete hacia 10.5.1.1 va por la VPN, un paquete hacia 192.168.20.7 sale por la interfaz local y un paquete hacia un sitio web público va al proveedor.

Consejo para el examen: Cuando las rutas se superponen, gana el prefijo más largo (la ruta más específica), no la que aparece primero. Sin coincidencia y sin ruta por defecto, el paquete se descarta.

Comprueba lo que sabes

Un router tiene rutas hacia 172.16.0.0/16 y 172.16.4.0/24. ¿Cuál usa para 172.16.4.20?

172.16.4.0/24, porque es la coincidencia de prefijo más largo (más específica).

¿Qué código de la tabla de enrutamiento marca las redes directamente conectadas en un router Cisco?

C (con L para la dirección de la propia interfaz del router).
