Lo que necesita un cliente para unirse al Wi-Fi: SSID, tipo de seguridad y contraseña o credenciales

Para conectarse a una red inalámbrica, un dispositivo cliente necesita tres datos que coincidan con la configuración del access point: el nombre de la red (SSID), el tipo de seguridad y la contraseña o las credenciales que requiere ese tipo de seguridad. Si cualquiera de ellos no coincide, la conexión falla.

El SSID (service set identifier) es el nombre de la red, de hasta 32 caracteres, y distingue mayúsculas de minúsculas. Los access points normalmente lo difunden en tramas beacon varias veces por segundo, así que aparece en la lista de redes disponibles del dispositivo. Un SSID puede estar oculto (no difundido), en cuyo caso el usuario debe escribir el nombre exacto manualmente. Ocultar el SSID no es una medida de seguridad, porque el nombre sigue apareciendo en otras tramas inalámbricas y es fácil de descubrir con herramientas comunes. Un solo access point puede ofrecer varios SSID, por ejemplo uno para el personal y otro para los invitados, cada uno asociado a una VLAN distinta.

El tipo de seguridad define cómo se autentican los clientes y cómo se cifra el tráfico. Las opciones comunes son Open (sin cifrado, a veces con un captive portal web), WPA2-Personal, WPA3-Personal, el modo mixto o de transición WPA2/WPA3, y WPA2- o WPA3-Enterprise. Un dispositivo normalmente detecta el tipo automáticamente a partir del beacon, pero al agregar a mano una red oculta debes seleccionarlo correctamente. Los dispositivos antiguos que no soportan WPA3 no pueden unirse a una red solo WPA3.

Las credenciales dependen del tipo de seguridad. Los modos Personal usan una pre-shared key (PSK, clave precompartida), una frase de contraseña compartida por todos en la red; con WPA2 debe tener de 8 a 63 caracteres y distingue mayúsculas de minúsculas. Los modos Enterprise usan 802.1X, donde cada usuario inicia sesión con su propio usuario y contraseña o con un certificado digital, verificados por un servidor de autenticación (normalmente RADIUS). Las configuraciones Enterprise también pueden requerir que el dispositivo confíe en el certificado del servidor. Los captive portals (portales cautivos), comunes en hoteles y cafeterías, dejan que el dispositivo se conecte primero y luego piden al usuario aceptar los términos o iniciar sesión en una página web antes de permitir el acceso a internet.

Cuando un usuario no puede conectarse, verifica que el Wi-Fi esté activado y el modo avión apagado, que haya elegido el SSID correcto (son comunes los nombres parecidos, como Office y Office-Guest), que la contraseña esté escrita exactamente, incluidas las mayúsculas, y que el dispositivo soporte el tipo de seguridad y la banda. Después de un cambio de contraseña, el dispositivo puede seguir intentando con el perfil antiguo guardado; usa 'olvidar' la red y vuelve a unirte. Una vez conectado, confirma que recibió una dirección IP y que no es una dirección 169.254.

Términos clave

SSID
Service set identifier: el nombre de una red inalámbrica, que distingue mayúsculas de minúsculas.
Pre-shared key (PSK, clave precompartida)
Una frase de contraseña compartida por todos los usuarios de una red WPA2- o WPA3-Personal.
802.1X
Autenticación basada en puertos usada por el Wi-Fi Enterprise, en la que un servidor de autenticación verifica a cada usuario o dispositivo.
Captive portal (portal cautivo)
Una página web que los usuarios deben completar, por ejemplo aceptando términos o iniciando sesión, antes de obtener acceso a internet.
Ejemplo real

Después de que la oficina cambió su frase de contraseña Wi-Fi, la laptop de un usuario muestra 'Can't connect to this network' (no se puede conectar a esta red). La laptop todavía tiene guardada la frase anterior. Le pides al usuario que olvide la red, seleccione el SSID correcto e ingrese la nueva frase, y la laptop se conecta y recibe una dirección normal.

Consejo para el examen: Ocultar el SSID no protege una red. La seguridad viene del cifrado WPA2 o WPA3 con una frase de contraseña fuerte o con credenciales 802.1X.

Comprueba lo que sabes

¿Qué tres cosas debe tener un cliente para unirse a una red Wi-Fi protegida?

El SSID correcto, un tipo de seguridad que coincida y la frase de contraseña o las credenciales correctas.

¿En qué se diferencian WPA2-Personal y WPA2-Enterprise en cuanto a las credenciales que dan los usuarios?

Personal usa una sola frase de contraseña compartida por todos; Enterprise usa credenciales individuales que un servidor de autenticación verifica mediante 802.1X.
