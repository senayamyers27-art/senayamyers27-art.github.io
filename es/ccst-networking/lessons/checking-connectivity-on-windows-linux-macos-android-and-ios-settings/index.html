Cómo verificar la conectividad en Windows, Linux, macOS, Android e iOS: pantallas de configuración y herramientas de línea de comandos

Todos los sistemas operativos te permiten ver la configuración de red de un dispositivo: su dirección IP, máscara de subred, default gateway, servidores DNS y estado de conexión. Saber dónde buscar en cada plataforma te permite guiar a un usuario por teléfono y confirmar lo básico antes de un diagnóstico más profundo.

En Windows, la app Settings (Configuración), en Network and internet (Red e internet), muestra cada conexión y sus propiedades, incluidos los detalles de IP y DNS. La vista clásica Network Connections del Control Panel (a la que se llega ejecutando ncpa.cpl) lista los adaptadores y si están habilitados. Desde Command Prompt o PowerShell, ipconfig muestra la dirección, la máscara y el gateway, e ipconfig /all agrega la dirección MAC, el servidor DHCP, los tiempos de concesión y los servidores DNS. ipconfig /release e ipconfig /renew solicitan una nueva concesión DHCP, e ipconfig /flushdns borra los resultados DNS almacenados en caché. Otras herramientas útiles son ping, tracert, nslookup, netstat y arp -a. PowerShell también ofrece Test-NetConnection, que puede probar un puerto TCP específico.

En Linux, los escritorios gráficos tienen un panel de configuración de red, pero los técnicos usan sobre todo la terminal. ip addr (o ip a) muestra las interfaces y direcciones, ip route muestra la tabla de enrutamiento, incluido el default gateway, e ip link muestra si las interfaces están activas. El antiguo ifconfig todavía existe en algunos sistemas. Los servidores DNS a menudo aparecen en /etc/resolv.conf o se muestran con resolvectl status. Las herramientas incluyen ping, traceroute (o tracepath), nslookup y dig, y ss para las conexiones abiertas.

En macOS, System Settings (System Preferences en versiones anteriores) tiene una sección Network que muestra la conexión Wi-Fi o Ethernet, su dirección IP, el router (el default gateway) y los servidores DNS en Details. En Terminal, ifconfig muestra las interfaces, y funcionan comandos como ping, traceroute, nslookup y networksetup. Mantener presionada la tecla Option al hacer clic en el ícono de Wi-Fi muestra detalles adicionales, como la intensidad de la señal y el canal.

En Android, abre Settings (Ajustes) y luego Network and internet (Red e internet) (los nombres exactos varían según el fabricante), selecciona la red Wi-Fi conectada y mira sus detalles, incluidos la dirección IP, el gateway, la intensidad de la señal y el tipo de seguridad. La pantalla About phone (Acerca del teléfono) muestra información de la dirección MAC del Wi-Fi. En iOS y iPadOS, ve a Settings, Wi-Fi, y toca el ícono de información junto a la red conectada para ver la dirección IP, la máscara de subred, el router y la configuración DNS, además de opciones como Renew Lease y Private Wi-Fi Address. Los dispositivos móviles no tienen una línea de comandos integrada, así que los técnicos dependen de estas pantallas o de apps de utilidades de red.

Sea cual sea la plataforma, revisa las mismas cosas en el mismo orden: si está conectado o no, una dirección válida (no 169.254), el gateway y el DNS correctos, y luego las pruebas de alcanzabilidad.

Términos clave

ipconfig
Comando de Windows que muestra la configuración IP; /all agrega detalles, /release y /renew renuevan DHCP, /flushdns borra la caché DNS.
ip
Comando de Linux para ver y configurar interfaces (ip addr), rutas (ip route) y enlaces (ip link).
ifconfig
Comando Unix más antiguo para ver la configuración de las interfaces, todavía usado en macOS.
Test-NetConnection
Comando de PowerShell que prueba la alcanzabilidad y puede verificar si un puerto TCP específico está abierto.
Ejemplo real

Un usuario de iPhone dice que el Wi-Fi de la oficina aparece como conectado pero nada carga. Le pides que abra Settings, Wi-Fi, y toque el ícono de información. La dirección IP empieza con 169.254, así que el teléfono nunca obtuvo una concesión DHCP. Tocar Renew Lease y luego revisar la configuración de VLAN del access point resuelve el problema.

Consejo para el examen: Conoce el comando de cada plataforma: Windows usa ipconfig y tracert; Linux usa ip y traceroute; macOS usa ifconfig y traceroute. Los teléfonos usan la pantalla de detalles del Wi-Fi.

Comprueba lo que sabes

¿Qué comando de Windows muestra la dirección MAC y los servidores DNS de cada adaptador?

ipconfig /all.

¿Cómo puedes ver el default gateway de un host Linux desde la terminal?

Ejecuta ip route y busca la línea que empieza con default via.
