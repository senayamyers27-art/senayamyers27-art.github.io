VPN e IPsec (AH vs ESP, modo túnel vs transporte)

Una red privada virtual (VPN) crea un túnel cifrado a través de una red no confiable, normalmente internet, para que el tráfico esté protegido como si viajara por un enlace privado. Las VPN de sitio a sitio conectan redes completas, como una sucursal con la sede central, usando puertas de enlace (gateways) en cada extremo; los usuarios no se dan cuenta de ellas. Las VPN de acceso remoto conectan los dispositivos de usuarios individuales a la red corporativa mediante software cliente. Las tecnologías comunes incluyen IPsec, las VPN basadas en TLS (a menudo llamadas VPN SSL, que pueden funcionar desde un navegador o un cliente) y protocolos más nuevos como WireGuard.
