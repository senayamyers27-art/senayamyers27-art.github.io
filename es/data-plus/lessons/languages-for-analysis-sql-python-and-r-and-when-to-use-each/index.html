CompTIA Data+ DA0-002

Lenguajes para análisis: SQL, Python y R, y cuándo usar cada uno

Data+ no te evalúa como programador, pero espera que sepas para qué sirven los lenguajes principales, que puedas leer código sencillo y que elijas el adecuado para cada tarea.

SQL (Structured Query Language) es el lenguaje de las bases de datos relacionales y de la mayoría de los data warehouses en la nube. Es declarativo: describes el resultado que quieres y la base de datos decide cómo obtenerlo. Los analistas de datos usan SQL para seleccionar columnas, filtrar filas, unir tablas, agrupar y agregar, y cada vez más para transformar los datos dentro del warehouse. Como el trabajo ocurre donde viven los datos, SQL escala a tablas muy grandes sin tener que mover los datos a tu computadora. Las distintas bases de datos tienen dialectos con pequeñas diferencias, pero las instrucciones básicas son comunes.

SELECT region, SUM(amount) AS revenue
FROM sales
WHERE sale_date >= '2025-01-01'
GROUP BY region
ORDER BY revenue DESC;

Python es un lenguaje de propósito general con un gran ecosistema de datos. pandas maneja tablas (DataFrames) para limpiar, reorganizar y agregar. NumPy maneja arreglos numéricos rápidos. Matplotlib y seaborn dibujan gráficos. scikit-learn ofrece machine learning. Python es una buena opción cuando una tarea combina trabajo con datos y automatización, como llamar a una API, procesar archivos, programar un pipeline o integrar un modelo en una aplicación.

R fue creado por estadísticos para la estadística. Tiene un soporte profundo para pruebas estadísticas, modelos y gráficos con calidad de publicación (ggplot2), y los paquetes del tidyverse hacen que la manipulación de datos sea legible. R es común en la academia, la investigación, el sector salud y en cualquier ámbito donde el análisis estadístico riguroso sea central.

En la práctica, la elección depende de la tarea y del equipo. Usa SQL para obtener y dar forma a los datos de las bases de datos. Usa Python o R cuando necesites lógica que SQL expresa mal: limpieza compleja, estadística, machine learning, automatización o gráficos personalizados. Muchos analistas extraen los datos con SQL y luego los analizan en Python o R. Uses lo que uses, mantén el código en control de versiones, comenta lo que no sea obvio y evita escribir valores fijos en el código (hard-coding), como fechas, para que el análisis se pueda volver a ejecutar.

Términos clave

SQL
Un lenguaje declarativo para consultar y administrar datos en bases de datos relacionales.
pandas
Una biblioteca de Python para trabajar con datos tabulares en DataFrames.
R
Un lenguaje de programación y entorno diseñado para computación estadística y gráficos.
Declarative language (lenguaje declarativo)
Un lenguaje en el que indicas el resultado que quieres en lugar de los pasos para producirlo.
Ejemplo real

Una analista necesita pronosticar la demanda semanal. Escribe una consulta SQL para agregar dos años de ventas por semana en el warehouse, carga el resultado, mucho más pequeño, en un notebook de Python con pandas, ajusta y verifica un modelo de pronóstico, y programa el notebook para que se actualice cada semana.

Consejo para el examen: Consultar y agregar datos donde viven apunta a SQL; automatización y machine learning apuntan a Python; análisis estadístico intensivo apunta a R. Espera tener que leer fragmentos cortos de código y decir qué hacen.

Comprueba lo que sabes

¿Por qué suele ser mejor agregar una tabla de mil millones de filas en SQL que cargarla en un notebook?

El motor de la base de datos está hecho para procesar los datos donde están almacenados; mover mil millones de filas a una herramienta local es lento y puede que no quepa en memoria.
