CompTIA Data+ DA0-002

Conceptos de IA y automatización para analistas: machine learning, IA generativa, modelos de lenguaje grandes, NLP y RPA

La IA ya forma parte del trabajo analítico diario, y los objetivos de DA0-002 esperan que los analistas entiendan los conceptos principales lo bastante bien como para usarlos con sensatez y explicarlos a otras personas.

Machine learning (ML, aprendizaje automático) se refiere a algoritmos que aprenden patrones a partir de los datos en lugar de seguir reglas escritas a mano. En el aprendizaje supervisado, los datos de entrenamiento tienen respuestas conocidas (etiquetas) y el modelo aprende a predecirlas para casos nuevos: la clasificación predice una categoría, como abandono o no abandono (churn), y la regresión predice un número, como las ventas del próximo mes. En el aprendizaje no supervisado no hay etiquetas; el modelo encuentra estructura, por ejemplo agrupando a los clientes en segmentos (clustering). Los modelos se entrenan con una parte de los datos y se prueban con datos reservados para comprobar que generalizan en lugar de memorizar (sobreajuste u overfitting).

La IA generativa crea contenido nuevo, como texto, imágenes, código o audio, a partir de patrones aprendidos de enormes conjuntos de datos de entrenamiento. Un modelo fundacional (foundation model) es un modelo grande entrenado con datos amplios que puede adaptarse a muchas tareas. Los modelos de lenguaje grandes (LLM) son modelos fundacionales para texto: predicen las palabras siguientes más probables y pueden redactar resúmenes, explicar resultados, escribir SQL o Python y responder preguntas. También pueden producir resultados seguros y verosímiles pero incorrectos, lo que suele llamarse alucinación (hallucination), así que todo lo que generan debe verificarse. Nunca pegues datos sensibles o regulados en una herramienta a menos que tu organización la haya aprobado para esos datos.

El procesamiento de lenguaje natural (NLP) es el campo más amplio que busca que las computadoras trabajen con el lenguaje humano: análisis de sentimiento, extracción de entidades (nombres, lugares, productos), clasificación por temas, traducción y conversión de voz a texto. Para los analistas, el NLP convierte texto no estructurado, como comentarios de encuestas o tickets de soporte, en campos estructurados que puedes contar y graficar.

La automatización robótica de procesos (RPA) usa bots de software que imitan los clics y las pulsaciones de teclado que una persona hace en las aplicaciones, siguiendo reglas fijas: copiar los valores de una factura en una pantalla del ERP, descargar un reporte cada mañana, mover archivos. No aprende; automatiza tareas repetitivas y predecibles, a menudo cuando los sistemas no tienen una API. A veces se combinan RPA e IA, por ejemplo un NLP que lee un documento y un bot que ingresa los valores extraídos.

Sea cual sea la herramienta, el analista sigue siendo responsable del resultado. Compara los resultados de los modelos con cifras conocidas, vigila el sesgo en los datos de entrenamiento y documenta cómo se usó la IA en un análisis.

Términos clave

Supervised learning (aprendizaje supervisado)
Machine learning entrenado con ejemplos etiquetados para predecir una etiqueta o un valor en datos nuevos.
Large language model, LLM (modelo de lenguaje grande)
Un modelo fundacional entrenado con grandes cantidades de texto que genera e interpreta lenguaje.
Natural language processing, NLP (procesamiento de lenguaje natural)
Técnicas que permiten a las computadoras analizar y generar lenguaje humano, como el análisis de sentimiento.
Robotic process automation, RPA (automatización robótica de procesos)
Bots de software que repiten tareas de interfaz de usuario basadas en reglas, como la captura de datos, sin aprender.
Ejemplo real

Una gerente de soporte quiere saber qué provoca las quejas. El NLP etiqueta 20,000 comentarios de tickets por tema y sentimiento, un modelo supervisado predice qué tickets abiertos probablemente escalarán, y un bot de RPA copia los resultados semanales en un sistema de reportes heredado que no tiene API. El analista revisa a mano una muestra de etiquetas antes de presentar las cifras.

Consejo para el examen: La automatización de interfaz basada en reglas es RPA, no machine learning. Predecir una etiqueta conocida es aprendizaje supervisado; encontrar grupos sin etiquetas es no supervisado. Los resultados de un LLM siempre deben validarse.

Comprueba lo que sabes

¿Cuál es la diferencia entre clasificación y clustering?

La clasificación es supervisada: predice categorías conocidas aprendidas de datos etiquetados. El clustering es no supervisado: agrupa registros similares sin etiquetas predefinidas.

¿Por qué un analista debe validar el SQL escrito por un LLM?

Los LLM pueden generar código verosímil pero incorrecto, como un join o un filtro equivocados, así que los resultados deben probarse contra cifras conocidas antes de usarlos.
