CompTIA Data+ DA0-002

Elegir herramientas y funciones de análisis: fórmulas de hojas de cálculo, agregados y funciones de ventana de SQL, bibliotecas de Python y R

Saber estadística no basta; tienes que hacer el trabajo con herramientas reales. Data+ espera que reconozcas las funciones comunes y elijas una herramienta sensata para cada tarea.

Las hojas de cálculo cubren gran parte del análisis cotidiano. Las funciones de agregación incluyen SUM, AVERAGE, COUNT (números), COUNTA (celdas no vacías), MIN y MAX, y versiones condicionales como SUMIF, COUNTIF y AVERAGEIF (o SUMIFS para varias condiciones). Las funciones estadísticas incluyen MEDIAN, MODE, STDEV.S, PERCENTILE y CORREL. Las funciones de búsqueda como XLOOKUP, VLOOKUP e INDEX con MATCH obtienen valores de otra tabla mediante una clave. IF construye lógica condicional, y las funciones de texto como LEFT, TRIM y CONCAT limpian cadenas. Las tablas dinámicas resumen los datos por categorías sin fórmulas.

Las funciones de agregación de SQL (COUNT, SUM, AVG, MIN, MAX) reducen las filas a una por grupo con GROUP BY. Las funciones de ventana (window functions) calculan sobre filas relacionadas sin reducirlas, usando OVER. Un total acumulado es SUM(amount) OVER (ORDER BY sale_date). Una clasificación dentro de cada región es RANK() OVER (PARTITION BY region ORDER BY revenue DESC). LAG y LEAD obtienen el valor de la fila anterior o siguiente, lo que facilita calcular el cambio de un periodo a otro, y un promedio móvil usa un marco como ROWS BETWEEN 6 PRECEDING AND CURRENT ROW.

SELECT sale_date, amount,
       SUM(amount) OVER (ORDER BY sale_date) AS running_total,
       amount - LAG(amount) OVER (ORDER BY sale_date) AS change_vs_prior_day
FROM daily_sales;

En Python, pandas maneja la mayor parte del análisis: groupby().agg() para resúmenes agrupados, describe() para estadísticas rápidas, merge para joins, pivot_table y melt para reorganizar, y rolling() para ventanas móviles. NumPy y SciPy agregan funciones numéricas y estadísticas, incluidas las pruebas de hipótesis comunes. Matplotlib y seaborn dibujan gráficos. En R, los verbos de dplyr (filter, select, mutate, group_by, summarise) manejan la manipulación de datos, ggplot2 maneja los gráficos, y R base trae integradas pruebas estadísticas y modelos lineales.

Elige según el tamaño de los datos, la repetibilidad y el público. Una revisión puntual de unos cuantos miles de filas cabe en una hoja de cálculo. Cualquier cosa grande o recurrente pertenece a SQL, cerca de los datos. La estadística compleja, el modelado o la automatización encajan en Python o R. Sea cual sea la herramienta, evita los números fijos enterrados en las fórmulas y mantén la lógica donde otra persona pueda revisarla y volver a ejecutarla.

Términos clave

Window function (función de ventana)
Una función de SQL que calcula sobre un conjunto de filas relacionadas usando OVER, sin reducirlas a grupos.
PARTITION BY
La parte de la definición de una ventana que reinicia el cálculo para cada grupo, como cada región.
XLOOKUP
Una función de hoja de cálculo que busca una clave en un rango y devuelve el valor correspondiente de otro rango.
LAG
Una función de ventana que devuelve un valor de una fila anterior; se usa para comparaciones entre periodos.
Ejemplo real

Una analista financiera necesita los ingresos mensuales de cada tienda, su posición dentro de su región y su cambio respecto al mes anterior. En lugar de exportar a una hoja de cálculo y escribir cientos de fórmulas, escribe una sola consulta SQL con SUM para los totales mensuales, RANK() OVER (PARTITION BY region ...) para la posición y LAG para el mes anterior, y conecta el resultado al dashboard.

Consejo para el examen: GROUP BY reduce las filas; las funciones de ventana conservan todas las filas. Totales acumulados, clasificaciones y comparaciones con el periodo anterior apuntan a funciones de ventana.

Comprueba lo que sabes

¿Qué función de hoja de cálculo cuenta las celdas de un rango que cumplen una sola condición?

COUNTIF (COUNTIFS para varias condiciones).

¿Qué hace PARTITION BY region en RANK() OVER (PARTITION BY region ORDER BY sales DESC)?

Reinicia la clasificación para cada región, así que cada región tiene su propio 1, 2, 3, etcétera.
