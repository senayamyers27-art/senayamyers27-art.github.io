CompTIA Data+ DA0-002

Métodos de adquisición de datos: extracciones de bases de datos, API, web scraping, exportaciones de archivos, encuestas y muestreo

Antes de poder analizar los datos tienes que obtenerlos, y el método que elijas afecta qué tan actuales, completos, confiables y legales son. Data+ espera que asocies un método de recolección con cada escenario.

Las extracciones de bases de datos (database extracts) obtienen los datos directamente de la base de datos de un sistema de origen mediante una consulta, a menudo de forma programada. Son precisas y repetibles, pero requieren credenciales de acceso, conocer el esquema de origen y cuidado para no sobrecargar un sistema de producción. Por eso muchos equipos extraen desde una réplica de lectura o en horarios de poca actividad.

Las API (interfaces de programación de aplicaciones) son la forma oficial de que un programa solicite datos a otro. Una API web típica usa solicitudes HTTPS a endpoints y devuelve JSON. Las API suelen requerir autenticación con una API key o un token OAuth, limitan cuántas solicitudes puedes hacer (rate limits) y devuelven los resultados grandes en páginas, así que tu código debe recorrer la paginación en un ciclo. Cuando un proveedor ofrece una API, prefiérela al scraping: es estable, está documentada y está permitida.

El web scraping extrae datos de páginas web descargando el HTML e interpretándolo para obtener los valores. Es útil cuando no existe una API, pero es frágil, porque un rediseño de la página rompe el scraper, y plantea cuestiones legales y éticas. Revisa los términos de uso del sitio y el archivo robots.txt, recolecta solo lo que necesitas, evita los datos personales y mantén un ritmo de solicitudes moderado para no sobrecargar el servidor.

Las exportaciones de archivos y los archivos compartidos, como descargas CSV de una herramienta SaaS, hojas de cálculo de un socio o archivos depositados en un servidor de transferencia segura de archivos, son comunes y sencillos, pero son instantáneas (snapshots). Verifica cuándo se generó el archivo, si su estructura cambió y si está completo. Las exportaciones manuales también son difíciles de automatizar de forma confiable.

Las encuestas y la observación recolectan datos primarios que tú mismo generas. Las buenas encuestas necesitan preguntas claras e imparciales y una muestra bien elegida. El muestreo selecciona una parte de una población cuando medir a todos no es práctico. En un muestreo aleatorio simple, cada miembro tiene la misma probabilidad de ser seleccionado. El muestreo estratificado divide la población en grupos, como regiones, y muestrea aleatoriamente dentro de cada uno para que todos los grupos estén representados. El muestreo sistemático elige cada n-ésimo elemento de una lista. El muestreo por conglomerados (cluster sampling) elige al azar grupos completos, como unas cuantas tiendas, y mide a todos los que están en ellos. El muestreo por conveniencia usa a quien sea fácil de contactar, lo que es rápido pero propenso al sesgo. El sesgo de muestreo ocurre cuando la muestra no representa a la población, por ejemplo al encuestar solo a los clientes que aceptaron recibir correos.

Términos clave

API
Una interfaz que permite a los programas solicitar datos a un sistema de forma documentada y estructurada, a menudo por HTTPS y devolviendo JSON.
Web scraping
Extraer datos descargando e interpretando páginas web; se usa cuando no hay una API disponible.
Stratified sampling (muestreo estratificado)
Dividir una población en grupos y muestrear aleatoriamente dentro de cada grupo.
Sampling bias (sesgo de muestreo)
Error sistemático que ocurre cuando una muestra no representa a la población que debería describir.
Ejemplo real

Una empresa de viajes quiere conocer los precios de la competencia. Un competidor publica una API para socios con una API key y un límite de solicitudes, así que el analista la usa con paginación. Otro no tiene API y sus términos prohíben la recolección automatizada, así que el equipo compra una fuente de datos con licencia en lugar de hacer scraping.

Consejo para el examen: Si existe una API, casi siempre es la respuesta preferida frente al scraping. En encuestas, busca el método de muestreo que garantiza que todos los subgrupos estén representados: el estratificado.

Comprueba lo que sabes

¿Por qué es riesgoso el muestreo por conveniencia?

Las personas fáciles de contactar pueden ser sistemáticamente diferentes de la población, así que los resultados pueden estar sesgados y no ser generalizables.

Una API devuelve 100 registros por llamada y tiene 12,000 registros. ¿Qué debe manejar tu código?

La paginación: repetir las solicitudes para cada página (con el número de página, el offset o el token de página siguiente) hasta obtener todos los registros, respetando los límites de solicitudes.
