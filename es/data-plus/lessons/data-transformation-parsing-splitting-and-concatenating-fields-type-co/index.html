CompTIA Data+ DA0-002

Transformación de datos: parsing, división y concatenación de campos, conversión de tipos, recodificación y variables derivadas

La transformación convierte los campos sin procesar en la forma que tu análisis necesita. La mayoría de estas operaciones son sencillas por sí solas, pero necesitas reconocerlas por su nombre y elegir la adecuada para cada escenario.

Hacer parsing (analizar sintácticamente) significa leer una cadena estructurada y extraer sus partes. La división (splitting) es una forma común: separar 'Smith, John' por la coma en apellido y nombre, descomponer una dirección en calle, ciudad y código postal, o extraer el dominio de una dirección de correo. El parsing también incluye extraer campos de JSON o de líneas de log, y leer una fecha a partir de un texto como '2025-03-14T09:30:00Z'. Las funciones de cadena hacen el trabajo: LEFT, RIGHT, SUBSTRING (MID), TRIM para quitar espacios sobrantes, UPPER y LOWER para mayúsculas y minúsculas, REPLACE, y funciones de posición que encuentran un delimitador.

La concatenación es lo contrario: unir varios campos en uno, como el nombre y el apellido en un nombre completo, o el año y el mes en una clave de periodo. En SQL se usa CONCAT(first_name, ' ', last_name) o el operador || en muchas bases de datos; las hojas de cálculo tienen CONCAT y TEXTJOIN; pandas puede sumar columnas de texto.

La conversión de tipos cambia el tipo de dato de un campo para que se comporte correctamente: de texto a fecha para poder agrupar por mes, de texto a número para poder sumar, o de número a texto para los identificadores. Las conversiones pueden fallar con valores incorrectos, así que cuenta los fallos en lugar de suponer que todo salió bien.

La recodificación (recoding) asigna valores nuevos a los valores existentes. Podrías convertir 'M', 'Male' y 'male' en un solo código, reducir veinte tipos de producto detallados a cinco categorías, o convertir 'Y'/'N' en verdadero y falso. Una tabla de búsqueda (mapping table) hace que la recodificación sea transparente y fácil de mantener.

Las variables derivadas, también llamadas campos calculados o ingeniería de características (feature engineering), son columnas nuevas construidas a partir de las existentes: el total del pedido como cantidad por precio unitario, la edad del cliente a partir de la fecha de nacimiento, los días hasta el envío como fecha de envío menos fecha de pedido, el margen de ganancia como ganancia dividida entre ingresos, o un indicador como is_weekend. La lógica condicional crea categorías, por ejemplo CASE WHEN days_to_ship > 5 THEN 'Late' ELSE 'On time' END.

Mantén las transformaciones repetibles, en un script, una consulta o pasos de Power Query en lugar de ediciones manuales, para que la misma lógica se ejecute cada vez que lleguen datos nuevos, y conserva el campo original hasta que hayas verificado el resultado.

Términos clave

Parsing (análisis sintáctico)
Extraer partes significativas de una cadena o un documento estructurado, como dividir un nombre por una coma.
Concatenation (concatenación)
Unir dos o más valores en una sola cadena.
Recoding (recodificación)
Asignar a los valores existentes valores nuevos, estandarizados o agrupados.
Derived variable (variable derivada)
Un campo nuevo calculado a partir de campos existentes, como el margen de ganancia o los días hasta el envío.
Ejemplo real

Una analista de logística recibe datos de envíos con un solo campo 'City, ST ZIP' y marcas de tiempo en texto. Hace parsing de la ubicación en columnas de ciudad, estado y código postal, convierte las marcas de tiempo a datetime, deriva days_in_transit a partir de las fechas de envío y entrega, y recodifica los nombres de los transportistas para que 'UPS', 'U.P.S.' y 'ups ground' se conviertan en un solo valor.

Consejo para el examen: Dividir un campo en varios significa parsing; unir varios en uno significa concatenación; crear una nueva columna calculada significa una variable derivada.

Comprueba lo que sabes

Una columna contiene correos completos y necesitas el dominio de la empresa. ¿Qué transformación es esta?

Parsing: buscar la @ y extraer el texto que sigue, por ejemplo con SUBSTRING y una función de posición.

¿Por qué usar una tabla de búsqueda para recodificar en lugar de editar los valores a mano?

Documenta las reglas, es fácil de actualizar y aplica la misma recodificación de forma consistente cada vez que se procesan datos nuevos.
