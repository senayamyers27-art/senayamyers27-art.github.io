Azure AI Document Intelligence: modelos precompilados (facturas, recibos, identificaciones), el modelo layout y los modelos personalizados

Azure AI Document Intelligence (antes Form Recognizer) es el servicio de Azure AI para extraer texto, estructura y datos de documentos. Se basa en OCR pero devuelve mucho más: el diseño (layout) de la página y, con el modelo adecuado, campos con nombre y sus valores, listos para guardarse en una base de datos o enviarse a un sistema de negocio.

Los modelos precompilados (prebuilt models) están entrenados por Microsoft con tipos de documentos comunes y no necesitan que tú los entrenes. Algunos ejemplos son las facturas (proveedor, cliente, número de factura, fechas, partidas, totales), los recibos (comercio, fecha, artículos, subtotal, impuestos, total), los documentos de identidad como pasaportes y licencias de conducir, las tarjetas de presentación y varios formularios fiscales y financieros. Cada campo extraído incluye su valor, su ubicación en la página y una puntuación de confianza, así que una app puede enviar los documentos de baja confianza a una persona.

El modelo layout extrae texto, tablas (con filas, columnas y celdas), marcas de selección como casillas de verificación, párrafos y la estructura del documento de cualquier documento, sin buscar campos con nombre específicos. El modelo read extrae solo texto. Una opción de documento general también encuentra pares clave-valor. Usa layout cuando necesites la estructura de documentos que ningún modelo precompilado cubre, o como primer paso antes de un procesamiento personalizado.

Los modelos personalizados (custom models) manejan tipos de documentos propios de tu organización. Un modelo de extracción personalizado (custom extraction model) aprende a extraer los campos que tú defines a partir de un conjunto de tus documentos de muestra que etiquetas en Document Intelligence Studio; unos cuantos ejemplos etiquetados pueden bastar para un formulario con un diseño consistente. Un modelo de clasificación personalizado (custom classification model) identifica qué tipo de documento es un archivo, para que puedas enviarlo al modelo de extracción correcto.

Creas un recurso de Document Intelligence (o usas un recurso multiservicio de Azure AI services), luego pruebas los modelos en Document Intelligence Studio sin código, o los llamas a través de la REST API y los SDK. Los documentos se pueden enviar como imágenes o PDF. Hay un nivel gratuito F0 con páginas limitadas para experimentar.

La distinción principal en el examen es entre OCR simple y document intelligence. El OCR de Azure AI Vision te da texto y posiciones. Document Intelligence te da significado y estructura: qué texto es el total, qué filas forman una tabla, qué casilla está marcada.

Términos clave

Prebuilt model (modelo precompilado)
Un modelo de Document Intelligence entrenado por Microsoft para un tipo de documento común, como facturas o recibos.
Layout model (modelo de diseño)
Un modelo que extrae texto, tablas, marcas de selección y estructura de cualquier documento.
Custom extraction model (modelo de extracción personalizado)
Un modelo que entrenas con muestras etiquetadas para extraer tus propios campos de tu propio tipo de documento.
Selection mark (marca de selección)
Una casilla de verificación o botón de opción en un formulario, devuelto como seleccionado o no seleccionado.
Ejemplo real

Una app de gastos permite al personal fotografiar recibos. El modelo precompilado de recibos devuelve el comercio, la fecha, los impuestos y el total, y la app llena automáticamente la solicitud de reembolso. El formulario de kilometraje propio de la empresa tiene un diseño único, así que el equipo etiqueta diez ejemplos y entrena un modelo de extracción personalizado para él.

Consejo para el examen: Documento de negocio común con campos estándar: modelo precompilado. Tablas y estructura de cualquier documento: layout. Tu propio formulario único: modelo personalizado entrenado con muestras etiquetadas.

Comprueba lo que sabes

Una empresa necesita las partidas y los totales de las facturas de sus proveedores. ¿Qué modelo debería probar primero?

El modelo precompilado de facturas, porque ya extrae esos campos sin entrenamiento.

¿Qué hace un modelo de clasificación personalizado?

Identifica el tipo de cada documento para que pueda enviarse al modelo de extracción correcto.
