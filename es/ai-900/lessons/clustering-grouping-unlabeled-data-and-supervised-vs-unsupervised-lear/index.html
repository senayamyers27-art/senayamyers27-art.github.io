Clustering: agrupar datos sin etiquetar, y aprendizaje supervisado vs no supervisado

El clustering (agrupamiento) es machine learning no supervisado que agrupa elementos similares. A diferencia de la regresión y la clasificación, no hay columna de etiqueta ni respuesta correcta en los datos de entrenamiento. El algoritmo solo mira las características y decide qué elementos se parecen.

El algoritmo de ejemplo más común es k-means. Tú eliges el número de clusters, k. El algoritmo coloca k puntos centrales, asigna cada elemento al centro más cercano, mueve cada centro al promedio de sus elementos y repite hasta que los clusters dejan de cambiar. El resultado es un número de cluster para cada elemento. Queda en manos de las personas interpretar qué significan los clusters: 'el cluster 2 parece de cazadores de ofertas que compran los fines de semana'.

El clustering es útil cuando quieres descubrir una estructura que no conocías. Las empresas lo usan para la segmentación de clientes (encontrar grupos de clientes con hábitos de compra similares para marketing dirigido), agrupar documentos por tema, organizar productos con características similares y explorar datos antes de construir otros modelos. También puede ayudar a etiquetar datos: una vez que entiendes los clusters, podrías nombrarlos y usarlos como clases para entrenar un clasificador.

La evaluación es diferente a la del aprendizaje supervisado porque no hay etiquetas reales con las cuales comparar. Las métricas de clustering miden qué tan compacto es cada cluster y qué tan bien separados están los clusters, por ejemplo la distancia promedio entre los elementos y el centro de su cluster, y la distancia entre los centros de los clusters.

La distinción clave en AI-900 es supervisado frente a no supervisado. El aprendizaje supervisado entrena con datos que incluyen etiquetas conocidas, así que el modelo aprende a predecir esas etiquetas: regresión (números) y clasificación (categorías). El aprendizaje no supervisado entrena con datos sin etiquetas y encuentra patrones por sí solo: el clustering es el ejemplo del examen.

Fíjate en la redacción de los escenarios. 'Asigna a cada cliente a uno de nuestros tres niveles de lealtad' usa categorías conocidas, así que es clasificación. 'Descubre grupos de clientes con comportamiento similar' sin grupos predefinidos es clustering.

Términos clave

Clustering (agrupamiento)
Aprendizaje no supervisado que agrupa elementos con valores de características similares.
Unsupervised learning (aprendizaje no supervisado)
Machine learning con datos sin etiquetas, que encuentra la estructura por sí solo.
Supervised learning (aprendizaje supervisado)
Machine learning con datos que incluyen etiquetas conocidas, usado para predecir esas etiquetas.
k-means
Un algoritmo de clustering que agrupa elementos alrededor de k puntos centrales y ajusta los centros repetidamente.
Ejemplo real

Una librería en línea ejecuta k-means sobre la frecuencia de compra, el gasto promedio y los géneros favoritos de sus clientes, con k igual a 4. Encuentra un cluster de fanáticos de la novela policiaca con alto gasto que compran el día del lanzamiento, y diseña una campaña de preventa solo para ellos.

Consejo para el examen: Sin etiquetas y 'descubrir grupos' significa clustering. Categorías conocidas que predecir significa clasificación, aunque el escenario use la palabra 'grupo'.

Comprueba lo que sabes

¿El clustering es supervisado o no supervisado, y por qué?

No supervisado, porque los datos de entrenamiento no tienen etiquetas; el algoritmo encuentra grupos solo a partir de las características.

Una escuela quiere predecir si los estudiantes aprobarán o reprobarán usando los resultados del año pasado. ¿Clustering o clasificación?

Clasificación, porque los resultados anteriores proporcionan etiquetas conocidas (aprobado o reprobado).
