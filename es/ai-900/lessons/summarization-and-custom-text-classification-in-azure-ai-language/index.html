Resumen y clasificación de texto personalizada en Azure AI Language

Además de las funciones de análisis precompiladas, Azure AI Language puede condensar textos largos en resúmenes y puede aprender tus propias categorías para clasificar texto. Estas dos capacidades aparecen en escenarios sobre el manejo de grandes volúmenes de documentos y mensajes.

El resumen (summarization) produce una versión más corta de un documento o una conversación que conserva los puntos clave. El resumen extractivo (extractive summarization) selecciona las oraciones más importantes del texto original y las devuelve, cada una con una puntuación de rango, así que el resumen usa las palabras exactas del autor. El resumen abstractivo (abstractive summarization) genera oraciones nuevas que captan las ideas principales, lo que normalmente se lee de forma más natural, como si una persona escribiera el resumen. El resumen de conversaciones (conversation summarization) está diseñado para transcripciones como llamadas de soporte o reuniones y puede producir resúmenes del problema y la resolución, o títulos de capítulos para una grabación larga.

El resumen ayuda a las personas a lidiar con la sobrecarga de información: captar la idea general de un informe largo, poner al tanto a un agente sobre las llamadas anteriores de un cliente o crear una vista previa breve de cada artículo. Complementa la extracción de frases clave, que devuelve frases sueltas en lugar de oraciones legibles.

La clasificación de texto personalizada (custom text classification) te permite entrenar un modelo para asignar tus propias etiquetas al texto. Defines las clases, como 'queja', 'reembolso', 'cambio de pedido' y 'comentarios', subes documentos de ejemplo a una cuenta de almacenamiento, los etiquetas en Language Studio, entrenas el modelo, revisas sus métricas de evaluación (precision, recall y F1 por clase) y lo implementas. La clasificación de una sola etiqueta (single-label) asigna una clase por documento; la clasificación multietiqueta (multi-label) puede asignar varias, como la sinopsis de una película etiquetada como 'comedia' y 'romance'.

De forma similar, el reconocimiento de entidades con nombre personalizado (custom named entity recognition) te permite entrenar el servicio para extraer tus propios tipos de entidades, como tipos de cláusulas contractuales o números de pieza internos, cuando las categorías de entidades precompiladas no los cubren.

El patrón coincide con el resto de Azure AI: usa primero las funciones precompiladas cuando encajen, y entrena un modelo personalizado solo cuando tus categorías o entidades sean específicas de tu negocio. Personalizar un modelo de esta forma solo requiere ejemplos etiquetados, no experiencia en ciencia de datos. Para resúmenes abiertos o reescritura en un estilo específico, un modelo de IA generativa es otra opción que estudiarás en el dominio 5.

Términos clave

Extractive summarization (resumen extractivo)
Resumir seleccionando y devolviendo las oraciones más importantes del texto original.
Abstractive summarization (resumen abstractivo)
Resumir generando oraciones nuevas que captan las ideas principales.
Custom text classification (clasificación de texto personalizada)
Entrenar Azure AI Language para asignar tus propias categorías a los documentos usando ejemplos etiquetados.
Multi-label classification (clasificación multietiqueta)
Clasificación en la que un documento puede recibir más de una etiqueta.
Ejemplo real

Un ayuntamiento recibe miles de correos por semana. Un modelo de clasificación de texto personalizada los ordena en 'recolección de basura', 'estacionamiento', 'impuesto predial' y 'planeación urbana' para los equipos correctos, y el resumen abstractivo le da a cada funcionario un resumen de dos oraciones de los hilos de correo largos.

Consejo para el examen: Versión corta de un texto largo: summarization (el extractivo elige oraciones, el abstractivo escribe nuevas). Tus propias categorías: custom text classification entrenada con ejemplos etiquetados.

Comprueba lo que sabes

¿Cuál es la diferencia entre el resumen extractivo y el abstractivo?

El extractivo devuelve oraciones clave del texto original; el abstractivo genera oraciones nuevas que captan el significado.

¿Qué necesitas para entrenar un modelo de clasificación de texto personalizada?

Documentos de ejemplo etiquetados con tus propias clases, subidos al almacenamiento y etiquetados en Language Studio.
