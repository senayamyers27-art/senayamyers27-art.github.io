Ingeniería de prompts: mensajes de sistema, prompts de usuario, ejemplos few-shot e instrucciones claras

Un prompt es todo lo que le envías a un modelo generativo para obtener una respuesta. La ingeniería de prompts (prompt engineering) es la práctica de diseñar prompts que produzcan salidas precisas, relevantes y con un formato consistente. Es la forma más barata y rápida de mejorar una app de IA generativa, antes de considerar el grounding o el fine-tuning.

Los modelos de chat reciben mensajes con roles. El mensaje de sistema (system message) va primero y define el comportamiento del modelo para toda la conversación: su rol y personalidad, la tarea, las reglas y límites, el tono y el formato de salida. Por ejemplo: 'Eres un asistente de soporte de Contoso Outdoor. Responde solo preguntas sobre productos de Contoso. Si no sabes algo, dilo. Responde con no más de tres viñetas.' El mensaje de usuario (user message) contiene la solicitud real del usuario. Los mensajes del asistente (assistant messages) guardan las respuestas anteriores del modelo, así que el historial de la conversación da contexto a las preguntas de seguimiento.

Las instrucciones claras importan. Sé específico sobre lo que quieres, la audiencia, la longitud y el formato (una tabla, JSON, viñetas). Divide las tareas complejas en pasos. Proporciona el contexto relevante en lugar de suponer que el modelo lo conoce. Di qué hacer en lugar de solo qué no hacer. Usa delimitadores, como comillas triples o encabezados, para separar las instrucciones del contenido con el que debe trabajar el modelo.

El prompting few-shot incluye en el prompt un número pequeño de ejemplos de entrada y salida deseada, para que el modelo copie el patrón: por ejemplo, tres reseñas de productos, cada una seguida de la categoría que quieres. El prompting zero-shot da solo la instrucción sin ejemplos. El one-shot da un solo ejemplo. Los ejemplos son especialmente eficaces para imponer un formato o un estilo.

Otras técnicas incluyen pedir al modelo que resuelva un problema paso a paso antes de responder (prompting de tipo chain-of-thought, cadena de pensamiento), pedirle que cite qué fuente proporcionada respalda cada afirmación y especificar una respuesta alternativa cuando falta información. Los prompts también son una capa de seguridad: un mensaje de sistema bien escrito puede reducir las respuestas fuera de tema, sin fundamento o dañinas, aunque no reemplaza a los filtros de contenido.

La ingeniería de prompts es iterativa: prueba un prompt, revisa los resultados, ajusta y vuelve a probar, idealmente con un conjunto de entradas de prueba representativas. En Microsoft Foundry, el chat playground te permite editar el mensaje de sistema, agregar ejemplos y comparar resultados sin escribir código.

Términos clave

System message (mensaje de sistema)
Instrucciones enviadas antes de la conversación que definen el rol, las reglas, el tono y el formato de salida del modelo.
User prompt (prompt de usuario)
La solicitud o pregunta del usuario enviada al modelo.
Few-shot prompting
Incluir en el prompt algunos ejemplos de entrada y salida deseada para que el modelo siga el patrón.
Zero-shot prompting
Darle al modelo solo una instrucción, sin ejemplos.
Ejemplo real

El prompt de clasificación de un minorista devolvía etiquetas inconsistentes. El equipo agregó un mensaje de sistema que listaba las cinco categorías permitidas, pidió la salida como una sola palabra e incluyó tres ejemplos etiquetados (few-shot). La consistencia mejoró de inmediato, sin volver a entrenar.

Consejo para el examen: El rol, las reglas y el formato que aplican a toda la conversación van en el mensaje de sistema. Los ejemplos en el prompt son few-shot. Cambiar los pesos del modelo es fine-tuning, no ingeniería de prompts.

Comprueba lo que sabes

¿Dónde deberías poner 'Responde siempre en inglés formal y nunca des asesoría legal'?

En el mensaje de sistema, porque define reglas para toda la conversación.

¿Qué es el prompting few-shot?

Incluir en el prompt algunos ejemplos de entrada y salida deseada para que el modelo siga el mismo patrón.
