Microsoft Certified: Azure AI Fundamentals AI-900

Microsoft Foundry (antes Azure AI Foundry): hubs y proyectos, el catálogo de modelos y los playgrounds

Microsoft Foundry es la plataforma y el portal de Microsoft para construir apps y agentes de IA generativa en Azure. Antes se llamaba Azure AI Studio y luego Azure AI Foundry, y todavía puedes ver esos nombres en material de capacitación y preguntas de examen más antiguos. Los nombres de productos en esta área cambian seguido; lo que importa son los conceptos de abajo.

El trabajo en Foundry se organiza en proyectos (projects). Un proyecto es un espacio de trabajo para una solución: contiene tus implementaciones de modelos, agentes, conexiones de datos, evaluaciones y archivos, y permite que un equipo colabore con acceso compartido. Los proyectos se apoyan en recursos de Azure que proporcionan los modelos, el almacenamiento, la seguridad y la facturación. En el diseño actual, un recurso de Foundry contiene los proyectos directamente. Un diseño anterior usaba un recurso hub que guardaba configuraciones y conexiones compartidas (como a Azure AI Search o al almacenamiento) para varios proyectos; los proyectos basados en hubs todavía existen, así que reconoce ambos términos.

El catálogo de modelos (model catalog) es donde descubres y comparas modelos. Incluye modelos de Azure OpenAI, otros modelos de Microsoft (como la familia pequeña Phi) y modelos de proveedores como Meta, Mistral y otros, además de modelos de código abierto. Cada modelo tiene una ficha del modelo (model card) que describe sus capacidades, usos previstos, limitaciones y opciones de implementación. Los benchmarks y las tablas de clasificación (leaderboards) ayudan a comparar calidad, costo y velocidad. Desde el catálogo implementas un modelo en tu proyecto, lo que le da un endpoint al que tu app puede llamar. Algunos modelos se cobran por token como servicio administrado; otros se ejecutan en cómputo que tú aprovisionas.

Los playgrounds te permiten probar cosas sin código. El chat playground te permite elegir un modelo de chat implementado, escribir un mensaje de sistema, agregar ejemplos, ajustar parámetros como temperature y max tokens, agregar tus propios datos para grounding y ver los resultados de inmediato. También hay playgrounds para agentes, imágenes y algunos servicios de Azure AI como voz y lenguaje. Cuando un prompt funciona bien, puedes ver código de ejemplo para usarlo en una aplicación.

Foundry también ofrece herramientas para el resto del ciclo de vida: conectar datos y Azure AI Search para RAG, construir agentes, ejecutar evaluaciones, configurar filtros de contenido y barreras de protección (guardrails) y monitorear las apps implementadas. Los servicios de Azure AI como Vision, Language, Speech y Content Safety se pueden usar desde el mismo portal.

Para AI-900, recuerda para qué sirve cada parte: los proyectos organizan el trabajo, el catálogo de modelos te ayuda a elegir e implementar modelos, y los playgrounds te permiten experimentar antes de escribir código.

Términos clave

Microsoft Foundry
La plataforma y el portal de Microsoft para construir apps y agentes de IA generativa, antes Azure AI Studio y Azure AI Foundry.
Project (proyecto)
Un espacio de trabajo de Foundry que contiene las implementaciones de modelos, los agentes, las conexiones de datos y las evaluaciones de una solución.
Model catalog (catálogo de modelos)
La biblioteca de Foundry para descubrir, comparar e implementar modelos de Microsoft, OpenAI y otros proveedores.
Model card (ficha del modelo)
Documentación que describe las capacidades, los usos previstos, las limitaciones y las opciones de implementación de un modelo.
Ejemplo real

Una desarrolladora crea un proyecto de Foundry para un asistente interno de políticas, compara dos modelos de chat en el catálogo de modelos usando sus model cards y benchmarks, implementa el más barato e itera sobre el mensaje de sistema en el chat playground antes de copiar el código de ejemplo a su app.

Consejo para el examen: Comparar y elegir modelos: model catalog. Probar prompts y parámetros sin código: playground. Organizar los recursos de una solución y el acceso del equipo: project. Espera ver tanto el nombre Azure AI Foundry como Microsoft Foundry.

Comprueba lo que sabes

¿Qué te dice una model card?

Las capacidades, los usos previstos, las limitaciones y las opciones de implementación de un modelo.

¿Dónde puedes probar un mensaje de sistema y la temperatura con un modelo implementado sin código?

En el chat playground del portal de Foundry.
