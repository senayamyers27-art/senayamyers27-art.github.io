Elegir el servicio de visión de Azure adecuado para un escenario

Muchas preguntas de visión en AI-900 describen una necesidad de negocio y preguntan qué servicio o función usar. La forma más rápida de responder es identificar la entrada y la salida que busca el escenario, y luego asociarlas con el servicio. Esta lección integra el dominio como una guía de decisión.

Si la entrada es una foto o un cuadro de video y la salida es una descripción de lo que contiene, usa el análisis de imágenes de Azure AI Vision. Elige la función específica según la salida: una oración (captions), oraciones para regiones (dense captions), palabras clave (tags), objetos con ubicación (object detection), personas con ubicación (people detection) o una región para miniatura (smart crops).

Si la salida es el texto de la imagen, usa OCR con la función Read de Azure AI Vision. Si la entrada es un documento como una factura, un recibo, una identificación o un formulario y la salida son datos estructurados (campos con nombre, tablas, pares clave-valor, casillas de verificación), usa Azure AI Document Intelligence: un modelo precompilado para documentos comunes, el modelo layout para la estructura de cualquier documento y un modelo personalizado para tus propios formularios.

Si el escenario trata de rostros, usa Azure AI Face. La detección y los atributos de la imagen como desenfoque, lentes o posición de la cabeza están disponibles. La verificación y la identificación requieren aprobación de Limited Access. No se ofrece inferir emoción, género ni edad. Si el escenario solo necesita contar personas, la detección de personas de Azure AI Vision evita por completo el análisis facial.

Si el escenario necesita categorías que los modelos precompilados no conocen, como los productos, piezas o defectos propios de tu empresa, necesitas un modelo de visión personalizado entrenado con tus propias imágenes etiquetadas, por ejemplo con las tareas de imagen de AutoML de Azure Machine Learning. Si el escenario quiere hacer preguntas libres sobre una imagen o combinar la comprensión de imágenes con razonamiento, lo adecuado es un modelo generativo multimodal (como un modelo GPT que acepta imágenes, implementado a través de Microsoft Foundry).

Por último, revisa las pistas no funcionales: experimentar gratis sugiere un recurso de un solo servicio F0; una sola clave para varios servicios sugiere un recurso multiservicio; los escenarios sensibles con rostros traen consigo Limited Access e IA responsable.

Términos clave

Azure AI Vision
El servicio de Azure AI para análisis de imágenes y OCR con modelos precompilados.
Azure AI Face
El servicio de Azure AI para detectar y analizar rostros, con el reconocimiento bajo Limited Access.
Azure AI Document Intelligence
El servicio de Azure AI que extrae campos, tablas y estructura de documentos.
Custom vision model (modelo de visión personalizado)
Un modelo de imágenes entrenado con tus propias imágenes etiquetadas para reconocer clases que los modelos precompilados no cubren.
Ejemplo real

Una empresa de logística tiene cuatro necesidades: leer los códigos de contenedores en fotos del muelle (OCR de Vision), extraer campos de los conocimientos de embarque (Document Intelligence), contar a los trabajadores en una zona de carga (people detection de Vision) y detectar tipos de daños específicos de sus contenedores (un modelo personalizado entrenado con fotos etiquetadas).

Consejo para el examen: Asocia la salida con el servicio: descripción u objetos con el análisis de imágenes de Vision, texto con Read de Vision, campos y tablas con Document Intelligence, rostros con Face, tus propias clases con un modelo personalizado.

Comprueba lo que sabes

Una empresa quiere el nombre del comercio y el total de recibos fotografiados. ¿Qué servicio?

Azure AI Document Intelligence con el modelo precompilado de recibos.

Un museo necesita una oración que describa cada foto para visitantes con discapacidad visual. ¿Qué servicio y qué función?

El análisis de imágenes de Azure AI Vision con captions.
