Microsoft Certified: Azure AI Fundamentals AI-900

Modelos de Azure OpenAI en Foundry: modelos de chat GPT, modelos de embeddings y modelos de generación de imágenes

Azure OpenAI da a las organizaciones acceso a los modelos de OpenAI, alojados en Azure. Está disponible a través de Microsoft Foundry, donde los modelos de Azure OpenAI aparecen en el catálogo de modelos junto con modelos de otros proveedores. Lo que agrega Azure es el alojamiento empresarial: identidad y control de acceso de Azure, opciones de red privada, opciones de implementación por región, filtrado de contenido integrado y los compromisos de protección de datos de Microsoft.

Los modelos se agrupan en unas cuantas familias, y AI-900 espera que asocies cada familia con un trabajo. Los modelos de chat GPT (chat completion), como la serie GPT-4o y los modelos GPT posteriores, reciben una conversación de mensajes y generan una respuesta. Impulsan asistentes de chat, copilotos, resúmenes, redacción, clasificación mediante prompts y generación de código. Algunos aceptan imágenes como entrada además de texto (multimodales). Los modelos de razonamiento (reasoning models) dedican más cómputo a resolver problemas complejos antes de responder, lo que ayuda con tareas de varios pasos como matemáticas y planificación.

Los modelos de embeddings convierten texto en vectores que representan el significado. No generan texto legible. Se usan para búsqueda semántica, recomendaciones, clustering y, sobre todo, el paso de recuperación de RAG, donde los fragmentos de documentos y las preguntas de los usuarios se convierten en embeddings para encontrar los fragmentos más relevantes.

Los modelos de generación de imágenes crean imágenes a partir de descripciones de texto (DALL-E y los modelos de imagen GPT más recientes son ejemplos). Úsalos para material visual de marketing, arte conceptual e ideas de diseño; los filtros de contenido también se aplican a los prompts y las salidas de imágenes. Los modelos con capacidad de audio manejan entrada y salida de voz para experiencias de voz, y Azure AI Speech sigue siendo el servicio para el speech to text y el text to speech clásicos.

Para usar un modelo, lo implementas en tu recurso o proyecto de Foundry, eligiendo un tipo de implementación y una capacidad; luego tu app llama al endpoint de la implementación usando el nombre de la implementación. El uso se cobra, normalmente por token de entrada y de salida en los modelos de lenguaje; no hay nivel gratuito para Azure OpenAI, así que elimina las implementaciones que no uses. Microsoft indica que los prompts y las respuestas no se usan para entrenar los modelos fundacionales de OpenAI ni de Microsoft.

El enfoque del examen es la adecuación: chat y generación de texto, elige un modelo de chat GPT; búsqueda por significado, elige un modelo de embeddings; crear imágenes, elige un modelo de generación de imágenes.

Términos clave

Azure OpenAI
Modelos de OpenAI alojados en Azure con la seguridad, la red, el filtrado de contenido y la protección de datos de Azure.
Chat completion model (modelo de chat completion)
Un modelo que recibe una conversación de mensajes y genera la siguiente respuesta, como un modelo GPT.
Embeddings model (modelo de embeddings)
Un modelo que convierte texto en vectores para búsqueda semántica y similitud, no en texto legible.
Deployment (implementación)
Una instancia de un modelo en tu recurso, con un nombre y un endpoint a los que llama tu app.
Ejemplo real

Una editorial construye un asistente de investigación. Un modelo de embeddings vectoriza 20 años de artículos para la búsqueda semántica, un modelo de chat GPT responde las preguntas de los lectores usando los artículos recuperados y un modelo de generación de imágenes crea ilustraciones para los boletines.

Consejo para el examen: Vectores para búsqueda y RAG: modelo de embeddings. Conversación y generación de texto: modelo de chat GPT. Imágenes a partir de texto: modelo de generación de imágenes. Azure OpenAI se cobra y no tiene nivel gratuito.

Comprueba lo que sabes

¿Qué tipo de modelo se usa para indexar documentos para la búsqueda semántica en una solución RAG?

Un modelo de embeddings, que convierte el texto en vectores.

¿Qué usa una app para llamar a un modelo específico en Azure OpenAI?

El endpoint y el nombre de la implementación del modelo, con una clave o autenticación de Microsoft Entra ID.
