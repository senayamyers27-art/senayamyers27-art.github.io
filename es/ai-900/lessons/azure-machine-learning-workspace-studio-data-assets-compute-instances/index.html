Azure Machine Learning: workspace, studio, data assets, compute instances y compute clusters

Azure Machine Learning es la plataforma en la nube de Microsoft para que científicos de datos e ingenieros de ML entrenen, implementen y administren sus propios modelos de machine learning. Mientras que Azure AI services te dan modelos preentrenados a través de una API, Azure Machine Learning es para cuando necesitas un modelo entrenado con tus propios datos para tu propia tarea de predicción.

Todo empieza con un workspace (área de trabajo), el recurso de Azure de nivel superior que contiene todos tus recursos de machine learning: datos, cómputo, experimentos, modelos y endpoints. Cuando creas un workspace, Azure también crea o vincula recursos de apoyo, incluida una cuenta de almacenamiento (para datos y archivos), un key vault (para secretos), Application Insights (para monitoreo) y, opcionalmente, un container registry (para imágenes de modelos).

Azure Machine Learning studio es el portal web para trabajar en el workspace. Desde ahí puedes subir y explorar datos, ejecutar notebooks, iniciar trabajos de ML automatizado, construir pipelines en el designer, ver resultados y métricas de los trabajos, registrar modelos e implementar endpoints. Los desarrolladores pueden hacer lo mismo con el SDK de Python o la extensión de machine learning de la CLI de Azure.

Los data assets (recursos de datos) son referencias a los datos que usas para entrenar, como un archivo o carpeta en Azure Blob Storage o una tabla. Registrar datos como asset les da un nombre y una versión, para que los experimentos sean reproducibles y los compañeros de equipo reutilicen los mismos datos. Los datastores guardan la información de conexión al almacenamiento subyacente.

El cómputo (compute) es donde se ejecuta el trabajo, y es donde está el costo. Una compute instance es una máquina virtual en la nube administrada para un científico de datos, usada para notebooks y desarrollo; deberías detenerla cuando no la estés usando. Un compute cluster es un conjunto de VM que escala automáticamente para ejecutar trabajos de entrenamiento y puede reducirse a cero nodos cuando está inactivo, así que solo pagas mientras se ejecutan los trabajos. Los modelos también se pueden implementar en managed online endpoints, y puedes conectar cómputo existente, como un clúster de Kubernetes.

Azure Machine Learning también registra cada trabajo de entrenamiento, sus parámetros, métricas y salidas, y mantiene un registro de modelos (model registry) con versiones. Ese historial apoya la rendición de cuentas y permite reproducir o revertir un modelo más adelante.

Términos clave

Workspace (área de trabajo)
El recurso de nivel superior de Azure Machine Learning que contiene datos, cómputo, trabajos, modelos y endpoints.
Azure Machine Learning studio
El portal web para trabajar con un workspace de Azure Machine Learning.
Compute instance (instancia de cómputo)
Una VM de desarrollo administrada para los notebooks y experimentos de un solo usuario.
Compute cluster (clúster de cómputo)
Un grupo de VM que escala automáticamente para trabajos de entrenamiento y puede reducirse a cero cuando está inactivo.
Ejemplo real

Un equipo de analítica minorista crea un workspace por proyecto. Cada analista tiene una compute instance pequeña que se detiene automáticamente por la tarde, los trabajos de entrenamiento se ejecutan en un compute cluster que escala de cero a ocho nodos, y el historial de ventas está registrado como un data asset versionado para que cada experimento use los mismos datos.

Consejo para el examen: La compute instance es para desarrollo de una sola persona; el compute cluster es para trabajos de entrenamiento escalables. Azure Machine Learning es para entrenar tus propios modelos; Azure AI services te dan modelos ya hechos.

Comprueba lo que sabes

¿Qué tipo de cómputo de Azure Machine Learning puede reducirse a cero nodos para ahorrar costos entre trabajos de entrenamiento?

Un compute cluster.

¿Cuándo elegirías Azure Machine Learning en lugar de un servicio de Azure AI?

Cuando necesitas entrenar un modelo personalizado con tus propios datos para una tarea de predicción que los servicios precompilados no cubren, como predecir tus propias ventas.
