Agentes de IA: modelos con instrucciones, herramientas y conocimiento, y Foundry Agent Service

Un agente de IA (AI agent) es una aplicación de IA generativa que puede razonar sobre un objetivo y actuar para lograrlo, no solo responder con texto. Los agentes son una de las partes de la IA generativa que más rápido crecen y un tema explícito del dominio de IA generativa de AI-900.

Un agente combina tres cosas con un modelo. Las instrucciones (similares a un mensaje de sistema) definen su propósito, comportamiento y límites: 'Eres un agente de soporte de TI. Ayuda a los empleados a restablecer contraseñas y consultar el estado de sus tickets. Nunca modifiques cuentas de administrador.' El conocimiento le da información para fundamentar sus respuestas, como archivos, un índice de búsqueda o búsqueda web. Las herramientas (tools) le permiten hacer cosas: buscar, ejecutar código para analizar datos, llamar a una API, consultar una base de datos o activar un flujo de trabajo. El modelo decide cuándo usar cada herramienta, la llama, lee el resultado y continúa hasta que termina la tarea o necesita preguntarle algo al usuario.

Ese ciclo de razonar, actuar y observar es lo que separa a un agente de un asistente de chat básico. Un asistente de chat responde 'Tu sistema de tickets indica cómo restablecer contraseñas así...'. Un agente busca al usuario, llama a la API de restablecimiento de contraseñas, confirma que funcionó y lo registra en el ticket. Los agentes también pueden trabajar juntos en soluciones multiagente, donde agentes especializados se encargan de partes de una tarea más grande y se coordinan.

Foundry Agent Service (antes llamado Azure AI Agent Service) es la capacidad de Microsoft Foundry para construir, implementar y administrar agentes. Eliges un modelo, escribes las instrucciones y adjuntas conocimiento y herramientas, como búsqueda de archivos (file search), Azure AI Search, un intérprete de código (code interpreter), Bing grounding o tus propias funciones y API, y luego pruebas el agente en el playground de agentes. El servicio administra los hilos de conversación, ejecuta las llamadas a herramientas y se encarga de la infraestructura para que los desarrolladores se concentren en el comportamiento del agente. Microsoft también ofrece opciones para crear agentes en productos como Copilot Studio.

Los agentes elevan lo que está en juego para la IA responsable porque pueden realizar acciones reales. Las buenas prácticas incluyen dar a cada agente solo las herramientas y los permisos que necesita (mínimo privilegio, least privilege), exigir aprobación humana para acciones importantes como pagos o eliminaciones, registrar cada acción para la rendición de cuentas, aplicar filtros de contenido y protegerse contra la inyección de prompts (prompt injection), en la que texto malicioso dentro de un documento o página web intenta redirigir al agente.

Para el examen, busca escenarios en los que la IA debe completar una tarea usando sistemas o datos, no solo conversar: esos describen agentes.

Términos clave

AI agent (agente de IA)
Una aplicación de IA generativa que usa un modelo con instrucciones, conocimiento y herramientas para razonar y realizar acciones hacia un objetivo.
Tool (herramienta)
Una capacidad que un agente puede llamar, como búsqueda, ejecución de código o una API.
Foundry Agent Service
La capacidad de Microsoft Foundry para construir, implementar y administrar agentes.
Prompt injection (inyección de prompts)
Instrucciones maliciosas ocultas en el contenido de entrada que intentan que un modelo o agente actúe en contra de sus instrucciones.
Ejemplo real

El agente de reservas de una empresa de viajes lee la solicitud de un cliente, busca disponibilidad de vuelos mediante una herramienta de API, revisa el archivo de la política de viajes de la empresa para conocer las reglas de tarifas, aparta la mejor opción y le pide al empleado que confirme antes de reservar y enviar el itinerario por correo.

Consejo para el examen: Solo responde preguntas: asistente de chat o copiloto. Usa herramientas para realizar acciones o completar tareas de varios pasos: agente. Los agentes necesitan herramientas con mínimo privilegio y aprobación humana para acciones de alto impacto.

Comprueba lo que sabes

¿Qué tres cosas combina un agente con un modelo?

Instrucciones, conocimiento y herramientas.

¿Por qué un agente que puede emitir reembolsos debería requerir aprobación humana por encima de cierto monto?

Los agentes pueden realizar acciones reales; la supervisión humana limita el daño de errores o manipulaciones, lo que apoya la confiabilidad y la rendición de cuentas.
