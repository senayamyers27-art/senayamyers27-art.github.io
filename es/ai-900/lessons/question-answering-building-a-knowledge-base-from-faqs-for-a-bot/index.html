Question answering: construir una base de conocimiento a partir de preguntas frecuentes para un bot

Muchas organizaciones ya tienen las respuestas que necesitan sus clientes, repartidas en páginas de preguntas frecuentes (FAQ), manuales de productos y artículos de ayuda. Question answering (respuesta a preguntas), una función de Azure AI Language, convierte ese contenido en una base de conocimiento que un bot o una app pueden consultar en lenguaje natural. Reemplazó al antiguo servicio QnA Maker.

Un proyecto de question answering contiene pares de pregunta y respuesta. Puedes importarlos de fuentes existentes, como páginas web de FAQ, documentos (PDF, Word y archivos similares) o archivos estructurados, y el servicio extrae automáticamente los pares de pregunta y respuesta. También puedes agregar pares a mano, y agregar formas alternativas de hacer la misma pregunta para que la base de conocimiento reconozca las distintas maneras en que pregunta la gente.

Cuando un usuario hace una pregunta, el servicio usa comprensión del lenguaje natural para encontrar la pregunta de la base de conocimiento que mejor coincide, incluso si la redacción es distinta, y devuelve la respuesta asociada con una puntuación de confianza. Si ninguna respuesta tiene suficiente confianza, la app puede devolver una respuesta predeterminada, como ofrecer un agente humano.

Varias funciones hacen que la experiencia sea conversacional. Chit-chat agrega respuestas precompiladas para la conversación casual, como 'hola' o '¿quién eres?', con una personalidad elegida, por ejemplo profesional o amigable. Las conversaciones de varios turnos (multi-turn) usan indicaciones de seguimiento para guiar a los usuarios a través de un tema, como preguntar qué producto tienen antes de dar los pasos para resolver un problema. El aprendizaje activo (active learning) sugiere preguntas alternativas basadas en consultas reales de los usuarios para que puedas mejorar la base de conocimiento con el tiempo.

Construyes y pruebas el proyecto en Language Studio, y luego lo implementas. Los bots se crean comúnmente con Azure AI Bot Service, que conecta la base de conocimiento con canales como una ventana de chat en un sitio web, Microsoft Teams u otras plataformas de mensajería.

La distinción clave con la comprensión del lenguaje conversacional: question answering devuelve una respuesta a partir de contenido almacenado; CLU identifica una intención y entidades para que tu código realice una acción. Un bot de soporte podría usar ambos, y la IA generativa con generación aumentada por recuperación (RAG) es un enfoque más reciente para el mismo problema, que se cubre en el dominio 5.

Términos clave

Question answering (respuesta a preguntas)
Una función de Azure AI Language que responde preguntas en lenguaje natural a partir de una base de conocimiento de pares de pregunta y respuesta.
Knowledge base (base de conocimiento)
La colección de pares de pregunta y respuesta, a menudo importada de FAQ y documentos, en la que busca question answering.
Chit-chat (conversación casual)
Respuestas precompiladas para la conversación casual que dan a un bot una personalidad consistente.
Multi-turn conversation (conversación de varios turnos)
Indicaciones de seguimiento que guían a un usuario por varios pasos dentro de un tema.
Ejemplo real

Una universidad importa su página de preguntas frecuentes de admisiones y el manual del estudiante a un proyecto de question answering, agrega chit-chat con una personalidad amigable y publica el bot en su sitio web con Azure AI Bot Service. Los estudiantes que preguntan '¿cuándo cierran las solicitudes?' o '¿cuál es la fecha límite para postularse?' obtienen la misma respuesta.

Consejo para el examen: Contenido de FAQ existente y 'responder preguntas comunes' apuntan a question answering. 'Entender qué quiere hacer el usuario y extraer detalles' apunta a conversational language understanding.
