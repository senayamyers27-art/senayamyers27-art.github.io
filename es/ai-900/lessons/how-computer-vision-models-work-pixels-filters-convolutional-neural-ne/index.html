Microsoft Certified: Azure AI Fundamentals AI-900

Cómo funcionan los modelos de visión artificial: píxeles, filtros, redes neuronales convolucionales y modelos multimodales

Para una computadora, una imagen digital es un arreglo de números. Una imagen en escala de grises es una cuadrícula de valores de píxeles, normalmente de 0 (negro) a 255 (blanco). Una imagen a color tiene tres de esas cuadrículas, una para cada canal: rojo, verde y azul. Toda técnica de visión artificial parte de estos números.

Una idea clásica del procesamiento de imágenes es el filtro (filter, también llamado kernel): una pequeña cuadrícula de pesos, como de 3 por 3, que se desliza sobre la imagen. En cada posición, los pesos del filtro se multiplican por los valores de los píxeles que tiene debajo y se suman para producir un nuevo valor. Esta operación se llama convolución. Según los pesos, un filtro puede desenfocar la imagen, hacerla más nítida o resaltar bordes. La salida de aplicar un filtro se llama mapa de características (feature map).

Una red neuronal convolucional (convolutional neural network, CNN) es un modelo de deep learning que aprende sus propios filtros. En lugar de que una persona elija los pesos para detectar bordes, el entrenamiento ajusta los valores de los filtros para que capten lo que sea que ayude a la red a clasificar correctamente las imágenes. Las primeras capas suelen aprender características simples como bordes y esquinas; las capas más profundas las combinan en texturas, formas y finalmente partes completas de objetos, como ruedas u ojos. Las capas de pooling reducen los mapas de características para conservar la información más importante, y las capas finales totalmente conectadas convierten las características en probabilidades de clase.

Entrenar una CNN requiere muchas imágenes etiquetadas. La red predice una etiqueta para cada imagen de entrenamiento, la función de pérdida mide el error y los pesos de los filtros y demás pesos se ajustan a lo largo de muchas epochs. Las redes preentrenadas con millones de imágenes se pueden adaptar a clases nuevas con muchas menos imágenes, una técnica llamada aprendizaje por transferencia (transfer learning).

Los modelos de visión más recientes también usan la arquitectura transformer. Los modelos multimodales se entrenan con enormes cantidades de imágenes emparejadas con descripciones en texto, así que aprenden una representación compartida de imágenes y lenguaje. Eso permite que un solo modelo describa imágenes con oraciones, encuentre imágenes que coincidan con una consulta de texto o responda preguntas sobre una imagen. Las descripciones (captioning) de Azure AI Vision y la capacidad de entrada de imágenes de modelos generativos como GPT-4o se basan en este tipo de aprendizaje multimodal.

Para AI-900, recuerda la cadena: los píxeles son números, los filtros extraen características, las CNN aprenden filtros para clasificar imágenes y los modelos multimodales conectan imágenes con lenguaje.

Términos clave

Pixel (píxel)
El elemento más pequeño de una imagen digital, almacenado como uno o más valores numéricos.
Filter (kernel) (filtro)
Una pequeña cuadrícula de pesos que se aplica sobre una imagen para producir un feature map, por ejemplo para resaltar bordes.
Convolutional neural network (CNN, red neuronal convolucional)
Un modelo de deep learning que aprende filtros para extraer características de imágenes en tareas como la clasificación.
Multimodal model (modelo multimodal)
Un modelo entrenado con más de un tipo de datos, como imágenes y texto juntos.
Ejemplo real

Un fabricante adapta una CNN preentrenada para detectar grietas en azulejos de cerámica usando solo unos cientos de fotos etiquetadas (transfer learning). Más adelante prueba un modelo multimodal que puede responder preguntas en texto libre como '¿Hay un desportillado en el borde izquierdo?' sobre cualquier foto.

Consejo para el examen: Las CNN aprenden sus filtros durante el entrenamiento en lugar de usar filtros elegidos a mano. Un modelo que puede responder preguntas sobre imágenes o relacionar imágenes con texto es multimodal.
