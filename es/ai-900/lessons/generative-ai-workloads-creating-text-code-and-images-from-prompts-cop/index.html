Cargas de trabajo de IA generativa: crear texto, código e imágenes a partir de prompts, copilotos y agentes

La IA generativa es IA que crea contenido nuevo. Le das un prompt, una instrucción o pregunta en lenguaje natural, y devuelve texto, código, una imagen u otra salida que no existía antes. Es el área de la IA que más rápido crece y la que tiene mayor peso en AI-900 (dominio 5), así que esta lección presenta el vocabulario.

La mayoría de las apps de IA generativa se construyen sobre modelos de lenguaje grandes (large language models, LLM), que se entrenan con enormes cantidades de texto y generan respuestas un token a la vez. Con el prompt adecuado, el mismo modelo puede redactar un correo, resumir un informe, responder una pregunta, traducir, clasificar texto o escribir y explicar código. Los modelos de generación de imágenes crean imágenes a partir de una descripción en texto. Los modelos multimodales pueden recibir imágenes como entrada además de texto.

Un copiloto (copilot) es un asistente de IA generativa integrado en una aplicación para ayudar a las personas con su trabajo: redactar documentos en un procesador de texto, resumir una reunión, escribir una fórmula en una hoja de cálculo o sugerir código en un editor. El nombre indica la relación que se busca: el usuario sigue siendo el piloto, que revisa y decide, mientras la IA asiste.

Un agente (agent) va un paso más allá. Combina un modelo con instrucciones, conocimiento y herramientas, como la capacidad de buscar en una base de conocimiento, ejecutar código o llamar a una API de negocio, para poder trabajar hacia un objetivo y realizar acciones, a veces en varios pasos. Un bot de viajes que revisa la disponibilidad de vuelos, reserva un asiento y envía la confirmación por correo es un agente; un bot que solo escribe una descripción de un vuelo no lo es.

La IA generativa trae riesgos específicos. Los modelos pueden producir afirmaciones fluidas pero falsas (a menudo llamadas alucinaciones), reflejar sesgos de sus datos de entrenamiento, generar contenido dañino o ser manipulados con prompts diseñados para ello. Las organizaciones reducen estos riesgos fundamentando (grounding) el modelo en datos confiables, usando filtros de contenido, escribiendo mensajes de sistema claros, manteniendo a personas en el proceso (human in the loop) y probando a fondo. Estudiarás estas mitigaciones en detalle más adelante.

En el examen, la IA generativa es la respuesta cuando el escenario pide crear, redactar, escribir, reescribir, resumir en lenguaje natural o conversar libremente. Si pide extraer, clasificar con etiquetas fijas o detectar, un servicio de IA tradicional puede ser la opción más precisa.

Términos clave

Prompt
La instrucción, pregunta o contexto que se le da a un modelo de IA generativa para producir una respuesta.
Large language model (LLM, modelo de lenguaje grande)
Una red neuronal muy grande entrenada con texto que genera lenguaje prediciendo tokens.
Copilot (copiloto)
Un asistente de IA generativa integrado en una app que ayuda al usuario con tareas mientras el usuario mantiene el control.
Agent (agente)
Una solución de IA generativa que combina un modelo con instrucciones, conocimiento y herramientas para poder realizar acciones hacia un objetivo.
Ejemplo real

Una empresa de software da a sus ingenieros de soporte un copiloto dentro del sistema de tickets. Resume historiales largos de tickets, redacta respuestas basadas en la base de conocimiento y, como agente con las herramientas adecuadas, puede consultar el estado de la licencia de un cliente y reiniciar un periodo de prueba después de que el ingeniero lo aprueba.

Consejo para el examen: Copilot: asiste a un usuario dentro de una app. Agent: además puede usar herramientas y realizar acciones. Ambos son IA generativa. Fíjate en las palabras 'crear' o 'redactar' como señal de una carga de trabajo de IA generativa.

Comprueba lo que sabes

¿Qué hace diferente a un agente de un asistente de chat básico?

Un agente puede usar herramientas y conocimiento para realizar acciones hacia un objetivo, no solo responder con texto.

Menciona dos riesgos específicos de la salida de la IA generativa.

Afirmaciones inventadas pero plausibles (alucinaciones) y contenido dañino o sesgado; la manipulación mediante prompts diseñados para ello es otro.
