Microsoft Certified: Azure AI Fundamentals AI-900

Implementar modelos en endpoints para inferencia en tiempo real o por lotes, y herramientas de IA responsable en Azure Machine Learning

Un modelo solo genera valor cuando las aplicaciones pueden usarlo. En Azure Machine Learning, implementas un modelo entrenado en un endpoint, una dirección web que acepta datos de entrada y devuelve predicciones. AI-900 espera que conozcas los dos tipos principales de endpoint y las herramientas de IA responsable que te ayudan a revisar un modelo antes y después de implementarlo.

Primero registras el modelo en el model registry del workspace, dándole un nombre y una versión. Los modelos entrenados con AutoML o con el designer se pueden registrar e implementar directamente desde studio. Una implementación (deployment) empaqueta el modelo con el código y el entorno necesarios para ejecutarlo, en un cómputo que Azure administra por ti.

Un endpoint en tiempo real (llamado online endpoint) entrega predicciones bajo demanda con baja latencia. Una app envía una solicitud, normalmente JSON sobre HTTPS con los valores de las características de uno o unos pocos elementos, y recibe una predicción en cuestión de momentos. Úsalo cuando una persona o un proceso está esperando una respuesta: aprobar una solicitud de préstamo, recomendar un producto en una página web, revisar una transacción en el momento en que ocurre. Los online endpoints pueden tener varias implementaciones detrás, así que puedes probar una nueva versión del modelo con una parte del tráfico.

Un batch endpoint (endpoint por lotes) puntúa grandes cantidades de datos de forma asíncrona. Lo diriges a una carpeta o conjunto de datos, ejecuta un trabajo en un compute cluster y escribe las predicciones en el almacenamiento. Úsalo cuando nadie está esperando, como puntuar a todos los clientes durante la noche según su riesgo de cancelación. La puntuación por lotes suele ser más barata para grandes volúmenes porque el cómputo solo se ejecuta durante el trabajo.

Los clientes se autentican en los endpoints con una clave o un token de Microsoft Entra ID, y deberías monitorear los modelos implementados para detectar errores, latencia y deriva en los datos que reciben.

El Responsible AI dashboard de Azure Machine Learning reúne varias herramientas para un modelo entrenado: análisis de errores (error analysis, en qué grupos de datos se equivoca más el modelo), evaluación de equidad (fairness assessment, cómo difiere el rendimiento entre grupos sensibles), interpretabilidad del modelo (model interpretability, qué características impulsan las predicciones, en general y para casos individuales), análisis contrafactual what-if (qué tendría que cambiar para obtener un resultado distinto) y análisis de datos. Un scorecard puede resumir los hallazgos para partes interesadas que no son científicos de datos. Estas herramientas ponen en práctica los principios de equidad, confiabilidad y transparencia.

Términos clave

Endpoint
Una dirección web donde un modelo implementado acepta datos de entrada y devuelve predicciones.
Online (real-time) endpoint (endpoint en línea o en tiempo real)
Un endpoint que devuelve predicciones de inmediato para solicitudes individuales.
Batch endpoint (endpoint por lotes)
Un endpoint que puntúa grandes volúmenes de datos de forma asíncrona como un trabajo y escribe los resultados en el almacenamiento.
Responsible AI dashboard (panel de IA responsable)
Una herramienta de Azure Machine Learning que combina análisis de errores, equidad, interpretabilidad y análisis what-if para un modelo.
Ejemplo real

Un proveedor de energía implementa su modelo de cancelación dos veces. La app del centro de llamadas usa un online endpoint para mostrar una puntuación de riesgo de cancelación en vivo mientras un agente habla con un cliente. Cada domingo, un batch endpoint puntúa a los 2 millones de clientes para que marketing planifique las ofertas de retención de la semana. Antes del lanzamiento, el Responsible AI dashboard mostró que el modelo era menos preciso con los clientes rurales, así que el equipo agregó más datos rurales.

Consejo para el examen: Alguien esperando una respuesta inmediata significa un endpoint en tiempo real (online). Puntuar un conjunto de datos grande de forma programada significa batch. Las preguntas sobre encontrar dónde un modelo comete más errores o trata distinto a los grupos apuntan al Responsible AI dashboard.

Comprueba lo que sabes

Una tienda en línea necesita recomendaciones de productos mientras el cliente navega. ¿Qué tipo de endpoint encaja?

Un endpoint en tiempo real (online), porque la respuesta se necesita de inmediato para cada solicitud.

Menciona tres herramientas del Responsible AI dashboard.

Análisis de errores, evaluación de equidad e interpretabilidad del modelo; también incluye el análisis contrafactual what-if y el análisis de datos.
