Análisis de imágenes con Azure AI Vision: captions, dense captions, tags, detección de objetos, detección de personas y smart crops

Azure AI Vision es el servicio de Azure AI para analizar imágenes y video. Su función de análisis de imágenes (image analysis) te da capacidades de visión preentrenadas mediante una sola llamada a la API: envías una imagen (como URL o como los bytes de la imagen) e indicas qué características visuales quieres recibir. No se necesita entrenamiento. AI-900 espera que asocies cada función con un escenario.

Captions (descripciones) genera una oración legible que describe toda la imagen, como 'un hombre andando en bicicleta por una calle de la ciudad', con una puntuación de confianza. Dense captions (descripciones densas) genera descripciones para varias regiones de la imagen, cada una con un bounding box, así obtienes una descripción de distintas partes de la escena. Las captions son ideales para el texto alternativo de accesibilidad y para hacer consultables las bibliotecas de fotos.

Tags (etiquetas) devuelve una lista de palabras de cosas, entornos y acciones visibles en la imagen, como 'outdoor', 'tree', 'dog', 'grass' (exterior, árbol, perro, pasto), cada una con una puntuación de confianza. Las etiquetas son útiles para indexar y buscar. Object detection devuelve objetos con sus bounding boxes y etiquetas, por ejemplo tres objetos 'car' con coordenadas. People detection (detección de personas) encuentra específicamente personas y devuelve sus bounding boxes, lo que sirve para escenarios de conteo y ocupación sin identificar a nadie.

Smart crops (recortes inteligentes) sugiere una región de recorte que conserva la parte más importante de la imagen para una relación de aspecto determinada, útil para generar miniaturas. La función Read (OCR) extrae texto y se cubre en su propia lección. Según la versión de la API, también hay funciones como la eliminación de fondo y embeddings multimodales para búsqueda de imágenes; revisa la documentación actual para saber qué admite tu versión.

Para usar el servicio, creas un recurso de Azure AI Vision (o un recurso multiservicio de Azure AI services) y llamas a su endpoint con una clave o con Microsoft Entra ID. Puedes explorar las funciones sin código en la experiencia de prueba de visión del portal de Microsoft Foundry o en Vision Studio, y luego usar la REST API o los SDK desde tu app. Algunas funciones solo están disponibles en ciertas regiones.

Cuando un escenario necesita categorías específicas de tu negocio, como tus propios modelos de productos, es posible que el análisis de imágenes precompilado no las conozca; en ese caso entrenas un modelo personalizado con tus propias imágenes etiquetadas.

Términos clave

Caption (descripción)
Una oración generada que describe una imagen, devuelta con una puntuación de confianza.
Dense captions (descripciones densas)
Descripciones para varias regiones de una imagen, cada una con un bounding box.
Tag (etiqueta)
Una palabra que describe algo visible en una imagen, como un objeto, un entorno o una acción.
Smart crop (recorte inteligente)
Una región de recorte sugerida que conserva el área de interés para una relación de aspecto dada.
Ejemplo real

Un museo sube 40,000 fotos digitalizadas. El análisis de imágenes agrega captions para usuarios de lectores de pantalla, tags como 'ship', 'harbour' y 'black and white' (barco, puerto, blanco y negro) para la búsqueda, smart crops para las miniaturas de la galería y people detection para encontrar fotos que incluyen visitantes.

Consejo para el examen: Oración que describe la imagen: captions. Lista de palabras clave: tags. Dónde están las cosas: object detection o people detection. Región para miniatura: smart crops. Texto en la imagen: OCR (Read).

Comprueba lo que sabes

¿Qué función de análisis de imágenes produce mejor el texto alternativo para un lector de pantalla?

Captions, porque genera una oración legible que describe la imagen.

¿En qué se diferencian las dense captions de las captions?

Las dense captions describen varias regiones de la imagen, cada una con su propio bounding box, en lugar de una sola oración para toda la imagen.
