Deep learning: redes neuronales, pesos y capas, y por qué son adecuadas para imágenes, voz y lenguaje

El aprendizaje profundo (deep learning) es una rama del machine learning que usa redes neuronales artificiales con muchas capas. Está detrás de casi toda la visión artificial moderna, el reconocimiento de voz y los modelos de lenguaje, incluidos los modelos de lenguaje grandes que se usan en la IA generativa.

Una red neuronal (neural network) está inspirada vagamente en el cerebro. Está formada por capas de unidades simples (neuronas artificiales). Cada neurona toma números de la capa anterior, multiplica cada uno por un peso (weight), los suma junto con un valor de sesgo (bias) y pasa el resultado por una función de activación que decide con qué intensidad se activa. La primera capa recibe las características de entrada, como los valores de los píxeles; la última capa produce la salida, como una probabilidad para cada clase. Las capas intermedias son capas ocultas (hidden layers), y una red con muchas de ellas se llama profunda.

El entrenamiento ajusta los pesos. La red hace predicciones sobre los datos de entrenamiento, una función de pérdida (loss function) mide qué tan equivocadas son y un método de optimización (descenso de gradiente, gradient descent, usando una técnica llamada backpropagation) empuja cada peso en la dirección que reduce la pérdida. Esto se repite a lo largo de muchas pasadas por los datos (epochs) hasta que las predicciones son buenas. Las redes grandes tienen millones o miles de millones de pesos, por eso el entrenamiento necesita muchos datos y hardware potente como las GPU.

La gran fortaleza del deep learning es que aprende automáticamente características útiles. Con el machine learning clásico, a menudo una persona tenía que diseñar las características a mano, por ejemplo 'número de palabras en mayúsculas'. Una red profunda alimentada con píxeles en bruto aprende por sí misma que las primeras capas deben detectar bordes, las siguientes formas y las posteriores objetos completos. Eso la hace ideal para datos no estructurados como imágenes, audio y texto, donde es difícil diseñar buenas características a mano.

Distintas arquitecturas se adaptan a distintos datos. Las redes neuronales convolucionales (CNN) están diseñadas para imágenes. Los transformers, que se cubren en la siguiente lección, dominan el lenguaje y se usan cada vez más también para imágenes y audio. Los modelos de deep learning igual pueden hacer regresión y clasificación; simplemente son un tipo de modelo más potente.

Para AI-900 no necesitas las matemáticas. Recuerda que las redes neuronales son capas de conexiones con pesos, que el entrenamiento ajusta los pesos para reducir el error y que el deep learning destaca cuando los datos son complejos y abundantes.

Términos clave

Neural network (red neuronal)
Un modelo formado por capas de neuronas artificiales conectadas cuyos pesos se aprenden durante el entrenamiento.
Weight (peso)
Un número en una conexión entre neuronas que se ajusta durante el entrenamiento para reducir el error.
Deep learning (aprendizaje profundo)
Machine learning con redes neuronales que tienen muchas capas ocultas.
Loss function (función de pérdida)
Un cálculo que mide qué tan lejos están las predicciones de un modelo de las respuestas correctas.
Ejemplo real

Un servicio postal entrena una red neuronal profunda con millones de imágenes de códigos postales escritos a mano. Nadie escribe reglas para bucles y trazos; las primeras capas aprenden bordes, las siguientes aprenden las formas de los dígitos y la capa de salida da una probabilidad para cada dígito.

Consejo para el examen: El deep learning es un subconjunto del machine learning, que a su vez es un subconjunto de la IA. Si un escenario involucra imágenes, audio o lenguaje natural a gran escala, el deep learning es la técnica de fondo.

Comprueba lo que sabes

¿Qué se ajusta cuando se entrena una red neuronal?

Los pesos (y los sesgos) de las conexiones entre neuronas, para reducir la pérdida.

¿Por qué el deep learning es adecuado para imágenes?

Aprende características útiles como bordes y formas directamente de los píxeles en bruto, en lugar de necesitar características diseñadas a mano.
