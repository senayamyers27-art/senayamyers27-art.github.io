Machine learning automatizado (AutoML) y el designer de Azure Machine Learning

Construir un buen modelo normalmente significa probar muchos algoritmos, pasos de preparación de datos y configuraciones, y luego comparar los resultados. Azure Machine Learning ofrece dos formas low-code de hacerlo sin que tengas que escribir código de entrenamiento: el machine learning automatizado y el designer. AI-900 te pide reconocer para qué sirve cada uno.

El machine learning automatizado (AutoML) automatiza la búsqueda del mejor modelo. Eliges un conjunto de datos registrado, seleccionas el tipo de tarea (clasificación, regresión, pronóstico de series temporales y también algunas tareas de visión artificial y NLP), indicas la columna de etiqueta, eliges la métrica principal (primary metric, por ejemplo accuracy o RMSE normalizado) y estableces límites como el tiempo máximo de entrenamiento. Luego AutoML prueba muchas combinaciones de algoritmos y preprocesamiento, entrena cada una en el cómputo y clasifica los modelos resultantes según la métrica.

AutoML también hace la caracterización (featurization) automáticamente: completa valores faltantes, codifica categorías de texto como números y escala valores. Puede aplicar protecciones (guardrails), como detectar el desbalance de clases, y muestra explicaciones de qué características importaron más. Cuando termina el trabajo, revisas la tabla de clasificación (leaderboard), abres las métricas y gráficos del mejor modelo y lo implementas con unos pocos clics.

El designer es un lienzo de arrastrar y soltar para construir pipelines de machine learning de forma visual. Arrastras componentes al lienzo, como un conjunto de datos, un paso de limpieza de datos, una división de los datos en conjuntos de entrenamiento y prueba, un algoritmo de entrenamiento, un paso de puntuación (scoring) y un paso de evaluación, y los conectas. Al enviar el pipeline, cada paso se ejecuta en el cómputo. Tú eliges el algoritmo y los pasos, así que el designer es adecuado para personas que entienden los conceptos de ML pero prefieren no programar.

En resumen, AutoML responde '¿qué algoritmo y configuración funcionan mejor con estos datos?' probándolos por ti. El designer responde 'déjame construir mi propio flujo de trabajo visualmente'. Ambos se ejecutan en Azure Machine Learning studio, usan el cómputo del workspace y producen modelos que puedes registrar e implementar.

Una tercera opción es el código: los científicos de datos pueden escribir Python en notebooks con frameworks como scikit-learn o PyTorch y enviar trabajos a través del SDK. El examen se enfoca en saber que existen las herramientas low-code y cuándo elegirlas.

Términos clave

Automated machine learning (AutoML, machine learning automatizado)
Una función que prueba automáticamente muchos algoritmos y configuraciones y clasifica los modelos resultantes según una métrica elegida.
Primary metric (métrica principal)
La medida que usa AutoML para clasificar los modelos, como accuracy o RMSE normalizado.
Designer
Un lienzo de arrastrar y soltar en Azure Machine Learning studio para construir pipelines de entrenamiento de forma visual.
Featurization (caracterización)
Preparar los datos en bruto para el entrenamiento, como manejar valores faltantes y codificar categorías.
Ejemplo real

Una pequeña aseguradora no tiene científicos de datos. Un analista sube cinco años de datos de reclamos, inicia un trabajo de clasificación con AutoML para predecir si un reclamo será impugnado, establece AUC como métrica principal y un límite de una hora, y luego implementa el mejor modelo del leaderboard.

Consejo para el examen: Probar muchos algoritmos automáticamente y elegir el mejor: AutoML. Construir un pipeline visualmente conectando componentes: designer. Ninguno requiere escribir código.

Comprueba lo que sabes

¿Qué debes especificar al iniciar un trabajo de AutoML?

Los datos, el tipo de tarea (como clasificación o regresión), la columna de etiqueta, la métrica principal y los límites de cómputo y tiempo.

¿En qué se diferencia el designer de AutoML?

En el designer tú eliges y conectas los pasos y el algoritmo en un lienzo; AutoML elige y compara los algoritmos por ti.
