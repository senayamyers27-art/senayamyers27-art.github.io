CompTIA Network+ N10-009

IPv6: tipos de direcciones, dual stack, tunelización, NAT64

IPv6 se creó principalmente porque se agotaron las aproximadamente 4,300 millones de direcciones de IPv4. Una dirección IPv6 tiene 128 bits, escritos como ocho grupos de cuatro dígitos hexadecimales separados por dos puntos, por ejemplo 2001:0db8:0000:0000:0000:ff00:0042:8329. Dos reglas la acortan: eliminar los ceros a la izquierda en cada grupo y reemplazar una serie de grupos de solo ceros por un doble dos puntos, que solo puede usarse una vez. Esa dirección se convierte en 2001:db8::ff00:42:8329. Las subredes casi siempre son /64, con los primeros 64 bits para el prefijo de red y los últimos 64 bits para el ID de interfaz.

Los tipos de direcciones importan en el examen. Las direcciones unicast globales (GUA) son públicas y enrutables, y actualmente se asignan desde 2000::/3, así que empiezan con 2 o 3. Las direcciones locales únicas (ULA), fc00::/7 (en la práctica fd00::/8), son como el espacio privado de RFC 1918. Las direcciones link-local (de enlace local), fe80::/10, se configuran automáticamente en toda interfaz IPv6 y solo son válidas en el enlace local; los routers las usan como siguientes saltos y los vecinos las usan para comunicarse antes de que existan otras direcciones. El loopback es ::1, y :: significa no especificada. Las direcciones multicast empiezan con ff00::/8; por ejemplo, ff02::1 llega a todos los nodos del enlace y ff02::2 a todos los routers. Las direcciones anycast se ven como unicast pero se asignan a varios dispositivos. En IPv6 no existe el broadcast.

Los hosts IPv6 pueden configurarse solos. El protocolo de descubrimiento de vecinos (NDP, Neighbor Discovery Protocol), transportado en ICMPv6, reemplaza a ARP: los hosts envían solicitudes de vecino (neighbor solicitations) para encontrar direcciones MAC y solicitudes de router (router solicitations) para encontrar routers, y los routers responden con anuncios de router (router advertisements) que llevan el prefijo de red. Con SLAAC (stateless address autoconfiguration), el host combina ese prefijo con un ID de interfaz que genera él mismo, ya sea a partir de su dirección MAC con el método EUI-64 o, más comúnmente hoy, de forma aleatoria por privacidad. También puede usarse DHCPv6, con estado para asignar direcciones o sin estado para opciones como los servidores DNS.

Como internet funcionará con ambas versiones durante mucho tiempo, necesitas métodos de transición. Dual stack (doble pila) significa que un dispositivo ejecuta IPv4 e IPv6 al mismo tiempo con direcciones de ambos tipos; es el enfoque preferido y simplemente usa el protocolo que admita el destino. La tunelización (tunneling) transporta paquetes IPv6 dentro de IPv4 a través de redes que todavía no admiten IPv6. Algunos ejemplos son los túneles 6in4 configurados manualmente, 6to4 y Teredo, que tuneliza a través de NAT usando UDP; los métodos automáticos están en gran parte obsoletos hoy, pero todavía pueden aparecer en el examen.

NAT64 permite que los clientes solo IPv6 lleguen a servidores solo IPv4. Un gateway NAT64 traduce entre los protocolos, y DNS64 ayuda sintetizando registros AAAA (IPv6) para los nombres que solo tienen registros A (IPv4), apuntándolos a una dirección dentro de un prefijo especial que el gateway traduce. Esto es común en redes móviles solo IPv6.

En el laboratorio, ejecuta ipconfig o ip -6 addr y verás al menos una dirección link-local fe80:: en cada interfaz, aunque nadie haya configurado IPv6.

Términos clave

Link-local address (dirección de enlace local)
Una dirección IPv6 fe80::/10 configurada automáticamente que solo es válida en el segmento de red local.
SLAAC
Stateless address autoconfiguration: los hosts construyen su propia dirección IPv6 a partir de un prefijo anunciado por el router.
Dual stack (doble pila)
Ejecutar IPv4 e IPv6 de forma simultánea en los mismos dispositivos y la misma red.
NAT64
Un mecanismo de traducción que permite que los hosts solo IPv6 se comuniquen con hosts solo IPv4, normalmente junto con DNS64.
NDP
Neighbor Discovery Protocol: protocolo basado en ICMPv6 que reemplaza a ARP y ofrece el descubrimiento de routers en IPv6.
Ejemplo real

Un operador móvil tiene una red solo IPv6. Cuando un teléfono busca un sitio que solo tiene dirección IPv4, DNS64 devuelve una dirección IPv6 sintetizada, y el gateway NAT64 del operador traduce el tráfico a IPv4 para que el usuario nunca lo note.

Consejo para el examen: fe80 = link-local, fc00/fd00 = local única (privada), 2000::/3 = unicast global, ff = multicast, ::1 = loopback. El doble dos puntos solo puede aparecer una vez en una dirección. IPv6 no tiene broadcast.

Comprueba lo que sabes

¿Qué tipo de dirección IPv6 empieza con fe80?

Link-local, válida solo en el enlace local.

¿Qué método de transición a IPv6 ejecuta ambos protocolos lado a lado?

Dual stack.
