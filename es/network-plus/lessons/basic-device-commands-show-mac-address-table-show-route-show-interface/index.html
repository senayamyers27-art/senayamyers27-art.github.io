CompTIA Network+ N10-009

Comandos básicos de dispositivos: show mac-address-table, show route, show interface, show config, show arp, show vlan, show power

Network+ incluye un conjunto de comandos genéricos de dispositivos basados en las interfaces de línea de comandos comunes de switches y routers. La sintaxis exacta varía entre fabricantes (por ejemplo, show ip route en Cisco IOS o show route en otros, y show mac address-table con o sin guion), pero el examen se enfoca en lo que muestra cada comando y cuándo usarlo. Practícalos en un simulador o laboratorio y aprende a leer la salida.

show mac-address-table (a menudo show mac address-table) enumera las direcciones MAC que ha aprendido un switch, con su VLAN y su puerto. Úsalo para encontrar dónde está conectado un dispositivo, rastrear una IP duplicada hasta un puerto después de encontrar la MAC con arp, o detectar problemas: muchas MAC en un puerto de usuario sugieren un switch no autorizado, y una MAC que se mueve entre puertos sugiere un bucle. show route (o show ip route) muestra la tabla de enrutamiento: las rutas conectadas, estáticas y dinámicas, sus siguientes saltos, las distancias administrativas y las métricas, y la puerta de enlace de último recurso. Úsalo cuando falla el tráfico hacia algunas redes.

show interface (o show interfaces) da el estado y las estadísticas detalladas de cada interfaz: el estado up/down, el line protocol, la velocidad, el dúplex, la MTU, las tasas de entrada y salida, y contadores de errores como CRC, runts, giants, collisions y drops. Es el primer lugar donde buscar problemas físicos y de dúplex. Las versiones breves como show ip interface brief o show interfaces status resumen todos los puertos en una sola pantalla.

show config abarca la visualización de las configuraciones: show running-config muestra la configuración activa en memoria, y show startup-config muestra lo que se cargará después de un reinicio. Compararlas revela los cambios sin guardar. Revisar la configuración te permite confirmar las asignaciones de VLAN, las ACL, la configuración de los trunks, NTP y AAA, y compararla con la configuración dorada.

show arp (o show ip arp) muestra la tabla ARP del dispositivo, que asocia direcciones IP con direcciones MAC en las redes conectadas, normalmente en un router o switch de Capa 3. Junto con la tabla de direcciones MAC, te permite ir de una dirección IP a un puerto físico del switch. show vlan (a menudo show vlan brief) enumera las VLAN configuradas en el switch con sus nombres, su estado y los puertos de acceso asignados. Úsalo cuando un dispositivo cae en la subred equivocada o parece faltar una VLAN; ten en cuenta que los puertos trunk no aparecen allí, así que para ellos usa show interfaces trunk.

show power (a menudo show power inline) muestra el estado de PoE: el presupuesto de energía total, cuánto se usa y cuánto queda, y para cada puerto si la energía está activa, qué clase se detectó y cuántos vatios están asignados. Úsalo cuando los teléfonos, las cámaras o los puntos de acceso no encienden o se reinician constantemente.

Términos clave

MAC address table (tabla de direcciones MAC)
La tabla del switch que asocia las direcciones MAC aprendidas con los puertos y las VLAN.
Running configuration (configuración en ejecución)
La configuración activa que se está usando en la memoria de un dispositivo.
Startup configuration (configuración de inicio)
La configuración guardada que se carga cuando arranca un dispositivo.
ARP table (tabla ARP)
Una tabla que asocia direcciones IP con direcciones MAC para los dispositivos de las redes conectadas directamente.
Ejemplo real

Una alerta de IP duplicada menciona 10.1.20.33. En el switch de núcleo, show arp muestra que la IP corresponde a la MAC 0011.2233.4455. show mac address-table encuentra esa MAC en el puerto Gi1/0/12 de un switch de acceso en la VLAN 20, y show interface en ese puerto muestra que se conecta a una impresora que alguien configuró con una dirección estática dentro del ámbito DHCP.

Consejo para el examen: ¿Dónde está conectada esta MAC? show mac-address-table. ¿Qué IP corresponde a qué MAC? show arp. ¿Por qué no llegamos a esa red? show route. ¿Errores o dúplex? show interface. ¿VLAN equivocada? show vlan. ¿Dispositivo PoE muerto? show power. ¿Cambios sin guardar? Compara la configuración en ejecución con la de inicio.

Comprueba lo que sabes

¿Qué dos comandos te permiten rastrear una dirección IP hasta un puerto físico del switch?

show arp para encontrar la dirección MAC de la IP, y luego show mac-address-table para encontrar el puerto de esa MAC.

Una cámara no enciende. ¿Qué comando revisa el presupuesto PoE del switch y la asignación de los puertos?

show power (show power inline).

¿Cómo puedes averiguar si un switch tiene cambios de configuración que se perderían al reiniciar?

Comparando la configuración en ejecución con la configuración de inicio usando los comandos show config.
