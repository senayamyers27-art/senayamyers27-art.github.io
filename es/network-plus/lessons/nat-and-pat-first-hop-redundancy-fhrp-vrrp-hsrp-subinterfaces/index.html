CompTIA Network+ N10-009

NAT y PAT, redundancia del primer salto (FHRP/VRRP/HSRP), subinterfaces

La traducción de direcciones de red (NAT, network address translation) reescribe las direcciones IP a medida que los paquetes pasan por un router o firewall. Su función principal es permitir que los hosts con direcciones privadas RFC 1918 lleguen a internet usando direcciones públicas, lo que ahorra el escaso espacio IPv4 y oculta el direccionamiento interno. El router mantiene una tabla de traducción para que el tráfico de retorno se asigne de nuevo al host interno correcto.

Hay varias formas. NAT estática asigna de forma permanente una dirección privada a una dirección pública, lo que se usa cuando un servidor interno debe ser accesible desde fuera. NAT dinámica asigna direcciones privadas a direcciones públicas tomadas de un pool según el orden de llegada; cuando el pool se agota, los nuevos hosts no pueden conectarse. La traducción de direcciones de puerto (PAT, port address translation), también llamada NAT overload, asigna muchas direcciones privadas a una sola dirección pública traduciendo también el puerto de origen, de modo que cada conexión interna obtiene un par único de dirección pública y puerto. PAT es lo que hacen todos los routers domésticos y la mayoría de los bordes corporativos. El reenvío de puertos (port forwarding) es una regla estática que envía el tráfico entrante de un puerto público determinado a un host interno, por ejemplo el TCP 443 público a un servidor web interno.

Términos de NAT que puedes ver en la salida de un router: inside local es la dirección privada del host interno, inside global es la dirección pública a la que se traduce y outside global es la dirección real del host de internet. NAT rompe el direccionamiento verdadero de extremo a extremo, lo que complica algunos protocolos como IPsec (de ahí NAT traversal) y SIP, y no es un control de seguridad por sí mismo, aunque como efecto secundario sí bloquea las conexiones entrantes no solicitadas.

Cada host tiene una sola puerta de enlace predeterminada. Si ese router falla, los hosts pierden el acceso más allá de su subred aunque exista un segundo router. Un protocolo de redundancia del primer salto (FHRP, first hop redundancy protocol) resuelve esto permitiendo que dos o más routers compartan una dirección IP virtual y una dirección MAC virtual. Los hosts usan la IP virtual como su puerta de enlace; un router está activo y responde por ella, y si falla, un router en espera (standby) toma la dirección virtual en segundos, sin reconfigurar ningún host. HSRP (Hot Standby Router Protocol) es propietario de Cisco, con los roles activo y standby. VRRP (Virtual Router Redundancy Protocol) es el estándar abierto, con los roles master y backup. Ambos usan una prioridad configurable para elegir el router activo, y la preferencia (preemption) permite que un router de mayor prioridad recupere el rol cuando vuelve a funcionar. GLBP es otra opción de Cisco que además balancea la carga.

Una subinterfaz es una interfaz lógica creada sobre una interfaz física, como GigabitEthernet0/0.10. El uso clásico es router on a stick (router en un palo): un solo puerto del router se conecta a un trunk del switch, y cada subinterfaz se etiqueta con un ID de VLAN usando encapsulación 802.1Q y recibe una dirección IP para actuar como la puerta de enlace de esa VLAN. El router entonces enruta entre las VLAN por un solo cable. Es barato y sencillo, aunque ese único enlace puede convertirse en un cuello de botella, por lo que las redes más grandes usan switches de Capa 3 con SVI en su lugar.

Al resolver problemas, show ip nat translations muestra las asignaciones actuales, y una falla de PAT suele manifestarse como que algunos usuarios funcionan y otros agotan el tiempo de espera cuando se acaban los recursos de puertos o del pool.

Términos clave

PAT
Port address translation: asigna muchas direcciones privadas a una dirección pública usando puertos de origen únicos.
Static NAT (NAT estática)
Una asignación fija uno a uno entre una dirección IP privada y una pública.
FHRP
First hop redundancy protocol: permite que varios routers compartan una IP de puerta de enlace virtual para que los hosts mantengan la conectividad si uno falla.
VRRP
Virtual Router Redundancy Protocol: el FHRP de estándar abierto, con routers master y backup.
Subinterface (subinterfaz)
Una interfaz lógica en un puerto físico, comúnmente etiquetada con una VLAN para el enrutamiento router on a stick.
Ejemplo real

Una oficina tiene dos routers configurados con VRRP que comparten la puerta de enlace virtual 192.168.1.1. Todas las PC usan esa dirección. Cuando el router master se queda sin energía, el backup toma la IP virtual en segundos y los usuarios siguen navegando, mientras PAT en los routers sigue traduciendo el tráfico de todos a la única dirección pública de la oficina.

Consejo para el examen: PAT = muchos a uno usando puertos. NAT estática = uno a uno, se usa para servidores accesibles desde fuera. HSRP es solo de Cisco; VRRP es el estándar abierto. Router on a stick usa subinterfaces con etiquetas 802.1Q.

Comprueba lo que sabes

¿Qué tipo de NAT permite que toda una oficina comparta una sola IP pública?

PAT (NAT overload), que distingue las conexiones por el puerto de origen.

¿Qué configuran los hosts como puerta de enlace predeterminada cuando se usa un FHRP?

La dirección IP virtual compartida, no la dirección física de ninguno de los routers.

¿Por qué crearías subinterfaces en un puerto de router?

Para enrutar entre varias VLAN por un solo enlace trunk, con cada subinterfaz etiquetada para una VLAN (router on a stick).
