CompTIA Network+ N10-009

DNS: tipos de registros (A, AAAA, CNAME, MX, TXT, NS, PTR, SOA), zonas, recursivo vs autoritativo, DNSSEC, DoH/DoT, archivo hosts

El sistema de nombres de dominio (DNS, Domain Name System) traduce los nombres que las personas recuerdan, como www.example.com, a las direcciones IP que usan las computadoras. Casi toda conexión comienza con una consulta DNS, así que cuando el DNS falla, los usuarios dicen que 'se cayó internet' aunque la red esté bien; una prueba rápida es verificar si puedes llegar a un sitio por su dirección IP pero no por su nombre. DNS usa el puerto 53: UDP para la mayoría de las consultas y TCP para las transferencias de zona y las respuestas grandes. Network+ evalúa los tipos de registros, cómo funciona la resolución, los conceptos de zona y la seguridad de DNS.
