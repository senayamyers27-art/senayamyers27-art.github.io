CompTIA Network+ N10-009

Puertos y protocolos comunes: FTP, SSH, Telnet, SMTP, DNS, DHCP, HTTP/S, NTP, SNMP, LDAP/S, SMB, Syslog, SQL, RDP, SIP

Las aplicaciones se encuentran entre sí en un host mediante números de puerto, valores de 16 bits que viajan en el encabezado TCP o UDP. Los puertos bien conocidos (well-known, del 0 al 1023) están asignados a servicios comunes, de modo que un servidor escucha en un puerto conocido y los clientes se conectan a él desde un puerto de origen aleatorio de numeración alta. El examen espera que reconozcas el puerto y el transporte de cada protocolo común y si es seguro o no. Las reglas de firewall, la resolución de problemas y los resultados de escaneos dependen de este conocimiento.

Transferencia de archivos y acceso remoto: FTP (File Transfer Protocol) usa TCP 21 para control y TCP 20 para datos en modo activo; envía las credenciales en texto claro. SFTP funciona dentro de SSH en TCP 22, y FTPS es FTP protegido con TLS (a menudo TCP 990 en modo implícito). SSH (Secure Shell) en TCP 22 ofrece acceso cifrado por línea de comandos y reemplaza a Telnet en TCP 23, que no está cifrado. TFTP (Trivial FTP) usa UDP 69, no tiene autenticación y se usa para cosas como el firmware y los archivos de configuración de los dispositivos. RDP (Remote Desktop Protocol) usa TCP 3389 para el acceso remoto gráfico a Windows.

Correo y web: SMTP (Simple Mail Transfer Protocol) envía correo entre servidores en TCP 25; los clientes de correo a menudo envían el correo en TCP 587 con STARTTLS, y SMTP sobre TLS implícito (SMTPS) usa el 465. HTTP usa TCP 80 y HTTPS, que es HTTP sobre TLS, usa TCP 443. Para completar, POP3 es 110 (995 seguro) e IMAP es 143 (993 seguro).

Servicios de infraestructura: DNS usa el puerto 53, UDP para la mayoría de las consultas y TCP para las transferencias de zona y las respuestas grandes. DHCP usa UDP 67 en el servidor y UDP 68 en el cliente. NTP (Network Time Protocol) usa UDP 123. SNMP (Simple Network Management Protocol) usa UDP 161 para consultar (polling) a los dispositivos y UDP 162 para las traps enviadas al administrador (manager). Syslog envía mensajes de registro a un colector en UDP 514 (también existen variantes con TCP y TLS). LDAP (Lightweight Directory Access Protocol) consulta directorios en TCP 389, y LDAPS (LDAP sobre TLS) usa TCP 636.

Compartición de archivos, bases de datos y voz: SMB (Server Message Block), que se usa para compartir archivos e impresoras en Windows, funciona directamente sobre TCP 445. Microsoft SQL Server escucha por defecto en TCP 1433; otras bases de datos usan sus propios puertos, como el 3306 para MySQL y el 1521 para Oracle. SIP (Session Initiation Protocol) establece y termina llamadas de voz y video en el puerto 5060 (UDP o TCP), y en el 5061 cuando está protegido con TLS. El audio en sí viaja por separado, normalmente como RTP.

Una forma práctica de estudiar es ejecutar netstat -an en Windows o ss -tuln en Linux y asociar cada puerto en escucha con un servicio, y luego hacer tarjetas de estudio (flashcards). Agrupa los protocolos inseguros con sus reemplazos seguros: Telnet a SSH, HTTP a HTTPS, FTP a SFTP o FTPS, LDAP a LDAPS, SNMPv1/v2c a SNMPv3. Las preguntas de seguridad suelen pedir qué reemplazo usar.

Términos clave

Well-known ports (puertos bien conocidos)
Números de puerto del 0 al 1023, asignados a servicios comunes como HTTP (80) y SSH (22).
Ephemeral port (puerto efímero)
Un puerto de origen temporal de numeración alta que elige un cliente para una conexión saliente.
SNMP trap
Una alerta no solicitada que envía un dispositivo administrado al SNMP manager en UDP 162.
LDAPS
LDAP protegido con TLS, en TCP 636.
Ejemplo real

A una administradora de firewall le piden que permita al help desk administrar los switches de forma segura y recibir sus registros. Ella permite TCP 22 (SSH) hacia los switches, bloquea TCP 23 (Telnet) y permite UDP 514 desde los switches hacia el servidor syslog y UDP 162 para las traps SNMP hacia el servidor de monitoreo.

Consejo para el examen: Cuidado con los pares que es fácil confundir: SNMP 161 (polling) vs 162 (traps), DHCP 67 (servidor) vs 68 (cliente), LDAP 389 vs LDAPS 636, SSH 22 vs Telnet 23, FTP 20/21 vs TFTP UDP 69.

Comprueba lo que sabes

¿Qué puerto y protocolo deberían reemplazar a Telnet para la administración remota por CLI?

SSH en TCP 22, porque cifra la sesión.

¿Qué puertos usa DNS y cuándo usa TCP?

El puerto 53; UDP para las consultas normales y TCP para las transferencias de zona y las respuestas grandes.

¿Qué puerto usa RDP?

TCP 3389.
