CompTIA Network+ N10-009

Enrutamiento estático vs dinámico; OSPF, EIGRP y BGP; selección de rutas (prefijo más largo, distancia administrativa, métricas)

Un router reenvía cada paquete buscando la dirección de destino en su tabla de enrutamiento. Las rutas entran a la tabla de tres formas: redes conectadas directamente (de las propias interfaces del router), rutas estáticas que escribe un administrador y rutas dinámicas aprendidas de protocolos de enrutamiento. Una ruta predeterminada (default route), 0.0.0.0/0 en IPv4 o ::/0 en IPv6, coincide con todo lo que no se conoce de otra forma y a menudo se llama gateway of last resort (puerta de enlace de último recurso).

El enrutamiento estático es sencillo, predecible y no usa ancho de banda ni CPU para tráfico de protocolos, lo que lo hace ideal para redes pequeñas, sitios stub con una sola salida y rutas predeterminadas hacia un ISP. Su debilidad es que no se adapta: si un enlace falla, la ruta estática permanece hasta que alguien la cambie, y en redes grandes mantener rutas estáticas es propenso a errores. Una ruta estática flotante (floating static route) es una ruta estática de respaldo a la que se le da una distancia administrativa peor, para que solo se use cuando desaparece la ruta principal. Los protocolos de enrutamiento dinámico intercambian rutas automáticamente y vuelven a converger después de las fallas, a costa de algo de complejidad y sobrecarga.

Los protocolos de gateway interior (IGP) enrutan dentro de la red de una sola organización, llamada sistema autónomo. OSPF (Open Shortest Path First) es un protocolo de estado de enlace (link-state) de estándar abierto: cada router aprende el mapa completo de la topología, ejecuta el algoritmo de la ruta más corta primero (shortest path first) y elige las rutas por costo, que se basa en el ancho de banda de la interfaz. Organiza las redes en áreas, con el área 0 como backbone, y converge rápidamente. EIGRP (Enhanced Interior Gateway Routing Protocol) es un protocolo de vector de distancia avanzado (a veces llamado híbrido) desarrollado por Cisco que usa una métrica compuesta, por defecto basada en el ancho de banda y el retardo, y converge rápidamente gracias a rutas de respaldo precalculadas. El antiguo RIP usa el conteo de saltos, con un máximo de 15 saltos.

BGP (Border Gateway Protocol) es el protocolo de gateway exterior que enruta entre sistemas autónomos y mantiene unido internet. Cada organización o ISP tiene un número de sistema autónomo (ASN). BGP es un protocolo de vector de ruta (path-vector): selecciona las rutas usando atributos como el AS path y políticas, no la velocidad bruta del enlace. El BGP externo (eBGP) funciona entre distintos AS; el BGP interno (iBGP) funciona dentro de uno. Las organizaciones usan BGP cuando se conectan a más de un ISP.

Cuando un router tiene varias rutas hacia un destino, elige en un orden fijo. Primero, la coincidencia del prefijo más largo (longest prefix match): gana la ruta más específica. Un paquete hacia 10.1.1.5 coincide con 10.0.0.0/8, 10.1.0.0/16 y 10.1.1.0/24, y se usa la /24. Segundo, si prefijos idénticos vienen de distintas fuentes, gana la menor distancia administrativa (AD), una calificación de confiabilidad. Los valores predeterminados típicos de Cisco son: conectada 0, estática 1, eBGP 20, EIGRP interno 90, OSPF 110, RIP 120 e iBGP 200. Tercero, dentro de un mismo protocolo, gana la métrica más baja, como el costo de OSPF o el conteo de saltos de RIP. Si las métricas empatan, muchos routers balancean la carga entre las rutas de igual costo.

En un router, show ip route muestra la tabla con códigos como C para conectada, S para estática y O para OSPF, y cada entrada muestra la AD y la métrica entre corchetes, por ejemplo [110/20].

Términos clave

Administrative distance (distancia administrativa)
Un valor que califica la confiabilidad de una fuente de rutas; se prefiere el valor más bajo cuando los prefijos son iguales.
Longest prefix match (coincidencia del prefijo más largo)
La regla según la cual un router usa la ruta coincidente más específica (la máscara de subred más larga) para un destino.
Link-state protocol (protocolo de estado de enlace)
Un protocolo de enrutamiento, como OSPF, en el que cada router construye un mapa completo de la topología y calcula las mejores rutas.
Autonomous system (sistema autónomo)
Una red o grupo de redes bajo un mismo control administrativo, identificado en BGP por un ASN.
Ejemplo real

Un router tiene una ruta OSPF hacia 172.16.0.0/16 y una ruta estática hacia 172.16.8.0/24. Un paquete hacia 172.16.8.9 sigue la ruta estática /24 por la coincidencia del prefijo más largo, mientras que un paquete hacia 172.16.9.9 sigue la ruta OSPF /16. Si el router también tuviera una ruta EIGRP hacia 172.16.0.0/16, preferiría EIGRP (AD 90) sobre OSPF (AD 110).

Consejo para el examen: Orden de selección: primero el prefijo más largo, luego la distancia administrativa y después la métrica. No compares métricas entre protocolos distintos. BGP es el único protocolo de gateway exterior que necesitas conocer.

Comprueba lo que sabes

¿Cuál se prefiere para un paquete hacia 10.5.1.1: una ruta estática (AD 1) hacia 10.0.0.0/8 o una ruta OSPF (AD 110) hacia 10.5.0.0/16?

La ruta OSPF /16, porque la coincidencia del prefijo más largo se evalúa antes que la distancia administrativa.

¿Qué métrica usa OSPF?

El costo, derivado del ancho de banda de la interfaz.

¿Qué protocolo de enrutamiento conecta los sistemas autónomos en internet?

BGP (Border Gateway Protocol).
