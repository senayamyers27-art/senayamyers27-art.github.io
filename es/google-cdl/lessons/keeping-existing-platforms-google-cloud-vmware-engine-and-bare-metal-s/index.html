Conservar las plataformas existentes: Google Cloud VMware Engine y Bare Metal Solution

Algunas cargas de trabajo no se pueden mover fácilmente a VMs estándar en la nube ni reescribirse. Pueden depender de una plataforma de virtualización en particular, de hardware especializado o de términos de licencia ligados a servidores físicos. Google Cloud ofrece dos servicios que permiten a las organizaciones llevar estas cargas de trabajo a la nube conservando su plataforma existente.

Google Cloud VMware Engine ejecuta un entorno VMware completo, que incluye el hipervisor vSphere, el almacenamiento vSAN y la red NSX, como servicio administrado sobre infraestructura dedicada en las regiones de Google Cloud. Muchas empresas ya ejecutan cientos o miles de VMs en VMware en sus centros de datos, con herramientas, procesos y habilidades del personal establecidos. Con VMware Engine pueden mover esas VMs a Google Cloud con pocos o ningún cambio, usando las herramientas de VMware que ya conocen, a menudo mucho más rápido que convertir cada VM. Google administra la infraestructura subyacente, mientras el cliente sigue administrando sus VMs. Una vez en Google Cloud, las cargas de trabajo pueden conectarse a servicios nativos como BigQuery y Cloud Storage y modernizarse gradualmente.

Bare Metal Solution ofrece servidores físicos dedicados, no máquinas virtuales, ubicados en las regiones de Google Cloud o cerca de ellas y conectados con enlaces de baja latencia. Está diseñado para cargas de trabajo especializadas que deben ejecutarse en bare metal, sobre todo las bases de datos Oracle, que tienen requisitos de licenciamiento y soporte que dificultan ejecutarlas en algunas plataformas virtualizadas. El cliente obtiene su propio hardware, mientras las aplicaciones que se ejecutan en otras partes de Google Cloud pueden llegar rápidamente a la base de datos.

Estos servicios encajan con las estrategias de rehospedar y de retener y extender. Ayudan a una organización a salir de sus centros de datos dentro de un plazo sin reescribir sistemas críticos, y ofrecen un paso intermedio: primero mover la plataforma y luego modernizar las aplicaciones con el tiempo.

Para el examen: entorno VMware existente, mismas herramientas y habilidades, migración más rápida, elige Google Cloud VMware Engine. Cargas de trabajo especializadas que necesitan servidores físicos dedicados, como bases de datos Oracle, elige Bare Metal Solution.

Términos clave

Google Cloud VMware Engine
Un servicio administrado que ejecuta un entorno VMware nativo en Google Cloud.
Bare Metal Solution
Servidores físicos dedicados cerca de las regiones de Google Cloud para cargas de trabajo especializadas como bases de datos Oracle.
Hypervisor (hipervisor)
Software que crea y ejecuta máquinas virtuales sobre hardware físico.
Bare metal
Un servidor físico que se usa directamente, sin una capa de virtualización compartida con otros.
Ejemplo real

Un minorista con 2,000 VMs de VMware las mueve a Google Cloud VMware Engine en unos pocos meses, conservando sus herramientas de vCenter. Su sistema de pedidos basado en Oracle pasa a Bare Metal Solution junto a la región, y la nueva analítica construida en BigQuery lee de ambos.

Consejo para el examen: Las palabras 'VMware', 'herramientas y procesos existentes' y 'migración rápida' apuntan a Google Cloud VMware Engine. 'Oracle' o 'hardware físico dedicado' apuntan a Bare Metal Solution.

Comprueba lo que sabes

¿Cuál es el principal beneficio de Google Cloud VMware Engine para un cliente de VMware?

Puede mover rápidamente sus VMs existentes a Google Cloud sin convertirlas, conservando las herramientas, los procesos y las habilidades de VMware.

¿Por qué una base de datos Oracle podría ejecutarse en Bare Metal Solution en lugar de en una VM?

Por requisitos de licenciamiento y soporte que favorecen los servidores físicos dedicados.
