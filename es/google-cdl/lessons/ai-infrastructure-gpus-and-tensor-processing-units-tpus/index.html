Infraestructura de IA: GPUs y Tensor Processing Units (TPUs)

Entrenar y ejecutar los modelos modernos de aprendizaje automático, en especial los grandes modelos de aprendizaje profundo y generativos, requiere cantidades enormes de cómputo, sobre todo operaciones matemáticas con grandes matrices y vectores. Las CPUs de propósito general pueden hacer este trabajo, pero lentamente. El hardware especializado llamado aceleradores (accelerators) lo agiliza de forma drástica, y el acceso a aceleradores a escala es una de las razones por las que las organizaciones usan la nube para la IA.

Las unidades de procesamiento gráfico (GPUs, graphics processing units) se diseñaron originalmente para generar imágenes, lo que también implica cálculos matemáticos masivos en paralelo. Resultaron ser excelentes para el ML y tienen amplio soporte en frameworks como PyTorch y TensorFlow. Google Cloud ofrece varios tipos de GPU que puedes conectar a VMs de Compute Engine, usar en clústeres de GKE o usar mediante el entrenamiento y la predicción de Vertex AI.

Las Tensor Processing Units (TPUs) son chips personalizados que Google diseñó específicamente para el aprendizaje automático. Son circuitos integrados de aplicación específica (ASICs), es decir, están construidos para un tipo de carga de trabajo y no para el cómputo general. Google desarrolló las TPUs para ejecutar de forma eficiente sus propios servicios de IA, como Search y Translate, y las usa para entrenar sus modelos Gemini. En Google Cloud, las TPUs están disponibles mediante Vertex AI, GKE y Compute Engine, y se pueden conectar en grupos grandes, llamados pods, para entrenar modelos muy grandes.

Cuál usar depende del modelo, el framework y el costo. Las GPUs son muy flexibles y tienen amplio soporte. Las TPUs pueden ofrecer un gran rendimiento y eficiencia de costos para el entrenamiento y el servicio a gran escala de los modelos adecuados para ellas. Muchos equipos prueban ambas. Para los líderes de negocio, el punto clave es que Google Cloud ofrece una variedad de infraestructura de IA, incluidas sus propias TPUs, sin necesidad de comprar y operar hardware especializado costoso.

Rara vez necesitas aceleradores cuando usas APIs preentrenadas o modelos generativos mediante Vertex AI, porque Google opera esa infraestructura por ti. Los aceleradores importan cuando entrenas o alojas tus propios modelos.

Términos clave

Accelerator (acelerador)
Hardware especializado, como una GPU o una TPU, que agiliza el cómputo de ML.
GPU
Unidad de procesamiento gráfico: un procesador con muchos núcleos en paralelo, muy usado para ML.
TPU
Tensor Processing Unit: el ASIC personalizado de Google diseñado para cargas de trabajo de aprendizaje automático.
ASIC
Circuito integrado de aplicación específica: un chip diseñado para un tipo de tarea.
Ejemplo real

Una startup de biotecnología necesita entrenar un modelo grande de proteínas durante unas semanas. En lugar de comprar hardware, renta TPUs mediante Vertex AI para el entrenamiento y luego sirve el modelo terminado en instancias más pequeñas con GPU, y paga cada una solo mientras la usa.

Consejo para el examen: Las TPUs son los chips de ML diseñados a la medida por Google. Si una pregunta pide qué construyó Google específicamente para acelerar el aprendizaje automático, la respuesta es TPUs, no GPUs.

¿Qué es una TPU?

Una Tensor Processing Unit, el ASIC personalizado de Google diseñado para acelerar el entrenamiento y la inferencia del aprendizaje automático.

¿Por qué rara vez necesitas pensar en aceleradores cuando usas una API preentrenada?

Google opera y administra la infraestructura subyacente; tú solo llamas a la API.
