BigQuery: data warehouse serverless y analítica

BigQuery es el data warehouse serverless y completamente administrado de Google Cloud. Cargas o transmites datos en él, o lo apuntas a datos que están en otros lugares, y los consultas con SQL estándar. No hay servidores, clústeres ni índices que administrar, y puede recorrer muy rápido conjuntos de datos muy grandes, de terabytes o más. Es uno de los productos más importantes de la sección de datos del examen.

Su arquitectura separa el almacenamiento del cómputo. Los datos se almacenan en formato columnar, lo que significa que una consulta lee solo las columnas que necesita, y la capacidad de procesamiento se asigna bajo demanda desde un grupo compartido muy grande. Como ambos están separados, puedes almacenar muchos datos a bajo costo y pagar el procesamiento solo cuando ejecutas consultas. El precio tiene dos partes: el almacenamiento y el cómputo de las consultas, ya sea bajo demanda según los bytes procesados o mediante capacidad reservada. Por eso la buena práctica es seleccionar solo las columnas que necesitas y usar tablas particionadas, en lugar de escribir SELECT * sobre todo.

BigQuery hace más que almacenar tablas. Los datos pueden llegar por lotes o en tiempo real mediante streaming. Puede consultar datos que permanecen en Cloud Storage o incluso en otras nubes, mediante tablas externas. BigQuery ML permite a los analistas crear y usar modelos de aprendizaje automático con SQL. Las funciones geoespaciales integradas, una gran colección de conjuntos de datos públicos y las conexiones con Looker, Looker Studio y hojas de cálculo hacen que los resultados sean fáciles de usar.

El acceso se controla con IAM a nivel de proyecto, conjunto de datos (dataset), tabla e incluso fila y columna, y los datos se cifran en reposo de forma predeterminada. Muchas fuentes de datos, incluidas Google Ads y otras herramientas SaaS, se pueden cargar de forma programada con BigQuery Data Transfer Service.

Puedes probarlo sin costo con el BigQuery sandbox, que ofrece una cuota mensual gratuita de almacenamiento y procesamiento de consultas sin tarjeta de crédito. Consultar un conjunto de datos público es un buen primer laboratorio.

Términos clave

Data warehouse
Un almacén central de datos limpios y estructurados optimizado para consultas analíticas.
Serverless (sin servidor)
Sin infraestructura que aprovisionar ni administrar; la capacidad se asigna automáticamente.
Columnar storage (almacenamiento columnar)
Almacenar los datos por columna, de modo que las consultas lean solo las columnas que necesitan.
BigQuery sandbox
Una forma sin costo de probar BigQuery dentro de límites mensuales gratuitos, sin una cuenta de facturación.
Ejemplo real

Un servicio de streaming de música carga cada día miles de millones de eventos de reproducción en BigQuery. Los analistas escriben SQL para encontrar qué canciones están ganando oyentes por país, el área de marketing construye un tablero en Looker Studio con los resultados y una científica de datos entrena un modelo de abandono de clientes (churn) con BigQuery ML en el mismo lugar.

Consejo para el examen: Para analítica SQL a gran escala sin administrar infraestructura, la respuesta es BigQuery. Cloud SQL ejecuta las transacciones de las aplicaciones; BigQuery analiza los datos de todo el negocio.

Comprueba lo que sabes

¿Por qué BigQuery separa el almacenamiento y el cómputo?

Para que cada uno escale de forma independiente: los datos se almacenan a bajo costo y el procesamiento se asigna solo cuando se ejecutan consultas.

¿Cuál es una forma sencilla de reducir el costo de las consultas en BigQuery?

Seleccionar solo las columnas necesarias (evitar SELECT *) y filtrar por columnas particionadas para que se procesen menos bytes.
