BigQuery ML: crear y usar modelos con SQL donde ya están los datos

Muchas organizaciones guardan sus datos de negocio más valiosos en BigQuery, y muchos de sus analistas dominan SQL pero no Python ni los frameworks de ML. BigQuery ML cierra esa brecha: te permite crear, entrenar, evaluar y usar modelos de aprendizaje automático con sentencias SQL, directamente dentro de BigQuery.

El flujo de trabajo parece SQL normal. Escribes una sentencia CREATE MODEL que indica el tipo de modelo y selecciona los datos de entrenamiento de una tabla, y BigQuery lo entrena. ML.EVALUATE informa qué tan preciso es el modelo, y ML.PREDICT lo aplica a filas nuevas, devolviendo las predicciones como resultados de consulta que puedes unir, guardar o mostrar en un tablero. Por ejemplo, un modelo podría predecir si cada cliente volverá a comprar, con base en sus pedidos anteriores.

BigQuery ML admite tipos de modelo comunes, entre ellos la regresión lineal para predecir números, la regresión logística para clasificación de sí o no, el clustering para agrupar clientes similares, los pronósticos de series de tiempo para la demanda y los modelos de recomendación. También puede conectarse a modelos alojados en Vertex AI, incluidos modelos de IA generativa, para que los analistas los llamen desde SQL, por ejemplo para resumir columnas de texto.

Las ventajas clave son la velocidad y la simplicidad. Los datos no tienen que exportarse a un sistema de ML separado, lo que ahorra tiempo, reduce las copias de datos sensibles y mantiene los controles de acceso existentes. Los analistas pueden construir modelos útiles sin esperar a los escasos científicos de datos. El entrenamiento usa el procesamiento escalable de BigQuery y pagas mediante los precios normales de BigQuery.

BigQuery ML no está pensado para todos los problemas. El aprendizaje profundo muy personalizado, las arquitecturas de modelo poco comunes o los datos no estructurados complejos se manejan mejor con el entrenamiento personalizado de Vertex AI. Pero para muchas predicciones de negocio con datos estructurados, es el camino más rápido de los datos a los resultados. Puedes probarlo en el BigQuery sandbox con un conjunto de datos público pequeño.

Términos clave

BigQuery ML
Una función de BigQuery para crear, entrenar y usar modelos de ML con SQL.
CREATE MODEL
La sentencia SQL que define y entrena un modelo en BigQuery ML.
ML.PREDICT
La función de BigQuery ML que aplica un modelo entrenado a los datos para producir predicciones.
Logistic regression (regresión logística)
Un tipo de modelo que predice la probabilidad de un resultado de sí o no.
Ejemplo real

Los analistas de una empresa de cajas de suscripción escriben una consulta CREATE MODEL sobre dos años de datos de clientes en BigQuery para predecir quién probablemente cancelará. Ejecutan ML.PREDICT cada semana y envían los resultados a un tablero de Looker Studio para el equipo de retención, todo sin mover ningún dato.

Consejo para el examen: Analistas con dominio de SQL más datos que ya están en BigQuery más una tarea de predicción común es igual a BigQuery ML. Evita mover los datos y no necesita Python.

¿Cuáles son dos beneficios de BigQuery ML?

Los analistas pueden usar SQL en lugar de aprender herramientas nuevas, y los datos se quedan en BigQuery sin exportarlos, lo que los mantiene seguros y ahorra tiempo.

¿Qué función de BigQuery ML devuelve predicciones?

ML.PREDICT.
