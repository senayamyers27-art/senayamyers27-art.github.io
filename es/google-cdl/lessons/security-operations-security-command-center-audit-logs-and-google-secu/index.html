Operaciones de seguridad: Security Command Center, logs de auditoría y Google Security Operations

Las operaciones de seguridad (SecOps) son el trabajo continuo de detectar, investigar y responder a las amenazas. Los controles preventivos nunca son perfectos, así que las organizaciones necesitan visibilidad de lo que está pasando y la capacidad de reaccionar rápido. Google Cloud ofrece herramientas en varios niveles.

Security Command Center es la plataforma integrada de seguridad y gestión de riesgos de Google Cloud. Da una vista central, en todos los proyectos de una organización, de los activos, las configuraciones erróneas (como buckets públicos o puertos de firewall abiertos), las vulnerabilidades (como software desactualizado en VMs o fallas en aplicaciones web) y las amenazas activas (como una VM que mina criptomonedas u otorgamientos de IAM inusuales). Prioriza los hallazgos y recomienda correcciones, y puede comparar el entorno con referencias de cumplimiento (benchmarks). Los niveles superiores agregan más capacidades de detección.

Cloud Audit Logs registran quién hizo qué, dónde y cuándo en Google Cloud. Los logs de auditoría de Admin Activity registran los cambios de configuración, como crear una VM o cambiar las políticas de IAM; siempre están activados y no se pueden desactivar. Los logs de auditoría de Data Access registran las lecturas y escrituras de datos de usuario y en su mayoría están desactivados de forma predeterminada por su volumen; los activas donde se necesiten. Los logs de System Event registran los cambios iniciados por Google, y los logs de Policy Denied registran los accesos rechazados por las políticas de seguridad. Los logs se consultan en el Logs Explorer de Cloud Logging y se pueden exportar a BigQuery u otras herramientas para su análisis a largo plazo. Los logs de auditoría responden preguntas como '¿quién eliminó esta instancia?' y apoyan las investigaciones y el cumplimiento.

Google Security Operations (antes Chronicle) es una plataforma de operaciones de seguridad nativa de la nube que combina SIEM (gestión de información y eventos de seguridad) y SOAR (orquestación, automatización y respuesta de seguridad). Ingiere grandes volúmenes de telemetría de seguridad de la nube, de on-premises y de otras fuentes, la enriquece con la inteligencia de amenazas de Google, incluida la de Mandiant, detecta amenazas y automatiza los flujos de respuesta.

Otros servicios también ayudan, como Sensitive Data Protection para descubrir información sensible y Web Security Scanner para las vulnerabilidades de las aplicaciones. Mandiant ofrece experiencia en respuesta a incidentes e inteligencia de amenazas.

Términos clave

Security Command Center
La plataforma central de Google Cloud para la postura de seguridad, las vulnerabilidades, las configuraciones erróneas y la detección de amenazas.
Cloud Audit Logs
Logs que registran las acciones administrativas y el acceso a los datos en Google Cloud.
SIEM
Gestión de información y eventos de seguridad: recopilar y analizar logs de seguridad para detectar amenazas.
SOAR
Orquestación, automatización y respuesta de seguridad: automatizar los pasos de investigación y respuesta.
Ejemplo real

Security Command Center marca que un nuevo bucket de Cloud Storage se puede leer públicamente y que una VM muestra señales de minería de criptomonedas. El equipo de seguridad revisa los logs de auditoría de Admin Activity para ver qué cuenta creó el bucket y lo hizo público, elimina el acceso público y aísla la VM.

Consejo para el examen: Postura y amenazas en los proyectos de Google Cloud: Security Command Center. Quién hizo qué y cuándo: Cloud Audit Logs (Admin Activity siempre está activado). SIEM y SOAR para toda la empresa: Google Security Operations.

Comprueba lo que sabes

¿Qué logs de auditoría siempre están activados y no se pueden desactivar?

Los logs de auditoría de Admin Activity.

¿Qué ofrece Security Command Center?

Una vista central de los activos, las configuraciones erróneas, las vulnerabilidades y las amenazas en toda una organización, con hallazgos priorizados y recomendaciones.
