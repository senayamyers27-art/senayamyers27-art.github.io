Mover datos a Google Cloud: Database Migration Service, BigQuery Data Transfer Service, Storage Transfer Service y Transfer Appliance

Antes de que los datos puedan crear valor en la nube, tienen que llegar ahí. Google Cloud ofrece varios servicios de transferencia, y el examen evalúa si sabes elegir el correcto según el tipo de datos, su origen y la red disponible.

Database Migration Service mueve bases de datos, como MySQL, PostgreSQL, SQL Server y Oracle, a Cloud SQL o AlloyDB. Puede hacer replicación continua para que el origen siga en uso durante la migración, lo que mantiene corto el tiempo de inactividad: dejas que el destino se ponga al día y luego cambias la aplicación. Es serverless y administra el proceso de migración por ti.

BigQuery Data Transfer Service automatiza la carga programada de datos en BigQuery. Tiene conectores para fuentes de Google como Google Ads, YouTube y Google Play, para muchas aplicaciones SaaS de terceros, para archivos en Cloud Storage y en los almacenes de objetos de otras nubes, y para migrar desde otros data warehouses. Los equipos de marketing y analítica lo usan para mantener BigQuery actualizado sin escribir pipelines.

Storage Transfer Service mueve grandes cantidades de datos de archivos u objetos por la red hacia Cloud Storage, desde el almacenamiento de otros proveedores de nube, desde ubicaciones HTTP o desde sistemas de archivos on-premises mediante agentes. Admite transferencias programadas y repetidas, así que también puede mantener buckets sincronizados.

Transfer Appliance es un dispositivo físico de almacenamiento de gran capacidad que Google envía a tu centro de datos. Copias los datos en él, lo envías de regreso y Google sube los datos a Cloud Storage. Los datos en el dispositivo están cifrados. Es la opción correcta cuando la cantidad de datos es tan grande, o la red tan lenta, que una transferencia en línea tardaría demasiado; por ejemplo, cientos de terabytes con una conexión modesta.

Para el examen: bases de datos hacia Cloud SQL o AlloyDB, Database Migration Service. Cargas programadas a BigQuery desde SaaS y otras fuentes, BigQuery Data Transfer Service. Archivos y objetos por la red hacia Cloud Storage, Storage Transfer Service. Conjuntos de datos enormes con ancho de banda limitado, Transfer Appliance.

Términos clave

Database Migration Service
Un servicio administrado que migra bases de datos a Cloud SQL o AlloyDB con un tiempo de inactividad mínimo.
BigQuery Data Transfer Service
Cargas de datos programadas y administradas hacia BigQuery desde Google, SaaS y otras fuentes.
Storage Transfer Service
Transferencias en línea de datos de objetos y archivos hacia Cloud Storage desde otras nubes, HTTP u on-premises.
Transfer Appliance
Un dispositivo físico que se envía al cliente para mover sin conexión conjuntos de datos muy grandes a Google Cloud.
Ejemplo real

Una empresa de medios tiene 600 TB de video on-premises y un enlace a internet lento, así que usa Transfer Appliance. Su base de datos PostgreSQL pasa a Cloud SQL con Database Migration Service sin dejar de estar en línea, y ahora sus datos de rendimiento publicitario llegan a BigQuery cada mañana mediante BigQuery Data Transfer Service.

Consejo para el examen: Pon atención a las pistas sobre la velocidad de la red y el tamaño de los datos. 'Conexión lenta' y 'cientos de terabytes' significan Transfer Appliance. 'Mover una base de datos con tiempo de inactividad mínimo' significa Database Migration Service.

Comprueba lo que sabes

¿Qué servicio mantiene en uso una base de datos de origen mientras se copia a Cloud SQL?

Database Migration Service, usando replicación continua antes del cambio final (cutover).

Una empresa quiere copiar cada noche datos del almacenamiento de objetos de otra nube a Cloud Storage. ¿Qué servicio usa?

Storage Transfer Service.
