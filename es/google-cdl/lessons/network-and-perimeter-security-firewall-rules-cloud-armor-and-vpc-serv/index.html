Seguridad de red y perímetro: reglas de firewall, Cloud Armor y VPC Service Controls

Incluso en un mundo de confianza cero, los controles de red siguen siendo una capa importante de la defensa en profundidad. Google Cloud ofrece varios, cada uno de los cuales protege contra amenazas distintas.

Una nube privada virtual (VPC, Virtual Private Cloud) es la red privada de un cliente en Google Cloud, que abarca varias regiones y en la que recursos como las VMs obtienen direcciones IP internas. Las reglas de firewall de VPC y las políticas de firewall permiten o niegan el tráfico hacia y desde los recursos según direcciones, puertos, protocolos, etiquetas de red o cuentas de servicio. La buena práctica es negar por defecto y permitir solo lo necesario, por ejemplo permitir HTTPS desde internet solo hacia el balanceador de carga y SSH solo desde Identity-Aware Proxy en lugar de desde cualquier lugar. Las políticas de firewall también se pueden aplicar de forma centralizada a nivel de organización o de carpeta. Cloud NGFW agrega funciones de inspección más avanzadas.

Cloud Armor protege las aplicaciones y los sitios web expuestos a internet que están detrás de los balanceadores de carga externos de Google Cloud. Ofrece protección contra ataques de denegación de servicio distribuidos (DDoS), usando la escala de la red de borde de Google para absorber grandes volúmenes de tráfico, y funciona como un firewall de aplicaciones web (WAF) con reglas preconfiguradas para ataques comunes como la inyección de SQL y el cross-site scripting. Las reglas también pueden bloquear o permitir tráfico por dirección IP o región geográfica y limitar la tasa de solicitudes. Como trabaja en el borde, los ataques se detienen antes de llegar a la aplicación.

VPC Service Controls atiende un riesgo distinto: la exfiltración de datos desde servicios administrados de Google Cloud como Cloud Storage y BigQuery. Te permite trazar un perímetro de servicio alrededor de proyectos y servicios. Las solicitudes para acceder a los datos desde fuera del perímetro, o para copiar datos a recursos fuera de él, se bloquean aunque quien llama tenga credenciales de IAM válidas. Esto ayuda a contener el daño por credenciales robadas o personal interno malintencionado.

Las opciones de conectividad privada, como Private Google Access y Private Service Connect, permiten que las cargas de trabajo lleguen a los servicios de Google sin usar direcciones IP públicas, y Cloud VPN y Cloud Interconnect ofrecen conexiones seguras con las redes on-premises.

Términos clave

VPC firewall rules (reglas de firewall de VPC)
Reglas que permiten o niegan el tráfico de red hacia y desde los recursos de una red VPC.
Cloud Armor
La protección contra DDoS y el firewall de aplicaciones web de Google Cloud para aplicaciones detrás de balanceadores de carga externos.
Web application firewall (WAF, firewall de aplicaciones web)
Un filtro que bloquea ataques web comunes como la inyección de SQL y el cross-site scripting.
VPC Service Controls
Perímetros de servicio alrededor de los servicios de Google Cloud que reducen el riesgo de exfiltración de datos.
Ejemplo real

Una tienda en línea coloca su sitio detrás de un balanceador de carga global con Cloud Armor, que absorbe un gran ataque DDoS y bloquea intentos de inyección de SQL. Sus datos de clientes en BigQuery están dentro de un perímetro de VPC Service Controls, así que la credencial robada de un analista no se puede usar para copiar tablas a un proyecto externo.

Consejo para el examen: DDoS y ataques web contra un sitio público: Cloud Armor. Datos copiados fuera de los servicios administrados incluso con credenciales válidas: VPC Service Controls. Permitir o negar el tráfico hacia las VMs por puerto y dirección: reglas de firewall.

Comprueba lo que sabes

¿Qué servicio protege una aplicación web pública contra la inyección de SQL y los DDoS en el borde de Google?

Cloud Armor.

¿Contra qué protege VPC Service Controls que IAM por sí solo no cubre?

Contra la exfiltración de datos por parte de alguien con credenciales válidas, al bloquear el acceso y la copia a través del perímetro de servicio.
