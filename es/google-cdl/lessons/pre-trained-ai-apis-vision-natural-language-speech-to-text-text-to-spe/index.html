APIs de IA preentrenadas: Vision, Natural Language, Speech-to-Text, Text-to-Speech y Translation

La forma más rápida de agregar IA a una aplicación es llamar a un modelo preentrenado mediante una API. Google ya entrenó estos modelos con conjuntos de datos muy grandes, así que envías tus datos, como una imagen, un documento o un archivo de audio, y recibes resultados en segundos. No necesitas datos de entrenamiento, experiencia en ML ni infraestructura, y normalmente pagas por uso, con una cuota mensual gratuita en muchos de ellos.

La Cloud Vision API analiza imágenes. Puede detectar objetos y etiquetas (como 'perro' o 'playa'), leer texto impreso y manuscrito mediante reconocimiento óptico de caracteres (OCR), detectar rostros (no identificar personas), lugares emblemáticos y logotipos, y marcar contenido explícito con SafeSearch. La Video Intelligence API hace un análisis similar con video.

La Cloud Natural Language API analiza texto. Puede encontrar el sentimiento (positivo o negativo), extraer entidades como personas, lugares y productos, clasificar contenido en categorías y analizar la sintaxis. Es útil para revisar comentarios de clientes, enrutar tickets de soporte u organizar documentos.

Speech-to-Text convierte audio hablado en texto, lo que es útil para transcribir llamadas, agregar subtítulos y comandos de voz. Text-to-Speech hace lo contrario: produce voz de sonido natural a partir de texto en muchos idiomas y voces, por ejemplo para sistemas telefónicos o accesibilidad. La Cloud Translation API traduce texto entre muchos idiomas y puede detectar el idioma de origen.

Document AI es un servicio relacionado para extraer datos estructurados, como campos y tablas, de documentos como facturas, recibos y formularios.

Las APIs preentrenadas son ideales cuando tu problema es común y los modelos generales ya lo resuelven bien. Si necesitas reconocer cosas específicas de tu negocio, como los defectos de tus propios productos o la jerga de tu industria, quizá necesites un modelo personalizado mediante AutoML o entrenamiento personalizado. En el examen, elige una API preentrenada cuando un escenario enfatiza la rapidez, la ausencia de un equipo de ML y una tarea común.

Términos clave

Pre-trained model (modelo preentrenado)
Un modelo ya entrenado por el proveedor que puedes usar de inmediato sin tus propios datos de entrenamiento.
OCR
Reconocimiento óptico de caracteres: extraer texto de imágenes de documentos impresos o manuscritos.
Sentiment analysis (análisis de sentimiento)
Determinar si un texto expresa una opinión positiva, negativa o neutral.
Entity extraction (extracción de entidades)
Identificar nombres de personas, lugares, organizaciones y otros elementos en un texto.
Ejemplo real

Una cadena hotelera envía cada reseña de huéspedes a la Natural Language API para calificar el sentimiento y extraer los temas mencionados, como 'desayuno' o 'wifi'. Las reseñas negativas sobre temas específicos se envían al gerente correspondiente el mismo día, sin que intervenga ningún equipo de ciencia de datos.

Consejo para el examen: Tarea común más ninguna habilidad de ML más necesitarlo rápido es igual a una API preentrenada. La Vision API lee el texto de las imágenes; la Natural Language API analiza el significado de un texto; Translation convierte entre idiomas.
