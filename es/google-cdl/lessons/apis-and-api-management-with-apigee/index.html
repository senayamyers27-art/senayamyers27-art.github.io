APIs y administración de APIs con Apigee

Una interfaz de programación de aplicaciones (API, application programming interface) es una forma definida en que un software solicita datos o acciones a otro. Cuando una aplicación de banca móvil muestra tu saldo, llama a la API del banco; cuando una tienda en línea muestra las tarifas de envío, llama a la API de una paquetería. Las APIs ocultan la complejidad de los sistemas que están detrás y permiten reutilizar esos sistemas de nuevas formas.

Las APIs son centrales para la transformación digital. Permiten a las organizaciones liberar datos y funciones atrapados en sistemas heredados y exponerlos a nuevas aplicaciones, socios y canales sin reescribir el back end. Permiten que los microservicios trabajen juntos. Y crean nuevos modelos de negocio: una empresa puede ofrecer sus capacidades como productos sobre los que construyen sus socios, a veces por una tarifa. Un minorista podría publicar APIs de productos e inventario para que los socios de un marketplace publiquen sus artículos automáticamente.

Una vez que las APIs se comparten fuera de un solo equipo, necesitan administrarse como productos. La administración de APIs (API management) cubre la seguridad (autenticación con claves de API u OAuth, protección contra abusos), la gestión del tráfico (límites de tasa y cuotas para que un consumidor no sobrecargue el back end), la analítica (quién usa qué APIs y cómo funcionan), el control de versiones para que los cambios no afecten a los consumidores, un portal para desarrolladores con documentación y registro de autoservicio y, cuando se necesita, la monetización.

Apigee es la plataforma de administración de APIs de Google Cloud. Funciona como una capa de proxy delante de los servicios de back end, dondequiera que se ejecuten, en Google Cloud, on-premises o en otras nubes, y aplica políticas de seguridad, limitación de tasa, transformación y caché. Ofrece tableros sobre el tráfico de las APIs y las métricas de negocio, y portales para desarrolladores. Como el proxy desacopla a los consumidores de los back ends, una organización puede modernizar los sistemas detrás de una API sin cambiar las aplicaciones que la llaman.

Para el examen, cuando un escenario implica compartir servicios de forma segura con socios o desarrolladores, controlar el uso con cuotas, analizar el tráfico de las APIs o monetizar APIs, la respuesta es Apigee.

Términos clave

API
Interfaz de programación de aplicaciones: una forma definida en que un software solicita datos o acciones a otro software.
API management (administración de APIs)
Asegurar, controlar, monitorear y publicar APIs como productos.
Apigee
La plataforma de administración de APIs de Google Cloud.
Rate limiting (limitación de tasa)
Restringir cuántas solicitudes puede hacer un consumidor en un periodo para proteger los sistemas de back end.
Ejemplo real

Un grupo hospitalario quiere permitir que aplicaciones de salud aprobadas muestren a los pacientes los horarios de sus citas. Expone una API de citas mediante Apigee, que verifica las credenciales de cada aplicación, limita la tasa de solicitudes, registra el uso para auditorías y ofrece un portal para desarrolladores, mientras el sistema de agenda antiguo que está detrás permanece sin cambios.

Consejo para el examen: Las APIs liberan los datos heredados y habilitan ecosistemas de socios. Apigee las administra: seguridad, cuotas, analítica, portales para desarrolladores y monetización.

Comprueba lo que sabes

¿Cómo pueden las APIs ayudar a modernizar un sistema heredado sin reescribirlo?

Una API expone los datos y las funciones del sistema heredado a nuevas aplicaciones; más adelante el back end se puede reemplazar sin cambiar a los consumidores.

Menciona cuatro capacidades de la administración de APIs.

Seguridad, limitación de tasa y cuotas, analítica, control de versiones, portales para desarrolladores y monetización (cuatro cualesquiera).
