Controlar los costos: cuentas de facturación, presupuestos y alertas, cuotas, etiquetas y exportación de facturación

Google Cloud ofrece varias herramientas para ver, asignar y controlar el gasto. El examen suele evaluar qué hace cada una y, con la misma importancia, qué no hace.

Una cuenta de Cloud Billing paga el uso. Está vinculada a un método de pago y a uno o más proyectos; cada proyecto está vinculado a una sola cuenta de facturación a la vez. El acceso a la facturación se controla por separado con roles como Billing Account Administrator y Billing Account Viewer, para que el personal de finanzas pueda ver los costos sin poder cambiar los recursos.

Los presupuestos y las alertas de presupuesto (budgets y budget alerts) te permiten fijar un monto planeado para una cuenta de facturación, un proyecto, un conjunto de servicios o recursos con ciertas etiquetas, y recibir notificaciones cuando el gasto real o pronosticado alcanza ciertos umbrales, como 50%, 90% y 100%. Los presupuestos no detienen automáticamente los recursos ni ponen un tope al gasto. Si necesitas una acción automática, puedes enviar las notificaciones del presupuesto a Pub/Sub y disparar una automatización, por ejemplo una función que deshabilite la facturación en un proyecto de pruebas (sandbox).

Las cuotas (quotas) limitan cuánto de un recurso puede usar un proyecto, como el número de vCPUs en una región o las solicitudes a una API por minuto. Existen para proteger tanto a los clientes como a Google Cloud de picos inesperados, scripts descontrolados o abusos, y pueden limitar el gasto de forma indirecta. Algunas cuotas se pueden aumentar por solicitud, y los administradores pueden reducir algunas para fijar límites más estrictos.

Las etiquetas (labels) son pares clave-valor, como team=marketing o env=prod, asociados a los recursos. Aparecen en los datos de facturación, así que los costos se pueden agrupar y filtrar por equipo, aplicación o entorno. Una estrategia de etiquetado consistente es esencial para la asignación de costos.

Los reportes de facturación en la consola muestran las tendencias de gasto y los desgloses por proyecto, servicio, región y etiqueta. Para un análisis más profundo, la exportación de Cloud Billing (Cloud Billing export) envía datos detallados de uso y costo a BigQuery, donde se pueden consultar con SQL y visualizar en Looker Studio. La Pricing Calculator estima los costos antes de construir.

Términos clave

Cloud Billing account (cuenta de Cloud Billing)
La cuenta que paga el uso de Google Cloud, vinculada a proyectos y a un método de pago.
Budget alert (alerta de presupuesto)
Una notificación que se envía cuando el gasto real o pronosticado alcanza un umbral; no detiene el gasto.
Quota (cuota)
Un límite de cuánto de un recurso o de una API puede usar un proyecto.
Label (etiqueta)
Un par clave-valor asociado a los recursos, que se usa para organizar y asignar los costos.
Ejemplo real

Una universidad le da a cada grupo de investigación su propio proyecto con un presupuesto y alertas al 50% y al 90%. Los recursos llevan etiquetas con el número de la beca, y los datos de facturación se exportan a BigQuery para que la oficina de finanzas pueda cargar con precisión cada beca cada mes. Un proyecto sandbox usa una función disparada por Pub/Sub para deshabilitar la facturación cuando se excede su presupuesto.

Consejo para el examen: Los presupuestos alertan, no ponen tope. Las cuotas limitan el uso de recursos. Las etiquetas asignan el costo. La exportación de la facturación a BigQuery permite un análisis detallado. Conoce qué herramienta conviene a cada objetivo.

Comprueba lo que sabes

¿Un presupuesto detiene automáticamente los recursos cuando se excede?

No. Los presupuestos envían alertas; una acción automática requiere automatización, por ejemplo mediante notificaciones de Pub/Sub.

¿Cómo puede una empresa ver los costos de la nube por equipo?

Aplicando a los recursos etiquetas como team (o usando proyectos separados) y luego agrupando los reportes de facturación o los datos de facturación exportados por esas etiquetas.
