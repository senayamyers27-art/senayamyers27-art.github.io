AWS Certified Security – Specialty SCS-C03

Resiliencia ante DDoS: AWS Shield Standard vs Shield Advanced, CloudFront, Route 53 y AWS Firewall Manager

Un ataque de denegación de servicio distribuido (DDoS) intenta agotar el ancho de banda, las conexiones o la capacidad de la aplicación con tráfico desde muchos orígenes. El enfoque de AWS es por capas: absorber y filtrar los ataques en su enorme red de borde, escalar la aplicación y filtrar las solicitudes malas en la capa 7.

AWS Shield Standard es automático y gratuito para todos los clientes. Protege contra los ataques más comunes de las capas de red y transporte, como SYN floods y reflexión UDP, sobre todo para el tráfico que entra por CloudFront, Route 53 y Global Accelerator. AWS Shield Advanced es una suscripción paga para una organización que agrega detección mejorada para recursos protegidos (CloudFront, hosted zones de Route 53, Global Accelerator, ELB y Elastic IPs), detección basada en la salud usando health checks de Route 53, mitigación automática de DDoS en la capa de aplicación que crea reglas de WAF por ti, acceso 24/7 al Shield Response Team (SRT), protección de costos por DDoS que acredita los cargos de escalado causados por un ataque, informes detallados de ataques y AWS WAF y Firewall Manager sin costo adicional para los recursos protegidos. También puedes dar acceso al SRT a tu cuenta para que ayude a escribir reglas de WAF durante un ataque.

La arquitectura importa tanto como Shield. Pon CloudFront delante de las aplicaciones, incluso las dinámicas, para que los ataques golpeen primero el borde. Usa Route 53, que está diseñado para resistir inundaciones de DNS. Mantén los orígenes privados, accesibles solo desde CloudFront (por ejemplo, origin access control para S3, o un encabezado personalizado más la managed prefix list de CloudFront para un ALB). Usa Auto Scaling y balanceadores de carga para absorber picos, y rate-based rules de WAF para inundaciones HTTP.

AWS Firewall Manager gestiona de forma central las protecciones en una organización: web ACLs de WAF, protecciones de Shield Advanced, políticas de security groups y políticas de Network Firewall y DNS Firewall. Necesita AWS Organizations, una cuenta de administrador de Firewall Manager y AWS Config habilitado, y aplica automáticamente las políticas a las cuentas y recursos nuevos que coinciden.

Términos clave

Shield Standard
Protección gratuita y automática contra ataques DDoS comunes de las capas de red y transporte.
Shield Advanced
Servicio pago que agrega detección mejorada, el Shield Response Team, protección de costos y mitigación automática en capa 7.
Shield Response Team
Expertos en DDoS de AWS disponibles 24/7 para clientes de Shield Advanced durante los ataques.
Firewall Manager
Servicio que aplica políticas de WAF, Shield Advanced, security groups y firewalls en toda una organización.
Ejemplo real

Un sitio de apuestas espera ataques durante eventos importantes. Se suscribe a Shield Advanced, protege su distribución de CloudFront y su zona de Route 53 con detección basada en la salud, activa la mitigación automática en la capa de aplicación y usa Firewall Manager para que las cuentas nuevas reciban las mismas reglas de WAF. Durante un ataque, el SRT ayuda a ajustar reglas y la protección de costos cubre la factura de escalado.

Consejo para el examen: La protección de costos, el equipo de respuesta y los informes avanzados solo vienen con Shield Advanced. Si una pregunta dice 'sin costo adicional' para una protección básica contra DDoS, la respuesta es Shield Standard.

Comprueba lo que sabes

¿Qué requisitos previos necesita Firewall Manager?

AWS Organizations, una cuenta designada como administrador de Firewall Manager y AWS Config habilitado en las cuentas.

¿Cómo ayudan los health checks de Route 53 a Shield Advanced?

Permiten que Shield Advanced use la salud de la aplicación en la detección, lo que la hace más rápida y precisa para identificar ataques reales.
