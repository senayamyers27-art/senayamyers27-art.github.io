AWS Certified Security – Specialty SCS-C03

Evidencia e informes de auditoría: AWS Audit Manager y AWS Artifact

Las auditorías necesitan evidencia de dos lados: prueba de que AWS opera su parte de la infraestructura de forma segura, y prueba de que tú operas tu parte de forma segura. AWS ofrece un servicio para cada una.

AWS Artifact es un portal de autoservicio para los documentos de cumplimiento propios de AWS. Artifact Reports da acceso bajo demanda a informes de auditoría de terceros y certificaciones de AWS, como los informes SOC 1, SOC 2 y SOC 3, la attestation of compliance de PCI DSS, certificaciones ISO y otros. Algunos solo están disponibles después de aceptar términos, y muchos son confidenciales, así que los compartes con tus auditores bajo esos términos. Artifact Agreements te permite revisar y aceptar acuerdos con AWS, como el Business Associate Addendum (BAA) necesario para cargas de trabajo HIPAA, para una cuenta o para toda la organización. También puedes recibir notificaciones cuando se publican informes nuevos. Artifact cubre la mitad de 'seguridad de la nube' de la responsabilidad compartida.

AWS Audit Manager ayuda con la mitad de 'seguridad en la nube'. Creas una evaluación a partir de un marco, como los marcos predefinidos para CIS, PCI DSS, HIPAA, SOC 2, GDPR, NIST o buenas prácticas de IA generativa, o un marco personalizado. Audit Manager recopila entonces evidencia de forma continua y automática desde tus cuentas: evaluaciones de reglas de AWS Config, verificaciones de controles de Security Hub, actividad de usuarios en CloudTrail y snapshots de configuración obtenidos por API, y asigna cada pieza a controles. Puedes agregar evidencia manual, como documentos de políticas, delegar la revisión de controles a sus dueños y generar un informe de evaluación con la evidencia para los auditores. No decide si cumples; eso lo deciden los auditores con su evidencia.

Recuerda la pareja: las certificaciones y acuerdos de AWS vienen de Artifact; la evidencia sobre tu propio entorno viene de Audit Manager, alimentado por Config, Security Hub y CloudTrail.

Términos clave

AWS Artifact
Portal para descargar informes de cumplimiento de AWS y aceptar acuerdos como el BAA.
AWS Audit Manager
Servicio que recopila de forma continua evidencia de tu uso de AWS y la asigna a marcos de auditoría.
Informe de evaluación
Salida de Audit Manager que agrupa la evidencia seleccionada para los auditores.
Business Associate Addendum
Acuerdo con AWS requerido antes de guardar información de salud protegida bajo HIPAA.
Ejemplo real

Antes de una auditoría SOC 2, una empresa SaaS descarga de Artifact el informe SOC 2 de AWS para mostrar los controles de infraestructura que opera AWS. También ejecuta durante tres meses una evaluación SOC 2 de Audit Manager en sus cuentas de producción y luego entrega al auditor un informe de evaluación con evidencia de Config y CloudTrail sobre sus propios controles.

Consejo para el examen: Las palabras 'el informe de AWS' o 'acuerdo con AWS' significan Artifact. 'Recopilar evidencia sobre nuestros recursos para una auditoría' significa Audit Manager.
