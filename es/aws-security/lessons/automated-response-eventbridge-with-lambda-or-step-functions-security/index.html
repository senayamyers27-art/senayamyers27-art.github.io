AWS Certified Security – Specialty SCS-C03

Respuesta automatizada: EventBridge con Lambda o Step Functions, automation rules de Security Hub y remediación de AWS Config

Las personas son lentas de noche y los fines de semana; las APIs no. La respuesta automatizada reduce el tiempo entre la detección y la contención, y hace que cada respuesta sea consistente y quede registrada. El examen espera que elijas el componente de automatización correcto.

EventBridge es el disparador. Los hallazgos de GuardDuty, Security Hub, Inspector, Macie y Access Analyzer, los cambios de cumplimiento de Config y las llamadas a la API de CloudTrail llegan como eventos. Una regla que coincide con un tipo o una severidad de hallazgo puede llamar a Lambda para una acción corta, como desactivar una access key, o iniciar una máquina de estados de Step Functions para un flujo de varios pasos con reintentos, esperas, ramas en paralelo y pasos de aprobación humana, como aislar, tomar snapshot, notificar y abrir un ticket. También puede iniciar directamente un runbook de Systems Manager Automation.

Las automation rules de Security Hub manejan los propios hallazgos sin código: cuando llega un hallazgo que cumple los criterios, la regla puede cambiar su severidad, poner su estado de flujo de trabajo en SUPPRESSED o NOTIFIED, agregar notas o actualizar campos. Las custom actions permiten a los analistas enviar hallazgos seleccionados a EventBridge cuando lo deciden, lo que conviene cuando una persona debe decidir antes de ejecutar una respuesta.

La remediación de AWS Config corrige desviaciones de configuración. Asocias una acción de remediación, un documento de Systems Manager Automation, a una regla de Config, manual o automática con ajustes de reintento. Por ejemplo, cuando s3-bucket-public-read-prohibited encuentra una violación, la remediación bloquea el acceso público, o cuando falla restricted-ssh, elimina la regla abierta. Diseña la automatización con cuidado: da a cada función o runbook un rol de mínimo privilegio, prueba en entornos que no sean de producción, registra cada acción y evita ciclos en los que la remediación dispara de nuevo la misma regla. Algunas acciones, como terminar instancias de producción, conviene hacerlas con un paso de aprobación humana.

Términos clave

Step Functions
Servicio de flujos de trabajo que coordina varios pasos con reintentos, ramas y esperas, útil para respuestas de varios pasos.
Remediación automática
Función de AWS Config que ejecuta un documento de Systems Manager Automation cuando una regla encuentra un recurso no conforme.
Custom action
Función de Security Hub que envía hallazgos elegidos a EventBridge cuando un analista los selecciona.
Paso de aprobación humana
Pausa en un flujo automatizado que espera que una persona confirme una acción riesgosa.
Ejemplo real

Cuando GuardDuty informa un hallazgo de EC2 de alta severidad, EventBridge inicia un flujo de Step Functions que etiqueta y aísla la instancia, toma snapshots de sus volúmenes, publica en el canal de seguridad y espera que un analista apruebe la terminación. Mientras tanto, la remediación de Config cierra cualquier regla de security group que abra SSH a internet.

Consejo para el examen: Una acción rápida: Lambda. Varios pasos con reintentos o aprobaciones: Step Functions. Corregir una configuración no conforme: remediación de Config con un documento de Automation. Cambiar o suprimir hallazgos: automation rules de Security Hub.

Comprueba lo que sabes

¿Qué ejecuta una acción de remediación de Config?

Un documento de Systems Manager Automation, de forma manual o automática.

¿Cuándo agregarías un paso de aprobación humana a una respuesta automatizada?

En acciones de alto impacto para el negocio, como terminar recursos de producción, donde un falso positivo sería costoso.
