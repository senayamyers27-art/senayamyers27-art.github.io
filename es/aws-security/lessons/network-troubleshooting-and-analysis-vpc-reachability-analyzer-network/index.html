AWS Certified Security – Specialty SCS-C03

Diagnóstico y análisis de red: VPC Reachability Analyzer, Network Access Analyzer y Traffic Mirroring

Los problemas de seguridad de red son de dos tipos: algo que debería conectarse no se conecta, y algo que no debería conectarse sí puede. AWS tiene herramientas de análisis para ambos, y el examen espera que sepas cuál es cuál.

VPC Reachability Analyzer responde '¿puede A llegar a B y, si no, por qué?'. Eliges un origen y un destino, como una instancia, una interfaz de red, un internet gateway, un attachment de Transit Gateway o un VPC endpoint, además del protocolo y el puerto. Construye un modelo de tu configuración, tablas de rutas, security groups, network ACLs, gateways, peering y balanceadores, e informa si existe una ruta. Si no, nombra el componente que la bloquea, como una ruta faltante o una regla de network ACL. No envía ningún paquete, así que es seguro ejecutarlo en producción. Cada análisis tiene un cargo pequeño.

Network Access Analyzer responde '¿qué puede llegar a qué, que no debería?'. Defines un Network Access Scope, como 'ninguna ruta desde internet hacia las subredes de bases de datos' o 'todo el tráfico de producción hacia internet debe pasar por el firewall', y encuentra cada ruta que lo incumple. Sirve para verificar la segmentación y el cumplimiento en VPCs completas más que en una sola conexión.

VPC Traffic Mirroring copia paquetes reales desde una interfaz de red elástica a un destino, como un Network Load Balancer o una instancia con software de detección de intrusiones o de captura de paquetes. Los filtros limitan qué tráfico se copia. Úsalo para inspección profunda y análisis forense, cuando los metadatos de los flow logs no alcanzan. Junto con los flow logs, que muestran los flujos aceptados y rechazados, estas herramientas te permiten pasar de 'algo anda mal' a la regla o ruta exacta responsable.

Términos clave

Reachability Analyzer
Herramienta que analiza la configuración para mostrar si existe una ruta de red entre dos recursos y qué la bloquea.
Network Access Analyzer
Herramienta que encuentra rutas de red que incumplen un Network Access Scope definido.
Network Access Scope
Definición de qué acceso de red está permitido o no, usada por Network Access Analyzer.
Mirror filter
Reglas que eligen qué tráfico copia Traffic Mirroring.
Ejemplo real

Una aplicación no puede llegar a su base de datos después de un cambio. Reachability Analyzer muestra que la ruta está bloqueada por una regla de salida de la network ACL a la que le faltan los puertos efímeros. Más tarde, el equipo de seguridad ejecuta Network Access Analyzer para confirmar que ninguna subred de base de datos es alcanzable desde ningún internet gateway.

Consejo para el examen: Una ruta, por qué está bloqueada: Reachability Analyzer. Todas las rutas no deseadas en la red: Network Access Analyzer. Contenido real de los paquetes: Traffic Mirroring.

Comprueba lo que sabes

¿Reachability Analyzer envía tráfico de prueba?

No. Solo analiza la configuración, así que no afecta el tráfico de producción.

¿Qué herramienta usarías para demostrar que no existe ninguna ruta desde internet hacia una subred de base de datos?

Network Access Analyzer con un scope que describa ese acceso prohibido.
