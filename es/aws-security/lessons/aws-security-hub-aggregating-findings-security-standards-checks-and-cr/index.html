AWS Certified Security – Specialty SCS-C03

AWS Security Hub: agregación de hallazgos, verificación de estándares de seguridad y agregación entre regiones

AWS Security Hub te da un solo lugar para ver y gestionar hallazgos de seguridad. Recopila hallazgos de servicios de AWS como GuardDuty, Inspector, Macie, IAM Access Analyzer, Firewall Manager y Config, y de productos de socios, y los guarda en un formato común, el AWS Security Finding Format (ASFF). AWS también ha ido ampliando Security Hub para correlacionar señales y presentarlas en el Open Cybersecurity Schema Framework (OCSF), y la parte de verificación de configuración ahora se llama Security Hub CSPM (cloud security posture management). Las habilidades de abajo aplican de cualquier forma.
