CWNP Certified Wireless Network Administrator CWNA-109

Tipos de antena: omnidireccional, semidireccional (patch, panel, Yagi, sector) y altamente direccional (parabólica)

Una antena no crea potencia; enfoca la potencia que recibe en algunas direcciones a costa de otras. Elegir la forma de antena adecuada para un espacio es una habilidad central del CWNA. El examen agrupa las antenas en tres familias: omnidireccionales, semidireccionales y altamente direccionales.

Las antenas omnidireccionales irradian en todas las direcciones horizontales, con un patrón de cobertura que a menudo se describe como una dona cuando la antena se monta verticalmente. El ejemplo más sencillo es el dipolo, a menudo llamado antena rubber duck, con unos 2.14 dBi de ganancia. Las omnis de mayor ganancia aplanan más la dona: llegan más lejos horizontalmente pero cubren menos verticalmente. La mayoría de los APs empresariales para interiores tienen antenas omnidireccionales internas y se montan en el techo para cubrir el área de abajo. Un problema común de las omnis de alta ganancia montadas muy alto es la cobertura débil justo debajo de ellas.

Las antenas semidireccionales enfocan la energía en una dirección general. Las antenas patch y panel son planas y a menudo se montan en paredes para cubrir un pasillo, una sala desde un costado o una sección de asientos de un estadio. Las antenas Yagi, también llamadas Yagi-Uda, usan una fila de elementos paralelos para crear un haz más estrecho, y a menudo se usan para enlaces exteriores de corta a media distancia o para cubrir corredores largos. Las antenas de sector (sector antennas) son antenas semidireccionales de alta ganancia diseñadas para cubrir una porción específica, como 60, 90 o 120 grados; varios sectores montados espalda con espalda en una torre pueden cubrir un círculo completo con celdas separadas.

Las antenas altamente direccionales producen un haz muy estrecho con alta ganancia. La antena parabólica (parabolic dish) es el ejemplo clásico, y las antenas de rejilla (grid) son una variante más ligera que resiste la carga del viento. Se usan para puentes punto a punto de larga distancia entre edificios o sitios. Su haz estrecho hace que la alineación sea crítica; unos pocos grados de movimiento por el viento o un soporte flojo pueden romper el enlace.

Todas las antenas semidireccionales y altamente direccionales tienen lóbulos traseros (back lobes) y lóbulos laterales (side lobes), pequeñas áreas de radiación detrás y a los lados del haz principal. Esto importa cuando colocas un panel en una pared, porque algo de señal se filtrará a la sala de atrás.

Las antenas también pueden ser arreglos (arrays). Los APs modernos usan varias antenas para MIMO, y algunos usan arreglos de antenas adaptativas o inteligentes que pueden dirigir los patrones. Las opciones especializadas para interiores incluyen antenas downtilt para techos altos y el cable coaxial radiante (leaky coax) para túneles o cubos de elevador.

Al elegir, adapta la antena a la forma del área: omni para salas abiertas con un AP central, patch o panel para paredes y zonas de asientos de alta densidad, Yagi o sector para áreas exteriores específicas, y una parabólica para puentes largos.

Términos clave

Omnidirectional antenna (antena omnidireccional)
Una antena que irradia en todas las direcciones horizontales, produciendo un patrón en forma de dona.
Semi-directional antenna (antena semidireccional)
Una antena que enfoca la energía en una dirección general; incluye los tipos patch, panel, Yagi y sector.
Yagi antenna (antena Yagi)
Una antena semidireccional que usa una fila de elementos paralelos para producir un haz relativamente estrecho.
Sector antenna (antena de sector)
Una antena semidireccional diseñada para cubrir una porción horizontal definida, que a menudo se combina en una torre para cubrir 360 grados.
Parabolic dish (antena parabólica)
Una antena altamente direccional con un haz muy estrecho y alta ganancia, usada para enlaces punto a punto largos.
Ejemplo real

Una universidad cubre un auditorio con antenas patch montadas en la pared y apuntadas hacia los asientos, de modo que cada AP atiende a un bloque definido de estudiantes, mientras que la biblioteca del campus usa APs de techo con omnis internas. Dos edificios separados por un kilómetro se unen con un par de antenas parabólicas.

Consejo para el examen: Una mayor ganancia no agrega potencia; cambia la forma del patrón. Una omni de mayor ganancia llega más lejos horizontalmente pero tiene un ancho de haz vertical más estrecho, lo que puede dejar una cobertura deficiente justo debajo.

Comprueba lo que sabes

¿Qué tipo de antena elegirías para un puente largo entre edificios?

Una antena altamente direccional, como una parabólica o de rejilla (grid), por su haz estrecho y su alta ganancia.

¿Cuál es el efecto de aumentar la ganancia de una antena omnidireccional?

El patrón se aplana: el alcance horizontal aumenta mientras la cobertura vertical se reduce.

Nombra dos tipos de antena semidireccional que se usan en interiores.

Las antenas patch y panel, a menudo montadas en la pared para cubrir salas, pasillos o zonas de asientos.
