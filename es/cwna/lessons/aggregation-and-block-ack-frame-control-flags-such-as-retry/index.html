CWNP Certified Wireless Network Administrator CWNA-109

Agregación y Block Ack; flags del campo Frame Control como Retry

Toda transmisión 802.11 tiene una sobrecarga fija: interframe spaces, backoff, el preámbulo y el encabezado PHY, y un ACK. A tasas de datos altas, la carga útil ocupa tan poco tiempo que la sobrecarga domina. La agregación, introducida con 802.11n, envía varias tramas en una sola transmisión para repartir esa sobrecarga, y Block Ack las confirma de manera eficiente.

Hay dos tipos de agregación. Un A-MSDU (Aggregate MAC Service Data Unit) combina varios paquetes de capas superiores en una MPDU (MAC Protocol Data Unit) con un solo encabezado MAC y una sola frame check sequence (FCS). Tiene poca sobrecarga, pero si alguna parte se corrompe, todo el A-MSDU falla y debe reenviarse. Un A-MPDU (Aggregate MAC Protocol Data Unit) combina varias MPDUs completas, cada una con su propio encabezado MAC y su propia FCS, detrás de un solo encabezado PHY y separadas por delimitadores. Como cada subtrama se puede verificar por separado, solo es necesario retransmitir las subtramas que fallaron. A-MPDU generalmente es más resistente y se usa mucho en 802.11ac y 802.11ax; los dos métodos también se pueden combinar, con A-MSDUs dentro de un A-MPDU.

Block Ack, de 802.11e y ampliado por 802.11n, confirma muchas tramas con una sola trama Block Ack que contiene un mapa de bits, un bit por trama, que muestra cuáles se recibieron. Luego, el emisor retransmite solo las que faltan. Un acuerdo de Block Ack se establece por traffic identifier mediante las action frames ADDBA Request y ADDBA Response, y se termina con DELBA. Los A-MPDUs requieren Block Ack. La agregación también está limitada por la TXOP de QoS y por los tamaños máximos que cada lado anuncia en sus capacidades.

El campo Frame Control, los primeros dos bytes de todo encabezado MAC, contiene varios flags de un bit además del tipo y el subtipo. To DS y From DS definen el significado de las direcciones. More Fragments indica que siguen más fragmentos de la misma trama. Retry se activa cuando una trama es una retransmisión, para que el receptor pueda descartar duplicados. Power Management indica si el emisor entrará en ahorro de energía. More Data le dice a un cliente dormido que el AP tiene más tramas en búfer. Protected Frame indica que la carga útil está cifrada. El último bit, +HTC/Order, indica que hay un campo HT Control presente en las PHYs más nuevas.

El flag Retry es especialmente útil para diagnosticar problemas. Una herramienta de captura puede contar qué porcentaje de tramas tiene Retry activado. Algunas retransmisiones son normales, pero una tasa de reintentos sostenida por encima de aproximadamente el 10 por ciento suele indicar interferencia, hidden nodes, señal deficiente o co-channel contention excesiva. Muchos reintentos desperdician tiempo de aire y aumentan la latencia, lo que perjudica la voz y el video.

En Wireshark, el filtro wlan.fc.retry == 1 muestra las tramas retransmitidas, y se pueden examinar las tramas Block Ack para ver qué subtramas de un A-MPDU faltaron.

Términos clave

A-MSDU
Aggregate MSDU, varias cargas útiles en una MPDU que comparten un solo encabezado MAC y una sola FCS.
A-MPDU
Aggregate MPDU, varias MPDUs completas, cada una con su propio encabezado y FCS, enviadas en una sola transmisión PHY.
Block Ack
Una trama de control con un mapa de bits que confirma varias tramas a la vez, y que se establece con action frames ADDBA.
Retry flag (flag Retry)
Un bit del campo Frame Control que se activa en las tramas retransmitidas, y que se usa para detectar duplicados y medir tasas de reintentos.
Frame Control field (campo Frame Control)
El primer campo del encabezado MAC, que contiene la versión del protocolo, el tipo, el subtipo y flags como To DS, From DS, Retry y Protected Frame.
Ejemplo real

Una captura en un salón de clases concurrido muestra que cerca del 25 por ciento de las tramas de datos tienen el flag Retry activado, sobre todo de clientes al fondo del salón. Los mapas de bits de Block Ack muestran que las últimas subtramas de los A-MPDUs largos fallan con frecuencia. Agregar un AP para mejorar la señal y reducir el ancho de canal baja la tasa de reintentos y mejora el throughput.

Consejo para el examen: A-MSDU usa un encabezado y una FCS, así que cualquier error hace perder toda la trama; A-MPDU le da a cada subtrama su propio encabezado y FCS, así que solo se reenvían las subtramas que fallaron. El bit Retry marca las retransmisiones, y un porcentaje alto de reintentos es un indicador clave de salud.

Comprueba lo que sabes

¿Por qué A-MPDU es más resistente a los errores que A-MSDU?

Cada MPDU de un A-MPDU tiene su propia FCS, así que el receptor puede identificar y solicitar solo las subtramas corruptas, mientras que un A-MSDU tiene una sola FCS para todo el agregado.

¿Qué tramas establecen un acuerdo de Block Ack?

Las action frames ADDBA Request y ADDBA Response.

¿Qué indica el bit Retry en el campo Frame Control?

Que la trama es una retransmisión de una trama enviada anteriormente.
