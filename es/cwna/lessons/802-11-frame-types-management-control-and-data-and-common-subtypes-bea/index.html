CWNP Certified Wireless Network Administrator CWNA-109

Tipos de tramas 802.11: de administración, de control y de datos, y subtipos comunes (beacon, probe, auth, assoc, ACK, RTS/CTS, null data)

Toda transmisión 802.11 es una trama (frame), y cada trama tiene un tipo y un subtipo que se indican en el campo Frame Control al inicio del encabezado MAC. Hay tres tipos principales: management (administración), control y data (datos). Saber qué tramas pertenecen a cada tipo y qué hace cada una es esencial para leer capturas de paquetes y para el examen.

Las tramas de administración crean, mantienen y terminan la relación entre clientes y APs. Los beacons los envían periódicamente los APs, por defecto aproximadamente cada 102.4 ms (100 time units), y anuncian el SSID, las tasas soportadas, la seguridad y las capacidades. Los probe requests los envían los clientes que buscan redes, y los APs responden con probe responses. Las tramas de authentication realizan la autenticación 802.11, que en las redes modernas suele ser Open System, un intercambio simple de dos tramas. Las tramas association request y association response unen a un cliente con el AP; reassociation request y reassociation response se usan al hacer roaming. Las tramas de deauthentication y disassociation terminan la relación. Las action frames cumplen muchas funciones, como las solicitudes de 802.11k y v, la configuración de Block Ack y los anuncios de cambio de canal.

Las tramas de control ayudan a entregar otras tramas y a gestionar el acceso al medio. La trama de acknowledgment (ACK) confirma la recepción exitosa de una trama unicast; si el emisor no recibe el ACK, retransmite. Las tramas Request to Send (RTS) y Clear to Send (CTS) reservan el medio antes de una transmisión. Las tramas Block Ack Request y Block Ack confirman grupos de tramas a la vez. PS-Poll lo usan los clientes con ahorro de energía heredado para solicitar datos almacenados en búfer. 802.11ax agrega la trigger frame para programar transmisiones multiusuario de subida (uplink).

Las tramas de datos transportan la carga útil (payload) real de capas superiores, como paquetes IP. El subtipo QoS Data agrega un campo QoS Control con la prioridad de tráfico que usa WMM. Algunas tramas de datos no llevan ninguna carga útil. La null data frame, y su variante QoS Null, se usa principalmente para señalizar la administración de energía: un cliente envía una null data frame con el bit de power management activado para avisarle al AP que va a dormir, a menudo antes de escanear otro canal. Las null data frames también pueden servir como keepalives.

Las tramas broadcast y multicast no se confirman; solo las tramas unicast reciben ACK. Las tramas de administración como los beacons se envían a una tasa de datos básica (obligatoria) para que todas las estaciones puedan decodificarlas, y esa es una de las razones por las que deshabilitar las tasas de datos bajas reduce el tiempo de aire (airtime) que consumen los beacons.

En un analizador de protocolos, filtra por tipo y subtipo para encontrar estas tramas. Por ejemplo, Wireshark muestra wlan.fc.type_subtype, y puedes filtrar beacons, probe responses o ACKs para diagnosticar problemas de descubrimiento, asociación o reintentos.

Términos clave

Management frame (trama de administración)
Un tipo de trama 802.11 que se usa para descubrir, unirse, mantener y abandonar un BSS, como beacons, probes, authentication y association.
Control frame (trama de control)
Un tipo de trama 802.11 que ayuda a la entrega y al acceso al medio, como ACK, RTS, CTS y Block Ack.
Data frame (trama de datos)
Un tipo de trama 802.11 que transporta carga útil de capas superiores, incluida QoS Data; las null data frames no llevan carga útil.
Beacon
Una trama de administración que un AP envía periódicamente para anunciar el BSS y sus capacidades.
Null data frame
Una trama de datos sin carga útil, que se usa comúnmente para señalizar al AP el estado de administración de energía.
Ejemplo real

Al revisar una captura, un analista ve que un cliente envía una null data frame con el bit de power management activado, luego probe requests en otros canales y después otra null data frame con el bit desactivado. Esto muestra que el cliente le pidió al AP que almacenara su tráfico en búfer mientras salía del canal para escanear.

Consejo para el examen: Conoce el tipo de cada trama: beacons, probes, authentication, association y action frames son de administración; ACK, RTS, CTS, Block Ack y PS-Poll son de control; null data es una trama de datos aunque no lleve carga útil.

Comprueba lo que sabes

¿Una association request es una trama de administración, de control o de datos?

Una trama de administración.

¿Para qué usa normalmente un cliente una null data frame?

Para avisarle al AP que entra o sale del modo de ahorro de energía, por ejemplo antes de escanear fuera del canal.

¿Se confirman las tramas broadcast en 802.11?

No. Solo las tramas unicast reciben ACK.
