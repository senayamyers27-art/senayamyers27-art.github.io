Lecciones de Azure Fundamentals AZ-900

  • Qué es la computación en la nube y el modelo de responsabilidad compartida en on-premises, IaaS, PaaS y SaaS
  • Modelos de nube: nube pública, privada e híbrida, además de multicloud y el lugar de Azure Arc
  • El modelo basado en el consumo y el precio de pago por uso frente a comprar hardware
  • Gasto de capital (CapEx) frente a gasto operativo (OpEx) y cómo la nube cambia el gasto
  • Alta disponibilidad, acuerdos de nivel de servicio (SLA) y disponibilidad compuesta
  • Escalabilidad y elasticidad: escalado vertical frente a horizontal, manual frente a automático
  • Confiabilidad y previsibilidad del rendimiento y del costo en la nube
  • Beneficios de seguridad, gobernanza y administración de la nube (administración de la nube frente a en la nube)
  • Infraestructura como servicio (IaaS): qué administras y casos de uso típicos como lift-and-shift
  • Plataforma como servicio (PaaS) y serverless: qué administra el proveedor y casos de uso típicos
  • Software como servicio (SaaS) y cómo elegir entre IaaS, PaaS y SaaS para un escenario
  • Regiones de Azure, pares de regiones y regiones soberanas (Azure Government, Azure operado por 21Vianet en China)
  • Zonas de disponibilidad y datacenters: servicios zonales frente a redundantes entre zonas
  • Recursos, grupos de recursos, suscripciones y grupos de administración de Azure: la jerarquía y para qué sirve cada uno
  • Cómputo: máquinas virtuales, VM scale sets, availability sets y Azure Virtual Desktop
  • Contenedores y cómputo serverless: Container Instances, Container Apps, AKS, Azure Functions y App Service
  • Redes virtuales, subredes, peering, Azure DNS y endpoints públicos frente a privados
  • Conectividad híbrida: VPN Gateway (site-to-site, point-to-site) frente a ExpressRoute
  • Servicios de Azure Storage (Blob, Files, Queue, Table, Disks), tipos de cuenta de almacenamiento y niveles de acceso (Hot, Cool, Cold, Archive)
  • Redundancia de almacenamiento: LRS, ZRS, GRS, GZRS y opciones de lectura en la región secundaria
  • Mover datos y migrar: AzCopy, Storage Explorer, Azure File Sync, Azure Migrate y Azure Data Box
  • Microsoft Entra ID y Entra Domain Services; métodos de autenticación: SSO, MFA y sin contraseña
  • Identidades externas (B2B e identidad de clientes) y acceso condicional
  • Control de acceso basado en roles de Azure (RBAC), Zero Trust, defensa en profundidad y Microsoft Defender for Cloud
  • Factores que afectan el costo en Azure: tipo de recurso, consumo, región, ancho de banda, reservas y Azure Hybrid Benefit
  • La Pricing Calculator frente a la calculadora del costo total de propiedad (TCO Calculator)
  • Microsoft Cost Management: análisis de costos, presupuestos y alertas, y uso de etiquetas para seguir el gasto
  • Microsoft Purview para la gobernanza de datos y el Service Trust Portal para los informes de cumplimiento
  • Azure Policy: definiciones, iniciativas, asignaciones y cumplimiento
  • Bloqueos de recursos: CanNotDelete frente a ReadOnly y cómo se heredan
  • Herramientas para interactuar con Azure: el portal, Azure Cloud Shell, Azure CLI y Azure PowerShell
  • Azure Arc para administrar recursos on-premises y multicloud
  • Azure Resource Manager e infraestructura como código con plantillas ARM y Bicep
  • Recomendaciones de Azure Advisor y Azure Service Health (Azure status, Service Health, Resource Health)
  • Azure Monitor: métricas, Log Analytics, alertas y Application Insights
