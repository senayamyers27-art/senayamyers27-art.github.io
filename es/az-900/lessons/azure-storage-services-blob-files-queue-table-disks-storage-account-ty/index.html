Microsoft Certified: Azure Fundamentals AZ-900

Servicios de Azure Storage (Blob, Files, Queue, Table, Disks), tipos de cuenta de almacenamiento y niveles de acceso (Hot, Cool, Cold, Archive)

Azure Storage es la plataforma de almacenamiento en la nube de Microsoft para casi cualquier tipo de dato que produce una aplicación: documentos, imágenes, copias de seguridad, mensajes, registros estructurados y los discos duros virtuales que están detrás de las máquinas virtuales (VM). Es durable (siempre se mantienen varias copias), de alta disponibilidad, segura de manera predeterminada (los datos se cifran en reposo automáticamente) y enormemente escalable, y pagas solo por la capacidad y las operaciones que usas. La mayoría de los servicios de almacenamiento viven dentro de una cuenta de almacenamiento, que le da a tus datos un espacio de nombres único accesible por HTTP o HTTPS. Como el nombre de la cuenta forma parte de las direcciones de los endpoints públicos, como mystorage.blob.core.windows.net, debe ser único en todo Azure, tener entre 3 y 24 caracteres y usar solo letras minúsculas y números.
