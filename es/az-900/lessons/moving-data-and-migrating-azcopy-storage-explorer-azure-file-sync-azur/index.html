Mover datos y migrar: AzCopy, Storage Explorer, Azure File Sync, Azure Migrate y Azure Data Box

Llevar datos y cargas de trabajo a Azure suele ser el primer proyecto real que una organización ejecuta en la nube. Azure ofrece distintas herramientas según cuántos datos haya, con qué frecuencia se mueven, si quieres una línea de comandos o una herramienta gráfica y si estás moviendo archivos o servidores completos. El examen te da un escenario breve y espera que elijas la herramienta adecuada, así que ayuda conocer la pista que apunta a cada una. AzCopy es una utilidad de línea de comandos para copiar blobs o archivos hacia o desde una cuenta de almacenamiento, y entre cuentas de almacenamiento. Se ejecuta en Windows, macOS y Linux, se puede automatizar con scripts para trabajos repetidos y se autentica con Microsoft Entra ID o con una firma de acceso compartido (SAS), una URL firmada que concede acceso limitado. azcopy copy realiza copias, mientras que azcopy sync sincroniza en una sola dirección, haciendo que el destino coincida con el origen.
