Herramientas para interactuar con Azure: el portal, Azure Cloud Shell, Azure CLI y Azure PowerShell

Puedes administrar Azure mediante varias herramientas. Todas envían solicitudes al mismo lugar, Azure Resource Manager, así que todo lo que creas con una herramienta se puede ver y administrar con cualquier otra, y se aplican los mismos permisos RBAC, directivas y bloqueos. La elección depende de la tarea, de si necesitas repetirla y del lenguaje con el que te sientas cómodo. El examen espera que sepas qué es cada herramienta y que reconozcas un comando de cada una. El portal de Azure es una consola web unificada. Inicias sesión desde un navegador y creas, configuras y supervisas los recursos mediante menús, formularios y hojas (blades); creas y compartes paneles personalizados; y ves los costos, las alertas y el estado. Es ideal para aprender, explorar, tareas puntuales y ver las cosas de forma visual, y tiene buenas funciones de accesibilidad. Es menos adecuado para repetir una tarea muchas veces, porque recorrer formularios a mano es lento y es fácil equivocarse ligeramente cada vez. Microsoft también ofrece la aplicación móvil de Azure para supervisar recursos, revisar alertas y ejecutar acciones rápidas desde un teléfono.

Azure Cloud Shell es un shell basado en el navegador que abres desde el ícono de la barra de herramientas del portal o directamente en un navegador. Te permite elegir entre Bash o PowerShell, ya está autenticado con tu cuenta de Azure y tiene preinstalados Azure CLI, Azure PowerShell, editores de texto, Git y otras herramientas comunes, así que no hay nada que instalar ni actualizar en tu propia computadora. Cloud Shell puede montar un recurso compartido de Azure Files para conservar tus scripts y archivos entre sesiones, o ejecutarse como una sesión efímera sin almacenamiento. Es adecuado para administradores que trabajan desde distintas computadoras o desde máquinas restringidas donde no pueden instalar software.

Azure CLI es una herramienta de línea de comandos multiplataforma que se ejecuta en Windows, macOS y Linux. Sus comandos empiezan con az, seguido de un grupo y una acción, y es popular entre quienes usan Bash y para crear scripts. Azure PowerShell es un conjunto de módulos, conocido como el módulo Az, que agrega a PowerShell cmdlets para administrar Azure. Los cmdlets siguen un patrón Verbo-Sustantivo con Az en el sustantivo, y es popular entre los administradores de Windows, aunque PowerShell también se ejecuta en macOS y Linux. Las mismas tareas se ven así en cada herramienta:

# Azure CLI
az login
az group create --name rg-demo --location eastus
az vm list --output table

# Azure PowerShell
Connect-AzAccount
New-AzResourceGroup -Name rg-demo -Location eastus
Get-AzVM

Azure CLI y Azure PowerShell pueden hacer básicamente las mismas cosas; la elección depende sobre todo del lenguaje y las habilidades de tu equipo. Ambos se pueden usar de forma interactiva, escribiendo un comando a la vez, o en scripts que automatizan una secuencia de pasos, y ambos están disponibles dentro de Cloud Shell y se pueden instalar localmente. Para implementaciones repetibles de entornos completos irías más allá, a la infraestructura como código con plantillas ARM o Bicep, que se cubre en una lección posterior. Una regla práctica útil: usa el portal para aprender y explorar, y luego convierte en un script de CLI o PowerShell todo lo que vayas a hacer más de una vez.

Considera un ejemplo práctico. Una nueva administradora explora Azure creando una cuenta de almacenamiento en el portal, lo que le ayuda a ver todas las opciones. La semana siguiente debe crear el mismo grupo de recursos, la misma red y tres VM en cada una de cinco regiones. Hacerlo a mano tomaría horas y se prestaría a errores de escritura, así que escribe un script de Azure CLI y lo ejecuta desde Cloud Shell en una laptop prestada donde no puede instalar nada. Su colega, que tiene años de experiencia con PowerShell, escribe el equivalente con cmdlets New-AzVM. Ambos enfoques producen los mismos recursos porque ambos pasan por Resource Manager.

Errores comunes: pensar que Cloud Shell es un lenguaje aparte (es un entorno hospedado donde ejecutas Bash con Azure CLI o PowerShell con el módulo Az); creer que Azure CLI solo se ejecuta en Linux o PowerShell solo en Windows (ambos son multiplataforma); y suponer que el portal no puede automatizar nada (puede, pero los scripts son más adecuados para la repetición).

Redacción del examen: un comando que empieza con az es Azure CLI; un cmdlet Verbo-AzSustantivo como Get-AzVM es Azure PowerShell; 'interfaz gráfica' o 'paneles' apunta al portal; 'sin instalación local' o 'línea de comandos basada en el navegador' apunta a Cloud Shell; 'automatizar tareas repetitivas' apunta a scripts de CLI o PowerShell.

Términos clave

Portal de Azure (Azure portal)
Una consola gráfica web para crear, administrar y supervisar recursos de Azure.
Azure Cloud Shell
Un shell basado en el navegador y ya autenticado que ofrece Bash o PowerShell con las herramientas de Azure preinstaladas.
Azure CLI
Una herramienta de línea de comandos multiplataforma para Azure cuyos comandos empiezan con az.
Azure PowerShell
El módulo Az de PowerShell que proporciona cmdlets Verbo-AzSustantivo para administrar Azure.
Cmdlet
Un comando de PowerShell que sigue un patrón Verbo-Sustantivo, como Get-AzVM.
Aplicación móvil de Azure (Azure mobile app)
Una aplicación de teléfono para supervisar recursos de Azure y ejecutar acciones rápidas.
Azure Resource Manager
La capa de administración a través de la cual todas las herramientas de Azure envían sus solicitudes.
Ejemplo real

Una consultora visita a un cliente cuyas laptops bloquean la instalación de software. Necesita enumerar todas las VM y reiniciar dos de ellas. Desde el navegador del cliente abre Azure Cloud Shell, que ya tiene la sesión iniciada, elige Bash y ejecuta az vm list --output table seguido de az vm restart. No se instaló nada localmente, y sus scripts guardados en el recurso compartido de archivos de Cloud Shell estarán allí la próxima vez.

Consejo para el examen: Los comandos que empiezan con az son Azure CLI; los cmdlets Verbo-AzSustantivo como Get-AzVM son Azure PowerShell. Cloud Shell no necesita instalación local y admite tanto Bash como PowerShell. Todas las herramientas pasan por Azure Resource Manager.

Comprueba lo que sabes

¿A qué herramienta pertenece el comando New-AzResourceGroup?

A Azure PowerShell, porque es un cmdlet Verbo-AzSustantivo del módulo Az.

Una administradora debe administrar Azure desde una computadora donde no puede instalar software. ¿Qué herramienta encaja?

Azure Cloud Shell, que se ejecuta en el navegador con la CLI y PowerShell preinstalados.

¿Los recursos creados en el portal se pueden administrar después con Azure CLI?

Sí. Todas las herramientas pasan por Azure Resource Manager, así que los recursos son los mismos sin importar la herramienta.

¿Qué shells puedes elegir en Azure Cloud Shell?

Bash o PowerShell.
