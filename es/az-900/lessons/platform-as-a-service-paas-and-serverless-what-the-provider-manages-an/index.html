Plataforma como servicio (PaaS) y serverless: qué administra el proveedor y casos de uso típicos

La plataforma como servicio (PaaS) es un punto intermedio entre la infraestructura como servicio (IaaS) y el software como servicio (SaaS). El proveedor administra la infraestructura física y también el sistema operativo, el middleware, el runtime y las herramientas de desarrollo. Tú aportas el código de tu aplicación y tus datos, y configuras cómo se ejecuta el servicio. No inicias sesión en servidores ni les instalas actualizaciones. El objetivo de PaaS es permitir que los desarrolladores dediquen su tiempo a la aplicación y no a las máquinas que están debajo.
