ISACA Certified Information Systems Auditor (CISA) 2024 job practice

Pruebas y muestreo de auditoría: pruebas de cumplimiento frente a sustantivas, muestreo estadístico y no estadístico

Los auditores rara vez prueban todos los elementos, así que necesitan saber qué tipo de prueba responde su pregunta y cómo elegir una muestra que puedan defender. El examen evalúa ambas ideas con frecuencia.

Una prueba de cumplimiento (o prueba de controles) verifica si un control opera como fue diseñado, por ejemplo si los cambios de la muestra tuvieron aprobación antes del despliegue. Una prueba sustantiva revisa los datos en sí buscando errores, como recalcular intereses o confirmar saldos. Ambas están relacionadas: cuando las pruebas de cumplimiento muestran controles sólidos, se necesitan menos pruebas sustantivas; cuando los controles son débiles, el auditor amplía las pruebas sustantivas para saber si realmente ocurrieron errores.

El muestreo puede ser estadístico o no estadístico. El estadístico usa selección aleatoria o sistemática y cálculos de probabilidad para que el auditor pueda indicar un nivel de confianza y proyectar resultados a la población. El no estadístico (de juicio) depende del criterio del auditor, por ejemplo elegir todos los elementos de alto valor; es más rápido, pero no mide el riesgo de muestreo de forma objetiva. El muestreo por atributos estima una tasa de ocurrencia, útil para pruebas de cumplimiento. El muestreo de variables estima una cantidad, como un monto, útil para pruebas sustantivas; el muestreo por unidad monetaria es una forma común. El muestreo stop-or-go permite detenerse pronto si aparecen pocos errores, y el muestreo de descubrimiento se usa para encontrar al menos un caso de un evento raro, como un fraude.

Hay términos clave frecuentes. El coeficiente de confianza es qué tan seguro quieres estar; más confianza exige una muestra más grande. La tasa de error tolerable es la tasa máxima aceptable; una tasa tolerable menor exige una muestra más grande. La tasa de error esperada también importa: esperar más errores requiere más muestras. La estratificación divide la población en grupos, por ejemplo por monto, para muestrear cada uno de forma adecuada.

Términos clave

Prueba de cumplimiento
Una prueba de si un control opera como fue diseñado, como verificar aprobaciones en una muestra de cambios.
Prueba sustantiva
Una prueba de los datos o transacciones en sí para detectar errores.
Muestreo por atributos
Un método que estima la tasa con que aparece una característica, como una falla de control, en una población.
Tasa de error tolerable
La tasa máxima de desviación que el auditor acepta sin dejar de confiar en el control.
Ejemplo real

Una auditora elige al azar 40 solicitudes de acceso de un año con 3,000 y verifica en cada una la aprobación del gerente. Dos no la tienen, lo que da una tasa de desviación del 5% frente a una tasa tolerable del 3%, así que concluye que el control no es confiable y amplía las pruebas sustantivas de los accesos reales.

Consejo para el examen: Ajusta el método a la pregunta: muestreo por atributos para saber con qué frecuencia falla un control, muestreo de variables o por unidad monetaria para saber cuánto dinero está mal, y muestreo de descubrimiento para demostrar que existe un evento raro.

Comprueba lo que sabes

¿Qué pasa con el tamaño de la muestra si el auditor quiere más confianza?

Aumenta; una mayor confianza requiere una muestra más grande.

Si las pruebas de cumplimiento muestran que un control es débil, ¿qué debe hacer el auditor?

Aumentar las pruebas sustantivas para determinar si realmente ocurrieron errores.
