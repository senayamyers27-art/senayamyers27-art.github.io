Prevención de pérdida de datos y cifrado de datos

Los datos pueden salir de una organización por error o a propósito: un correo a la persona equivocada, un archivo subido a una nube personal, una laptop perdida o un robo deliberado. La prevención de pérdida de datos (DLP) y el cifrado son dos defensas técnicas principales.

Las herramientas de DLP identifican datos sensibles mediante patrones (como números de tarjeta), palabras clave, huellas de documentos específicos o etiquetas de clasificación, y luego los monitorean o bloquean. La DLP de red inspecciona el tráfico, como el correo y las cargas web; la DLP de endpoint controla acciones en los equipos, como copiar a memorias USB; y la DLP de nube revisa los servicios en la nube. La DLP depende de la clasificación de datos y necesita ajuste para evitar falsos positivos. Muchas implementaciones empiezan en modo de solo monitoreo, lo cual es razonable para ajustarla, pero una herramienta de DLP cuyas alertas nadie revisa ofrece poca protección real.

El cifrado convierte los datos legibles en texto cifrado que solo pueden leer quienes tienen la clave. El cifrado simétrico, como AES, usa una sola clave compartida y es rápido, así que se usa para grandes volúmenes de datos. El cifrado asimétrico, como RSA o curva elíptica, usa un par de claves pública y privada y se usa para intercambiar claves y para firmas digitales. Los datos en reposo se protegen con cifrado de disco completo, de base de datos o de archivos; los datos en tránsito, con protocolos como TLS y VPN. El hash es una función de un solo sentido que prueba integridad, pero no es cifrado.

El cifrado es tan fuerte como la gestión de claves: generarlas de forma segura, guardarlas separadas de los datos (por ejemplo en un módulo de seguridad de hardware o un servicio de gestión de claves), controlar el acceso, rotarlas y destruirlas de forma segura al final de su vida. El auditor verifica que los datos sensibles se cifren según la política, que los algoritmos y longitudes de clave estén vigentes y que las claves se gestionen y protejan.

Términos clave

Prevención de pérdida de datos (DLP)
Herramientas y procesos que detectan y evitan la transmisión o el almacenamiento no autorizados de datos sensibles.
Cifrado simétrico
Cifrado que usa la misma clave secreta para cifrar y descifrar.
Gestión de claves
Controles sobre la generación, el almacenamiento, la distribución, la rotación y la destrucción de claves criptográficas.
Módulo de seguridad de hardware (HSM)
Un dispositivo resistente a manipulaciones que genera, guarda y usa claves criptográficas de forma segura.
Ejemplo real

Una auditora encuentra una base de datos de clientes cifrada, pero la clave de cifrado está en un archivo de configuración en el mismo servidor, legible por los administradores de la aplicación. Reporta que el cifrado da poca protección y recomienda mover las claves a un servicio de gestión de claves con acceso restringido.

Consejo para el examen: El cifrado vale lo que vale su gestión de claves. Una clave guardada junto a los datos que protege es un hallazgo común.

Comprueba lo que sabes

¿Por qué la DLP depende de la clasificación de datos?

La herramienta necesita saber qué datos son sensibles para poder reconocerlos y protegerlos.

¿Qué tipo de cifrado se usa normalmente para grandes volúmenes de datos y por qué?

El cifrado simétrico, porque es mucho más rápido que el asimétrico.
