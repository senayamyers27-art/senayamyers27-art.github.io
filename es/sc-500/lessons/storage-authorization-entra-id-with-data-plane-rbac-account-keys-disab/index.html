Microsoft Certified: Cloud and AI Security Engineer Associate (replaces Azure Security Engineer Associate / AZ-500) SC-500

Autorización de Storage: Entra ID con RBAC del plano de datos, claves de cuenta, deshabilitar Shared Key, rotación de claves

Toda solicitud para leer o escribir datos en Azure Storage (blobs, archivos, colas, tablas) debe estar autorizada. Hay varias formas, y el examen quiere que sepas ordenarlas. La más sólida es la autorización con Microsoft Entra ID: quien llama presenta un token OAuth 2.0 de un usuario, grupo, service principal o identidad administrada, y Azure comprueba sus roles de RBAC del plano de datos. No existe un secreto compartido que pueda filtrarse, el acceso está ligado a la identidad y puede revocarse, y cada solicitud es atribuible en los registros.
