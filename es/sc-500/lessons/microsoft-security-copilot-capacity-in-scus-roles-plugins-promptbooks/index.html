Microsoft Certified: Cloud and AI Security Engineer Associate (replaces Azure Security Engineer Associate / AZ-500) SC-500

Microsoft Security Copilot: capacidad en SCU, roles, plugins, promptbooks, experiencias independiente vs integrada y agentes

Microsoft Security Copilot es un asistente de IA generativa para equipos de seguridad y de TI. Permite a los analistas hacer preguntas en lenguaje natural, como 'resume este incidente', 'explica qué hace este script de PowerShell' o 'escribe una consulta KQL para inicios de sesión desde países nuevos', y responde usando un modelo de lenguaje grande fundamentado en datos de los productos de seguridad de Microsoft y de otras fuentes conectadas. Respeta el propio acceso del usuario: solo puede recuperar los datos que el usuario tiene permiso de ver en los productos subyacentes.

La capacidad se mide en Security Compute Units (SCU). Una organización aprovisiona SCU, que determinan cuánto procesamiento puede realizar Security Copilot. La capacidad aprovisionada se compra como una cantidad fija de SCU por hora, y se pueden permitir unidades de excedente (overage) para manejar picos; algunos clientes de Microsoft 365 E5 reciben una asignación incluida. La supervisión del uso en el portal muestra el consumo por usuario, plugin y experiencia, lo que ayuda a dimensionar la capacidad. Como los precios y las condiciones de inclusión cambian, consulta los detalles actuales en lugar de memorizar cifras.

El acceso se controla con los roles de Security Copilot. Los propietarios de Copilot (Copilot owners) administran la configuración, la capacidad, los plugins y el uso compartido de datos. Los colaboradores de Copilot (Copilot contributors) pueden crear sesiones y usar las funciones. Los roles de Microsoft Entra como Global Administrator y Security Administrator se asignan de forma predeterminada al acceso de propietario, y puedes asignar el rol de colaborador a grupos o a todos. Además, los permisos de cada producto subyacente siguen aplicándose, así que un colaborador sin acceso a los incidentes de Defender XDR no puede recuperarlos.

Los plugins conectan Security Copilot con fuentes de datos y habilidades. Los plugins de Microsoft incluyen Microsoft Defender XDR, Microsoft Sentinel, Microsoft Entra, Microsoft Intune, Microsoft Purview, Defender for Cloud y Defender Threat Intelligence. Los plugins que no son de Microsoft se conectan con herramientas de seguridad de terceros, y pueden crearse plugins personalizados usando definiciones de KQL, API o de tipo GPT. Los propietarios deciden qué plugins están disponibles y si los usuarios pueden agregar los suyos.

Los promptbooks son secuencias guardadas de prompts que se ejecutan juntas para completar una tarea común, como una investigación de incidentes, el perfil de un actor de amenazas o una evaluación del impacto de una vulnerabilidad. Pueden recibir entradas (por ejemplo, un número de incidente), se pueden compartir en toda la organización y dan resultados coherentes. Puedes crear los tuyos a partir de una sesión.

Hay dos formas de usarlo. La experiencia independiente (standalone) es el portal de Security Copilot, donde los usuarios inician sesiones, fijan resultados en un tablero (pinboard), ejecutan promptbooks y combinan datos de varios plugins. Las experiencias integradas (embedded) aparecen dentro de otros productos: en el portal de Defender como resúmenes de incidentes, respuestas guiadas y análisis de scripts; en Entra para explicaciones de inicios de sesión y usuarios riesgosos; en Intune, Purview y Defender for Cloud. Ambas consumen la misma capacidad de SCU.

Los agentes de Security Copilot amplían esto con el manejo autónomo o semiautónomo de tareas, como clasificar los informes de phishing enviados por los usuarios, priorizar alertas o sugerir mejoras en las directivas de Conditional Access. Los agentes se ejecutan con su propia identidad y sus propios permisos, operan dentro de las barreras de protección definidas por los administradores, pueden aprender de los comentarios de los analistas y deben gobernarse como cualquier otra automatización con privilegios.

Términos clave

Security Compute Unit
La unidad de capacidad aprovisionada que determina cuánto procesamiento puede realizar Security Copilot.
Copilot owner (propietario de Copilot)
El rol de Security Copilot que administra la configuración, los plugins y la capacidad.
Plugin
Un conector que proporciona a Security Copilot datos y habilidades de un producto de Microsoft o de terceros.
Promptbook
Una secuencia guardada y reutilizable de prompts para una tarea de seguridad común.
Embedded experience (experiencia integrada)
Funciones de Security Copilot que aparecen dentro de productos como Defender XDR, Entra o Intune.
Ejemplo real

Un SOC pequeño aprovisiona unas cuantas SCU, da al grupo de analistas el rol de colaborador de Copilot, habilita los plugins de Defender XDR, Sentinel y Entra, y crea un promptbook que recibe un ID de incidente, lo resume, enumera los usuarios y dispositivos afectados y redacta un informe para la dirección. Los analistas también usan el resumen de incidentes integrado directamente en el portal de Defender.

Consejo para el examen: Copilot no omite los permisos: un usuario solo ve los datos a los que ya tiene acceso. La capacidad son las SCU, compartidas por el uso independiente y el integrado. Los propietarios administran los plugins y la configuración; los colaboradores lo usan. Los prompts reutilizables de varios pasos son promptbooks.

Comprueba lo que sabes

¿Qué ocurre cuando un analista le pregunta a Security Copilot por incidentes a los que no puede acceder en Defender XDR?

Copilot no puede recuperarlos, porque usa los propios permisos del usuario en los productos subyacentes.

¿Cuál es la diferencia entre las experiencias independiente e integrada?

La independiente es el portal dedicado de Security Copilot con sesiones y promptbooks; la integrada muestra Copilot dentro de productos como Defender, Entra e Intune.

¿Qué rol de Security Copilot puede activar o desactivar los plugins para la organización?

El rol de propietario de Copilot (Copilot owner).
