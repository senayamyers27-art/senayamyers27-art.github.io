Web Application Firewall en Application Gateway y Front Door, DDoS Protection

Un firewall de aplicaciones web (web application firewall, WAF) inspecciona las solicitudes HTTP y HTTPS en la capa 7 y bloquea ataques web comunes como la inyección SQL, el cross-site scripting, la inclusión remota de archivos y las violaciones de protocolo. Complementa, pero no reemplaza, la programación segura. Azure Web Application Firewall puede ejecutarse en dos lugares. En Azure Application Gateway, un balanceador de carga regional de capa 7, protege aplicaciones en una región, normalmente dentro de una red virtual o delante de ella. En Azure Front Door, un servicio perimetral global con puntos de entrada anycast, filtra el tráfico en el perímetro de Microsoft antes de que llegue a tus orígenes, lo cual encaja con aplicaciones globales y detiene el tráfico malicioso cerca de su origen.
