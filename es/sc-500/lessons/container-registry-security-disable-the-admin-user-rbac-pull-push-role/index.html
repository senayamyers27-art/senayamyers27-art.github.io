Seguridad del registro de contenedores: deshabilitar el usuario administrador, roles RBAC de pull/push, private endpoints, análisis de vulnerabilidades de imágenes

Azure Container Registry (ACR) almacena las imágenes de contenedor que ejecutan AKS, App Service, Container Apps y otros servicios. Si un atacante puede hacer push a tu registro, puede plantar una imagen maliciosa que tus clústeres desplegarán sin problema; si puede hacer pull, puede encontrar secretos o código propietario dentro de las imágenes. Por eso la seguridad del registro forma parte de la cadena de suministro de software.
