Defender for Cloud: CSPM básica vs Defender CSPM, puntuación de seguridad y recomendaciones

Microsoft Defender for Cloud es una plataforma de protección de aplicaciones nativas de la nube (CNAPP). Combina la administración de la postura de seguridad en la nube (CSPM), que encuentra debilidades en la configuración, con los planes de protección de cargas de trabajo en la nube (CWP), que detectan amenazas contra las cargas de trabajo en ejecución. Cubre Azure, AWS, GCP y máquinas locales mediante Azure Arc.

Foundational CSPM (CSPM básica) es gratuita y se activa automáticamente en cada suscripción de Azure que abre Defender for Cloud. Evalúa continuamente los recursos frente al Microsoft cloud security benchmark (MCSB), genera recomendaciones de seguridad, calcula la puntuación de seguridad (secure score), proporciona un inventario de activos, muestra la postura multinube básica mediante conectores e incluye el panel de cumplimiento normativo para el MCSB. Defender CSPM es el plan de pago que agrega capacidades avanzadas: análisis de rutas de ataque, el cloud security explorer, análisis sin agente para máquinas y contenedores, el grafo de seguridad y la priorización por riesgo, reglas de gobernanza, postura consciente de los datos (descubrimiento de datos confidenciales), postura de seguridad de IA, información contextual del código a la nube (DevOps) y estándares normativos adicionales.

Una recomendación describe un problema y cómo corregirlo, por ejemplo 'Storage accounts should restrict network access using virtual network rules' o 'MFA should be enabled on accounts with owner permissions on your subscription'. Cada una muestra los recursos afectados, la gravedad, los pasos de corrección, a veces un botón Fix que corrige automáticamente y una opción Deny o Enforce que crea una Azure Policy para evitar que se repita. Las recomendaciones están respaldadas por definiciones de Azure Policy de la iniciativa MCSB asignada a cada suscripción. Puedes eximir un recurso de una recomendación (waiver o mitigated), lo que también lo saca de los cálculos de la puntuación de seguridad. Con Defender CSPM, las recomendaciones reciben un nivel de riesgo que considera la posibilidad de explotación, la exposición a internet y los datos confidenciales, lo que te ayuda a corregir primero lo más riesgoso.

La puntuación de seguridad (secure score) es un porcentaje que resume tu postura. Las recomendaciones se agrupan en controles de seguridad (como 'Enable MFA' o 'Secure management ports'), cada uno con un valor en puntos. Solo obtienes todos los puntos de un control cuando todos sus recursos están en buen estado; las correcciones parciales obtienen un crédito parcial proporcional. La puntuación se muestra por suscripción, por grupo de administración y en total. Mejorar la puntuación de seguridad es un buen indicador de la reducción del riesgo, pero no es un certificado de cumplimiento.

Operaciones útiles: filtrar las recomendaciones por gravedad o tipo de recurso, asignar propietarios y fechas límite (gobernanza, en Defender CSPM), exportar continuamente las recomendaciones y la puntuación de seguridad a Log Analytics o Event Hubs con la exportación continua (continuous export), y usar consultas de Azure Resource Graph para informar en todas las suscripciones. El ámbito de grupo de administración te permite ver la postura de toda la organización.

Términos clave

CSPM
Cloud security posture management (administración de la postura de seguridad en la nube): evaluación continua de la configuración frente a las buenas prácticas.
Foundational CSPM (CSPM básica)
El nivel gratuito de Defender for Cloud que proporciona recomendaciones, puntuación de seguridad, inventario y cumplimiento con el MCSB.
Defender CSPM
El plan de postura de pago que agrega rutas de ataque, cloud security explorer, análisis sin agente, gobernanza y postura consciente de los datos.
Secure score (puntuación de seguridad)
Un porcentaje basado en controles de seguridad, que se obtiene cuando todos los recursos de un control están en buen estado.
Security control (control de seguridad)
Un grupo de recomendaciones relacionadas cuyos puntos cuentan para la puntuación de seguridad.
Ejemplo real

Un nuevo CISO quiere una sola métrica de postura para 60 suscripciones. Abres Defender for Cloud en el grupo de administración raíz del tenant, revisas la puntuación de seguridad, ordenas los controles de seguridad por el aumento potencial de puntuación, corriges primero 'Enable MFA' y configuras la exportación continua de recomendaciones a un área de trabajo de Log Analytics para paneles de tendencias.

Consejo para el examen: El nivel gratuito da recomendaciones, puntuación de seguridad y cumplimiento con el MCSB; el análisis de rutas de ataque, el cloud security explorer, las reglas de gobernanza y el análisis sin agente requieren Defender CSPM. Todos los puntos de un control solo llegan cuando cada recurso afectado está en buen estado.

Comprueba lo que sabes

¿Qué nivel de Defender for Cloud está habilitado sin costo de forma predeterminada?

Foundational CSPM.

¿Por qué corregir 9 de 10 recursos de un control podría no darte todos sus puntos?

Todos los puntos requieren que todos los recursos del control estén en buen estado; la corrección parcial solo obtiene un crédito proporcional.

¿Qué pasa con la puntuación de seguridad cuando eximes un recurso de una recomendación?

El recurso eximido deja de contarse, así que no reduce la puntuación.
