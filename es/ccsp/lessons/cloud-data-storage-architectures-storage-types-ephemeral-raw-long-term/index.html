Arquitecturas de almacenamiento de datos en la nube: tipos de almacenamiento (efímero, en bruto, de largo plazo, de objetos, de volumen, de base de datos) y amenazas al almacenamiento

Los distintos tipos de almacenamiento en la nube se comportan de manera diferente, y cada uno necesita controles distintos. El examen CCSP usa el vocabulario de los tipos de almacenamiento, así que aprende qué es cada uno y qué puede fallar.

El almacenamiento efímero es espacio temporal conectado a una instancia en ejecución; desaparece cuando la instancia se detiene, así que nunca debe tener la única copia de datos importantes, y no se debe suponer que los restos sensibles se borran a menos que el proveedor lo indique. El almacenamiento en bruto (raw device mapping) da a una máquina virtual acceso directo a un dispositivo de almacenamiento físico, sin pasar por el sistema de archivos de la capa de virtualización. El almacenamiento de volumen (almacenamiento en bloques) presenta un disco virtual conectado a una instancia y formateado con un sistema de archivos, muy parecido a un disco duro. El almacenamiento de objetos guarda archivos como objetos con metadatos en contenedores planos llamados buckets, a los que se accede mediante API web; es barato y escalable, y también es el tipo de almacenamiento que más a menudo queda expuesto por configuraciones de acceso público accidentales. El almacenamiento de bases de datos abarca bases de datos relacionales y no relacionales administradas en PaaS. El almacenamiento de largo plazo está diseñado para archivos y respaldos: muy barato, durable y lento para recuperar, lo que encaja con los requisitos de retención.

Los modelos de servicio también determinan el almacenamiento. Los clientes de IaaS ven principalmente almacenamiento de volumen y de objetos. PaaS agrega almacenamiento estructurado (bases de datos) y no estructurado (big data y servicios de archivos). Los clientes de SaaS ven el almacenamiento y la gestión de información dentro de la aplicación y el almacenamiento de contenido y archivos para documentos.

Las amenazas al almacenamiento incluyen el acceso no autorizado por permisos débiles o llaves filtradas, la exposición pública por mala configuración, la pérdida de disponibilidad durante caídas, el borrado accidental, el ransomware que cifra o elimina datos, los restos de datos en medios compartidos, la exposición jurisdiccional cuando los datos terminan en la región equivocada y la manipulación. Las contramedidas estándar son políticas de acceso de mínimo privilegio, bloquear el acceso público por defecto, cifrado con llaves bien gestionadas, versionado y respaldos inmutables, replicación, registro de accesos y escaneos regulares de configuración.

Términos clave

Almacenamiento efímero
Almacenamiento temporal ligado a la vida de una instancia que se pierde cuando la instancia se detiene o se termina.
Almacenamiento de objetos
Almacenamiento que guarda los datos como objetos con metadatos en buckets, a los que se accede mediante API y no mediante un sistema de archivos.
Almacenamiento de volumen
Almacenamiento en bloques que se presenta a una máquina virtual como un disco virtual que el sistema invitado formatea con un sistema de archivos.
Respaldo inmutable
Una copia de respaldo que no se puede cambiar ni borrar durante un periodo definido, lo que la protege del ransomware y de los errores.
Ejemplo real

Un laboratorio de investigación guarda imágenes en un bucket de almacenamiento de objetos. Un escaneo semanal de configuración encuentra un bucket con una política de lectura pública creada para una demostración en un congreso. El equipo elimina el permiso público, activa el bloqueo de acceso público para toda la cuenta y habilita el registro de accesos para detectar rápido errores similares.

Consejo para el examen: Si una pregunta menciona buckets, metadatos y acceso por API, se trata de almacenamiento de objetos. Si menciona datos que se pierden al reiniciar, se trata de almacenamiento efímero.

Comprueba lo que sabes

¿Qué tipo de almacenamiento se pierde cuando se termina una instancia?

El almacenamiento efímero.

¿Qué tipo de almacenamiento conviene más para retener durante siete años registros que casi no se consultan?

El almacenamiento de largo plazo (de archivo), que es barato y durable pero lento para recuperar.

Nombra dos contramedidas contra el ransomware en el almacenamiento en la nube.

El versionado y los respaldos inmutables (también el mínimo privilegio y la replicación a una cuenta separada).
