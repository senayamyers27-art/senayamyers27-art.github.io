ISC2 Certified Cloud Security Professional 2026 outline (effective Aug 1, 2026)

Tecnologías relacionadas: contenedores, serverless, cómputo en el borde, cómputo confidencial, DevSecOps y cuántica

La seguridad en la nube no se trata solo de máquinas virtuales. El temario del CCSP te pide entender tecnologías que suelen ejecutarse en plataformas de nube o junto a ellas y las preguntas de seguridad que plantea cada una. No se espera que seas ingeniero en cada una, pero sí que sepas qué es, por qué las organizaciones la usan y dónde están sus riesgos.

Los contenedores empaquetan una aplicación con sus bibliotecas para que funcione igual en cualquier lugar. Comparten el kernel del sistema operativo del host, así que el aislamiento es más débil que entre máquinas virtuales; una falla del kernel o un contenedor que se ejecuta con privilegios excesivos puede afectar al host y a sus vecinos. Las buenas prácticas incluyen escanear las imágenes en busca de vulnerabilidades conocidas, usar imágenes base mínimas y confiables, ejecutar como usuario no root y dejar que un orquestador como Kubernetes aplique políticas de red y el manejo de secretos. Serverless (función como servicio) va más allá: subes una función y el proveedor la ejecuta bajo demanda. No hay servidor que parchar, pero cada función necesita permisos bien acotados, validación de entradas y registro, porque muchas funciones pequeñas multiplican la superficie de ataque.

El cómputo en el borde (edge computing) acerca el procesamiento al lugar donde se generan los datos, como sensores de una fábrica o tiendas, para reducir la latencia. Esos dispositivos pueden estar en lugares sin seguridad física, así que importan la resistencia a la manipulación, el arranque seguro y la actualización remota. El cómputo confidencial protege los datos en uso al procesarlos dentro de un entorno de ejecución confiable (TEE) basado en hardware, un enclave cuya memoria no pueden leer ni el sistema operativo del host ni el hipervisor. Complementa el cifrado en reposo y en tránsito, cerrando la brecha mientras los datos se procesan.

DevSecOps incorpora la seguridad en el flujo de desarrollo y operaciones: el escaneo automatizado de código, la revisión de dependencias y las pruebas de políticas se ejecutan en cada cambio y no al final. La computación cuántica está en la lista porque se espera que las computadoras cuánticas grandes rompan los algoritmos de clave pública actuales, como RSA y la criptografía de curva elíptica. Los atacantes pueden recolectar datos cifrados ahora y descifrarlos después, por lo que las organizaciones están haciendo inventario de su criptografía y planificando el paso a algoritmos poscuánticos, que NIST ya comenzó a estandarizar.

Términos clave

Contenedor
Un paquete ligero de una aplicación y sus dependencias que comparte el kernel del sistema operativo del host con otros contenedores.
Serverless
Un modelo en el que el proveedor ejecuta código bajo demanda en respuesta a eventos y el cliente no administra servidores.
Entorno de ejecución confiable (TEE)
Un área del procesador aislada por hardware donde el código y los datos están protegidos incluso del sistema operativo del host y del hipervisor.
Recolectar ahora, descifrar después
La amenaza de que los atacantes guarden hoy datos cifrados para descifrarlos cuando las computadoras cuánticas puedan romper los algoritmos de clave pública actuales.
Ejemplo real

Una empresa de pagos traslada un modelo de detección de fraude a cómputo confidencial para poder analizar datos de tarjetas de bancos socios dentro de un enclave. Ni los administradores del proveedor de nube ni un hipervisor comprometido pueden leer los datos mientras se procesan, algo que los bancos socios exigieron en el contrato.

Consejo para el examen: Los contenedores comparten el kernel y las máquinas virtuales no; ese solo hecho explica la mayoría de las preguntas sobre aislamiento de contenedores. El cómputo confidencial es la respuesta cuando la pregunta trata de proteger los datos en uso.

Comprueba lo que sabes

¿Por qué el aislamiento entre contenedores es más débil que entre máquinas virtuales?

Los contenedores comparten el kernel del host, así que una falla del kernel o un contenedor privilegiado puede afectar a otros contenedores y al host.

¿Qué tecnología protege los datos mientras se procesan?

El cómputo confidencial, usando un entorno de ejecución confiable basado en hardware.

¿Por qué importa la computación cuántica para los datos cifrados hoy?

Los atacantes pueden guardarlos ahora y descifrarlos después, cuando las computadoras cuánticas puedan romper RSA y la criptografía de curva elíptica.
