ISC2 Certified Cloud Security Professional 2026 outline (effective Aug 1, 2026)

Particularidades de la arquitectura de aplicaciones en la nube: WAF, gateways XML, gateways de API, monitoreo de actividad de bases de datos, criptografía, sandboxing y virtualización de aplicaciones

Más allá del código seguro, las aplicaciones en la nube dependen de componentes de seguridad complementarios ubicados a su alrededor. El temario del CCSP enumera varios, y el examen suele preguntar cuál se ajusta a una necesidad específica.

Un firewall de aplicaciones web (WAF) inspecciona el tráfico HTTP y HTTPS en la capa 7 y bloquea ataques comunes como la inyección SQL y el cross-site scripting mediante firmas, reglas y análisis de comportamiento. También puede limitar la tasa de solicitudes y filtrar bots. Un WAF es un control compensatorio que gana tiempo y bloquea patrones conocidos; no corrige el código subyacente. Los gateways XML, y sus equivalentes modernos para JSON, inspeccionan los mensajes estructurados entre servicios: validan los mensajes contra esquemas, bloquean cargas excesivas o maliciosas como los ataques de entidades externas XML y pueden transformar, firmar o cifrar mensajes y quitar campos sensibles antes de que salgan. Un gateway de API es la puerta de entrada de las API: autentica a quienes llaman, aplica la autorización y las cuotas, limita la tasa y regula el tráfico, enruta las solicitudes a los servicios de fondo y registra el tráfico en un solo lugar.

El monitoreo de actividad de bases de datos (DAM) vigila las consultas a las bases de datos, a menudo mediante un agente o leyendo los registros de auditoría de la base de datos, y alerta o bloquea comportamientos sospechosos, como una cuenta de servicio que de pronto lee toda una tabla de clientes o un administrador que consulta datos fuera del horario laboral. Da separación de funciones sobre los administradores de bases de datos, cuyas acciones de otro modo serían difíciles de revisar. La criptografía en la capa de aplicación abarca TLS en todas las conexiones, el cifrado de campos sensibles antes de guardarlos y la firma de tokens y mensajes, todo con llaves de un servicio de llaves administrado.

El sandboxing ejecuta código en un entorno restringido y aislado para que, si se comporta mal o es malicioso, no pueda afectar al host ni a otras aplicaciones. Se usa para detonar archivos sospechosos, ejecutar complementos no confiables y probar código nuevo. La virtualización de aplicaciones ejecuta una aplicación en una capa encapsulada separada del sistema operativo subyacente, lo que permite ejecutar aplicaciones heredadas o en conflicto y limita su acceso al host, además de facilitar su distribución y actualización centralizada.

Términos clave

WAF
Un firewall de aplicaciones web que filtra el tráfico HTTP en la capa 7 para bloquear ataques como la inyección y el cross-site scripting.
Gateway de API
Un servicio que se ubica delante de las API para manejar la autenticación, la autorización, la limitación de tasa, el enrutamiento y el registro.
Monitoreo de actividad de bases de datos (DAM)
Monitorear en tiempo real las consultas y la actividad de las bases de datos para detectar y alertar sobre accesos sospechosos o que violan políticas.
Sandbox
Un entorno de ejecución aislado y restringido que contiene los efectos del código no confiable.
Ejemplo real

Una empresa de reservas de viajes expone API para socios. Coloca delante de ellas un gateway de API que exige tokens OAuth y aplica cuotas por socio, un WAF que bloquea intentos de inyección y monitoreo de actividad en la base de datos de reservas, que más tarde alerta cuando la llave comprometida de un socio empieza a extraer registros muy fuera de su patrón normal.

Consejo para el examen: Un WAF protege las aplicaciones web en la capa 7 pero no corrige el código vulnerable; un gateway de API maneja la autenticación, las cuotas y el enrutamiento de las API; el DAM vigila lo que pasa dentro de la base de datos. Relaciona la herramienta con el lugar donde está el riesgo.

Comprueba lo que sabes

¿Qué componente aplicaría límites de tasa por cliente y autenticación con tokens para API REST?

Un gateway de API.

¿Por qué se considera que un WAF es un control compensatorio?

Bloquea patrones de ataque en el tráfico, pero no elimina la vulnerabilidad del código de la aplicación.

¿Qué amenaza atiende el monitoreo de actividad de bases de datos que los controles de red no detectan?

El uso indebido por parte de cuentas autorizadas, como empleados malintencionados o cuentas de servicio comprometidas que ejecutan consultas inusuales.
