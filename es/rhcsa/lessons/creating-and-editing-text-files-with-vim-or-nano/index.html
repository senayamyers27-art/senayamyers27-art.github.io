Crear y editar archivos de texto con vim o nano

La configuración de Linux vive en archivos de texto plano, así que editarlos rápido y correctamente es una habilidad central del RHCSA. RHEL siempre incluye vi, y normalmente está instalado vim (Vi IMproved); nano es un editor más sencillo que puedes instalar si lo prefieres. En el examen puedes usar cualquiera, pero vi está garantizado incluso en sistemas mínimos, así que vale la pena sentirse cómodo con lo básico de vi/vim.

Vim es modal: la misma tecla hace cosas distintas según el modo. Empiezas en el modo normal, donde las teclas son comandos. Presiona i para entrar en el modo de inserción y escribir texto (a añade después del cursor, o abre una línea nueva debajo). Presiona Esc para volver al modo normal. Escribir : desde el modo normal abre el modo de línea de comandos en la parte inferior de la pantalla, donde guardas y sales. La mayor parte de la confusión de los principiantes viene de escribir texto estando todavía en el modo normal, así que ante la duda presiona Esc.

:w        guardar          :q        salir
:wq o :x  guardar y salir  :q!       salir, descartar cambios
dd        borrar línea     yy / p    copiar línea / pegar debajo
u         deshacer         Ctrl+r    rehacer
/text     buscar abajo     n         siguiente coincidencia
gg / G    inicio / final   :set nu   mostrar números de línea

Unos cuantos comandos más hacen que editar configuración sea rápido. :%s/old/new/g reemplaza todas las apariciones en el archivo. x borra un carácter, cw cambia una palabra y un número antes de un comando lo repite, así que 5dd borra cinco líneas. El modo visual (v, o V para líneas completas) te permite seleccionar texto y luego borrarlo, copiarlo o indentarlo. Si vim avisa que existe un archivo swap, otra sesión estaba editando el archivo o se cerró inesperadamente; elige abrirlo en solo lectura o recuperarlo en lugar de borrarlo a ciegas.

nano no tiene modos: simplemente escribes. Los atajos se muestran en la parte inferior de la pantalla, donde ^ significa Ctrl. Ctrl+O escribe el archivo (presiona Enter para confirmar el nombre), Ctrl+X sale, Ctrl+W busca y Ctrl+K corta una línea. Es más fácil de aprender, aunque más lento para ediciones grandes.

Algunos archivos tienen comandos de edición más seguros y específicos. Usa visudo para /etc/sudoers, porque revisa la sintaxis antes de guardar y evita que te quedes sin acceso a sudo. vipw y vigr bloquean los archivos de cuentas mientras los editas. Para archivos nuevos y pequeños también funciona la redirección: echo 'text' > file o un here-document con cat > file.

Uses el editor que uses, verifica tu cambio después con cat, grep o el comando de prueba propio del servicio, y reinicia o recarga el servicio que lee el archivo.

Términos clave

Normal mode (modo normal)
El modo predeterminado de vim, en el que las teclas son comandos para moverse, borrar, copiar y pegar.
Insert mode (modo de inserción)
Modo de vim al que se entra con i, a u o, en el que las teclas escritas se convierten en texto; Esc sale de él.
:wq / :q!
Comandos de vim para guardar y salir, o para salir descartando los cambios no guardados.
visudo
Edita de forma segura el archivo sudoers, bloqueándolo y revisando la sintaxis antes de guardar.
Swap file (archivo swap de vim)
Un archivo de recuperación .swp que vim mantiene mientras editas; uno sobrante indica una edición simultánea o que falló.
Ejemplo real

Necesitas configurar PermitRootLogin no en /etc/ssh/sshd_config. En vim escribes /PermitRootLogin para encontrar la línea, cw para cambiar el valor, Esc y luego :wq. Lo compruebas con grep PermitRootLogin /etc/ssh/sshd_config y ejecutas systemctl reload sshd.

Consejo para el examen: Si vim parece ignorar lo que escribes o hace cosas raras, estás en el modo equivocado: presiona Esc y luego usa :wq para guardar o :q! para abandonar los cambios.

Comprueba lo que sabes

¿Cómo sales de vim sin guardar después de hacer cambios?

Presiona Esc, luego escribe :q! y Enter.

¿Por qué usar visudo en lugar de editar /etc/sudoers directamente?

visudo revisa la sintaxis antes de guardar, así que un error de escritura no puede romper el acceso con sudo.

¿Qué comando de vim reemplaza cada 'foo' por 'bar' en el archivo?

:%s/foo/bar/g
