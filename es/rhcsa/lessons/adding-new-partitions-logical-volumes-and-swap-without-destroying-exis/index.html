Red Hat Certified System Administrator EX200 (RHEL 10)

Añadir nuevas particiones, volúmenes lógicos y swap sin destruir los datos existentes

Muchas tareas de almacenamiento del RHCSA se plantean sobre discos que ya contienen datos o configuración que debes conservar. El evaluador comprueba tanto que tu nuevo almacenamiento funcione como que las particiones, volúmenes y sistemas de archivos existentes sigan intactos. La habilidad aquí es añadir almacenamiento sin destruir nada: usar el espacio libre, no volver a crear nada que ya exista y verificar antes y después.

Empieza haciendo un reconocimiento. lsblk, lsblk -f, fdisk -l o parted DEVICE print free, pvs, vgs y swapon --show te dicen qué existe, qué está montado y dónde hay espacio libre. Busca espacio sin asignar al final de un disco, un disco completamente sin usar o extensiones libres en un grupo de volúmenes.

Para añadir una partición, abre el disco con fdisk, gdisk o parted y crea una nueva partición solo en el espacio libre. No crees una nueva tabla de particiones (fdisk g/o, parted mklabel); eso descarta todas las particiones existentes. Acepta el primer sector predeterminado, que es el inicio del espacio libre, y especifica un tamaño con +SIZE. Después de escribir, si el disco tiene particiones montadas, puede que el kernel no vuelva a leer la tabla de inmediato; partprobe o udevadm settle suelen resolverlo, y lsblk debería mostrar la nueva partición.

Para añadir un volumen lógico, revisa vgs en busca de espacio libre. Si hay suficiente, lvcreate en el VG existente no toca los otros LV. Si no, añade primero una nueva partición o disco como PV y amplía el VG con vgextend. Nunca ejecutes pvcreate ni mkfs en un dispositivo que ya contiene datos: ambos sobrescriben lo que hay.

El swap es espacio en disco que el kernel usa como memoria de desbordamiento. Para añadir swap sin destruir nada, crea una nueva partición (tipo Linux swap) o un LV, y luego:

mkswap /dev/vdb3                 # escribe una firma de swap, imprime el UUID
swapon /dev/vdb3                 # activar ahora
echo 'UUID=<uuid-from-mkswap> none swap defaults 0 0' >> /etc/fstab
swapoff /dev/vdb3 && swapon -a   # probar la entrada de fstab
swapon --show ; free -h          # confirmar que aumentó el swap total

Fíjate en el >> para añadir al final; un solo > borraría fstab. swapon -a activa todas las entradas de swap de fstab y es la prueba para ellas, como mount -a para los sistemas de archivos. Una tarea puede decir que añadas swap conservando el swap existente, así que el total en free -h debería aumentar en lugar de que un área reemplace a la otra. Las prioridades (opción pri=) establecen qué swap se usa primero, pero rara vez se exigen.

Termina cada tarea de almacenamiento de la misma forma: lsblk para ver la distribución, mount -a y swapon -a para probar fstab, un reinicio y luego findmnt, swapon --show y un vistazo a los datos antiguos para confirmar que no se perdió nada.

Términos clave

Free space (espacio libre)
Área sin asignar en un disco o extensiones libres en un grupo de volúmenes, donde se puede añadir almacenamiento de forma segura.
Swap space (espacio swap)
Espacio en disco que usa el kernel para guardar páginas de memoria cuando la RAM está bajo presión.
mkswap
Escribe una firma de swap en un dispositivo, preparándolo para usarse como swap.
swapon / swapoff
Activan o desactivan áreas de swap; swapon -a activa todas las entradas de swap de fstab.
swapon --show
Lista las áreas de swap activas con su tamaño, uso y prioridad.
Ejemplo real

Un disco /dev/vdb tiene una partición XFS de 1 GiB montada en /data y 4 GiB libres. Añades una partición swap de 512 MiB con fdisk (n, inicio predeterminado, +512M, t swap, w), ejecutas mkswap y swapon, añades su UUID al final de /etc/fstab con >>, y tras un reinicio free -h muestra el swap adicional mientras /data conserva sus archivos.

Consejo para el examen: Nunca vuelvas a crear una tabla de particiones ni ejecutes pvcreate/mkfs sobre algo que contiene datos. Añade a fstab con >> (o edítalo) y prueba con mount -a y swapon -a antes de reiniciar.

Comprueba lo que sabes

¿Qué comandos de fdisk destruirían todas las particiones existentes de un disco?

g (nueva tabla GPT) u o (nueva tabla DOS), seguidos de w.

¿Cómo activas una nueva partición swap y pruebas su entrada de fstab?

Aplícale mkswap y swapon, añade una línea con el UUID a fstab, luego haz swapoff y ejecuta swapon -a para confirmar que fstab la activa.

Un VG no tiene espacio libre pero necesitas un nuevo LV. ¿Qué haces primero?

Añadir un nuevo PV (partición o disco) y ampliar el VG con vgextend, y luego lvcreate.
