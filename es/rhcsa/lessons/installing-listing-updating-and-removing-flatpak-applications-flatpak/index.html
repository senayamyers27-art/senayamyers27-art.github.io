Instalar, listar, actualizar y eliminar aplicaciones Flatpak (flatpak install, list, update, uninstall, run)

Una vez configurado un remote, el comando flatpak gestiona sus aplicaciones de forma muy parecida a como dnf gestiona los RPM. La diferencia está en los nombres: las aplicaciones Flatpak se identifican con un ID de aplicación en formato DNS inverso, como org.example.Editor, y una referencia completa (ref) también incluye la arquitectura y la rama (branch), como app/org.example.Editor/x86_64/stable.

flatpak install REMOTE APPID instala una aplicación y, automáticamente, cualquier runtime que necesite. Sin nombre de remote, flatpak busca en todos los remotes configurados y te pide que elijas. -y responde automáticamente a las preguntas, y --user o --system elige dónde se instala; las instalaciones de sistema son las predeterminadas. flatpak search keyword encuentra IDs de aplicación en los remotes cuando no conoces el nombre exacto.

flatpak search editor
flatpak install -y myremote org.example.Editor
flatpak list                 # apps y runtimes instalados
flatpak list --app           # solo apps
flatpak info org.example.Editor
flatpak run org.example.Editor
flatpak update -y
flatpak uninstall -y org.example.Editor
flatpak uninstall --unused   # eliminar runtimes que ninguna app necesita

flatpak list muestra lo que está instalado: nombre, ID de aplicación, versión, rama, remote de origen e instalación (system o user). --app limita la lista a aplicaciones y --runtime a runtimes. flatpak info APPID muestra los detalles de una aplicación instalada, incluidos el runtime que usa y su tamaño instalado.

flatpak run APPID inicia una aplicación dentro de su sandbox. Los entornos de escritorio también añaden los Flatpaks instalados a sus menús de aplicaciones, pero en un servidor o en el sistema del examen flatpak run es la forma directa de probar que una aplicación funciona. El sandbox restringe la aplicación a los permisos que declaró quien la empaquetó, que puedes inspeccionar con flatpak info --show-permissions APPID.

flatpak update actualiza todas las aplicaciones y runtimes instalados a sus últimas versiones desde sus remotes, o solo la que nombres. flatpak uninstall APPID elimina una aplicación, pero deja su runtime porque otras aplicaciones pueden compartirlo; flatpak uninstall --unused limpia los runtimes que ya nadie necesita. Añadir --delete-data también elimina los datos guardados de la aplicación en los directorios personales de los usuarios.

Flatpak y dnf son independientes: rpm -qa no mostrará las aplicaciones Flatpak y flatpak list no mostrará los RPM. Cuando una tarea diga 'instala la aplicación desde el repositorio Flatpak', verifica con flatpak list, no con rpm.

Términos clave

Application ID (ID de aplicación)
Un identificador en estilo DNS inverso para una app Flatpak, como org.example.Editor.
Ref (referencia)
Una referencia Flatpak completa que combina tipo, ID, arquitectura y rama, p. ej. app/ID/x86_64/stable.
flatpak install
Instala una aplicación y el runtime que necesita desde un remote.
flatpak run
Inicia una aplicación Flatpak instalada en su sandbox.
flatpak uninstall --unused
Elimina los runtimes y extensiones que ya no necesita ninguna aplicación instalada.
Ejemplo real

Una tarea te pide instalar una aplicación del remote examplerepo para todos los usuarios. Ejecutas flatpak search para obtener su ID, la instalas como root con flatpak install -y examplerepo org.example.App, confirmas con flatpak list --app que la columna Installation dice system y la inicias con flatpak run org.example.App.

Consejo para el examen: Usa el ID de aplicación (nombre DNS inverso) con los comandos flatpak, y verifica las tareas de Flatpak con flatpak list; rpm y dnf no saben nada de las apps Flatpak.

Comprueba lo que sabes

¿Qué comando muestra las aplicaciones Flatpak instaladas pero no los runtimes?

flatpak list --app.

¿Por qué desinstalar una app no elimina su runtime?

Los runtimes pueden estar compartidos por varias apps; usa flatpak uninstall --unused para eliminar los que no se necesitan.

¿Cómo inicias una aplicación Flatpak desde la línea de comandos?

flatpak run seguido de su ID de aplicación.
