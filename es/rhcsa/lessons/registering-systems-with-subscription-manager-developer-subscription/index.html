Red Hat Certified System Administrator EX200 (RHEL 10)

Registrar sistemas con subscription-manager (suscripción Developer)

Un sistema RHEL necesita estar registrado con Red Hat para recibir paquetes y actualizaciones desde la CDN (content delivery network) de Red Hat. El registro vincula la máquina a una cuenta de Red Hat y a sus suscripciones. Para estudiar, la suscripción gratuita Red Hat Developer para individuos te permite registrar sistemas RHEL personales, así que puedes practicar con el producto real en lugar de una recompilación.

La herramienta es subscription-manager. Te registras con el nombre de usuario de tu cuenta de Red Hat, y te pide la contraseña. Las organizaciones con muchos sistemas suelen usar en su lugar una clave de activación y un ID de organización, lo que evita escribir contraseñas en scripts.

subscription-manager register --username your_login
subscription-manager status
subscription-manager repos --list-enabled
dnf repolist

Las cuentas de Red Hat ahora usan el acceso simple al contenido (simple content access), en el que un sistema registrado obtiene acceso al contenido al que tiene derecho su cuenta sin adjuntar una suscripción concreta a cada máquina. Las guías antiguas te dicen que ejecutes subscription-manager attach --auto; con el acceso simple al contenido ese paso no es necesario. Después de registrarte, los repositorios BaseOS y AppStream aparecen en /etc/yum.repos.d/redhat.repo, y dnf repolist los muestra.

Otros comandos útiles: subscription-manager repos --enable repo-id y --disable repo-id activan o desactivan repositorios adicionales; subscription-manager identity muestra la identidad de registro del sistema; subscription-manager unregister elimina el registro, por ejemplo antes de dar de baja una VM para que deje de contar en tu cuenta. El instalador gráfico y la consola web también pueden registrar un sistema.

En el examen no debes esperar acceso a la CDN; las tareas normalmente proporcionan una dirección de repositorio. Aun así vale la pena conocer el registro, porque el objetivo incluye instalar desde la CDN de Red Hat y porque tus VMs de práctica lo necesitan para las actualizaciones. Si el registro falla, revisa la resolución de nombres y el acceso de red saliente, y recuerda que un sistema clonado de una VM registrada lleva la misma identidad, así que anula el registro del clon y vuelve a registrarlo.

Términos clave

subscription-manager
La herramienta de línea de comandos que registra un sistema RHEL con Red Hat y gestiona sus repositorios.
Developer subscription (suscripción Developer)
Una suscripción gratuita de Red Hat para individuos que permite registrar sistemas RHEL para desarrollo y aprendizaje.
Simple content access (acceso simple al contenido)
El modelo de Red Hat en el que un sistema registrado puede usar el contenido al que tiene derecho sin adjuntar suscripciones a cada máquina.
Activation key (clave de activación)
Una clave preconfigurada que se usa con un ID de organización para registrar sistemas sin usuario ni contraseña.
Ejemplo real

Instalas RHEL 10 en una VM para practicar. Tras el primer arranque, dnf repolist no muestra nada. Ejecutas subscription-manager register --username con tu usuario de Red Hat Developer, introduces la contraseña y ahora dnf repolist muestra los repositorios BaseOS y AppStream, así que dnf update funciona.

Consejo para el examen: Si dnf repolist está vacío en una instalación nueva de RHEL, probablemente el sistema no está registrado. Es el registro, y no un archivo .repo que te falte escribir, lo que proporciona los repositorios de la CDN.

Comprueba lo que sabes

¿Qué archivo contiene los repositorios de la CDN después del registro?

/etc/yum.repos.d/redhat.repo, gestionado por subscription-manager.

¿Por qué podrías registrarte con una clave de activación en lugar de un nombre de usuario?

Evita poner contraseñas de la cuenta en scripts y permite que una organización controle qué contenido reciben los sistemas registrados.

¿Qué debes hacer antes de borrar una VM de práctica registrada?

Ejecutar subscription-manager unregister para que deje de contar en tu cuenta.
