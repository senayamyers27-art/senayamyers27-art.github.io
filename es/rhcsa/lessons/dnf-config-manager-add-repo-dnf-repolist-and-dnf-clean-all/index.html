Red Hat Certified System Administrator EX200 (RHEL 10)

dnf config-manager --add-repo, dnf repolist y dnf clean all

Escribir un archivo .repo a mano es solo una forma de añadir un repositorio. El subcomando config-manager, proporcionado por el paquete dnf-plugins-core que RHEL instala por defecto, puede crear el archivo por ti, y otros dos comandos te permiten revisar el resultado y reiniciar la caché de dnf. Juntos hacen que las tareas de repositorios sean rápidas de completar y fáciles de verificar.
