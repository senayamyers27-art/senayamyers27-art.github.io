Bucles con for (sobre listas, globs, $(seq)) y while read

Los bucles permiten que un script repita trabajo: crear diez usuarios, revisar cada archivo de configuración, procesar cada línea de una lista. Bash tiene dos bucles que necesitas para el RHCSA: for, que recorre una lista de palabras, y while, que se repite mientras un comando tenga éxito. Combinado con read, un bucle while procesa un archivo línea por línea.

Un bucle for asigna por turnos cada elemento de una lista a una variable y ejecuta el cuerpo una vez por elemento. La lista puede escribirse literalmente, producirse con un glob que coincide con nombres de archivo o generarse con un comando. La estructura es for var in list; do ... done.

for user in alice bob carol; do
    useradd "$user"
done

for f in /etc/*.conf; do
    echo "$f: $(wc -l < "$f") lines"
done

for n in $(seq 1 5); do
    echo "server$n"
done

El shell expande los globs de un bucle for en los nombres de archivo que coinciden, lo que es más seguro que analizar la salida de ls porque los nombres con espacios quedan intactos. Si nada coincide, el bucle recibe el patrón literal, por eso los scripts suelen probar [ -e "$f" ] || continue dentro del bucle. seq FIRST LAST imprime una secuencia de números, y seq 0 5 20 cuenta de 5 en 5. La expansión de llaves de Bash {1..5} da una secuencia similar sin ejecutar un comando, y los bucles al estilo C for ((i=1; i<=5; i++)) también funcionan.

Un bucle while se repite mientras su comando de condición devuelva 0. while read line es el modismo estándar para leer la entrada línea por línea: read devuelve éxito cada vez que obtiene una línea y fallo al final de la entrada, lo que termina el bucle. Alimenta el archivo con una redirección después de done.

while read -r name uid; do
    echo "Creating $name with UID $uid"
    useradd -u "$uid" "$name"
done < /root/newusers.txt

read divide cada línea por los espacios en blanco en las variables que nombres, y las palabras sobrantes van a la última. -r impide que las barras invertidas se traten como escapes, que es casi siempre lo que quieres. Para dividir por otro carácter, establece IFS (Internal Field Separator) solo para el read: while IFS=: read -r user x uid rest; do ... done < /etc/passwd. Dentro de cualquier bucle, continue salta al siguiente elemento y break sale del bucle por completo.

Una advertencia: enviar datos a un bucle while mediante una tubería (cat file | while read ...) ejecuta el bucle en un subshell, así que las variables definidas dentro se pierden después. Redirigir con < file lo evita.

Términos clave

for loop (bucle for)
Repite un bloque una vez por cada palabra de una lista, asignando la palabra a una variable.
while loop (bucle while)
Repite un bloque mientras su comando de condición devuelva el código de salida 0.
read
Comando interno que lee una línea de entrada en variables; devuelve un valor distinto de cero al final de la entrada.
seq
Comando que imprime una secuencia de números, p. ej. seq 1 10.
IFS
Internal Field Separator: los caracteres que read y la división de palabras usan para dividir el texto.
Ejemplo real

Dado /root/hosts.txt con un nombre de host por línea, escribes while read -r h; do ping -c1 -W1 "$h" &>/dev/null && echo "$h up" || echo "$h down"; done < /root/hosts.txt y obtienes un informe rápido del estado de cada host.

Consejo para el examen: Recorre archivos con un glob (for f in /dir/*), no con $(ls), y lee los archivos línea por línea con while read -r ... done < file en lugar de for line in $(cat file), que divide en cada espacio.

Comprueba lo que sabes

¿Cómo recorres los números del 1 al 10?

for i in $(seq 1 10); do ...; done (o for i in {1..10}).

¿Qué termina un bucle while read line?

read devuelve un código distinto de cero al final de la entrada, lo que hace falsa la condición del while.

¿Qué hace break dentro de un bucle?

Sale del bucle inmediatamente; continue, en cambio, saltaría a la siguiente iteración.
