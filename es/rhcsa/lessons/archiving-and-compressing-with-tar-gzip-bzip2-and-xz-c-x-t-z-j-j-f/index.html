Archivar y comprimir con tar, gzip, bzip2 y xz (-c, -x, -t, -z, -j, -J, -f)

Archivar y comprimir son dos trabajos distintos. Archivar agrupa muchos archivos y directorios, con sus permisos, propietarios y marcas de tiempo, en un solo archivo. Comprimir hace que un archivo sea más pequeño. tar (tape archive) hace la agrupación y puede llamar a un compresor al mismo tiempo, por eso los archivos de respaldo suelen terminar en .tar.gz, .tar.bz2 o .tar.xz. Una tarea típica del examen dice: 'crea un archivo comprimido con bzip2 de /etc llamado /root/etc.tar.bz2'.

Las opciones de tar describen primero la acción. -c crea un archivo tar, -x lo extrae y -t lista su contenido sin extraerlo. -f nombra el archivo tar y debe ir seguido directamente de ese nombre, por eso por convención es la última letra de un grupo: -cf archive.tar funciona, pero -fc archive.tar trataría la c como el nombre del archivo. -v (verbose) imprime cada archivo a medida que se procesa.

Las opciones de compresión eligen el compresor: -z para gzip (.gz, rápido, compresión moderada), -j para bzip2 (.bz2, más lento, normalmente más pequeño) y -J para xz (.xz, el más lento, normalmente el más pequeño). Al extraer o listar, el GNU tar moderno detecta la compresión automáticamente, pero escribir la letra correspondiente no hace daño y deja clara tu intención.

tar -czvf /root/etc.tar.gz /etc      # crear, gzip
tar -cjf /root/etc.tar.bz2 /etc      # crear, bzip2
tar -cJf /root/etc.tar.xz /etc       # crear, xz
tar -tf /root/etc.tar.gz             # listar el contenido
tar -xzf /root/etc.tar.gz -C /tmp    # extraer en /tmp

tar elimina la / inicial de las rutas almacenadas e imprime un aviso al respecto. Es una medida de seguridad: al extraer, se recrea etc/... relativo a tu directorio actual (o al directorio indicado con -C) en lugar de sobrescribir el /etc en uso. Revisa siempre dónde estás, o usa -C, antes de extraer.

Los compresores también funcionan solos sobre archivos individuales. gzip file lo reemplaza con file.gz y gunzip file.gz (o gzip -d) lo revierte; bzip2/bunzip2 y xz/unxz se comportan igual. Por defecto reemplazan el archivo original, así que usa -k para conservarlo. No agrupan directorios, por eso normalmente se combinan con tar. zcat, bzcat y xzcat imprimen el contenido de un archivo comprimido sin descomprimirlo en disco.

Después de crear un archivo tar, verifícalo: tar -tf debe listar las rutas esperadas y file /root/etc.tar.bz2 debe indicar datos comprimidos con bzip2. Los evaluadores revisan tanto el nombre como el formato.

Términos clave

Archive (archivo tar)
Un solo archivo que agrupa muchos archivos y directorios junto con sus metadatos; se crea con tar.
-c / -x / -t
Acciones de tar: crear un archivo tar, extraerlo o listar su contenido (tabla de contenido) sin extraerlo.
-f
Opción de tar que nombra el archivo tar; el nombre del archivo debe ir inmediatamente después.
-z / -j / -J
Usar compresión gzip, bzip2 o xz, respectivamente.
-C
Opción de tar que cambia a un directorio antes de extraer (o archivar).
Ejemplo real

Te piden respaldar /var/log como un archivo comprimido con xz; ejecutas tar -cJf /root/logs.tar.xz /var/log, luego tar -tf /root/logs.tar.xz | head para confirmar que las rutas están ahí y file /root/logs.tar.xz para confirmar que son datos comprimidos con XZ.

Consejo para el examen: Relaciona la letra con la extensión: z = .gz, j = .bz2, J = .xz. Deja la f al final del grupo de opciones para que el nombre del archivo tar vaya justo después.

Comprueba lo que sabes

¿Qué comando lista el contenido de backup.tar.gz sin extraerlo?

tar -tzf backup.tar.gz (o tar -tf backup.tar.gz, ya que tar detecta la compresión al leer).

¿Por qué tar imprime 'Removing leading /' al archivar /etc?

Guarda rutas relativas para que la extracción no sobrescriba los archivos del sistema en uso; se recrean bajo el directorio actual o el indicado con -C.

¿Qué le hace gzip notes.txt al archivo original?

Lo reemplaza con notes.txt.gz; usa -k para conservar el original.
