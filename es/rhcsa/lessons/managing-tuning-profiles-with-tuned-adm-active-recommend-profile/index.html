Red Hat Certified System Administrator EX200 (RHEL 10)

Gestionar perfiles de ajuste con tuned-adm (active, recommend, profile)

Cargas de trabajo distintas necesitan ajustes de kernel y hardware distintos. Un servidor de bases de datos se beneficia de ajustes que favorecen el rendimiento de procesamiento, un portátil del ahorro de energía y una máquina virtual invitada de ajustes adecuados para discos y CPUs virtualizados. El servicio tuned de RHEL aplica conjuntos de estos ajustes, llamados perfiles, para que no tengas que ajustar docenas de parámetros a mano. Seleccionar un perfil es un objetivo del RHCSA.

tuned se ejecuta como el servicio tuned. Un perfil puede cambiar cosas como los reguladores de frecuencia de la CPU, los planificadores de E/S de disco, los parámetros sysctl del kernel y el comportamiento de gestión de energía. Algunos perfiles de tuned también supervisan el sistema y se ajustan dinámicamente. Los perfiles incluidos con el paquete están en /usr/lib/tuned/, y los administradores pueden crear perfiles personalizados en /etc/tuned/.

Entre los perfiles más comunes están balanced (un término medio entre rendimiento y energía), powersave, throughput-performance (ajustado para alto rendimiento de procesamiento), latency-performance, network-latency, network-throughput, virtual-guest (para sistemas que se ejecutan como máquinas virtuales) y virtual-host (para hipervisores). La lista exacta depende de la versión instalada, así que revísala en lugar de memorizarla.

dnf install -y tuned
systemctl enable --now tuned
tuned-adm list          # perfiles disponibles y el actual
tuned-adm active        # perfil activo actualmente
tuned-adm recommend     # perfil sugerido para este sistema
tuned-adm profile virtual-guest
tuned-adm verify        # comprobar que los ajustes están aplicados
tuned-adm off           # desactivar el ajuste

El flujo de trabajo es sencillo. Asegúrate de que tuned esté instalado y de que el servicio esté habilitado y en ejecución, porque es el servicio quien aplica el perfil. tuned-adm active muestra el perfil actual. tuned-adm recommend imprime el perfil que tuned considera mejor para esta máquina, según la detección de cosas como si es una máquina virtual. tuned-adm profile NAME cambia a un perfil de inmediato, y la elección se guarda, así que persiste tras los reinicios mientras el servicio esté habilitado.

Una tarea del examen normalmente dice 'establece el perfil de ajuste recomendado' o 'establece el perfil de ajuste en X'. Para la primera, ejecuta tuned-adm recommend, pasa su salida a tuned-adm profile y confírmalo con tuned-adm active. Puedes combinar perfiles listando varios nombres, y los posteriores anulan a los anteriores donde entran en conflicto, pero lo normal es un solo perfil.

Si tuned-adm informa que no puede comunicarse con el demonio, el servicio no está en ejecución; inícialo, habilítalo y vuelve a intentarlo. Como el servicio aplica el perfil al arrancar, un servicio tuned deshabilitado es la razón habitual por la que un perfil parece perderse tras un reinicio.

Términos clave

tuned
El servicio de RHEL que aplica perfiles de ajuste que modifican los ajustes del kernel y del hardware para una carga de trabajo.
Tuning profile (perfil de ajuste)
Un conjunto con nombre de ajustes de rendimiento y energía, como balanced o virtual-guest.
tuned-adm active
Muestra el perfil de ajuste activo actualmente.
tuned-adm recommend
Muestra el perfil que tuned recomienda para el sistema detectado.
tuned-adm profile
Cambia al perfil indicado y lo guarda de forma persistente.
Ejemplo real

Una tarea dice que apliques el perfil de ajuste recomendado en serverb. tuned-adm recommend imprime virtual-guest, así que ejecutas systemctl enable --now tuned y tuned-adm profile virtual-guest, y luego tuned-adm active lo confirma. Después de un reinicio sigue mostrando virtual-guest.

Consejo para el examen: El perfil lo aplica el servicio tuned, así que asegúrate de que esté habilitado y en ejecución (systemctl enable --now tuned). No adivines el perfil recomendado: pregúntaselo a tuned-adm recommend.

Comprueba lo que sabes

¿Cómo averiguas qué perfil sugiere tuned para una máquina?

tuned-adm recommend.

¿Qué comando muestra el perfil que se está usando actualmente?

tuned-adm active.

¿Por qué un perfil elegido podría no estar activo después de un reinicio?

El servicio tuned no está habilitado, así que nada aplica el perfil al arrancar.
