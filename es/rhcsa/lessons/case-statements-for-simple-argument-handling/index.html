Sentencias case para manejar argumentos sencillos

Cuando un script debe elegir entre varias opciones fijas, como start, stop y status, una larga cadena de comparaciones de cadenas con if/elif se vuelve difícil de leer. La sentencia case compara un valor con una lista de patrones y ejecuta el bloque del primer patrón que coincide. Es la forma estándar de manejar un argumento de línea de comandos que selecciona una acción.

La estructura es case WORD in, luego una o más cláusulas y después esac (case escrito al revés). Cada cláusula es un patrón que termina en ), seguido de comandos, y termina con ;;. Los patrones son patrones glob del shell, no expresiones regulares: * coincide con cualquier cosa, ? con cualquier carácter individual y [ ] con un conjunto. Puedes listar alternativas en una cláusula con |. Una cláusula final *) actúa como predeterminada y atrapa todo lo que no coincidió antes.

#!/bin/bash
# svc.sh - controlar el servidor web
case "$1" in
    start|up)
        systemctl start httpd ;;
    stop|down)
        systemctl stop httpd ;;
    status)
        systemctl status httpd --no-pager ;;
    *)
        echo "Usage: $0 {start|stop|status}" >&2
        exit 1 ;;
esac

Los patrones se prueban en orden y solo se ejecuta la primera coincidencia, así que pon los patrones específicos antes que los generales y el comodín *) al final. Pon entre comillas la palabra que se prueba, "$1", para que un argumento vacío o con espacios se maneje limpiamente; un argumento vacío cae entonces en la cláusula predeterminada, que es justo donde imprimes un mensaje de uso y sales con un código distinto de cero.

Los patrones de case facilitan aceptar variaciones. [Yy]|[Yy][Ee][Ss]) coincide con y, Y, yes, YES y combinaciones de mayúsculas y minúsculas, y *.tar.gz|*.tgz) coincide con nombres de archivo por su extensión. Esto hace que case también sea útil para interpretar la entrada del usuario obtenida con read: haz una pregunta y luego usa case para decidir qué significa la respuesta.

Case también se combina bien con los bucles. Un patrón común procesa las opciones una a una: while [ $# -gt 0 ]; do case "$1" in -v) verbose=1 ;; -h) usage ;; *) files+=("$1") ;; esac; shift; done. Para el RHCSA, la forma más sencilla de comparar un solo argumento con unas pocas palabras suele bastar.

Cuida la puntuación, ya que es la fuente habitual de errores de sintaxis: in después de la palabra, ) después de cada patrón, ;; al final de cada cláusula y esac al final. Ejecutar bash -n script revisa la sintaxis sin ejecutar nada.

Términos clave

case ... esac
Sentencia que compara un valor con patrones y ejecuta la primera cláusula que coincide.
;;
Termina una cláusula de case; la ejecución continúa después de esac.
Pattern alternatives (patrones alternativos)
Varios patrones en una cláusula separados por |, como start|up).
*) default clause (cláusula predeterminada)
Una cláusula final que coincide con todo lo que no coincidió antes, normalmente para errores de uso.
bash -n
Revisa la sintaxis de un script sin ejecutarlo.
Ejemplo real

Una tarea pide un script que imprima 'green' cuando se ejecuta con 'go', 'red' con 'stop' y 'Usage: script go|stop' en cualquier otro caso, con código de salida 2. Escribes un case sobre "$1" con las cláusulas go), stop) y *), y luego pruebas las tres más la ejecución sin argumento, revisando $? cada vez.

Consejo para el examen: case usa patrones glob del shell, no regex, se detiene en la primera coincidencia y necesita ;; después de cada cláusula y esac al final. Pon el comodín *) al final.

Comprueba lo que sabes

¿Qué palabra clave termina una sentencia case?

esac.

¿Cómo haces que una cláusula coincida tanto con 'start' como con 'up'?

Usa start|up) como patrón.

¿Qué pasa si dos patrones podrían coincidir con el mismo valor?

Solo se ejecuta la primera cláusula que coincide, en orden.
