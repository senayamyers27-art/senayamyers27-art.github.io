Red Hat Certified System Administrator EX200 (RHEL 10)

Configurar direcciones IPv4 e IPv6 estáticas y por DHCP con nmcli (ipv4.method manual/auto, ipv4.addresses, ipv4.gateway)

RHEL gestiona la red con NetworkManager, y nmcli es su interfaz de línea de comandos. NetworkManager separa los dispositivos (interfaces físicas o virtuales como enp1s0) de las conexiones (perfiles de configuración guardados). Un dispositivo puede tener varios perfiles de conexión, pero solo uno activo a la vez. Casi todas las tareas de red del examen consisten en: modificar o crear una conexión y luego activarla.

nmcli device status muestra los dispositivos y qué conexión usa cada uno. nmcli connection show (abreviado: nmcli con show) lista los perfiles, y nmcli con show name imprime todas sus propiedades. Las propiedades usan un estilo de nombre setting.property, como ipv4.method, ipv4.addresses, ipv4.gateway e ipv4.dns.

ipv4.method auto significa DHCP (Dynamic Host Configuration Protocol): la dirección, la puerta de enlace y el DNS vienen de un servidor. ipv4.method manual significa estática: tú proporcionas la dirección en forma CIDR (Classless Inter-Domain Routing), como 192.168.10.20/24, y normalmente una puerta de enlace y servidores DNS. IPv6 es paralelo: ipv6.method auto usa los anuncios de router y DHCPv6, manual recibe ipv6.addresses como fd00:10::20/64 y disabled desactiva IPv6.

nmcli con add con-name static1 ifname enp1s0 type ethernet \
  ipv4.method manual ipv4.addresses 192.168.10.20/24 \
  ipv4.gateway 192.168.10.1 ipv4.dns 192.168.10.1 \
  ipv6.method manual ipv6.addresses fd00:10::20/64
nmcli con up static1

Para cambiar un perfil existente, usa nmcli con mod. Los cambios se guardan de inmediato, pero no llegan a la interfaz en ejecución hasta que reactivas la conexión con nmcli con up name. Esa es la razón más común por la que un cambio parece no funcionar. Para añadir una dirección adicional en lugar de reemplazar la lista, antepón un signo más a la propiedad: nmcli con mod static1 +ipv4.addresses 10.0.0.5/24; un signo menos quita una.

nmcli con mod 'Wired connection 1' ipv4.method auto   # volver a DHCP
nmcli con mod static1 ipv4.addresses 192.168.10.30/24
nmcli con up static1
ip addr show enp1s0

El orden importa al cambiar a manual: establecer ipv4.method manual sin dirección se rechaza, así que indica el método y la dirección en el mismo comando. Al volver a auto, borra los valores estáticos que queden con cadenas vacías, por ejemplo ipv4.addresses '' e ipv4.gateway '', para que no se añadan encima de la concesión de DHCP. El autocompletado con Tab funciona con las propiedades de nmcli y ahorra escritura.

Términos clave

NetworkManager
El servicio de RHEL que configura y gestiona las interfaces de red mediante perfiles de conexión.
Connection profile (perfil de conexión)
Un conjunto guardado de ajustes de red que NetworkManager aplica a un dispositivo cuando se activa.
ipv4.method
La propiedad que selecciona el direccionamiento auto (DHCP), manual (estático), link-local o disabled.
CIDR notation (notación CIDR)
Una dirección seguida de una barra y la longitud del prefijo, como 192.168.10.20/24, que da la dirección y la máscara de red juntas.
Ejemplo real

El examen dice que asignes a serverb la dirección estática 172.25.250.11/24, la puerta de enlace 172.25.250.254 y el DNS 172.25.250.254 en su conexión existente. Ejecutas un solo comando nmcli con mod que establece ipv4.method manual con la dirección, la puerta de enlace y el DNS, luego nmcli con up, e ip addr e ip route muestran los nuevos valores.

Consejo para el examen: nmcli con mod guarda el perfil pero no lo aplica. Ejecuta siempre después nmcli con up (y ten en cuenta que puede cortar una sesión SSH si cambia la dirección).

Comprueba lo que sabes

¿Qué valor de ipv4.method significa DHCP?

auto.

¿Cómo añades una segunda dirección IPv4 sin quitar la primera?

nmcli con mod name +ipv4.addresses address/prefix, y luego reactiva la conexión.

Cambiaste la dirección con nmcli con mod, pero ip addr muestra la anterior. ¿Por qué?

El perfil está guardado pero no se ha vuelto a aplicar; ejecuta nmcli con up name para activarlo.
