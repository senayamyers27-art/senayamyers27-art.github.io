Red Hat Certified System Administrator EX200 (RHEL 10)

Encontrar documentación con man, man -k, info y /usr/share/doc

El RHCSA se presenta sin acceso a internet, así que la documentación instalada en el sistema es tu única referencia. Saber encontrar rápido la página correcta es una verdadera habilidad de examen: muchos candidatos rescatan una opción o una sintaxis de configuración que recuerdan a medias consultando una página man o un archivo de ejemplo.

Las páginas del manual, que se leen con man command, son la fuente principal. Cada página sigue la misma estructura: NAME, SYNOPSIS (la sintaxis, con las partes opcionales entre corchetes), DESCRIPTION, OPTIONS, a menudo EXAMPLES cerca del final, y SEE ALSO que apunta a páginas relacionadas. Dentro del visor, /text busca hacia adelante, n salta a la siguiente coincidencia, Space avanza una página, g y G van al inicio y al final, y q sale.

Las páginas man se organizan en secciones numeradas, y el mismo nombre puede existir en varias. Las que más usarás son la sección 1 (comandos de usuario), la 5 (formatos de archivo como /etc/fstab), la 7 (panoramas generales y convenciones) y la 8 (comandos de administración del sistema). man 5 passwd describe el archivo /etc/passwd, mientras que man passwd muestra el comando de la sección 1. Para el examen, man 5 fstab, man 5 crontab, man 5 sshd_config, man 7 regex y man 8 semanage-fcontext son especialmente valiosas.

Cuando no conoces el nombre de la página, busca por palabra clave. man -k keyword (lo mismo que apropos) busca en los nombres de las páginas y en sus descripciones cortas: man -k partition lista herramientas como fdisk, parted y gdisk. La búsqueda depende de una base de datos de índice; si no devuelve nada en un sistema recién instalado, ejecuta mandb como root para reconstruirla. Puedes filtrar por sección con grep, por ejemplo man -k user | grep '(8)'.

man -k selinux | grep '(8)'   # comandos de administración sobre SELinux
man 5 fstab                   # formato de archivo
man -K 'Storage='            # búsqueda de texto completo (lenta)
info coreutils                # manual GNU info
ls /usr/share/doc/            # documentación y ejemplos de paquetes

info muestra documentos GNU info, que se parecen más a libros con nodos y enlaces; herramientas GNU como coreutils, tar y grep tienen allí su documentación más completa. Muévete con las flechas, presiona Enter sobre un enlace, u para subir un nivel y q para salir. Muchos comandos también imprimen un resumen rápido con --help.

Por último, /usr/share/doc/ contiene directorios por paquete con archivos README, licencias y, lo más útil, archivos de configuración de ejemplo. Cuando necesitas la sintaxis de un archivo de configuración que no conoces, rpm -qd package lista los archivos de documentación de ese paquete y /usr/share/doc/<package>/ suele contener un ejemplo comentado que puedes adaptar.

Términos clave

man page (página man)
Una página del manual que se ve con man, organizada en secciones estándar como SYNOPSIS, OPTIONS y EXAMPLES.
Man section (sección del manual)
Una categoría numerada de páginas man: 1 comandos de usuario, 5 formatos de archivo, 8 comandos de administración.
man -k
Busca una palabra clave en los nombres y descripciones de las páginas man; equivale a apropos.
mandb
Construye o actualiza la base de datos de índice en la que busca man -k.
/usr/share/doc
Directorio que contiene la documentación adicional de los paquetes instalados y archivos de configuración de ejemplo.
Ejemplo real

No recuerdas el nombre de la herramienta para cambiar la caducidad de la contraseña de un usuario. man -k expir muestra chage(1) entre los resultados; luego man chage te recuerda que chage -M 90 harry establece la edad máxima de la contraseña.

Consejo para el examen: Si man -k devuelve 'nothing appropriate', el índice todavía no se ha construido: ejecuta mandb como root y vuelve a buscar. Usa el número de sección (man 5 ...) cuando necesites un formato de archivo en lugar de un comando.

Comprueba lo que sabes

¿Qué sección del manual documenta los formatos de los archivos de configuración?

La sección 5, p. ej. man 5 fstab o man 5 passwd.

¿Cómo buscas en las páginas man cuando no conoces el nombre del comando?

man -k keyword (apropos keyword), después de que mandb haya construido el índice si hace falta.

¿Dónde buscarías un archivo de configuración de ejemplo incluido con un paquete?

En /usr/share/doc/<package>/, que puedes encontrar con rpm -qd package.
