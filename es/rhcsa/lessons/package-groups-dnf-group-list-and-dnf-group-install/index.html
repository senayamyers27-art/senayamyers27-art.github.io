Grupos de paquetes: dnf group list y dnf group install

Algunos trabajos necesitan muchos paquetes a la vez: un escritorio gráfico, herramientas de desarrollo o un conjunto completo de utilidades de servidor. En lugar de listar docenas de nombres, los repositorios definen grupos de paquetes, y dnf puede instalar un grupo entero con un solo comando. Las definiciones vienen de los metadatos de grupos del repositorio (a menudo llamados comps), así que los grupos disponibles dependen de tus repositorios configurados.

Hay dos tipos de agrupación. Un grupo es un conjunto de paquetes relacionados como 'Development Tools' o 'System Tools'. Un grupo de entorno (environment group) es un paquete mayor formado por varios grupos, que representa un tipo completo de sistema, como 'Server with GUI' o 'Minimal Install'; son las opciones que ves en el instalador. Dentro de un grupo, los paquetes se clasifican como obligatorios (mandatory), predeterminados (default) u opcionales (optional). Por defecto dnf instala los obligatorios y los predeterminados; los opcionales necesitan --with-optional.

dnf group list muestra los grupos de entorno y los grupos disponibles e instalados. Algunos grupos están ocultos por defecto; dnf group list hidden también los muestra, y dnf group list --ids muestra los IDs cortos, que son más fáciles de escribir que los nombres con espacios. dnf group info 'Development Tools' lista los paquetes de un grupo por categoría, para que veas lo que estás a punto de instalar.

dnf group list
dnf group list --ids
dnf group info 'System Tools'
dnf group install -y 'Development Tools'
dnf group install -y --with-optional 'System Tools'
dnf group remove 'Development Tools'

dnf group install instala un grupo o un grupo de entorno. Pon entre comillas los nombres que contienen espacios, o usa el ID. La sintaxis más antigua dnf install @groupname (y @^environment para entornos) es equivalente y práctica en scripts. dnf group remove elimina los paquetes que se instalaron como parte del grupo, y dnf group upgrade actualiza un grupo, incluidos los paquetes añadidos recientemente a su definición.

En el RHCSA te podrían pedir instalar un grupo para obtener algunas herramientas, o instalar un grupo y luego verificar que funciona un comando que forma parte de él. Revisa tu resultado con dnf group list --installed o ejecutando uno de los comandos esperados. Como en cualquier trabajo con dnf, si dnf group list no muestra nada útil, comprueba que tu configuración de repositorios incluya los repositorios que contienen los datos de grupos; en RHEL contribuyen tanto BaseOS como AppStream.

Términos clave

Package group (grupo de paquetes)
Un conjunto con nombre de paquetes relacionados, definido en los metadatos del repositorio, que se puede instalar en un solo paso.
Environment group (grupo de entorno)
Un conjunto mayor de grupos que representa un tipo completo de sistema, como Server with GUI.
Mandatory / default / optional (obligatorio / predeterminado / opcional)
Clases de paquetes dentro de un grupo; dnf instala los obligatorios y los predeterminados a menos que se indique --with-optional.
dnf group info
Muestra los paquetes que contiene un grupo, ordenados por clase.
@group syntax (sintaxis @grupo)
Forma abreviada para grupos en dnf install, p. ej. dnf install @development; @^ indica un grupo de entorno.
Ejemplo real

Un desarrollador necesita un compilador y make en un servidor mínimo. dnf group list --ids muestra development-tools; dnf group info development-tools confirma que incluye gcc y make, y dnf group install -y development-tools los instala. gcc --version prueba que funcionó.

Consejo para el examen: Pon entre comillas los nombres de grupo con espacios o usa sus IDs, y recuerda que los paquetes opcionales no se instalan a menos que añadas --with-optional.

Comprueba lo que sabes

¿Cómo ves qué paquetes contiene un grupo antes de instalarlo?

dnf group info 'Group Name'.

¿Cuál es la diferencia entre un grupo y un grupo de entorno?

Un grupo de entorno es un conjunto mayor compuesto por varios grupos que describe un tipo de sistema completo.

¿Qué sintaxis alternativa instala un grupo con dnf install?

dnf install @groupname (o @^environmentname para un grupo de entorno).
