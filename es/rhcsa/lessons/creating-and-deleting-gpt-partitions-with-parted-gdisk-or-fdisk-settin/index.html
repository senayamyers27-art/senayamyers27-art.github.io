Red Hat Certified System Administrator EX200 (RHEL 10)

Crear y borrar particiones GPT con parted, gdisk o fdisk; establecer el tipo de partición (lvm, swap)

Particionar divide un disco en secciones independientes que pueden contener cada una un sistema de archivos, espacio swap o un volumen físico LVM. RHEL admite dos esquemas de tabla de particiones. El más antiguo, MBR (Master Boot Record, mostrado como 'dos'), solo permite cuatro particiones primarias y discos de hasta 2 TiB. GPT (GUID Partition Table) permite muchas particiones (128 por defecto) y discos muy grandes, guarda una copia de respaldo de la tabla al final del disco y es lo normal en sistemas modernos y UEFI. Las tareas del examen pueden pedir GPT específicamente.

Tres herramientas pueden hacer el trabajo. fdisk es interactiva y maneja tanto MBR como GPT. gdisk es una herramienta parecida a fdisk solo para GPT. parted funciona de forma interactiva o con comandos en una sola línea, lo que la hace adecuada para scripts. En fdisk y gdisk los cambios se mantienen en memoria hasta que los escribes (w), mientras que parted aplica cada comando de inmediato.

fdisk /dev/vdb
  g            crear una nueva tabla GPT vacía (¡solo en un disco vacío!)
  n            nueva partición: aceptar el número y el primer sector,
               último sector +1G para una partición de 1 GiB
  t            cambiar el tipo: introducir lvm, swap o linux (L lista los alias)
  p            imprimir la tabla para revisarla
  w            escribir y salir (q sale sin guardar)

Con parted, el mismo trabajo es: parted /dev/vdb mklabel gpt para crear la tabla, parted /dev/vdb mkpart data xfs 1MiB 1025MiB para crear una partición, donde en GPT el primer argumento es un nombre de partición y el tipo de sistema de archivos solo establece una indicación de tipo, y parted /dev/vdb set 1 lvm on o set 2 swap on para establecer el indicador (flag) de tipo. parted /dev/vdb print muestra el resultado y rm 1 borra la partición 1. Empezar en 1MiB mantiene las particiones alineadas para un mejor rendimiento.

En gdisk, n también crea particiones, y el tipo se da como un código hexadecimal de cuatro dígitos: 8300 Linux filesystem (el predeterminado), 8e00 Linux LVM y 8200 Linux swap; l los lista y w escribe. En fdisk sobre un disco GPT, el comando t acepta alias como lvm y swap. Establecer el tipo correcto es obligatorio cuando una tarea lo dice, y documenta el propósito de la partición para las herramientas y los administradores, aunque el kernel te dejará usar una partición de cualquier tipo.

Borrar es d en fdisk o gdisk (y luego elegir el número) y rm NUMBER en parted. Borrar una partición destruye el acceso a sus datos, así que primero asegúrate de que esté desmontada, de que no se use como swap y de que no sea un volumen físico de un grupo de volúmenes; quítala también de /etc/fstab.

Después de escribir, ejecuta lsblk para confirmar que el kernel ve las nuevas particiones. Si el disco estaba en uso y el kernel no pudo volver a leer la tabla, ejecuta partprobe /dev/vdb o udevadm settle. Nunca crees una nueva tabla de particiones (g, o o mklabel) en un disco que ya contiene datos que necesitas; en la práctica borra todas las particiones existentes.

Términos clave

GPT
GUID Partition Table: esquema moderno que admite muchas particiones y discos muy grandes, con una tabla de respaldo.
MBR (dos)
Esquema de particiones más antiguo, limitado a cuatro particiones primarias y a discos de 2 TiB.
Partition type (tipo de partición)
Identificador que describe el propósito de una partición, como Linux LVM (8e00) o Linux swap (8200).
mklabel
Comando de parted que crea una tabla de particiones nueva y vacía (msdos o gpt).
partprobe
Pide al kernel que vuelva a leer la tabla de particiones de un disco después de cambios.
Ejemplo real

Necesitas una partición LVM de 2 GiB en el disco vacío /dev/vdc. Ejecutas parted /dev/vdc mklabel gpt, parted /dev/vdc mkpart lvmpart 1MiB 2049MiB y parted /dev/vdc set 1 lvm on; luego lsblk /dev/vdc muestra vdc1 con 2G y fdisk -l /dev/vdc muestra su tipo como Linux LVM.

Consejo para el examen: fdisk y gdisk no cambian nada hasta que presionas w; parted aplica cada comando de inmediato. Crear una etiqueta nueva (g, o, mklabel) en un disco con datos borra sus particiones.

Comprueba lo que sabes

¿Cuál es el código de tipo de gdisk para una partición Linux LVM?

8e00 (8200 es Linux swap y 8300 Linux filesystem).

¿Cómo marcas la partición 1 como LVM con parted?

parted /dev/DISK set 1 lvm on.

¿Por qué usar +1G en la pregunta del último sector de fdisk?

Crea una partición de 1 GiB de tamaño a partir del primer sector elegido, sin calcular sectores a mano.
