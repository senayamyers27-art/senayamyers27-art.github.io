Red Hat Certified System Administrator EX200 (RHEL 10)

Montar, desmontar y usar sistemas de archivos; mount -a y findmnt --verify

Linux tiene un único árbol de directorios que empieza en /. Montar conecta un sistema de archivos a un directorio de ese árbol, llamado punto de montaje, para que su contenido aparezca ahí. Lo que hubiera antes dentro del directorio del punto de montaje queda oculto hasta que desmontas. En RHEL montas manualmente para probar y usas /etc/fstab para que los montajes persistan tras los reinicios.
