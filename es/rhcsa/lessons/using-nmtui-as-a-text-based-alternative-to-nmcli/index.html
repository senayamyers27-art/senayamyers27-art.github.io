Usar nmtui como alternativa en modo texto a nmcli

nmtui (NetworkManager text user interface) es un programa con menús para las mismas tareas que haces con nmcli. Funciona en cualquier terminal, usa las flechas, Tab, Enter y la barra espaciadora, y escribe los mismos keyfiles que nmcli. Bajo la presión de tiempo del examen, muchas personas lo encuentran más rápido y menos propenso a errores para cambios puntuales, porque cada campo está etiquetado y no hace falta saber los nombres exactos de las propiedades. Viene del paquete NetworkManager-tui, que puede que haya que instalar.

El menú principal ofrece tres opciones. Edit a connection te permite añadir, cambiar o borrar perfiles de conexión. Activate a connection te permite activar o desactivar perfiles. Set system hostname establece el nombre de host estático, como hostnamectl set-hostname. Puedes ir directamente a una con nmtui edit, nmtui connect o nmtui hostname, nombrando opcionalmente una conexión, como en nmtui edit static1.

Al editar un perfil, la línea IPV4 CONFIGURATION tiene un ajuste como Automatic o Manual. Elige Manual y luego selecciona Show para desplegar los campos Addresses, Gateway, DNS servers y Search domains. Introduce las direcciones en forma CIDR, como 192.168.10.20/24. Debajo hay casillas, entre ellas Automatically connect, que corresponde a connection.autoconnect, y existen los mismos ajustes para IPv6.

La única trampa es la activación. Guardar en nmtui escribe el perfil, pero, igual que con nmcli con mod, la interfaz en funcionamiento puede conservar sus ajustes anteriores. Después de guardar, ve a Activate a connection y desactiva y vuelve a activar el perfil, o ejecuta nmcli con up name desde el shell.

dnf install -y NetworkManager-tui
nmtui edit 'Wired connection 1'   # cambiar los ajustes, OK
nmcli con up 'Wired connection 1'  # aplicarlos
ip addr; ip route; cat /etc/resolv.conf

Usa la herramienta con la que seas más rápido y preciso, pero conoce ambas. nmtui es excelente de forma interactiva; nmcli se puede usar en scripts, funciona sobre cualquier conexión y es más fácil de verificar con nmcli con show. En cualquier caso, verifica el resultado con ip addr, ip route y una conexión de prueba, y confirma que el perfil tiene habilitado autoconnect para que sobreviva al reinicio.

Términos clave

nmtui
Una interfaz de NetworkManager en modo texto y con menús para editar conexiones, activarlas y establecer el nombre de host.
NetworkManager-tui
El paquete que proporciona el comando nmtui.
Automatically connect
La casilla de nmtui que establece connection.autoconnect en un perfil.
Activate a connection
El menú de nmtui para activar o desactivar perfiles de modo que los cambios guardados surtan efecto.
Ejemplo real

En la consola del examen necesitas una dirección estática, una puerta de enlace, DNS y un nombre de host. Ejecutas nmtui, pones IPv4 en Manual con los valores, marcas Automatically connect, guardas, reactivas el perfil en Activate a connection y luego estableces el nombre de host desde la tercera opción del menú, y lo verificas con ip addr y hostnamectl.

Consejo para el examen: nmtui guarda el perfil pero puede no aplicarlo; desactiva y reactiva la conexión después, exactamente como ejecutarías nmcli con up después de nmcli con mod.

Comprueba lo que sabes

¿Qué tres tareas ofrece el menú principal de nmtui?

Editar una conexión, activar una conexión y establecer el nombre de host del sistema.

Guardaste nuevos ajustes en nmtui pero ip addr muestra la dirección anterior. ¿Qué haces?

Reactiva la conexión en el menú Activate de nmtui o con nmcli con up.

¿nmtui y nmcli guardan la configuración de forma distinta?

No; ambos usan NetworkManager y escriben los mismos keyfiles en /etc/NetworkManager/system-connections/.
