Listar discos y particiones con lsblk, blkid y fdisk -l

Antes de particionar, formatear o montar nada, debes saber exactamente qué discos existen, cómo están divididos y qué está ya en uso. Elegir el dispositivo equivocado es el error más destructivo posible en el examen, así que estos comandos de listado de solo lectura son lo primero que hay que ejecutar en cualquier tarea de almacenamiento.

Linux nombra los dispositivos de bloques según su controlador. Los discos SATA, SAS y USB aparecen como /dev/sda, /dev/sdb, etc.; las máquinas virtuales suelen usar discos virtio llamados /dev/vda, /dev/vdb; las unidades NVMe aparecen como /dev/nvme0n1. Las particiones añaden un número: /dev/vdb1, o /dev/nvme0n1p1 para NVMe, donde una p separa el número. Los volúmenes lógicos LVM aparecen como /dev/mapper/vg-lv y /dev/vg/lv.

lsblk (list block devices) muestra cada disco, partición y volumen lógico como un árbol, con su tamaño, tipo (disk, part, lvm, rom) y puntos de montaje. El árbol muestra la relación directamente: una partición aparece bajo su disco, y un volumen lógico bajo la partición usada como su volumen físico. Es la forma más rápida de encontrar el disco vacío al que se refiere una tarea. lsblk -f añade el tipo de sistema de archivos, la etiqueta y el UUID (universally unique identifier), y lsblk -p imprime las rutas completas de los dispositivos.

lsblk
lsblk -f
blkid
blkid /dev/vdb1
fdisk -l /dev/vdb
parted /dev/vdb print
cat /proc/partitions

blkid imprime los atributos de los dispositivos que contienen una firma reconocida: el UUID, el TYPE del sistema de archivos (xfs, ext4, swap, LVM2_member), el LABEL si se estableció uno y, para las particiones GPT, el PARTUUID. Su uso principal en el examen es obtener el UUID para ponerlo en /etc/fstab. Un dispositivo para el que blkid no muestra nada todavía no tiene un sistema de archivos ni una firma reconocidos. Ejecútalo como root para obtener resultados completos.

fdisk -l lista la tabla de particiones de cada disco, o solo del que nombres. Muestra el tamaño del disco y del sector, el tipo de tabla de particiones (dos para el esquema más antiguo MBR, Master Boot Record, o gpt para la GUID Partition Table) y el sector inicial y final, el tamaño y el tipo de cada partición, como 'Linux filesystem', 'Linux LVM' o 'Linux swap'. parted DEVICE print da información similar y muestra claramente el espacio libre.

Juntos responden las preguntas clave: qué disco es nuevo o tiene espacio libre (lsblk, fdisk -l), qué tipo de partición tiene (fdisk -l), qué contiene (lsblk -f, blkid) y dónde está montado (lsblk, findmnt). Acostúmbrate a ejecutar lsblk antes y después de cada cambio: antes para elegir el dispositivo correcto y después para confirmar el resultado.

Términos clave

Block device (dispositivo de bloques)
Un dispositivo de almacenamiento, como un disco o una partición, al que se accede por bloques; se encuentra en /dev.
lsblk
Lista los dispositivos de bloques como un árbol con tamaño, tipo y punto de montaje; -f añade detalles del sistema de archivos.
blkid
Muestra el UUID, el tipo de sistema de archivos y la etiqueta de los dispositivos con firmas reconocidas.
fdisk -l
Lista las tablas de particiones, mostrando el tipo de tabla (dos o gpt) y el tamaño y tipo de cada partición.
UUID
Identificador único universal asignado a un sistema de archivos u otra firma, estable aunque cambie el nombre del dispositivo.
Ejemplo real

Una tarea dice que crees una partición swap en el segundo disco. lsblk muestra /dev/vda con las particiones del sistema y un /dev/vdb de 5G sin usar y sin hijos. fdisk -l /dev/vdb confirma una etiqueta gpt sin particiones, así que sabes exactamente en qué dispositivo trabajar.

Consejo para el examen: Ejecuta lsblk antes de tocar cualquier disco para asegurarte de tener el nombre de dispositivo correcto, y usa blkid (o lsblk -f) para obtener el UUID para /etc/fstab. Las particiones NVMe incluyen una p: nvme0n1p1.

Comprueba lo que sabes

¿Qué comando muestra discos, particiones y volúmenes lógicos como un árbol con puntos de montaje?

lsblk.

¿Cómo obtienes el UUID de /dev/vdb1?

blkid /dev/vdb1 (o lsblk -f /dev/vdb1).

¿Cómo puedes saber si un disco usa MBR o GPT?

fdisk -l muestra Disklabel type dos (MBR) o gpt; parted print muestra la Partition Table.
