Red Hat Certified System Administrator EX200 (RHEL 10)

Arrancar, reiniciar y apagar el sistema normalmente (systemctl reboot, poweroff)

En un sistema RHEL, systemd es el primer proceso que inicia el kernel (ID de proceso 1). Levanta los servicios en el orden correcto durante el arranque y los detiene limpiamente al apagar. Apagar o reiniciar a través de systemd, en lugar de desconectar la corriente, da tiempo a los servicios para guardar datos, desmontar los sistemas de archivos y vaciar las cachés de disco. En el examen reiniciarás a menudo, porque toda configuración debe sobrevivir a un reinicio, así que debes hacerlo limpiamente y saber qué ocurre.

Los comandos principales son systemctl reboot para reiniciar la máquina, systemctl poweroff para apagarla y cortar la energía, y systemctl halt para detener el sistema sin apagarlo. Los comandos tradicionales reboot, poweroff y halt siguen existiendo y llaman a systemd por ti. shutdown añade programación: shutdown -r now reinicia de inmediato, shutdown -h +10 apaga en diez minutos y avisa a los usuarios conectados, y shutdown -c cancela un apagado programado.

systemctl reboot
systemctl poweroff
shutdown -r +5 "Rebooting for kernel update"
shutdown -c
systemctl get-default        # target usado al arrancar
systemctl set-default multi-user.target

Detrás de estos comandos están los targets de systemd, grupos de unidades que describen un estado del sistema. poweroff.target y reboot.target son lo que activan los comandos. Al arrancar, systemd inicia el target predeterminado, normalmente multi-user.target para servidores (modo texto con red y servicios) o graphical.target para sistemas con escritorio. systemctl get-default lo muestra y systemctl set-default lo cambia de forma persistente; systemctl isolate multi-user.target cambia el sistema en ejecución a otro target inmediatamente, sin reiniciar.

Vale la pena conocer la secuencia de arranque a grandes rasgos, porque temas posteriores se basan en ella. El firmware (BIOS o UEFI) se ejecuta primero e inicia el cargador de arranque, GRUB 2. GRUB carga el kernel y el initramfs, un pequeño sistema de archivos inicial que contiene los controladores necesarios para encontrar el sistema de archivos raíz real. El código del initramfs monta el sistema de archivos raíz y cede el control a systemd, que inicia el target predeterminado.

Después de un reinicio, confirma que el sistema arrancó como se esperaba: inicia sesión, revisa systemctl --failed para ver las unidades que no arrancaron y usa journalctl -b para ver los mensajes del arranque actual o journalctl -b -1 para los del arranque anterior, si el journal es persistente. En el examen, haz un último reinicio antes de terminar y comprueba que tus montajes, servicios y ajustes siguen en su lugar, porque así es como el evaluador verá la máquina.

Evita forzar un reinicio a menos que el sistema esté realmente colgado. Un apagado no limpio puede dejar sistemas de archivos que necesitan reparación y pierde todo lo que todavía no se había escrito en disco.

Términos clave

systemd
El sistema de inicio y gestor de servicios, el proceso 1 en RHEL, que inicia y detiene todo lo demás.
systemctl reboot / poweroff
Reinician limpiamente el sistema, o lo apagan y cortan la energía.
Target
Una unidad de systemd que agrupa otras unidades para describir un estado del sistema, p. ej. multi-user.target.
Default target (target predeterminado)
El target que systemd inicia al arrancar; se muestra con systemctl get-default y se cambia con set-default.
initramfs
Sistema de archivos inicial en RAM cargado junto con el kernel, que contiene lo necesario para montar el sistema de archivos raíz real.
Ejemplo real

Tras terminar todas las tareas ejecutas systemctl reboot, vuelves a iniciar sesión y revisas findmnt /data, systemctl is-active httpd y systemctl --failed. Descubres que un error de escritura en /etc/fstab dejó un montaje sin hacer, lo corriges y reinicias otra vez antes de que se acabe el tiempo.

Consejo para el examen: systemctl set-default cambia lo que ocurre en el PRÓXIMO arranque; systemctl isolate cambia el target AHORA. El examen se califica después de un reinicio, así que prueba reiniciando.

Comprueba lo que sabes

¿Qué comando muestra el target con el que arranca el sistema por defecto?

systemctl get-default.

¿Cómo programas un reinicio en 10 minutos y luego lo cancelas?

shutdown -r +10 y después shutdown -c.

¿Qué papel cumple el initramfs en el arranque?

Proporciona los controladores y herramientas necesarios para encontrar y montar el sistema de archivos raíz real antes de ceder el control a systemd.
