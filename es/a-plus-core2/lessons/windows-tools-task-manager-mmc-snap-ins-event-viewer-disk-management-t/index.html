CompTIA A+ Core 2 220-1202

Herramientas de Windows: Task Manager, complementos de MMC (Event Viewer, Disk Management, Task Scheduler, Device Manager, Certificate Manager, Local Users and Groups, Performance Monitor, Group Policy Editor), msinfo32, Resource Monitor, System Configuration, Registry Editor, Disk Cleanup

Windows incluye una caja de herramientas de utilidades gráficas, y el examen te da un síntoma o una tarea y te pregunta qué herramienta abrir. Aprende el propósito de cada herramienta y su comando de ejecución, porque puedes abrir la mayoría desde el cuadro Run (tecla Windows + R).

Task Manager (Administrador de tareas; taskmgr o Ctrl+Shift+Esc) muestra los procesos en ejecución y su uso de CPU, memoria, disco y red; te permite finalizar tareas que no responden; muestra gráficos de rendimiento; lista las apps de inicio con su impacto para que puedas deshabilitarlas; y muestra los servicios y los usuarios con sesión iniciada. Resource Monitor (Monitor de recursos, resmon) profundiza más y muestra exactamente qué proceso está usando qué archivo, conexión de red o disco. System Configuration (Configuración del sistema, msconfig) controla las opciones de arranque, como iniciar en Safe Mode, y te permite deshabilitar los servicios que no son de Microsoft para diagnosticar problemas. System Information (Información del sistema, msinfo32) ofrece un informe de solo lectura del hardware, los controladores, la versión del BIOS y los recursos del sistema.

La Microsoft Management Console (MMC, mmc) es un contenedor para herramientas administrativas llamadas complementos (snap-ins). Muchos también están disponibles directamente. Event Viewer (Visor de eventos, eventvwr.msc) muestra los registros Application, Security y System, donde buscas errores y advertencias por hora. Disk Management (Administración de discos, diskmgmt.msc) inicializa discos; crea, extiende, reduce y formatea particiones; y asigna letras de unidad. Task Scheduler (Programador de tareas, taskschd.msc) ejecuta programas o scripts según un horario o ante eventos como el inicio de sesión. Device Manager (Administrador de dispositivos, devmgmt.msc) muestra el hardware, te permite actualizar, revertir, deshabilitar o desinstalar controladores y marca los dispositivos con problemas con un ícono de advertencia amarillo. Certificate Manager (Administrador de certificados; certmgr.msc para el usuario actual, certlm.msc para el equipo local) permite ver y administrar certificados digitales. Local Users and Groups (Usuarios y grupos locales, lusrmgr.msc) crea cuentas y membresías de grupo en el equipo local (no disponible en las ediciones Home). Performance Monitor (Monitor de rendimiento, perfmon) registra contadores como el tiempo de procesador o la memoria disponible a lo largo del tiempo y puede crear conjuntos de recopiladores de datos y líneas base. El Local Group Policy Editor (Editor de directivas de grupo local, gpedit.msc, Pro y superiores) configura directivas en un solo equipo.

El Registry Editor (Editor del Registro, regedit) edita el registro, la base de datos jerárquica de configuraciones de Windows y de las aplicaciones, organizada en subárboles (hives) como HKEY_LOCAL_MACHINE y HKEY_CURRENT_USER. Los errores aquí pueden hacer que Windows no arranque, así que exporta la clave (o haz un respaldo) antes de cambiarla y solo haz cambios que entiendas.

Disk Cleanup (Liberador de espacio en disco, cleanmgr) elimina archivos temporales, el contenido de la Papelera de reciclaje, archivos de actualizaciones antiguas y otros desechos para liberar espacio. La página más nueva de Storage (Almacenamiento) en Settings ofrece opciones similares.

Una buena manera de recordarlas es por pregunta. '¿Qué está usando la CPU ahora mismo?' Task Manager. '¿Qué proceso tiene abierto este archivo?' Resource Monitor. '¿Qué error ocurrió anoche?' Event Viewer. '¿Por qué no funciona este dispositivo?' Device Manager. '¿Ejecutar un script cada lunes?' Task Scheduler. '¿Monitorear el uso de memoria durante una semana?' Performance Monitor. '¿Agregar una partición?' Disk Management.

Términos clave

MMC
Microsoft Management Console: un marco que aloja complementos administrativos como Device Manager y Event Viewer.
Snap-in (complemento)
Una herramienta de administración que se carga en la MMC, normalmente guardada como archivo .msc.
msconfig
La utilidad System Configuration, que se usa para cambiar opciones de arranque (como Safe Boot) y deshabilitar servicios de forma selectiva.
Registry (registro)
La base de datos jerárquica de Windows con la configuración del sistema, el hardware, los usuarios y las aplicaciones; se edita con regedit.
Performance Monitor (Monitor de rendimiento)
Herramienta (perfmon) que registra contadores de rendimiento a lo largo del tiempo para crear líneas base y analizar tendencias.
Ejemplo real

Un usuario reporta que su PC se vuelve lentísima cada mañana a las 9:00. El técnico abre Task Scheduler y encuentra un actualizador de terceros programado para ejecutarse a esa hora, confirma en Task Manager que el proceso consume la mayor parte de la CPU y reprograma la tarea para que se ejecute a la hora del almuerzo.

Consejo para el examen: Cuidado con las trampas de la edición Home: lusrmgr.msc y gpedit.msc no están disponibles en Windows Home. Además, Task Manager muestra el uso en tiempo real, mientras que Performance Monitor registra datos a lo largo del tiempo.

Comprueba lo que sabes

¿Qué herramienta usarías para asignar una letra de unidad a un segundo disco duro recién instalado?

Disk Management (diskmgmt.msc), después de inicializar el disco y crear un volumen.

Un dispositivo muestra un triángulo amarillo. ¿Dónde lo verías y qué puedes hacer ahí?

En Device Manager; puedes actualizar, revertir, deshabilitar o reinstalar el controlador y ver el código de error en las propiedades del dispositivo.

¿Qué debes hacer antes de editar el registro?

Respaldar el registro o exportar la clave que vas a cambiar para poder restaurarla si algo falla.
