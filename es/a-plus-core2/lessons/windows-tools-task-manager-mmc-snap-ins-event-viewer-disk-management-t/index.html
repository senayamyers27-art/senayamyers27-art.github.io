CompTIA A+ Core 2 220-1202

Herramientas de Windows: Task Manager, complementos de MMC (Event Viewer, Disk Management, Task Scheduler, Device Manager, Certificate Manager, Local Users and Groups, Performance Monitor, Group Policy Editor), msinfo32, Resource Monitor, System Configuration, Registry Editor, Disk Cleanup

Windows incluye una caja de herramientas de utilidades gráficas, y el examen te da un síntoma o una tarea y pregunta qué herramienta abrir. Aprender el propósito de cada herramienta y su comando de ejecución rinde doble: respondes las preguntas con rapidez y, en el trabajo real de soporte, puedes abrir la mayoría desde el cuadro Run (tecla Windows + R) o desde un símbolo del sistema sin buscar entre menús. Piensa en cada herramienta como la respuesta a una pregunta concreta que se hace un técnico.

Task Manager (taskmgr, o Ctrl+Shift+Esc) es la primera parada ante una PC lenta o congelada. Muestra los procesos en ejecución y su uso de CPU, memoria, disco y red; te permite finalizar tareas que no responden; muestra gráficas de rendimiento en tiempo real; enumera las apps de inicio con su impacto para que puedas deshabilitarlas; y muestra los servicios y los usuarios con sesión iniciada. Resource Monitor (resmon) profundiza más, mostrando exactamente qué proceso usa qué archivo, conexión de red o disco, y así encuentras el programa que tiene un archivo bloqueado. System Configuration (msconfig) controla las opciones de arranque, como iniciar en Safe Mode (modo seguro), y te permite ocultar los servicios de Microsoft y deshabilitar el resto para diagnosticar con un arranque limpio (clean boot). System Information (msinfo32) ofrece un informe de solo lectura del hardware, los controladores, la versión de BIOS o UEFI y los recursos del sistema, útil cuando necesitas los datos del modelo sin abrir el gabinete.

Microsoft Management Console (MMC, mmc) es un contenedor para herramientas administrativas llamadas complementos (snap-ins); puedes armar una consola personalizada con los que más usas, y muchos también están disponibles directamente. Event Viewer (eventvwr.msc) muestra los registros Application, Security y System, donde buscas errores, advertencias y eventos de auditoría por hora y origen. Disk Management (diskmgmt.msc) inicializa discos; crea, extiende, reduce y formatea particiones; y asigna letras de unidad. Task Scheduler (taskschd.msc) ejecuta programas o scripts según un horario o ante desencadenadores como el inicio de sesión o el arranque. Device Manager (devmgmt.msc) muestra el hardware, te permite actualizar, revertir, deshabilitar o desinstalar controladores y marca los dispositivos con problemas con un ícono de advertencia.

Otros complementos completan la lista. Certificate Manager (certmgr.msc para el usuario actual, certlm.msc para el equipo local) permite ver, importar y exportar certificados digitales. Local Users and Groups (lusrmgr.msc) crea cuentas locales y administra la pertenencia a grupos, y no está disponible en las ediciones Home. Performance Monitor (perfmon) registra contadores como el tiempo de procesador o la memoria disponible a lo largo del tiempo, y puede crear conjuntos de recopiladores de datos y líneas base para compararlas después. El Editor de directivas de grupo local (gpedit.msc, Pro y superiores) configura directivas en un solo equipo. Registry Editor (regedit) edita el registro, la base de datos jerárquica de configuraciones de Windows y de las aplicaciones, organizada en subárboles (hives) como HKEY_LOCAL_MACHINE y HKEY_CURRENT_USER. Un error allí puede dejar Windows sin arrancar, así que exporta la clave antes de modificarla. Disk Cleanup (cleanmgr) elimina archivos temporales, el contenido de la Papelera de reciclaje, archivos de actualizaciones antiguas y otros desechos; la página más reciente de Storage en Settings ofrece opciones similares.

Las distinciones que le gustan al examen son tiempo real frente a histórico, y ver frente a cambiar. Task Manager muestra lo que está pasando ahora; Performance Monitor registra tendencias durante horas o días. Task Manager te dice que un proceso está ocupado; Resource Monitor te dice qué archivo o conexión está usando. msinfo32 informa la configuración pero no cambia nada, mientras que msconfig cambia el comportamiento del arranque y del inicio. Device Manager se ocupa de controladores y dispositivos, mientras que Disk Management se ocupa de particiones y volúmenes.

Veamos un ejemplo práctico. Una usuaria informa que su PC se volvió lenta y se bloquea aproximadamente una vez al día desde la semana pasada. Abres Task Manager y no ves nada inusual en ese momento, así que revisas el registro System de Event Viewer y encuentras errores repetidos de un controlador de pantalla que comenzaron el día en que se instaló un controlador nuevo. En Device Manager abres las propiedades del adaptador de pantalla y eliges Roll Back Driver. Para confirmar la solución, creas un conjunto de recopiladores de datos en Performance Monitor que registre los contadores de procesador y memoria durante los próximos días.

Errores comunes: usar Task Manager para investigar un problema que ocurrió anoche (Event Viewer guarda el historial); editar el registro sin exportar primero la clave; buscar lusrmgr.msc o gpedit.msc en una edición Home, donde no están incluidos; confundir msconfig con msinfo32; y usar Disk Management para resolver un problema de controladores. Recuerda también que en las versiones actuales de Windows un programa de inicio se deshabilita desde la pestaña Startup de Task Manager, no desde msconfig, que ahora te redirige allí.

Las preguntas del examen son más fáciles si asocias cada pista con una herramienta. '¿Qué está usando la CPU en este momento?' Task Manager. '¿Qué proceso tiene abierto este archivo?' Resource Monitor. '¿Qué error ocurrió anoche?' Event Viewer. '¿Por qué no funciona este dispositivo, o cómo revierto un controlador?' Device Manager. '¿Ejecutar un script todos los lunes?' Task Scheduler. '¿Seguir el uso de memoria durante una semana o crear una línea base?' Performance Monitor. '¿Agregar, reducir o extender una partición?' Disk Management. '¿Arrancar en Safe Mode en el próximo reinicio?' System Configuration. '¿Encontrar la versión de BIOS sin reiniciar?' System Information.

Términos clave

Task Manager
Vista en tiempo real de procesos, rendimiento, apps de inicio, servicios y usuarios, que se abre con Ctrl+Shift+Esc.
Microsoft Management Console (MMC)
Un marco que aloja complementos administrativos como Event Viewer y Device Manager.
Event Viewer
El complemento que muestra los registros Application, Security y System para diagnosticar eventos pasados.
Performance Monitor
Una herramienta que registra contadores de rendimiento a lo largo del tiempo para crear líneas base y encontrar tendencias.
Resource Monitor
Una vista detallada de qué procesos usan archivos, disco, red y recursos de memoria específicos.
System Configuration (msconfig)
Una herramienta para cambiar opciones de arranque como Safe Mode y deshabilitar servicios para diagnosticar con un arranque limpio.
Registro (Registry)
La base de datos jerárquica de configuraciones de Windows y de las aplicaciones, que se edita con regedit.
Ejemplo real

Un usuario no puede eliminar una hoja de cálculo porque Windows indica que está abierta en otro programa, aunque no se ve nada en pantalla. El técnico abre Resource Monitor, busca el nombre del archivo en los identificadores asociados (associated handles) de la pestaña CPU, encuentra un proceso en segundo plano colgado que lo retiene, finaliza ese proceso y elimina el archivo.

Consejo para el examen: Task Manager muestra el uso en tiempo real, mientras que Performance Monitor registra datos a lo largo del tiempo. lusrmgr.msc y gpedit.msc no están disponibles en Windows Home, y Event Viewer es la herramienta para lo que ya ocurrió.

Comprueba lo que sabes

¿Qué herramienta usarías para ver los errores registrados durante la noche?

Event Viewer, que registra eventos de Application, Security y System con marcas de tiempo.

Necesitas seguir el uso de memoria durante una semana completa. ¿Qué herramienta corresponde?

Performance Monitor, porque puede registrar contadores a lo largo del tiempo con un conjunto de recopiladores de datos.

¿Qué herramienta te permite configurar el próximo reinicio para arrancar en Safe Mode?

System Configuration (msconfig), en su pestaña Boot.

¿Qué debes hacer antes de cambiar una clave del registro?

Exportar o respaldar la clave para poder restaurarla si el cambio causa problemas.
