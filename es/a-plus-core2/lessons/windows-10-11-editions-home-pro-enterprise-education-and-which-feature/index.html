CompTIA A+ Core 2 220-1202

Ediciones de Windows 10/11 (Home, Pro, Enterprise, Education) y las funciones de cada una: BitLocker, unión a dominio, Group Policy, host de Remote Desktop

Microsoft vende Windows 10 y Windows 11 en varias ediciones. Comparten el mismo núcleo, pero las funciones empresariales solo se activan en las ediciones superiores. El examen A+ a menudo describe una necesidad, como 'la laptop debe unirse al dominio de la empresa', y pregunta qué edición la admite, así que vale la pena memorizar la línea divisoria.

Windows Home está dirigido a consumidores. No puede unirse a un dominio de Active Directory, no incluye el Editor de directivas de grupo local (gpedit.msc), no puede actuar como host de Remote Desktop (aunque sí puede conectarse a otras computadoras con el cliente de Remote Desktop) y no incluye la administración completa de BitLocker. Muchos dispositivos con Home ofrecen una función más sencilla de 'Device encryption' (cifrado de dispositivo) cuando el hardware lo permite, pero no es lo mismo que BitLocker completo con sus opciones de administración. Home está bien para uso personal y permite iniciar sesión con una cuenta Microsoft.

Windows Pro agrega las funciones que necesita una pequeña empresa: unión a dominio (Active Directory y Microsoft Entra ID, antes Azure AD), Group Policy, BitLocker y BitLocker To Go, la capacidad de alojar conexiones entrantes de Remote Desktop, virtualización con Hyper-V y soporte para la administración empresarial de actualizaciones. Pro es la edición mínima para la mayoría de los equipos de escritorio corporativos. Si un usuario con Home necesita alguna de estas funciones, puedes actualizar la edición in-place ingresando una clave de producto de Pro, sin reinstalar.

Windows Enterprise se licencia a organizaciones mediante licenciamiento por volumen o suscripciones. Incluye todo lo de Pro más funciones avanzadas de seguridad y administración pensadas para grandes flotas de equipos, como control adicional de aplicaciones y opciones de despliegue. Windows Education es, en esencia, la funcionalidad de nivel Enterprise licenciada a escuelas y universidades. Para el examen, considera Enterprise y Education como 'todo lo que tiene Pro, y más'.

Este es el resumen que debes memorizar. BitLocker: Pro, Enterprise, Education (no Home). Unión a dominio: Pro, Enterprise, Education (no Home). Editor de Group Policy: Pro, Enterprise, Education (no Home). Host de Remote Desktop: Pro, Enterprise, Education (no Home). Todas las ediciones pueden usar el cliente de Remote Desktop para conectarse a otra computadora.

Considera también los requisitos de hardware y las rutas de actualización. Windows 11 requiere, entre otras cosas, un chip TPM (Trusted Platform Module) 2.0, firmware UEFI con capacidad de Secure Boot y un procesador compatible. Windows 10 llegó al fin del soporte en octubre de 2025, así que las organizaciones que todavía lo usan necesitan actualizar o comprar actualizaciones de seguridad extendidas (ESU). Puedes comprobar tu edición y versión actuales con winver o en Settings, en System > About.

Términos clave

Domain join (unión a dominio)
Agregar una computadora a un dominio de Active Directory (o Entra ID) para que se administre de forma centralizada y los usuarios inicien sesión con cuentas del dominio.
Group Policy (directiva de grupo)
Una forma centralizada de aplicar configuraciones y ajustes de seguridad a usuarios y computadoras; el editor local es gpedit.msc.
Remote Desktop host (host de Escritorio remoto)
Una computadora que acepta conexiones entrantes del Remote Desktop Protocol (RDP); no está disponible en las ediciones Home.
BitLocker
Cifrado de volumen completo de Windows, disponible en las ediciones Pro, Enterprise y Education.
Edition upgrade (actualización de edición)
Cambiar, por ejemplo, de Home a Pro ingresando una nueva clave de producto, conservando apps y datos.
Ejemplo real

Un empleado nuevo lleva al trabajo una laptop comprada en una tienda minorista, y el técnico no encuentra la opción para unirla al dominio de la empresa. Al revisar Settings > System > About ve que tiene Windows 11 Home. El técnico compra una clave de actualización a Pro, la ingresa en Activation, reinicia, y ahora aparece la opción de unión a dominio.

Consejo para el examen: Si una pregunta menciona unión a dominio, gpedit.msc, BitLocker o aceptar conexiones de Remote Desktop y el equipo tiene Home, la respuesta es actualizar a Pro (o superior).

Comprueba lo que sabes

¿Puede una computadora con Windows 11 Home conectarse a otra computadora usando Remote Desktop?

Sí, puede usar el cliente de Remote Desktop para conectarse hacia afuera; simplemente no puede actuar como host de Remote Desktop que acepte conexiones entrantes.

¿Cuál es la edición de Windows más básica que puede unirse a un dominio de Active Directory?

Pro.

¿Cómo pasas de Home a Pro sin reinstalar?

Ingresando una clave de producto de Pro (o comprando la actualización) en Settings, en Activation; Windows actualiza la edición in-place.
