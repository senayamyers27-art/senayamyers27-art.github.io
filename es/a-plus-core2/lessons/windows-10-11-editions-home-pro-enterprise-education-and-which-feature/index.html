CompTIA A+ Core 2 220-1202

Ediciones de Windows 10/11 (Home, Pro, Enterprise, Education) y las funciones de cada una: BitLocker, unión a dominio, Group Policy, host de Remote Desktop

Microsoft vende Windows 10 y Windows 11 en varias ediciones. Comparten el mismo núcleo, pero las funciones empresariales solo se activan en las ediciones superiores. El examen A+ a menudo describe una necesidad, como 'la laptop debe unirse al dominio de la empresa' o 'la unidad debe cifrarse con BitLocker', y pregunta qué edición la admite o qué hacer cuando la edición actual no puede. Memorizar la línea divisoria entre Home y Pro responde la mayoría de estas preguntas.

Windows Home está dirigido a consumidores. No puede unirse a un dominio de Active Directory, no incluye el Editor de directivas de grupo local (gpedit.msc), no puede actuar como host de Remote Desktop (aunque sí puede conectarse a otras computadoras con el cliente de Remote Desktop) y no incluye la administración completa de BitLocker. Muchos dispositivos con Home ofrecen una función más sencilla de 'Device encryption' (cifrado de dispositivo) cuando el hardware lo permite, pero no es lo mismo que BitLocker completo con sus opciones de administración y BitLocker To Go. Home está bien para uso personal y normalmente inicia sesión con una cuenta Microsoft.

Windows Pro agrega lo que necesita una pequeña empresa: unión a dominio (Active Directory y Microsoft Entra ID, antes Azure AD), Group Policy, BitLocker y BitLocker To Go, la capacidad de alojar conexiones entrantes de Remote Desktop, virtualización con Hyper-V y administración empresarial de actualizaciones. Pro es la edición mínima para la mayoría de los equipos de escritorio corporativos. Si un usuario con Home necesita alguna de estas funciones, puedes actualizar la edición in-place ingresando una clave de producto de Pro o comprando la actualización, sin reinstalar ni perder datos.

Windows Enterprise se licencia a organizaciones mediante licenciamiento por volumen o suscripciones. Incluye todo lo de Pro más funciones avanzadas de seguridad y administración pensadas para grandes flotas de equipos, como control adicional de aplicaciones, protección de credenciales y opciones de despliegue. Windows Education es, en esencia, la funcionalidad de nivel Enterprise licenciada a escuelas y universidades. Para el examen, considera Enterprise y Education como 'todo lo que tiene Pro, y más', y recuerda que no se venden en caja al público para consumidores individuales. Este es el resumen que debes memorizar. BitLocker: Pro, Enterprise, Education, no Home. Unión a dominio: Pro, Enterprise, Education, no Home. Editor de directivas de grupo: Pro, Enterprise, Education, no Home. Host de Remote Desktop: Pro, Enterprise, Education, no Home. Todas las ediciones pueden usar el cliente de Remote Desktop para conectarse a otra computadora. La diferencia entre ser cliente de Remote Desktop y ser host de Remote Desktop es una trampa favorita del examen: Home puede conectarse a un equipo con Pro, pero nadie puede conectarse a un equipo con Home mediante Remote Desktop.

Veamos un ejemplo práctico. Una pequeña firma contable compra una laptop en una tienda minorista para un empleado nuevo, y llega con Windows Home. Cuando intentas unirla al dominio de la firma, la opción para unirse a un dominio no está disponible, y la política de la firma además exige BitLocker. En lugar de borrar el equipo, abres Settings, vas a System y Activation, y actualizas la edición a Pro con una clave comprada. Después de reiniciar, la laptop puede unirse al dominio, recibir Group Policy y tener BitLocker habilitado, con los archivos del usuario intactos.

Considera también los requisitos de hardware y las fechas de soporte. Windows 11 requiere, entre otras cosas, un chip TPM (Trusted Platform Module) 2.0, firmware UEFI con capacidad de Secure Boot y un procesador compatible. Windows 10 llegó al fin del soporte en octubre de 2025, así que las organizaciones que todavía lo usan necesitan actualizar o inscribirse en las actualizaciones de seguridad extendidas. Puedes consultar la edición y la versión actuales con winver o en Settings, en System y About.

Errores comunes: suponer que Device encryption en Home es lo mismo que BitLocker con todas sus herramientas de administración; reinstalar Windows para cambiar de edición cuando una actualización in-place con clave funciona y conserva los datos; olvidar que Home sí puede usar el cliente de Remote Desktop para llegar a otros equipos; y suponer que Enterprise se puede comprar en una tienda para una sola PC doméstica. Otra trampa es culpar a la red cuando falla Remote Desktop hacia una PC con Home, cuando la causa real es la edición.

Las preguntas del examen suelen dar un síntoma en un equipo con Home. 'Falta la opción para unirse a un dominio', 'no se encuentra gpedit.msc', 'BitLocker no está disponible en Control Panel' o 'los compañeros no pueden conectarse a esta PC con Remote Desktop' llevan todos a la misma respuesta: actualizar a Pro o superior. 'Organización grande, licenciamiento por volumen, seguridad avanzada' sugiere Enterprise, y 'licenciamiento para escuelas o universidades' sugiere Education. Si la pregunta plantea qué necesita Windows 11 que a las PC antiguas les puede faltar, busca TPM 2.0 y Secure Boot.

Términos clave

Windows Home
La edición para consumidores, sin unión a dominio, Editor de directivas de grupo, administración de BitLocker ni host de Remote Desktop.
Windows Pro
La edición empresarial que agrega unión a dominio, Group Policy, BitLocker, host de Remote Desktop e Hyper-V.
Windows Enterprise
La edición con licenciamiento por volumen para organizaciones, con las funciones de Pro más seguridad y administración avanzadas.
Windows Education
Funciones de nivel Enterprise licenciadas para escuelas y universidades.
Unión a dominio (domain join)
Agregar una computadora a un directorio como Active Directory para que use cuentas y políticas centralizadas.
Host de Remote Desktop
Una computadora que acepta conexiones entrantes de Remote Desktop, disponible en Pro y superiores.
TPM 2.0
Un chip de seguridad de hardware que almacena claves, requerido por Windows 11 y usado por BitLocker.
Ejemplo real

Una trabajadora remota le pide a la mesa de ayuda conectarse a su PC de casa con Remote Desktop desde la oficina, pero la conexión falla cada vez. La mesa de ayuda descubre que la PC de casa tiene Windows Home, que solo puede ser cliente de Remote Desktop. Le sugieren una herramienta de soporte remoto compatible por ahora y le explican que alojar Remote Desktop requiere actualizar esa PC a Pro.

Consejo para el examen: Si una pregunta menciona unión a dominio, gpedit.msc, BitLocker o aceptar conexiones de Remote Desktop en un equipo con Home, la respuesta es actualizar la edición a Pro o superior, no reinstalar.

Comprueba lo que sabes

Una laptop con Windows Home debe unirse al dominio de la empresa. ¿Cuál es la solución más sencilla?

Actualizar la edición a Pro con una clave de producto; Home no puede unirse a un dominio y la actualización no requiere reinstalar.

¿Puede una PC con Windows Home conectarse a otra computadora usando Remote Desktop?

Sí, todas las ediciones incluyen el cliente de Remote Desktop; a Home solo le falta la capacidad de alojar sesiones entrantes.

¿Qué ediciones incluyen BitLocker?

Pro, Enterprise y Education; Home no incluye BitLocker completo.

¿Qué componentes de hardware suelen faltar en las PC antiguas que no pueden ejecutar Windows 11?

Un chip TPM 2.0, firmware UEFI con capacidad de Secure Boot o un procesador compatible.
