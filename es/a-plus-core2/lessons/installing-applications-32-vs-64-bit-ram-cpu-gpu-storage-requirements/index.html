CompTIA A+ Core 2 220-1202

Instalación de aplicaciones: 32 vs. 64 bits, requisitos de RAM/CPU/GPU/almacenamiento, métodos de distribución (ISO, descarga, imagen) e impacto en el negocio

Instalar software parece sencillo, pero el trabajo de un técnico es asegurarse de que realmente funcione, sea adecuado para el hardware y no interrumpa el negocio. Antes de hacer clic en Install, verifica la compatibilidad y los requisitos.

Empieza por la arquitectura. Una aplicación de 32 bits (x86) puede direccionar una cantidad limitada de memoria (unos 4 GB), mientras que una aplicación de 64 bits (x64) puede usar mucho más. Un sistema operativo Windows de 64 bits ejecuta tanto apps de 64 bits como la mayoría de las apps de 32 bits, usando una capa de compatibilidad y guardando los programas de 32 bits en la carpeta C:\Program Files (x86), mientras que los programas de 64 bits van en C:\Program Files. Un sistema operativo de 32 bits no puede ejecutar aplicaciones de 64 bits en absoluto. En un sistema operativo de 64 bits se requieren controladores de 64 bits. Windows 11 solo está disponible en versiones de 64 bits. Ten en cuenta también que los dispositivos basados en ARM usan un conjunto de instrucciones diferente, así que verifica que el software ofrezca una versión para ARM o que sea compatible mediante emulación.

Luego, compara los requisitos del sistema publicados con los del equipo. RAM: una app que necesita más memoria de la que hay libre paginará al disco y se volverá lenta. CPU: verifica la velocidad requerida, la cantidad de núcleos y cualquier característica de instrucciones necesaria. GPU: el software con uso intensivo de gráficos, como CAD, edición de video o juegos, puede necesitar una tarjeta gráfica dedicada, una cantidad mínima de memoria de video (VRAM) o compatibilidad con una API de gráficos en particular. Almacenamiento: verifica tanto el espacio libre para la instalación como si la app espera un SSD para tener un rendimiento aceptable. Revisa también la versión del sistema operativo que admite el fabricante, cualquier token de hardware o periférico externo, y los frameworks necesarios.

El software puede distribuirse de varias maneras. Las descargas desde el sitio web del fabricante o desde una tienda de apps son comunes para instalaciones individuales; usa siempre fuentes confiables y verifica el hash del archivo cuando el fabricante lo publique. Un archivo ISO es una imagen de disco que montas (con doble clic en Windows) o grabas, y suele usarse para suites grandes y medios de sistemas operativos. En las organizaciones, las aplicaciones a menudo se empaquetan en una imagen estándar del sistema operativo o se distribuyen mediante herramientas de administración, para que cientos de máquinas reciban la misma versión sin que los técnicos visiten cada escritorio. Los medios físicos, como las unidades USB, todavía se usan en algunos entornos.

Por último, considera el impacto en el negocio. Una instalación nueva puede entrar en conflicto con el software existente, cambiar las asociaciones de archivos, requerir un reinicio en horario laboral, necesitar licencias para cada usuario o abrir nuevos puertos de red. En el dispositivo de un usuario, una instalación podría afectar solo a esa persona; en un sistema crítico para el negocio (line-of-business) puede detener a todo un departamento. Por eso las organizaciones prueban primero el software, programan los despliegues, siguen la gestión de cambios y documentan qué versión está instalada en cada lugar. Considera el impacto en el dispositivo (rendimiento, estabilidad), en la red (ancho de banda para descargas grandes), en las operaciones (tiempo de inactividad) y en el negocio (cumplimiento de licencias y soporte).

Términos clave

64-bit application (aplicación de 64 bits)
Software compilado para un procesador y un sistema operativo de 64 bits, capaz de direccionar mucho más de 4 GB de memoria.
Program Files (x86)
La carpeta donde Windows de 64 bits instala las aplicaciones de 32 bits, separada de los programas de 64 bits en Program Files.
System requirements (requisitos del sistema)
La CPU, RAM, GPU, almacenamiento y sistema operativo mínimos o recomendados que un programa necesita para funcionar correctamente.
VRAM
Video RAM: memoria dedicada en una tarjeta gráfica que se usa para texturas y datos de fotogramas.
ISO
Una imagen de un disco óptico en un solo archivo que se usa para distribuir instaladores; puede montarse o grabarse.
Ejemplo real

El departamento de ingeniería compra una suite de modelado 3D que requiere un sistema operativo de 64 bits, 16 GB de RAM y una GPU dedicada. Antes del despliegue, el técnico revisa el inventario de activos, encuentra seis PC antiguas con gráficos integrados y 8 GB de RAM, y recomienda actualizar esas máquinas antes de la implementación en lugar de dejar que los usuarios descubran que el software no se puede usar.

Consejo para el examen: Un sistema operativo de 64 bits ejecuta apps de 32 bits, pero un sistema operativo de 32 bits no puede ejecutar apps de 64 bits. Si un instalador se niega a ejecutarse en un equipo antiguo, verifica si el sistema operativo es de 32 bits.

Comprueba lo que sabes

¿Se puede instalar una aplicación de 64 bits en Windows de 32 bits?

No. Un sistema operativo de 32 bits no puede ejecutar aplicaciones de 64 bits; el sistema operativo debe ser de 64 bits.

¿Dónde instala Windows de 64 bits las aplicaciones de 32 bits?

En C:\Program Files (x86).

Menciona dos impactos en el negocio que debes considerar antes de instalar software nuevo en toda la empresa.

Por ejemplo: costos y cumplimiento de licencias, tiempo de inactividad o reinicios en horario laboral, conflictos con apps existentes, ancho de banda de red para el despliegue, y necesidades de soporte y capacitación.
