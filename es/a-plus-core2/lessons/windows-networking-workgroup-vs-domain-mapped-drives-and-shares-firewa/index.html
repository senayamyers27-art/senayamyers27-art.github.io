CompTIA A+ Core 2 220-1202

Redes en Windows: grupo de trabajo vs. dominio, unidades asignadas y recursos compartidos, excepciones del firewall, direccionamiento estático vs. DHCP, configuración de VPN y proxy, perfiles de red público vs. privado, conexiones de uso medido

Las preguntas sobre redes en Windows plantean cómo se organizan las computadoras, cómo llegan los usuarios a los archivos compartidos y por qué una PC no puede conectarse cuando las demás sí. Los conceptos son sencillos una vez que ves qué controla cada configuración. Las computadoras con Windows pueden organizarse de dos maneras. En un grupo de trabajo (workgroup), cada computadora es un par que mantiene sus propias cuentas de usuario locales, así que un usuario necesita una cuenta en cada equipo al que quiera acceder. Los grupos de trabajo son adecuados para oficinas pequeñas con unas pocas computadoras y sin servidor. En un dominio, un servidor que ejecuta Active Directory Domain Services (un controlador de dominio) contiene una base de datos central de usuarios, equipos y directivas. Los usuarios inician sesión una vez con una cuenta de dominio desde cualquier equipo unido, y los administradores aplican Group Policy a todos. Unirse a un dominio requiere Windows Pro o superior. HomeGroup era una función antigua para compartir en el hogar y ya no existe en las versiones actuales de Windows.

Para compartir una carpeta, abre sus Properties, usa la pestaña Sharing (Advanced Sharing) para establecer un nombre de recurso compartido y los permisos de recurso compartido, y recuerda que los permisos NTFS de la pestaña Security también se aplican. Los usuarios llegan al recurso compartido mediante una ruta UNC (Universal Naming Convention) como \\fileserver\sales. Asignar una unidad le da una letra a esa ruta para que parezca una unidad local: en File Explorer elige 'Map network drive' y marca 'Reconnect at sign-in' para que sea persistente, o usa net use S: \\fileserver\sales /persistent:yes. Un nombre de recurso compartido que termina en $ queda oculto al explorar, y Windows crea recursos compartidos administrativos como C$ y ADMIN$ para los administradores.

Windows Defender Firewall bloquea de forma predeterminada el tráfico entrante no solicitado. Cuando una aplicación o un servicio debe aceptar conexiones, creas una excepción: permites una app a través del firewall en la interfaz básica, o creas una regla de entrada para un programa, puerto y protocolo específicos en Windows Defender Firewall with Advanced Security (wf.msc). Las reglas pueden aplicarse a perfiles de red específicos. Cada conexión recibe un perfil. Public (público) es para lugares no confiables, como las cafeterías; desactiva la detección de redes y el uso compartido de archivos y aplica reglas más estrictas. Private (privado) es para redes confiables de hogar u oficina pequeña; permite que la computadora sea detectada y comparta archivos e impresoras. Domain se aplica automáticamente cuando la computadora puede comunicarse con su controlador de dominio.

El direccionamiento IP puede ser dinámico o estático. Con DHCP (Dynamic Host Configuration Protocol), la computadora recibe automáticamente su dirección IP, máscara de subred, puerta de enlace predeterminada y servidores DNS, lo cual es lo adecuado para la mayoría de los clientes. Una dirección estática se escribe a mano en las propiedades IPv4 del adaptador y es adecuada para servidores, impresoras y dispositivos de red que nunca deben cambiar de dirección. Si un cliente DHCP muestra una dirección que empieza con 169.254, es una dirección APIPA (Automatic Private IP Addressing), lo que significa que ningún servidor DHCP respondió. También puedes establecer una configuración alternativa que se usa cuando DHCP no está disponible, lo que ayuda a las laptops que se mueven entre una oficina y un sitio con direccionamiento fijo.

Una VPN (red privada virtual) crea un túnel cifrado a través de una red no confiable hacia una red remota; agrégala en Settings, Network and internet, VPN, o instala el cliente del proveedor. Un servidor proxy reenvía las solicitudes web en nombre del usuario para filtrar, registrar o almacenar en caché; configúralo en Network and internet, Proxy, ya sea automáticamente con un script de configuración o manualmente con una dirección y un puerto. Una configuración de proxy incorrecta es una razón común por la que una PC no puede navegar mientras las demás sí. Por último, una conexión de uso medido (metered connection) le indica a Windows que los datos cuestan dinero, como en un punto de acceso móvil, así que limita las descargas en segundo plano, como algunas actualizaciones y la sincronización.

Veamos un ejemplo práctico. La laptop de una empleada nueva puede acceder a sitios web, pero no ve la impresora de la oficina ni los recursos compartidos del servidor de archivos, y sus compañeros tampoco la ven a ella. ipconfig muestra una dirección normal del ámbito DHCP de la oficina, así que el direccionamiento está bien. En Settings descubres que la red Wi-Fi de la oficina se marcó como Public cuando se conectó por primera vez, lo que deshabilita la detección de redes y el uso compartido de archivos. Cambias el perfil a Private, ya que la oficina es una red confiable sin dominio, y aparecen la impresora y los recursos compartidos. Luego asignas el recurso compartido de ventas a S: con reconexión al iniciar sesión.

Errores comunes: tratar una dirección 169.254 como una red que funciona; darle a una impresora una dirección DHCP y luego perderla cuando cambia la concesión; marcar como Private la red de un café; abrir un puerto del firewall para todos los perfiles cuando solo lo necesita el perfil de dominio; confundir una VPN (túnel cifrado hacia una red) con un proxy (un intermediario para solicitudes web); y olvidar que los permisos de recurso compartido y los permisos NTFS se aplican ambos a través de la red, y gana el más restrictivo.

Las preguntas del examen usan palabras clave claras. 'Cuentas y directivas centralizadas' significa dominio; 'cada PC tiene sus propias cuentas' significa grupo de trabajo. 'La dirección empieza con 169.254' significa que DHCP falló. 'La impresora siempre debe conservar la misma dirección' significa IP estática. 'No puede ver otras computadoras en una red confiable' significa que el perfil es Public. 'Solo esta PC no puede navegar; las demás sí' sugiere una configuración de proxy incorrecta. 'Evitar descargas grandes en el punto de acceso del teléfono' significa conexión de uso medido. 'Acceder de forma segura a los recursos de la empresa desde casa' significa VPN.

Términos clave

Grupo de trabajo (workgroup)
Una organización de igual a igual en la que cada computadora con Windows mantiene sus propias cuentas locales.
Dominio (domain)
Una red administrada centralmente en la que un controlador de dominio proporciona cuentas, autenticación y Group Policy.
Ruta UNC
Una ruta de red con el formato \\server\share que se usa para acceder a recursos compartidos.
Unidad asignada (mapped drive)
Una letra de unidad asignada a un recurso compartido de red para que aparezca como una unidad local.
APIPA
Automatic Private IP Addressing, que asigna una dirección 169.254.x.x cuando ningún servidor DHCP responde.
Perfil de red (network profile)
La categoría Public, Private o Domain que define el comportamiento de detección, uso compartido y firewall de una conexión.
Servidor proxy
Un servidor que reenvía solicitudes web en nombre de un cliente para filtrar, registrar o almacenar en caché.
Conexión de uso medido (metered connection)
Una configuración que le indica a Windows que los datos son limitados o costosos para que reduzca las descargas en segundo plano.
Ejemplo real

Una contadora que trabaja a distancia puede navegar por la web desde su casa, pero no puede abrir el recurso compartido de finanzas. No ha conectado la VPN de la empresa, así que su laptop no tiene ruta hacia el servidor interno. Una vez que la VPN se conecta, \\fileserver\finance se abre y su unidad asignada se vuelve a conectar, porque el tráfico ahora viaja por el túnel cifrado hacia la red de la oficina.

Consejo para el examen: Una dirección 169.254.x.x significa que DHCP falló, no que la red esté bien. El perfil Public bloquea la detección y el uso compartido; Private los permite en redes confiables.

Comprueba lo que sabes

Una PC muestra la dirección 169.254.12.7. ¿Qué te indica eso?

Es una dirección APIPA, así que la PC no pudo comunicarse con un servidor DHCP.

¿Por qué una laptop en una red de oficina confiable podría no ver las impresoras compartidas?

La red puede estar configurada con el perfil Public, que desactiva la detección de redes y el uso compartido de archivos.

¿Qué comando asigna la unidad S: a un recurso compartido de forma persistente?

net use S: \\server\share /persistent:yes.

¿Cuál es la principal diferencia entre un grupo de trabajo y un dominio?

Un grupo de trabajo tiene cuentas locales separadas en cada PC, mientras que un dominio usa cuentas y directivas centralizadas en un controlador de dominio.
