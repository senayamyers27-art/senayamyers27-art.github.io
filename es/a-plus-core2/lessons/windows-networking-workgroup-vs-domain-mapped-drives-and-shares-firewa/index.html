CompTIA A+ Core 2 220-1202

Redes en Windows: grupo de trabajo vs. dominio, unidades asignadas y recursos compartidos, excepciones del firewall, direccionamiento estático vs. DHCP, configuración de VPN y proxy, perfiles de red público vs. privado, conexiones de uso medido

Las computadoras con Windows pueden organizarse de dos maneras. En un grupo de trabajo (workgroup), cada computadora es un par que guarda sus propias cuentas de usuario locales, así que un usuario necesita una cuenta en cada máquina a la que quiera acceder. Los grupos de trabajo son adecuados para oficinas pequeñas con unas pocas computadoras. En un dominio (domain), un servidor que ejecuta Active Directory Domain Services (un controlador de dominio) contiene una base de datos central de usuarios, computadoras y directivas. Los usuarios inician sesión una sola vez con una cuenta de dominio desde cualquier computadora unida, y los administradores aplican Group Policy a todos. Los dominios requieren Windows Pro o superior. El homegroup (grupo en el hogar) era una función antigua para compartir en casa y ya no existe en las versiones actuales de Windows.

Para compartir una carpeta, abre sus Properties, usa la pestaña Sharing (Advanced Sharing) para definir un nombre de recurso compartido y los permisos de recurso compartido, y recuerda que los permisos NTFS de la pestaña Security también se aplican. Los usuarios acceden al recurso compartido mediante una ruta UNC (Universal Naming Convention) como \\fileserver\sales. Asignar una unidad (mapping) le da una letra a esa ruta para que parezca una unidad local: en File Explorer elige 'Map network drive' y marca 'Reconnect at sign-in' para que sea persistente, o usa net use S: \\fileserver\sales /persistent:yes. Un nombre de recurso compartido que termina en $ queda oculto al explorar, y Windows crea recursos compartidos administrativos como C$ y ADMIN$ para los administradores.

Windows Defender Firewall bloquea de forma predeterminada el tráfico entrante no solicitado. Cuando una aplicación o un servicio debe aceptar conexiones, creas una excepción: permites una app a través del firewall en la interfaz básica, o creas una regla de entrada para un programa, puerto y protocolo específicos en Windows Defender Firewall with Advanced Security (wf.msc). Las reglas pueden aplicarse a perfiles de red específicos.

A cada conexión de red se le asigna un perfil. Public (Público) es para lugares no confiables como las cafeterías; desactiva la detección de redes y el uso compartido de archivos, y aplica reglas de firewall más estrictas. Private (Privado) es para redes confiables de casa u oficina pequeña; permite que la computadora sea detectada y comparta archivos e impresoras. Domain (Dominio) se aplica automáticamente cuando la computadora puede comunicarse con su controlador de dominio. Si un usuario no puede ver otras PC en la red de la oficina, verifica que la red no esté marcada como Public.

El direccionamiento IP puede ser dinámico o estático. Con DHCP (Dynamic Host Configuration Protocol), la computadora recibe automáticamente su dirección IP, máscara de subred, puerta de enlace predeterminada y servidores DNS, lo cual es lo correcto para la mayoría de los clientes. Una dirección estática se escribe a mano en las propiedades IPv4 del adaptador y es adecuada para servidores e impresoras que nunca deben cambiar de dirección. Si un cliente DHCP muestra una dirección que empieza con 169.254, se trata de una dirección APIPA (Automatic Private IP Addressing), lo que significa que ningún servidor DHCP respondió. También puedes definir una configuración alternativa que se usa cuando DHCP no está disponible.

Una VPN (red privada virtual) crea un túnel cifrado hacia una red remota; agrega una en Settings > Network and internet > VPN o instala el cliente del proveedor. Un servidor proxy reenvía las solicitudes web en nombre del usuario para filtrarlas o almacenarlas en caché; configúralo en Network and internet > Proxy, ya sea automáticamente con un script de configuración o manualmente con una dirección y un puerto. Una configuración de proxy incorrecta es una razón común por la que una PC no puede navegar mientras las demás sí. Por último, una conexión de uso medido (metered connection) le indica a Windows que los datos cuestan dinero, como en un hotspot móvil, así que limita las descargas en segundo plano, como algunas actualizaciones y la sincronización.

Términos clave

Workgroup (grupo de trabajo)
Una organización de igual a igual en la que cada computadora administra sus propias cuentas de usuario locales.
Domain (dominio)
Un grupo de computadoras y usuarios administrado de forma centralizada y controlado por controladores de dominio de Active Directory.
UNC path (ruta UNC)
Ruta Universal Naming Convention hacia un recurso de red, con el formato \\server\share.
APIPA
Automatic Private IP Addressing: una dirección 169.254.x.x autoasignada que se usa cuando ningún servidor DHCP responde.
Metered connection (conexión de uso medido)
Una red marcada como limitada o costosa, por lo que Windows restringe el uso de datos en segundo plano.
Ejemplo real

La laptop de la gerente de una oficina no puede ver la impresora compartida ni el servidor de archivos, mientras que sus colegas sí. El técnico descubre que la red Wi-Fi de la oficina quedó configurada como Public cuando la laptop se conectó por primera vez. Al cambiar el perfil de red a Private se activan la detección de redes y el uso compartido de archivos e impresoras, y los recursos aparecen.

Consejo para el examen: Una dirección 169.254.x.x significa que DHCP falló, no que la red esté bien. El perfil Public bloquea la detección y el uso compartido; Private los permite.

Comprueba lo que sabes

¿Cuál es la principal diferencia administrativa entre un grupo de trabajo y un dominio?

En un grupo de trabajo cada computadora tiene sus propias cuentas locales; en un dominio, las cuentas y las directivas se administran de forma centralizada en los controladores de dominio.

¿Por qué asignarías una dirección IP estática a una impresora de red?

Para que su dirección nunca cambie y los clientes configurados para imprimir en esa dirección sigan funcionando.

Una laptop conectada a un hotspot móvil sigue consumiendo muchos datos en actualizaciones. ¿Qué configuración ayuda?

Marcar la conexión como de uso medido (metered), lo que limita las descargas en segundo plano.
