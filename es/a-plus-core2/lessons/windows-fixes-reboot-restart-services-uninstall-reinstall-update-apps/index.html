CompTIA A+ Core 2 220-1202

Soluciones en Windows: reiniciar, reiniciar servicios, desinstalar/reinstalar/actualizar apps, agregar recursos, verificar requisitos, sfc y DISM, reparar Windows, System Restore, reinstalar la imagen, revertir actualizaciones, reconstruir el perfil de usuario

Una vez que identificaste una causa probable, elige una solución. Una buena regla es probar la solución menos disruptiva que atienda la causa y pasar a opciones más drásticas solo si es necesario. Respalda siempre los datos del usuario antes de cualquier acción que pueda perderlos, y documenta lo que hiciste.

Empieza por lo simple. Un reinicio libera la memoria, reinicia los servicios y completa las actualizaciones pendientes; resuelve una cantidad sorprendente de problemas. Recuerda que Shut down con inicio rápido no recarga el kernel por completo, así que elige Restart. Si un servicio se detuvo, reinícialo en Services (services.msc) o en Task Manager, configura correctamente su tipo de inicio y revisa sus dependencias. Para una aplicación que se comporta mal, primero actualízala (el fabricante puede haber corregido el error), luego prueba la opción de reparación en la configuración de Apps y después desinstálala y reinstálala para reemplazar los archivos y configuraciones dañados.

Si al sistema simplemente le falta capacidad, agrega recursos: más RAM para las advertencias de poca memoria, una unidad más grande o más rápida para un disco lleno, o un archivo de paginación más grande. Antes de culpar a Windows, verifica los requisitos: comprueba que la versión de la aplicación, del controlador o del sistema operativo cumpla con los requisitos indicados por el fabricante y sea compatible con esta edición y arquitectura.

Para los archivos del sistema dañados, ejecuta sfc /scannow desde un símbolo del sistema con privilegios elevados. Si no puede repararlo todo, ejecuta DISM /Online /Cleanup-Image /RestoreHealth para reparar el almacén de componentes y luego vuelve a ejecutar sfc. Si Windows está muy dañado, repara Windows: usa Startup Repair desde el Windows Recovery Environment para los problemas de arranque, o realiza una instalación de reparación in-place que reinstala Windows conservando las apps y los archivos.

Deshaz los cambios recientes cuando los problemas empezaron después de uno. System Restore revierte los archivos del sistema, los controladores, el registro y los programas instalados a un punto de restauración sin tocar los documentos personales. Puedes revertir un controlador en Device Manager y revertir actualizaciones desinstalando una actualización de calidad reciente (Settings > Windows Update > Update history > Uninstall updates) o volviendo a la versión de características anterior dentro del plazo permitido. Pausa las actualizaciones mientras esperas una solución.

Para los problemas específicos de un perfil, como configuraciones que no se guardan, un perfil temporal o apps que fallan para un usuario mientras que para los demás funcionan bien, reconstruye el perfil de usuario. El método habitual es respaldar los datos del usuario, iniciar sesión como administrador, renombrar o eliminar la carpeta del perfil dañado y su entrada en el registro (ProfileList), y hacer que el usuario vuelva a iniciar sesión para que Windows cree un perfil nuevo; luego vuelve a copiar los datos.

Por último, reinstala la imagen de la computadora (reimage), es decir, reinstala una imagen estándar o haz una instalación limpia, cuando el sistema esté muy dañado, infectado sin que puedas confiar en la limpieza, o cuando diagnosticar tomaría más tiempo que reconstruir. Reset this PC es una variante integrada que puede conservar o eliminar los archivos personales. Reinstalar la imagen es confiable, pero lento para el usuario, así que asegúrate de que los datos estén respaldados y de que las aplicaciones puedan reinstalarse.

Términos clave

System Restore (Restaurar sistema)
Revierte los archivos del sistema, el registro, los controladores y los programas a un punto de restauración, conservando los archivos personales.
Reimage (reinstalar la imagen)
Reemplazar la instalación del sistema operativo de una computadora con una imagen estándar nueva o una instalación limpia.
Roll back driver (revertir controlador)
Una opción de Device Manager que reinstala la versión del controlador instalada anteriormente.
Repair install (instalación de reparación)
Reinstalar Windows in-place para reemplazar los archivos del sistema conservando las aplicaciones y los datos.
User profile rebuild (reconstrucción del perfil de usuario)
Crear un perfil de usuario nuevo para corregir un daño y luego restaurar en él los datos del usuario.
Ejemplo real

Después de una actualización mensual, una aplicación crítica del negocio falla al iniciar para todos los usuarios de un modelo de PC. El técnico confirma la coincidencia de fechas en Reliability Monitor, desinstala la actualización específica desde Update history, pausa las actualizaciones en esas máquinas e informa el conflicto al fabricante.

Consejo para el examen: Elige la solución menos invasiva que corresponda a la causa: reiniciar antes que reinstalar, reinstalar la app antes que reparar Windows, System Restore antes que reinstalar la imagen. Si solo un usuario tiene el problema, sospecha del perfil.

Comprueba lo que sabes

Solo un usuario de una PC compartida recibe un perfil temporal al iniciar sesión. ¿Qué solución es adecuada?

Reconstruir el perfil de ese usuario: respaldar los datos, eliminar o renombrar el perfil dañado y dejar que Windows cree uno nuevo; luego restaurar los datos.

¿System Restore elimina los documentos de un usuario?

No; revierte los archivos del sistema, las configuraciones, los controladores y los programas, pero no toca los archivos personales.

¿Qué deberías ejecutar si sfc /scannow no puede reparar algunos archivos?

DISM /Online /Cleanup-Image /RestoreHealth, y luego sfc /scannow de nuevo.
