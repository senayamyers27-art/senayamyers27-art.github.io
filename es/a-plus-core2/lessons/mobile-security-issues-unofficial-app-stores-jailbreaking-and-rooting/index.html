CompTIA A+ Core 2 220-1202

Problemas de seguridad en móviles: tiendas de apps no oficiales, jailbreak y rooting, APK instalados por sideloading, tráfico de red alto, alertas de límite de datos, respuesta lenta, advertencias de seguridad falsas, comportamiento inesperado de las apps, archivos personales filtrados

Los dispositivos móviles están protegidos en gran medida por sus tiendas de apps y por los entornos aislados (sandboxes) del sistema operativo, que mantienen las apps aisladas entre sí y del sistema. La mayoría de los problemas de seguridad móvil comienzan cuando un usuario debilita esas protecciones, así que reconocer las causas y los síntomas es el núcleo de este tema.

Causas a las que hay que prestar atención: las tiendas de apps no oficiales (mercados de terceros) no revisan las apps como lo hacen las tiendas oficiales, y muchas alojan apps reempaquetadas con malware agregado. El sideloading consiste en instalar una app desde fuera de la tienda oficial; en Android normalmente significa descargar un archivo APK (Android Package) y permitir instalaciones desde fuentes desconocidas. Los APK instalados por sideloading se saltan la revisión de la tienda y son una vía común para distribuir spyware, stalkerware y troyanos bancarios. El jailbreak (iOS) y el rooting (Android) eliminan las restricciones del fabricante y dan control administrativo total. Eso también elimina el modelo de seguridad que mantiene aisladas las apps, puede detener las actualizaciones del sistema operativo, anula algunas garantías y hace que los sistemas MDM marquen o bloqueen el dispositivo. Las organizaciones normalmente prohíben las tres prácticas.

Síntomas que sugieren un compromiso: un tráfico de red alto y alertas de límite de datos cuando el usuario no ha cambiado sus hábitos pueden significar que un malware está enviando datos hacia afuera, descargando anuncios o participando en una botnet. La respuesta lenta, el sobrecalentamiento y el agotamiento rápido de la batería pueden significar procesos ocultos, como criptomineros o spyware. Las advertencias de seguridad falsas, ventanas emergentes que dicen 'tu teléfono está infectado' e insisten en que instales una app de limpieza o llames a un número, son scareware; el sistema operativo real no muestra advertencias de esa manera. El comportamiento inesperado de las apps incluye apps que se abren solas, apps nuevas que el usuario no instaló, configuraciones cambiadas, permisos inusuales o mensajes extraños enviados desde la cuenta. Los archivos personales filtrados, como fotos, mensajes o documentos que aparecen en internet o se usan para extorsión, indican datos robados, a menudo mediante apps maliciosas con permisos excesivos o una cuenta en la nube comprometida.

Pasos de respuesta: desconecta el dispositivo de las redes si sospechas una extracción de datos activa. Revisa las apps instaladas, especialmente las instaladas recientemente y las que tienen privilegios de administrador del dispositivo o de accesibilidad, y elimina todo lo que no reconozcas. Revisa los permisos de las apps. Ejecuta un análisis con una solución de seguridad móvil de buena reputación y actualiza el sistema operativo. Si el dispositivo tiene jailbreak, está rooteado o sigue mostrando síntomas, respalda solo los datos personales (no las apps) y realiza un restablecimiento de fábrica; luego restaura desde un respaldo confiable. Cambia desde un dispositivo limpio las contraseñas de las cuentas usadas en el dispositivo, habilita MFA y revisa las cuentas en la nube en busca de sesiones desconocidas. Si sospechas de stalkerware, ten en cuenta que la persona que lo instaló podría notar que se eliminó, y manéjalo con el cuidado apropiado para la seguridad del usuario.

La prevención es más sencilla: instala apps solo desde las tiendas oficiales, mantén actualizado el sistema operativo, usa políticas de MDM que bloqueen las fuentes desconocidas y detecten el jailbreak, y revisa los permisos periódicamente.

Términos clave

Sideloading (instalación lateral)
Instalar una app desde fuera de la tienda de apps oficial, por ejemplo desde un archivo APK descargado.
APK
Android Package: el formato de archivo que se usa para distribuir e instalar apps de Android.
Jailbreaking (jailbreak)
Eliminar las restricciones de iOS de Apple para obtener control total, lo que debilita el modelo de seguridad del dispositivo.
Rooting
Obtener acceso root (de administrador) en un dispositivo Android, eludiendo sus protecciones integradas.
Scareware
Alertas de seguridad falsas diseñadas para asustar a los usuarios y lograr que instalen malware o paguen por servicios inútiles.
Ejemplo real

El teléfono de un empleado activa una alerta de límite de datos a mitad de mes, y la batería se agota rápidamente. El técnico encuentra una app de video 'gratuita' instalada desde un sitio web como APK, con permisos de SMS, contactos y servicios de accesibilidad. La elimina, restablece el dispositivo desde un respaldo limpio, cambia las contraseñas del empleado y activa una política de MDM que bloquea las instalaciones desde fuentes desconocidas.

Consejo para el examen: El jailbreak y el rooting son causas; el alto uso de datos, el agotamiento de la batería, las advertencias falsas y el comportamiento extraño de las apps son síntomas. El remedio habitual para un dispositivo comprometido o con jailbreak es respaldar los datos personales y hacer un restablecimiento de fábrica.

Comprueba lo que sabes

¿Por qué el jailbreak o el rooting hacen que un dispositivo sea menos seguro?

Eliminan las restricciones del sistema operativo y el aislamiento (sandboxing) que separan las apps y protegen el sistema, y pueden detener las actualizaciones oficiales.

Un teléfono muestra una ventana emergente que dice que tiene 12 virus e insiste en una descarga. ¿Qué es probablemente?

Una advertencia de seguridad falsa (scareware), normalmente de un sitio web o una app maliciosa, no una alerta real del sistema operativo.

¿Qué podría indicar una alerta inesperada de límite de datos?

Malware o una app maliciosa que envía o recibe datos en segundo plano.
