CompTIA A+ Core 2 220-1202

Fundamentos de scripting: .bat, .ps1, .vbs, .sh, .js, .py; casos de uso (automatización, reinicios, asignación de unidades, instalaciones, respaldos, actualizaciones) y riesgos

Un script es un archivo de texto plano con comandos que un intérprete ejecuta en orden. Los scripts permiten a los técnicos automatizar tareas repetitivas, aplicar la misma configuración en muchas máquinas y evitar errores manuales. El examen A+ espera que reconozcas los tipos de script comunes por su extensión, sepas para qué se usan y entiendas los riesgos.

Tipos de script: .bat es un archivo por lotes (batch) de Windows que ejecuta el intérprete de Command Prompt (cmd.exe); usa comandos clásicos como net use y copy. .ps1 es un script de PowerShell, el lenguaje de scripting moderno y mucho más potente de Windows, capaz de administrar casi cualquier parte de Windows y muchos servicios en la nube; su directiva de ejecución (execution policy) controla si los scripts pueden ejecutarse. .vbs es VBScript, un lenguaje de scripting antiguo de Windows que ejecuta Windows Script Host, ahora obsoleto según Microsoft y común en scripts de inicio de sesión heredados y en malware. .sh es un script de shell para Linux y macOS, que ejecuta bash u otro shell. .js es JavaScript, que se usa en los navegadores web y con Node.js, y en Windows también puede ejecutarse mediante Windows Script Host. .py es Python, un lenguaje multiplataforma de propósito general popular para tareas de automatización y de datos.

Los componentes básicos de los scripts que debes reconocer incluyen las variables (almacenamiento con nombre para valores), los comentarios (notas que el intérprete ignora, como REM en batch, # en PowerShell, bash y Python, ' en VBScript y // en JavaScript), los bucles que repiten acciones, las sentencias condicionales if y los tipos de datos como cadenas (strings) y enteros (integers).

Casos de uso comunes: automatización básica de tareas repetitivas; reiniciar máquinas o servicios según un horario; volver a asignar unidades de red al iniciar sesión; instalar aplicaciones de forma silenciosa en muchas computadoras; iniciar actualizaciones; ejecutar respaldos y copiar archivos con robocopy o rsync; recopilar información o registros; y la administración remota de muchos dispositivos a la vez.

REM map-drives.bat: asigna las unidades compartidas al iniciar sesión
net use S: \\fileserver\sales /persistent:yes
net use H: \\fileserver\home\%USERNAME%

Riesgos y consideraciones: un script se ejecuta con los permisos de quien lo ejecuta, así que un error en un script ejecutado como administrador puede eliminar datos o dañar muchas máquinas a la vez. Prueba los scripts en un sandbox antes de desplegarlos. Los scripts descargados de internet pueden contener malware, y los atacantes suelen usar archivos de PowerShell, VBScript y JavaScript como adjuntos de correo o para ataques sin archivos, así que revisa los scripts antes de ejecutarlos, mantén las directivas de ejecución y los controles de aplicaciones, y firma digitalmente los scripts de confianza. Otros riesgos incluyen cambiar por accidente la configuración del sistema, fallos del navegador o del sistema por un mal manejo de los recursos, y scripts que consumen recursos en exceso. Nunca escribas contraseñas directamente en los scripts; usa en su lugar un almacén seguro de credenciales.

Términos clave

.ps1
Un archivo de script de PowerShell, el lenguaje de automatización moderno de Windows.
.bat
Un archivo por lotes (batch) de Windows con comandos de Command Prompt.
.sh
Un script de shell para Linux o macOS, que ejecuta bash u otro shell.
Execution policy (directiva de ejecución)
Configuración de PowerShell que controla si pueden ejecutarse scripts y cuáles, por ejemplo solo los firmados.
Variable
Un marcador con nombre en un script que almacena un valor para usarlo más adelante.
Ejemplo real

Cada empleado nuevo necesita que se le asignen las mismas cinco unidades de red. En lugar de asignarlas a mano, el técnico escribe un breve script batch de inicio de sesión con comandos net use, lo prueba en una máquina de laboratorio y lo asigna mediante Group Policy. Ahora todos los usuarios reciben automáticamente las mismas unidades al iniciar sesión.

Consejo para el examen: Asocia las extensiones con las plataformas: .bat, .ps1 y .vbs son de Windows; .sh es de Linux/macOS; .py y .js son multiplataforma. Las respuestas principales sobre riesgos son los cambios no intencionados en el sistema, la introducción de malware y los problemas de recursos, así que prueba antes de desplegar.

Comprueba lo que sabes

¿Qué tipo de archivo de script usarías para automatizar una tarea en un servidor Linux?

Un script de shell (.sh), o un script multiplataforma de Python (.py).

¿Por qué es peligroso ejecutar como administrador un script descargado sin revisarlo?

Se ejecuta con privilegios completos y podría contener malware o comandos que dañen el sistema.

Menciona tres usos comunes de los scripts en el soporte de TI.

Por ejemplo: asignar unidades, reiniciar máquinas o servicios, instalar aplicaciones, ejecutar respaldos, iniciar actualizaciones, recopilar información.
