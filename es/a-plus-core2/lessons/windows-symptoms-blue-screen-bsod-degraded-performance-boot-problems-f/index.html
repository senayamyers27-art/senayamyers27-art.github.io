CompTIA A+ Core 2 220-1202

Síntomas en Windows: pantalla azul (BSOD), rendimiento degradado, problemas de arranque, apagados frecuentes, servicios que no inician, fallos de aplicaciones, advertencias de poca memoria, advertencias de recursos del controlador USB, inestabilidad del sistema, no se encuentra el sistema operativo, carga lenta del perfil, desfase del reloj

La solución de problemas comienza por reconocer un síntoma y saber a qué suele apuntar. El examen describe lo que ve el usuario y pregunta por la causa más probable o el mejor paso siguiente, así que relaciona cada síntoma con sus causas comunes.

Una pantalla azul de la muerte (BSOD, blue screen of death), o error de detención (stop error), significa que Windows sufrió un error fatal y se detuvo para protegerse. La pantalla muestra un código de detención (stop code, como un código con nombre del tipo IRQL_NOT_LESS_OR_EQUAL) y Windows escribe un volcado de memoria. Las causas comunes son controladores defectuosos o incompatibles, RAM que está fallando, sobrecalentamiento, errores de disco y cambios recientes de hardware o software. Anota el código de detención, revisa Event Viewer y Reliability Monitor, y piensa en qué cambió recientemente. La inestabilidad del sistema, es decir, congelamientos aleatorios, reinicios y errores extraños, tiene la misma lista de sospechosos más el malware y los problemas de energía.

El rendimiento degradado (la PC está lenta) a menudo se debe a demasiados programas de inicio, un disco casi lleno, RAM insuficiente para la carga de trabajo, una unidad que está fallando, malware, actualizaciones en segundo plano o reducción térmica del rendimiento (thermal throttling). Las advertencias de poca memoria significan que el sistema se quedó sin RAM y sin memoria virtual; pueden causarlas un programa con una fuga de memoria (memory leak), demasiadas aplicaciones o un archivo de paginación pequeño. Los fallos de aplicaciones pueden deberse a errores de programación, instalaciones dañadas, dependencias faltantes, versiones incompatibles o configuraciones de usuario dañadas. Los servicios que no inician normalmente se deben a un servicio deshabilitado, una dependencia que falló, credenciales incorrectas de la cuenta de servicio o archivos dañados; Services (services.msc) y Event Viewer muestran la razón.

Los problemas de arranque abarcan varios síntomas. 'No OS found' (o 'Operating system not found', 'Bootmgr is missing') sugiere que el firmware no encuentra un disco de arranque: revisa el orden de arranque, si quedó conectada una memoria USB, si la unidad se detecta en UEFI/BIOS y si la configuración de arranque está dañada. Los apagados frecuentes sin aviso apuntan fuertemente al sobrecalentamiento (polvo, ventilador averiado) o a una fuente de poder que está fallando, más que al software. Una carga lenta del perfil, una larga espera en 'Preparing Windows' o 'Welcome', a menudo se debe a un perfil móvil (roaming profile) grande o dañado, a conexiones de red lentas hacia unidades asignadas o scripts de inicio de sesión, o a un perfil local dañado, que también puede producir un perfil temporal.

Las advertencias de recursos del controlador USB aparecen cuando hay demasiados dispositivos conectados a un solo controlador USB y este se queda sin recursos (endpoints o ancho de banda). Mover los dispositivos a puertos de otro controlador, quitar un hub o actualizar los controladores del chipset suele resolverlo. El desfase del reloj (time drift) significa que el reloj del sistema está mal o se desfasa lentamente. Las causas incluyen una batería CMOS que está fallando (la hora se restablece tras un corte de energía), una zona horaria incorrecta y la falta de sincronización con un servidor de hora (NTP, Network Time Protocol) o un controlador de dominio. La hora importa: la autenticación Kerberos en un dominio falla si los relojes difieren demasiado, y las verificaciones de certificados pueden fallar.

Un buen hábito ante cualquier síntoma es hacerse tres preguntas: ¿qué cambió recientemente?, ¿afecta a un usuario o a muchos?, y ¿es software o hardware?

Términos clave

BSOD
Blue screen of death (pantalla azul de la muerte): un error de detención de Windows que detiene el sistema tras una falla crítica, a menudo relacionada con controladores o hardware.
Stop code (código de detención)
El nombre o número de error que aparece en una BSOD e identifica el tipo de falla.
Memory leak (fuga de memoria)
Un error de programación que sigue consumiendo memoria sin liberarla, lo que con el tiempo provoca condiciones de poca memoria.
Time drift (desfase del reloj)
Un reloj de computadora que se vuelve impreciso gradualmente, a menudo por una batería CMOS agotada o por problemas de sincronización de la hora.
Temporary profile (perfil temporal)
Un perfil que Windows carga cuando no puede cargar el perfil real del usuario; descarta los cambios al cerrar sesión.
Ejemplo real

Una estación de trabajo muestra una BSOD todas las tardes, y el código de detención hace referencia a un archivo de controlador de red. Reliability Monitor muestra que los fallos comenzaron el día después de instalar un nuevo controlador del adaptador de red. El técnico revierte el controlador en Device Manager y los fallos se detienen.

Consejo para el examen: Los apagados inesperados sin BSOD normalmente significan calor o energía. 'No OS found' a menudo significa que el orden de arranque es incorrecto o que todavía hay una unidad USB conectada. Si el reloj se restablece tras un corte de energía, es la batería CMOS.

Comprueba lo que sabes

El reloj de una PC vuelve a una fecha de hace años cada vez que se desconecta. ¿Cuál es la causa probable?

Una batería CMOS agotada en la tarjeta madre.

¿Cuál es la causa más común de una BSOD justo después de instalar hardware nuevo?

Un controlador defectuoso o incompatible para ese hardware.

Un usuario recibe una advertencia de recursos del controlador USB después de conectar un hub nuevo lleno de dispositivos. ¿Qué deberías intentar?

Mover algunos dispositivos a puertos de otro controlador USB, quitar el hub o reducir los dispositivos, y actualizar los controladores del chipset.
