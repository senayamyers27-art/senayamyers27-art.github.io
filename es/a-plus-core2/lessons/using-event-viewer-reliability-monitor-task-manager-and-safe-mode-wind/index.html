CompTIA A+ Core 2 220-1202

Uso de Event Viewer, Reliability Monitor, Task Manager y Safe Mode / Windows Recovery Environment para encontrar la causa raíz

Adivinar hace perder tiempo. Windows registra mucha información sobre lo que falla, y unas cuantas herramientas integradas te permiten rastrear un síntoma hasta su causa raíz en lugar de tratarlo una y otra vez. Cada herramienta responde a una pregunta distinta, así que la habilidad que evalúa el examen es elegir la correcta según la situación: qué está pasando ahora, qué quedó registrado, qué cambió y qué hacer cuando Windows no inicia normalmente.

Event Viewer (eventvwr.msc) es el lector central de registros. Los principales registros de Windows son Application (eventos de los programas), System (eventos de los componentes y controladores de Windows, como fallos de servicios, errores de disco y apagados inesperados) y Security (eventos auditados, como inicios de sesión exitosos y fallidos). También existen Setup y Forwarded Events, y Applications and Services Logs contiene registros detallados de componentes individuales. Cada evento tiene un nivel (Information, Warning, Error, Critical), una fecha y hora, un origen y un Event ID. Filtra el registro por nivel y por la hora en que ocurrió el problema, y luego busca el origen y el Event ID en la documentación del fabricante. Las vistas personalizadas guardan los filtros útiles para la próxima vez.

Reliability Monitor (busca “reliability history” o abre Control Panel > Security and Maintenance) muestra un gráfico de estabilidad día por día. Cada día enumera los fallos de aplicaciones, los fallos de Windows, los fallos varios, las advertencias y los eventos informativos, como instalaciones de software y actualizaciones exitosas. Como coloca los fallos junto a las instalaciones en una sola línea de tiempo, es la forma más rápida de responder “¿qué cambió justo antes de que empezara esto?”. Haz clic en cualquier evento para ver sus detalles. Task Manager (Ctrl+Shift+Esc) muestra lo que está pasando en este momento. La pestaña Processes muestra qué programa está usando CPU, memoria, disco o red; la pestaña Performance muestra si la RAM, el disco o la CPU están saturados; la pestaña Startup apps enumera los programas que se cargan al iniciar sesión junto con su impacto; y la pestaña Services muestra los servicios en ejecución. Resource Monitor, que se abre desde la pestaña Performance, desglosa el uso de disco y de red por proceso.

Cuando Windows está demasiado inestable para diagnosticarlo normalmente, Safe Mode lo inicia con un conjunto mínimo de controladores y servicios. Si un problema desaparece en Safe Mode, la causa probablemente sea un controlador, un programa de inicio o un servicio de terceros, y puedes eliminarlo desde ahí. Safe Mode with Networking agrega los controladores de red para que puedas descargar herramientas o actualizaciones, y Safe Mode with Command Prompt ofrece una consola de comandos. Llegas a Safe Mode mediante Startup Settings de WinRE, o activando Safe boot en la pestaña Boot de msconfig; recuerda desactivar esa opción después, o la PC seguirá arrancando en Safe Mode.

El Entorno de recuperación de Windows (WinRE) es un pequeño sistema operativo de recuperación. Se carga automáticamente después de varios arranques fallidos, y puedes acceder a él desde Settings > System > Recovery > Advanced startup, manteniendo presionada la tecla Shift mientras eliges Restart, o arrancando desde un medio de instalación. En Troubleshoot > Advanced options ofrece Startup Repair, Startup Settings (incluido Safe Mode), System Restore, Uninstall Updates, System Image Recovery, UEFI Firmware Settings y un Command Prompt para herramientas como chkdsk, sfc y comandos de reparación del arranque como bootrec. En conjunto, te permiten reparar un equipo que nunca llega al escritorio.

Veamos un ejemplo práctico. Una laptop se reinicia sola algunas veces por semana. Abres Reliability Monitor y ves “Windows was not properly shut down” en esos días, sin fallos de aplicaciones ni instalaciones justo antes. En el registro System de Event Viewer encuentras un evento crítico Kernel-Power (Event ID 41) cada vez, lo que significa que el sistema perdió energía o dejó de responder sin un apagado limpio; no hay ningún BSOD registrado. Las rejillas de ventilación de la laptop están tapadas de polvo. Limpias el sistema de enfriamiento, vigilas las temperaturas bajo carga y los reinicios inesperados se detienen.

Errores comunes: buscar en el registro Application fallos de controladores y servicios que se registran en el registro System; buscar fallos en el registro Security cuando este solo contiene eventos de auditoría; olvidar desactivar Safe boot en msconfig; usar Task Manager para investigar algo que ocurrió ayer, cuando solo muestra el presente; y reinstalar Windows cuando Startup Repair o System Restore de WinRE habrían resuelto el problema de arranque en minutos.

Las preguntas del examen relacionan la necesidad con la herramienta. “Qué proceso está usando toda la CPU en este momento” apunta a Task Manager. “Intentos de inicio de sesión fallidos” apunta al registro Security de Event Viewer. “Un servicio no pudo iniciar durante el arranque” apunta al registro System. “Los fallos comenzaron en algún momento de la semana pasada; qué cambió” apunta a Reliability Monitor. “El problema desaparece cuando solo se cargan los controladores esenciales” apunta a Safe Mode y a un controlador o elemento de inicio de terceros. “La PC no llega al escritorio” apunta a WinRE y a Startup Repair.

Términos clave

Event Viewer
El lector de registros de Windows que muestra los registros Application, System, Security y otros, con niveles, orígenes y Event IDs.
Event ID
Un número que identifica un tipo específico de evento registrado y que se puede buscar en la documentación.
Reliability Monitor
Una línea de tiempo de fallos, advertencias e instalaciones que se usa para descubrir qué cambió antes de que empezara un problema.
Task Manager
Una herramienta que muestra los procesos actuales, el rendimiento, las apps de inicio y los servicios.
Resource Monitor
Una vista detallada de la actividad de CPU, memoria, disco y red por proceso, que se abre desde Task Manager.
Safe Mode
Un modo de inicio que carga solo los controladores y servicios esenciales para aislar causas de terceros.
Entorno de recuperación de Windows (WinRE)
Un sistema operativo de recuperación que ofrece Startup Repair, acceso a Safe Mode, System Restore, desinstalación de actualizaciones y un símbolo del sistema.
Ejemplo real

Una PC se volvió muy lenta esta mañana. La pestaña Processes de Task Manager muestra un agente de respaldo que usa casi toda la actividad del disco. Reliability Monitor muestra que ese agente se actualizó durante la noche, y el registro Application de Event Viewer muestra que reintenta una tarea fallida cada minuto. El técnico corrige la ruta de destino de la tarea, el agente se calma y el rendimiento vuelve a la normalidad.

Consejo para el examen: Usa la herramienta adecuada para cada pregunta: “qué está lento ahora” es Task Manager, “qué errores se registraron” es Event Viewer, “qué cambió antes de que empezara esto” es Reliability Monitor, y “Windows no arranca” es WinRE.

Comprueba lo que sabes

¿Qué registro de Event Viewer guarda los intentos de inicio de sesión fallidos y cuál guarda un fallo de controlador o de servicio?

El registro Security guarda los inicios de sesión auditados; el registro System guarda los fallos de controladores y servicios.

¿Qué te indica que un problema desaparezca en Safe Mode?

Que la causa probablemente sea un controlador, un programa de inicio o un servicio de terceros, porque Safe Mode solo carga los componentes esenciales.

¿Qué herramienta muestra mejor que un fallo empezó justo después de instalar un software?

Reliability Monitor, porque muestra los fallos y las instalaciones en la misma línea de tiempo día por día.

Menciona dos formas de acceder al Entorno de recuperación de Windows.

Mantener presionada la tecla Shift al elegir Restart, usar Settings > System > Recovery > Advanced startup, arrancar desde un medio de instalación o dejar que se cargue tras varios arranques fallidos.
