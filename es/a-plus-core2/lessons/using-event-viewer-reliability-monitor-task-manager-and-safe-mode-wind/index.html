CompTIA A+ Core 2 220-1202

Uso de Event Viewer, Reliability Monitor, Task Manager y Safe Mode / Windows Recovery Environment para encontrar la causa raíz

Adivinar hace perder tiempo; Windows registra mucha información sobre lo que falla, y estas herramientas te ayudan a encontrar la causa raíz en lugar de solo tratar los síntomas.

Event Viewer (Visor de eventos, eventvwr.msc) es el lector central de registros. Los principales registros de Windows son Application (eventos de los programas), System (eventos de los componentes y controladores de Windows, como fallas de servicios y apagados inesperados) y Security (eventos auditados como los inicios de sesión y los intentos fallidos de inicio de sesión). También existen Setup y Forwarded Events, y Applications and Services Logs contiene registros detallados de componentes individuales. Cada evento tiene un nivel (Information, Warning, Error, Critical), una fecha y hora, un origen (source) y un Event ID. Filtra el registro por nivel y por la hora en que ocurrió el problema, y luego busca el origen y el Event ID en la documentación del fabricante. Las vistas personalizadas (custom views) guardan los filtros útiles.

Reliability Monitor (Monitor de confiabilidad; busca 'reliability history' o ábrelo desde Security and Maintenance) muestra un gráfico de estabilidad día por día. Cada día lista las fallas de aplicaciones, las fallas de Windows, las advertencias y los eventos informativos, como las actualizaciones y las instalaciones de software exitosas. Como coloca los fallos junto a las instalaciones en una línea de tiempo, es la forma más rápida de responder '¿qué cambió justo antes de que empezara esto?'. Haz clic en un evento para ver sus detalles y un enlace a su información técnica.

Task Manager muestra lo que está ocurriendo en este momento. La pestaña Processes revela qué programa está consumiendo CPU, memoria, disco o red; la pestaña Performance muestra si al sistema le falta RAM o rendimiento de disco; la pestaña Startup apps muestra los programas que se cargan al iniciar sesión con su impacto; la pestaña Services muestra qué servicios se están ejecutando. Resource Monitor (desde la pestaña Performance) profundiza en el uso de disco y de red por proceso.

Cuando Windows está demasiado inestable para diagnosticarlo normalmente, Safe Mode (Modo seguro) lo inicia con un conjunto mínimo de controladores y servicios. Si un problema desaparece en Safe Mode, la causa probablemente es un controlador, programa de inicio o servicio de terceros. Safe Mode with Networking agrega los controladores de red, lo cual es útil para descargar herramientas. Llegas a él a través del Windows Recovery Environment o configurando Safe boot en msconfig (recuerda desactivarlo después).

El Windows Recovery Environment (WinRE) se carga automáticamente tras varios arranques fallidos, o desde Settings > System > Recovery > Advanced startup, manteniendo presionada la tecla Shift mientras haces clic en Restart, o desde un medio de instalación. Su menú Troubleshoot > Advanced options ofrece Startup Repair, Startup Settings (Safe Mode y otros), System Restore, desinstalar actualizaciones, System Image Recovery, la configuración del firmware UEFI y un Command Prompt para herramientas como chkdsk, sfc y los comandos de reparación del arranque. En conjunto, estas herramientas te permiten rastrear un problema hasta su causa y corregirlo incluso cuando Windows no inicia normalmente.

Términos clave

Event ID
Un número que identifica el tipo de evento registrado por un origen determinado en Event Viewer.
Reliability Monitor (Monitor de confiabilidad)
Una línea de tiempo de fallas de aplicaciones y de Windows, advertencias e instalaciones que se usa para correlacionar los problemas con los cambios.
Safe Mode (Modo seguro)
Un modo de inicio de diagnóstico que carga solo los controladores y servicios esenciales.
WinRE
Windows Recovery Environment: un sistema operativo de recuperación que ofrece Startup Repair, System Restore, opciones de Safe Mode y un símbolo del sistema.
System log (registro System)
El registro de Event Viewer que guarda los eventos de los componentes, controladores y servicios de Windows.
Ejemplo real

Una laptop se reinicia sola algunas veces por semana. Reliability Monitor muestra 'Windows was not properly shut down' en esos días, y el registro System de Event Viewer muestra un evento crítico Kernel-Power cada vez. No hay BSOD, y las rejillas de ventilación de la laptop están llenas de polvo. El técnico limpia el sistema de enfriamiento y los reinicios inesperados se detienen.

Consejo para el examen: Usa la herramienta adecuada para cada pregunta: 'qué está lento ahora mismo' es Task Manager, 'qué errores se registraron' es Event Viewer, 'qué cambió antes de que empezara esto' es Reliability Monitor, 'Windows no arranca' es WinRE.

Comprueba lo que sabes

¿Qué registro de Event Viewer mostraría un intento fallido de inicio de sesión?

El registro Security (cuando la auditoría está habilitada).

Un problema desaparece cuando arrancas en Safe Mode. ¿Qué sugiere eso?

Que lo causa un controlador, programa de inicio o servicio de terceros, ya que Safe Mode solo carga los componentes esenciales.

Menciona dos formas de llegar al Windows Recovery Environment.

Mantener presionada la tecla Shift mientras haces clic en Restart; usar Settings > Recovery > Advanced startup; arrancar desde un medio de instalación; o dejar que se inicie automáticamente tras varios arranques fallidos.
