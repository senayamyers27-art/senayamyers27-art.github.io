CompTIA A+ Core 2 220-1202

Linux: comandos de archivos y permisos (ls, cp, mv, rm, chmod, chown, sudo, su), gestores de paquetes (apt, dnf), ip, df, top, ps, grep, find, man, archivos clave (/etc/passwd, /etc/shadow, /etc/hosts, /etc/fstab, /etc/resolv.conf)

Linux se administra principalmente desde un shell como bash. Los comandos distinguen entre mayúsculas y minúsculas, las rutas usan barras diagonales (/) y no hay letras de unidad: todo cuelga del directorio raíz /. Si tienes dudas, lee la página del manual con man, como en man chmod, y presiona q para salir.

Trabajo con archivos: ls lista un directorio (ls -l muestra permisos, propietario, tamaño y fecha; ls -a incluye los archivos ocultos que empiezan con punto). cp copia (cp -r para directorios), mv mueve o renombra, y rm elimina (rm -r elimina un árbol de directorios). En el shell no hay Papelera de reciclaje, así que rm es permanente. pwd muestra el directorio actual y cd lo cambia.

ls -l muestra los permisos como una cadena del tipo -rwxr-x---: el primer carácter es el tipo, y luego vienen tres conjuntos de lectura (r), escritura (w) y ejecución (x) para el propietario (user), el grupo y los demás (others). chmod los cambia, ya sea de forma simbólica (chmod g+w file) o en octal, donde r=4, w=2, x=1, de modo que chmod 750 script.sh le da al propietario rwx (7), al grupo r-x (5) y a los demás nada (0). chown cambia el propietario, por ejemplo chown alice:staff report.txt. Trabajar a diario como el superusuario root es riesgoso, así que los administradores usan sudo para ejecutar un solo comando con privilegios elevados (pide la contraseña del propio usuario y registra la acción) y su para cambiar a otro usuario, por defecto root, lo cual requiere la contraseña de esa cuenta.

El software se instala con un gestor de paquetes, que descarga desde repositorios confiables y resuelve las dependencias. Debian y Ubuntu usan apt: sudo apt update actualiza la lista de paquetes, y luego sudo apt upgrade o sudo apt install nginx. Red Hat, Fedora y las distribuciones relacionadas usan dnf (el sucesor de yum): sudo dnf install nginx, sudo dnf upgrade.

Información del sistema y de la red: ip addr (o ip a) muestra las interfaces y las direcciones, e ip route muestra la tabla de enrutamiento; reemplaza al antiguo ifconfig. df -h muestra el espacio libre de cada sistema de archivos montado en unidades legibles. top es una vista en vivo que se actualiza con los procesos y el uso de CPU y memoria, y ps aux ofrece una lista instantánea de todos los procesos. grep busca un patrón en un texto, como en grep error /var/log/syslog, y a menudo se combina con tuberías (pipes): ps aux | grep ssh. find busca en el sistema de archivos por nombre, tamaño o fecha, por ejemplo find /home -name '*.pdf'.

Conoce estos archivos de configuración. /etc/passwd lista las cuentas de usuario (nombre, ID de usuario, directorio personal y shell de inicio de sesión) y todos pueden leerlo; a pesar de su nombre, ya no contiene contraseñas. /etc/shadow almacena las contraseñas en forma de hash y los datos de vencimiento de contraseñas, y solo root puede leerlo. /etc/hosts asocia nombres de host con direcciones IP de forma local y, de manera predeterminada, se consulta antes que el DNS. /etc/fstab lista los sistemas de archivos que se montan al arrancar y dónde. /etc/resolv.conf lista los servidores DNS que usa el sistema.

ls -l /var/www
sudo chmod 644 index.html
sudo chown www-data:www-data index.html
sudo apt update && sudo apt install htop
df -h

Términos clave

sudo
Ejecuta un solo comando con privilegios elevados (normalmente de root), autenticándose con la contraseña del propio usuario y registrando la acción.
chmod
Cambia los permisos de un archivo, de forma simbólica o con valores octales como 755.
Package manager (gestor de paquetes)
Herramienta como apt o dnf que instala, actualiza y elimina software desde repositorios, manejando las dependencias.
/etc/shadow
Archivo accesible solo para root que almacena los hashes de las contraseñas de los usuarios y la información de vencimiento de contraseñas.
/etc/fstab
Archivo que define qué sistemas de archivos se montan al arrancar y en qué puntos de montaje.
Ejemplo real

El nuevo script de un desarrollador web no se ejecuta y el shell dice 'Permission denied'. El técnico ejecuta ls -l y ve -rw-r--r--, lo que significa que nadie tiene permiso de ejecución. Al ejecutar chmod 755 deploy.sh el propietario obtiene todos los permisos y los demás, lectura y ejecución, y el script ahora se ejecuta.

Consejo para el examen: Los permisos octales aparecen con frecuencia: 7 = rwx, 6 = rw-, 5 = r-x, 4 = r--. Recuerda también que /etc/passwd contiene las cuentas, pero /etc/shadow contiene los hashes de las contraseñas.

Comprueba lo que sabes

¿Qué permisos establece chmod 640?

Lectura y escritura para el propietario (6), solo lectura para el grupo (4) y ningún acceso para los demás (0).

¿Qué comando instala un paquete en Ubuntu y cuál en Fedora?

sudo apt install <package> en Ubuntu; sudo dnf install <package> en Fedora.

¿Qué archivo revisarías para ver qué servidores DNS usa un equipo Linux?

/etc/resolv.conf.
