Sistemas de archivos: NTFS, ReFS, FAT32, exFAT, ext4, XFS, APFS y sus límites

Un sistema de archivos (file system) es el conjunto de reglas que usa un sistema operativo para organizar los datos en un dispositivo de almacenamiento: cómo se nombran los archivos, dónde se ubican sus partes en el disco, qué metadatos (fechas, propietarios, permisos) se guardan y cómo se lleva el control del espacio libre. Cuando formateas una unidad eliges un sistema de archivos, y esa elección decide qué sistemas operativos pueden leerla, qué tan grandes pueden ser los archivos y qué funciones de seguridad están disponibles.

NTFS (New Technology File System) es el estándar para las unidades de sistema de Windows. Admite permisos de archivos y carpetas, cifrado con EFS (Encrypting File System), compresión, cuotas de disco y journaling (registro por diario), que anota los cambios pendientes para que el volumen pueda recuperarse limpiamente tras un fallo. Sus límites de tamaño de archivo y de volumen son tan grandes que nunca importan en el trabajo normal. macOS puede leer NTFS pero no escribir en él de forma predeterminada, y el soporte en Linux varía según la distribución.

ReFS (Resilient File System) es un sistema de archivos más reciente de Microsoft, diseñado para la integridad de los datos y para volúmenes muy grandes. Usa sumas de verificación (checksums) para detectar la corrupción y puede reparar los datos automáticamente cuando se combina con el espejado de Storage Spaces. Está pensado para servidores y grupos de almacenamiento, y carece de algunas funciones de NTFS, por lo que normalmente no instalas Windows en él.

FAT32 (File Allocation Table, 32 bits) es antiguo, sencillo y casi todo puede leerlo: Windows, macOS, Linux, cámaras, consolas de videojuegos y estéreos de automóvil. Su límite famoso es un tamaño máximo de archivo de 4 GB (menos un byte), y las herramientas gráficas de formateo integradas en Windows tradicionalmente solo ofrecen FAT32 para volúmenes de hasta 32 GB. No tiene permisos ni journaling. exFAT (Extended FAT) se creó para medios flash: elimina el límite de 4 GB por archivo, admite volúmenes muy grandes y las versiones modernas de Windows y macOS pueden leerlo y escribirlo, lo que lo convierte en la opción habitual para unidades USB grandes y tarjetas SD que se comparten entre esos sistemas.

En Linux, ext4 (fourth extended file system) es el predeterminado más común; tiene journaling y admite los permisos de Linux y archivos grandes. XFS es un sistema de archivos con journaling de alto rendimiento, predeterminado en Red Hat Enterprise Linux y sus derivados, muy adecuado para archivos grandes y cargas de trabajo paralelas. Windows no puede leer ninguno de los dos de forma nativa.

APFS (Apple File System) es el predeterminado para macOS, iOS y iPadOS. Está optimizado para SSD y admite instantáneas (snapshots), espacio compartido entre volúmenes dentro de un mismo contenedor y un cifrado integrado robusto. Las Mac más antiguas usaban HFS+ (Mac OS Extended). Windows no puede leer APFS sin herramientas de terceros.

Para el examen, asocia el sistema de archivos con la tarea. Unidad de arranque de Windows: NTFS. Unidad flash para archivos grandes compartida entre Windows y Mac: exFAT. Máxima compatibilidad con dispositivos antiguos y archivos pequeños: FAT32. Servidor Linux: ext4 o XFS. Mac: APFS. Grupo de almacenamiento resiliente de Windows: ReFS.

Términos clave

NTFS
El sistema de archivos principal de Windows, con journaling, que admite permisos, cifrado EFS, compresión y cuotas.
exFAT
Un sistema de archivos ligero para medios flash sin el límite de 4 GB por archivo de FAT32, que Windows y macOS pueden leer y escribir.
Journaling (registro por diario)
Registrar los cambios previstos en un log antes de aplicarlos, para que el sistema de archivos pueda recuperarse de forma consistente tras un fallo o un corte de energía.
APFS
Apple File System, el predeterminado optimizado para SSD en macOS, iOS y iPadOS, con instantáneas y cifrado nativo.
ext4
El cuarto sistema de archivos extendido (fourth extended file system), un predeterminado común con journaling en las distribuciones de Linux.
Ejemplo real

Un editor de video copia un archivo de proyecto de 9 GB a una memoria USB nueva y recibe un error de que el archivo es demasiado grande, aunque la memoria tiene 60 GB libres. La memoria está formateada en FAT32. El técnico respalda el contenido de la memoria, la reformatea como exFAT para que tanto la PC con Windows como la Mac del editor puedan usarla, y la copia se completa con éxito.

Consejo para el examen: Un mensaje de 'archivo demasiado grande' en una unidad con mucho espacio libre casi siempre significa FAT32 y su límite de 4 GB por archivo. La solución es exFAT (para uso multiplataforma) o NTFS (solo para Windows).

Comprueba lo que sabes

¿Qué sistema de archivos elegirías para una unidad USB que debe guardar archivos de video de 10 GB y usarse tanto en Windows como en macOS?

exFAT, porque no tiene límite de 4 GB por archivo y ambos sistemas operativos pueden leerlo y escribirlo de forma nativa.

¿Qué sistema de archivos de Windows admite permisos por archivo y cifrado EFS?

NTFS.

¿Cuál es el sistema de archivos predeterminado en las Mac y los iPhone actuales?

APFS (Apple File System).
