CompTIA A+ Core 2 220-1202

Herramientas de línea de comandos: cd, dir, md, rmdir, robocopy, xcopy, diskpart, format, chkdsk, sfc, DISM, gpupdate, gpresult, net use, net user, whoami, winver, shutdown, ipconfig, ping, tracert, pathping, nslookup, netstat, hostname

La línea de comandos de Windows (Command Prompt, cmd, o PowerShell, que ejecuta la mayoría de los mismos comandos) es más rápida que la interfaz gráfica para muchas tareas y es esencial para crear scripts y trabajar de forma remota. Algunos comandos necesitan un símbolo del sistema con privilegios elevados: haz clic derecho en Command Prompt y elige 'Run as administrator'. Agrega /? a cualquier comando para ver su ayuda, por ejemplo robocopy /?.

Navegación de archivos y carpetas: cd cambia de directorio (cd .. sube un nivel, cd \ va a la raíz). dir lista el contenido de una carpeta (dir /a incluye archivos ocultos). md (o mkdir) crea un directorio y rmdir (o rd) elimina uno; rmdir /s lo elimina con todo su contenido. xcopy copia archivos y árboles de directorios (/s para subcarpetas, /e incluyendo las vacías). robocopy (Robust File Copy) es el reemplazo más potente: puede reanudar tras interrupciones, reintentar, conservar permisos y reflejar carpetas (/mir), lo que lo hace ideal para migraciones y respaldos.

Herramientas de disco: diskpart es una herramienta interactiva de particionado; ejecutas list disk, select disk 1, luego clean, create partition primary, etc. Ten cuidado, porque actúa de inmediato y no se puede deshacer. format prepara un volumen con un sistema de archivos, por ejemplo format E: /fs:NTFS. chkdsk revisa un volumen en busca de errores del sistema de archivos; chkdsk /f los corrige y chkdsk /r además localiza sectores defectuosos y recupera los datos legibles. Herramientas de reparación del sistema: sfc /scannow (System File Checker) analiza los archivos protegidos de Windows y reemplaza los dañados a partir de una caché local. DISM (Deployment Image Servicing and Management) repara la imagen de Windows subyacente, comúnmente con DISM /Online /Cleanup-Image /RestoreHealth; ejecútalo cuando sfc no pueda reparar los archivos y luego vuelve a ejecutar sfc.

Directivas y cuentas: gpupdate actualiza la Group Policy (gpupdate /force vuelve a aplicar todas las directivas). gpresult /r muestra qué directivas se aplicaron al usuario y al equipo actuales. net use asigna o desconecta unidades de red, como en net use S: \\server\share. net user lista, crea o modifica cuentas locales, por ejemplo net user alice /add. whoami muestra la cuenta con sesión iniciada (whoami /groups muestra las membresías). winver abre una ventana con la versión y la compilación de Windows. shutdown /s /t 0 apaga el equipo de inmediato, /r lo reinicia y /a cancela un apagado pendiente.

Redes: ipconfig muestra la configuración IP; /all agrega la dirección MAC y los servidores DHCP y DNS, /release y /renew obtienen una nueva concesión DHCP, y /flushdns vacía la caché DNS. ping prueba la accesibilidad con solicitudes de eco ICMP. tracert lista cada salto de router hasta un destino. pathping combina ambos y mide la pérdida de paquetes en cada salto durante un periodo. nslookup consulta el DNS para verificar la resolución de nombres. netstat lista las conexiones y los puertos en escucha (-a todos, -n numérico, -b el programa propietario, lo cual requiere privilegios elevados). hostname muestra el nombre del equipo.

ipconfig /all
ping 8.8.8.8
nslookup intranet.example.com
sfc /scannow
robocopy C:\Data D:\Backup /mir

Términos clave

robocopy
Herramienta de copia robusta de archivos que puede reintentar, reanudar, conservar permisos y reflejar árboles de directorios.
sfc /scannow
Comando de System File Checker (Comprobador de archivos del sistema) que verifica y repara los archivos protegidos del sistema Windows.
DISM
Deployment Image Servicing and Management: repara o da mantenimiento a la imagen de Windows de la que depende sfc.
gpresult
Comando que informa las configuraciones de Group Policy aplicadas a un usuario y a un equipo.
pathping
Comando que combina ping y tracert para medir la latencia y la pérdida de paquetes en cada salto.
Ejemplo real

Un usuario no puede acceder a un sitio web interno por su nombre. El técnico ejecuta ping a la dirección IP del servidor y obtiene respuestas, luego ejecuta nslookup con el nombre del sitio y no obtiene respuesta. Eso apunta al DNS, así que revisa el servidor DNS indicado en ipconfig /all y ejecuta ipconfig /flushdns después de que se corrige el registro DNS.

Consejo para el examen: Conoce los pares: sfc repara archivos del sistema, DISM repara la imagen que usa sfc; gpupdate aplica directivas, gpresult las informa; tracert muestra la ruta, pathping agrega estadísticas de pérdida por salto.

Comprueba lo que sabes

sfc /scannow informa que encontró archivos dañados pero no pudo reparar algunos. ¿Qué deberías ejecutar después?

DISM /Online /Cleanup-Image /RestoreHealth para reparar el almacén de componentes y luego volver a ejecutar sfc /scannow.

¿Qué comando asigna la letra de unidad S: a una carpeta compartida en un servidor?

net use S: \\servername\sharename

¿Qué comando muestra qué objetos de Group Policy se aplicaron al usuario actual?

gpresult /r
