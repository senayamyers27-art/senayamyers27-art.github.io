CompTIA A+ Core 2 220-1202

Herramientas de línea de comandos: cd, dir, md, rmdir, robocopy, xcopy, diskpart, format, chkdsk, sfc, DISM, gpupdate, gpresult, net use, net user, whoami, winver, shutdown, ipconfig, ping, tracert, pathping, nslookup, netstat, hostname

La línea de comandos de Windows (Command Prompt, cmd, o PowerShell, que ejecuta la mayoría de los mismos comandos) es más rápida que la interfaz gráfica para muchas tareas y es esencial para los scripts y el trabajo remoto. Algunos comandos necesitan un símbolo del sistema con privilegios elevados: haz clic derecho en Command Prompt o Terminal y elige 'Run as administrator'. Agrega /? a cualquier comando para ver su ayuda, por ejemplo robocopy /?. El examen enumera estos comandos y espera que sepas qué hace cada uno y qué modificador realiza una tarea común. Empieza por la navegación de archivos y carpetas: cd cambia de directorio (cd .. sube un nivel, cd \ va a la raíz de la unidad). dir lista el contenido de una carpeta (dir /a incluye archivos ocultos y de sistema). md (o mkdir) crea un directorio y rmdir (o rd) elimina uno; rmdir /s lo elimina con todo su contenido. xcopy copia archivos y árboles de directorios (/s para subcarpetas, /e incluidas las vacías). robocopy (Robust File Copy) es el reemplazo más potente: puede reanudar después de interrupciones, reintentar, conservar permisos y marcas de tiempo y reflejar carpetas con /mir, lo que lo convierte en la opción para migraciones y respaldos grandes. Ten cuidado con /mir, porque también elimina en el destino los archivos que ya no existen en el origen.

Herramientas de disco: diskpart es una herramienta interactiva de particionado; ejecutas list disk, select disk 1 y luego clean, create partition primary, format, etc. Actúa de inmediato y no se puede deshacer, así que confirma dos veces el número de disco. format prepara un volumen con un sistema de archivos, por ejemplo format E: /fs:NTFS. chkdsk revisa un volumen en busca de errores del sistema de archivos; chkdsk /f los corrige y chkdsk /r además localiza sectores defectuosos y recupera los datos legibles. Herramientas de reparación del sistema: sfc /scannow (System File Checker) analiza los archivos protegidos de Windows y reemplaza los dañados desde una caché local. DISM (Deployment Image Servicing and Management) repara esa imagen subyacente de Windows, normalmente con DISM /Online /Cleanup-Image /RestoreHealth; ejecútalo cuando sfc no pueda reparar los archivos y luego vuelve a ejecutar sfc.

Directivas y cuentas: gpupdate actualiza Group Policy (gpupdate /force vuelve a aplicar todas las directivas, no solo las que cambiaron). gpresult /r muestra qué directivas se aplicaron al usuario y al equipo actuales. net use asigna o desconecta unidades de red, como en net use S: \\server\share. net user lista, crea o modifica cuentas locales, por ejemplo net user alice /add, o net user alice /domain para consultar una cuenta de dominio. whoami muestra la cuenta con sesión iniciada (whoami /groups muestra las pertenencias a grupos). winver abre una ventana con la versión y la compilación de Windows. shutdown /s /t 0 apaga de inmediato, /r reinicia y /a cancela un apagado pendiente.

Redes: ipconfig muestra la configuración IP; /all agrega la dirección MAC y los servidores DHCP y DNS, /release y /renew obtienen una nueva concesión DHCP, y /flushdns vacía la caché de DNS (Domain Name System). ping prueba la accesibilidad con solicitudes de eco ICMP (Internet Control Message Protocol). tracert enumera cada salto de router hasta un destino. pathping combina ambos y mide la pérdida de paquetes en cada salto durante un período. nslookup consulta DNS para verificar la resolución de nombres. netstat enumera las conexiones y los puertos en escucha (-a todos, -n numérico, -b programa propietario, que requiere privilegios elevados). hostname imprime el nombre del equipo.

ipconfig /all
ping 8.8.8.8
nslookup intranet.example.com
sfc /scannow
robocopy C:\Data D:\Backup /mir

Veamos un ejemplo práctico. Un usuario no puede acceder a la intranet por su nombre. Ejecutas ipconfig /all y ves una dirección válida y un servidor DNS. Un ping a la dirección IP del servidor de la intranet funciona, pero nslookup intranet.example.com falla, así que la ruta de red está bien y el problema es la resolución de nombres. Después de que el equipo de DNS corrige el registro, ejecutas ipconfig /flushdns para que la PC deje de usar la respuesta fallida que tenía en caché.

Errores comunes: ejecutar sfc o DISM desde un símbolo del sistema sin privilegios elevados; confundir gpupdate (aplicar) con gpresult (informar); esperar que tracert muestre estadísticas de pérdida, que es tarea de pathping; usar format cuando primero hay que particionar el disco en diskpart; y olvidar que rmdir /s y diskpart clean no pasan por la Papelera de reciclaje.

Las preguntas del examen emparejan una tarea con un comando. 'Copiar una carpeta y reanudar tras caídas de red, conservando permisos' es robocopy. 'Archivos de sistema dañados' es sfc /scannow, y 'sfc no pudo repararlos' es DISM. 'Los cambios de directiva todavía no se aplicaron' es gpupdate /force; '¿qué directivas se aplicaron?' es gpresult. 'Asignar una letra de unidad a un recurso compartido' es net use. '¿Qué cuenta estoy usando?' es whoami. 'Encontrar dónde se pierden paquetes a lo largo de la ruta' es pathping. '¿En qué puertos escucha esta PC?' es netstat.

Términos clave

robocopy
Robust File Copy, una herramienta de copia resiliente que reintenta, reanuda, conserva permisos y puede reflejar carpetas.
diskpart
Una herramienta interactiva de línea de comandos para administrar discos, particiones y volúmenes, sin opción de deshacer.
chkdsk
Revisa un volumen en busca de errores del sistema de archivos; /f corrige errores y /r además encuentra sectores defectuosos.
sfc
System File Checker, que analiza y repara los archivos protegidos del sistema Windows.
DISM
Deployment Image Servicing and Management, que repara el almacén de componentes de Windows del que depende sfc.
gpupdate y gpresult
gpupdate aplica Group Policy en el momento; gpresult informa qué directivas se aplicaron.
nslookup
Una herramienta que consulta servidores DNS para probar la resolución de nombres.
pathping
Combina ping y tracert para medir la latencia y la pérdida de paquetes en cada salto a lo largo del tiempo.
Ejemplo real

Después de una actualización fallida, Windows muestra errores extraños y sfc /scannow informa que encontró archivos dañados que no pudo reparar. El técnico ejecuta DISM /Online /Cleanup-Image /RestoreHealth desde un símbolo del sistema con privilegios elevados para reparar el almacén de componentes, reinicia y vuelve a ejecutar sfc /scannow, que ahora repara con éxito los archivos restantes.

Consejo para el examen: Conoce las parejas: sfc repara los archivos de sistema y DISM repara la imagen que usa sfc; gpupdate aplica la directiva y gpresult la informa; tracert muestra la ruta y pathping agrega estadísticas de pérdida por salto.

Comprueba lo que sabes

sfc /scannow informa archivos dañados que no puede reparar. ¿Qué debes ejecutar a continuación?

DISM /Online /Cleanup-Image /RestoreHealth para reparar la imagen y luego volver a ejecutar sfc /scannow.

¿Qué comando muestra la dirección MAC y los servidores DNS de cada adaptador?

ipconfig /all.

¿Cómo obligas a que toda la configuración de Group Policy se vuelva a aplicar de inmediato?

Ejecutando gpupdate /force.

¿Qué comando copia un árbol de carpetas grande con reintentos y puede reflejar el origen en el destino?

robocopy, por ejemplo con el modificador /mir.
