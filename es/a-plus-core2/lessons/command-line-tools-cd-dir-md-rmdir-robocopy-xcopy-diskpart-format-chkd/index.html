CompTIA A+ Core 2 220-1202

Herramientas de línea de comandos: cd, dir, md, rmdir, robocopy, xcopy, diskpart, format, chkdsk, sfc, DISM, gpupdate, gpresult, net use, net user, whoami, winver, shutdown, ipconfig, ping, tracert, pathping, nslookup, netstat, hostname

La línea de comandos de Windows (Command Prompt, cmd, o PowerShell, que ejecuta la mayoría de los mismos comandos) es más rápida que la interfaz gráfica para muchas tareas y es esencial para los scripts y el trabajo remoto. Algunos comandos necesitan un símbolo del sistema con privilegios elevados: haz clic derecho en Command Prompt o Terminal y elige 'Run as administrator'. Agrega /? a cualquier comando para ver su ayuda, por ejemplo robocopy /?. El examen enumera estos comandos y espera que sepas qué hace cada uno y qué modificador realiza una tarea común. Empieza por la navegación de archivos y carpetas: cd cambia de directorio (cd .. sube un nivel, cd \ va a la raíz de la unidad). dir lista el contenido de una carpeta (dir /a incluye archivos ocultos y de sistema). md (o mkdir) crea un directorio y rmdir (o rd) elimina uno; rmdir /s lo elimina con todo su contenido. xcopy copia archivos y árboles de directorios (/s para subcarpetas, /e incluidas las vacías). robocopy (Robust File Copy) es el reemplazo más potente: puede reanudar después de interrupciones, reintentar, conservar permisos y marcas de tiempo y reflejar carpetas con /mir, lo que lo convierte en la opción para migraciones y respaldos grandes. Ten cuidado con /mir, porque también elimina en el destino los archivos que ya no existen en el origen.
