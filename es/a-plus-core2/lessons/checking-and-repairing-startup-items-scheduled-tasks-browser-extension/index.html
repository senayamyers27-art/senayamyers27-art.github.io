CompTIA A+ Core 2 220-1202

Revisión y reparación de elementos de inicio, tareas programadas, extensiones del navegador y configuración del proxy después de una infección

Eliminar el archivo del malware no siempre es suficiente. Muchas infecciones establecen persistencia, es decir, mecanismos que vuelven a iniciar el malware o restauran sus cambios después de un reinicio o después de que eliminas el archivo principal. Otras cambian configuraciones, como el proxy o el motor de búsqueda del navegador, que siguen causando daño incluso después de que el programa desapareció. Después de la remediación, necesitas revisar los lugares de persistencia más comunes y las configuraciones que al malware le gusta cambiar, o el problema regresará sin que nadie lo note.

Empieza por los elementos de inicio. La pestaña Startup apps de Task Manager enumera los programas que se inician al iniciar sesión, con su editor y su impacto en el inicio; deshabilita todo lo desconocido o sospechoso, y búscalo si no estás seguro. Los programas también pueden iniciarse desde las carpetas Startup (escribe shell:startup para el usuario actual o shell:common startup para todos los usuarios en el cuadro Run) y desde las claves Run del registro, como HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run y la clave equivalente en HKEY_LOCAL_MACHINE. Revisa la consola Services (services.msc) en busca de servicios desconocidos configurados para iniciar automáticamente, sobre todo los que tengan nombres raros o no tengan descripción. Herramientas como Autoruns de Sysinternals de Microsoft muestran todos los lugares de inicio automático en una sola lista, lo que ahorra muchos clics.

Después, las tareas programadas. El malware con frecuencia crea una tarea en Task Scheduler (taskschd.msc) que se ejecuta al iniciar sesión, al arrancar o cada pocos minutos para reinstalarse o iniciar un script. Recorre Task Scheduler Library y sus subcarpetas, busca tareas con nombres aleatorios o que imitan a otros, y abre la pestaña Actions de cada tarea desconocida para ver qué programa o script ejecuta, junto con la pestaña Triggers para ver cuándo. Anota los detalles en el ticket y luego deshabilita o elimina las tareas maliciosas. Una tarea que ejecuta un script desde la carpeta temporal de un usuario o desde AppData es una señal de alerta común.

Luego, las extensiones y la configuración del navegador. Abre el administrador de extensiones o complementos en todos los navegadores instalados, no solo en el predeterminado, y elimina todo lo que el usuario no haya instalado intencionalmente. Luego revisa la página de inicio, las páginas de arranque, la página de nueva pestaña y el motor de búsqueda predeterminado, porque los secuestradores los cambian. Si la configuración sigue volviendo, verifica si se aplicó una política; los navegadores muestran un aviso de “administrado por tu organización” cuando hay políticas configuradas, y algunos malware instalan sus propias políticas del navegador. Restablecer el navegador a los valores predeterminados elimina la mayoría de los restos. Borra la caché y las cookies, y elimina los permisos de notificaciones inesperados. Por último, la configuración del proxy y de la resolución de nombres. El malware puede configurar un proxy para que todo el tráfico web pase por el servidor del atacante, o para que los sitios de seguridad no carguen. Revisa Settings > Network and internet > Proxy y la opción heredada Internet Options > Connections > LAN settings; a menos que la organización use un proxy, los scripts de configuración automática y los servidores proxy manuales deben estar desactivados. Revisa el proxy del sistema que usan los servicios con netsh winhttp show proxy, la configuración de los servidores DNS del adaptador de red y el archivo hosts en busca de entradas de redirección.

shell:startup
taskschd.msc
netsh winhttp show proxy
notepad C:\Windows\System32\drivers\etc\hosts

Veamos un ejemplo práctico. Después de eliminar un adware, un técnico descubre que los anuncios regresan después de cada reinicio. Task Scheduler muestra una tarea con un nombre parecido al de un actualizador del navegador que ejecuta un script desde AppData cada 30 minutos, y el navegador todavía muestra una extensión desconocida que la sincronización sigue restaurando. Eliminas la tarea, quitas la extensión, cierras la sesión de sincronización del navegador y borras la extensión sincronizada de la cuenta, restableces el navegador y reinicias dos veces para confirmar que nada reaparezca. Terminas con un análisis completo con definiciones actualizadas y documentas cada elemento eliminado. Si la persistencia hubiera seguido regresando a pesar de la limpieza, lo más seguro habría sido reinstalar la imagen.

Errores comunes: eliminar el archivo del malware pero dejar la tarea programada que lo vuelve a descargar; revisar solo Startup apps de Task Manager y pasar por alto los servicios, las claves Run y las tareas; limpiar un navegador pero no los demás; olvidar que la sincronización del perfil puede restaurar una extensión maliciosa; y corregir el proxy del navegador pero pasar por alto el proxy de WinHTTP o el archivo hosts.

Las preguntas del examen a menudo describen lo que ocurre después de una limpieza. “El malware regresa después de cada reinicio” apunta a persistencia, como una tarea programada, una clave Run o un servicio. “El tráfico web sigue comportándose mal después de la eliminación” apunta a la configuración del proxy, del DNS o del archivo hosts, y “la página de inicio del navegador sigue volviendo a cambiar” apunta a una extensión, la sincronización o una política del navegador. Cuando una pregunta plantea qué hacer después de que todos los intentos de limpieza fallaron y la infección sigue regresando, la respuesta es reinstalar el sistema a partir de una imagen en buen estado.

Términos clave

Persistencia
Un mecanismo que permite que el malware sobreviva a reinicios o intentos de eliminación, como una tarea programada o una entrada de inicio.
Clave Run (Run key)
Una ubicación del registro cuyas entradas inician programas automáticamente cuando un usuario inicia sesión.
Carpeta Startup
Una carpeta, que se abre con shell:startup, cuyos accesos directos se ejecutan al iniciar sesión.
Task Scheduler
La herramienta de Windows que ejecuta programas según desencadenadores como el inicio de sesión, el arranque o un temporizador.
Autoruns
Una herramienta de Sysinternals que muestra en una sola vista todos los lugares de inicio automático de un sistema Windows.
Configuración del proxy
Una configuración que dirige el tráfico web a través de un servidor intermedio, que el malware puede establecer para interceptar el tráfico.
netsh winhttp show proxy
Un comando que muestra el proxy de todo el sistema que usan los servicios de Windows.
Ejemplo real

El navegador de un usuario sigue abriendo un sitio de compras al iniciar sesión, incluso después de que un análisis antimalware informó que la PC estaba limpia. El técnico abre Autoruns y encuentra una entrada en una clave Run que inicia el navegador con esa dirección, además de una tarea programada que vuelve a crear la entrada todos los días. Al eliminar ambas y restablecer el navegador, el comportamiento se detiene, y el ticket enumera cada elemento como referencia futura.

Consejo para el examen: Si el malware sigue regresando después de eliminarlo, busca persistencia: Startup apps, claves Run, servicios y, sobre todo, tareas programadas. Si el tráfico web sigue comportándose mal, revisa el proxy, el DNS y el archivo hosts.

Comprueba lo que sabes

Un adware regresa después de cada reinicio aunque se eliminaron sus archivos. ¿Qué debes revisar?

Los lugares de persistencia: tareas programadas, claves Run del registro, carpetas Startup, servicios y extensiones del navegador.

¿Cómo puedes ver el proxy de todo el sistema que usan los servicios de Windows?

Ejecuta netsh winhttp show proxy desde un símbolo del sistema.

¿Por qué revisar todos los navegadores y no solo el predeterminado?

El malware a menudo instala extensiones o cambia la configuración en todos los navegadores instalados, y uno que no se revise puede reinfectar o seguir redirigiendo.

¿Qué podría hacer que reaparezca una extensión eliminada?

Que la sincronización del perfil del navegador la restaure desde la cuenta, o que una política del navegador o una tarea programada la reinstale.
