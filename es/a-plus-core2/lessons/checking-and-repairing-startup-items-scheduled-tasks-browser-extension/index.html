CompTIA A+ Core 2 220-1202

Revisión y reparación de elementos de inicio, tareas programadas, extensiones del navegador y configuración del proxy después de una infección

Eliminar el archivo del malware no siempre es suficiente. Muchas infecciones configuran persistencia, es decir, mecanismos que vuelven a iniciar el malware o restauran sus cambios después de un reinicio o después de que lo eliminas. Después de la remediación, revisa las ubicaciones de persistencia comunes y las configuraciones que al malware le gusta cambiar, o el problema volverá.

Elementos de inicio: abre la pestaña Startup apps de Task Manager para ver los programas que se inician al iniciar sesión, con su editor y su impacto. Deshabilita todo lo desconocido o sospechoso (búscalo si no estás seguro). Los programas también pueden iniciarse desde las carpetas de inicio (escribe shell:startup para el usuario actual o shell:common startup para todos los usuarios en el cuadro Run) y desde las claves Run del registro, como HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run y la clave correspondiente en HKEY_LOCAL_MACHINE. Revisa también Services (services.msc) en busca de servicios desconocidos configurados como Automatic, y msconfig para la configuración de arranque. Herramientas como Autoruns de Microsoft Sysinternals muestran todas las ubicaciones de inicio automático en una sola lista.

Tareas programadas: el malware con frecuencia crea una tarea en Task Scheduler (taskschd.msc) que se ejecuta al iniciar sesión, al arrancar o cada pocos minutos para reinstalarse o ejecutar un script. Explora la Task Scheduler Library, ordena por autor o por próxima ejecución e inspecciona la pestaña Actions de cada tarea desconocida para ver qué programa o script ejecuta. Deshabilita o elimina las tareas maliciosas después de anotar los detalles en el ticket.

Extensiones del navegador: abre el administrador de extensiones o complementos en cada navegador instalado, no solo en el predeterminado, y elimina todo lo que el usuario no haya instalado intencionalmente. Luego revisa la página de inicio del navegador, las páginas de arranque, la página de nueva pestaña y el buscador predeterminado, porque los secuestradores los cambian. Si las configuraciones siguen regresando, verifica si se estableció una directiva (los navegadores muestran un aviso de 'administrado por tu organización' cuando se aplican directivas); a veces el malware instala directivas del navegador. Restablecer el navegador a los valores predeterminados elimina la mayoría de los restos. Borra la caché y las cookies, y quita los permisos de notificación inesperados.

Configuración del proxy: el malware puede configurar un proxy para que todo el tráfico web pase por el servidor del atacante, o para que los sitios de seguridad fallen. Revisa Settings > Network and internet > Proxy (y la opción heredada Internet Options > Connections > LAN settings). A menos que la organización use un proxy, los scripts de configuración automática y los servidores proxy manuales deben estar desactivados. Revisa también netsh winhttp show proxy para ver el proxy del sistema que usan los servicios, la configuración del servidor DNS en el adaptador de red y el archivo hosts en busca de redirecciones.

Termina reiniciando y verificando de nuevo que nada reaparezca, ejecutando un análisis completo con un antimalware actualizado y documentando cada elemento eliminado. Si la persistencia sigue regresando a pesar de la limpieza, lo más seguro es reinstalar la imagen de la computadora.

Términos clave

Persistence (persistencia)
Técnicas que usa el malware para sobrevivir a los reinicios y a los intentos de eliminación, como claves Run, servicios y tareas programadas.
Run key (clave Run)
Una ubicación del registro cuyas entradas inician programas automáticamente al iniciar sesión o al arrancar.
Startup folder (carpeta de inicio)
Una carpeta cuyos accesos directos se ejecutan cuando un usuario inicia sesión (shell:startup).
Proxy server (servidor proxy)
Un intermediario que reenvía las solicitudes web; un proxy malicioso puede interceptar o redirigir el tráfico.
Autoruns
Una utilidad de Sysinternals que lista todas las ubicaciones que usa Windows para iniciar programas automáticamente.
Ejemplo real

Después de eliminar un adware, un técnico descubre que los anuncios regresan después de cada reinicio. Task Scheduler muestra una tarea con un nombre que imita a un actualizador y que ejecuta un script cada 30 minutos, y el navegador todavía muestra una extensión desconocida. Al eliminar la tarea, quitar la extensión y restablecer el navegador, los anuncios dejan de regresar.

Consejo para el examen: Si el malware sigue regresando después de eliminarlo, busca la persistencia: Startup apps, claves Run, servicios y, sobre todo, tareas programadas. Si el tráfico web sigue comportándose mal, revisa el proxy, el DNS y el archivo hosts.

Comprueba lo que sabes

¿Dónde buscarías una tarea que reinstala el malware cada 30 minutos?

En Task Scheduler (taskschd.msc), en la Task Scheduler Library, revisando los desencadenadores (triggers) y las acciones de cada tarea.

Menciona dos lugares desde los que Windows inicia programas automáticamente al iniciar sesión.

Startup apps de Task Manager (respaldado por la carpeta de inicio y las claves Run del registro), además de los servicios y las tareas programadas.

¿Por qué revisar la configuración del proxy después de una infección?

El malware puede configurar un proxy malicioso para interceptar o redirigir el tráfico web o para bloquear los sitios de seguridad.
