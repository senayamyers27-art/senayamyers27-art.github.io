CompTIA A+ Core 2 220-1202

Problemas de seguridad en la PC: no se puede acceder a la red, alertas de antivirus falsas, archivos del sistema alterados o faltantes, notificaciones no deseadas del sistema operativo, actualizaciones del sistema fallidas

Algunos síntomas en una PC con Windows son señales fuertes de malware, y el examen espera que los reconozcas y respondas con el procedimiento de eliminación de malware en lugar de tratarlos como fallas comunes.

No poder acceder a la red, o acceder solo a algunos sitios, puede deberse al malware. Algunos malware cambian la configuración del servidor DNS, editan el archivo hosts (C:\Windows\System32\drivers\etc\hosts) para redirigir o bloquear los sitios de seguridad, configuran un proxy malicioso o deshabilitan los adaptadores de red para impedir que la máquina reciba actualizaciones o sea limpiada. Otros malware bloquean específicamente el acceso a los sitios web de los fabricantes de antivirus. Revisa la configuración DNS del adaptador, el archivo hosts y la configuración del proxy, y compáralos con una máquina que funcione bien. Por supuesto, descarta primero las fallas de red comunes.

Las alertas de antivirus falsas, a menudo llamadas antivirus falso (rogue antivirus) o scareware, parecen software de seguridad que afirma haber encontrado decenas de infecciones y exige un pago por una 'versión completa' para eliminarlas, o insiste en que el usuario llame a un número de soporte. Pueden aparecer como ventanas emergentes de un sitio web o como un programa instalado en la máquina. Las alertas genuinas provienen del producto de seguridad que realmente usa la organización, lo cual puedes confirmar en Windows Security. Nunca pagues ni llames; trata la PC como infectada.

Los archivos del sistema alterados o faltantes, como archivos renombrados o eliminados, permisos cambiados o archivos que desaparecen de System32, pueden ser resultado de un malware que manipula el sistema operativo o se oculta, lo que a menudo provoca errores o fallos. Ejecuta sfc /scannow para detectar y reparar los archivos del sistema modificados, investiga más a fondo con herramientas antimalware y considera reinstalar la imagen si no se puede confiar en la integridad del sistema. Presta atención también a archivos desconocidos, extensiones de archivo cambiadas y archivos cifrados por ransomware.

Las notificaciones no deseadas del sistema operativo aparecen en el área de notificaciones de Windows, a menudo porque el usuario permitió que un sitio web enviara notificaciones del navegador, que luego muestran anuncios o advertencias falsas. Quita el permiso de notificaciones del sitio en la configuración del navegador y busca adware. Las actualizaciones del sistema fallidas, cuando Windows Update falla una y otra vez o el software de seguridad no puede actualizar sus definiciones, son una señal clásica, porque el malware intenta mantener vulnerable la máquina deteniendo o dañando los servicios de actualización. Otras causas incluyen poco espacio en disco, componentes de actualización dañados y problemas de red, así que revísalos también. Si Windows Update y el antivirus fallan al mismo tiempo, sospecha de malware.

Otros síntomas de esta familia incluyen un antivirus o firewall deshabilitado, configuraciones de seguridad que vuelven a cambiar después de corregirlas, cuentas de usuario desconocidas y nuevos elementos de inicio. Cuando aparecen varios de estos juntos, sigue el procedimiento de eliminación de malware en siete pasos: verificar los síntomas, poner en cuarentena, deshabilitar System Restore, remediar con herramientas actualizadas, programar análisis y actualizaciones, volver a habilitar System Restore y educar al usuario.

Términos clave

Rogue antivirus (antivirus falso)
Software de seguridad falso que informa infecciones inexistentes para engañar a los usuarios y lograr que paguen o instalen malware.
hosts file (archivo hosts)
Un archivo local que asocia nombres de host con direcciones IP y se consulta antes que el DNS; el malware puede editarlo para redirigir o bloquear sitios.
Browser notifications (notificaciones del navegador)
Alertas permitidas por un sitio que aparecen en el área de notificaciones del sistema operativo y se abusan para mostrar anuncios y advertencias falsas.
Integrity (integridad)
La garantía de que los archivos y los sistemas no se han alterado sin autorización.
Windows Update failure (falla de Windows Update)
Actualizaciones que fallan una y otra vez al instalarse, posiblemente porque un malware deshabilitó los servicios de actualización.
Ejemplo real

Un usuario reporta que su antivirus dice que no puede actualizarse y que el sitio web del fabricante no carga, aunque otros sitios funcionan. El técnico encuentra entradas en el archivo hosts que dirigen los dominios del fabricante del antivirus a 127.0.0.1. Al reconocer la manipulación por malware, desconecta la PC e inicia el procedimiento de eliminación de malware, analizando desde un medio de rescate de arranque.

Consejo para el examen: Cuando fallan tanto el software de seguridad como Windows Update, o solo los sitios de seguridad son inaccesibles, sospecha de malware. Las alertas de seguridad reales de Windows provienen de Windows Security o del antivirus administrado, no de una ventana emergente del navegador.

Comprueba lo que sabes

¿Por qué un malware bloquearía Windows Update?

Para mantener el sistema sin parches e impedir que las herramientas de seguridad se actualicen, de modo que el malware no sea eliminado ni detectado.

¿Qué archivo podría modificar un malware para redirigir o bloquear sitios web específicos?

El archivo hosts (C:\Windows\System32\drivers\etc\hosts).

Un usuario sigue viendo ventanas emergentes de anuncios de un sitio web en el área de notificaciones de Windows. ¿Cuál es la solución?

Quitar el permiso de notificaciones de ese sitio web en la configuración del navegador y buscar adware o extensiones no deseadas.
