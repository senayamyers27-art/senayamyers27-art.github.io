CompTIA A+ Core 2 220-1202

Problemas de seguridad en la PC: no se puede acceder a la red, alertas de antivirus falsas, archivos del sistema alterados o faltantes, notificaciones no deseadas del sistema operativo, actualizaciones del sistema fallidas

Algunos síntomas en una PC con Windows son señales claras de malware más que fallas comunes. El examen espera que los reconozcas, descartes las explicaciones cotidianas y luego respondas con el procedimiento de eliminación de malware en lugar de simplemente tapar el síntoma. El malware a menudo daña justamente lo que te ayudaría a eliminarlo, como el acceso de red a sitios de seguridad, los servicios de actualización y los archivos del sistema, así que estos síntomas son pistas sobre aquello de lo que intenta protegerse.

No poder acceder a la red, o acceder solo a algunos sitios, puede deberse a malware. Algunos malware cambian la configuración de los servidores DNS (Domain Name System) del adaptador, editan el archivo hosts en C:\Windows\System32\drivers\etc\hosts para redirigir o bloquear sitios de seguridad, configuran un proxy malicioso o deshabilitan los adaptadores de red para que el equipo no pueda actualizarse ni limpiarse. Una señal clásica es que la navegación general funciona, pero los sitios de los fabricantes de antivirus y Windows Update no. Por supuesto, descarta primero las fallas de red comunes: revisa el cableado, el Wi-Fi, la configuración IP y si otros usuarios están afectados. Luego compara la configuración de DNS, proxy y hosts con un equipo en buen estado.

Las alertas de antivirus falsas, también llamadas antivirus falsos (rogue antivirus) o scareware, parecen software de seguridad que informa decenas de infecciones y exige un pago por la “versión completa”, o insiste en que el usuario llame a un número de soporte. Pueden ser una ventana emergente de un sitio web o un programa realmente instalado en el equipo. Las alertas genuinas provienen del producto de seguridad que usa la organización, lo cual puedes confirmar en Windows Security o en la consola del antivirus administrado. Nunca pagues ni llames; trata la PC como posiblemente infectada e investiga. Las notificaciones no deseadas del sistema operativo aparecen en el área de notificaciones de Windows, a menudo porque el usuario hizo clic en “Allow” cuando un sitio web pidió enviar notificaciones; luego el sitio envía anuncios o advertencias falsas que parecen mensajes del sistema. Elimina el permiso de notificaciones de ese sitio en la configuración del navegador y busca adware.

Los archivos del sistema alterados o faltantes, como archivos renombrados o eliminados en System32, permisos cambiados o ejecutables desconocidos en carpetas del sistema, pueden deberse a que un malware manipula el sistema operativo o se oculta, lo que a menudo provoca errores o fallos. Ejecuta sfc /scannow para detectar y reparar los archivos protegidos modificados, analiza con herramientas antimalware actualizadas y considera reinstalar la imagen si no se puede confiar en la integridad del sistema. Presta atención también a extensiones de archivo cambiadas y a archivos cifrados por ransomware. Las actualizaciones del sistema fallidas, cuando Windows Update falla una y otra vez o el software de seguridad no puede actualizar sus definiciones, son otra señal clásica, porque el malware intenta mantener vulnerable el equipo deteniendo o dañando los servicios de actualización. El poco espacio en disco, los componentes de actualización dañados y los problemas de red también causan fallos, así que revísalos, pero si fallan tanto Windows Update como el antivirus, sospecha de malware.

Cuando varias de estas señales aparecen juntas, junto con otras como un antivirus o firewall deshabilitado, configuraciones de seguridad que vuelven a cambiar después de corregirlas, cuentas de usuario desconocidas o nuevos elementos de inicio, sigue el procedimiento de siete pasos de CompTIA para eliminar malware: (1) investigar y verificar los síntomas de malware; (2) poner en cuarentena el sistema infectado desconectándolo de la red; (3) deshabilitar System Restore en Windows para que no se reutilicen puntos de restauración infectados; (4) remediar actualizando el software antimalware y analizando, usando Safe Mode o un entorno de preinstalación si hace falta; (5) programar análisis y ejecutar actualizaciones; (6) habilitar System Restore y crear un nuevo punto de restauración; (7) capacitar al usuario final.

Veamos un ejemplo práctico. Un usuario informa que su antivirus dice que no puede actualizarse y que el sitio web del fabricante no carga, aunque los sitios de noticias y de compras sí funcionan. Abres el archivo hosts y encuentras entradas que apuntan los dominios del fabricante del antivirus y los dominios de actualización de Microsoft a 127.0.0.1, la dirección de loopback local, lo que los bloquea silenciosamente. Al reconocer la manipulación por malware, desconectas la PC, deshabilitas System Restore, analizas desde un medio de rescate de arranque, limpias el archivo hosts, actualizas y vuelves a analizar, luego habilitas de nuevo System Restore y le explicas al usuario cómo probablemente llegó la infección.

Errores comunes: corregir el archivo hosts o la configuración de DNS y cerrar el ticket sin eliminar el malware que los cambió; llamar al número de una alerta de antivirus falsa para “verificar”; culpar al malware de todas las actualizaciones fallidas sin revisar el espacio en disco; dejar System Restore habilitado durante la limpieza, de modo que sobreviva un punto de restauración infectado; y mantener el equipo conectado a la red mientras investigas.

Las preguntas del examen usan patrones reconocibles. “Solo los sitios web de seguridad no son accesibles” apunta a una manipulación del archivo hosts, del DNS o del proxy por malware. “Una ventana emergente exige un pago para eliminar las amenazas detectadas” apunta a un antivirus falso. “Fallan tanto el software de seguridad como Windows Update” apunta a malware. “Aparecen notificaciones con anuncios en la esquina de Windows después de visitar un sitio” apunta a los permisos de notificaciones del navegador. “Qué se debe hacer primero” suele ser verificar los síntomas; “qué se debe hacer a continuación después de confirmar el malware” es la cuarentena.

Términos clave

Antivirus falso (rogue antivirus)
Software de seguridad falso que informa infecciones inventadas para extorsionar un pago o instalar malware.
Archivo hosts
Un archivo local que asocia nombres con direcciones IP antes de usar DNS, que el malware puede editar para redirigir o bloquear sitios.
Proxy malicioso (rogue proxy)
Una configuración de proxy no autorizada que dirige el tráfico web de la PC a través de un servidor controlado por un atacante.
System File Checker (sfc)
Una herramienta de Windows que analiza los archivos protegidos del sistema y repara los que fueron alterados o faltan.
Cuarentena
Aislar un sistema infectado de la red para que el malware no pueda propagarse ni comunicarse.
Procedimiento de eliminación de malware
Los siete pasos ordenados de CompTIA, desde verificar los síntomas hasta capacitar al usuario.
Ejemplo real

La página Windows Security de una PC muestra la protección en tiempo real desactivada, y cada vez que el técnico la activa, se vuelve a desactivar en pocos minutos. Windows Update también falla con errores genéricos. En lugar de volver a activar la protección una y otra vez, el técnico lo trata como malware, desconecta la PC, deshabilita System Restore y la limpia desde un entorno de preinstalación antes de actualizar y volver a analizar.

Consejo para el examen: Cuando fallan tanto el software de seguridad como Windows Update, o solo los sitios de seguridad son inaccesibles, sospecha de malware. Las alertas de seguridad reales de Windows provienen de Windows Security o del antivirus administrado, nunca de una ventana emergente del navegador con un número de teléfono.

Comprueba lo que sabes

¿Por qué un malware podría editar el archivo hosts?

Para redirigir o bloquear dominios específicos, como los sitios de antivirus y de actualizaciones, de modo que la PC no pueda limpiarse ni parcharse.

¿Cuáles son los dos primeros pasos del procedimiento de eliminación de malware de CompTIA?

Investigar y verificar los síntomas de malware, y luego poner en cuarentena el sistema infectado.

¿Por qué se deshabilita System Restore durante la eliminación de malware?

Para que se eliminen los puntos de restauración que podrían contener el malware y no puedan volver a infectar el sistema más adelante.

Aparecen anuncios como notificaciones de Windows después de que un usuario visitó un sitio web. ¿Cuál es la causa probable y la solución?

El usuario permitió que el sitio enviara notificaciones; elimina su permiso de notificaciones en la configuración del navegador y busca adware.
