CompTIA A+ Core 2 220-1202

macOS: instalar y eliminar apps (.dmg, .pkg, .app, App Store), System Settings, Time Machine, FileVault, Keychain, Spotlight, Mission Control, Terminal, Disk Utility, Force Quit

Los técnicos de soporte se encuentran cada vez más con Mac, y el examen verifica que puedas realizar tareas cotidianas en ellas. Empieza por el software. La fuente más sencilla es la App Store, que instala, actualiza y elimina apps revisadas vinculadas al Apple ID del usuario. Fuera de la tienda, las apps suelen llegar como un archivo .dmg (imagen de disco): haz doble clic para montarlo como una unidad virtual, luego arrastra la .app a la carpeta Applications y expulsa la imagen. Una .app es en realidad un paquete (bundle) con forma de carpeta que contiene el programa y sus recursos. Un .pkg es un paquete instalador que ejecuta un asistente paso a paso y puede colocar archivos en varias ubicaciones del sistema; se usa cuando una app necesita controladores, servicios o componentes más allá de un solo bundle.

Eliminar apps suele ser fácil: arrastra la .app desde Applications a la Papelera (Trash), o en Launchpad mantén presionada una app de la App Store hasta que se mueva y haz clic en el botón de eliminar. Las apps instaladas desde un .pkg pueden dejar componentes, así que verifica si el fabricante ofrece un desinstalador. Gatekeeper, una protección integrada de macOS, comprueba que las apps descargadas estén firmadas y notarizadas por desarrolladores identificados, y advierte antes de abrir cualquier otra cosa.

System Settings (llamado System Preferences antes de macOS Ventura) es el panel de control de la Mac: usuarios y grupos, red, pantallas, privacidad y seguridad, impresoras, actualizaciones de software, etc. Time Machine es la herramienta de respaldo integrada; dirígela a una unidad externa o a un destino de red compatible y mantendrá respaldos cada hora, diarios y semanales, permitiéndote restaurar archivos individuales o la Mac completa. FileVault es el cifrado de disco completo; actívalo en Privacy and Security (o la sección equivalente) y guarda la clave de recuperación en un lugar seguro, porque sin ella o sin la contraseña del usuario los datos no pueden recuperarse.

Keychain (Llavero) es el gestor de contraseñas de macOS. Keychain Access almacena contraseñas de sitios web y de Wi-Fi, certificados y notas seguras, e iCloud Keychain sincroniza las contraseñas entre los dispositivos Apple del usuario. Las solicitudes repetidas de contraseña después de un cambio de contraseña suelen ser un problema del llavero. Spotlight (Command + Space) busca archivos, apps, configuraciones y más, y es la forma más rápida de abrir cualquier cosa. Mission Control muestra todas las ventanas abiertas y los escritorios virtuales (Spaces) para que puedas cambiar entre ellos; se abre con un deslizamiento en el trackpad o con su tecla del teclado.

Terminal ofrece un shell de línea de comandos Unix (zsh de forma predeterminada en las versiones actuales), donde funcionan comandos al estilo Linux como ls, cd, sudo y ps. Disk Utility (Utilidad de discos) administra las unidades: borrar y formatear con APFS, Mac OS Extended, exFAT o FAT, particionar, crear imágenes de disco y ejecutar First Aid para revisar y reparar un volumen. Force Quit (Forzar salida) cierra una app congelada; presiona Command + Option + Esc o elígelo en el menú Apple. También puedes abrir Activity Monitor (Monitor de actividad), el equivalente de Task Manager en la Mac, para ver el uso de CPU y memoria.

Otros elementos que vale la pena conocer son el Dock, Finder, iCloud, los gestos del trackpad, Boot Camp en las Mac Intel más antiguas para ejecutar Windows, y Remote Disc para compartir la unidad óptica de otra computadora con las Mac que no tienen una.

Términos clave

.dmg
Un archivo de imagen de disco de macOS que se monta como una unidad y normalmente contiene una app para arrastrar a Applications.
.pkg
Un paquete instalador de macOS que ejecuta una instalación guiada y puede instalar componentes en varias ubicaciones.
Time Machine
La utilidad de respaldo integrada de macOS que mantiene respaldos incrementales en una unidad externa o de red.
FileVault
El cifrado de disco completo de macOS, que protege los datos si la Mac se pierde o es robada.
Keychain (llavero)
El almacén de credenciales de macOS para contraseñas, certificados y notas seguras, que opcionalmente se sincroniza mediante iCloud.
Ejemplo real

La Mac de un diseñador se congela mientras se ejecuta una exportación grande; el mouse todavía se mueve, pero la app ignora los clics. El técnico presiona Command + Option + Esc, selecciona la app que no responde y elige Force Quit; luego usa Activity Monitor para confirmar que la presión de memoria bajó antes de volver a abrir la app.

Consejo para el examen: Asocia las herramientas de Mac con sus equivalentes en Windows: Activity Monitor es Task Manager, Force Quit es End task, FileVault es BitLocker, Time Machine es File History o el respaldo, Disk Utility es Disk Management más chkdsk, Spotlight es la búsqueda de Windows.

Comprueba lo que sabes

Un usuario descarga una app como .dmg. ¿Cómo la instala normalmente?

Hace doble clic para montar el .dmg, arrastra la .app a la carpeta Applications y luego expulsa la imagen de disco.

¿Qué atajo de teclado abre la ventana Force Quit?

Command + Option + Esc.

¿Qué debe guardar el usuario en un lugar seguro después de activar FileVault y por qué?

La clave de recuperación, porque sin ella o sin la contraseña de la cuenta el disco cifrado no puede desbloquearse.
