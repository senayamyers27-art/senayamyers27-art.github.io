Dominio 1: Operating systems (28%)

Consejos para el examen

  • EOL no significa que el sistema operativo deje de funcionar; significa que ya no habrá más parches de seguridad. Las respuestas del examen sobre sistemas EOL suelen apuntar a actualizarlos, reemplazarlos o aislarlos.
  • Un mensaje de 'archivo demasiado grande' en una unidad con mucho espacio libre casi siempre significa FAT32 y su límite de 4 GB por archivo. La solución es exFAT (para uso multiplataforma) o NTFS (solo para Windows).
  • Conoce las palabras clave: 'conservar archivos y apps' significa actualización in-place o instalación de reparación; 'empezar desde cero' significa instalación limpia; 'muchas máquinas idénticas' significa despliegue de imagen; 'arrancar por la red' significa PXE; los discos de más de 2 TB necesitan GPT.
  • Si una pregunta menciona unión a dominio, gpedit.msc, BitLocker o aceptar conexiones de Remote Desktop y el equipo tiene Home, la respuesta es actualizar a Pro (o superior).
  • Cuidado con las trampas de la edición Home: lusrmgr.msc y gpedit.msc no están disponibles en Windows Home. Además, Task Manager muestra el uso en tiempo real, mientras que Performance Monitor registra datos a lo largo del tiempo.
  • Conoce los pares: sfc repara archivos del sistema, DISM repara la imagen que usa sfc; gpupdate aplica directivas, gpresult las informa; tracert muestra la ruta, pathping agrega estadísticas de pérdida por salto.
  • Si una corrección de controlador o una actualización no parece surtir efecto después de Shut down, recuerda el inicio rápido: elige Restart, porque Shut down con inicio rápido no recarga el kernel por completo.
  • Una dirección 169.254.x.x significa que DHCP falló, no que la red esté bien. El perfil Public bloquea la detección y el uso compartido; Private los permite.
  • Asocia las herramientas de Mac con sus equivalentes en Windows: Activity Monitor es Task Manager, Force Quit es End task, FileVault es BitLocker, Time Machine es File History o el respaldo, Disk Utility es Disk Management más chkdsk, Spotlight es la búsqueda de Windows.
  • Los permisos octales aparecen con frecuencia: 7 = rwx, 6 = rw-, 5 = r-x, 4 = r--. Recuerda también que /etc/passwd contiene las cuentas, pero /etc/shadow contiene los hashes de las contraseñas.
  • Un sistema operativo de 64 bits ejecuta apps de 32 bits, pero un sistema operativo de 32 bits no puede ejecutar apps de 64 bits. Si un instalador se niega a ejecutarse en un equipo antiguo, verifica si el sistema operativo es de 32 bits.
  • La sincronización en la nube también replica las eliminaciones y los archivos cifrados por ransomware; no es un respaldo. Si un usuario 'no tiene buzón' o 'no puede activar Office', revisa primero la asignación de licencias.

Términos clave

Operating system (OS) (sistema operativo)
Software que administra los recursos del hardware y ofrece servicios y una interfaz para las aplicaciones y los usuarios.
End-of-life (EOL) (fin de vida)
La fecha a partir de la cual un fabricante ya no ofrece parches de seguridad ni soporte para un producto.
Open source (código abierto)
Software cuyo código fuente está disponible públicamente para inspeccionarlo, modificarlo y redistribuirlo según su licencia, como el kernel de Linux y el núcleo de Android.
Over-the-air (OTA) update (actualización inalámbrica)
Una actualización del sistema operativo o del firmware que se entrega de forma inalámbrica a un dispositivo móvil.
ChromeOS
El sistema operativo ligero de Google, enfocado en la nube, para Chromebooks, centrado en el navegador Chrome y en aplicaciones web.
NTFS
El sistema de archivos principal de Windows, con journaling, que admite permisos, cifrado EFS, compresión y cuotas.
exFAT
Un sistema de archivos ligero para medios flash sin el límite de 4 GB por archivo de FAT32, que Windows y macOS pueden leer y escribir.
Journaling (registro por diario)
Registrar los cambios previstos en un log antes de aplicarlos, para que el sistema de archivos pueda recuperarse de forma consistente tras un fallo o un corte de energía.
APFS
Apple File System, el predeterminado optimizado para SSD en macOS, iOS y iPadOS, con instantáneas y cifrado nativo.
ext4
El cuarto sistema de archivos extendido (fourth extended file system), un predeterminado común con journaling en las distribuciones de Linux.
PXE
Preboot Execution Environment: función del firmware que permite que una computadora arranque y cargue un instalador o una imagen a través de la red.
In-place upgrade (actualización in-place)
Instalar una versión más nueva del sistema operativo sobre la existente, conservando los archivos del usuario, las configuraciones y las aplicaciones.
GPT
GUID Partition Table: esquema de particionado moderno que se usa con UEFI y admite discos muy grandes y muchas particiones.
MBR
Master Boot Record: esquema de particionado heredado, limitado a cuatro particiones primarias y a discos de unos 2 TB.
Image deployment (despliegue de imagen)
Copiar una imagen de sistema operativo preparada y estandarizada en muchas computadoras para que queden configuradas de forma idéntica.
Domain join (unión a dominio)
Agregar una computadora a un dominio de Active Directory (o Entra ID) para que se administre de forma centralizada y los usuarios inicien sesión con cuentas del dominio.
Group Policy (directiva de grupo)
Una forma centralizada de aplicar configuraciones y ajustes de seguridad a usuarios y computadoras; el editor local es gpedit.msc.
Remote Desktop host (host de Escritorio remoto)
Una computadora que acepta conexiones entrantes del Remote Desktop Protocol (RDP); no está disponible en las ediciones Home.
BitLocker
Cifrado de volumen completo de Windows, disponible en las ediciones Pro, Enterprise y Education.
Edition upgrade (actualización de edición)
Cambiar, por ejemplo, de Home a Pro ingresando una nueva clave de producto, conservando apps y datos.
MMC
Microsoft Management Console: un marco que aloja complementos administrativos como Device Manager y Event Viewer.
Snap-in (complemento)
Una herramienta de administración que se carga en la MMC, normalmente guardada como archivo .msc.
msconfig
La utilidad System Configuration, que se usa para cambiar opciones de arranque (como Safe Boot) y deshabilitar servicios de forma selectiva.
Registry (registro)
La base de datos jerárquica de Windows con la configuración del sistema, el hardware, los usuarios y las aplicaciones; se edita con regedit.
Performance Monitor (Monitor de rendimiento)
Herramienta (perfmon) que registra contadores de rendimiento a lo largo del tiempo para crear líneas base y analizar tendencias.
robocopy
Herramienta de copia robusta de archivos que puede reintentar, reanudar, conservar permisos y reflejar árboles de directorios.
sfc /scannow
Comando de System File Checker (Comprobador de archivos del sistema) que verifica y repara los archivos protegidos del sistema Windows.
DISM
Deployment Image Servicing and Management: repara o da mantenimiento a la imagen de Windows de la que depende sfc.
gpresult
Comando que informa las configuraciones de Group Policy aplicadas a un usuario y a un equipo.
pathping
Comando que combina ping y tracert para medir la latencia y la pérdida de paquetes en cada salto.
Sleep (suspensión)
Estado de bajo consumo que mantiene la sesión en la RAM para reanudar muy rápido; la sesión se pierde si se corta la energía.
Hibernate (hibernación)
Guarda el contenido de la RAM en el disco (hiberfil.sys) y apaga el equipo por completo, así que la sesión sobrevive a un corte de energía.
Fast startup (inicio rápido)
Función de Windows que hiberna la sesión del kernel al apagar para acelerar el siguiente arranque; Restart la omite.
Default apps (apps predeterminadas)
Configuraciones que deciden qué aplicación abre un tipo de archivo o un enlace determinado.
Microsoft account (cuenta Microsoft)
Una identidad en línea que se usa para iniciar sesión en Windows, que puede sincronizar configuraciones y conectarse a los servicios en la nube de Microsoft, a diferencia de una cuenta local.
Workgroup (grupo de trabajo)
Una organización de igual a igual en la que cada computadora administra sus propias cuentas de usuario locales.
Domain (dominio)
Un grupo de computadoras y usuarios administrado de forma centralizada y controlado por controladores de dominio de Active Directory.
UNC path (ruta UNC)
Ruta Universal Naming Convention hacia un recurso de red, con el formato \\server\share.
APIPA
Automatic Private IP Addressing: una dirección 169.254.x.x autoasignada que se usa cuando ningún servidor DHCP responde.
Metered connection (conexión de uso medido)
Una red marcada como limitada o costosa, por lo que Windows restringe el uso de datos en segundo plano.
.dmg
Un archivo de imagen de disco de macOS que se monta como una unidad y normalmente contiene una app para arrastrar a Applications.
.pkg
Un paquete instalador de macOS que ejecuta una instalación guiada y puede instalar componentes en varias ubicaciones.
Time Machine
La utilidad de respaldo integrada de macOS que mantiene respaldos incrementales en una unidad externa o de red.
FileVault
El cifrado de disco completo de macOS, que protege los datos si la Mac se pierde o es robada.
Keychain (llavero)
El almacén de credenciales de macOS para contraseñas, certificados y notas seguras, que opcionalmente se sincroniza mediante iCloud.
sudo
Ejecuta un solo comando con privilegios elevados (normalmente de root), autenticándose con la contraseña del propio usuario y registrando la acción.
chmod
Cambia los permisos de un archivo, de forma simbólica o con valores octales como 755.
Package manager (gestor de paquetes)
Herramienta como apt o dnf que instala, actualiza y elimina software desde repositorios, manejando las dependencias.
/etc/shadow
Archivo accesible solo para root que almacena los hashes de las contraseñas de los usuarios y la información de vencimiento de contraseñas.
/etc/fstab
Archivo que define qué sistemas de archivos se montan al arrancar y en qué puntos de montaje.
64-bit application (aplicación de 64 bits)
Software compilado para un procesador y un sistema operativo de 64 bits, capaz de direccionar mucho más de 4 GB de memoria.
Program Files (x86)
La carpeta donde Windows de 64 bits instala las aplicaciones de 32 bits, separada de los programas de 64 bits en Program Files.
System requirements (requisitos del sistema)
La CPU, RAM, GPU, almacenamiento y sistema operativo mínimos o recomendados que un programa necesita para funcionar correctamente.
VRAM
Video RAM: memoria dedicada en una tarjeta gráfica que se usa para texturas y datos de fotogramas.
ISO
Una imagen de un disco óptico en un solo archivo que se usa para distribuir instaladores; puede montarse o grabarse.
Software as a Service (SaaS) (software como servicio)
Aplicaciones alojadas y mantenidas por un proveedor que se usan a través de internet mediante una suscripción.
Synced storage (almacenamiento sincronizado)
Un servicio de archivos en la nube que mantiene los archivos sincronizados entre la nube y todos los dispositivos del usuario con sesión iniciada.
IMAP
Internet Message Access Protocol: mantiene el correo en el servidor y lo sincroniza entre varios clientes.
Subscription licensing (licenciamiento por suscripción)
Licencias por usuario o por dispositivo que se pagan de forma recurrente y pueden reasignarse cuando el personal se va.
Files on demand (archivos a petición)
Una función de sincronización que muestra localmente todos los archivos de la nube, pero descarga cada uno solo cuando se abre.

Dominio 2: Security (28%)

Consejos para el examen

  • Los bolardos detienen vehículos, no personas. Los vestíbulos de control de acceso detienen el tailgating. La videovigilancia principalmente detecta y graba en lugar de prevenir, aunque las cámaras visibles también disuaden.
  • Una contraseña más un PIN sigue siendo un solo factor (ambos son 'algo que sabes'). De los métodos de MFA mencionados, los códigos por SMS y por correo electrónico son los más débiles; los tokens de hardware son los más fuertes.
  • Cuando se combinan permisos de recurso compartido y NTFS, toma el más restrictivo. Copiar un archivo hereda los permisos del destino; moverlo dentro del mismo volumen conserva los permisos originales.
  • RADIUS: UDP, cifra solo la contraseña, común para usuarios de Wi-Fi y VPN. TACACS+: TCP, cifra todo, común para el acceso de administradores a dispositivos de red. Elige AES en lugar de TKIP y WPA3 en lugar de WPA2 cuando esté disponible.
  • Asocia el síntoma: archivos cifrados con una nota de rescate significa ransomware; CPU alta sin razón significa criptominero; malware que se carga antes que el sistema operativo significa virus de sector de arranque o rootkit, lo que requiere analizar desde un entorno de recuperación o un medio de arranque.
  • Conoce los canales: phishing es correo electrónico, vishing es voz, smishing es SMS, quishing es código QR, whaling apunta a ejecutivos. Evil twin es una red Wi-Fi falsa; on-path es la interceptación entre dos partes.
  • La mayoría de las preguntas piden el siguiente paso. La cuarentena va antes de deshabilitar System Restore; actualizar el software antimalware va antes de analizar; volver a habilitar System Restore va después de que el sistema está limpio; educar al usuario va al final.
  • Las preguntas sobre laptops perdidas o robadas apuntan al cifrado de datos en reposo. 'Los usuarios dejan sus escritorios sin supervisión' apunta a los tiempos de bloqueo de pantalla. 'El malware se propaga desde memorias USB' apunta a deshabilitar AutoRun/AutoPlay.
  • Para BYOD, la respuesta suele ser un perfil de trabajo más el borrado selectivo de los datos corporativos, no un borrado total del teléfono personal del empleado. El borrado remoto solo funciona si se configuró antes de que el dispositivo se perdiera.
  • La desmagnetización no le hace nada a los SSD ni a los medios flash. Un formato rápido o estándar no elimina los datos. Si la unidad debe reutilizarse, bórrala por sobrescritura; si nunca más debe poder leerse, destrúyela físicamente y obtén un certificado.
  • El primer paso de endurecimiento de cualquier router SOHO es cambiar la contraseña de administrador predeterminada. El reenvío de puertos necesita una dirección interna estable, así que combínalo con una reserva DHCP o una IP estática.
  • La navegación privada oculta el historial solo en el dispositivo local; no ofrece anonimato ni protección contra malware. Un candado válido demuestra el cifrado hacia un dominio con nombre, no que el sitio sea confiable.

Términos clave

Access control vestibule (vestíbulo de control de acceso)
Un área de entrada pequeña con dos puertas interconectadas que deja pasar a una sola persona autenticada a la vez, evitando el tailgating.
Bollard (bolardo)
Un poste corto y resistente que impide que los vehículos lleguen a la entrada de un edificio, pero permite el paso de los peatones.
Badge reader (lector de credenciales)
Un dispositivo que lee tarjetas de identificación o llaveros electrónicos para desbloquear puertas a los usuarios autorizados y registrar cada entrada.
Tailgating (acceso a cuestas)
Seguir a una persona autorizada a través de una puerta protegida sin autenticarse.
Defense in depth (defensa en profundidad)
Usar varias capas de controles de seguridad para que la falla de una no deje expuesto el activo.
Least privilege (mínimo privilegio)
Conceder solo los derechos de acceso mínimos necesarios para realizar una tarea.
Zero trust (confianza cero)
Modelo de seguridad que nunca confía automáticamente en un usuario o dispositivo y verifica cada solicitud de acceso.
MFA
Autenticación multifactor: requerir factores de al menos dos categorías diferentes (algo que sabes, algo que tienes, algo que eres).
SSO
Single sign-on (inicio de sesión único): una sola autenticación da acceso a varias aplicaciones conectadas.
DLP
Data loss prevention (prevención de pérdida de datos): herramientas que detectan y bloquean la transferencia no autorizada de datos sensibles.
UAC
User Account Control (Control de cuentas de usuario): solicita consentimiento o credenciales antes de acciones que requieren derechos de administrador.
NTFS permissions (permisos NTFS)
Permisos del sistema de archivos que se aplican tanto localmente como a través de la red.
Share permissions (permisos de recurso compartido)
Permisos de una carpeta compartida que se aplican solo al acceso por red; combinados con NTFS, gana el más restrictivo.
BitLocker To Go
Cifrado BitLocker para unidades extraíbles como las memorias flash USB.
EFS
Encrypting File System: cifrado por archivo en NTFS vinculado al certificado de un usuario.
WPA3
El estándar actual de seguridad Wi-Fi, que usa SAE en el modo Personal para resistir los intentos de adivinar la contraseña sin conexión.
AES
Advanced Encryption Standard: el cifrado simétrico robusto que usan WPA2 y WPA3.
TKIP
Temporal Key Integrity Protocol: cifrado obsoleto del WPA original; evítalo.
RADIUS
Un protocolo y servidor AAA que se usa para autenticar de forma centralizada a los usuarios de Wi-Fi, VPN y la red; usa UDP.
TACACS+
Un protocolo AAA que usa TCP y cifra toda la carga útil, común para el acceso de administradores a dispositivos de red.
Kerberos
Protocolo de autenticación basado en tickets que usan los dominios de Active Directory.
Trojan (troyano)
Malware disfrazado de software legítimo que realiza acciones maliciosas ocultas; no se replica por sí mismo.
Rootkit
Malware que se incrusta profundamente en el sistema operativo o el firmware para ocultarse y mantener un acceso privilegiado.
Ransomware
Malware que cifra o roba datos y exige un pago para liberarlos.
Fileless malware (malware sin archivos)
Malware que se ejecuta en la memoria y abusa de herramientas legítimas del sistema en lugar de dejar archivos en el disco.
EDR
Endpoint detection and response: herramientas que monitorean el comportamiento de los endpoints para detectar, investigar y contener amenazas.
Phishing
Mensajes fraudulentos que suplantan a fuentes de confianza para robar credenciales o distribuir malware.
Whaling
Phishing dirigido específicamente a altos ejecutivos.
Evil twin (gemelo malvado)
Un punto de acceso inalámbrico falso que imita el nombre de una red legítima para interceptar el tráfico de los usuarios.
BEC
Business email compromise (compromiso del correo empresarial): usar una cuenta de correo de empresa secuestrada o falsificada para engañar al personal y obtener pagos o la divulgación de datos.
Zero-day (día cero)
Una vulnerabilidad desconocida para el fabricante o que no tiene un parche disponible.
On-path attack (ataque on-path)
Un atacante situado entre dos partes que se comunican para interceptar o modificar el tráfico.
Quarantine (cuarentena)
Aislar un sistema infectado de la red y de otros dispositivos para detener la propagación del malware.
System Restore (Restaurar sistema)
Función de Windows que devuelve los archivos y la configuración del sistema a un punto de restauración anterior; se deshabilita durante la eliminación de malware porque los puntos de restauración pueden estar infectados.
Remediation (remediación)
Eliminar el malware y reparar el daño, comenzando por actualizar las herramientas antimalware.
Preinstallation environment (entorno de preinstalación)
Un sistema operativo mínimo de arranque, como Windows PE, que se usa para analizar o reparar un sistema mientras su propio sistema operativo no se está ejecutando.
Restore point (punto de restauración)
Una instantánea de los archivos del sistema, el registro y la configuración a la que System Restore puede volver.
Hardening (endurecimiento)
Reducir la superficie de ataque de un sistema deshabilitando las funciones innecesarias y asegurando el resto.
Data at rest (datos en reposo)
Datos almacenados en un disco u otro medio, a diferencia de los datos que se mueven por una red.
Account lockout (bloqueo de cuenta)
Política que deshabilita temporalmente una cuenta tras un número determinado de intentos fallidos de inicio de sesión.
AutoPlay (reproducción automática)
Función de Windows que pregunta o actúa automáticamente al insertar un medio extraíble; se deshabilita al endurecer el sistema.
Guest account (cuenta de invitado)
Una cuenta integrada que permite iniciar sesión sin credenciales personales; debe permanecer deshabilitada.
Remote wipe (borrado remoto)
Borrar a través de la red los datos de un dispositivo perdido o robado.
MDM
Mobile device management (administración de dispositivos móviles): inscripción central y aplicación de políticas en dispositivos móviles, incluidos el bloqueo y el borrado remotos.
BYOD
Bring your own device (trae tu propio dispositivo): los empleados usan dispositivos personales para el trabajo, normalmente con un perfil de trabajo administrado.
Locator app (app de localización)
Una app o servicio que muestra la ubicación de un dispositivo y puede hacerlo sonar, bloquearlo o borrarlo.
Selective wipe (borrado selectivo)
Eliminar solo los datos y las apps corporativos de un dispositivo, dejando intactos los datos personales.
Degaussing (desmagnetización)
Borrar medios magnéticos con un campo magnético fuerte; no es eficaz en SSD ni en medios ópticos.
Wiping (borrado por sobrescritura)
Sobrescribir todos los datos de una unidad para que no puedan recuperarse, permitiendo reutilizar la unidad.
Standard format (formato estándar)
Crear un sistema de archivos nuevo sin sobrescribir los datos; los datos anteriores siguen siendo recuperables.
Certificate of destruction (certificado de destrucción)
Documento de un proveedor de destrucción que registra qué medios se destruyeron, cómo y cuándo.
Cryptographic erase (borrado criptográfico)
Sanitizar una unidad autocifrada destruyendo su clave de cifrado, lo que hace ilegibles los datos.
WPS
Wi-Fi Protected Setup: una función de emparejamiento simplificada cuyo método de PIN es vulnerable a ser adivinado; deshabilítala.
UPnP
Universal Plug and Play: permite que los dispositivos abran puertos del router automáticamente; deshabilítalo para evitar abusos.
Port forwarding (reenvío de puertos)
Regla del router que envía el tráfico que llega a un puerto externo a un dispositivo y puerto internos específicos.
DHCP reservation (reserva DHCP)
Configuración que siempre asigna la misma dirección IP a un dispositivo según su dirección MAC.
Guest network (red de invitados)
Una red inalámbrica separada que da acceso a internet a los visitantes, aislándolos de los recursos internos.
Hash check (verificación de hash)
Comparar el valor hash calculado de un archivo con el valor publicado por el fabricante para confirmar que no fue alterado.
Browser extension (extensión del navegador)
Un complemento que amplía las funciones del navegador y puede acceder al contenido de las páginas, por lo que debe provenir de fuentes confiables.
Certificate authority (CA) (autoridad de certificación)
Una organización de confianza que emite certificados digitales que avalan la identidad de un sitio web.
Private browsing (navegación privada)
Un modo del navegador que no conserva localmente el historial, las cookies ni los datos de formularios al terminar la sesión.
Profile sync (sincronización de perfiles)
Sincronizar marcadores, contraseñas, extensiones y configuraciones entre dispositivos mediante una cuenta del navegador.

Dominio 3: Software troubleshooting (23%)

Consejos para el examen

  • Los apagados inesperados sin BSOD normalmente significan calor o energía. 'No OS found' a menudo significa que el orden de arranque es incorrecto o que todavía hay una unidad USB conectada. Si el reloj se restablece tras un corte de energía, es la batería CMOS.
  • Elige la solución menos invasiva que corresponda a la causa: reiniciar antes que reinstalar, reinstalar la app antes que reparar Windows, System Restore antes que reinstalar la imagen. Si solo un usuario tiene el problema, sospecha del perfil.
  • Usa la herramienta adecuada para cada pregunta: 'qué está lento ahora mismo' es Task Manager, 'qué errores se registraron' es Event Viewer, 'qué cambió antes de que empezara esto' es Reliability Monitor, 'Windows no arranca' es WinRE.
  • La pantalla no gira: revisa primero el bloqueo de rotación. La app no se actualiza: revisa el almacenamiento y la compatibilidad del sistema operativo. El accesorio Bluetooth no se conecta: desemparéjalo y vuelve a emparejarlo.
  • El jailbreak y el rooting son causas; el alto uso de datos, el agotamiento de la batería, las advertencias falsas y el comportamiento extraño de las apps son síntomas. El remedio habitual para un dispositivo comprometido o con jailbreak es respaldar los datos personales y hacer un restablecimiento de fábrica.
  • Cuando fallan tanto el software de seguridad como Windows Update, o solo los sitios de seguridad son inaccesibles, sospecha de malware. Las alertas de seguridad reales de Windows provienen de Windows Security o del antivirus administrado, no de una ventana emergente del navegador.
  • Los errores de certificado en todos los sitios normalmente significan un reloj del sistema incorrecto (o un proxy que intercepta). Una advertencia en un solo sitio normalmente significa que el certificado de ese sitio tiene un problema, o que te están interceptando en esa conexión.
  • Si el malware sigue regresando después de eliminarlo, busca la persistencia: Startup apps, claves Run, servicios y, sobre todo, tareas programadas. Si el tráfico web sigue comportándose mal, revisa el proxy, el DNS y el archivo hosts.

Términos clave

BSOD
Blue screen of death (pantalla azul de la muerte): un error de detención de Windows que detiene el sistema tras una falla crítica, a menudo relacionada con controladores o hardware.
Stop code (código de detención)
El nombre o número de error que aparece en una BSOD e identifica el tipo de falla.
Memory leak (fuga de memoria)
Un error de programación que sigue consumiendo memoria sin liberarla, lo que con el tiempo provoca condiciones de poca memoria.
Time drift (desfase del reloj)
Un reloj de computadora que se vuelve impreciso gradualmente, a menudo por una batería CMOS agotada o por problemas de sincronización de la hora.
Temporary profile (perfil temporal)
Un perfil que Windows carga cuando no puede cargar el perfil real del usuario; descarta los cambios al cerrar sesión.
System Restore (Restaurar sistema)
Revierte los archivos del sistema, el registro, los controladores y los programas a un punto de restauración, conservando los archivos personales.
Reimage (reinstalar la imagen)
Reemplazar la instalación del sistema operativo de una computadora con una imagen estándar nueva o una instalación limpia.
Roll back driver (revertir controlador)
Una opción de Device Manager que reinstala la versión del controlador instalada anteriormente.
Repair install (instalación de reparación)
Reinstalar Windows in-place para reemplazar los archivos del sistema conservando las aplicaciones y los datos.
User profile rebuild (reconstrucción del perfil de usuario)
Crear un perfil de usuario nuevo para corregir un daño y luego restaurar en él los datos del usuario.
Event ID
Un número que identifica el tipo de evento registrado por un origen determinado en Event Viewer.
Reliability Monitor (Monitor de confiabilidad)
Una línea de tiempo de fallas de aplicaciones y de Windows, advertencias e instalaciones que se usa para correlacionar los problemas con los cambios.
Safe Mode (Modo seguro)
Un modo de inicio de diagnóstico que carga solo los controladores y servicios esenciales.
WinRE
Windows Recovery Environment: un sistema operativo de recuperación que ofrece Startup Repair, System Restore, opciones de Safe Mode y un símbolo del sistema.
System log (registro System)
El registro de Event Viewer que guarda los eventos de los componentes, controladores y servicios de Windows.
Force stop (forzar detención)
Cerrar por completo los procesos de una app para que se reinicie limpiamente la próxima vez que se abra.
Clear cache (borrar caché)
Eliminar los archivos temporales de una app sin quitar los datos de su cuenta ni su configuración.
Reset network settings (restablecer configuración de red)
Devolver la configuración de Wi-Fi, Bluetooth y red celular a los valores predeterminados, eliminando las redes guardadas y los emparejamientos.
NFC
Near-field communication (comunicación de campo cercano): tecnología inalámbrica de muy corto alcance que se usa para pagos sin contacto y emparejamiento.
Rotation lock (bloqueo de rotación)
Una configuración que mantiene la pantalla en una sola orientación sin importar cómo se sostenga el dispositivo.
Sideloading (instalación lateral)
Instalar una app desde fuera de la tienda de apps oficial, por ejemplo desde un archivo APK descargado.
APK
Android Package: el formato de archivo que se usa para distribuir e instalar apps de Android.
Jailbreaking (jailbreak)
Eliminar las restricciones de iOS de Apple para obtener control total, lo que debilita el modelo de seguridad del dispositivo.
Rooting
Obtener acceso root (de administrador) en un dispositivo Android, eludiendo sus protecciones integradas.
Scareware
Alertas de seguridad falsas diseñadas para asustar a los usuarios y lograr que instalen malware o paguen por servicios inútiles.
Rogue antivirus (antivirus falso)
Software de seguridad falso que informa infecciones inexistentes para engañar a los usuarios y lograr que paguen o instalen malware.
hosts file (archivo hosts)
Un archivo local que asocia nombres de host con direcciones IP y se consulta antes que el DNS; el malware puede editarlo para redirigir o bloquear sitios.
Browser notifications (notificaciones del navegador)
Alertas permitidas por un sitio que aparecen en el área de notificaciones del sistema operativo y se abusan para mostrar anuncios y advertencias falsas.
Integrity (integridad)
La garantía de que los archivos y los sistemas no se han alterado sin autorización.
Windows Update failure (falla de Windows Update)
Actualizaciones que fallan una y otra vez al instalarse, posiblemente porque un malware deshabilitó los servicios de actualización.
Browser hijacker (secuestrador del navegador)
Malware o una extensión no deseada que cambia la página de inicio, el buscador o la página de nueva pestaña y redirige el tráfico.
Certificate warning (advertencia de certificado)
Una alerta del navegador que indica que el certificado de un sitio no es válido, está vencido, no es de confianza o no coincide con la dirección.
Tech support scam (estafa de soporte técnico)
Una ventana emergente o llamada que afirma falsamente que la computadora está infectada e insiste en que la víctima llame o pague.
Browser reset (restablecimiento del navegador)
Devolver la configuración de un navegador a los valores predeterminados, deshabilitando las extensiones y borrando los datos temporales.
Rogue root certificate (certificado raíz falso)
Una autoridad de certificación no confiable agregada al almacén de certificados, que permite a un atacante suplantar sitios seguros.
Persistence (persistencia)
Técnicas que usa el malware para sobrevivir a los reinicios y a los intentos de eliminación, como claves Run, servicios y tareas programadas.
Run key (clave Run)
Una ubicación del registro cuyas entradas inician programas automáticamente al iniciar sesión o al arrancar.
Startup folder (carpeta de inicio)
Una carpeta cuyos accesos directos se ejecutan cuando un usuario inicia sesión (shell:startup).
Proxy server (servidor proxy)
Un intermediario que reenvía las solicitudes web; un proxy malicioso puede interceptar o redirigir el tráfico.
Autoruns
Una utilidad de Sysinternals que lista todas las ubicaciones que usa Windows para iniciar programas automáticamente.

Dominio 4: Operational procedures (21%)

Consejos para el examen

  • Las buenas notas de ticket son específicas, objetivas y lo bastante completas para que otra persona pueda continuar el trabajo. La severidad y la prioridad aumentan con el número de personas afectadas y el impacto en el negocio.
  • Un inventario te dice qué posees; una CMDB además te dice cómo se relacionan y dependen los elementos entre sí. Los registros de activos siempre deben incluir el usuario asignado y la información de garantía y licencias.
  • Reglas para los usuarios: AUP. Tarea rutinaria paso a paso: SOP. Respuesta o disponibilidad prometida: SLA. Registro de lo que ocurrió: informe de incidente. Solución reutilizable: artículo de la base de conocimientos.
  • Los cambios deben probarse en un sandbox y ser aprobados por el CAB antes de implementarse, y todo cambio necesita un plan de reversión. La aceptación del usuario final viene después de la implementación.
  • Incremental: los respaldos más rápidos, la restauración más lenta (completo más cada incremental). Diferencial: los respaldos crecen cada día, la restauración solo necesita el completo más el diferencial más reciente. No se puede confiar en respaldos que no se han probado.
  • Nunca uses agua en un incendio eléctrico, nunca abras una fuente de poder y nunca uses una pulsera ESD al trabajar con equipos de alto voltaje. Levanta con las piernas, no con la espalda.
  • Para saber cómo manejar o desechar un producto químico, consulta su SDS. Un UPS mantiene la energía durante los cortes; un supresor de picos solo protege contra los picos; una regleta no protege contra nada.
  • Orden ante contenido prohibido: identificar, reportar por los canales adecuados, preservar la evidencia, documentar. PCI DSS abarca los datos de tarjetas, PHI son datos de salud, GDPR son datos personales de la UE, PII es cualquier dato que identifique.
  • Ante la duda en las preguntas de profesionalismo, elige la respuesta que sea calmada y respetuosa, que mantenga informado al cliente y que evite las distracciones. Nunca discutas, culpes al usuario ni hables de sus datos privados.
  • Asocia las extensiones con las plataformas: .bat, .ps1 y .vbs son de Windows; .sh es de Linux/macOS; .py y .js son multiplataforma. Las respuestas principales sobre riesgos son los cambios no intencionados en el sistema, la introducción de malware y los problemas de recursos, así que prueba antes de desplegar.
  • SSH (22) reemplazó a Telnet para el acceso seguro por línea de comandos; RDP (3389) es el acceso gráfico a Windows y nunca debe exponerse directamente a internet. Una VPN protege la conexión; por sí sola no es una herramienta de control remoto.
  • Nunca ingreses datos confidenciales o regulados en un modelo de IA público a menos que la política lo permita explícitamente. Verifica siempre los resultados de la IA, ya que las alucinaciones suenan seguras.

Términos clave

Ticket
Un registro en un sistema de gestión de servicios de TI que da seguimiento a una solicitud o incidente desde el reporte hasta la resolución.
Severity (severidad)
Qué tan grave es el impacto de un problema; combinada con la urgencia, determina la prioridad del ticket.
Escalation (escalamiento)
Pasar un ticket a un nivel de soporte superior o a un equipo especialista cuando supera las habilidades, los permisos o los límites de tiempo actuales.
Progress notes (notas de avance)
Entradas en orden cronológico que documentan las acciones, los hallazgos y las comunicaciones de un ticket.
Resolution (resolución)
La entrada de cierre que describe la causa, la solución y la confirmación del usuario.
Asset tag (etiqueta de activo)
Una etiqueta con un ID único, a menudo un código de barras o código QR, que vincula un dispositivo físico con su registro en el inventario.
CMDB
Configuration management database (base de datos de gestión de la configuración): almacena los elementos de configuración y sus relaciones para apoyar la gestión de cambios y de incidentes.
Configuration item (CI) (elemento de configuración)
Cualquier componente registrado en una CMDB, como un servidor, una aplicación o un servicio.
Procurement life cycle (ciclo de vida de adquisición)
Las etapas de un activo desde la solicitud de compra hasta el despliegue, el mantenimiento y la eliminación.
License compliance (cumplimiento de licencias)
Asegurar que el número y el tipo de instalaciones de software coincidan con las licencias adquiridas.
AUP
Acceptable use policy (política de uso aceptable): reglas sobre cómo los usuarios pueden usar los sistemas y los datos de la organización.
SOP
Standard operating procedure (procedimiento operativo estándar): instrucciones documentadas paso a paso para una tarea rutinaria.
SLA
Service level agreement (acuerdo de nivel de servicio): define los niveles de servicio esperados, como los tiempos de respuesta y la disponibilidad, entre el proveedor y el cliente.
Incident report (informe de incidente)
Un registro objetivo de un incidente de seguridad o de servicio, su impacto y la respuesta.
Knowledge base (base de conocimientos)
Una colección de artículos con búsqueda que documenta soluciones y procedimientos.
Change request (solicitud de cambio)
Un formulario formal que propone un cambio, incluidos el propósito, el alcance, el calendario, el riesgo y los planes.
CAB
Change advisory board (comité asesor de cambios): el grupo que revisa y aprueba o rechaza los cambios propuestos.
Rollback plan (plan de reversión)
Pasos documentados para restaurar los sistemas a su estado previo al cambio si este falla.
Sandbox
Un entorno de pruebas aislado donde se pueden probar los cambios sin afectar la producción.
End-user acceptance (aceptación del usuario final)
La confirmación por parte del negocio o de los usuarios de que un cambio completado satisface sus necesidades.
Incremental backup (respaldo incremental)
Respalda los datos que cambiaron desde el último respaldo de cualquier tipo; la restauración necesita el completo más todos los incrementales.
Differential backup (respaldo diferencial)
Respalda los datos que cambiaron desde el último respaldo completo; la restauración necesita el completo más el diferencial más reciente.
Synthetic full backup (respaldo completo sintético)
Un respaldo completo armado en el sistema de respaldo a partir de un completo anterior y los incrementales posteriores.
3-2-1 rule (regla 3-2-1)
Conservar tres copias de los datos en dos tipos distintos de medios, con una copia fuera de sitio.
GFS rotation (rotación GFS)
Grandfather-father-son (abuelo-padre-hijo): conjuntos de respaldo diarios, semanales y mensuales que se conservan durante periodos cada vez más largos.
ESD
Electrostatic discharge (descarga electrostática): transferencia repentina de electricidad estática que puede dañar los componentes electrónicos.
ESD wrist strap (pulsera antiestática)
Una pulsera conectada a tierra que drena de forma segura la estática del cuerpo del técnico mientras trabaja con componentes.
Class C extinguisher (extintor Clase C)
Clasificación de Estados Unidos para los extintores adecuados para incendios en equipos eléctricos energizados.
PPE (EPP)
Equipo de protección personal, como lentes de seguridad, guantes y mascarillas.
Self-grounding (autoconexión a tierra)
Tocar el metal sin pintar de un chasis conectado a tierra para igualar la carga estática cuando no hay una pulsera disponible.
SDS
Safety data sheet (hoja de datos de seguridad): documento del fabricante que describe los peligros, el manejo, los primeros auxilios y el desecho de un producto.
E-waste (residuos electrónicos)
Equipos electrónicos desechados que deben reciclarse o eliminarse según la normativa.
UPS
Uninterruptible power supply (sistema de alimentación ininterrumpida): unidad con batería que alimenta los equipos durante cortes y caídas de voltaje.
Surge suppressor (supresor de picos)
Un dispositivo que protege los equipos de los picos de voltaje desviando el exceso de energía; su capacidad se mide en joules.
Toner vacuum (aspiradora para tóner)
Una aspiradora con un filtro fino diseñada para limpiar de forma segura los derrames de tóner.
Chain of custody (cadena de custodia)
Registro documentado de cada persona que manipuló la evidencia y cuándo, que demuestra que no fue alterada.
EULA
End-user license agreement (contrato de licencia de usuario final): los términos bajo los cuales se permite a un usuario usar el software.
PII
Personally identifiable information (información de identificación personal): datos que pueden identificar a una persona específica.
PCI DSS
Payment Card Industry Data Security Standard: requisitos de seguridad para el manejo de datos de tarjetas de pago.
GDPR
Reglamento de la UE que protege los datos personales y los derechos de privacidad de las personas en la Unión Europea.
PHI
Protected health information (información de salud protegida): datos de salud que identifican a una persona, protegidos en Estados Unidos por HIPAA.
Active listening (escucha activa)
Concentrarse por completo en quien habla, sin interrumpir, y reformular el problema para confirmar que se entendió.
Open-ended question (pregunta abierta)
Una pregunta que invita a una respuesta detallada; se usa para reunir información.
Closed-ended question (pregunta cerrada)
Una pregunta que se responde con sí, no o un dato específico; se usa para acotar un problema.
Jargon (jerga técnica)
Lenguaje técnico especializado que las personas que no son expertas podrían no entender.
Setting expectations (establecer expectativas)
Decirle al cliente qué va a pasar, cuánto tiempo tomará y cuáles son las opciones.
.ps1
Un archivo de script de PowerShell, el lenguaje de automatización moderno de Windows.
.bat
Un archivo por lotes (batch) de Windows con comandos de Command Prompt.
.sh
Un script de shell para Linux o macOS, que ejecuta bash u otro shell.
Execution policy (directiva de ejecución)
Configuración de PowerShell que controla si pueden ejecutarse scripts y cuáles, por ejemplo solo los firmados.
Variable
Un marcador con nombre en un script que almacena un valor para usarlo más adelante.
RDP
Remote Desktop Protocol: el protocolo de sesión remota gráfica de Microsoft; puerto TCP predeterminado 3389.
SSH
Secure Shell: acceso remoto cifrado por línea de comandos; puerto TCP predeterminado 22.
VNC
Virtual Network Computing: protocolo multiplataforma para compartir pantalla que a menudo necesita un túnel cifrado.
RMM
Remote monitoring and management (monitoreo y administración remotos): plataformas para monitorear, aplicar parches y controlar muchos endpoints.
WinRM
Windows Remote Management: protocolo para ejecutar comandos de PowerShell en sistemas Windows remotos.
Generative AI (IA generativa)
IA que crea texto, imágenes, código u otro contenido nuevo a partir de patrones aprendidos de los datos de entrenamiento.
Hallucination (alucinación)
Un resultado seguro de sí mismo pero falso o inventado de un modelo de IA.
Bias (sesgo)
Injusticia sistemática en los resultados de la IA causada por datos de entrenamiento o un diseño sesgados.
Public model (modelo público)
Un servicio de IA abierto al público, cuyos términos pueden permitir que las instrucciones se almacenen o se usen para entrenamiento.
Private model (modelo privado)
Un modelo de IA ejecutado internamente o bajo un acuerdo empresarial que mantiene los datos de la organización bajo su control.
