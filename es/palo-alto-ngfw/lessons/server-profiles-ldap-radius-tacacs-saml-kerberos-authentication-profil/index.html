Server profiles (LDAP, RADIUS, TACACS+, SAML, Kerberos), perfiles y secuencias de autenticación, MFA

PAN-OS separa el 'dónde está el servidor de identidad' del 'cómo autenticamos'. Un server profile le indica al firewall cómo llegar a un servicio externo. Un perfil de autenticación (authentication profile) indica qué server profile (o base de datos local) usar para un inicio de sesión determinado y agrega reglas como MFA y listas de permitidos. Luego, funciones como el inicio de sesión de administradores, GlobalProtect y Authentication Portal hacen referencia al perfil de autenticación.

Los server profiles se encuentran en Device > Server Profiles. Los perfiles LDAP enumeran los servidores, el tipo (Active Directory, eDirectory, Sun u otro), el base DN, el bind DN y la contraseña, y si se usa SSL/TLS (LDAPS). Se usan tanto para la autenticación como para el group mapping de User-ID. Los perfiles RADIUS contienen los servidores, un secreto compartido, el tiempo de espera y los reintentos, y un protocolo de autenticación como PEAP-MSCHAPv2 o PAP; RADIUS admite challenge-response, que usan muchos productos de MFA, y puede devolver atributos específicos del fabricante para los roles de administrador. Los perfiles TACACS+ son similares, pero cifran toda la carga útil y funcionan sobre TCP, y son populares para la administración de dispositivos. Los perfiles SAML se crean importando los metadatos del proveedor de identidad (IdP), incluidos su certificado de firma y su URL de SSO, lo que habilita el inicio de sesión único mediante proveedores como Microsoft Entra ID u Okta. Los perfiles Kerberos apuntan a un Key Distribution Center para la autenticación Kerberos; el inicio de sesión único Kerberos para clientes web también necesita un keytab en el perfil de autenticación.

Un perfil de autenticación (Device > Authentication Profile) define el tipo (Local Database, LDAP, RADIUS, TACACS+, SAML, Kerberos, Cloud Authentication Service), el server profile, un dominio de usuario y un modificador de nombre de usuario (por ejemplo %USERDOMAIN%\%USERINPUT%), una lista de usuarios o grupos permitidos (allow list) y la configuración de bloqueo. Su pestaña Factors habilita la autenticación multifactor (MFA) agregando MFA server profiles de los fabricantes compatibles, que solicitan factores adicionales después de que el primero tiene éxito.

Una secuencia de autenticación (authentication sequence) es una lista ordenada de perfiles de autenticación. El firewall prueba cada uno en orden hasta que uno tiene éxito. Un uso común es probar LDAP para los empleados y luego la base de datos local como respaldo de emergencia (break-glass) si el directorio no está disponible, o probar dos dominios. Puedes hacer referencia a una secuencia en cualquier lugar donde se acepte un perfil de autenticación.

La autenticación multifactor puede ocurrir en varios lugares. Lo más sencillo es que un IdP maneje la MFA a través de SAML, o un servidor RADIUS que realice la MFA por sí mismo. El firewall también puede conducir la MFA mediante MFA server profiles en un perfil de autenticación, y la Authentication policy puede exigir MFA antes de que los usuarios lleguen a recursos sensibles, incluso para aplicaciones que no son web.

Prueba con test authentication authentication-profile <name> username <user> en la CLI y revisa los fallos en los logs System y Authentication.

Términos clave

Server profile (perfil de servidor)
La configuración de conexión para un servicio externo como LDAP, RADIUS, TACACS+, un IdP SAML o un KDC Kerberos.
Authentication profile (perfil de autenticación)
Un perfil que selecciona el método y el servidor de autenticación, el formato del nombre de usuario, la lista de permitidos, el bloqueo y los factores de MFA.
Authentication sequence (secuencia de autenticación)
Una lista ordenada de perfiles de autenticación que se prueban uno tras otro hasta que uno tiene éxito.
TACACS+
Un protocolo AAA para administración de dispositivos que funciona sobre TCP y cifra toda la carga útil.
Ejemplo real

Los administradores remotos inician sesión con RADIUS respaldado por un servicio de MFA, pero si los servidores RADIUS no están disponibles, nadie puede administrar el firewall. Creas una secuencia de autenticación que prueba primero el perfil RADIUS y después la base de datos local, y mantienes una cuenta local de emergencia robusta guardada de forma segura.

Consejo para el examen: Server profile = dónde; perfil de autenticación = cómo y quién; secuencia = probar varios en orden. SAML se configura importando los metadatos del IdP. RADIUS y los IdP SAML suelen proporcionar la MFA.

¿Qué tipo de server profile cifra todo el cuerpo del paquete y usa TCP?

TACACS+.

¿Qué hace una secuencia de autenticación si el servidor del primer perfil no está disponible?

Pasa al siguiente perfil de autenticación de la lista.

¿Qué server profile se usa tanto para la autenticación como para el group mapping?

LDAP.
