Palo Alto Networks Certified Next-Generation Firewall Engineer NGFW-Engineer

Formatos: PA-Series, VM-Series, CN-Series, Cloud NGFW para AWS y Azure

Palo Alto ejecuta la misma tecnología central, PAN-OS con App-ID, User-ID, Content-ID y las suscripciones de seguridad, en varios formatos (form factors). El examen espera que sepas elegir el adecuado para un escenario y que sepas cómo se administra cada uno.

Los firewalls PA-Series son appliances físicos, desde modelos pequeños para sucursales hasta grandes chasis para centros de datos y proveedores de servicios. Usan una arquitectura single-pass en la que el tráfico se clasifica e inspecciona una sola vez, con hardware dedicado para el plano de administración y el plano de datos, de modo que las tareas pesadas de administración no ralentizan el tráfico. Elige PA-Series para bordes de campus, centros de datos y sucursales donde eres dueño de la red física.

Los firewalls VM-Series son el mismo PAN-OS como máquina virtual. Se ejecutan en hipervisores de nube privada como VMware ESXi, KVM e Hyper-V, y en nubes públicas como AWS, Azure, Google Cloud y Oracle Cloud. El licenciamiento está disponible mediante modelos flexibles basados en créditos o mediante los marketplaces de la nube. Administras VM-Series como cualquier firewall, normalmente a través de Panorama o de la administración en la nube, y los despliegas con bootstrapping e infraestructura como código. En la nube sigues siendo dueño de las máquinas virtuales: el dimensionamiento, el escalado, la aplicación de parches y la alta disponibilidad son tu responsabilidad, a menudo usando balanceadores de carga de la nube.

Los firewalls CN-Series protegen entornos Kubernetes. Se entregan como contenedores: un componente de administración (CN-MGMT) y componentes de plano de datos del firewall (CN-NGFW) que inspeccionan el tráfico entre pods, namespaces y servicios, incluido el tráfico este-oeste que nunca sale del clúster. Se despliegan con manifiestos de Kubernetes o Helm charts, ya sea como DaemonSet (un pod de firewall por nodo) o en modo de servicio de Kubernetes, y se administran con Panorama mediante un plugin de Kubernetes que puede aprender las etiquetas (labels) de los pods y convertirlas en tags para una política dinámica.

Cloud NGFW for AWS y Cloud NGFW for Azure son servicios administrados. Palo Alto opera la infraestructura del firewall, incluidos el escalado, la disponibilidad y las actualizaciones, y tú lo consumes como un recurso nativo de la nube comprado a través del marketplace de la nube. En AWS se inserta con endpoints que funcionan con el modelo de Gateway Load Balancer; en Azure se despliega en una red virtual o en un hub de Virtual WAN. La política se administra como rulestacks a través de la consola de la nube, API o infraestructura como código, o mediante la integración con Panorama. Renuncias a parte del control de bajo nivel en comparación con VM-Series a cambio de no tener que operar tú mismo los firewalls.

Una forma sencilla de decidir: red física, PA-Series; máquinas virtuales que quieres controlar por completo, VM-Series; cargas de trabajo en Kubernetes, CN-Series; redes en la nube donde quieres una experiencia administrada al estilo de un proveedor, Cloud NGFW. Los usuarios remotos y las sucursales consumidos como servicio en la nube apuntan a Prisma Access, la oferta SASE construida sobre la misma tecnología.

Términos clave

PA-Series
Los firewalls físicos de hardware de Palo Alto, con recursos separados para el plano de administración y el plano de datos.
VM-Series
La forma de máquina virtual de PAN-OS para hipervisores privados y nubes públicas, operada por el cliente.
CN-Series
Firewalls en contenedores para Kubernetes, con componentes CN-MGMT y CN-NGFW administrados por Panorama.
Cloud NGFW
Un servicio de firewall administrado para AWS y Azure que opera Palo Alto y que los clientes consumen como un recurso nativo de la nube.
Rulestack
La colección de reglas y objetos usada para configurar un recurso de Cloud NGFW.
Ejemplo real

Una empresa protege su centro de datos con PA-Series, ejecuta VM-Series en una nube privada VMware, usa CN-Series para controlar el tráfico entre namespaces en sus clústeres de Kubernetes y, para una nueva cuenta de AWS en la que el equipo no quiere administrar instancias de firewall, se suscribe a Cloud NGFW for AWS a través del marketplace.

Consejo para el examen: Servicio administrado sin instancias que operar significa Cloud NGFW. Inspección este-oeste en Kubernetes significa CN-Series. Control total de un firewall virtual en cualquier hipervisor o nube significa VM-Series.

Comprueba lo que sabes

¿Qué formato debes elegir para inspeccionar el tráfico de pod a pod dentro de un clúster de Kubernetes?

CN-Series.

¿Quién se encarga del escalado y las actualizaciones de Cloud NGFW for AWS?

Palo Alto Networks, porque es un servicio administrado.

¿Qué administra los firewalls CN-Series?

Panorama con el plugin de Kubernetes.
