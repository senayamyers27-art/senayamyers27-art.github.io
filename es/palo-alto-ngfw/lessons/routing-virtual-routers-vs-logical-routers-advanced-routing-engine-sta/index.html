Enrutamiento: virtual routers vs logical routers (Advanced Routing Engine), rutas estáticas, OSPF, BGP, distancias administrativas predeterminadas, ECMP

Un firewall PAN-OS enruta con una instancia de enrutamiento a la que se asignan las interfaces Layer 3. Durante muchos años esa instancia ha sido el virtual router (VR); un firewall nuevo viene con uno llamado default. Puedes crear más VR para separar dominios de enrutamiento, y las rutas pueden apuntar a otro VR como siguiente salto. Cada VR tiene su propia tabla de enrutamiento (RIB) y su propia tabla de reenvío (FIB).

Las versiones más recientes de PAN-OS agregan el Advanced Routing Engine en las plataformas compatibles. Cuando habilitas Advanced Routing (en la configuración de administración, seguido de un commit y un reinicio), los virtual routers se reemplazan por logical routers. Los protocolos son los mismos en esencia, pero la configuración se reorganiza: el filtrado de rutas, la redistribución y el ajuste de BGP/OSPF usan perfiles de enrutamiento, filtros y route maps reutilizables, más parecido a cómo se configuran los routers tradicionales. Habilitarlo cambia la estructura de la configuración de enrutamiento, así que respalda y planifica el cambio primero. Para el examen, recuerda que 'logical router' significa Advanced Routing Engine y 'virtual router' significa el motor heredado.

Las rutas estáticas tienen un prefijo de destino, una interfaz de salida y/o un siguiente salto, una distancia administrativa y una métrica. El path monitoring opcional hace ping a una dirección y retira la ruta cuando falla, lo que permite que una ruta estática de respaldo tome el control. OSPF (Open Shortest Path First) es un protocolo interior de estado de enlace: defines el router ID, las áreas (el área 0 como backbone, además de áreas stub o NSSA) y qué interfaces participan, y luego verificas que los vecinos lleguen al estado Full. BGP (Border Gateway Protocol) se usa hacia los ISP y entre redes grandes: configuras el AS local, los peer groups y los peers con sus números de AS, y las reglas de importación/exportación o redistribución para controlar qué se anuncia.

Cuando el mismo prefijo se aprende de varias fuentes, el firewall prefiere primero la coincidencia de prefijo más larga, luego la menor distancia administrativa (AD) y después la menor métrica. Los valores AD predeterminados de PAN-OS son: static 10, eBGP 20, OSPF internal 30, RIP 120, OSPF external 110 e iBGP 200. Observa que OSPF internal (30) difiere del 110 de Cisco, una trampa frecuente en el examen. Puedes cambiar la AD por ruta o por protocolo.

Equal-cost multipath (ECMP) permite que el firewall instale varias rutas de igual costo hacia el mismo destino y reparta las sesiones entre ellas. Lo habilitas en el router y eliges un método de balanceo de carga: IP Modulo, IP Hash, Weighted Round Robin o Balanced Round Robin. El balanceo es por sesión, así que los paquetes de una sesión permanecen en un mismo camino. La opción Symmetric Return hace que el tráfico de retorno salga por la interfaz por la que llegó la sesión.

Para solucionar problemas, usa Network > Virtual Routers (o Logical Routers) > More Runtime Stats, o comandos de CLI como show routing route y test routing fib-lookup en el motor heredado. El Advanced Routing Engine tiene su propia familia de comandos show advanced-routing.

Términos clave

Virtual router (router virtual)
La instancia de enrutamiento heredada de PAN-OS que contiene interfaces, rutas estáticas y protocolos dinámicos con su propia tabla de enrutamiento.
Logical router (router lógico)
La instancia de enrutamiento usada cuando el Advanced Routing Engine está habilitado, configurada con perfiles de enrutamiento y route maps reutilizables.
Administrative distance (distancia administrativa)
Un valor de preferencia para las fuentes de rutas; gana el menor cuando los prefijos tienen la misma longitud. Los valores predeterminados de PAN-OS incluyen static 10 y OSPF internal 30.
ECMP
Equal-cost multipath: instalar varias rutas iguales y balancear las sesiones entre ellas.
Ejemplo real

Un firewall de sucursal aprende 10.20.0.0/16 por OSPF y además tiene una ruta estática para 10.20.0.0/16 a través de un circuito de respaldo. Configuras la AD de la ruta estática en 200 para que se prefiera OSPF (internal, AD 30), y la ruta estática flotante solo aparece en la tabla de reenvío si OSPF pierde el prefijo.

Consejo para el examen: Memoriza las AD predeterminadas de PAN-OS, especialmente OSPF internal 30 e iBGP 200, y recuerda que la coincidencia de prefijo más larga le gana a la AD. Logical router siempre implica el Advanced Routing Engine.

Comprueba lo que sabes

¿Qué debes hacer para pasar de virtual routers a logical routers?

Habilitar Advanced Routing en la configuración de administración del dispositivo, hacer commit y reiniciar, en una plataforma y versión que lo admitan.

¿Cuál gana para un destino dentro del /24: un /24 aprendido por iBGP o una ruta estática /16?

El /24, porque la coincidencia de prefijo más larga se evalúa antes que la distancia administrativa.

¿El balanceo de carga ECMP es por paquete o por sesión?

Por sesión; todos los paquetes de una sesión usan el mismo camino.
