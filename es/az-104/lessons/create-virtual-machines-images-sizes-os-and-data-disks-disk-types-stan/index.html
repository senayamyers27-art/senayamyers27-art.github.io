Microsoft Certified: Azure Administrator Associate AZ-104

Crear máquinas virtuales: imágenes, tamaños, discos de SO y de datos, tipos de disco (de Standard HDD a Ultra), encryption at host y Azure Disk Encryption

Azure Virtual Machines te da control total de un sistema operativo en la nube, lo que también significa que eres responsable de aplicarle revisiones, configurarlo y protegerlo. Crear una implica una serie de decisiones en la página Crear una máquina virtual: suscripción y grupo de recursos, nombre, región y opciones de disponibilidad, tipo de seguridad (Estándar o Inicio seguro, Trusted Launch), imagen, tamaño, cuenta de administrador (contraseña o clave SSH), puertos de entrada, discos, redes y opciones de administración. Cada decisión afecta al costo, al rendimiento o a la resiliencia, y varias no se pueden cambiar después sin volver a implementar.
