Puntos de conexión de servicio vs. puntos de conexión privados, y zonas DNS privadas para Private Link

Muchos servicios de plataforma de Azure, como Azure Storage, Azure SQL Database y Azure Key Vault, se alcanzan de forma predeterminada mediante puntos de conexión públicos en internet. Dos funciones permiten que los recursos de una red virtual (VNet) lleguen a ellos de forma más segura: los puntos de conexión de servicio (service endpoints) y los puntos de conexión privados (private endpoints). Sus nombres se parecen, pero funcionan de manera muy diferente, y elegir entre ellos es un escenario frecuente del examen, que suele decidirse según si se requiere acceso desde la red local, un ámbito por recurso o deshabilitar por completo el acceso público.
