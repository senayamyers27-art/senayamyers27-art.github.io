Virtual Machine Scale Sets: modos de orquestación, reglas de escalado automático y reducción horizontal

Un Virtual Machine Scale Set (VMSS, conjunto de escalado de máquinas virtuales) administra un grupo de máquinas virtuales (VM) con equilibrio de carga como un solo recurso. En lugar de crear cada VM a mano, describes el modelo una vez (imagen, tamaño, red, extensiones) e indicas al conjunto de escalado cuántas instancias debe ejecutar. Puede agregar y quitar instancias automáticamente según la demanda, repartirlas entre zonas de disponibilidad y dominios de error, e implementar actualizaciones. Los conjuntos de escalado son la respuesta estándar para niveles sin estado, como front-ends web, servidores de API y trabajadores por lotes, donde cualquier instancia puede atender cualquier solicitud y perder una no implica perder datos.
