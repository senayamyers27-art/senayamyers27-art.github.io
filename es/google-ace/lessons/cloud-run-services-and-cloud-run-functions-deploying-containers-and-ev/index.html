Servicios de Cloud Run y Cloud Run functions: desplegar contenedores y código basado en eventos con Eventarc y Pub/Sub

Cloud Run ejecuta contenedores sin servidores ni clústeres. Un contenedor para un servicio de Cloud Run debe escuchar solicitudes HTTP en el puerto indicado en la variable de entorno PORT (8080 de forma predeterminada) y debe ser sin estado, porque las instancias se pueden iniciar y detener en cualquier momento. Despliegas con gcloud run deploy web --image=us-docker.pkg.dev/my-proj/repo/web:1.0 --region=us-central1, o desde el código fuente con --source ., que construye la imagen con Cloud Build.

Cada despliegue crea una revisión inmutable. Cloud Run escala la cantidad de instancias de contenedor según el tráfico, desde cero hasta un máximo que puedes establecer, y cada instancia puede atender varias solicitudes a la vez (concurrencia). Cada servicio obtiene una URL HTTPS. El acceso se controla con IAM: permitir invocaciones no autenticadas otorga el rol Cloud Run Invoker a allUsers, lo que sirve para un sitio web público; de lo contrario, quienes llaman deben presentar un token de identidad de un principal que tenga roles/run.invoker. La configuración de ingress puede restringir aún más el tráfico a fuentes internas o a un balanceador de carga.

Los jobs de Cloud Run son para trabajo que se ejecuta hasta completarse, como una exportación de datos nocturna, y pueden ejecutar muchas tareas en paralelo. A menudo se activan con Cloud Scheduler.

Cloud Run functions te permite desplegar solo una función escrita en un lenguaje compatible, como Node.js, Python, Go o Java. Despliegas con gcloud functions deploy (o desde las páginas de Cloud Run), y Google la construye y la ejecuta en Cloud Run. Las funciones se activan mediante solicitudes HTTP o mediante eventos.

Los eventos los entrega Eventarc, que enruta eventos de fuentes de Google hacia servicios y funciones de Cloud Run. Las fuentes incluyen Cloud Storage (por ejemplo, un objeto que se finaliza después de subirse), mensajes de Pub/Sub y entradas de Cloud Audit Logs de muchos servicios. Pub/Sub es el servicio de mensajería de Google: los publicadores envían mensajes a un tema (topic), y las suscripciones los entregan a los suscriptores mediante pull o push, desacoplando a los productores de los consumidores. Una suscripción push puede enviar mensajes directamente a una URL de Cloud Run.

La cuenta de servicio del activador necesita permiso para invocar el destino, y un servicio de Cloud Run necesita su propia cuenta de servicio (idealmente, no la predeterminada) con solo los roles que requiere, como acceso a un bucket o a un secreto.

Términos clave

Revision (revisión)
Una instantánea inmutable de la imagen y la configuración de un servicio de Cloud Run que se crea en cada despliegue.
Concurrency (concurrencia)
La cantidad máxima de solicitudes que una instancia de Cloud Run atiende al mismo tiempo.
Eventarc
Un servicio que enruta eventos de fuentes de Google Cloud hacia servicios y funciones de Cloud Run.
Pub/Sub
Un servicio de mensajería administrado en el que los publicadores envían mensajes a temas y los suscriptores los reciben mediante suscripciones.
Ejemplo real

Una app de fotos guarda las subidas en un bucket. Un activador de Eventarc sobre el evento de objeto finalizado invoca una Cloud Run function que crea una miniatura y publica un mensaje en un tema de Pub/Sub, que un servicio de Cloud Run aparte consume para actualizar el índice de búsqueda.

Consejo para el examen: 'Ejecutar código cuando llega un archivo a un bucket' es una función basada en eventos mediante Eventarc. 'Solo ciertos servicios pueden llamarlo' significa exigir autenticación y otorgar Cloud Run Invoker a esas identidades.

Comprueba lo que sabes

¿Qué hace realmente permitir invocaciones no autenticadas?

Otorga el rol Cloud Run Invoker a allUsers, lo que hace que el servicio se pueda llamar públicamente.

¿Cuál es la diferencia entre un servicio de Cloud Run y un job de Cloud Run?

Un servicio responde a solicitudes y escala con el tráfico; un job ejecuta tareas hasta completarlas y luego se detiene.
