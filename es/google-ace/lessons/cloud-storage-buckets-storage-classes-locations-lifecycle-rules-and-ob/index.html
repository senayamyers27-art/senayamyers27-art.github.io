Buckets de Cloud Storage: clases de almacenamiento, ubicaciones, reglas de ciclo de vida y Object Versioning

Cloud Storage almacena objetos (archivos y sus metadatos) en buckets. Los nombres de los buckets son únicos a nivel global. Creas un bucket con gcloud storage buckets create gs://my-bucket --location=us-central1 --default-storage-class=STANDARD, y eliges su ubicación al crearlo; no puedes cambiar la ubicación de un bucket después.

Las ubicaciones son de tres tipos. Una región, como us-central1, mantiene los datos en una región al menor costo, lo cual es bueno para datos que usa el cómputo de esa región. Una ubicación birregional (dual-region), como un par de regiones predefinido o un par configurable, mantiene los datos en dos regiones para mayor disponibilidad. Una ubicación multirregional (multi-region), como US, EU o ASIA, distribuye los datos en un área geográfica amplia para contenido que se sirve a muchos lugares.

Las clases de almacenamiento equilibran el precio del almacenamiento contra el costo de acceso. Standard es para datos de acceso frecuente (calientes) y no tiene duración mínima de almacenamiento. Nearline es para datos a los que se accede aproximadamente una vez al mes o menos, con una duración mínima de 30 días. Coldline es para datos a los que se accede aproximadamente una vez por trimestre o menos, con un mínimo de 90 días. Archive es para datos a los que se accede menos de una vez al año, como archivos de cumplimiento a largo plazo, con un mínimo de 365 días. Las clases más frías cobran tarifas de recuperación y cargos por eliminación anticipada si borras los datos antes del mínimo. A diferencia de los niveles de archivo de otras nubes, todas las clases tienen el mismo acceso rápido (milisegundos) cuando sí lees. Autoclass puede mover objetos entre clases automáticamente según el acceso.

Object Lifecycle Management aplica reglas a los objetos automáticamente. Cada regla tiene una acción, como SetStorageClass o Delete, y condiciones, como la antigüedad en días, la fecha de creación, la clase de almacenamiento o la cantidad de versiones más nuevas. Una política típica mueve los objetos a Coldline después de 90 días y los elimina después de 3 años.

Object Versioning conserva una versión no actual cada vez que un objeto activo se sobrescribe o se elimina, para que puedas restaurarlo. Las versiones no actuales se cobran como almacenamiento, así que combina el versionado con una regla de ciclo de vida que elimine las versiones antiguas después de un tiempo. La eliminación suave (soft delete) además retiene los objetos eliminados durante un período de retención. Una política de retención (retention policy), que se puede bloquear con Bucket Lock, hace lo contrario de una eliminación por ciclo de vida: impide que los objetos se eliminen o sobrescriban hasta que alcancen cierta antigüedad, por motivos de cumplimiento.

Términos clave

Storage class (clase de almacenamiento)
La configuración Standard, Nearline, Coldline o Archive que define el precio de almacenamiento, el costo de acceso y la duración mínima.
Lifecycle rule (regla de ciclo de vida)
Una acción automática, como cambiar de clase o eliminar, que se aplica cuando un objeto cumple ciertas condiciones.
Object Versioning
Una configuración del bucket que conserva versiones no actuales de los objetos sobrescritos o eliminados.
Retention policy (política de retención)
Un tiempo mínimo durante el cual los objetos deben conservarse antes de poder eliminarse o reemplazarse, que se puede bloquear con Bucket Lock.
Ejemplo real

Un hospital guarda expedientes escaneados en un bucket regional con clase Standard. Una regla de ciclo de vida mueve los objetos a Coldline después de 90 días y a Archive después de un año, y una política de retención bloqueada garantiza que nada se pueda eliminar durante 7 años, lo que satisface al regulador.

Consejo para el examen: Relaciona la frecuencia de acceso con la clase: mensual es Nearline, trimestral es Coldline, anual o menos es Archive. Recuerda los mínimos de 30, 90 y 365 días, y que la ubicación de un bucket no se puede cambiar después.

Comprueba lo que sabes

¿Qué clase conviene para copias de seguridad que se leen aproximadamente una vez por trimestre?

Coldline, que tiene una duración mínima de almacenamiento de 90 días.

¿Qué pasa cuando sobrescribes un objeto en un bucket con el versionado activado?

El contenido anterior se convierte en una versión no actual que puedes restaurar.
