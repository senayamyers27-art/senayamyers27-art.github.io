Cloud Shell, la consola de Google Cloud y Cloud Shell Editor

La consola de Google Cloud es la interfaz web que está en el centro del trabajo diario. Usas el selector de proyectos de la parte superior para elegir un proyecto, el menú de navegación para llegar a cada producto y la barra de búsqueda para saltar a un servicio o recurso. Muchas páginas de la consola tienen un enlace Equivalent code o command line que muestra el comando de gcloud o la solicitud REST de lo que configuraste, lo cual es una excelente forma de aprender la CLI.

Cloud Shell es una terminal gratuita basada en el navegador que se ejecuta en una VM temporal de Compute Engine administrada por Google. Ya está autenticada como el usuario que la abrió y viene con Google Cloud CLI, kubectl, Terraform, Docker, git, entornos de ejecución de lenguajes y editores preinstalados. La abres con el ícono de terminal en la consola. Como se ejecuta en el navegador, es ideal cuando no puedes instalar software localmente o necesitas ejecutar un comando rápido desde cualquier máquina.

Cada usuario obtiene un directorio home persistente (de unos pocos gigabytes) que sobrevive entre sesiones, así que los scripts y archivos de configuración que guardes en $HOME permanecen. Todo lo que se instale fuera del directorio home se pierde cuando la VM se recicla. Las sesiones terminan después de un período de inactividad y, si no usas Cloud Shell por mucho tiempo, tu directorio home puede eliminarse, así que no lo trates como almacenamiento a largo plazo.

Cloud Shell Editor es un editor de código basado en el proyecto de código abierto Code OSS, que se abre con el botón Open Editor. Te permite editar archivos en tu directorio home de Cloud Shell, trabajar con git y usar las extensiones de Cloud Code para desplegar en Cloud Run o GKE. Para un desarrollo más pesado o de larga duración, Google también ofrece Cloud Workstations, que son entornos de desarrollo administrados por los que pagas.

Otras herramientas cotidianas de la consola incluyen la vista Activity con las acciones recientes, el panel Notifications, el Marketplace y la vista previa web (web preview) de Cloud Shell, que te permite abrir en una pestaña del navegador un servidor web que se ejecuta en Cloud Shell en un puerto como el 8080.

Términos clave

Cloud Shell
Una terminal gratuita en el navegador, ya autenticada, sobre una VM temporal con las herramientas de Google Cloud preinstaladas.
Cloud Shell Editor
Un editor de código en el navegador basado en Code OSS que trabaja sobre el directorio home de Cloud Shell.
Persistent home directory (directorio home persistente)
El almacenamiento de Cloud Shell que sobrevive entre sesiones, a diferencia del resto de la VM.
Web preview (vista previa web)
Una función de Cloud Shell que abre un servidor web que se ejecuta en la sesión en un puerto elegido.
Ejemplo real

Desde una PC del centro de negocios de un hotel, una ingeniera de guardia inicia sesión en la consola, abre Cloud Shell y ejecuta kubectl get pods y gcloud logging read para diagnosticar un incidente, sin instalar nada. Sus scripts de ayuda siguen en su directorio home de Cloud Shell desde la semana pasada.

Consejo para el examen: 'No se puede instalar software localmente' o 'la forma más rápida de ejecutar gcloud y kubectl' apunta a Cloud Shell. Recuerda que solo persiste el directorio home.

Comprueba lo que sabes

¿Qué parte de un entorno de Cloud Shell persiste entre sesiones?

El directorio home. El software instalado en otras partes de la VM se pierde cuando la VM de la sesión se recicla.

¿Cómo puedes aprender el comando de gcloud de algo que configuraste en la consola?

Usa el enlace Equivalent code o command line que aparece en muchas páginas de creación de la consola.
