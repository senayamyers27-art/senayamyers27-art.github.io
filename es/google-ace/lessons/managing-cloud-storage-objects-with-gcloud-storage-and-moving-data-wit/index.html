Administrar objetos de Cloud Storage con gcloud storage y mover datos con Storage Transfer Service

El grupo de comandos gcloud storage es la CLI actual para Cloud Storage y reemplaza la mayoría de los usos del antiguo gsutil. Los buckets y objetos se identifican con URLs gs://. Comandos comunes: gcloud storage ls gs://my-bucket lista los objetos; gcloud storage cp report.csv gs://my-bucket/reports/ sube un archivo; gcloud storage cp -r ./site gs://my-bucket copia una carpeta; gcloud storage mv mueve o cambia el nombre; gcloud storage rm gs://my-bucket/old/** elimina; y gcloud storage rsync sincroniza un directorio con un prefijo del bucket. Las transferencias grandes se paralelizan automáticamente.

Puedes cambiar la clase de almacenamiento de un objeto reescribiéndolo, por ejemplo gcloud storage objects update gs://my-bucket/file --storage-class=COLDLINE, pero para muchos objetos es mejor una regla de ciclo de vida. La configuración del bucket se administra con gcloud storage buckets update, por ejemplo para cambiar la clase de almacenamiento predeterminada, agregar etiquetas o habilitar el versionado con --versioning. Cambiar la clase predeterminada de un bucket solo afecta a los objetos nuevos.

Recuerda que Cloud Storage no tiene carpetas reales; nombres como reports/2026/jan.csv simplemente contienen barras, y la consola los muestra como carpetas. Los objetos son inmutables: una actualización escribe un objeto nuevo (o una versión nueva si el versionado está activado).

Para transferencias grandes o recurrentes, usa Storage Transfer Service. Es un servicio administrado que copia datos a Cloud Storage desde otras nubes (Amazon S3, Azure Blob Storage), desde listas de URLs HTTP/HTTPS, desde otros buckets de Cloud Storage y desde sistemas de archivos locales usando agentes que instalas. Los trabajos pueden ejecutarse una vez o según un calendario, copiar solo los archivos modificados, eliminar los archivos de origen después de la transferencia, e informar el progreso y los errores. Eso lo convierte en la opción correcta para mover terabytes desde otra nube o mantener dos buckets sincronizados cada noche.

Para conjuntos de datos muy grandes con ancho de banda de red limitado, Transfer Appliance es un dispositivo de almacenamiento físico que Google te envía; cargas los datos en él y lo devuelves. Como guía aproximada, si subir los datos por tu red tomaría semanas, considera el appliance. BigQuery Data Transfer Service es algo distinto: carga datos en BigQuery desde fuentes como apps SaaS y consultas programadas.

Términos clave

gcloud storage
El grupo de comandos actual de gcloud para administrar buckets y objetos.
gcloud storage rsync
Un comando que hace que un prefijo de bucket coincida con un directorio local u otra ubicación.
Storage Transfer Service
Un servicio administrado para copiar datos a Cloud Storage desde otras nubes, URLs, buckets o entornos locales.
Transfer Appliance
Un dispositivo físico que envía Google para la transferencia sin conexión de conjuntos de datos muy grandes.
Ejemplo real

Una empresa de medios configura un trabajo de Storage Transfer Service que copia los archivos nuevos de un bucket de Amazon S3 a Cloud Storage todas las noches a la 01:00 y no elimina nada en el origen. Sus editores usan gcloud storage rsync para subir los proyectos terminados desde una estación de trabajo a un bucket.

Consejo para el examen: De otra nube a Cloud Storage, programado y administrado: Storage Transfer Service. Cientos de terabytes a través de un enlace lento: Transfer Appliance. Hacia BigQuery desde SaaS: BigQuery Data Transfer Service.

Comprueba lo que sabes

¿Qué comando lista los objetos de gs://logs-bucket?

gcloud storage ls gs://logs-bucket.

¿Cambiar la clase de almacenamiento predeterminada de un bucket cambia los objetos existentes?

No. Se aplica a los objetos nuevos; los objetos existentes conservan su clase a menos que se reescriban o que una regla de ciclo de vida los cambie.
