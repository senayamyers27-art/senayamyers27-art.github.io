Administrar objetos de Cloud Storage con gcloud storage y mover datos con Storage Transfer Service

El grupo de comandos gcloud storage es la CLI actual para Cloud Storage y reemplaza la mayoría de los usos del antiguo gsutil. Los buckets y objetos se identifican con URLs gs://. Comandos comunes: gcloud storage ls gs://my-bucket lista los objetos; gcloud storage cp report.csv gs://my-bucket/reports/ sube un archivo; gcloud storage cp -r ./site gs://my-bucket copia una carpeta; gcloud storage mv mueve o cambia el nombre; gcloud storage rm gs://my-bucket/old/** elimina; y gcloud storage rsync sincroniza un directorio con un prefijo del bucket. Las transferencias grandes se paralelizan automáticamente.
