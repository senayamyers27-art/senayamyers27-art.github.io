AWS Certified Cloud Practitioner CLF-C02

Cifrado en reposo y en tránsito: AWS KMS, AWS CloudHSM y AWS Certificate Manager

El cifrado protege los datos para que solo las personas con la clave correcta puedan leerlos. Lo necesitas en dos lugares. El cifrado en reposo (encryption at rest) protege los datos almacenados, como archivos en Amazon S3, discos en Amazon EBS o filas en una base de datos. El cifrado en tránsito (encryption in transit) protege los datos que se mueven por una red, normalmente con Transport Layer Security (TLS), que es lo que usa HTTPS.

AWS Key Management Service (AWS KMS) es el servicio administrado para crear y controlar claves de cifrado. La mayoría de los servicios de AWS que almacenan datos se integran con KMS, así que cifrar un volumen EBS o un bucket de S3 suele ser una sola opción de configuración. Las claves de KMS nunca salen del servicio sin cifrar; están protegidas por módulos de seguridad de hardware que administra AWS. Tú controlas quién puede usar cada clave mediante políticas de clave (key policies) e IAM, y cada uso de una clave queda registrado en AWS CloudTrail. Existen las claves administradas por AWS (AWS managed keys), que un servicio crea por ti, y las claves administradas por el cliente (customer managed keys), que tú creas y controlas, incluida su rotación y eliminación.

AWS CloudHSM proporciona módulos de seguridad de hardware (HSM) dedicados en la nube de AWS. Un HSM es un dispositivo resistente a manipulaciones que almacena claves y realiza operaciones criptográficas. Con CloudHSM, los HSM son de un solo inquilino (single-tenant) y tú administras las claves y los usuarios; AWS no puede acceder a tus claves. Las organizaciones eligen CloudHSM cuando una regulación o un contrato exige hardware dedicado bajo su control exclusivo, o cuando una aplicación necesita interfaces estándar como PKCS#11. KMS es más sencillo y está más integrado; CloudHSM da más control pero requiere más trabajo.

AWS Certificate Manager (ACM) aprovisiona, administra y despliega certificados TLS para el cifrado en tránsito. Solicitas un certificado público para un dominio, demuestras que controlas el dominio y adjuntas el certificado a servicios integrados como Elastic Load Balancing, Amazon CloudFront o Amazon API Gateway. ACM renueva sus certificados automáticamente, eliminando la clásica interrupción causada por una fecha de vencimiento olvidada.

Muchos servicios de AWS ahora también cifran por defecto; por ejemplo, los objetos nuevos en Amazon S3 se cifran en reposo automáticamente. Decidir qué más cifrar y administrar el acceso a las claves sigue siendo responsabilidad del cliente.

Términos clave

Encryption at rest (cifrado en reposo)
Cifrar los datos almacenados, por ejemplo en discos, en bases de datos o en almacenamiento de objetos.
Encryption in transit (cifrado en tránsito)
Cifrar los datos mientras se mueven por una red, normalmente con TLS.
AWS KMS
AWS Key Management Service, un servicio administrado para crear y controlar claves de cifrado, integrado con la mayoría de los servicios de AWS.
AWS CloudHSM
Un servicio que proporciona módulos de seguridad de hardware dedicados, de un solo inquilino, cuyas claves controla exclusivamente el cliente.
AWS Certificate Manager (ACM)
Un servicio que aprovisiona, despliega y renueva automáticamente certificados TLS para los servicios de AWS.
Ejemplo real

Una clínica en línea habilita el cifrado en sus volúmenes EBS y en su base de datos RDS usando una clave de KMS administrada por el cliente, restringe el uso de esa clave al rol de IAM de la aplicación y adjunta un certificado de ACM a su Application Load Balancer para que los pacientes se conecten por HTTPS. ACM renueva el certificado antes de que venza.

Consejo para el examen: Las palabras clave deciden: 'claves administradas integradas con los servicios de AWS' es KMS; 'HSM dedicado, de un solo inquilino' o 'el cliente tiene control exclusivo del hardware' es CloudHSM; 'certificados SSL/TLS' es ACM.

Comprueba lo que sabes

Una regulación exige que las claves se almacenen en hardware de un solo inquilino que solo controle el cliente. ¿Qué servicio encaja?

AWS CloudHSM.

¿Qué servicio usarías para obtener y renovar automáticamente un certificado HTTPS para un balanceador de carga?

AWS Certificate Manager (ACM).
