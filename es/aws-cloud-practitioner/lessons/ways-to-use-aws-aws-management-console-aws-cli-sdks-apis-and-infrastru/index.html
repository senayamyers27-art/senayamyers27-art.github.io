AWS Certified Cloud Practitioner CLF-C02

Formas de usar AWS: AWS Management Console, AWS CLI, SDK, API e infraestructura como código con AWS CloudFormation

Todo lo que haces en AWS, ya sea crear un bucket, lanzar un servidor o leer una factura, es en última instancia una llamada a una interfaz de programación de aplicaciones (API) de un servicio de AWS. Cada solicitud se autentica con tus credenciales, se verifica contra tus permisos y normalmente queda registrada en AWS CloudTrail. Las distintas formas de usar AWS son simplemente distintas interfaces para esas mismas API. El examen te pide relacionar cada interfaz con el tipo de trabajo para el que sirve: explorar, automatizar con scripts, escribir aplicaciones o construir infraestructura repetible.
