AWS Certified Cloud Practitioner CLF-C02

Formas de usar AWS: AWS Management Console, AWS CLI, SDK, API e infraestructura como código con AWS CloudFormation

Todo lo que haces en AWS, ya sea crear un bucket o lanzar un servidor, es en última instancia una llamada de API a un servicio de AWS. Las distintas formas de usar AWS son simplemente distintas interfaces para esas API, y cada una se adapta a un tipo de trabajo diferente.

La AWS Management Console es la interfaz web. Inicias sesión desde un navegador y avanzas por asistentes y paneles. Es ideal para aprender, explorar servicios, tareas puntuales y monitoreo visual. También existe la AWS Console Mobile Application para revisar recursos y alarmas desde cualquier lugar. La consola es fácil pero no repetible: si necesitas construir el mismo entorno diez veces, hacerlo a clics diez veces es lento y propenso a errores.

La AWS Command Line Interface (AWS CLI) te permite controlar los servicios escribiendo comandos en una terminal, lo que hace que las tareas se puedan automatizar con scripts y repetir. Por ejemplo, aws s3 ls lista tus buckets y aws ec2 describe-instances lista tus instancias. AWS CloudShell te ofrece un shell en el navegador, ya autenticado y con la CLI instalada, directamente desde la consola. Los kits de desarrollo de software (SDK) permiten que el código de una aplicación llame a los servicios de AWS en lenguajes como Python (Boto3), JavaScript, Java, Go y .NET, encargándose por ti de la firma de solicitudes y de los reintentos. También puedes llamar directamente a las API de los servicios por HTTPS, pero los SDK y la CLI son mucho más cómodos.

aws s3 mb s3://example-lesson-bucket-12345
aws s3 cp report.csv s3://example-lesson-bucket-12345/
aws s3 ls s3://example-lesson-bucket-12345/

La infraestructura como código (IaC) con AWS CloudFormation lleva la repetibilidad más lejos. Describes los recursos que quieres, como una VPC, subredes, instancias y una base de datos, en una plantilla JSON o YAML. CloudFormation los crea como una sola unidad llamada pila (stack), en el orden correcto, y puede actualizar o eliminar toda la pila de forma coherente. Las plantillas se pueden versionar y revisar como el código de una aplicación, y la misma plantilla puede crear entornos idénticos de desarrollo, prueba y producción o desplegar en varias Regiones. El AWS Cloud Development Kit (CDK) te permite definir la misma infraestructura en un lenguaje de programación y genera CloudFormation por ti.

Para el examen: explorar y hacer tareas puntuales sugiere la consola; automatizar con scripts sugiere la CLI; código de aplicación que llama a AWS sugiere los SDK; entornos repetibles y coherentes sugieren CloudFormation.

Términos clave

AWS Management Console
La interfaz gráfica en el navegador para administrar los servicios de AWS.
AWS CLI
Una herramienta de línea de comandos para administrar los servicios de AWS desde una terminal y automatizar tareas con scripts.
SDK (kit de desarrollo de software)
Un kit de desarrollo de software que permite que el código de una aplicación llame a los servicios de AWS en un lenguaje de programación específico.
AWS CloudFormation
Un servicio de infraestructura como código que aprovisiona recursos de AWS a partir de plantillas JSON o YAML como pilas (stacks).
Stack (pila)
Un conjunto de recursos de AWS que se crean, actualizan y eliminan juntos a partir de una plantilla de CloudFormation.
Ejemplo real

Una empresa de capacitación necesita entornos de laboratorio idénticos para 20 clases al año. En lugar de construir cada uno a mano en la consola, escribe una plantilla de CloudFormation que define una VPC, un servidor web y una base de datos. Cada clase recibe una pila creada a partir de la plantilla en minutos, y la pila se elimina después, borrando todos los recursos para que nada siga generando cargos.

Consejo para el examen: Si una pregunta menciona desplegar la misma infraestructura de forma repetida y coherente, en varias cuentas o Regiones, o tratar la infraestructura como código, la respuesta es AWS CloudFormation, no la consola ni la CLI.

Comprueba lo que sabes

¿Qué herramienta permite que una aplicación en Python suba archivos a Amazon S3?

El AWS SDK para Python (Boto3).

¿Cómo llama CloudFormation al grupo de recursos que crea a partir de una plantilla?

Una pila (stack).
