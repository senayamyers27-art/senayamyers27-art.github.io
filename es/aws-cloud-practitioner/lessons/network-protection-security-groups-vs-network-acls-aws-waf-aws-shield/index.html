AWS Certified Cloud Practitioner CLF-C02

Protección de red: security groups frente a network ACLs, AWS WAF, AWS Shield Standard y Advanced, AWS Firewall Manager

AWS te ofrece varias capas de protección de red, cada una trabajando en un nivel distinto. El examen evalúa tanto las diferencias entre ellas como cuál usar ante una amenaza determinada.

Los security groups (grupos de seguridad) son firewalls (cortafuegos) virtuales para recursos como las instancias EC2 (más precisamente, sus interfaces de red). Solo admiten reglas de permiso; todo lo que no está permitido se deniega. Tienen estado (stateful): si se permite una solicitud entrante, la respuesta se permite automáticamente de salida, y viceversa. Las listas de control de acceso de red (network ACLs) protegen subredes completas en una Amazon VPC. Admiten reglas de permiso y de denegación, se evalúan en orden numérico y gana la primera coincidencia, y no tienen estado (stateless): el tráfico de retorno debe permitirse explícitamente con una regla separada. Un diseño típico usa security groups para la mayor parte del control y network ACLs como respaldo general a nivel de subred, por ejemplo para bloquear un rango de direcciones específico.

AWS WAF es un firewall de aplicaciones web. Inspecciona las solicitudes HTTP y HTTPS en la capa 7 para recursos como Amazon CloudFront, Application Load Balancers y Amazon API Gateway. Escribes reglas (o usas grupos de reglas administradas) para bloquear ataques comunes como la inyección SQL y el cross-site scripting, filtrar por dirección IP o por país y limitar la tasa de los clientes que envían demasiadas solicitudes.

AWS Shield protege contra ataques de denegación de servicio distribuida (DDoS). Shield Standard se habilita automáticamente para todos los clientes de AWS sin costo adicional y defiende contra los ataques más comunes en las capas de red y de transporte. Shield Advanced es una suscripción de pago que agrega detección y mitigación mejoradas para recursos como EC2, Elastic Load Balancing, CloudFront, Route 53 y Global Accelerator, acceso al AWS Shield Response Team durante los ataques, informes detallados de ataques y protección de costos frente a los cargos de escalado causados por un ataque DDoS.

AWS Firewall Manager configura y administra de forma centralizada las reglas de firewall en todas las cuentas de AWS Organizations. Defines las políticas una sola vez, como un conjunto de reglas de WAF, la protección de Shield Advanced o los security groups obligatorios, y Firewall Manager las aplica automáticamente a las cuentas y recursos existentes y nuevos.

Términos clave

Security group (grupo de seguridad)
Un firewall virtual con estado y solo de permisos que se aplica a las interfaces de red de instancias y otros recursos.
Network ACL (lista de control de acceso de red)
Un firewall sin estado a nivel de subred con reglas numeradas de permiso y denegación que se evalúan en orden.
AWS WAF
Un firewall de aplicaciones web que filtra solicitudes HTTP/HTTPS para proteger contra ataques como la inyección SQL.
AWS Shield
Protección contra DDoS: Standard es gratuito y automático; Advanced es de pago y agrega acceso al equipo de respuesta y protección de costos.
AWS Firewall Manager
Un servicio para administrar de forma centralizada las políticas de WAF, Shield Advanced y security groups en toda una organización.
Ejemplo real

Un minorista en línea permite solo HTTPS desde su balanceador de carga hacia sus instancias web usando security groups, agrega una regla de network ACL que deniega un rango de direcciones detectado extrayendo datos de su sitio (scraping), adjunta AWS WAF con un conjunto de reglas contra inyección SQL a su Application Load Balancer y se suscribe a Shield Advanced antes de su temporada de compras más intensa.

Consejo para el examen: Con estado y solo de permisos significa security group; sin estado con permisos y denegaciones significa network ACL. Si necesitas bloquear explícitamente una dirección IP a nivel de red, un security group no puede hacerlo porque no tiene reglas de denegación.

Comprueba lo que sabes

Necesitas impedir que una sola dirección IP maliciosa llegue a todas las instancias de una subred. ¿Qué control puede hacerlo?

Una network ACL, porque admite reglas de denegación; los security groups solo permiten.

¿Qué protección contra DDoS se incluye automáticamente sin costo adicional?

AWS Shield Standard.
