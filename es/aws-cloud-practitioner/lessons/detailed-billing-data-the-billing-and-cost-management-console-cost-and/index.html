AWS Certified Cloud Practitioner CLF-C02

Datos de facturación detallados: la consola Billing and Cost Management, los Cost and Usage Reports y las exportaciones de datos, y las etiquetas de asignación de costos

Los gráficos resumidos bastan para muchas preguntas, pero las organizaciones grandes necesitan datos de facturación detallados, línea por línea, para asignar costos a los equipos, alimentar sus propias herramientas de informes y conciliar facturas. El examen cubre dónde están esos datos y cómo las etiquetas les dan sentido.

La consola AWS Billing and Cost Management es el lugar central para todas las tareas de facturación. Allí ves tus facturas actuales y pasadas, los cargos del mes hasta la fecha por servicio, administras los métodos de pago y la configuración de impuestos, abres Cost Explorer y Budgets, ves el uso del Free Tier y configuras preferencias de facturación como las alertas. En AWS Organizations, la cuenta de administración ve la factura consolidada de todas las cuentas miembro.

Para los datos más detallados, los AWS Cost and Usage Reports (CUR) entregan datos de facturación completos, hasta el nivel de recursos individuales, uso por hora o por día, precios y descuentos, como archivos en un bucket de Amazon S3 que eliges. AWS ha evolucionado esto hacia Data Exports, que te permite crear exportaciones de datos de costo y uso, incluido el formato más nuevo CUR 2.0, hacia S3. Desde allí puedes consultar los datos con Amazon Athena, cargarlos en Amazon Redshift o visualizarlos con Amazon QuickSight o herramientas de terceros. Si una pregunta pide los datos de facturación más granulares para un análisis personalizado, la respuesta es el Cost and Usage Report o las exportaciones de datos.

Las etiquetas de asignación de costos (cost allocation tags) dan sentido a esos datos. Una etiqueta es un par clave-valor, como Project=Checkout o CostCenter=1234, que adjuntas a los recursos. Existen etiquetas definidas por el usuario, que creas tú, y etiquetas generadas por AWS, como aws:createdBy. Una etiqueta se convierte en etiqueta de asignación de costos solo después de activarla en la consola Billing and Cost Management; tras la activación, aparece como columna en los informes de costos y como filtro y dimensión de agrupación en Cost Explorer y Budgets. Las etiquetas no se aplican de forma retroactiva a los datos pasados.

Una estrategia de etiquetado coherente, idealmente impuesta con políticas de etiquetas (tag policies) en AWS Organizations, permite a finanzas ver exactamente cuánto cuesta cada equipo, proyecto o entorno. Esa práctica, a menudo llamada showback o chargeback, apoya el principio 'analizar y atribuir el gasto' del pilar de optimización de costos.

Términos clave

Billing and Cost Management console (consola de facturación y gestión de costos)
El área de la consola para facturas, pagos, herramientas de costos y preferencias de facturación.
Cost and Usage Report (CUR)
El conjunto de datos de facturación más detallado de AWS, entregado como archivos en un bucket de S3.
Data Exports (exportaciones de datos)
Una función de facturación que crea exportaciones de datos de costo y uso, incluido CUR 2.0, hacia Amazon S3.
Cost allocation tag (etiqueta de asignación de costos)
Una etiqueta de recurso activada en facturación para que los costos se puedan agrupar y filtrar por ella en los informes.
Ejemplo real

Una empresa de software etiqueta cada recurso con Team y Environment, activa ambas como etiquetas de asignación de costos y configura una exportación de datos a S3. Cada mes, una consulta de Athena sobre la exportación produce el costo por equipo y por entorno, que finanzas usa para cobrar a cada grupo de producto su uso de la nube.

Consejo para el examen: Las etiquetas no aparecen en los informes de facturación hasta que se activan como etiquetas de asignación de costos en la consola de facturación. Si una pregunta pide por qué faltan los costos etiquetados en Cost Explorer, la activación es la respuesta probable.

Comprueba lo que sabes

¿Qué fuente de datos de facturación proporciona la información de costo y uso más detallada, partida por partida?

El AWS Cost and Usage Report (ahora disponible mediante Data Exports), entregado en un bucket de S3.

¿Qué debes hacer antes de poder usar una etiqueta definida por el usuario para agrupar costos en Cost Explorer?

Activarla como etiqueta de asignación de costos en la consola Billing and Cost Management.
