AWS Certified Cloud Practitioner CLF-C02

Infraestructura global de AWS: Regiones, Availability Zones, ubicaciones de borde, Local Zones, Wavelength Zones y AWS Outposts

AWS ejecuta sus servicios en una red mundial de instalaciones. Conocer los componentes básicos, y para qué sirve cada uno, te ayuda a diseñar para la disponibilidad, la baja latencia y el cumplimiento.

Una Región (Region) es un área geográfica separada, como un área metropolitana de un país determinado, que contiene varias Availability Zones aisladas. Las Regiones son independientes entre sí, y tus datos no salen de una Región a menos que los muevas o repliques. La mayoría de los servicios son regionales: eliges la Región al crear un recurso. Algunos, como IAM, son globales.

Una Availability Zone (AZ, zona de disponibilidad) es uno o más centros de datos independientes con energía, redes y conectividad redundantes dentro de una Región. Las AZ de una Región están separadas físicamente por una distancia considerable, de modo que es poco probable que una inundación o un corte de energía afecte a más de una, pero están conectadas por enlaces de gran ancho de banda y baja latencia. Desplegar en varias AZ es la forma estándar de lograr alta disponibilidad. AWS construye la mayoría de las Regiones con tres o más AZ.

Las ubicaciones de borde (edge locations) son sitios en muchas más ciudades que las que tienen Regiones. Las usan Amazon CloudFront para almacenar contenido en caché cerca de los usuarios, y Amazon Route 53 y otros servicios de borde, para reducir la latencia de los usuarios finales. No lanzas instancias EC2 en ubicaciones de borde.

Algunas cargas de trabajo necesitan una latencia aún menor de la que puede ofrecer una Región. Las AWS Local Zones colocan servicios de cómputo, almacenamiento y bases de datos más cerca de grandes centros de población e industria, como una extensión de una Región principal, para aplicaciones como juegos en tiempo real, producción de medios o video en vivo. Las AWS Wavelength Zones integran cómputo y almacenamiento de AWS dentro de las redes 5G de los proveedores de telecomunicaciones, para que los dispositivos móviles lleguen a las aplicaciones con una latencia muy baja sin que el tráfico salga de la red del operador. AWS Outposts lleva hardware diseñado por AWS a tu propio centro de datos, ejecutando servicios de AWS en tus instalaciones y administrándolos con las mismas API y la misma consola, para cargas de trabajo que necesitan procesamiento local de datos o una latencia muy baja hacia sistemas locales.

Recuerda la progresión: Región para la geografía y el cumplimiento, AZ para la alta disponibilidad, ubicaciones de borde para la entrega de contenido, Local Zones para una latencia de milisegundos de un solo dígito hacia una ciudad, Wavelength para móviles 5G y Outposts para AWS en tu propio edificio.

Términos clave

Region (Región)
Un área geográfica que contiene varias Availability Zones aisladas, independiente de las demás Regiones.
Availability Zone (zona de disponibilidad)
Uno o más centros de datos independientes con energía y redes redundantes dentro de una Región.
Edge location (ubicación de borde)
Un sitio que usan CloudFront y otros servicios de borde para almacenar contenido en caché y atender a los usuarios con baja latencia.
AWS Local Zones
Extensiones de una Región que colocan determinados servicios de AWS cerca de grandes centros de población e industria.
AWS Wavelength
Infraestructura de AWS integrada en las redes 5G de telecomunicaciones para aplicaciones móviles de latencia ultrabaja.
AWS Outposts
Racks o servidores administrados por AWS instalados en las instalaciones del cliente para ejecutar servicios de AWS localmente.
Ejemplo real

Un estudio de videojuegos aloja su backend principal en una Región distribuido en tres AZ para lograr disponibilidad, sirve las descargas del juego mediante ubicaciones de borde de CloudFront, ejecuta los servidores de partidas sensibles a la latencia en una Local Zone cerca de una gran ciudad y prueba una función de realidad aumentada móvil en una Wavelength Zone con un operador 5G.

Consejo para el examen: Las preguntas de alta disponibilidad buscan varias Availability Zones; la recuperación ante desastres frente a un evento que afecta a toda una Región busca varias Regiones. 'Servicios de AWS ejecutándose en el propio centro de datos del cliente' siempre es Outposts.

Comprueba lo que sabes

¿Cuál es la relación entre las Regiones y las Availability Zones?

Cada Región contiene varias Availability Zones aisladas, conectadas por enlaces de baja latencia.

Una empresa debe ejecutar servicios de AWS en sus instalaciones para procesar datos localmente. ¿Qué oferta encaja?

AWS Outposts.
