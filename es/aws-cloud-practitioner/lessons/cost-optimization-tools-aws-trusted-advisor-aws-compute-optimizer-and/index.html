AWS Certified Cloud Practitioner CLF-C02

Herramientas de optimización de costos: AWS Trusted Advisor, AWS Compute Optimizer y recomendaciones de ajuste de tamaño

Saber cuánto gastas es solo el comienzo; el siguiente paso es gastar menos sin afectar el rendimiento. AWS proporciona herramientas que analizan tu cuenta y sugieren ahorros concretos.

AWS Trusted Advisor inspecciona tu entorno de AWS y hace recomendaciones en varias categorías: optimización de costos, rendimiento, seguridad, tolerancia a fallos, límites de servicio (cuotas) y excelencia operativa. Las verificaciones de optimización de costos buscan cosas como instancias EC2 de baja utilización, balanceadores de carga inactivos, volúmenes EBS infrautilizados, direcciones Elastic IP no asociadas, instancias RDS inactivas y oportunidades para comprar Reserved Instances o Savings Plans. Cada verificación se muestra en verde (sin problema), amarillo (se recomienda investigar) o rojo (se recomienda actuar). Todos los clientes obtienen un conjunto básico de verificaciones, principalmente de seguridad y de cuotas de servicio; el conjunto completo, incluida la optimización de costos, requiere un plan Business Support o superior.

AWS Compute Optimizer usa aprendizaje automático para analizar las métricas históricas de utilización de tus recursos y recomendar configuraciones óptimas. Abarca instancias EC2, grupos de EC2 Auto Scaling, volúmenes EBS, funciones Lambda, servicios de Amazon ECS en Fargate y algunas licencias de software comercial. Para cada recurso informa si está sobreaprovisionado, subaprovisionado u optimizado, y sugiere mejores tipos o tamaños de instancia junto con el ahorro estimado y el riesgo para el rendimiento. Hay que habilitarlo (opt-in) y necesita cierto historial de métricas para hacer recomendaciones.

Las recomendaciones de ajuste de tamaño (rightsizing) también están disponibles en AWS Cost Explorer, que identifica instancias EC2 inactivas o infrautilizadas y sugiere reducirlas o terminarlas, mostrando el ahorro mensual estimado. El AWS Cost Optimization Hub reúne en un solo lugar las recomendaciones de varias de estas fuentes.

Las herramientas solo sugieren; las personas actúan. Una buena rutina es revisar las recomendaciones cada mes, ajustar el tamaño primero (para no comprometerte con capacidad que no necesitas), después cubrir el uso estable restante con Savings Plans o Reserved Instances, y programar los recursos que no son de producción para que se detengan fuera del horario laboral.

Términos clave

AWS Trusted Advisor
Un servicio que verifica una cuenta frente a buenas prácticas, incluida la optimización de costos, y recomienda acciones.
AWS Compute Optimizer
Un servicio que aplica aprendizaje automático al historial de utilización para recomendar configuraciones óptimas de recursos.
Over-provisioned (sobreaprovisionado)
Un recurso más grande de lo que necesita su carga de trabajo, lo que desperdicia dinero.
Rightsizing recommendation (recomendación de ajuste de tamaño)
Una sugerencia para reducir, cambiar o terminar un recurso según su utilización real.
Ejemplo real

Trusted Advisor señala diez instancias EC2 con baja utilización y tres direcciones Elastic IP no conectadas. Compute Optimizer confirma que siete de las instancias están sobreaprovisionadas y recomienda tamaños menores. El equipo ajusta su tamaño, libera las direcciones y luego compra un Savings Plan dimensionado para el nuevo uso estable, más pequeño.

Consejo para el examen: Trusted Advisor abarca muchas categorías en toda la cuenta; Compute Optimizer se enfoca específicamente en ajustar el tamaño del cómputo y de los recursos relacionados usando ML. Recuerda que el conjunto completo de verificaciones de Trusted Advisor requiere Business Support o superior.
