AWS Certified Cloud Practitioner CLF-C02

Cumplimiento y gobernanza: AWS Artifact, AWS Audit Manager, AWS Config y dónde encontrar información de cumplimiento

Las organizaciones reguladas deben demostrar que sus sistemas cumplen estándares como PCI DSS para pagos con tarjeta, HIPAA para datos de salud en EE. UU. o ISO 27001. En la nube, el cumplimiento (compliance) es compartido: AWS demuestra que su infraestructura cumple estos estándares, y tú demuestras que tus propias cargas de trabajo los cumplen. Varios servicios de AWS ayudan con cada lado.

AWS Artifact es el portal de autoservicio, dentro de la AWS Management Console, para los documentos de cumplimiento propios de AWS. Tiene dos partes. Artifact Reports te da acceso bajo demanda a los informes de seguridad y cumplimiento de AWS elaborados por auditores externos, como los informes SOC, las atestaciones PCI DSS y las certificaciones ISO, que puedes entregar a tus propios auditores como evidencia de que el lado de AWS está cubierto. Artifact Agreements te permite revisar y aceptar acuerdos con AWS, como el Business Associate Addendum (BAA), requerido cuando manejas información de salud protegida bajo HIPAA.

AWS Audit Manager te ayuda a auditar tu propio uso de AWS. Eliges un marco, por ejemplo uno predefinido para un estándar o uno personalizado, y Audit Manager recopila continuamente evidencia de tus cuentas, como instantáneas de configuración, actividad de CloudTrail y resultados de AWS Config, y la organiza en informes de evaluación asociados a los controles del marco. Eso ahorra semanas de capturas de pantalla y hojas de cálculo antes de una auditoría.

AWS Config registra la configuración de tus recursos de AWS y cómo cambia con el tiempo. Puedes ver cómo estaba un security group el martes pasado y quién lo cambió (en combinación con CloudTrail). Las reglas de Config (Config rules) evalúan los recursos frente a la configuración deseada, por ejemplo 'los buckets de S3 deben bloquear el acceso público' o 'los volúmenes EBS deben estar cifrados', y señalan los recursos que no cumplen; los paquetes de conformidad (conformance packs) agrupan muchas reglas. Config también puede disparar una corrección automática.

Para información general, las páginas de AWS Compliance Programs y de Services in Scope indican qué servicios están cubiertos por qué programas, y el AWS Customer Compliance Center y los whitepapers explican cómo cumplir los requisitos. En el examen: los informes de auditoría propios de AWS significan Artifact; recopilar evidencia para tu auditoría significa Audit Manager; registrar la configuración de los recursos y su cumplimiento de reglas significa Config.

Términos clave

AWS Artifact
Un portal en la consola que da acceso bajo demanda a los informes de cumplimiento de AWS y permite aceptar acuerdos como el BAA.
AWS Audit Manager
Un servicio que recopila continuamente evidencia de tu uso de AWS y la asocia a los controles de un marco de auditoría.
AWS Config
Un servicio que registra las configuraciones de los recursos a lo largo del tiempo y las evalúa frente a reglas de cumplimiento.
Conformance pack (paquete de conformidad)
Una colección de reglas de AWS Config y acciones de corrección que se despliegan juntas como una sola unidad.
Ejemplo real

El auditor de una empresa de pagos pide pruebas de que la infraestructura de nube subyacente cumple PCI DSS. La responsable de cumplimiento descarga la atestación PCI DSS de AWS desde AWS Artifact. Para el entorno propio de la empresa, el equipo usa Audit Manager para reunir evidencia y reglas de AWS Config para demostrar que todos los volúmenes de almacenamiento están cifrados.

Consejo para el examen: Artifact contiene los informes de cumplimiento de AWS; no evalúa tus recursos. Si la pregunta pide cómo verificar si tus propios recursos cumplen un estándar de configuración, la respuesta es AWS Config.

Comprueba lo que sabes

¿Dónde descargarías el informe SOC 2 de AWS para entregárselo a un auditor?

En AWS Artifact (Artifact Reports).

¿Qué servicio te alertaría cuando se crea un volumen EBS sin cifrado?

AWS Config, usando una regla de Config que verifique que los volúmenes estén cifrados.
