AWS Certified Cloud Practitioner CLF-C02

AWS Cloud Adoption Framework (AWS CAF): las seis perspectivas y los beneficios de negocio de la adopción

Pasar a la nube es tanto un cambio organizacional como técnico. Las personas necesitan nuevas habilidades, finanzas necesita nuevas formas de presupuestar y los equipos de seguridad necesitan nuevos controles. El AWS Cloud Adoption Framework (AWS CAF) reúne la guía de AWS para planificar y llevar a cabo ese cambio. Agrupa las capacidades que necesita una organización en seis perspectivas, cada una asociada con las partes interesadas que suelen ser sus responsables. El examen te pide relacionar una preocupación o una parte interesada con la perspectiva correcta y reconocer los beneficios de negocio de la adopción.
