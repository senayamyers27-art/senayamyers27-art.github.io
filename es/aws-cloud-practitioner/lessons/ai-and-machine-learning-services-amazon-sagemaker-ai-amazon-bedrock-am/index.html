AWS Certified Cloud Practitioner CLF-C02

Servicios de IA y aprendizaje automático: Amazon SageMaker AI, Amazon Bedrock, Amazon Q y servicios de IA para tareas específicas como Rekognition, Textract, Comprehend, Transcribe, Polly y Lex

AWS ofrece inteligencia artificial (IA) y aprendizaje automático (machine learning, ML) en tres niveles: plataformas para construir tus propios modelos, servicios que te dan acceso a modelos fundacionales (foundation models) de IA generativa y servicios listos para usar que resuelven una tarea mediante una API sencilla. El examen Cloud Practitioner verifica que sepas relacionar un caso de uso con el servicio adecuado.

Amazon SageMaker AI (antes Amazon SageMaker) es la plataforma para que los científicos de datos y los ingenieros de ML construyan, entrenen y desplieguen sus propios modelos de aprendizaje automático. Proporciona notebooks administrados, trabajos de entrenamiento en infraestructura administrada, ajuste de modelos, despliegue en endpoints y monitoreo. Elígelo cuando necesites un modelo personalizado entrenado con tus propios datos.

Amazon Bedrock es un servicio totalmente administrado que te da acceso a modelos fundacionales de Amazon y de las principales empresas de IA mediante una sola API, para que puedas construir aplicaciones de IA generativa, como asistentes de chat, resúmenes y generación de contenido, sin administrar infraestructura. Puedes personalizar los modelos con tus propios datos y fundamentar las respuestas en tus documentos. Amazon Q es un asistente impulsado por IA generativa: Amazon Q Business responde preguntas y completa tareas usando los datos y sistemas propios de una empresa, y Amazon Q Developer ayuda a los desarrolladores a escribir, explicar y transformar código y a trabajar con recursos de AWS.

Los servicios de IA para tareas específicas no requieren experiencia en ML. Amazon Rekognition analiza imágenes y video para detectar objetos, escenas, texto y rostros. Amazon Textract extrae texto impreso y manuscrito, formularios y tablas de documentos escaneados. Amazon Comprehend usa procesamiento de lenguaje natural para encontrar el sentimiento, las frases clave, las entidades y el idioma de un texto. Amazon Transcribe convierte voz en texto. Amazon Polly convierte texto en voz de sonido natural. Amazon Lex construye interfaces conversacionales (chatbots) usando voz y texto, la misma tecnología detrás de muchos bots de centros de contacto. Amazon Translate proporciona traducción de idiomas.

Cuidado con la dirección de Transcribe y Polly: Transcribe va de voz a texto, Polly va de texto a voz. Textract lee documentos; Comprehend entiende el significado del texto. Cuando un escenario implica construir un modelo personalizado, piensa en SageMaker AI; IA generativa con modelos fundacionales, piensa en Bedrock; un asistente para empleados o desarrolladores, piensa en Amazon Q.

Términos clave

Amazon SageMaker AI
Una plataforma para construir, entrenar y desplegar modelos de aprendizaje automático personalizados.
Amazon Bedrock
Un servicio administrado que proporciona acceso por API a modelos fundacionales para construir aplicaciones de IA generativa.
Amazon Q
Un asistente de IA generativa para empresas (Q Business) y desarrolladores (Q Developer).
Amazon Rekognition
Un servicio que analiza imágenes y video para detectar objetos, texto, escenas y rostros.
Amazon Comprehend
Un servicio de procesamiento de lenguaje natural que extrae el sentimiento, las entidades y las frases clave de un texto.
Amazon Transcribe
Un servicio que convierte voz en texto; Amazon Polly hace lo contrario.
Ejemplo real

Una aseguradora usa Textract para extraer datos de formularios de reclamación escaneados, Comprehend para detectar sentimiento negativo en los correos de los clientes, Transcribe para convertir en texto las grabaciones de llamadas, Lex para operar un chatbot de estado de reclamaciones y Bedrock para redactar resúmenes de reclamaciones para los ajustadores. Su equipo de ciencia de datos usa SageMaker AI para entrenar un modelo personalizado de detección de fraude.

Consejo para el examen: Al examen le encanta el par de voz: Transcribe es de voz a texto; Polly es de texto a voz. Distingue también Textract (extraer texto de documentos) de Comprehend (entender un texto que ya tienes).

Comprueba lo que sabes

¿Qué servicio usarías para convertir un artículo de noticias escrito en audio?

Amazon Polly (texto a voz).

Una empresa quiere construir una aplicación de chat con IA generativa usando modelos fundacionales sin administrar infraestructura. ¿Qué servicio encaja?

Amazon Bedrock.
