AWS Certified Cloud Practitioner CLF-C02

Bases de datos: Amazon RDS y Aurora, Amazon DynamoDB, Amazon ElastiCache, Amazon Redshift y otras bases de datos de propósito específico

AWS te anima a elegir una base de datos de propósito específico para cada trabajo en lugar de forzar todo tipo de datos en un solo motor. Puedes ejecutar cualquier base de datos por tu cuenta en Amazon EC2, pero entonces tú la instalas, la parchas, la respaldas y la replicas. Los servicios de bases de datos administradas asumen ese trabajo pesado indiferenciado, así que, según el modelo de responsabilidad compartida, AWS se encarga del software de base de datos y de la infraestructura, mientras que tú sigues siendo responsable de tus datos, el diseño del esquema, el control de acceso y configuraciones como el cifrado.
