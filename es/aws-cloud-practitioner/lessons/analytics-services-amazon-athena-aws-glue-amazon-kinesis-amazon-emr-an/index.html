Servicios de análisis: Amazon Athena, AWS Glue, Amazon Kinesis, Amazon EMR y Amazon OpenSearch Service

Las empresas recopilan enormes volúmenes de datos y quieren convertirlos en conocimiento. Los servicios de análisis de AWS cubren consultar los datos donde están, prepararlos, procesarlos en tiempo real o en grandes lotes, y buscarlos. Cada uno tiene un nicho claro.

Amazon Athena es un servicio de consultas interactivas serverless que te permite analizar datos directamente en Amazon S3 usando SQL estándar. No hay servidores ni clústeres que administrar ni datos que cargar; defines una tabla sobre archivos como CSV, JSON o Parquet y ejecutas consultas, pagando según los datos escaneados. Es ideal para análisis puntuales de registros o de data lakes. Guardar los datos en formatos comprimidos y columnares reduce los datos escaneados y, por lo tanto, el costo.

AWS Glue es un servicio serverless de integración de datos para extracción, transformación y carga (ETL). Los crawlers de Glue analizan las fuentes de datos y registran sus esquemas en el AWS Glue Data Catalog, un repositorio central de metadatos que pueden usar Athena, Amazon EMR y Redshift. Después, los jobs de Glue limpian, transforman y mueven datos entre almacenes, por ejemplo convirtiendo archivos CSV sin procesar a Parquet para consultarlos de forma eficiente.

Amazon Kinesis maneja datos de streaming en tiempo real. Amazon Kinesis Data Streams captura y almacena flujos de datos, como clickstreams, registros de aplicaciones o telemetría IoT, para que varias aplicaciones puedan procesarlos en segundos. Amazon Data Firehose (antes Kinesis Data Firehose) es la opción más sencilla para cargar datos de streaming en destinos como S3, Redshift u OpenSearch Service sin escribir código. Kinesis Video Streams maneja video.

Amazon EMR es una plataforma administrada de big data para ejecutar frameworks de código abierto como Apache Spark, Apache Hadoop, Hive y Presto en clústeres escalables, para procesamiento a gran escala como el análisis de registros, la preparación de datos para ML y las simulaciones financieras. Amazon OpenSearch Service es un servicio administrado para OpenSearch (y el antiguo Elasticsearch), que se usa para búsqueda de texto completo, análisis de registros y paneles operativos. Amazon QuickSight, que suele aparecer junto a estos, proporciona paneles de inteligencia de negocio.

Palabras clave del examen: 'consultas SQL sobre datos en S3 sin servidores' significa Athena; 'ETL' o 'catálogo de datos' significa Glue; 'streaming en tiempo real' significa Kinesis; 'Hadoop' o 'Spark' significa EMR; 'búsqueda' o 'paneles de análisis de registros' significa OpenSearch Service.

Términos clave

Amazon Athena
Un servicio serverless para consultar datos en S3 con SQL estándar, que se cobra por los datos escaneados.
AWS Glue
Un servicio serverless de integración de datos (ETL) con un Data Catalog de metadatos de tablas.
Amazon Kinesis
Una familia de servicios para recopilar y procesar datos de streaming en tiempo real.
Amazon EMR
Una plataforma administrada para frameworks de big data como Apache Spark y Hadoop.
Amazon OpenSearch Service
Un servicio administrado de búsqueda, análisis de registros y visualización con OpenSearch.
Ejemplo real

Una empresa de música en streaming envía los eventos de reproducción a través de Kinesis Data Streams para una lista en tiempo real de 'tendencias ahora' y usa Data Firehose para depositarlos en S3. Los jobs nocturnos de Glue los convierten a Parquet y actualizan el Data Catalog, los analistas los exploran con Athena y el equipo de ciencia de datos ejecuta grandes jobs de Spark en EMR para construir funciones de recomendación.

Consejo para el examen: Athena y Redshift ejecutan SQL. Athena consulta archivos en S3 bajo demanda sin cargarlos; Redshift es un almacén de datos en el que cargas los datos para análisis intensivos y repetidos.

Comprueba lo que sabes

¿Qué servicio te permite ejecutar consultas SQL sobre archivos de registro en S3 sin configurar ningún servidor?

Amazon Athena.

¿Qué servicio usarías para ingerir datos de clickstream y procesarlos en segundos?

Amazon Kinesis Data Streams.
