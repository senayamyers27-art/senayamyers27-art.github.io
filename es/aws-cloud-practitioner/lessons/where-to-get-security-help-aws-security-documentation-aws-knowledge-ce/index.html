AWS Certified Cloud Practitioner CLF-C02

Dónde obtener ayuda de seguridad: documentación de seguridad de AWS, AWS Knowledge Center, productos de seguridad de AWS Marketplace y AWS Partners

Nadie protege un entorno en la nube en solitario. El examen espera que sepas a dónde acudir para obtener información, herramientas y experiencia en seguridad, y qué recurso se adapta a cada necesidad.

La documentación de seguridad de AWS es el punto de partida. La documentación de cada servicio de AWS incluye un capítulo de seguridad (Security) que explica cómo se aplica el modelo de responsabilidad compartida a ese servicio, qué controles de cifrado y acceso ofrece y cómo registrar su actividad. El AWS Security Center y el AWS Security Blog publican orientación, y los AWS Security Bulletins anuncian problemas de seguridad que afectan a los servicios de AWS junto con cualquier acción que deba tomar el cliente. Los whitepapers y el pilar de seguridad (Security Pillar) del Well-Architected Framework ofrecen buenas prácticas más profundas.

El AWS Knowledge Center es una colección de artículos y videos que responden las preguntas más frecuentes que recibe AWS Support, como cómo solucionar errores de acceso denegado o cómo proteger un bucket. AWS re:Post es el sitio comunitario de preguntas y respuestas de AWS, donde puedes hacer preguntas y obtener respuestas de la comunidad y de expertos de AWS; los artículos del Knowledge Center también se publican allí.

AWS Marketplace es un catálogo digital seleccionado de software, datos y servicios de terceros que se ejecutan en AWS. Para seguridad puedes encontrar firewalls, protección de endpoints, escáneres de vulnerabilidades, herramientas de gestión de información y eventos de seguridad (SIEM) y más, a menudo con precios de pago por uso facturados a través de tu cuenta de AWS. Aquí es a donde vas cuando una organización quiere seguir usando en la nube el producto de un proveedor de seguridad que ya conoce.

La AWS Partner Network (APN) incluye socios de consultoría y de tecnología. Los socios con especializaciones en seguridad pueden diseñar, implementar y administrar controles de seguridad, realizar evaluaciones u operar servicios administrados de detección y respuesta. AWS Professional Services también puede ayudar en proyectos grandes. Cuando sospechas que un recurso de AWS se está usando para abusos, como enviar spam o atacar a otros, el contacto es el equipo AWS Trust & Safety.

En el examen: orientación oficial significa documentación; respuestas a problemas comunes significa Knowledge Center o re:Post; comprar software de seguridad de terceros significa Marketplace; contratar expertos significa AWS Partners o Professional Services.

Términos clave

AWS Knowledge Center
Una colección de artículos y videos que responden preguntas y problemas comunes planteados a AWS Support.
AWS re:Post
Un servicio comunitario de preguntas y respuestas sobre temas de AWS, con respuestas de la comunidad y de expertos de AWS.
AWS Marketplace
Un catálogo seleccionado de software, datos y servicios de terceros que se pueden comprar y desplegar en AWS.
AWS Partner Network (APN)
La comunidad global de AWS de socios de consultoría y tecnología que ayudan a los clientes a construir en AWS.
AWS Security Bulletins (boletines de seguridad)
Avisos de AWS sobre problemas de seguridad que afectan a sus servicios y cualquier acción recomendada para el cliente.
Ejemplo real

El equipo de seguridad de una empresa quiere mantener la marca de firewall de nueva generación que usa en sus instalaciones. Se suscribe al appliance virtual de ese proveedor mediante AWS Marketplace, facturado en su factura de AWS, y contrata a un AWS Partner con especialización en seguridad para diseñar el despliegue. Los ingenieros usan artículos del Knowledge Center para solucionar problemas de enrutamiento.

Consejo para el examen: AWS Marketplace vende productos de terceros; no es donde están los informes de cumplimiento propios de AWS (eso es AWS Artifact) ni donde denuncias abusos (eso es el equipo AWS Trust & Safety).
