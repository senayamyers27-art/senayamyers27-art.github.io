Lecciones de Cloud Practitioner CLF-C02

  • Beneficios de la nube de AWS: pago por uso, economías de escala, agilidad, elasticidad y alcance global
  • Las seis ventajas de la computación en la nube, incluido cambiar gasto fijo por gasto variable y dejar de adivinar la capacidad
  • Alta disponibilidad, tolerancia a fallos, escalabilidad y elasticidad: qué significa cada término y cómo lo ofrece AWS
  • AWS Well-Architected Framework: los seis pilares y de qué se encarga cada uno
  • Principios de diseño en la nube: bajo acoplamiento, diseñar para fallas, automatización y operaciones como código
  • La AWS Well-Architected Tool y cómo realizar una revisión Well-Architected
  • AWS Cloud Adoption Framework (AWS CAF): las seis perspectivas y los beneficios de negocio de la adopción
  • Estrategias de migración (las 7 R): rehost, replatform, refactor, repurchase, retire, retain y relocate
  • Herramientas de migración: AWS Application Migration Service, AWS DMS con la Schema Conversion Tool y AWS DataSync
  • Economía de la nube: costos fijos frente a variables, costo total de propiedad y los costos que pasan a AWS
  • Estrategias de licenciamiento (traer tu propia licencia frente a licencia incluida) y ajuste de tamaño para reducir el desperdicio
  • El modelo de responsabilidad compartida de AWS: seguridad de la nube frente a seguridad en la nube
  • Cómo cambian las responsabilidades entre Amazon EC2, Amazon RDS, AWS Lambda y Amazon S3
  • Cumplimiento y gobernanza: AWS Artifact, AWS Audit Manager, AWS Config y dónde encontrar información de cumplimiento
  • Cifrado en reposo y en tránsito: AWS KMS, AWS CloudHSM y AWS Certificate Manager
  • Proteger el usuario raíz: MFA, sin claves de acceso y las tareas que requieren las credenciales raíz
  • Usuarios, grupos, roles y políticas de IAM, y el principio de mínimo privilegio
  • Inicio de sesión único para empleados con AWS IAM Identity Center e inicio de sesión de clientes con Amazon Cognito
  • Guardar credenciales de forma segura: AWS Secrets Manager y AWS Systems Manager Parameter Store
  • Protección de red: security groups frente a network ACLs, AWS WAF, AWS Shield Standard y Advanced, AWS Firewall Manager
  • Detección de amenazas y postura de seguridad: Amazon GuardDuty, Amazon Inspector, Amazon Macie, Amazon Detective y AWS Security Hub
  • Registro y monitoreo para la seguridad: AWS CloudTrail, Amazon CloudWatch y las verificaciones de seguridad de AWS Trusted Advisor
  • Dónde obtener ayuda de seguridad: documentación de seguridad de AWS, AWS Knowledge Center, productos de seguridad de AWS Marketplace y AWS Partners
  • Formas de usar AWS: AWS Management Console, AWS CLI, SDK, API e infraestructura como código con AWS CloudFormation
  • Modelos de implementación (nube, híbrido y local) y aprovisionamiento único frente a repetible
  • Infraestructura global de AWS: Regiones, Availability Zones, ubicaciones de borde, Local Zones, Wavelength Zones y AWS Outposts
  • Elegir una Región: cumplimiento y residencia de datos, latencia hacia los usuarios, disponibilidad de servicios y precio
  • Familias de instancias de Amazon EC2, AMI, Elastic Load Balancing y Amazon EC2 Auto Scaling
  • Contenedores y cómputo serverless: Amazon ECS, Amazon EKS, AWS Fargate, AWS Lambda y AWS Elastic Beanstalk
  • Bases de datos: Amazon RDS y Aurora, Amazon DynamoDB, Amazon ElastiCache, Amazon Redshift y otras bases de datos de propósito específico
  • Redes: Amazon VPC, subredes, internet gateway y NAT gateway, Route 53, CloudFront, Site-to-Site VPN y Direct Connect
  • Almacenamiento: Amazon S3 y sus clases de almacenamiento, Amazon EBS, instance store, Amazon EFS, Amazon FSx, AWS Storage Gateway y AWS Backup
  • Servicios de IA y aprendizaje automático: Amazon SageMaker AI, Amazon Bedrock, Amazon Q y servicios de IA para tareas específicas como Rekognition, Textract, Comprehend, Transcribe, Polly y Lex
  • Servicios de análisis: Amazon Athena, AWS Glue, Amazon Kinesis, Amazon EMR y Amazon OpenSearch Service
  • Integración de aplicaciones, monitoreo y otros servicios: Amazon SQS, Amazon SNS, Amazon EventBridge, Amazon CloudWatch, AWS Systems Manager y AWS IoT Core
  • Opciones de compra de EC2: On-Demand, Reserved Instances, Savings Plans, Spot Instances, Dedicated Hosts y Dedicated Instances
  • Precios de transferencia de datos y almacenamiento: tráfico entrante frente a saliente, tráfico entre Regiones y costos de las clases de almacenamiento de S3
  • Ofertas del AWS Free Tier y cómo evitar cargos inesperados
  • Estimar y seguir los costos: AWS Pricing Calculator, AWS Cost Explorer y AWS Budgets
  • Datos de facturación detallados: la consola Billing and Cost Management, los Cost and Usage Reports y las exportaciones de datos, y las etiquetas de asignación de costos
  • AWS Organizations: facturación consolidada, descuentos por volumen combinados y descuentos compartidos de Reserved Instances y Savings Plans
  • Herramientas de optimización de costos: AWS Trusted Advisor, AWS Compute Optimizer y recomendaciones de ajuste de tamaño
  • Planes de AWS Support y qué incluye cada uno, incluidos los Technical Account Managers y AWS Health
  • Recursos de ayuda y de socios: AWS re:Post, Knowledge Center, AWS Marketplace, AWS Partner Network, AWS Professional Services y el equipo AWS Trust & Safety
