AWS Certified Cloud Practitioner CLF-C02

AWS Organizations: facturación consolidada, descuentos por volumen combinados y descuentos compartidos de Reserved Instances y Savings Plans

La mayoría de las organizaciones termina con muchas cuentas de AWS: cuentas separadas para producción y desarrollo, para distintos equipos o para distintas unidades de negocio. Una cuenta es un límite sólido para la seguridad, las cuotas y la facturación, de modo que un error o una brecha en una no se extiende automáticamente a las demás. Pero decenas de cuentas necesitan una administración central, o cada una se convierte en una isla con su propia factura. AWS Organizations ofrece esa administración central sin cargo adicional, y la facturación consolidada es una de sus funciones principales.
