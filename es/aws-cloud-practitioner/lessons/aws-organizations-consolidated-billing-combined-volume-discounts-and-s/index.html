AWS Certified Cloud Practitioner CLF-C02

AWS Organizations: facturación consolidada, descuentos por volumen combinados y descuentos compartidos de Reserved Instances y Savings Plans

La mayoría de las organizaciones terminan con muchas cuentas de AWS: cuentas separadas para producción y desarrollo, para distintos equipos o para distintas unidades de negocio. Tener varias cuentas da un fuerte aislamiento de la seguridad y la facturación, pero requiere administración central. AWS Organizations la proporciona sin costo adicional.

Una organización tiene una cuenta de administración (management account, antes llamada cuenta maestra) que crea la organización, invita o crea cuentas miembro y paga la factura. Las cuentas se pueden agrupar en unidades organizativas (OU), como Producción, Desarrollo o Seguridad, formando una jerarquía. Las políticas de control de servicios (service control policies, SCP) adjuntas a la raíz de la organización, a una OU o a una cuenta establecen los permisos máximos disponibles en esas cuentas. Por ejemplo, una SCP puede impedir que cualquiera en las cuentas de desarrollo use Regiones fuera de una lista aprobada, incluso los administradores. Las SCP no otorgan permisos; los limitan.

La facturación consolidada (consolidated billing) es una función de Organizations. Los cargos de todas las cuentas miembro se acumulan en la cuenta de administración, así que recibes una sola factura y haces un solo pago, sin dejar de ver el desglose por cuenta. La facturación consolidada no tiene cargo adicional.

La facturación consolidada también ahorra dinero. Algunos precios de AWS son escalonados y se abaratan por unidad a medida que crece el uso, como el almacenamiento de S3 y la transferencia de datos. La organización se trata como un solo cliente para estos niveles de precios por volumen, así que el uso combinado de todas las cuentas alcanza antes los niveles de precio más bajos de lo que lo haría cada cuenta por separado. Además, los descuentos de Reserved Instances y Savings Plans se pueden compartir entre cuentas: si una cuenta compra un Savings Plan pero no lo usa por completo, el beneficio no usado puede aplicarse al uso elegible de otras cuentas de la organización. La cuenta de administración puede desactivar este uso compartido para cuentas específicas si es necesario.

En el examen, 'una sola factura para varias cuentas' y 'combinar el uso para obtener descuentos por volumen' apuntan a la facturación consolidada de AWS Organizations. 'Restringir qué servicios o Regiones pueden usar las cuentas miembro' apunta a las SCP. AWS Control Tower se basa en Organizations para configurar automáticamente un entorno multicuenta gobernado, llamado landing zone.

Términos clave

AWS Organizations
Un servicio para administrar de forma centralizada varias cuentas de AWS, su facturación y sus políticas.
Management account (cuenta de administración)
La cuenta que crea la organización y paga por todas las cuentas miembro.
Organizational unit (OU, unidad organizativa)
Un grupo de cuentas dentro de una organización que se usa para aplicar políticas en conjunto.
Service control policy (SCP, política de control de servicios)
Una política que establece los permisos máximos disponibles para las cuentas de una organización o de una OU.
Consolidated billing (facturación consolidada)
Una función que combina los cargos de todas las cuentas miembro en una sola factura y agrega el uso para los precios por volumen.
Ejemplo real

Una empresa tiene ocho cuentas de AWS. Al unirlas en una organización, recibe una sola factura; su almacenamiento de S3 combinado alcanza un nivel de precio más bajo; y un Compute Savings Plan comprado en la cuenta de producción también cubre, con el beneficio no usado, horas de uso en las cuentas de prueba. Una SCP en la OU de Desarrollo bloquea el uso de Regiones no aprobadas.

Consejo para el examen: Las SCP nunca otorgan permisos; solo establecen barreras de protección (guardrails). Un usuario necesita tanto una política de IAM que permita la acción como que ninguna SCP la bloquee.

Comprueba lo que sabes

¿Cómo reduce los costos la facturación consolidada para una empresa con muchas cuentas?

El uso se agrega para los niveles de precios por volumen, y los descuentos de Reserved Instances y Savings Plans se pueden compartir entre cuentas.

¿Qué función de AWS Organizations puede impedir que las cuentas miembro usen ciertos servicios?

Las políticas de control de servicios (SCP).
