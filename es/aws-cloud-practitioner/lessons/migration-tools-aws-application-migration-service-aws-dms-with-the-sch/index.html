AWS Certified Cloud Practitioner CLF-C02

Herramientas de migración: AWS Application Migration Service, AWS DMS con la Schema Conversion Tool y AWS DataSync

AWS ofrece servicios dedicados para llevar a cabo migraciones. El examen espera que elijas el adecuado según lo que se va a mover: servidores completos, bases de datos o archivos.

AWS Application Migration Service (a menudo abreviado como AWS MGN) es el servicio principal de AWS para hacer rehost (lift and shift). Instalas un agente de replicación en tus servidores de origen, que pueden ser físicos, virtuales o estar en otra nube. El servicio replica continuamente los discos de los servidores a un área de preparación (staging) en tu cuenta de AWS, de modo que puedes lanzar instancias de prueba en cualquier momento sin interrumpir el origen. Cuando estás listo, realizas el corte (cutover) y los servidores se lanzan como instancias de Amazon EC2. La replicación continua mantiene corta la ventana de corte.

AWS Database Migration Service (AWS DMS) migra bases de datos a AWS. La base de datos de origen sigue totalmente operativa durante la migración, lo que minimiza el tiempo de inactividad, y DMS puede seguir replicando los cambios en curso hasta que hagas el cambio. DMS admite migraciones homogéneas, en las que el origen y el destino usan el mismo motor (por ejemplo, de Oracle a Oracle), y migraciones heterogéneas, en las que difieren (por ejemplo, de Oracle a Amazon Aurora PostgreSQL). En las migraciones heterogéneas, el esquema, es decir, las tablas, vistas, procedimientos almacenados y otros objetos de código, primero debe convertirse al dialecto del motor de destino. Ese es el trabajo de la AWS Schema Conversion Tool (AWS SCT); DMS también ofrece conversión de esquemas integrada en la consola. Después, DMS mueve los datos.

AWS DataSync es un servicio de transferencia de datos en línea para archivos y objetos. Mueve datos entre sistemas de almacenamiento locales (como recursos compartidos de archivos NFS o SMB) y servicios de almacenamiento de AWS como Amazon S3, Amazon EFS y Amazon FSx, y también entre servicios de almacenamiento de AWS. Se encarga de la programación, el cifrado en tránsito, las verificaciones de integridad de datos y las transferencias incrementales, por lo que es muy adecuado para migraciones únicas y sincronizaciones recurrentes de grandes conjuntos de archivos a través de la red.

Para conjuntos de datos muy grandes, en los que la transferencia por red sería demasiado lenta, AWS también ofrece dispositivos de transferencia sin conexión de la AWS Snow Family, pero la correspondencia clave de este tema es: los servidores van con Application Migration Service, las bases de datos con DMS (más SCT cuando los motores difieren) y los recursos compartidos de archivos con DataSync.

Términos clave

AWS Application Migration Service
Un servicio que replica continuamente los servidores de origen a AWS y los lanza como instancias EC2 para una migración lift and shift.
AWS DMS
AWS Database Migration Service, que migra bases de datos a AWS mientras el origen sigue operativo, incluida la replicación de los cambios en curso.
Heterogeneous migration (migración heterogénea)
Una migración de base de datos en la que los motores de origen y destino son distintos, lo que requiere convertir el esquema.
AWS Schema Conversion Tool (SCT)
Una herramienta que convierte esquemas y objetos de código de bases de datos del formato de un motor al de otro.
AWS DataSync
Un servicio en línea que transfiere archivos y objetos entre el almacenamiento local y los servicios de almacenamiento de AWS.
Ejemplo real

Un fabricante traslada 40 servidores de aplicaciones Windows y Linux a EC2 con Application Migration Service, convierte su esquema de Oracle a Aurora PostgreSQL con SCT y mueve los datos con DMS mientras producción sigue funcionando, y copia 30 TB de planos de ingeniería desde un recurso compartido de archivos NAS a Amazon EFS usando DataSync.

Consejo para el examen: Si los motores de base de datos de origen y destino son distintos, busca DMS junto con la Schema Conversion Tool. DMS por sí solo mueve los datos; SCT convierte el esquema. DataSync mueve archivos, no bases de datos.

Comprueba lo que sabes

¿Qué servicio convierte un esquema de Oracle para que pueda ejecutarse en Amazon Aurora PostgreSQL?

La AWS Schema Conversion Tool (o la conversión de esquemas de DMS); después AWS DMS migra los datos.

¿Qué servicio usarías para hacer lift and shift de una flota de servidores locales a EC2 con un tiempo de inactividad mínimo?

AWS Application Migration Service, que replica continuamente los servidores y los lanza en EC2 en el momento del corte.
