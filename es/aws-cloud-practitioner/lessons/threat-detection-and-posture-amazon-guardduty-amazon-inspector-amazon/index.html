AWS Certified Cloud Practitioner CLF-C02

Detección de amenazas y postura de seguridad: Amazon GuardDuty, Amazon Inspector, Amazon Macie, Amazon Detective y AWS Security Hub

AWS tiene una familia de servicios de seguridad cuyos nombres se confunden con facilidad. Cada uno tiene una función distinta, y las preguntas del examen suelen describir la función y pedir el nombre. La forma más fácil de aprenderlos es por la pregunta que responde cada uno: ¿está ocurriendo algo malo?, ¿qué es vulnerable?, ¿dónde están mis datos sensibles?, ¿qué pasó exactamente? y ¿cuál es mi postura de seguridad general?

Amazon GuardDuty responde '¿está ocurriendo algo malicioso en mi cuenta en este momento?'. Es un servicio de detección de amenazas que analiza continuamente fuentes de datos básicas, los eventos de administración de AWS CloudTrail, los Amazon VPC Flow Logs y los registros de consultas DNS, usando inteligencia de amenazas, detección de anomalías y aprendizaje automático. Los planes de protección opcionales lo amplían a los eventos de datos de S3, Amazon EKS, el monitoreo en tiempo de ejecución, el análisis de malware y la actividad de inicio de sesión en bases de datos. Genera hallazgos (findings) sobre cosas como una instancia EC2 que se comunica con una dirección maliciosa conocida, llamadas a la API desde una ubicación inusual, credenciales usadas desde fuera de AWS o señales de minería de criptomonedas. Lo habilitas con un clic o con aws guardduty create-detector --enable, y no hay nada que instalar para sus fuentes básicas.

Amazon Inspector responde '¿qué vulnerabilidades tienen mis cargas de trabajo?'. Analiza de forma automática y continua las instancias EC2, las imágenes de contenedores en Amazon Elastic Container Registry (Amazon ECR) y las funciones Lambda en busca de vulnerabilidades de software conocidas, catalogadas como Common Vulnerabilities and Exposures (CVE), y de exposición de red no intencionada, y luego prioriza los hallazgos con una puntuación de riesgo que considera tu entorno. Amazon Macie responde '¿dónde están mis datos sensibles?'. Usa aprendizaje automático y coincidencia de patrones para descubrir datos sensibles como información de identificación personal (PII), datos financieros y credenciales en Amazon S3, y además informa sobre la seguridad de los buckets, como el acceso público o la falta de cifrado.

Amazon Detective responde '¿qué pasó y por qué?'. Cuando tienes un hallazgo, por ejemplo de GuardDuty, Detective recopila y vincula automáticamente los datos de registro y construye visualizaciones de los recursos, usuarios y direcciones IP involucrados a lo largo del tiempo, lo que te ayuda a investigar el alcance y la causa raíz sin escribir consultas. AWS Security Hub responde '¿cuál es mi postura de seguridad general?'. Agrega en un solo lugar y en un formato estándar los hallazgos de GuardDuty, Inspector, Macie, Firewall Manager, IAM Access Analyzer y herramientas de socios, y ejecuta verificaciones automatizadas según normas de seguridad como las AWS Foundational Security Best Practices y el Center for Internet Security (CIS) AWS Foundations Benchmark. Esto suele llamarse gestión de la postura de seguridad en la nube (CSPM), y puede abarcar todas las cuentas de una organización.

Las diferencias tienen que ver con detección frente a evaluación frente a investigación. GuardDuty detecta amenazas activas a partir de registros; no analiza el software en busca de vulnerabilidades. Inspector evalúa las vulnerabilidades y la exposición del software; no vigila a los atacantes. Macie trata solo de datos sensibles, principalmente en S3. Detective no genera hallazgos de amenazas primarios; te ayuda a investigarlos. Security Hub recopila, normaliza y puntúa; depende de los otros servicios para gran parte del detalle.

Veamos un ejemplo práctico. GuardDuty genera un hallazgo de que una instancia EC2 está haciendo solicitudes DNS a un dominio vinculado con la minería de criptomonedas. El ingeniero de seguridad abre el hallazgo en Detective y ve que la instancia comenzó ese tráfico una hora después de que se desplegara un nuevo contenedor, y que el mismo rol de IAM se usó desde una dirección IP desconocida. Inspector muestra que la imagen del contenedor incluye un framework web con una CVE crítica, el probable punto de entrada. Macie confirma que el bucket de S3 que el rol podía leer contiene PII de clientes. Security Hub muestra todos estos hallazgos juntos, y el equipo aísla la instancia y aplica parches a la imagen.

Errores comunes: elegir GuardDuty para el análisis de vulnerabilidades (eso es Inspector); elegir Inspector para detectar credenciales comprometidas (eso es GuardDuty); usar Macie para datos en bases de datos o en discos de EC2, cuando se enfoca en S3; esperar que Detective prevenga ataques; y pensar que Security Hub reemplaza a los servicios individuales. Recuerda también que ninguno de ellos es un firewall; detectan, evalúan e informan, y el bloqueo se hace con herramientas como los security groups, las network ACLs y AWS WAF.

La redacción del examen se relaciona con un servicio en cada caso. 'Vulnerabilidades', 'CVE', 'paquetes de software' o 'alcanzabilidad de red de EC2' significa Inspector. 'Datos sensibles', 'PII' o 'descubrir números de tarjetas de crédito en S3' significa Macie. 'Actividad maliciosa', 'llamadas a la API inusuales', 'instancia comprometida' o 'analizar VPC Flow Logs y CloudTrail en busca de amenazas' significa GuardDuty. 'Investigar la causa raíz' o 'visualizar relaciones en un hallazgo de seguridad' significa Detective. 'Un solo panel de hallazgos', 'agregar alertas de seguridad' o 'verificar según normas de buenas prácticas de seguridad' significa Security Hub. Una ayuda para recordar: GuardDuty vigila (guard), Inspector inspecciona, Macie encuentra datos, Detective investiga y Security Hub es el centro (hub).

Términos clave

Amazon GuardDuty
Servicio de detección de amenazas que analiza CloudTrail, VPC Flow Logs, registros DNS y más en busca de actividad maliciosa.
Amazon Inspector
Servicio automatizado de gestión de vulnerabilidades que analiza EC2, imágenes de ECR y funciones Lambda en busca de CVE y exposición.
Common Vulnerabilities and Exposures (CVE)
Catálogo público de identificadores de vulnerabilidades de software conocidas.
Amazon Macie
Servicio que descubre datos sensibles, como PII, en Amazon S3 e informa sobre problemas de seguridad de los buckets.
Amazon Detective
Servicio que vincula y visualiza datos de registro para investigar la causa raíz de los hallazgos de seguridad.
AWS Security Hub
Servicio que agrega hallazgos de seguridad y verifica las cuentas según normas de seguridad.
Hallazgo (finding)
Registro generado por un servicio de seguridad que describe una amenaza, vulnerabilidad o mala configuración detectada.
Ejemplo real

Una empresa emergente del sector salud habilita GuardDuty, Inspector, Macie y Security Hub en todas sus cuentas de AWS Organizations en una sola tarde. En una semana, Macie marca un bucket de S3 con expedientes de pacientes exportados que nadie conocía, Inspector informa una CVE crítica en una imagen de contenedor antigua y GuardDuty alerta sobre llamadas a la API desde una clave de acceso usada en otro país. Security Hub clasifica los tres para que el equipo corrija primero la clave filtrada.

Consejo para el examen: Vulnerabilidades y CVE significan Inspector; datos sensibles o PII en S3 significan Macie; actividad maliciosa a partir de registros significa GuardDuty; investigar la causa raíz significa Detective; una vista única de hallazgos y verificaciones de cumplimiento significa Security Hub.

Comprueba lo que sabes

¿Qué servicio analiza las instancias EC2 y las imágenes de contenedores en busca de vulnerabilidades de software conocidas?

Amazon Inspector.

¿Qué servicio detecta una instancia EC2 que se comunica con una dirección IP maliciosa conocida?

Amazon GuardDuty, que analiza VPC Flow Logs, registros DNS y eventos de CloudTrail en busca de amenazas.

Una empresa necesita encontrar objetos de S3 que contengan números de tarjetas de crédito. ¿Qué servicio usa?

Amazon Macie.

¿Qué agrega AWS Security Hub por encima de GuardDuty, Inspector y Macie?

Un solo lugar que agrega sus hallazgos de todas las cuentas y ejecuta verificaciones automatizadas según normas de seguridad.
