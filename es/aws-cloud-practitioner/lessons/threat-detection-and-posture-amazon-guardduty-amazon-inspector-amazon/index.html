AWS Certified Cloud Practitioner CLF-C02

Detección de amenazas y postura de seguridad: Amazon GuardDuty, Amazon Inspector, Amazon Macie, Amazon Detective y AWS Security Hub

AWS tiene una familia de servicios de seguridad cuyos nombres son fáciles de confundir. Cada uno tiene un trabajo distinto, y las preguntas del examen suelen describir el trabajo y pedir el nombre. Aprende cada uno por la pregunta que responde.

Amazon GuardDuty responde '¿está ocurriendo algo malicioso en mi cuenta ahora mismo?'. Es un servicio de detección de amenazas que analiza continuamente fuentes de datos como los eventos de AWS CloudTrail, los VPC Flow Logs y los registros de DNS usando inteligencia de amenazas y aprendizaje automático. Genera hallazgos (findings) sobre cosas como una instancia EC2 que se comunica con una dirección maliciosa conocida, llamadas de API inusuales desde una ubicación desconocida o señales de minería de criptomonedas. Lo habilitas con un clic; no hay agentes que instalar para sus fuentes principales.

Amazon Inspector responde '¿qué vulnerabilidades tienen mis cargas de trabajo?'. Analiza automáticamente las instancias EC2, las imágenes de contenedor en Amazon ECR y las funciones Lambda en busca de vulnerabilidades de software conocidas (CVE) y de exposición de red no intencionada, y prioriza los hallazgos con una puntuación de riesgo. Amazon Macie responde '¿dónde están mis datos sensibles?'. Usa aprendizaje automático y coincidencia de patrones para descubrir datos sensibles, como información de identificación personal (PII) y datos financieros, en Amazon S3, y también informa sobre la seguridad de los buckets, como el acceso público o la falta de cifrado.

Amazon Detective responde '¿qué pasó y por qué?'. Cuando tienes un hallazgo, por ejemplo de GuardDuty, Detective recopila automáticamente datos de registros y construye visualizaciones de los recursos, usuarios y direcciones IP involucrados a lo largo del tiempo, ayudándote a investigar la causa raíz. AWS Security Hub responde '¿cuál es mi postura de seguridad general?'. Agrega en un solo lugar los hallazgos de GuardDuty, Inspector, Macie y otras herramientas de AWS y de socios, y ejecuta verificaciones automatizadas frente a estándares y buenas prácticas de seguridad (gestión de la postura de seguridad en la nube), dándote una vista consolidada de todas las cuentas.

Un truco útil para recordarlos: GuardDuty vigila (amenazas activas), Inspector inspecciona (vulnerabilidades), Macie encuentra datos sensibles en S3, Detective investiga y Security Hub es el centro (hub) que lo reúne todo.

Términos clave

Amazon GuardDuty
Un servicio de detección de amenazas que analiza CloudTrail, VPC Flow Logs y registros de DNS en busca de actividad maliciosa o no autorizada.
Amazon Inspector
Un servicio automatizado de gestión de vulnerabilidades para EC2, imágenes de contenedor y funciones Lambda.
Amazon Macie
Un servicio que descubre y protege datos sensibles, como PII, almacenados en Amazon S3.
Amazon Detective
Un servicio que analiza y visualiza datos de seguridad para ayudar a investigar la causa raíz de los hallazgos.
AWS Security Hub
Un servicio que agrega hallazgos de seguridad y verifica las cuentas frente a estándares de buenas prácticas de seguridad.
Ejemplo real

Security Hub muestra un hallazgo de GuardDuty de gravedad alta: una instancia EC2 se está comunicando con una dirección asociada a la minería de criptomonedas. La analista abre Amazon Detective para ver qué rol lanzó la instancia y desde dónde, revisa Amazon Inspector en busca de un paquete vulnerable en la instancia y luego la aísla y la reemplaza.

Consejo para el examen: Vulnerabilidades y CVE significan Inspector; datos sensibles o PII en S3 significa Macie; actividad maliciosa a partir de registros significa GuardDuty; investigar la causa raíz significa Detective; un solo panel de hallazgos y verificaciones de cumplimiento significa Security Hub.

Comprueba lo que sabes

¿Qué servicio identificaría números de tarjetas de crédito almacenados en buckets de S3?

Amazon Macie.

¿Qué servicio analiza instancias EC2 e imágenes de contenedor en busca de vulnerabilidades de software?

Amazon Inspector.
