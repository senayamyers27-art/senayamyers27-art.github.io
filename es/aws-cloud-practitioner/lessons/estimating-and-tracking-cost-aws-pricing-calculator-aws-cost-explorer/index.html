Estimar y seguir los costos: AWS Pricing Calculator, AWS Cost Explorer y AWS Budgets

Tres herramientas cubren el ciclo de vida de los costos de AWS: estimar antes de construir, analizar lo que ya gastaste y alertar cuando el gasto se desvía. La AWS Pricing Calculator, AWS Cost Explorer y AWS Budgets pueden sonar intercambiables, y el examen las ofrece deliberadamente como distractores entre sí. La forma de distinguirlas es preguntarte en qué momento se sitúa la pregunta: antes de la implementación, después del gasto o vigilando continuamente un umbral.

La AWS Pricing Calculator es una herramienta web gratuita para estimar el costo de una arquitectura antes de implementarla. Agregas servicios, eliges Regiones y configuraciones como tipos de instancia, opciones de compra, cantidades de almacenamiento y la transferencia de datos esperada, y produce estimaciones mensuales y anuales que puedes agrupar, exportar y compartir mediante un enlace. La calculadora pública no necesita una cuenta de AWS ni analiza tu uso real. Úsala para planificar, presupuestar un proyecto nuevo, comparar Regiones u opciones de compra y construir el caso de negocio para una migración.

AWS Cost Explorer analiza los costos y el uso en los que ya incurriste. Muestra gráficos interactivos del gasto por servicio, cuenta vinculada, Región, etiqueta de asignación de costos, tipo de uso y más, en periodos diarios o mensuales, con datos históricos y un pronóstico del gasto futuro. Lo usas para responder preguntas como «¿qué servicio causó el aumento del mes pasado?» o «¿cuánto cuesta la carga de trabajo del equipo de marketing?». También informa la utilización y la cobertura de Reserved Instances y Savings Plans, y ofrece recomendaciones de compra y de ajuste de tamaño.

AWS Budgets te permite definir presupuestos personalizados y te alerta cuando los costos o el uso reales o pronosticados los superan. Puedes crear presupuestos de costo, presupuestos de uso y presupuestos de utilización y cobertura de Reserved Instances o Savings Plans, con alertas por correo electrónico o hacia un tema de Amazon Simple Notification Service (Amazon SNS) que puede alimentar herramientas de chat. Las acciones de presupuesto (budget actions) pueden ir más allá y responder automáticamente cuando se cruza un umbral, por ejemplo aplicando una política de IAM o una política de control de servicios que bloquee recursos nuevos, o deteniendo instancias EC2 o RDS específicas.

Una herramienta relacionada, AWS Cost Anomaly Detection, que se encuentra junto a estas en la consola de Billing and Cost Management, usa aprendizaje automático para aprender tu patrón de gasto normal y alertarte sobre picos inusuales, incluso los que se mantienen por debajo de un presupuesto. Una regla sencilla para recordarlas: la Pricing Calculator mira hacia adelante antes de que exista algo, Cost Explorer mira hacia atrás (y un poco hacia adelante con los pronósticos) lo que ya gastaste, Budgets vigila el gasto frente a una línea que tú trazas, y Anomaly Detection vigila cualquier cosa fuera de lo normal. Todas están en la consola de Billing and Cost Management, y el acceso a ellas se controla con permisos de IAM, así que puedes dar al personal de finanzas visibilidad de costos sin derechos sobre la infraestructura.

Veamos un ejemplo práctico. Una empresa planea una nueva plataforma de analítica, y cada herramienta cumple su papel por turnos. El arquitecto la modela en la Pricing Calculator, comparando On-Demand con Savings Plans, y presenta la estimación a finanzas. Después del lanzamiento, se crea para el proyecto un presupuesto mensual con alertas al 80 y al 100 por ciento, con una notificación de SNS al canal del equipo. En el segundo mes se dispara una alerta por el gasto pronosticado; el equipo abre Cost Explorer, filtra por la etiqueta del proyecto, agrupa por tipo de uso y descubre que la transferencia de datos entre Availability Zones es mucho mayor que la estimada. Mueve los componentes que se comunican mucho a una sola AZ y el pronóstico vuelve a la normalidad.

Errores comunes: esperar que Cost Explorer envíe alertas por umbral (eso lo hace Budgets); usar la Pricing Calculator para entender la factura del mes pasado (solo estima configuraciones hipotéticas); pensar que Budgets detiene el gasto automáticamente por defecto (las alertas son lo predeterminado; las acciones deben configurarse); y olvidar activar las etiquetas de asignación de costos, sin las cuales no funciona el filtrado por equipo o proyecto en Cost Explorer y Budgets. Otra trampa es suponer que la estimación de la Pricing Calculator es un precio garantizado; las facturas reales dependen del uso real.

Las preguntas del examen suelen indicar la línea de tiempo. «Estimar el costo de una carga de trabajo planificada», «antes de migrar» o «comparar el costo de arquitecturas» es la Pricing Calculator. «Visualizar y analizar el gasto pasado», «identificar qué servicio hizo subir los costos» o «pronosticar el gasto a partir del historial» es Cost Explorer. «Alertarme cuando los costos superen un umbral» o «notificar cuando el gasto pronosticado vaya a pasar un límite» es AWS Budgets. «Detectar automáticamente gastos inusuales usando aprendizaje automático» es Cost Anomaly Detection.

Términos clave

AWS Pricing Calculator
Herramienta gratuita para estimar el costo de una arquitectura planificada antes de implementarla.
AWS Cost Explorer
Herramienta para visualizar y analizar el costo y el uso históricos, con pronósticos y recomendaciones.
AWS Budgets
Servicio que sigue el costo o el uso frente a umbrales y envía alertas o ejecuta acciones.
Acción de presupuesto (budget action)
Respuesta automática, como aplicar una política restrictiva o detener instancias, cuando se cruza un umbral de presupuesto.
Gasto pronosticado
Proyección de los costos futuros basada en los patrones de uso históricos.
AWS Cost Anomaly Detection
Servicio que usa aprendizaje automático para encontrar gastos inusuales y alertarte.
Ejemplo real

Una organización sin fines de lucro tiene una subvención anual fija para la nube. Antes de migrar, estima su sitio web y su base de datos de donantes en la Pricing Calculator. Después de la migración, define un AWS Budget mensual igual a la subvención con alertas al 50, 80 y 100 por ciento, y revisa Cost Explorer cada mes agrupado por servicio. Cuando una alerta muestra que el gasto pronosticado sube, Cost Explorer revela una base de datos de prueba olvidada, que el equipo elimina ese mismo día.

Consejo para el examen: «Estimar el costo de una carga de trabajo planificada» es la Pricing Calculator. «Analizar el gasto pasado» es Cost Explorer. «Alertar cuando los costos superen un umbral» es AWS Budgets. Cost Explorer no envía alertas por umbral; Budgets sí.

Comprueba lo que sabes

Una empresa quiere estimar los costos mensuales de una arquitectura que aún no ha construido. ¿Qué herramienta?

La AWS Pricing Calculator.

¿Qué herramienta muestra qué servicio causó el aumento de costos del mes pasado?

AWS Cost Explorer, que analiza el costo y el uso históricos por servicio y otras dimensiones.

Un gerente quiere recibir un correo cuando el gasto mensual pronosticado vaya a superar una cantidad definida. ¿Qué servicio?

AWS Budgets, con una alerta sobre el costo pronosticado.

¿Puede AWS Budgets hacer algo más que enviar notificaciones?

Sí. Las acciones de presupuesto pueden aplicar políticas de IAM o de control de servicios, o detener instancias EC2 y RDS específicas cuando se cruza un umbral.
