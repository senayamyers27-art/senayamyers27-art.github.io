Estimar y seguir los costos: AWS Pricing Calculator, AWS Cost Explorer y AWS Budgets

Tres herramientas cubren el ciclo de vida de los costos de AWS: estimar antes de construir, analizar lo que has gastado y alertar cuando el gasto se desvía. El examen a menudo pregunta cuál encaja en una situación.

La AWS Pricing Calculator es una herramienta web gratuita para estimar el costo de una arquitectura antes de desplegarla. Agregas servicios, eliges Regiones y configuraciones, como tipos de instancia, cantidades de almacenamiento y transferencia de datos, y produce una estimación mensual y anual que puedes agrupar, exportar y compartir mediante un enlace. No necesita una cuenta de AWS y no mira tu uso real. Úsala para planificar, presupuestar un proyecto nuevo, comparar Regiones u opciones de compra y construir el caso de negocio de una migración.

AWS Cost Explorer analiza los costos y el uso en que ya incurriste. Muestra gráficos interactivos de tu gasto por servicio, cuenta, Región, etiqueta, tipo de uso y más, en períodos diarios o mensuales, con datos históricos y un pronóstico del gasto futuro. Lo usas para responder preguntas como '¿qué servicio causó el aumento del mes pasado?' o '¿cuánto cuesta la carga de trabajo del equipo de marketing?'. También ofrece informes de utilización y cobertura de Reserved Instances y Savings Plans, junto con recomendaciones de compra y de ajuste de tamaño.

AWS Budgets te permite establecer presupuestos personalizados y recibir alertas cuando los costos o el uso reales o pronosticados los superan. Puedes crear presupuestos de costos, presupuestos de uso y presupuestos de utilización y cobertura de Reserved Instances o Savings Plans, y las alertas pueden llegar por correo electrónico o a temas de Amazon SNS. Las acciones de presupuesto (budget actions) incluso pueden aplicar una política de IAM o detener instancias específicas automáticamente cuando se cruza un umbral.

Una forma útil de recordarlas: la Pricing Calculator mira hacia adelante antes de que exista nada, Cost Explorer mira hacia atrás (y un poco hacia adelante con los pronósticos) lo que has gastado, y Budgets vigila el gasto y te avisa. Cost Anomaly Detection, que se encuentra junto a estas herramientas en la consola de facturación, usa aprendizaje automático para detectar patrones de gasto inusuales y alertarte.

Términos clave

AWS Pricing Calculator
Una herramienta web gratuita para estimar el costo de los servicios de AWS antes de desplegarlos.
AWS Cost Explorer
Una herramienta para visualizar, analizar y pronosticar tus costos y uso reales de AWS.
AWS Budgets
Un servicio que sigue los costos o el uso frente a umbrales y envía alertas o dispara acciones.
Cost Anomaly Detection (detección de anomalías de costos)
Una función de facturación que usa aprendizaje automático para encontrar gastos inusuales y alertar sobre ellos.
Ejemplo real

Antes de migrar, una gerente de finanzas usa la Pricing Calculator para estimar el costo mensual de la arquitectura planificada. Tres meses después de la puesta en producción, usa Cost Explorer y ve que la transferencia de datos es mayor de lo esperado. Crea un presupuesto mensual en AWS Budgets con alertas al 80 y al 100 por ciento del gasto planificado, enviadas a la lista de correo del equipo de ingeniería.

Consejo para el examen: 'Estimar el costo de una carga de trabajo planificada' es Pricing Calculator. 'Visualizar y analizar el gasto pasado' es Cost Explorer. 'Avísame cuando los costos superen un umbral' es AWS Budgets. Cost Explorer no envía alertas por umbral; Budgets sí.
