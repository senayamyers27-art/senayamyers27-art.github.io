Applets de Embedded Event Manager (EEM)

Embedded Event Manager (EEM) es automatización que se ejecuta en el propio dispositivo Cisco IOS o IOS XE. Vigila eventos y responde con acciones, sin necesidad de un servidor externo. Es útil para reaccionar al instante ante problemas, recolectar datos de diagnóstico en el momento en que algo ocurre y hacer cumplir reglas sencillas. EEM admite applets, escritos en modo de configuración, y scripts Tcl; ENCOR se enfoca en los applets.

Un applet tiene un nombre, un evento (el disparador) y un conjunto de acciones. Los detectores de eventos comunes incluyen event syslog pattern (un mensaje de log que coincide con una expresión regular), event timer (watchdog para un intervalo repetitivo, countdown para un retraso de una sola vez, cron para un horario), event track (un cambio de estado de un objeto de tracking, como una IP SLA que falla), event interface (un contador de interfaz que cruza un umbral), event snmp (un objeto SNMP que cruza un umbral), event cli pattern (alguien que escribe un comando, que incluso puede bloquearse) y event none (se ejecuta manualmente con event manager run NAME).

Las acciones tienen etiquetas y se ejecutan en el orden de sus etiquetas, que se comparan como cadenas de texto, así que etiquetas como 1.0, 2.0 y 10.0 pueden ordenarse de forma inesperada; muchos ingenieros usan formatos consistentes como 010, 020 y 030. Entre las acciones útiles están cli command para ejecutar un comando EXEC o de configuración, syslog msg para escribir un mensaje de log, mail para enviar un correo, snmp-trap para enviar un trap, wait para pausar, y control de flujo con if, foreach y variables. Cuando un applet ejecuta comandos CLI, necesita entrar por sí mismo al modo privilegiado, así que la primera acción CLI suele ser enable.

event manager applet UPLINK-DOWN
 event syslog pattern "Interface GigabitEthernet0/1, changed state to down"
 action 010 cli command "enable"
 action 020 cli command "show ip route | redirect flash:uplink-down.txt"
 action 030 syslog priority critical msg "Uplink Gi0/1 down, routing table saved"

Otro patrón común es el trabajo programado: event timer cron cron-entry "0 2 * * *" con una acción que copia la running configuration a un servidor todas las noches a las 02:00. Con event track 1 state down, un applet puede apagar una interfaz de respaldo o cambiar una ruta cuando falla una sonda IP SLA.

Si está configurada la autorización de comandos AAA, los comandos que ejecuta EEM también se autorizan, así que el applet puede fallar a menos que configures event manager session cli username NAME con una cuenta autorizada para ejecutarlos. Prueba los applets con event manager run (para applets con event none), revísalos con show event manager policy registered y show event manager history events, y usa debug event manager action cli en un laboratorio para ver los comandos que se ejecutan.

EEM es ideal para reacciones locales, rápidas y sencillas. Para configuración a nivel de toda la flota y lógica compleja, usa herramientas externas al equipo como Ansible o Python con NETCONF y RESTCONF; ambos enfoques se complementan.

Términos clave

EEM
Embedded Event Manager: automatización en el dispositivo que ejecuta acciones cuando ocurren eventos definidos.
Applet
Una política de EEM escrita en modo de configuración con un evento y un conjunto de acciones.
Event detector (detector de eventos)
El componente de EEM que dispara un applet, como syslog, timer, track o interface.
action cli command
Una acción de EEM que ejecuta un comando CLI en el dispositivo.
Ejemplo real

La CPU de un router se dispara durante unos segundos cada tarde, y nadie está mirando cuando ocurre. El ingeniero crea un applet con un evento SNMP sobre la utilización de CPU que ejecuta show processes cpu sorted y show interfaces hacia un archivo en flash y escribe un mensaje syslog. Al día siguiente, el archivo muestra exactamente qué proceso estaba ocupado.

Consejo para el examen: Cada applet necesita exactamente un evento y al menos una acción. Las etiquetas de las acciones se ejecutan en orden de cadena de texto. Empieza las acciones CLI con 'enable' y ten cuidado con la autorización de comandos AAA bloqueando los comandos de EEM.

Comprueba lo que sabes

¿Qué detector de eventos dispara un applet cuando aparece un mensaje de log específico?

event syslog pattern con una expresión regular que coincida con el mensaje.

¿Cómo ejecutas un applet a demanda?

Configúralo con event none y ejecútalo con event manager run seguido del nombre del applet.
