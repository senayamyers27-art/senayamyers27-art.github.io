Fundamentos de Python: variables, bucles, funciones, diccionarios, la biblioteca requests

Python es el lenguaje más común para la automatización de redes porque es legible, se ejecuta en todas partes y tiene bibliotecas para SSH, NETCONF y API REST. ENCOR no espera que seas desarrollador, pero debes poder leer un script corto y predecir lo que hace, especialmente uno que llama a una API REST.

Las variables guardan valores y no necesitan tipos declarados. Los tipos comunes son cadenas (hostname = "R1"), enteros (vlan = 10), flotantes, booleanos (True, False), listas (colecciones ordenadas, vlans = [10, 20, 30], indexadas desde 0, así que vlans[0] es 10) y diccionarios. La indentación es parte de la sintaxis: las líneas dentro de un bucle, una función o una sentencia if deben indentarse de forma consistente, normalmente con cuatro espacios.

Un diccionario almacena pares clave-valor y es la forma en que Python representa los objetos JSON. Lees un valor por su clave y puedes anidar diccionarios y listas:

device = {"hostname": "SW1", "ip": "10.0.0.11", "vlans": [10, 20]}
print(device["hostname"])      # SW1
print(device["vlans"][1])      # 20
device["site"] = "Branch-5"     # agrega una clave
print(device.get("model", "unknown"))  # unknown

Los bucles repiten trabajo. Un bucle for itera sobre una lista o un diccionario; un bucle while se repite mientras una condición sea verdadera. Las condiciones usan if, elif y else. Las funciones empaquetan lógica reutilizable con def, reciben parámetros y devuelven un resultado con return:

def describe(dev):
    return dev["hostname"] + " at " + dev["ip"]

inventory = [{"hostname": "R1", "ip": "10.0.0.1"},
             {"hostname": "R2", "ip": "10.0.0.2"}]
for dev in inventory:
    if dev["hostname"] != "R2":
        print(describe(dev))    # R1 at 10.0.0.1
for key, value in inventory[0].items():
    print(key, value)

La biblioteca requests simplifica las llamadas HTTP. requests.get(url, headers=..., auth=..., verify=...) envía un GET; requests.post(url, json=payload) envía un POST con un cuerpo JSON. El objeto de respuesta devuelto tiene status_code (como 200), text (el cuerpo sin procesar), json() (el cuerpo convertido en diccionarios y listas de Python) y headers. raise_for_status() lanza una excepción para los códigos 4xx y 5xx. En el ejemplo de abajo, user y password vendrían de variables de entorno o de un vault en lugar de estar escritos en el código, y verify apunta al certificado de la CA para que se verifique la identidad del servidor.

import os, requests
BASE = os.environ["DEVICE_URL"]  # la dirección HTTPS del dispositivo
user, password = os.environ["API_USER"], os.environ["API_PASS"]
url = BASE + "/restconf/data/ietf-interfaces:interfaces"
headers = {"Accept": "application/yang-data+json"}
resp = requests.get(url, headers=headers, auth=(user, password), verify="ca.pem")
if resp.status_code == 200:
    for intf in resp.json()["ietf-interfaces:interfaces"]["interface"]:
        print(intf["name"], intf["enabled"])

Términos clave

Variable
Un nombre ligado a un valor; Python infiere su tipo.
List (lista)
Una colección ordenada e indexada desde cero, escrita entre corchetes.
Dictionary (diccionario)
Una colección de pares clave-valor escrita entre llaves, equivalente a un objeto JSON.
Function (función)
Un bloque reutilizable definido con def que recibe parámetros y puede devolver un valor.
requests
Una biblioteca de Python para enviar solicitudes HTTP y manejar las respuestas.
Ejemplo real

Un ingeniero necesita saber cuáles de 50 switches ejecutan una imagen desactualizada. Un script corto recorre una lista de diccionarios de dispositivos, llama a la API REST del controlador para cada uno con requests.get, lee la versión de software de resp.json() e imprime los hostnames cuya versión no coincide con el estándar aprobado.

Consejo para el examen: Aprende a indexar datos anidados: resp.json()['key'][0]['name'] significa clave del diccionario, luego primer elemento de la lista, luego otra clave. Los índices de las listas empiezan en 0. response.json() convierte el cuerpo; response.status_code da el código HTTP.

Comprueba lo que sabes

Dado data = {'vlans': [10, 20, 30]}, ¿qué devuelve data['vlans'][2]?

30, porque los índices de las listas empiezan en 0.

¿Qué atributo de requests te dice si una llamada a la API tuvo éxito?

status_code, por ejemplo 200 para éxito (o llama a raise_for_status para lanzar una excepción ante errores).

¿Qué devuelve resp.json()?

El cuerpo de la respuesta convertido de JSON en diccionarios y listas de Python.
