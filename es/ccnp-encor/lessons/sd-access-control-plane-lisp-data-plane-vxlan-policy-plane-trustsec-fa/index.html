SD-Access: plano de control (LISP), plano de datos (VXLAN), plano de políticas (TrustSec), roles de los nodos del fabric

Cisco SD-Access es la solución de fabric de campus administrada por Catalyst Center (antes DNA Center). En lugar de extender VLAN a lo largo del campus y depender de spanning tree, SD-Access construye un underlay enrutado y un fabric overlay encima de él. Cada plano del fabric usa un protocolo específico, y ENCOR espera que sepas relacionarlos.

El plano de control usa LISP (Locator/ID Separation Protocol). LISP separa la identidad de un endpoint (su dirección IP o MAC, llamada EID o endpoint identifier) de su ubicación (la dirección loopback del switch al que está conectado, llamada RLOC o routing locator). Cuando un endpoint se conecta, el switch de borde registra el mapeo EID a RLOC con el nodo de plano de control, que actúa como map server y map resolver de LISP. Cuando otro switch necesita alcanzar ese endpoint, le pregunta al nodo de plano de control dónde se encuentra en lugar de inundar. Los endpoints pueden moverse entre switches y conservar su dirección IP, porque solo cambia el mapeo.

El plano de datos usa VXLAN (Virtual Extensible LAN). El tráfico entre los switches del fabric se encapsula en VXLAN sobre UDP y se transporta a través del underlay enrutado. SD-Access usa una variante llamada a menudo VXLAN-GPO (group policy option), que agrega un campo al encabezado VXLAN para transportar el Scalable Group Tag de origen. El identificador de red VXLAN (VNI) mantiene separadas las redes virtuales (que se mapean a VRF).

El plano de políticas usa Cisco TrustSec. Los usuarios y dispositivos se clasifican en Scalable Groups (por ejemplo Employees, Contractors, Cameras), normalmente mediante Cisco Identity Services Engine (ISE) durante la autenticación. Cada grupo tiene un Scalable Group Tag (SGT) que viaja con el paquete en el encabezado VXLAN. Las políticas de acceso basadas en grupos, aplicadas como SGACL (ACL de grupos escalables) en el borde de salida, deciden qué grupos pueden comunicarse. Esto da dos niveles de segmentación: macrosegmentación entre redes virtuales (VRF) y microsegmentación entre grupos dentro de una red virtual.

Los roles de los nodos del fabric son: el nodo de plano de control (control plane node), que ejecuta el map server y el map resolver de LISP; el nodo de borde (edge node), el switch de acceso donde se conectan los endpoints, que registra los endpoints y actúa como gateway predeterminado anycast para sus subredes; el nodo frontera (border node), que conecta el fabric con redes externas, con borders internos para redes conocidas como el centro de datos y borders externos como salida predeterminada, a menudo hacia internet; los nodos intermedios (intermediate nodes), switches del underlay que simplemente enrutan paquetes IP y no saben nada del fabric; y el controlador inalámbrico del fabric con access points en modo fabric, que integran lo inalámbrico en el mismo fabric. Catalyst Center es la plataforma de gestión y automatización e ISE es la plataforma de políticas e identidad. Las funciones de border y de plano de control a menudo se ubican juntas en el mismo par de switches.

Términos clave

EID
Endpoint identifier (identificador de endpoint): la dirección IP o MAC que identifica a un endpoint en LISP.
RLOC
Routing locator (localizador de enrutamiento): la dirección del underlay (normalmente una loopback) del nodo del fabric donde está conectado un endpoint.
Edge node (nodo de borde)
El switch de acceso del fabric que conecta los endpoints, los registra con el nodo de plano de control y actúa como su gateway anycast.
Border node (nodo frontera)
El nodo del fabric que conecta el fabric de SD-Access con redes externas como el centro de datos, la WAN o internet.
SGT
Scalable Group Tag: un identificador de grupo de 16 bits asignado a un usuario o dispositivo y usado para la política basada en grupos.
Ejemplo real

Una laptop del grupo Contractors se mueve del edificio 1 al edificio 3. El nuevo edge node registra el EID de la laptop con el nodo de plano de control asociado a su propio RLOC. Los demás edges consultan al nodo de plano de control, envían el tráfico VXLAN a la nueva ubicación, y el SGT de Contractors en cada paquete sigue bloqueando el acceso a los servidores del grupo Finance.

Consejo para el examen: Memoriza la tríada: plano de control LISP, plano de datos VXLAN, plano de políticas TrustSec (SGT). Los nodos intermedios son el único rol del fabric que no sabe nada del overlay.

Comprueba lo que sabes

¿Qué rol de nodo de SD-Access ejecuta el map server y el map resolver de LISP?

El nodo de plano de control (control plane node).

¿Cómo llega el SGT al punto de aplicación en SD-Access?

Viaja en línea dentro del encabezado VXLAN-GPO desde el edge node de entrada hasta el nodo de salida, que aplica la SGACL.

¿Cuál es la diferencia entre macrosegmentación y microsegmentación en SD-Access?

La macrosegmentación separa redes virtuales (VRF); la microsegmentación usa SGT para controlar el tráfico entre grupos dentro de la misma red virtual.
