Cisco CCNP Enterprise core exam (ENCOR) 350-401 v1.2

Plano de control y de datos de SD-WAN: Manager, Validator, Controllers, WAN Edges, OMP y túneles IPsec

Cisco Catalyst SD-WAN (antes Viptela) separa la WAN en planos distintos, cada uno a cargo de un componente diferente. Esta separación es lo que te permite administrar cientos de routers de sucursal como un solo fabric desde un único panel. ENCOR espera que puedas nombrar cada componente, su plano y lo que hace. Cisco renombró los componentes; verás tanto los nombres antiguos como los nuevos.

El plano de gestión es SD-WAN Manager (antes vManage). Es la interfaz gráfica y el endpoint de API donde construyes plantillas de dispositivos o grupos de configuración, defines políticas, aplicas actualizaciones de software y ves datos de monitoreo. No reenvía tráfico de usuarios.

El plano de orquestación es SD-WAN Validator (antes vBond). Es el primer punto de contacto para un WAN Edge nuevo o que se reinicia. El Validator autentica el dispositivo, le indica dónde están los Controllers y el Manager, y ayuda a los dispositivos detrás de Network Address Translation (NAT) a descubrir sus direcciones públicas para que se puedan formar los túneles. Por esa razón necesita una dirección alcanzable públicamente.

El plano de control es SD-WAN Controller (antes vSmart). Los WAN Edges establecen conexiones de control seguras Datagram Transport Layer Security (DTLS) o Transport Layer Security (TLS) hacia los Controllers e intercambian información de enrutamiento con ellos usando Overlay Management Protocol (OMP). OMP se ejecuta solo entre los WAN Edges y los Controllers, de forma muy parecida a un route reflector de BGP: los Edges anuncian sus prefijos del lado de servicio (rutas OMP), sus endpoints de transporte (rutas TLOC, por transport locators, que identifican una interfaz WAN por system IP, color y encapsulación) y rutas de servicio. El Controller aplica la política de control centralizada, por ejemplo para construir topologías hub-and-spoke, y refleja los resultados hacia los demás Edges. OMP también distribuye las claves que usan los Edges para el cifrado del plano de datos, de modo que los Edges no necesitan ejecutar un intercambio de claves con cada par.

El plano de datos son los routers WAN Edge (antes vEdge o cEdge). Se ubican en sucursales, campus y centros de datos, se conectan a uno o más transportes como MPLS, internet de banda ancha o LTE, y establecen túneles IPsec directamente entre sí a través de esos transportes. Cada interfaz de transporte se identifica con un color como mpls, biz-internet o lte. Bidirectional Forwarding Detection (BFD) se ejecuta dentro de cada túnel para medir pérdida, latencia y jitter y para detectar fallas, lo que alimenta el enrutamiento consciente de aplicaciones (application-aware routing).

Un punto de diseño importante: si los Controllers se vuelven inalcanzables, los túneles IPsec existentes y el reenvío siguen funcionando por un tiempo usando las últimas rutas y claves conocidas, porque el plano de datos es independiente del plano de control. Perder el Manager afecta solo la gestión y el monitoreo, no el reenvío.

Términos clave

SD-WAN Manager (vManage)
El plano de gestión: GUI, plantillas, definición de políticas, monitoreo y API REST.
SD-WAN Validator (vBond)
El plano de orquestación: autentica a los WAN Edges, los dirige a los controllers y asiste en el NAT traversal.
SD-WAN Controller (vSmart)
El plano de control: ejecuta OMP con los WAN Edges, aplica la política de control y distribuye rutas y claves.
OMP
Overlay Management Protocol, el protocolo de enrutamiento entre los WAN Edges y los Controllers que transporta rutas OMP, TLOC y de servicio.
TLOC
Transport locator (localizador de transporte): identifica una conexión de transporte de un WAN Edge por system IP, color y encapsulación.
Ejemplo real

Un nuevo router de sucursal arranca solo con una configuración básica de bootstrap. Contacta al Validator, se autentica con su certificado y número de serie, aprende las direcciones del Controller y del Manager, descarga su configuración desde el Manager, forma sesiones OMP con dos Controllers y luego establece túneles IPsec hacia el centro de datos a través de sus colores MPLS e internet.

Consejo para el examen: Relaciona cada componente con su plano: Manager es gestión, Validator es orquestación, Controller es control (OMP), WAN Edge es datos (IPsec más BFD). OMP nunca se ejecuta directamente entre dos WAN Edges.

Comprueba lo que sabes

¿Qué componente de SD-WAN contacta primero un WAN Edge cuando entra en línea?

El Validator (vBond), que lo autentica y le indica cómo alcanzar a los Controllers y al Manager.

¿Qué tres tipos de rutas transporta OMP?

Rutas OMP (prefijos del lado de servicio), rutas TLOC (endpoints de transporte) y rutas de servicio.

¿Qué le pasa al tráfico de usuarios si falla el SD-WAN Manager?

El reenvío continúa; solo se ven afectados la gestión, los cambios de configuración y el monitoreo, porque el Manager no está en el plano de datos ni en el de control.
