Sintaxis de JSON y análisis de JSON en Python

JSON (JavaScript Object Notation) es el formato de datos más común para las API REST, incluidas RESTCONF, Catalyst Center y SD-WAN Manager. Es texto plano, fácil de leer para las personas y de analizar para los programas. Las preguntas de ENCOR a menudo muestran un fragmento JSON y preguntan si es válido o cómo extraer un valor.

JSON tiene un conjunto pequeño de reglas. Un objeto es un conjunto no ordenado de pares clave-valor dentro de llaves {}. Las claves deben ser cadenas entre comillas dobles, seguidas de dos puntos y un valor, y los pares se separan con comas. Un arreglo (array) es una lista ordenada de valores dentro de corchetes [], separados por comas. Los valores pueden ser una cadena (siempre con comillas dobles, nunca simples), un número (sin comillas, como 10 o 1.5), un booleano (true o false, en minúsculas), null, un objeto o un arreglo. Los objetos y los arreglos pueden anidarse a cualquier profundidad.

{
  "hostname": "core-sw1",
  "managed": true,
  "uptimeDays": 142,
  "interfaces": [
    {"name": "Gi1/0/1", "vlan": 10, "status": "up"},
    {"name": "Gi1/0/2", "vlan": null, "status": "down"}
  ]
}

Errores de validez comunes que usan las preguntas del examen: comillas simples alrededor de cadenas o claves, una coma final después del último elemento de un objeto o arreglo, comas faltantes entre pares, claves sin comillas, comentarios (JSON no tiene) y True, False o None al estilo de Python en lugar de true, false y null. Los espacios en blanco y la indentación no importan para la validez.

El módulo integrado json de Python convierte entre texto JSON y objetos de Python. json.loads(text) convierte una cadena JSON en Python (loads significa load string); json.load(file) lee desde un objeto de archivo. json.dumps(obj, indent=2) convierte datos de Python en una cadena JSON, y json.dump(obj, file) escribe en un archivo. La correspondencia es: objeto a dict, arreglo a list, cadena a str, número a int o float, true y false a True y False, null a None.

import json
data = json.loads(raw_text)  # raw_text contiene el documento JSON anterior como cadena
print(data["hostname"])                 # core-sw1
print(data["interfaces"][1]["status"])   # down
up = [i["name"] for i in data["interfaces"] if i["status"] == "up"]
print(up)                               # ['Gi1/0/1']
print(json.dumps({"vlan": 10, "active": True}))  # {"vlan": 10, "active": true}

Cuando usas la biblioteca requests, response.json() hace el paso de json.loads por ti. Para navegar datos anidados, lee de afuera hacia adentro: encuentra la clave del objeto externo, fíjate si su valor es una lista (usa un índice o un bucle) u otro objeto (usa una clave), y repite. Si pides una clave que no existe, Python lanza un KeyError, y dict.get() devuelve en cambio un valor predeterminado.

Términos clave

JSON object (objeto JSON)
Pares clave-valor entre llaves con claves de cadena entre comillas dobles; corresponde a un dict de Python.
JSON array (arreglo JSON)
Una lista ordenada de valores entre corchetes; corresponde a una list de Python.
json.loads
Convierte una cadena JSON en objetos de Python.
json.dumps
Serializa objetos de Python en una cadena JSON.
null
El valor vacío de JSON, que se convierte en None en Python.
Ejemplo real

Un script que construye un payload JSON para un controlador falla con un 400 Bad Request. Al imprimir el payload, se ve que el ingeniero construyó la cadena a mano con comillas simples y una coma final. Reemplazarla con un diccionario de Python pasado por json.dumps (o el parámetro json= de requests) produce JSON válido y la llamada tiene éxito.

Consejo para el examen: El JSON válido usa solo comillas dobles, true, false y null en minúsculas, y no tiene comas finales ni comentarios. loads y dumps trabajan con cadenas; load y dump trabajan con archivos.

Comprueba lo que sabes

¿Es {'name': 'R1'} JSON válido?

No; las cadenas y las claves de JSON deben usar comillas dobles.

¿En qué tipo de Python se convierte un arreglo JSON después de json.loads?

En una list.

Dado el documento de ejemplo, ¿cómo obtienes la vlan de la primera interfaz?

data['interfaces'][0]['vlan'], que devuelve 10.
