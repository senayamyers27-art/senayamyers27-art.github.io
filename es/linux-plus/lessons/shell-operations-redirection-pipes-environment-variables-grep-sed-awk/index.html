CompTIA Linux+ XK0-006

Operaciones en el shell: redirección, tuberías, variables de entorno, grep, sed, awk, cut, sort, uniq, tr

El verdadero poder del shell de Linux viene de combinar herramientas pequeñas. Cada programa lee texto, lo transforma y escribe texto, y la redirección y las tuberías los conectan. Las preguntas basadas en desempeño de Linux+ a menudo te piden construir o interpretar una de estas líneas de comandos.

Todo proceso tiene tres flujos estándar: stdin (descriptor de archivo 0), stdout (1) y stderr (2). > redirige stdout a un archivo, sobrescribiéndolo; >> agrega al final; < alimenta stdin con un archivo. 2> redirige los errores, 2>/dev/null los descarta, y &> o > archivo 2>&1 envían tanto la salida como los errores al mismo archivo. El orden importa: cmd > out 2>&1 funciona, mientras que cmd 2>&1 > out envía los errores a la terminal. Una tubería | conecta el stdout de un comando con el stdin del siguiente, y tee archivo copia el flujo a un archivo mientras lo sigue pasando. Un here-document (<<EOF) alimenta texto en línea como entrada.

Las variables de entorno llevan configuraciones a los programas. NOMBRE=valor establece una variable del shell; export NOMBRE la convierte en una variable de entorno heredada por los procesos hijos. echo $PATH muestra la lista de directorios donde se buscan comandos, env o printenv listan el entorno y unset NOMBRE elimina una variable. Las configuraciones persistentes van en archivos de inicio: ~/.bashrc para shells interactivos, ~/.bash_profile o ~/.profile para shells de inicio de sesión, y /etc/profile o /etc/profile.d/*.sh para todos.

grep busca patrones: -i ignora mayúsculas y minúsculas, -v invierte la coincidencia, -r recorre recursivamente, -n muestra números de línea, -c cuenta coincidencias, -E habilita expresiones regulares extendidas y -w coincide con palabras completas. cut extrae campos o columnas: cut -d: -f1 /etc/passwd imprime los nombres de usuario. sort ordena líneas (-n numérico, -r inverso, -k2 por el campo 2, -h tamaños legibles), y uniq colapsa duplicados adyacentes, por eso casi siempre va después de sort; uniq -c los cuenta. tr traduce o elimina caracteres: tr 'a-z' 'A-Z' pasa a mayúsculas, tr -d '\r' quita los retornos de carro de Windows, tr -s ' ' comprime espacios repetidos.

sed es un editor de flujo. Su uso más común es la sustitución: sed 's/old/new/g' archivo imprime el archivo con cada coincidencia reemplazada, y sed -i 's/old/new/g' archivo lo edita en el lugar. sed -n '5,10p' imprime las líneas 5 a 10 y sed '/^#/d' elimina las líneas de comentario. awk procesa registros campo por campo, separando por espacios en blanco de forma predeterminada: awk '{print $1}' imprime el primer campo, awk -F: '$3 >= 1000 {print $1}' /etc/passwd lista los usuarios normales y awk '{sum += $5} END {print sum}' suma una columna.

Aquí tienes una tubería combinada clásica, que cuenta las IP de cliente más frecuentes en un log web:

awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -5

Términos clave

File descriptor (descriptor de archivo)
Un número que identifica un flujo abierto: 0 es stdin, 1 es stdout y 2 es stderr.
Pipe (tubería)
El operador | que envía la salida estándar de un comando a la entrada estándar de otro.
export
Marca una variable del shell para que se pase a los procesos hijos como variable de entorno.
sed
Un editor de flujo usado principalmente para buscar y reemplazar y para filtrar líneas; -i edita archivos en el lugar.
awk
Un lenguaje de análisis de patrones que divide las líneas en campos ($1, $2 ...) para filtrar y generar informes.
Ejemplo real

Necesitas una lista de todas las cuentas que usan bash como shell. Ejecutar grep '/bin/bash$' /etc/passwd | cut -d: -f1 | sort imprime los nombres de usuario en orden alfabético, y agregar > bash-users.txt 2>/dev/null guarda la lista mientras descarta cualquier error.

Consejo para el examen: uniq solo elimina duplicados adyacentes, así que las respuestas que envían datos sin ordenar a uniq -c suelen ser incorrectas; busca sort antes de uniq.

Comprueba lo que sabes

¿Cómo envías tanto stdout como stderr de un script de respaldo a backup.log, agregando al final?

backup.sh >> backup.log 2>&1 (o backup.sh &>> backup.log en bash).

¿Qué hace sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config?

Edita el archivo en el lugar, reemplazando en cada línea la primera aparición de 'PermitRootLogin yes' por 'PermitRootLogin no'.

¿Qué comando imprime solo el primer campo de /etc/group usando dos puntos como delimitador?

cut -d: -f1 /etc/group (o awk -F: '{print $1}' /etc/group).
