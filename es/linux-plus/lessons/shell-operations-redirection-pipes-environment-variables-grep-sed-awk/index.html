CompTIA Linux+ XK0-006

Operaciones en el shell: redirección, tuberías, variables de entorno, grep, sed, awk, cut, sort, uniq, tr

El verdadero poder del shell de Linux proviene de combinar herramientas pequeñas. Cada programa lee texto, lo transforma y escribe texto, y la redirección y las tuberías los conectan en una canalización (pipeline). Las preguntas basadas en desempeño de Linux+ a menudo te piden construir o interpretar una de estas líneas, así que léelas de izquierda a derecha y pregúntate qué recibe y qué entrega cada etapa. Todo proceso tiene tres flujos estándar: stdin (entrada estándar, descriptor de archivo 0), stdout (salida estándar, 1) y stderr (error estándar, 2). > redirige stdout a un archivo, sobrescribiéndolo; >> añade al final; < alimenta stdin con un archivo. 2> redirige los errores, 2>/dev/null los descarta, y &> o > file 2>&1 envían tanto la salida como los errores al mismo archivo. El orden importa: cmd > out 2>&1 funciona, mientras que cmd 2>&1 > out envía los errores a la terminal. Una tubería | conecta el stdout de un comando con el stdin del siguiente, y tee file copia el flujo a un archivo mientras lo sigue pasando. Un here-document (<<EOF) proporciona texto en línea como entrada.

Las variables de entorno llevan ajustes a los programas. NAME=value establece una variable del shell; export NAME la convierte en una variable de entorno que heredan los procesos hijos. echo $PATH muestra la lista de directorios donde se buscan los comandos, env o printenv listan el entorno y unset NAME elimina una variable. Los ajustes persistentes van en archivos de inicio: ~/.bashrc para shells interactivos, ~/.bash_profile o ~/.profile para shells de inicio de sesión, y /etc/profile o /etc/profile.d/*.sh para todos. Después de editar, source ~/.bashrc carga el cambio en el shell actual.

grep busca patrones: -i ignora mayúsculas y minúsculas, -v invierte la coincidencia, -r recorre de forma recursiva, -n muestra números de línea, -c cuenta las líneas que coinciden, -E habilita expresiones regulares extendidas y -w busca palabras completas. cut extrae campos o columnas: cut -d: -f1 /etc/passwd imprime los nombres de usuario. sort ordena líneas (-n numérico, -r inverso, -k2 por el campo 2, -h tamaños legibles, -u únicos), y uniq colapsa duplicados adyacentes, por eso casi siempre va después de sort; uniq -c los cuenta. tr traduce o elimina caracteres solo desde stdin: tr 'a-z' 'A-Z' pasa a mayúsculas, tr -d '\r' elimina los retornos de carro de Windows y tr -s ' ' comprime espacios repetidos.

sed es un editor de flujo. Su uso más común es la sustitución: sed 's/old/new/g' file imprime el archivo con cada coincidencia reemplazada, y sed -i 's/old/new/g' file lo edita en el lugar (añade un sufijo, como en -i.bak, para conservar un respaldo). Sin g, solo cambia la primera coincidencia de cada línea. sed -n '5,10p' imprime las líneas 5 a 10, y sed '/^#/d' elimina las líneas de comentario. awk procesa registros campo por campo, separando por espacios en blanco de forma predeterminada: awk '{print $1}' imprime el primer campo, awk -F: '$3 >= 1000 {print $1}' /etc/passwd lista los usuarios normales y awk '{sum += $5} END {print sum}' suma una columna.

# top five client IPs in a web log
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -rn | head -5

Veamos un ejemplo práctico. Necesitas una lista de todas las cuentas que usan bash como shell. grep '/bin/bash$' /etc/passwd encuentra las líneas (el $ ancla la coincidencia al final de la línea), | cut -d: -f1 conserva solo los nombres de usuario y | sort los ordena. Añadir > bash-users.txt 2>/dev/null guarda la lista y descarta cualquier error. El mismo resultado se obtiene con awk -F: '$7 == "/bin/bash" {print $1}' /etc/passwd | sort, lo que muestra cómo awk puede reemplazar el par grep y cut, ya que filtra e imprime un campo a la vez.

Errores comunes: enviar a uniq datos sin ordenar; escribir 2>&1 antes de la redirección al archivo; usar > cuando querías >> y borrar un log; olvidar export, de modo que un script hijo no ve una variable; pasar un nombre de archivo a tr (solo lee stdin, así que usa tr ... < file); y ejecutar sed -i sobre un archivo de configuración sin respaldo. Cuida también las comillas: las comillas simples impiden que el shell expanda $1 dentro de un programa awk, mientras que las comillas dobles permiten que el shell sustituya primero sus propias variables, lo que rompe el script sin avisar.

Las preguntas del examen a menudo muestran una canalización y preguntan por su salida, o describen un objetivo y preguntan qué herramienta encaja. 'Reemplazar texto en un archivo' es sed. 'Imprimir una columna o hacer aritmética con campos' es awk. 'Extraer un campo delimitado' es cut -d -f. 'Contar apariciones' es sort | uniq -c. 'Cambiar mayúsculas y minúsculas o eliminar caracteres' es tr. 'Guardar la salida y seguir viéndola' es tee. 'Descartar errores' es 2>/dev/null, y 'hacer que una variable sea visible para los procesos hijos' es export.

Términos clave

Descriptor de archivo (file descriptor)
Un número que identifica un flujo abierto: 0 es stdin, 1 es stdout y 2 es stderr.
Tubería (pipe)
El operador | que envía la salida estándar de un comando a la entrada estándar de otro.
export
Marca una variable del shell para que se pase a los procesos hijos como variable de entorno.
tee
Copia su entrada estándar a un archivo y a la salida estándar al mismo tiempo.
sed
Un editor de flujo que se usa principalmente para buscar y reemplazar y para filtrar líneas; -i edita archivos en el lugar.
awk
Un lenguaje de búsqueda de patrones que divide las líneas en campos ($1, $2 ...) para filtrar y generar informes.
Ejemplo real

Necesitas una lista de todas las cuentas que usan bash como shell. Ejecutar grep '/bin/bash$' /etc/passwd | cut -d: -f1 | sort imprime los nombres de usuario en orden alfabético, y añadir > bash-users.txt 2>/dev/null guarda la lista y descarta cualquier error. Adjuntas el archivo a un ticket de revisión de accesos.

Consejo para el examen: uniq solo elimina duplicados adyacentes, así que las respuestas que envían datos sin ordenar a uniq -c suelen ser incorrectas; busca sort antes de uniq.

Comprueba lo que sabes

¿Cómo envías tanto stdout como stderr de un script de respaldo a backup.log, añadiendo al final?

backup.sh >> backup.log 2>&1 (o backup.sh &>> backup.log en bash); el 2>&1 debe ir después de la redirección al archivo.

¿Qué hace sed -i 's/PermitRootLogin yes/PermitRootLogin no/' /etc/ssh/sshd_config?

Edita el archivo en el lugar, reemplazando en cada línea la primera aparición de 'PermitRootLogin yes' por 'PermitRootLogin no'.

¿Qué comando imprime solo el primer campo de /etc/group usando dos puntos como delimitador?

cut -d: -f1 /etc/group (o awk -F: '{print $1}' /etc/group).

Una variable que estableciste en tu shell está vacía dentro de un script que ejecutas. ¿Qué faltó?

export; sin él, la variable es solo una variable del shell y no se pasa a los procesos hijos.
