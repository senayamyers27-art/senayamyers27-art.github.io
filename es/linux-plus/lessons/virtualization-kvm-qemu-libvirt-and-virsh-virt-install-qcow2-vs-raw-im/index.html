CompTIA Linux+ XK0-006

Virtualización: KVM/QEMU, libvirt y virsh, virt-install, imágenes qcow2 vs raw

La virtualización permite que un solo host físico ejecute varios sistemas operativos aislados, llamados invitados o VM (máquinas virtuales). En Linux, la pila estándar de código abierto es KVM, QEMU y libvirt. Linux+ espera que sepas qué hace cada capa, que administres invitados desde la línea de comandos y que elijas un formato de imagen de disco. También ayuda tener clara la diferencia con los contenedores: una VM ejecuta su propio kernel sobre hardware virtual, mientras que un contenedor comparte el kernel del host.
