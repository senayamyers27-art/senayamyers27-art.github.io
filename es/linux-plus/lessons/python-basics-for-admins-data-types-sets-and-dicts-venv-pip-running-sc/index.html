CompTIA Linux+ XK0-006

Fundamentos de Python para administradores: tipos de datos, sets y dicts, venv, pip, ejecución de scripts

Bash es ideal para unir comandos, pero cuando una tarea implica datos estructurados, API o una lógica más compleja, Python suele ser más fácil de escribir y mantener. Linux+ espera Python a nivel de administrador: leer código básico, elegir tipos de datos, administrar paquetes y ejecutar scripts.

Los tipos básicos de Python son int (números enteros), float (decimales), str (texto, entre comillas simples o dobles), bool (True o False) y None (sin valor). Las variables se crean por asignación y tienen tipado dinámico, así que port = 22 crea un int. Convierte con int('22'), str(22) y float(). Las f-strings dan formato al texto: f'{host} uses port {port}'. La sangría, por convención de cuatro espacios, define los bloques de código, así que una sangría inconsistente es un error de sintaxis, no un asunto de estilo.

Las colecciones son donde Python brilla. Una lista es una secuencia ordenada y modificable: hosts = ['web01', 'web02'], con hosts.append('db01'), hosts[0] y rebanadas (slicing) como hosts[1:]. Una tupla es una secuencia ordenada pero inmutable: ('10.0.0.1', 22). Un set (conjunto) es una colección desordenada de elementos únicos, ideal para eliminar duplicados y comparar grupos: set(ips) elimina duplicados, y a - b (diferencia), a & b (intersección) y a | b (unión) responden preguntas como 'qué usuarios existen en el servidor A pero no en el B'. Las pruebas de pertenencia con in son rápidas en los sets. Un diccionario (dict) asocia claves con valores: ports = {'ssh': 22, 'https': 443}, se lee con ports['ssh'] o con ports.get('ftp', 0) para evitar un error cuando falta una clave, y se recorre con for name, num in ports.items():. Los datos JSON de las API se corresponden de forma natural con dicts y listas mediante el módulo json.

El control de flujo se lee como en Bash, pero con dos puntos y sangría: if/elif/else, for item in collection:, while condition:, y funciones con def name(args): y return. Maneja los errores con try:/except FileNotFoundError: en lugar de dejar que el script se caiga. Los módulos útiles de la biblioteca estándar para administradores incluyen os y pathlib (archivos y rutas), subprocess (ejecutar comandos, preferiblemente con una lista de argumentos en lugar de shell=True para evitar inyecciones), sys (argumentos en sys.argv, códigos de salida con sys.exit(1)), json, re (expresiones regulares), logging y argparse (opciones de línea de comandos).

Un entorno virtual aísla los paquetes de un proyecto del Python del sistema y de otros proyectos. python3 -m venv .venv crea uno, source .venv/bin/activate lo activa (tu prompt cambia) y deactivate sale de él. Mientras está activo, pip install requests instala solo en el venv. pip freeze > requirements.txt registra las versiones exactas y pip install -r requirements.txt las recrea en otro lugar. Instalar paquetes en el Python del sistema con sudo puede romper herramientas de la distribución que dependen de él, por eso muchas distribuciones ahora lo bloquean.

Ejecuta un script con python3 script.py, o agrega un shebang #!/usr/bin/env python3, hazlo ejecutable y ejecuta ./script.py. Para un script específico de un venv, apunta el shebang o el comando a .venv/bin/python. La protección común if __name__ == '__main__': ejecuta el código principal solo cuando el archivo se ejecuta directamente, no cuando se importa. python3 -m module ejecuta un módulo como script, y python3 solo abre un prompt interactivo para experimentos rápidos.

Términos clave

list vs tuple (lista vs tupla)
Una lista es una secuencia ordenada y mutable; una tupla es ordenada pero inmutable.
set (conjunto)
Una colección desordenada de elementos únicos que admite unión, intersección y diferencia.
dict (diccionario)
Una asociación de claves únicas con valores, como {'ssh': 22}.
venv
La herramienta integrada de Python para crear entornos virtuales aislados con sus propios paquetes.
requirements.txt
Un archivo que lista las versiones de los paquetes para que pip pueda reproducir un entorno.
Ejemplo real

Debes encontrar las cuentas presentes en el antiguo servidor de archivos pero ausentes en el nuevo. Un script corto de Python lee los nombres de usuario de la salida de getent passwd de cada servidor en dos sets e imprime sorted(old - new). Ejecutarlo desde un venv con el paquete paramiko instalado le permite reunir ambas listas por SSH en un solo paso.

Consejo para el examen: Elige el tipo de datos según la necesidad: un set para unicidad y comparaciones, un dict para búsquedas por clave-valor, una lista cuando importan el orden y los duplicados.

Comprueba lo que sabes

¿Qué tipo de Python elimina automáticamente las direcciones IP duplicadas de una lista?

Un set, por ejemplo set(ip_list).

¿Cómo creas y activas un entorno virtual llamado .venv?

python3 -m venv .venv y luego source .venv/bin/activate.

¿Por qué usar subprocess.run(['ls', path]) en lugar de subprocess.run('ls ' + path, shell=True)?

Pasar una lista de argumentos evita el shell, así que los caracteres especiales en path no pueden inyectar comandos adicionales.
