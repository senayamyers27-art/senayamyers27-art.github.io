CompTIA Cloud+ CV0-004

Identidades de carga de trabajo: roles de instancia, identidades gestionadas y cuentas de servicio en lugar de claves almacenadas

Las aplicaciones también necesitan llamar a las API de la nube: un servidor web lee de un almacenamiento de objetos, una función escribe en una cola, una canalización despliega infraestructura. La forma antigua era crear un usuario, generar una clave de acceso de larga duración y ponerla en un archivo de configuración o una variable de entorno. Esas claves se filtran constantemente, a través de código subido a repositorios públicos, imágenes de contenedor, registros y copias de seguridad, y a menudo siguen siendo válidas durante años.
