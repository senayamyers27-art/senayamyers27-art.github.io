OSPFv2 de área única: vecinos y adyacencias, redes punto a punto vs broadcast, elección de DR/BDR

OSPF (Open Shortest Path First) es un protocolo de enrutamiento de estado de enlace de estándar abierto. OSPFv2 transporta rutas IPv4. En lugar de pasar tablas de enrutamiento completas entre vecinos, cada router OSPF describe sus propios enlaces en anuncios de estado de enlace (LSA), los inunda para que todos los routers del área tengan una base de datos de estado de enlace (LSDB) idéntica, y ejecuta el algoritmo shortest path first (SPF) para calcular las mejores rutas. En un diseño de área única, todos los routers están en el área 0, el backbone.

Los routers OSPF se descubren entre sí enviando paquetes hello a la dirección multicast 224.0.0.5 por cada interfaz con OSPF habilitado. En redes broadcast y punto a punto, el intervalo hello predeterminado es de 10 segundos y el intervalo dead, cuánto esperar antes de declarar caído a un vecino, es de 40 segundos. Una relación de vecindad pasa por varios estados: Down, Init (escuché tu hello), 2-Way (nos vemos mutuamente en nuestros hellos), ExStart y Exchange (acordamos maestro/esclavo e intercambiamos resúmenes de la base de datos), Loading (pido los LSA que me faltan) y Full (nuestras bases de datos están sincronizadas). Un router que está en Full con un vecino tiene una adyacencia con él.

El tipo de red cambia lo que ocurre. En un enlace punto a punto, como un enlace serial o un enlace Ethernet configurado con ip ospf network point-to-point, solo hay dos routers, así que simplemente se vuelven totalmente adyacentes. En una red broadcast de acceso múltiple como Ethernet, que es el tipo predeterminado de las interfaces Ethernet, muchos routers pueden compartir el segmento. Si cada router formara una adyacencia completa con todos los demás, la inundación escalaría mal. Por eso OSPF elige un router designado (DR) y un router designado de respaldo (BDR).

En un segmento broadcast, cada router forma una adyacencia completa solo con el DR y el BDR. Los routers que no son ninguno de los dos, llamados DROTHER, permanecen en estado 2-Way entre sí, lo cual es normal y no es una falla. Los DROTHER envían las actualizaciones al DR y al BDR en 224.0.0.6, y el DR las vuelve a inundar a todos en 224.0.0.5. El BDR toma el control si el DR falla.

La elección del DR usa primero la prioridad OSPF de la interfaz: gana la prioridad más alta, 1 de forma predeterminada, con un rango de 0 a 255, y la prioridad 0 significa que el router nunca puede ser DR ni BDR. Si las prioridades empatan, gana el router ID más alto. El segundo mejor se convierte en BDR. La elección no es preferente (non-preemptive): una vez elegido un DR, un router nuevo con mayor prioridad no toma el control hasta que el DR falle o se reinicie el proceso OSPF. Por eso los primeros routers en arrancar suelen terminar como DR. Configura la prioridad con ip ospf priority 100 en la interfaz.

Verifica con show ip ospf neighbor, que lista el router ID de cada vecino, su prioridad, su estado como FULL/DR, FULL/BDR, FULL/- (punto a punto) o 2WAY/DROTHER, el tiempo dead, la dirección y la interfaz. show ip ospf interface g0/0 muestra el tipo de red, el DR, el BDR, los temporizadores y el costo.

Términos clave

Link-state advertisement, LSA (anuncio de estado de enlace)
Una unidad de datos OSPF que describe los enlaces de un router, inundada para construir la base de datos de estado de enlace.
Adjacency (adyacencia)
Una relación de vecindad que alcanzó el estado Full con las bases de datos sincronizadas.
DR / BDR
El router designado y el router designado de respaldo elegidos en un segmento de acceso múltiple para reducir la inundación.
DROTHER
Un router en un segmento broadcast que no es DR ni BDR; permanece en 2-Way con los demás DROTHER.
OSPF priority (prioridad OSPF)
Valor de la interfaz (1 de forma predeterminada) que se usa primero en la elección de DR/BDR; 0 significa que nunca es elegible.
Ejemplo real

Cuatro routers comparten una VLAN Ethernet. En R4, show ip ospf neighbor muestra a R1 como FULL/DR, a R2 como FULL/BDR y a R3 como 2WAY/DROTHER. Un ingeniero junior cree que R3 está fallando, pero es normal: los DROTHER solo forman una relación completa con el DR y el BDR. Entre R1 y R5, sobre un enlace punto a punto, el estado es FULL/- sin elección.

Consejo para el examen: 2WAY/DROTHER entre dos routers que no son DR es lo esperado. Un vecino atascado en INIT, EXSTART o EXCHANGE es la verdadera señal de un problema.

Comprueba lo que sabes

¿Cuál es el tipo de red OSPF predeterminado en Ethernet y qué provoca?

Broadcast, que desencadena una elección de DR y BDR en el segmento.

R1 tiene prioridad 1 y router ID 5.5.5.5; R2 tiene prioridad 10 y router ID 1.1.1.1. ¿Cuál se convierte en DR si ambos arrancan a la vez?

R2, porque la prioridad se compara antes que el router ID y 10 es mayor que 1.

Un router nuevo con prioridad 200 se une a un segmento que ya tiene un DR. ¿Toma el control?

No. La elección del DR no es preferente; solo se convierte en DR después de que fallen el DR y el BDR actuales o se reinicie OSPF.
