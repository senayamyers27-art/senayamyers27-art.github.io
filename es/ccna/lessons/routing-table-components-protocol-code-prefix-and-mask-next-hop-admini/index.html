Cisco CCNA 200-301 v2.0

Componentes de la tabla de enrutamiento: código de protocolo, prefijo y máscara, siguiente salto, distancia administrativa, métrica, gateway of last resort

Un router reenvía paquetes buscando el destino en su tabla de enrutamiento. Leer esa tabla con soltura es una de las habilidades más evaluadas del CCNA, porque casi todas las preguntas de enrutamiento empiezan con una salida de show ip route. Cada línea te dice de dónde vino una ruta, qué destino cubre, qué tan confiable y qué tan buena es, y a dónde enviar los paquetes.

Considera esta entrada: O 10.1.3.0/24 [110/3] via 10.0.12.2, 00:05:12, GigabitEthernet0/1. El primer campo es el código de protocolo, aquí O para OSPF. Otros códigos son C para conectada, L para local, S para estática, D para EIGRP, R para RIP, B para BGP, y un asterisco marca una ruta predeterminada candidata. También aparecen modificadores como O IA (OSPF inter-área) u O E2 (OSPF externa tipo 2).

Después viene el prefijo de destino y la máscara, aquí 10.1.3.0/24. El router compara los destinos de los paquetes con ellos. Cada interfaz configurada y activa produce dos entradas: una ruta C para la subred conectada y una ruta L para la propia dirección de la interfaz como ruta de host /32 (o /128 en IPv6).

El par entre corchetes es [distancia administrativa/métrica]. La distancia administrativa (AD) mide qué tan confiable es el origen de la ruta y se usa para elegir entre rutas hacia el mismo prefijo aprendidas de distintos orígenes. Se prefiere la más baja. Valores predeterminados comunes de Cisco: conectada 0, estática 1, eBGP 20, EIGRP 90, OSPF 110, RIP 120, EIGRP externa 170 e iBGP 200. Una AD de 255 significa que la ruta no es confiable y nunca se instala. La métrica es la medida propia del protocolo de enrutamiento sobre la calidad del camino, y se usa para elegir entre rutas del mismo protocolo: OSPF usa el costo, RIP el número de saltos y EIGRP una métrica compuesta basada en el ancho de banda y el retardo. Las métricas de protocolos distintos no se pueden comparar, y justamente por eso existe la AD.

Después de 'via' viene el siguiente salto (next hop), la dirección del router vecino al que se reenvía. Luego la antigüedad de la ruta y la interfaz de salida. Las rutas conectadas muestran 'is directly connected' y una interfaz en lugar de un siguiente salto. Las rutas estáticas pueden mostrar solo un siguiente salto, solo una interfaz o ambos.

Arriba, 'Gateway of last resort' muestra la ruta predeterminada, que se usa cuando no coincide nada más específico. Si dice 'Gateway of last resort is not set', los paquetes sin ruta coincidente se descartan y el router envía un ICMP unreachable. Una ruta predeterminada aparece como S* 0.0.0.0/0 [1/0] via 203.0.113.1 o como una ruta aprendida por OSPF O*E2 0.0.0.0/0. El equivalente en IPv6 es show ipv6 route, donde la ruta predeterminada es ::/0 y los siguientes saltos suelen ser direcciones link-local.

Términos clave

Administrative distance, AD (distancia administrativa)
Un valor que califica la confiabilidad del origen de una ruta; gana la más baja cuando el mismo prefijo se aprende de distintos orígenes.
Metric (métrica)
La medida de la calidad del camino de un protocolo de enrutamiento, usada para comparar rutas de ese mismo protocolo.
Next hop (siguiente salto)
La dirección del router vecino al que se reenvía un paquete para una ruta dada.
Local route, L (ruta local)
Una ruta de host /32 para la propia dirección de interfaz del router.
Gateway of last resort
La ruta predeterminada que se usa cuando ninguna ruta más específica coincide con un destino.
Ejemplo real

show ip route en R1 lista S* 0.0.0.0/0 [1/0] via 203.0.113.1, C 10.0.12.0/30 is directly connected, G0/1, L 10.0.12.1/32 is directly connected, G0/1 y O 10.1.3.0/24 [110/3] via 10.0.12.2. Puedes leer que R1 llega a 10.1.3.0/24 por OSPF con costo 3 a través de R2, y envía el tráfico de internet al ISP mediante una ruta predeterminada estática.

Consejo para el examen: En [110/3], el primer número es la AD y el segundo la métrica. Las preguntas suelen invertirlos en las opciones de respuesta.

Comprueba lo que sabes

Un router aprende 172.16.5.0/24 por OSPF y por EIGRP. ¿Cuál instala y por qué?

La ruta EIGRP, porque la distancia administrativa de EIGRP (90) es menor que la de OSPF (110).

¿Qué implica 'Gateway of last resort is not set'?

Que no hay ruta predeterminada, así que los paquetes hacia destinos que no están en la tabla se descartan.

¿Por qué cada interfaz configurada crea una ruta C y una ruta L?

C es la subred directamente conectada; L es una ruta de host /32 para la propia IP de la interfaz, para que el router reconozca los paquetes dirigidos a sí mismo.
