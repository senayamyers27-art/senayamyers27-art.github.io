VPN: IPsec site-to-site vs acceso remoto

Una red privada virtual (VPN) crea un túnel seguro a través de una red no confiable, normalmente internet, para que el tráfico sea privado y esté protegido contra alteraciones. Las VPN dan a las organizaciones la seguridad de una WAN privada al costo de la conectividad a internet. El CCNA distingue dos usos principales: conectar sitios completos y conectar usuarios individuales.

Una VPN site-to-site (de sitio a sitio) enlaza dos redes, como una sucursal y la oficina central. Los gateways VPN, normalmente routers o firewalls en cada sitio, construyen un túnel permanente entre ellos. Los hosts de cada sitio envían el tráfico normalmente a su gateway predeterminado y no saben que existe la VPN; el gateway cifra el tráfico destinado al otro sitio, lo envía a través de internet y el gateway remoto lo descifra. No se necesita software en los dispositivos finales.

Las VPN site-to-site normalmente usan IPsec, un marco de protocolos. IKE (Internet Key Exchange) negocia los parámetros de seguridad y autentica a los pares, usando claves precompartidas o certificados, y crea las claves. Luego ESP (Encapsulating Security Payload, protocolo IP 50) proporciona confidencialidad mediante cifrado, integridad mediante hashing y autenticación del origen. AH (Authentication Header, protocolo IP 51) proporciona integridad y autenticación pero no cifrado, así que en la práctica verás ESP. En el modo túnel, que se usa entre gateways, se cifra todo el paquete original y se agrega un nuevo encabezado IP con las direcciones de los gateways; el modo transporte protege solo la carga útil y se usa entre dos hosts. IPsec simple no transporta multicast, así que los protocolos de enrutamiento a través del túnel normalmente requieren GRE sobre IPsec o interfaces de túnel virtuales. Cisco DMVPN construye dinámicamente muchos túneles de sucursales en un diseño hub-and-spoke.

Una VPN de acceso remoto conecta el dispositivo de un usuario individual con la red de la organización, normalmente para teletrabajadores y personas que viajan. El usuario ejecuta un cliente VPN en su laptop o teléfono, como Cisco Secure Client (antes AnyConnect), que se conecta a un headend (concentrador) VPN, normalmente un firewall. Las VPN de acceso remoto suelen usar TLS (la misma protección que HTTPS) o IPsec con IKEv2. Las VPN sin cliente (clientless), en las que el usuario accede a aplicaciones web internas seleccionadas mediante un navegador sobre TLS, son otra forma. El usuario se autentica, a menudo con autenticación multifactor a través de RADIUS o similar, y recibe una dirección interna.

Los diseños de acceso remoto también eligen entre full tunnel (túnel completo), donde todo el tráfico del usuario pasa por la VPN, y split tunnel (túnel dividido), donde solo el tráfico hacia las redes corporativas usa el túnel y el tráfico de internet sale directamente. El túnel completo da más inspección y control; el túnel dividido reduce la carga en el headend.

Para compararlas en el examen: site-to-site está siempre activa, conecta redes, es invisible para los usuarios y usa dispositivos gateway en ambos extremos. El acceso remoto es bajo demanda, conecta un dispositivo, requiere software cliente o un navegador del lado del usuario, y lo inicia el usuario.

Términos clave

Site-to-site VPN (VPN de sitio a sitio)
Un túnel permanente entre gateways que conecta redes completas, transparente para los hosts finales.
Remote-access VPN (VPN de acceso remoto)
Un túnel bajo demanda desde el dispositivo de un usuario individual hacia un headend VPN.
IPsec
Un marco de protocolos (IKE, ESP, AH) que proporciona confidencialidad, integridad y autenticación para el tráfico IP.
ESP
Encapsulating Security Payload, protocolo IP 50, que cifra y autentica el tráfico IPsec.
Split tunnel (túnel dividido)
Una configuración de acceso remoto en la que solo el tráfico hacia la red corporativa usa la VPN y el resto del tráfico va directamente a internet.
Ejemplo real

Una cadena minorista conecta 30 tiendas con su centro de datos mediante túneles IPsec site-to-site en el router de cada tienda, así que las terminales de punto de venta llegan a los servidores de pago sin ningún software cliente. Sus compradores, que viajan, usan un cliente VPN de acceso remoto en sus laptops que se autentica con MFA contra un firewall en la oficina central.

Consejo para el examen: Si el escenario menciona software cliente, usuarios individuales o teletrabajadores, elige acceso remoto. Si menciona conectar oficinas con dispositivos en ambos extremos y sin intervención del usuario, elige IPsec site-to-site.

Comprueba lo que sabes

¿Qué protocolo de IPsec proporciona cifrado?

ESP (Encapsulating Security Payload). AH proporciona integridad y autenticación, pero no cifrado.

¿Los hosts de una sucursal necesitan software VPN para usar una VPN site-to-site?

No. Los gateways se encargan del cifrado; los hosts envían el tráfico normalmente.

¿Qué es una VPN de acceso remoto con split tunnel?

Solo el tráfico destinado a las redes corporativas pasa por el túnel; el resto del tráfico de internet sale directamente del dispositivo.
