Enrutamiento estático IPv4 e IPv6: rutas estáticas predeterminadas, de red, de host y flotantes

Una ruta estática es una ruta que configuras a mano. Las rutas estáticas son predecibles, no consumen ancho de banda ni CPU en actualizaciones de rutas y no revelan nada a los vecinos, así que son adecuadas para redes pequeñas, sitios stub con una sola salida y caminos de respaldo. Su debilidad es que no se adaptan: si la topología cambia, debes cambiarlas tú.

La sintaxis IPv4 es ip route <prefix> <mask> <next-hop | exit-interface> [AD]. Con una dirección de siguiente salto, el router hace una búsqueda recursiva para encontrar la interfaz que llega a ese siguiente salto. Con solo una interfaz de salida, la ruta aparece como directamente conectada; esto funciona bien en enlaces punto a punto, pero en Ethernet hace que el router haga ARP para cada destino, así que es mejor usar un siguiente salto o ambos: ip route 10.2.0.0 255.255.0.0 g0/1 10.0.12.2, una ruta estática totalmente especificada.

Hay cuatro tipos que debes conocer. Una ruta de red apunta a una subred, como ip route 192.168.20.0 255.255.255.0 10.0.12.2. Una ruta de host apunta a una sola dirección con máscara /32: ip route 192.168.20.50 255.255.255.255 10.0.13.2, útil para enviar el tráfico hacia un servidor por un camino concreto. Una ruta predeterminada coincide con todo usando 0.0.0.0 0.0.0.0 y se convierte en el gateway of last resort: ip route 0.0.0.0 0.0.0.0 203.0.113.1. Una sucursal con un solo enlace WAN a menudo solo necesita una ruta predeterminada.

Una ruta estática flotante (floating static route) es un respaldo. La configuras con una distancia administrativa mayor que la de la ruta principal, así que queda fuera de la tabla de enrutamiento mientras exista la principal. Por ejemplo, si OSPF (AD 110) proporciona el camino principal hacia la oficina central, ip route 10.0.0.0 255.0.0.0 172.31.1.1 120 se ignora hasta que desaparezca la ruta OSPF, y entonces se instala. Para respaldar una ruta estática principal (AD 1), dale a la ruta flotante cualquier AD mayor que 1. La ruta flotante debe tener una AD mayor que la principal; de lo contrario, la reemplazaría.

Las rutas estáticas IPv6 funcionan igual con ipv6 route. Primero habilita ipv6 unicast-routing. Ejemplos: una ruta de red ipv6 route 2001:db8:acad:2::/64 2001:db8:0:12::2, una ruta de host con /128, y una ruta predeterminada ipv6 route ::/0 2001:db8:0:12::2. Si usas una dirección link-local como siguiente salto, también debes especificar la interfaz de salida, porque la misma dirección fe80 puede existir en cada enlace: ipv6 route ::/0 g0/0 fe80::2.

Verifica con show ip route static y show ipv6 route static, y prueba el camino con ping y traceroute. Una ruta estática cuyo siguiente salto es inalcanzable, o cuya interfaz de salida está caída, se elimina de la tabla. Recuerda que el enrutamiento debe funcionar en ambos sentidos: el router remoto también necesita una ruta de regreso hacia tus redes.

Términos clave

Default route (ruta predeterminada)
Una ruta hacia 0.0.0.0/0 (o ::/0) que coincide con cualquier destino que no coincida con otra ruta.
Host route (ruta de host)
Una ruta hacia una sola dirección, con máscara /32 en IPv4 o /128 en IPv6.
Floating static route (ruta estática flotante)
Una ruta estática de respaldo configurada con una AD mayor que la principal, que solo se instala cuando la principal desaparece.
Fully specified static route (ruta estática totalmente especificada)
Una ruta estática que incluye tanto la interfaz de salida como la dirección del siguiente salto.
Recursive lookup (búsqueda recursiva)
Buscar el siguiente salto de una ruta estática en la tabla de enrutamiento para encontrar la interfaz de salida.
Ejemplo real

Un router de sucursal usa OSPF sobre un circuito MPLS y tiene una VPN por banda ancha como respaldo. El ingeniero agrega ip route 0.0.0.0 0.0.0.0 198.51.100.1 250. Mientras OSPF proporcione una ruta predeterminada (AD 110), la estática permanece oculta. Cuando falla el enlace MPLS y OSPF retira su ruta, show ip route muestra S* 0.0.0.0/0 [250/0] via 198.51.100.1 y el tráfico continúa por la banda ancha.

Consejo para el examen: Una ruta estática flotante debe tener una AD mayor que la ruta que respalda. Si una opción del examen usa un valor menor, reemplazaría a la ruta principal en lugar de respaldarla.

Comprueba lo que sabes

Escribe una ruta predeterminada IPv4 hacia el siguiente salto 203.0.113.1.

ip route 0.0.0.0 0.0.0.0 203.0.113.1

¿Por qué una ruta estática IPv6 que usa un siguiente salto link-local debe incluir una interfaz de salida?

Las direcciones link-local solo son únicas por enlace, así que el router necesita la interfaz para saber en qué enlace está el siguiente salto.

OSPF es el camino principal hacia 10.0.0.0/8. ¿Qué AD haría que una ruta estática fuera un respaldo funcional?

Cualquier AD mayor que 110, como 120 o 200, para que la ruta estática quede fuera de la tabla hasta que desaparezca la ruta de OSPF.
