Enrutamiento estático IPv4 e IPv6: rutas estáticas predeterminadas, de red, de host y flotantes

Una ruta estática es una ruta que configuras a mano. Las rutas estáticas son predecibles, no consumen ancho de banda ni CPU en actualizaciones de rutas y no revelan nada a los vecinos, así que son adecuadas para redes pequeñas, sitios stub con una sola salida y caminos de respaldo. Su debilidad es que no se adaptan: si la topología cambia, debes modificarlas tú mismo, y un error puede pasar inadvertido hasta que el tráfico falla. El CCNA espera que sepas escribirlas, leerlas y solucionar sus problemas tanto en IPv4 como en IPv6.

La sintaxis de IPv4 es ip route <prefix> <mask> <next-hop | exit-interface> [distance]. Con una dirección de siguiente salto, el router realiza una búsqueda recursiva para encontrar la interfaz que llega a ese siguiente salto. Con solo una interfaz de salida, la ruta aparece como directamente conectada; eso funciona bien en enlaces seriales punto a punto, pero en Ethernet hace que el router haga ARP (Address Resolution Protocol) por cada destino y dependa del proxy ARP del vecino. Es mejor usar un siguiente salto, o ambos, como en la ruta completamente especificada ip route 10.2.0.0 255.255.0.0 g0/1 10.0.12.2.

Hay cuatro tipos que debes conocer. Una ruta de red apunta a una subred, como ip route 192.168.20.0 255.255.255.0 10.0.12.2. Una ruta de host apunta a una sola dirección con máscara /32, como ip route 192.168.20.50 255.255.255.255 10.0.13.2, útil para dirigir el tráfico hacia un servidor por un camino particular. Una ruta predeterminada coincide con todo usando 0.0.0.0 0.0.0.0 y se convierte en el gateway of last resort: ip route 0.0.0.0 0.0.0.0 203.0.113.1. Una sucursal con un solo enlace WAN a menudo no necesita nada más. Una ruta estática flotante es un respaldo, configurado con una distancia administrativa (AD) mayor que la de la ruta principal, de modo que queda fuera de la tabla de enrutamiento mientras exista la principal.

Por ejemplo, si OSPF (Open Shortest Path First, AD 110) proporciona el camino principal hacia la oficina central, ip route 10.0.0.0 255.0.0.0 172.31.1.1 120 permanece oculta hasta que desaparece la ruta OSPF, y entonces se instala. Para respaldar una ruta estática principal (AD 1), dale a la ruta flotante cualquier AD mayor que 1. Una ruta flotante con una AD menor que la principal la reemplazaría en lugar de respaldarla. Ten en cuenta que una ruta estática se elimina cuando su interfaz de salida se cae, pero una ruta con solo siguiente salto sobre Ethernet puede seguir instalada si el enlace sigue activo aunque el siguiente salto haya fallado, y esa es una de las razones por las que se usan protocolos dinámicos o seguimiento (tracking) para las conmutaciones por falla importantes.

Las rutas estáticas IPv6 funcionan de la misma manera con ipv6 route, después de habilitar ipv6 unicast-routing. Ejemplos: una ruta de red ipv6 route 2001:db8:acad:2::/64 2001:db8:0:12::2, una ruta de host con /128, una ruta predeterminada ipv6 route ::/0 2001:db8:0:12::2 y una estática flotante agregando una distancia al final. Si usas una dirección link-local como siguiente salto, también debes especificar la interfaz de salida, porque la misma dirección fe80 puede existir en cada enlace: ipv6 route ::/0 g0/0 fe80::2.

Veamos un ejemplo práctico. Un router de sucursal usa OSPF sobre un circuito MPLS (Multiprotocol Label Switching) y tiene una VPN (red privada virtual) sobre banda ancha como respaldo. El ingeniero agrega ip route 0.0.0.0 0.0.0.0 198.51.100.1 250. Mientras OSPF proporciona una ruta predeterminada con AD 110, la estática permanece oculta y show ip route static no muestra nada. Cuando falla el enlace MPLS y OSPF retira su ruta, show ip route muestra S* 0.0.0.0/0 [250/0] via 198.51.100.1 y el tráfico continúa por la banda ancha. Cuando MPLS vuelve, regresa la ruta predeterminada de OSPF y la estática vuelve a quedar fuera de la tabla.

Errores comunes: darle a una estática flotante una AD menor que la principal; escribir la máscara como longitud de prefijo en IPv4 (IOS necesita notación decimal con puntos); apuntar el siguiente salto a la dirección de tu propia interfaz; omitir la interfaz de salida con un siguiente salto IPv6 link-local; y olvidar el camino de regreso. El enrutamiento debe funcionar en ambas direcciones, así que el router remoto necesita una ruta de vuelta hacia tus redes. Verifica con show ip route static, show ipv6 route static, ping y traceroute.

Las preguntas del examen usan una redacción constante. 'Red stub con una sola salida' apunta a una ruta estática predeterminada. 'Ruta hacia un solo servidor' es una ruta de host con /32 o /128. 'Ruta de respaldo que se usa solo cuando falla la principal' es una estática flotante con una AD mayor. 'Incluye tanto la interfaz como el siguiente salto' es completamente especificada. 'Siguiente salto link-local' requiere una interfaz de salida. 'El ping funciona solo en un sentido' sugiere que falta una ruta de regreso.

Términos clave

Ruta predeterminada (default route)
Una ruta hacia 0.0.0.0/0 (o ::/0) que coincide con cualquier destino que no coincida con otra ruta.
Ruta de red (network route)
Una ruta estática hacia una subred completa, como 192.168.20.0/24.
Ruta de host (host route)
Una ruta hacia una sola dirección, con máscara /32 en IPv4 o /128 en IPv6.
Ruta estática flotante (floating static route)
Una ruta estática de respaldo configurada con una AD mayor que la principal, que se instala solo cuando la principal desaparece.
Ruta estática completamente especificada (fully specified static route)
Una ruta estática que incluye tanto la interfaz de salida como la dirección del siguiente salto.
Búsqueda recursiva (recursive lookup)
Buscar en la tabla de enrutamiento el siguiente salto de una ruta estática para encontrar la interfaz de salida.
Ejemplo real

El router de una oficina pequeña tiene un enlace a internet y una LAN interna, así que la ingeniera configura solo ip route 0.0.0.0 0.0.0.0 203.0.113.1 e ipv6 route ::/0 g0/0 fe80::1 hacia el proveedor. Un grabador de cámaras de seguridad en la oficina central siempre debe usar el enlace WAN privado, así que agrega una ruta de host, ip route 10.8.8.20 255.255.255.255 172.31.0.2, que la coincidencia más larga prefiere sobre la predeterminada.

Consejo para el examen: Una estática flotante debe tener una AD mayor que la ruta que respalda. Si una opción del examen usa un valor menor, reemplazaría a la ruta principal en lugar de respaldarla.

Comprueba lo que sabes

Escribe una ruta predeterminada IPv4 hacia el siguiente salto 203.0.113.1.

ip route 0.0.0.0 0.0.0.0 203.0.113.1

¿Por qué una ruta estática IPv6 que usa un siguiente salto link-local debe incluir una interfaz de salida?

Las direcciones link-local solo son únicas por enlace, así que el router necesita la interfaz para saber en qué enlace está el siguiente salto.

OSPF es el camino principal hacia 10.0.0.0/8. ¿Qué AD haría que una ruta estática funcione como respaldo?

Cualquier AD mayor que 110, como 120 o 200, para que la ruta estática quede fuera de la tabla hasta que desaparezca la ruta de OSPF.

Escribe una ruta de host IPv4 hacia 192.168.20.50 a través del siguiente salto 10.0.13.2.

ip route 192.168.20.50 255.255.255.255 10.0.13.2
