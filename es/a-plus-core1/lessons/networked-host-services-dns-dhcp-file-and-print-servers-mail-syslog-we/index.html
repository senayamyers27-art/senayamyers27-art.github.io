CompTIA A+ Core 1 220-1201

Servicios de host en red: DNS, DHCP, servidores de archivos e impresión, correo, syslog, servidores web, AAA/RADIUS, servidores proxy, gateways antispam, UTM, balanceadores de carga, IoT y sistemas heredados/embebidos

Las redes existen para ofrecer servicios, y la mayoría de esos servicios se ejecuta en servidores. Para A+ necesitas reconocer cada función de servidor común, lo que hace y cómo se manifestaría un problema con ella ante los usuarios.

Un servidor DNS (Domain Name System) traduce nombres, como el nombre de la intranet de una empresa, a direcciones IP. Cuando DNS falla, los usuarios suelen reportar que internet no funciona aunque todavía pueden llegar a los sitios por dirección IP. Un servidor DHCP (Dynamic Host Configuration Protocol) entrega automáticamente direcciones IP, máscaras de subred, puertas de enlace predeterminadas y direcciones de servidores DNS. Cuando DHCP falla, los clientes no pueden obtener una dirección y pueden recurrir a una dirección APIPA en el rango 169.254.x.x. Los servidores de archivos almacenan archivos compartidos, normalmente mediante SMB en redes Windows. Los servidores de impresión administran impresoras compartidas, colas y controladores para que cada usuario no necesite una conexión directa a cada impresora.

Los servidores de correo envían y reciben email; SMTP mueve los mensajes entre servidores, y los usuarios recogen su correo mediante IMAP, POP3 o un servicio como Exchange. Un servidor syslog recopila los mensajes de registro enviados desde routers, switches, firewalls y servidores para que los administradores puedan buscarlos en un solo lugar, lo cual es importante para la solución de problemas y la seguridad. Un servidor web aloja sitios y aplicaciones web mediante HTTP y HTTPS.

AAA significa autenticación, autorización y contabilidad (authentication, authorization and accounting): demostrar quién eres, decidir qué puedes hacer y registrar lo que hiciste. RADIUS (Remote Authentication Dial-In User Service) es un protocolo AAA común que se usa para centralizar los inicios de sesión de Wi-Fi con WPA2 o WPA3 Enterprise, VPN y dispositivos de red. TACACS+ es otro protocolo AAA que suele usarse para administrar equipos de red. Un servidor proxy se ubica entre los usuarios e internet y hace solicitudes en su nombre; puede almacenar contenido en caché, filtrar sitios web y registrar la actividad. Un gateway antispam filtra el correo entrante en busca de spam, phishing y malware antes de que llegue al servidor de correo. Un equipo UTM (unified threat management, gestión unificada de amenazas) combina varias funciones de seguridad, como firewall, prevención de intrusiones, antivirus, filtrado de contenido y VPN, en un solo dispositivo, lo que conviene a pequeñas y medianas empresas. Un balanceador de carga (load balancer) reparte las solicitudes entrantes entre varios servidores para mejorar el rendimiento y la disponibilidad, y deja de enviar tráfico a un servidor que no pasa las comprobaciones de estado.

No todo dispositivo en red es un servidor tradicional. Los dispositivos IoT (Internet of Things, internet de las cosas) incluyen termostatos inteligentes, cámaras, iluminación y sensores. Los sistemas heredados y embebidos incluyen cosas como controladores industriales antiguos, equipo médico y sistemas de edificios que ejecutan firmware fijo y no pueden parchearse ni actualizarse fácilmente. Estos dispositivos suelen ser menos seguros que las computadoras administradas, así que la buena práctica es cambiar las contraseñas predeterminadas, actualizar el firmware cuando sea posible y colocarlos en un segmento de red o VLAN separado para que un compromiso no pueda propagarse fácilmente a los sistemas del negocio.

Términos clave

AAA
Autenticación, autorización y contabilidad (authentication, authorization and accounting), el marco para controlar y registrar el acceso.
RADIUS
Un protocolo que ofrece AAA centralizado para inicios de sesión de Wi-Fi, VPN y dispositivos de red.
Syslog
Un estándar para enviar mensajes de registro desde dispositivos a un servidor de registros central.
UTM
Unified threat management, un solo equipo que combina firewall, prevención de intrusiones, filtrado y otras funciones de seguridad.
Load balancer (balanceador de carga)
Un dispositivo o servicio que distribuye solicitudes entre varios servidores y retira de la rotación a los servidores que fallan.
Ejemplo real

Los usuarios dicen que internet no funciona, pero puedes hacer ping a una dirección IP pública sin problema. Luego intentas resolver el nombre de un sitio web y falla, lo que muestra que el servidor DNS dejó de responder. Reiniciar el servicio DNS restablece la resolución de nombres y la navegación de todos.

Consejo para el examen: Relaciona el síntoma con el servicio: los nombres fallan pero las IP funcionan significa DNS; direcciones 169.254 significan DHCP; inicios de sesión Wi-Fi centralizados significan RADIUS; muchas funciones de seguridad en un solo equipo significa UTM; repartir la carga entre servidores significa balanceador de carga.

Comprueba lo que sabes

¿Qué función de servidor agregarías para centralizar los inicios de sesión de Wi-Fi WPA2-Enterprise?

Un servidor RADIUS, que ofrece AAA para la autenticación inalámbrica y de VPN.

¿Qué hace un servidor proxy para una organización?

Hace solicitudes web en nombre de los usuarios y puede almacenar contenido en caché, filtrar sitios y registrar la actividad.

¿Por qué los dispositivos IoT deben colocarse en un segmento de red separado?

Suelen ser difíciles de parchear y menos seguros, así que aislarlos limita el daño si uno se ve comprometido.
