CompTIA A+ Core 1 220-1201

Servicios de host en red: DNS, DHCP, servidores de archivos e impresión, correo, syslog, servidores web, AAA/RADIUS, servidores proxy, gateways antispam, UTM, balanceadores de carga, IoT y sistemas heredados/embebidos

Las redes existen para entregar servicios, y la mayoría de esos servicios se ejecutan en servidores. Para A+ necesitas reconocer cada función de servidor común, qué hace y cómo se manifestaría un problema con ella ante los usuarios. El examen rara vez te pide configurar estos servidores; en cambio, describe un síntoma o un requisito y pregunta qué servicio está involucrado o qué equipo debe agregarse.
