CompTIA A+ Core 1 220-1201

Firmware: configuración de BIOS/UEFI, orden de arranque, contraseñas, Secure Boot, TPM y HSM, soporte de virtualización, monitoreo de ventiladores y temperatura

El firmware es el software de bajo nivel almacenado en un chip de la placa base que inicia la computadora antes de que se cargue el sistema operativo. Ejecuta la POST (autoprueba de encendido), inicializa el hardware y luego cede el control a un cargador de arranque. El estándar anterior era BIOS (Basic Input/Output System). Los sistemas modernos usan UEFI (Unified Extensible Firmware Interface), que admite unidades grandes particionadas con GPT (tabla de particiones GUID), un arranque más rápido, una pantalla de configuración gráfica con soporte de mouse y funciones de seguridad como Secure Boot. Mucha gente, y muchas preguntas de examen, todavía llaman BIOS a la configuración de UEFI, así que trata los términos como parientes cercanos, siendo UEFI el moderno.

Entras a la configuración del firmware presionando una tecla durante el arranque, a menudo Supr (Delete), F2, F10 o Esc según el fabricante, o desde las opciones de inicio avanzado de Windows cuando el inicio rápido hace difícil alcanzar la tecla. Las configuraciones comunes incluyen la fecha y la hora, que una pequeña batería CMOS (complementary metal-oxide semiconductor) en la placa mantiene funcionando mientras la PC está desconectada; habilitar o deshabilitar dispositivos integrados como el audio o los puertos de red; y el modo del controlador de almacenamiento, como AHCI (Advanced Host Controller Interface) o RAID. Cuando la batería CMOS se agota, el reloj se reinicia y la configuración puede volver a los valores predeterminados en cada corte de energía.

El orden de arranque define qué dispositivos intenta primero el firmware, como el SSD interno, una unidad USB o el arranque por red mediante PXE (Preboot Execution Environment). Para instalar un sistema operativo desde una unidad USB, sube USB por encima de la unidad interna o usa el menú de arranque de una sola vez, que no cambia nada de forma permanente. Las contraseñas de firmware añaden protección. Una contraseña de supervisor o administrador impide cambios no autorizados en la configuración del firmware. Una contraseña de usuario o de encendido debe ingresarse antes de que el sistema arranque siquiera. Algunos sistemas también admiten una contraseña de unidad. En conjunto, estas impiden que alguien cambie el orden de arranque para iniciar su propio sistema operativo y eludir la seguridad de Windows.

Secure Boot es una función de UEFI que verifica las firmas digitales de los cargadores de arranque y controladores contra claves de confianza almacenadas en el firmware, bloqueando la ejecución al inicio de código sin firmar o alterado, como el malware a nivel de arranque. Algunos sistemas operativos o herramientas más antiguos necesitan que se desactive, y requiere el modo UEFI en lugar del modo de compatibilidad con BIOS heredado. Un TPM (Trusted Platform Module) es un procesador criptográfico seguro, ya sea un chip en la placa o integrado en el firmware de la CPU, que almacena claves de cifrado y mide el proceso de arranque. El cifrado de unidades BitLocker usa el TPM para proteger sus claves, y Windows 11 requiere TPM 2.0. Un HSM (hardware security module) es un dispositivo dedicado, a menudo una tarjeta adicional o un appliance de red, que las organizaciones usan para generar y proteger muchas claves criptográficas, por ejemplo para una autoridad de certificación o el procesamiento de pagos.

El soporte de virtualización debe habilitarse en el firmware antes de que un hipervisor pueda usar las funciones de virtualización por hardware de la CPU, rotuladas Intel VT-x o AMD-V (a veces mostrada como SVM). Si una máquina virtual no inicia e informa que la virtualización no está disponible, revisa primero esta configuración. El firmware también ofrece monitoreo de hardware: temperaturas de la CPU y del sistema, velocidades de los ventiladores y voltajes. Puedes definir curvas de ventilador para que los ventiladores aceleren a medida que sube la temperatura, y configurar alertas o umbrales de apagado. Después de cambiar cualquier cosa, elige guardar y salir para que los cambios surtan efecto.

Veamos un ejemplo práctico. Un usuario quiere actualizar a Windows 11 pero la verificación de compatibilidad falla. Reinicias en la configuración del firmware y encuentras el sistema en modo de compatibilidad heredado, con Secure Boot desactivado y el TPM de firmware deshabilitado. Confirmas que el disco usa GPT (convirtiéndolo primero si es MBR, el esquema anterior de registro de arranque maestro), cambias a modo UEFI, habilitas el TPM de firmware y Secure Boot, guardas y sales. Windows arranca con normalidad y la verificación de actualización ahora pasa. Aprovechando, configuras una contraseña de administrador para que la configuración no se pueda revertir a la ligera.

Errores comunes: confundir la contraseña de supervisor (protege la configuración) con la contraseña de usuario (necesaria para arrancar); suponer que Secure Boot cifra algo, cuando solo verifica firmas; confundir TPM con HSM; habilitar la virtualización dentro de Windows y olvidar que primero va el interruptor del firmware; y reemplazar toda una placa base cuando el único problema es una batería CMOS agotada. Recuerda también que borrar la CMOS restablece la configuración a los valores predeterminados, lo que puede deshabilitar una función que depende del TPM y provocar una solicitud de recuperación de BitLocker.

La redacción del examen suele ir del síntoma a la configuración. 'La VM no inicia, virtualización por hardware no disponible' significa habilitar VT-x o AMD-V. 'No se puede arrancar desde el instalador USB' significa el orden de arranque o el menú de arranque de una sola vez. 'Actualización a Windows 11 bloqueada' a menudo significa que TPM 2.0 o Secure Boot están desactivados. 'El reloj se reinicia después de desconectar' significa la batería CMOS. 'Impedir el arranque desde medios no autorizados' significa una contraseña de firmware más el orden de arranque. 'Proteger claves para muchos servidores' significa un HSM.

Términos clave

UEFI
Unified Extensible Firmware Interface, el reemplazo moderno de BIOS que admite unidades GPT y Secure Boot.
POST
Autoprueba de encendido (power-on self-test), la verificación de hardware del firmware que se ejecuta cada vez que la computadora arranca.
Secure Boot
Una función de UEFI que solo permite ejecutar al inicio cargadores de arranque y controladores firmados y de confianza.
TPM
Trusted Platform Module, un procesador criptográfico seguro en una computadora que almacena claves y respalda funciones como BitLocker.
HSM
Módulo de seguridad de hardware (hardware security module), un dispositivo dedicado para generar y proteger claves criptográficas a gran escala.
Orden de arranque (boot order)
La secuencia de dispositivos que el firmware prueba al buscar un sistema operativo para iniciar.
Batería CMOS
Una pequeña pila tipo botón que conserva el reloj y la configuración del firmware cuando la PC está desconectada.
Ejemplo real

Un desarrollador instala un hipervisor, pero la máquina virtual se niega a iniciar con un mensaje de que la virtualización por hardware está deshabilitada. Reinicias en la configuración de UEFI, habilitas Intel VT-x en el menú de configuración de la CPU, guardas y sales, y la VM inicia con normalidad. Como la laptop sale de la oficina, también configuras una contraseña de supervisor para que nadie pueda cambiar discretamente el orden de arranque a una unidad USB.

Consejo para el examen: Relaciona el síntoma con la configuración: si la VM no inicia, es VT-x o AMD-V; si no arranca desde USB, es el orden de arranque; si Windows 11 está bloqueado, es TPM 2.0 o Secure Boot; si el reloj se reinicia, es la batería CMOS. Un TPM protege las claves de una computadora; un HSM protege muchas claves para una organización.

Comprueba lo que sabes

¿Contra qué protege Secure Boot?

Contra la ejecución durante el arranque de cargadores de arranque y controladores sin firmar o alterados, como el malware a nivel de arranque.

¿En qué se diferencia un TPM de un HSM?

Un TPM está integrado en una sola computadora para proteger sus claves; un HSM es un dispositivo dedicado que administra muchas claves para una organización o aplicación.

¿Qué contraseña de firmware impide que el sistema arranque siquiera sin ella?

La contraseña de usuario o de encendido; la contraseña de supervisor solo protege la configuración del setup.

La fecha de la PC vuelve a un valor predeterminado cada vez que se desconecta. ¿Cuál es la solución probable?

Reemplazar la batería CMOS de la placa base y luego configurar la fecha, la hora y cualquier ajuste perdido.
