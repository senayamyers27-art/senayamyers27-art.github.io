CompTIA A+ Core 1 220-1201

Propósitos de la virtualización: sandbox, pruebas/desarrollo, virtualización de aplicaciones, software y sistemas operativos heredados

La virtualización permite que una computadora física, el host (anfitrión), ejecute una o más máquinas virtuales (VM), llamadas guests (invitados). Cada VM se comporta como una computadora completa con su propio sistema operativo, hardware virtual y almacenamiento, pero en realidad es software que se ejecuta sobre recursos físicos compartidos. Para A+ debes saber por qué las personas y las organizaciones usan la virtualización, porque las preguntas a menudo describen una situación y preguntan qué uso encaja.

Un sandbox es un entorno aislado donde puedes ejecutar algo que no es de confianza sin arriesgar al host. Los equipos de seguridad abren archivos adjuntos sospechosos o prueban programas desconocidos en una VM sandbox; si resulta ser malicioso, el daño queda contenido y la VM puede eliminarse o revertirse. Windows incluye en algunas ediciones una función de sandbox integrada que crea un escritorio temporal y desechable que se borra al cerrarlo.

Los entornos de prueba y desarrollo son uno de los usos más comunes. Los desarrolladores pueden ejecutar varios sistemas operativos y versiones lado a lado para comprobar que su software funcione en todos. El personal de TI puede probar parches, software nuevo o cambios de configuración en una VM que replica la producción antes de desplegarlos. Las instantáneas (snapshots) les permiten revertir al instante si una prueba sale mal, lo que ahorra horas de reconstruir equipos.

La virtualización de aplicaciones separa una aplicación del sistema operativo subyacente. En lugar de instalar la aplicación normalmente, esta se ejecuta en su propio paquete aislado o se transmite desde un servidor, así que no entra en conflicto con otro software ni modifica el sistema local. Esto ayuda cuando dos versiones de una aplicación no pueden instalarse lado a lado, y simplifica la implementación y las actualizaciones para muchos usuarios.

El software y los sistemas operativos heredados son otra gran razón. Algunas empresas dependen de una aplicación antigua que solo funciona en una versión antigua de Windows, o en hardware que ya no está disponible. En lugar de mantener vivas computadoras físicas envejecidas, puedes ejecutar el sistema operativo antiguo en una VM sobre hardware moderno. Como los sistemas heredados a menudo no tienen soporte ni parches, la VM debe aislarse de la red tanto como sea posible. La virtualización también permite a las organizaciones consolidar muchos servidores poco utilizados en menos hosts físicos, ahorrando energía, espacio y costos, y facilita el respaldo y la recuperación, porque una VM completa es solo un conjunto de archivos.

Términos clave

Virtual machine (máquina virtual)
Una computadora basada en software que ejecuta su propio sistema operativo sobre hardware físico compartido.
Host (anfitrión)
La computadora física, o su hipervisor, que ejecuta máquinas virtuales.
Guest (invitado)
Un sistema operativo que se ejecuta dentro de una máquina virtual.
Sandbox
Un entorno aislado para ejecutar código que no es de confianza sin afectar al host.
Application virtualization (virtualización de aplicaciones)
Ejecutar una aplicación aislada del sistema operativo local, a menudo transmitida o empaquetada, para evitar conflictos.
Ejemplo real

Un despacho contable depende de un programa de impuestos que solo funciona en una versión de Windows que lleva mucho tiempo sin soporte. En lugar de mantener una PC vieja bajo un escritorio, creas una VM con ese sistema operativo en un host moderno, restringes su acceso a la red al único recurso compartido de archivos que necesita y tomas instantáneas con regularidad.

Consejo para el examen: Relaciona el escenario: archivo sospechoso significa sandbox; probar un parche de forma segura significa entorno de pruebas con instantáneas; versiones de aplicaciones en conflicto significa virtualización de aplicaciones; aplicación antigua en un sistema operativo antiguo significa una VM heredada.

Comprueba lo que sabes

¿Por qué es útil un sandbox para examinar un archivo adjunto sospechoso?

Aísla el archivo del host, así que cualquier comportamiento malicioso queda contenido y el entorno puede desecharse.

¿Cómo puede ayudar la virtualización a una empresa que depende de software que solo funciona en un sistema operativo antiguo?

Ejecutando ese sistema operativo antiguo en una VM sobre hardware moderno, aislada del resto de la red.

¿Qué es la virtualización de aplicaciones?

Ejecutar una aplicación aislada del sistema operativo local, a menudo empaquetada o transmitida, para que no entre en conflicto con otro software.
