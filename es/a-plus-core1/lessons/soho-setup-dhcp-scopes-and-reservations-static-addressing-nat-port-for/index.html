CompTIA A+ Core 1 220-1201

Configuración SOHO: ámbitos y reservas DHCP, direccionamiento estático, NAT, reenvío de puertos, DMZ, UPnP, subred filtrada, seguridad Wi-Fi (WPA2/WPA3)

SOHO significa small office/home office (oficina pequeña u oficina en casa). Configurar un router SOHO es una tarea clásica de A+, que a menudo se evalúa con preguntas basadas en el desempeño en las que debes configurar ajustes en una pantalla de router simulada. El orden habitual es: cambiar la contraseña de administrador predeterminada, actualizar el firmware, configurar el direccionamiento, establecer la seguridad inalámbrica y luego agregar cualquier reenvío de puertos que necesite el negocio.

El servidor DHCP del router entrega direcciones de un ámbito (scope), que es el rango de direcciones disponibles, por ejemplo de 192.168.1.100 a 192.168.1.199. Deja espacio fuera del ámbito para los dispositivos con direcciones estáticas. Una dirección estática se escribe en el propio dispositivo y nunca cambia; es adecuada para servidores y equipos de red. Una reserva DHCP, en cambio, vincula una dirección IP específica a la dirección MAC de un dispositivo, de modo que el dispositivo sigue usando DHCP pero siempre obtiene la misma dirección. Las reservas son más fáciles de administrar de forma centralizada, lo que las convierte en una buena opción para impresoras.

NAT (network address translation, traducción de direcciones de red) permite que muchos dispositivos con direcciones privadas compartan una sola dirección IP pública del ISP. El router reescribe los paquetes salientes con su dirección pública y da seguimiento a las conexiones para que las respuestas regresen al dispositivo correcto. NAT también bloquea por defecto las conexiones entrantes no solicitadas, porque el router no sabe qué dispositivo interno debería recibirlas. El reenvío de puertos (port forwarding) crea una regla que envía el tráfico entrante en un puerto específico a una dirección IP interna específica, por ejemplo reenviar TCP 443 a un servidor web en 192.168.1.20. Por eso el dispositivo de destino necesita una dirección estática o una reserva.

Una DMZ (zona desmilitarizada), en el sentido de un router SOHO, reenvía todo el tráfico entrante no solicitado a un solo host interno. A veces se usa para consolas de videojuegos, pero expone ese host por completo, así que debe evitarse cuando un reenvío de puertos basta. Una subred filtrada (screened subnet) es el diseño empresarial correcto: un segmento de red separado entre internet y la LAN interna, protegido por reglas de firewall, donde viven los servidores de cara al público para que un compromiso no llegue a los sistemas internos. UPnP (Universal Plug and Play) permite que los dispositivos y aplicaciones abran reenvíos de puertos en el router automáticamente. Es cómodo pero riesgoso, porque el malware también puede usarlo, así que la buena práctica es deshabilitarlo a menos que se necesite.

Para la seguridad inalámbrica, usa WPA3 donde todos los dispositivos lo admitan, o WPA2 con cifrado AES en caso contrario. WPA3 usa SAE (simultaneous authentication of equals), que resiste los ataques de adivinación de contraseñas fuera de línea. El modo Personal usa una frase de contraseña compartida; el modo Enterprise usa credenciales individuales mediante un servidor RADIUS. Evita WEP y el WPA original, y deshabilita WPS (Wi-Fi Protected Setup) porque su método de PIN es débil. Usa una frase de contraseña segura, cambia el SSID predeterminado por uno que no identifique al propietario y considera una red de invitados separada que no pueda llegar a los dispositivos internos.

Términos clave

DHCP reservation (reserva DHCP)
Un ajuste de DHCP que siempre asigna la misma dirección IP a un dispositivo identificado por su dirección MAC.
NAT
Network address translation, que permite que las direcciones privadas compartan una dirección IP pública.
Port forwarding (reenvío de puertos)
Una regla del router que envía el tráfico entrante de un puerto dado a un host interno específico.
Screened subnet (subred filtrada)
Un segmento de red separado y protegido por firewall para servidores de cara al público, históricamente llamado DMZ.
UPnP
Universal Plug and Play, que permite a los dispositivos abrir puertos del router automáticamente; normalmente es mejor deshabilitarlo.
Ejemplo real

Un consultorio dental necesita que el personal remoto llegue a un sistema de cámaras en el puerto TCP 8443. Creas una reserva DHCP para que el grabador de las cámaras siempre obtenga 192.168.1.50, agregas un reenvío de puerto de 8443 a esa dirección, deshabilitas UPnP y confirmas que el Wi-Fi use WPA3 con una red de invitados separada para los pacientes.

Consejo para el examen: El reenvío de puertos necesita una dirección interna fija, así que combínalo con una IP estática o una reserva DHCP. Prefiere el reenvío de puertos a la opción DMZ del router SOHO. Elige WPA3, o WPA2 con AES, y deshabilita WPS y UPnP.

Comprueba lo que sabes

¿Cuál es la diferencia entre una IP estática y una reserva DHCP?

Una IP estática se configura en el propio dispositivo; una reserva se configura en el servidor DHCP y siempre asigna la misma dirección a la dirección MAC de ese dispositivo.

¿Por qué es riesgosa la opción DMZ del router SOHO?

Reenvía todo el tráfico entrante no solicitado a un solo host, exponiendo a internet todos los puertos de ese dispositivo.

¿Qué ajuste de seguridad inalámbrica debes elegir para una nueva red SOHO si todos los dispositivos lo admiten?

WPA3, que usa SAE para proteger mejor la frase de contraseña.
