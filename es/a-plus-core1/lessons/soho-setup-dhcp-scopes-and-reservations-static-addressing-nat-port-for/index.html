CompTIA A+ Core 1 220-1201

Configuración SOHO: ámbitos y reservas DHCP, direccionamiento estático, NAT, reenvío de puertos, DMZ, UPnP, subred filtrada, seguridad Wi-Fi (WPA2/WPA3)

SOHO significa oficina pequeña u oficina en casa (small office/home office). Configurar un router SOHO es una tarea clásica de A+, que a menudo se evalúa con preguntas basadas en desempeño donde configuras ajustes en una pantalla simulada de router. El orden habitual es: cambiar la contraseña de administrador predeterminada, actualizar el firmware, configurar el direccionamiento, configurar la seguridad inalámbrica y luego agregar el reenvío de puertos que necesite el negocio. Hacer primero los pasos de seguridad es importante porque un router con credenciales predeterminadas y firmware antiguo es un blanco fácil desde el momento en que se conecta.

El servidor DHCP (Dynamic Host Configuration Protocol) del router entrega direcciones desde un ámbito, que es el rango de direcciones disponibles, por ejemplo de 192.168.1.100 a 192.168.1.199. Deja espacio fuera del ámbito para los dispositivos con direcciones estáticas, de modo que el router nunca entregue la misma dirección a dos dispositivos. Una dirección estática se escribe en el propio dispositivo y nunca cambia; es adecuada para servidores y equipos de red. Una reservación DHCP, en cambio, vincula una dirección IP específica a la dirección MAC (control de acceso al medio) de un dispositivo, así que el dispositivo sigue usando DHCP pero siempre obtiene la misma dirección. Las reservaciones son más fáciles de administrar de forma central, lo que las hace una buena opción para impresoras y servidores pequeños.

NAT (traducción de direcciones de red) permite que muchos dispositivos con direcciones privadas compartan una sola dirección IP pública del ISP (proveedor de servicios de internet). El router reescribe los paquetes salientes con su dirección pública y da seguimiento a las conexiones para que las respuestas regresen al dispositivo correcto. NAT también bloquea de forma predeterminada las conexiones entrantes no solicitadas, porque el router no sabe qué dispositivo interno debería recibirlas. El reenvío de puertos crea una regla que envía el tráfico entrante de un puerto específico a una dirección IP interna específica, por ejemplo, reenviar TCP 443 a un servidor web en 192.168.1.20. Por eso el dispositivo de destino necesita una dirección estática o una reservación; si su dirección cambia, la regla apunta al host equivocado.

Una DMZ (zona desmilitarizada), en el sentido de los routers SOHO, a menudo llamada host DMZ, reenvía todo el tráfico entrante no solicitado a un solo host interno. A veces se usa para consolas de videojuegos, pero expone por completo a ese host, así que debe evitarse cuando basta con un reenvío de puertos. Una subred filtrada (screened subnet) es el diseño empresarial adecuado: un segmento de red separado entre internet y la LAN interna, protegido por reglas de firewall, donde viven los servidores expuestos al público para que un compromiso no llegue a los sistemas internos. CompTIA ahora usa subred filtrada como el término preferido para este diseño. UPnP (Universal Plug and Play) permite que los dispositivos y las aplicaciones abran reenvíos de puertos en el router automáticamente. Es cómodo pero riesgoso, porque el malware también puede usarlo, así que la buena práctica es deshabilitarlo a menos que se necesite.

Para la seguridad inalámbrica, usa WPA3 (Wi-Fi Protected Access 3) cuando todos los dispositivos lo soporten, o WPA2 con AES (Advanced Encryption Standard) en caso contrario; un modo de transición WPA2/WPA3 puede soportar ambos durante una migración. WPA3 Personal usa SAE (Simultaneous Authentication of Equals), que resiste los ataques de adivinación de contraseñas sin conexión. El modo Personal usa una frase de acceso compartida; el modo Enterprise usa credenciales individuales mediante un servidor RADIUS. Evita WEP, el WPA original y TKIP, y deshabilita WPS (Wi-Fi Protected Setup) porque su método de PIN es débil. Usa una frase de acceso segura, cambia el SSID predeterminado por uno que no identifique al dueño y considera una red de invitados separada que no pueda llegar a los dispositivos internos.

Veamos un ejemplo práctico. Un fotógrafo tiene un pequeño servidor de archivos en casa al que sus clientes deben llegar por HTTPS. Cambias la contraseña de administrador del router, actualizas su firmware y configuras el ámbito DHCP de 192.168.1.100 a 199. Creas una reservación DHCP de 192.168.1.20 para la dirección MAC del servidor y luego reenvías TCP 443 desde internet a 192.168.1.20. Dejas desactivado el ajuste de host DMZ y deshabilitas UPnP. Para el Wi-Fi eliges WPA3, deshabilitas WPS y creas una red de invitados para los clientes que lo visitan.

Errores comunes: reenviar un puerto a un dispositivo que obtiene una nueva dirección DHCP cada pocos días; poner direcciones estáticas dentro del ámbito DHCP, lo que causa conflictos de IP; usar el ajuste de host DMZ cuando un solo reenvío de puertos funcionaría; dejar UPnP y WPS activados por comodidad; confundir un host DMZ SOHO con una verdadera subred filtrada; y elegir WPA2 con TKIP en lugar de AES.

Las preguntas del examen usan pistas de configuración. 'El reenvío de puertos deja de funcionar después de reiniciar' apunta a una reservación o IP estática faltante. 'Exponer un servicio a internet' significa reenvío de puertos, no el host DMZ. 'Servidores públicos aislados de la red interna' significa subred filtrada. 'Aplicaciones que abren puertos automáticamente' significa UPnP, que debe deshabilitarse. 'La seguridad inalámbrica más fuerte para una oficina en casa' significa WPA3, o WPA2 con AES cuando los dispositivos más antiguos lo requieren.

Términos clave

Ámbito DHCP (DHCP scope)
El rango de direcciones IP que un servidor DHCP puede entregar.
Reservación DHCP (DHCP reservation)
Ajuste que siempre le da la misma dirección IP a un dispositivo con base en su dirección MAC.
NAT
Traducción de direcciones de red (network address translation), que permite que muchas direcciones privadas compartan una dirección pública.
Reenvío de puertos (port forwarding)
Regla que envía el tráfico entrante de un puerto específico a un host interno específico.
Host DMZ (DMZ host)
Ajuste de un router SOHO que reenvía todo el tráfico entrante no solicitado a un solo dispositivo interno.
Subred filtrada (screened subnet)
Segmento de red separado y protegido por firewall para los servidores expuestos al público.
UPnP
Universal Plug and Play, que permite que los dispositivos abran reenvíos de puertos en el router automáticamente.
SAE
Simultaneous Authentication of Equals, el saludo de WPA3 Personal que resiste la adivinación de contraseñas sin conexión.
Ejemplo real

La grabadora de las cámaras de seguridad de un pequeño despacho contable debe poder verse de forma remota. El técnico le da a la grabadora una reservación DHCP, reenvía solo el puerto web seguro de la grabadora a esa dirección y cambia la contraseña predeterminada de la grabadora. También nota que UPnP había abierto varios puertos inesperados, así que deshabilita UPnP, elimina las reglas automáticas y confirma con una verificación de puertos externa que solo está abierto el puerto previsto.

Consejo para el examen: El reenvío de puertos necesita una dirección interna fija, así que combínalo con una IP estática o una reservación DHCP. Prefiere el reenvío de puertos sobre el ajuste de host DMZ SOHO. Elige WPA3, o WPA2 con AES, y deshabilita WPS y UPnP.

Comprueba lo que sabes

¿Por qué un dispositivo que recibe tráfico por reenvío de puertos debe tener una reservación o una IP estática?

La regla de reenvío apunta a una dirección interna específica; si la dirección del dispositivo cambia, el tráfico va al lugar equivocado.

¿Cuál es la diferencia entre una reservación DHCP y una dirección IP estática?

La reservación se configura en el servidor DHCP y está vinculada a la dirección MAC del dispositivo; la IP estática se configura manualmente en el dispositivo.

¿Por qué se desaconseja usar el ajuste de host DMZ SOHO?

Reenvía todo el tráfico entrante no solicitado a un solo host y lo expone por completo, cuando normalmente basta con un reenvío de puertos específico.

¿Qué ajustes inalámbricos son una buena práctica en un router SOHO nuevo?

WPA3 (o WPA2 con AES), una frase de acceso segura, WPS deshabilitado y un SSID que no identifique al dueño, con una red de invitados separada si es necesario.
