CompTIA A+ Core 1 220-1201

Herramientas de diagnóstico: Diagnóstico de memoria de Windows, CrystalDiskInfo, Visor de eventos, Administrador de dispositivos, ping, ipconfig, tracert, nslookup, probador de cables y multímetro

Una buena solución de problemas depende de la evidencia, y las herramientas de diagnóstico la proporcionan. Para cada herramienta, conoce qué pregunta responde, para que puedas elegir la correcta según el síntoma.

El Diagnóstico de memoria de Windows (Windows Memory Diagnostic) prueba la RAM en busca de errores. Lo ejecutas desde el menú Inicio buscándolo o con el comando mdsched; reinicia la computadora y prueba la memoria antes de que se cargue Windows, y luego informa los resultados después de que inicias sesión. Úsalo para bloqueos aleatorios, pantallas azules y corrupción de datos que podrían deberse a memoria defectuosa. CrystalDiskInfo es una utilidad gratuita de terceros que lee los datos S.M.A.R.T. de una unidad y muestra su estado de salud, su temperatura, las horas de encendido y atributos de advertencia como los sectores reasignados. Úsala cuando una unidad es lenta, hace ruido o se sospecha que está fallando.

El Visor de eventos (Event Viewer) es el visor de registros de Windows, que se abre con eventvwr.msc. La sección Registros de Windows incluye los registros Sistema, Aplicación y Seguridad, y las entradas se marcan como Información, Advertencia, Error o Crítico. Filtra por la hora en que ocurrió el problema para ver bloqueos, fallas de controladores, apagados inesperados y errores de servicios. El Administrador de dispositivos (Device Manager), que se abre con devmgmt.msc, enumera todos los dispositivos de hardware. Un signo de exclamación amarillo indica un dispositivo con un problema, como un controlador faltante, y una flecha hacia abajo indica un dispositivo deshabilitado. Desde aquí puedes actualizar, revertir, deshabilitar o desinstalar controladores.

Las herramientas de red de línea de comandos prueban la conectividad capa por capa. ipconfig muestra la dirección IP, la máscara de subred y la puerta de enlace predeterminada; ipconfig /all agrega los servidores DNS, los detalles de DHCP y la dirección MAC; ipconfig /release y /renew solicitan una nueva concesión DHCP, e ipconfig /flushdns limpia la caché DNS local. ping envía solicitudes de eco ICMP para comprobar si un host es alcanzable y cuánto tardan las respuestas; haz ping al loopback, luego a la puerta de enlace, luego a una dirección remota y luego a un nombre, para encontrar dónde está la falla. Ten en cuenta que algunos dispositivos bloquean el ping, así que no recibir respuesta no siempre significa que el host esté caído. tracert muestra cada salto de router en la ruta hacia un destino, revelando dónde se detiene o se hace lento el tráfico. nslookup consulta el DNS directamente para comprobar si un nombre se resuelve y qué servidor respondió.

Las herramientas de hardware completan el kit. Un probador de cables revisa los cables de red en busca de continuidad, hilos abiertos, cortocircuitos y un orden de pines incorrecto. Un multímetro mide voltaje, resistencia y continuidad; los técnicos lo usan para revisar los voltajes de salida de la fuente de poder, el voltaje del tomacorriente, la continuidad de los cables y los fusibles. Ten cuidado al medir voltajes con corriente, configura el medidor en el modo y el rango correctos antes de conectar las puntas y nunca abras una fuente de poder para hacer pruebas en su interior.

Términos clave

Event Viewer (Visor de eventos)
La herramienta de Windows que muestra los registros del sistema, de las aplicaciones y de seguridad.
Device Manager (Administrador de dispositivos)
La herramienta de Windows para ver los dispositivos de hardware y administrar sus controladores.
tracert
Un comando que enumera cada salto de router entre una computadora y un destino.
nslookup
Un comando que consulta los servidores DNS para probar la resolución de nombres.
Multimeter (multímetro)
Un medidor que mide voltaje, resistencia y continuidad.
Ejemplo real

Un usuario no puede llegar a un sitio web de la empresa. ipconfig muestra una dirección y una puerta de enlace válidas, ping a la puerta de enlace y a una IP pública funciona, pero nslookup del nombre del sitio agota el tiempo de espera. Eso aísla el problema en el DNS, así que revisas la configuración del servidor DNS con ipconfig /all y encuentras una dirección de servidor DNS desactualizada.

Consejo para el examen: Elige la herramienta que responde la pregunta: errores de RAM, Diagnóstico de memoria de Windows; salud de la unidad, CrystalDiskInfo; qué pasó y cuándo, Visor de eventos; problemas de controladores, Administrador de dispositivos; ¿es alcanzable?, ping; ¿dónde se detiene?, tracert; nombres, nslookup; mi dirección, ipconfig; voltaje, multímetro.

Comprueba lo que sabes

¿Qué herramienta usarías para ver en qué punto de la ruta de red se detiene el tráfico?

tracert, que enumera cada salto hacia el destino.

Un dispositivo en el Administrador de dispositivos muestra un signo de exclamación amarillo. ¿Qué indica?

El dispositivo tiene un problema, a menudo un controlador faltante o defectuoso.

¿Qué herramienta comprueba si una PSU está entregando los voltajes correctos?

Un multímetro, o un probador de fuentes de poder.
