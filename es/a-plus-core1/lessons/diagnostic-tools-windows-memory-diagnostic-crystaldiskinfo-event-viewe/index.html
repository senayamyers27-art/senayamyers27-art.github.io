CompTIA A+ Core 1 220-1201

Herramientas de diagnóstico: Diagnóstico de memoria de Windows, CrystalDiskInfo, Visor de eventos, Administrador de dispositivos, ping, ipconfig, tracert, nslookup, probador de cables y multímetro

Una buena solución de problemas depende de elegir la herramienta correcta para confirmar o descartar una teoría. El examen A+ espera que sepas qué hace cada herramienta de diagnóstico común y cuándo usarla, para que reúnas evidencia en lugar de adivinar y reemplazar piezas. Piensa en las herramientas en tres grupos: las del hardware dentro de la PC, las del sistema operativo y los dispositivos, y las de la red y el cableado.

El Diagnóstico de memoria de Windows (Windows Memory Diagnostic) prueba la RAM (memoria de acceso aleatorio) en busca de errores. Ejecútalo buscándolo en el menú Inicio o ejecutando mdsched.exe; reinicia la computadora, prueba la memoria antes de que cargue Windows y muestra los resultados después de que inicias sesión, además de registrarlos en el Visor de eventos. Úsalo cuando veas bloqueos aleatorios, pantallas azules o archivos dañados que podrían apuntar a una memoria defectuosa. Si aparecen errores, prueba los módulos de uno en uno para encontrar el defectuoso. CrystalDiskInfo es una utilidad gratuita de terceros que lee los datos S.M.A.R.T. (Self-Monitoring, Analysis and Reporting Technology) de una unidad y muestra un estado de salud bueno, precaución o malo, junto con la temperatura, las horas de encendido y atributos como los sectores reasignados. Úsala cuando una unidad está lenta, hace ruido o se sospecha que está fallando, y respalda de inmediato si muestra precaución o malo.

El Visor de eventos (eventvwr.msc) muestra los registros que Windows mantiene sobre eventos del sistema, de seguridad y de aplicaciones. El registro Sistema guarda errores de hardware y controladores, apagados inesperados y fallas de servicios; el registro Aplicación guarda los bloqueos de programas; el registro Seguridad guarda los inicios de sesión y los eventos de auditoría. Busca entradas de Error y Crítico cerca del momento en que ocurrió el problema. El Administrador de dispositivos (devmgmt.msc) enumera todos los dispositivos de hardware. Un triángulo de advertencia amarillo indica un problema, a menudo un controlador faltante o defectuoso, y una flecha hacia abajo significa que el dispositivo está deshabilitado. Desde el Administrador de dispositivos puedes actualizar, revertir, deshabilitar o desinstalar controladores y buscar cambios de hardware.

Cada herramienta de red de línea de comandos responde una pregunta diferente. ipconfig muestra la dirección IP, la máscara de subred, la puerta de enlace predeterminada y, con /all, los servidores DNS (Domain Name System), los detalles de DHCP y la dirección MAC. ipconfig /release y /renew solicitan una nueva concesión DHCP, e ipconfig /flushdns vacía la caché de DNS. ping prueba si un host responde y mide el tiempo de ida y vuelta; empieza haciendo ping a tu propia puerta de enlace y luego a una dirección externa. tracert muestra cada salto de router en la ruta hacia un destino, lo que revela dónde ocurren los retrasos o las fallas. nslookup consulta el DNS para ver si un nombre se resuelve a una dirección IP. Si ping a una dirección IP funciona pero a un nombre falla, sospecha del DNS.

Las herramientas físicas prueban el hardware directamente. Un probador de cables revisa los cables de red en busca de continuidad, hilos abiertos, cortocircuitos, pares cruzados o divididos y el orden de cableado correcto, y algunos modelos miden la longitud del cable o rastrean un cable a través de un edificio. Úsalo cuando una conexión cableada falla y se sospecha del cable. Un multímetro mide voltaje, resistencia y continuidad. Los técnicos lo usan para revisar los voltajes de salida de una fuente de poder, confirmar que un tomacorriente entrega energía o probar la continuidad de un cable o un fusible. Usa la configuración correcta y maneja las puntas con cuidado, y nunca abras una fuente de poder para hacer pruebas en su interior.

Veamos un ejemplo práctico. Un usuario no puede acceder a un sitio web interno por su nombre. ipconfig muestra una dirección y una puerta de enlace válidas, y ping a la puerta de enlace tiene éxito. ping a la dirección IP del servidor web tiene éxito, pero ping usando su nombre falla. nslookup muestra que el nombre no se resuelve con el servidor DNS configurado. Descubres que la PC tiene un servidor DNS ingresado manualmente y desactualizado, vuelves a configurar el DNS en automático, ejecutas ipconfig /flushdns y el sitio carga.

Errores comunes: usar tracert cuando un simple ping a la puerta de enlace aislaría la falla; olvidar que algunos hosts bloquean el ping, así que no recibir respuesta no siempre es una falla; ignorar el Visor de eventos; y usar un multímetro para probar el orden de cableado de un cable de red, que es trabajo del probador de cables.

Las preguntas de examen describen la necesidad y esperan la herramienta. 'Bloqueos aleatorios, se sospecha de la RAM' significa Diagnóstico de memoria de Windows. 'Revisar la salud de la unidad' significa CrystalDiskInfo o S.M.A.R.T. 'Por qué se reinició la PC durante la noche' significa Visor de eventos. 'Triángulo amarillo en un dispositivo' significa Administrador de dispositivos. 'Qué dirección IP tengo' significa ipconfig. 'El host es alcanzable' significa ping. 'Dónde falla la ruta' significa tracert. 'El nombre se resuelve' significa nslookup. 'El cable está bien cableado' significa un probador de cables. 'La PSU entrega 12 voltios' significa un multímetro.

Términos clave

Diagnóstico de memoria de Windows (Windows Memory Diagnostic)
Una herramienta integrada de Windows que prueba la RAM en busca de errores durante un reinicio.
CrystalDiskInfo
Una utilidad de terceros que muestra los datos de salud S.M.A.R.T. de una unidad.
Visor de eventos (Event Viewer)
Una herramienta de Windows que muestra los registros del sistema, de aplicaciones y de seguridad.
Administrador de dispositivos (Device Manager)
Una herramienta de Windows que enumera los dispositivos de hardware y administra sus controladores.
tracert
Un comando que muestra cada salto de router en la ruta hacia un destino.
nslookup
Un comando que consulta el DNS para comprobar cómo se resuelven los nombres a direcciones IP.
Probador de cables (cable tester)
Un dispositivo que revisa los cables de red en busca de continuidad, cortocircuitos y cableado correcto.
Multímetro (multimeter)
Un instrumento que mide voltaje, resistencia y continuidad.
Ejemplo real

El equipo de escritorio de un usuario se reinicia una y otra vez durante la noche. La técnica abre el Visor de eventos y encuentra errores críticos de Kernel-Power y un código de detención relacionado con la memoria en cada reinicio. Ejecuta el Diagnóstico de memoria de Windows, que informa problemas de hardware, prueba cada módulo por separado, encuentra el defectuoso y lo reemplaza. Al día siguiente revisa el Visor de eventos para confirmar que no hubo más reinicios inesperados.

Consejo para el examen: Relaciona la herramienta con la pregunta: RAM significa Diagnóstico de memoria de Windows, salud de la unidad significa CrystalDiskInfo, registros significa Visor de eventos, controladores significa Administrador de dispositivos, configuración IP significa ipconfig, alcanzabilidad significa ping, ruta significa tracert, nombres significa nslookup, cableado significa probador de cables, voltaje significa multímetro.

Comprueba lo que sabes

¿Qué herramienta usarías para averiguar por qué una PC se reinició inesperadamente durante la noche?

El Visor de eventos, revisando el registro Sistema en busca de errores como los eventos Kernel-Power.

Un sitio web carga por dirección IP pero no por nombre. ¿Qué comando confirma la causa probable?

nslookup, para comprobar si el nombre se resuelve; el problema probablemente es el DNS.

¿Qué indica un triángulo amarillo junto a un dispositivo en el Administrador de dispositivos?

El dispositivo tiene un problema, a menudo un controlador faltante, incorrecto o dañado.

¿Cuál es la diferencia entre un probador de cables y un multímetro?

Un probador de cables revisa el cableado, la continuidad y las fallas de los cables de red; un multímetro mide voltaje, resistencia y continuidad para pruebas eléctricas y de alimentación.
