Hipervisores: Tipo 1 (bare metal) vs. Tipo 2 (alojado)

Un hipervisor (hypervisor), también llamado monitor de máquinas virtuales, es la capa de software que crea y ejecuta máquinas virtuales. Reparte la CPU, la memoria, el almacenamiento y la red físicos entre las VM y las mantiene aisladas entre sí. Hay dos tipos, y conocer la diferencia es un básico del examen.

Un hipervisor Tipo 1, también llamado bare metal o nativo, se ejecuta directamente sobre el hardware físico sin un sistema operativo de propósito general debajo. En la práctica es un sistema operativo ligero diseñado solo para ejecutar VM. Como no hay un sistema operativo anfitrión en medio, los hipervisores Tipo 1 son eficientes, rápidos, estables y más seguros, con una superficie de ataque menor. Se usan en centros de datos y para servidores. Algunos ejemplos son VMware ESXi, Microsoft Hyper-V y el hipervisor KVM (Kernel-based Virtual Machine) de Linux, así como Xen. Los hipervisores Tipo 1 normalmente se administran de forma remota mediante una consola web o un software de administración desde otra computadora, y las implementaciones grandes usan herramientas de administración central para mover VM entre hosts y manejar la conmutación por error (failover).

Un hipervisor Tipo 2, también llamado alojado (hosted), se ejecuta como una aplicación sobre un sistema operativo normal como Windows, macOS o Linux. Lo instalas como cualquier otro programa y luego creas VM dentro de él. Algunos ejemplos son Oracle VirtualBox, VMware Workstation y VMware Fusion en Mac, y Parallels Desktop. Los hipervisores Tipo 2 son fáciles de configurar e ideales para uso de escritorio: probar software, aprender, ejecutar un segundo sistema operativo o practicar laboratorios. La desventaja es el rendimiento y la sobrecarga, porque cada solicitud pasa por el sistema operativo anfitrión, y las VM dependen de que ese sistema operativo anfitrión siga en buen estado. Si el anfitrión falla o se reinicia por actualizaciones, todas las VM se detienen.

Hyper-V es una fuente común de confusión. Cuando habilitas Hyper-V en Windows 10 u 11 Pro, parece una aplicación, pero en realidad instala un hipervisor Tipo 1 por debajo, y el propio Windows pasa a ejecutarse como una partición privilegiada sobre él. Para efectos del examen, Hyper-V se considera Tipo 1.

Para elegir entre ellos, piensa en la tarea. Una empresa que consolida veinte servidores en tres máquinas físicas necesita un hipervisor Tipo 1 por rendimiento, confiabilidad y administración centralizada. Un estudiante que quiere probar Linux en una laptop con Windows, o un técnico que quiere una VM de prueba rápida, debería usar un hipervisor Tipo 2. Ambos tipos necesitan que el soporte de virtualización por hardware (Intel VT-x o AMD-V) esté habilitado en el firmware para un buen rendimiento, y ambos necesitan suficiente RAM y almacenamiento para el anfitrión más cada invitado en ejecución.

Términos clave

Hypervisor (hipervisor)
Software que crea y ejecuta máquinas virtuales y les asigna recursos de hardware.
Type 1 hypervisor (hipervisor Tipo 1)
Un hipervisor bare metal que se ejecuta directamente sobre el hardware, usado en servidores y centros de datos.
Type 2 hypervisor (hipervisor Tipo 2)
Un hipervisor alojado que se ejecuta como aplicación sobre un sistema operativo normal.
Bare metal
Ejecutarse directamente sobre el hardware físico sin un sistema operativo de propósito general debajo.
Ejemplo real

Una técnica que estudia para A+ quiere practicar comandos de Linux en su laptop con Windows sin volver a particionar la unidad. Le sugieres instalar un hipervisor Tipo 2 como VirtualBox y crear una VM con Linux. Mientras tanto, el equipo de servidores de su empresa ejecuta sus servidores de archivos y bases de datos de producción en hipervisores Tipo 1 en el centro de datos.

Consejo para el examen: Tipo 1 significa bare metal, mejor rendimiento, servidores y centros de datos. Tipo 2 significa alojado en un sistema operativo de escritorio, más fácil pero más lento. Si la pregunta menciona instalarlo como aplicación sobre Windows o macOS, la respuesta es Tipo 2.

Comprueba lo que sabes

¿Qué tipo de hipervisor se ejecuta directamente sobre el hardware sin un sistema operativo anfitrión?

El hipervisor Tipo 1, o bare metal.

¿Por qué los hipervisores Tipo 2 generalmente rinden menos que los Tipo 1?

Las solicitudes de sus VM pasan por el sistema operativo anfitrión, lo que agrega sobrecarga, y comparten recursos con ese sistema operativo.

Da un ejemplo de cada tipo de hipervisor.

Tipo 1: VMware ESXi, Hyper-V, KVM o Xen. Tipo 2: VirtualBox, VMware Workstation, VMware Fusion o Parallels Desktop.
