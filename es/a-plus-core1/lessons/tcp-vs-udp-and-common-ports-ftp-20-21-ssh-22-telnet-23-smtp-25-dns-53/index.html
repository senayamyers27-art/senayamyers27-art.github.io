CompTIA A+ Core 1 220-1201

TCP vs. UDP y puertos comunes: FTP 20/21, SSH 22, Telnet 23, SMTP 25, DNS 53, DHCP 67/68, HTTP 80, POP3 110, IMAP 143, SNMP 161/162, LDAP 389, HTTPS 443, SMB 445, RDP 3389

Toda conversación en una red necesita dos cosas además de una dirección IP: un protocolo de transporte y un número de puerto. La dirección IP lleva un paquete a la computadora correcta, y el número de puerto lo lleva al servicio correcto dentro de esa computadora, como un servidor web o un servidor de correo. Los dos principales protocolos de transporte son TCP y UDP. El examen A+ espera que sepas en qué se diferencian y que recuerdes el puerto estándar de cada servicio común, porque los firewalls, las reglas del router y la solución de problemas dependen de ellos.

TCP (Transmission Control Protocol) está orientado a la conexión. Antes de enviar datos establece una sesión con un saludo de tres vías: SYN, SYN-ACK, ACK. Numera los segmentos, confirma lo que llega, retransmite cualquier cosa que se pierda y entrega los datos en orden. Esa confiabilidad tiene un costo de sobrecarga y retraso, así que TCP se usa donde cada byte importa: páginas web, correo, transferencias de archivos e inicios de sesión remotos. UDP (User Datagram Protocol) no está orientado a la conexión. Envía datagramas sin saludo ni confirmaciones, así que es más rápido y ligero, pero no garantiza la entrega ni el orden. UDP es adecuado para consultas cortas como las búsquedas DNS y DHCP, y para el tráfico en tiempo real como la voz y el video, donde un paquete que llega tarde de todos modos no sirve.

El primer grupo de puertos que debes aprender. FTP (File Transfer Protocol) usa TCP 20 para datos y 21 para control. SSH (Secure Shell) usa TCP 22 para el acceso remoto cifrado por línea de comandos y la transferencia segura de archivos mediante SFTP. Telnet usa TCP 23 para el acceso remoto sin cifrar y debe evitarse porque envía las credenciales en texto claro. SMTP (Simple Mail Transfer Protocol) usa TCP 25 para enviar correo entre servidores. DNS (Domain Name System) usa el puerto 53, principalmente UDP para las consultas y TCP para las respuestas grandes y las transferencias de zona. DHCP (Dynamic Host Configuration Protocol) usa UDP 67 en el servidor y UDP 68 en el cliente. HTTP (Hypertext Transfer Protocol) usa TCP 80 para el tráfico web sin cifrar.

Continuamos con la lista. POP3 (Post Office Protocol versión 3) usa TCP 110 para descargar el correo. IMAP (Internet Message Access Protocol) usa TCP 143 para acceder al correo que se guarda en el servidor. SNMP (Simple Network Management Protocol) usa UDP 161 para las consultas a los dispositivos administrados y UDP 162 para los traps, las alertas que los dispositivos envían a la estación de administración. LDAP (Lightweight Directory Access Protocol) usa el puerto 389 para consultar directorios como Active Directory. HTTPS (HTTP Secure) usa TCP 443 para el tráfico web cifrado. SMB (Server Message Block) usa TCP 445 para compartir archivos e impresoras en Windows. RDP (Remote Desktop Protocol) usa TCP 3389 para el acceso remoto gráfico a Windows.

Remote access   SSH 22 (secure)   Telnet 23 (clear text)   RDP 3389
Web             HTTP 80           HTTPS 443
Mail            SMTP 25 (send)    POP3 110   IMAP 143
Infrastructure  DNS 53            DHCP 67/68 (UDP)   SNMP 161/162 (UDP)   LDAP 389
File sharing    FTP 20/21         SMB 445

Veamos un ejemplo práctico. Una oficina pequeña coloca su servidor de contabilidad detrás de un firewall nuevo. Después, el personal puede navegar en la web pero no puede mapear la unidad compartida de finanzas, y el administrador no puede conectarse con Escritorio remoto. Revisas las reglas del firewall y ves que solo se permiten el 80 y el 443 entre la VLAN de la oficina y el servidor. SMB necesita TCP 445 y Escritorio remoto necesita TCP 3389, así que agregas reglas para esos puertos solo desde la subred de la oficina, manteniendo el servidor cerrado a todo lo demás. Dejas bloqueado Telnet 23 y usas SSH 22 para el switch en su lugar.

Errores comunes: decir que DHCP o SNMP son servicios TCP, cuando ambos usan UDP; olvidar que DNS usa TCP además de UDP; confundir POP3 110 con IMAP 143; darle a SMB los antiguos puertos NetBIOS cuando la respuesta del examen para SMB directo es 445; y considerar aceptable Telnet para la administración remota. Otra trampa es pensar que UDP es poco confiable en un mal sentido; se elige deliberadamente cuando la velocidad importa más que la entrega garantizada.

Las preguntas del examen a menudo dan un puerto y piden el servicio, o describen una función bloqueada y preguntan qué puerto abrir. 'Reemplazo seguro de Telnet' es SSH 22. 'Web cifrada' es HTTPS 443. 'Los clientes reciben direcciones 169.254 después de un cambio en el firewall' puede apuntar a DHCP 67/68 bloqueado. 'No llegan los traps del monitoreo de red' es UDP 162. 'Sin conexión, sin saludo, adecuado para streaming' es UDP; 'entrega garantizada y en orden con un saludo' es TCP.

Términos clave

TCP
Transmission Control Protocol, un transporte orientado a la conexión con saludos, confirmaciones y retransmisión.
UDP
User Datagram Protocol, un transporte sin conexión que es rápido pero no garantiza la entrega.
Saludo de tres vías (three-way handshake)
El intercambio SYN, SYN-ACK, ACK que usa TCP para abrir una conexión.
Número de puerto (port number)
Número que identifica un servicio o aplicación específicos en un host.
SSH
Secure Shell, acceso remoto cifrado por línea de comandos en TCP 22.
SMB
Server Message Block, uso compartido de archivos e impresoras de Windows en TCP 445.
RDP
Remote Desktop Protocol, acceso remoto gráfico a Windows en TCP 3389.
Trap SNMP (SNMP trap)
Alerta no solicitada que un dispositivo administrado envía a una estación de administración en UDP 162.
Ejemplo real

Una técnica de redes configura un switch nuevo para administrarlo de forma remota. La política de seguridad prohíbe los protocolos en texto claro, así que deshabilita Telnet en TCP 23 y habilita SSH en TCP 22. También dirige los traps SNMP del switch al servidor de monitoreo en UDP 162 y permite esos puertos en el firewall entre la VLAN de administración y el switch.

Consejo para el examen: Empareja las versiones seguras e inseguras: Telnet 23 contra SSH 22, HTTP 80 contra HTTPS 443. DHCP y SNMP usan UDP; DNS es principalmente UDP pero también TCP. SMB es 445 y RDP es 3389.

Comprueba lo que sabes

¿Qué protocolo de transporte usa un saludo de tres vías y por qué?

TCP, para establecer una sesión confiable y orientada a la conexión antes de enviar datos.

Un usuario puede navegar en la web pero no puede conectarse a un recurso compartido de archivos de Windows. ¿Qué puerto podría estar bloqueado?

TCP 445, que usa SMB.

¿Qué puertos usa DHCP y con qué transporte?

UDP 67 en el servidor y UDP 68 en el cliente.

¿Cuál es el reemplazo seguro de Telnet y en qué puerto?

SSH en TCP 22, que cifra la sesión.
