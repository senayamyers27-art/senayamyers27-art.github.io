CompTIA A+ Core 1 220-1201

TCP vs. UDP y puertos comunes: FTP 20/21, SSH 22, Telnet 23, SMTP 25, DNS 53, DHCP 67/68, HTTP 80, POP3 110, IMAP 143, SNMP 161/162, LDAP 389, HTTPS 443, SMB 445, RDP 3389

Toda conversación de red necesita dos cosas además de una dirección IP: un protocolo de transporte y un número de puerto. La dirección IP lleva un paquete a la computadora correcta, y el número de puerto lo lleva al servicio correcto en esa computadora, como un servidor web o un servidor de correo. Los dos principales protocolos de transporte son TCP y UDP.

TCP (Transmission Control Protocol) está orientado a conexión. Antes de enviar datos establece una sesión con un saludo de tres vías (three-way handshake: SYN, SYN-ACK, ACK). Numera los segmentos, confirma lo que llega, retransmite lo que se pierde y entrega los datos en orden. Esa confiabilidad cuesta algo de sobrecarga y retraso, así que TCP se usa donde cada byte importa: páginas web, correo, transferencias de archivos e inicios de sesión remotos. UDP (User Datagram Protocol) no tiene conexión. Envía datagramas sin saludo ni confirmaciones, así que es más rápido y ligero pero no garantiza la entrega. UDP es adecuado para consultas cortas como las búsquedas DNS y DHCP, y para tráfico en tiempo real como voz y video, donde un paquete que llega tarde de todos modos no sirve.

El examen espera que conozcas estos puertos. FTP (File Transfer Protocol) usa TCP 20 para datos y 21 para control. SSH (Secure Shell) usa TCP 22 para acceso remoto cifrado por línea de comandos y transferencia segura de archivos. Telnet usa TCP 23 para acceso remoto sin cifrar y debe evitarse. SMTP (Simple Mail Transfer Protocol) usa TCP 25 para enviar correo entre servidores. DNS (Domain Name System) usa el puerto 53, principalmente UDP para consultas y TCP para respuestas grandes y transferencias de zona. DHCP (Dynamic Host Configuration Protocol) usa UDP 67 en el servidor y 68 en el cliente. HTTP usa TCP 80 para tráfico web sin cifrar.

Continuando la lista: POP3 (Post Office Protocol version 3) usa TCP 110 para descargar correo. IMAP (Internet Message Access Protocol) usa TCP 143 para acceder al correo guardado en el servidor. SNMP (Simple Network Management Protocol) usa UDP 161 para consultas a dispositivos administrados y UDP 162 para traps, las alertas que los dispositivos envían a la estación de administración. LDAP (Lightweight Directory Access Protocol) usa el puerto 389 para consultar directorios como Active Directory. HTTPS (HTTP Secure) usa TCP 443 para tráfico web cifrado. SMB (Server Message Block) usa TCP 445 para compartir archivos e impresoras en Windows. RDP (Remote Desktop Protocol) usa TCP 3389 para acceso remoto gráfico a Windows.

Los puertos importan en el trabajo diario porque los firewalls permiten o bloquean el tráfico por puerto. Si los usuarios pueden navegar pero no enviar correo a través de un servidor, un puerto 25 bloqueado o una regla faltante es un fuerte sospechoso. Un buen truco de memoria es agruparlos: acceso remoto (22, 23, 3389), web (80, 443), correo (25, 110, 143), infraestructura (53, 67/68, 161/162, 389) y compartir archivos (20/21, 445).

Términos clave

TCP
Transmission Control Protocol, un transporte orientado a conexión que garantiza una entrega ordenada y confiable.
UDP
User Datagram Protocol, un transporte sin conexión con poca sobrecarga y sin garantía de entrega.
Port number (número de puerto)
Un número que identifica un servicio o aplicación específico en un host.
Three-way handshake (saludo de tres vías)
El intercambio SYN, SYN-ACK, ACK que TCP usa para abrir una conexión.
SNMP trap
Una alerta no solicitada que un dispositivo administrado envía a una estación de administración, por UDP 162.
Ejemplo real

Después de un cambio en el firewall, el personal puede navegar por sitios web pero ya no puede conectarse desde casa a las PC de la oficina con Escritorio remoto. Revisas las nuevas reglas y descubres que TCP 3389 se eliminó de la regla que permite el tráfico a través de la VPN, y luego lo restauras solo para los usuarios de la VPN.

Consejo para el examen: Conoce qué puertos corresponden a las versiones seguras e inseguras: Telnet 23 frente a SSH 22, HTTP 80 frente a HTTPS 443. DHCP y SNMP son UDP; DNS es principalmente UDP pero también usa TCP. SMB es 445, RDP es 3389.

Comprueba lo que sabes

¿Por qué DNS usa principalmente UDP?

Las consultas DNS son pequeñas y rápidas, así que la baja sobrecarga de UDP les conviene; TCP se usa para respuestas grandes y transferencias de zona.

¿Qué puerto debe estar abierto para la administración remota segura por línea de comandos de un servidor Linux?

TCP 22 para SSH.

¿Qué puertos usa SNMP y cuál es la diferencia entre ellos?

UDP 161 para consultas a dispositivos administrados y UDP 162 para traps que los dispositivos envían al administrador.
