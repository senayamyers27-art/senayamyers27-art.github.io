Cloud Practitioner vs Azure Fundamentals: which should you take?

Both are foundational cloud certifications: AWS Cloud Practitioner for Amazon Web Services, AZ-900 for Microsoft Azure.

Which first?

Either order works. Choose the cloud your employer, or the employers you want, use. The concepts transfer, so the second one is much faster.

Who each one is for

Cloud Practitioner (CLF-C02): Beginners, and non-technical staff, at organizations that use AWS.

Azure Fundamentals (AZ-900): Beginners, and non-technical staff, at organizations that use Microsoft Azure or Microsoft 365.

Key differences

  • Both cover cloud concepts, core services, security, pricing and support at an introductory level.
  • Neither is required before the associate-level certifications, but both make them easier.
  • AWS has the larger share of the cloud market; Azure is common in companies that already run Microsoft software.
