CKA vs CKAD: which should you take?

Both are hands-on Kubernetes exams: CKA is about administering clusters, CKAD about building and deploying applications on them.

Which first?

Either order works. Pick the one that matches your job. Their content overlaps, so the second one takes much less study.

Who each one is for

CKA (CKA (Kubernetes v1.35 curriculum)): Platform, operations and site reliability engineers who run Kubernetes clusters.

CKAD (CKAD (Kubernetes v1.35 curriculum)): Developers who package and deploy applications on Kubernetes.

Key differences

  • CKA includes cluster installation, upgrades, backups, networking and troubleshooting nodes; CKAD doesn't.
  • CKAD goes deeper into pods, deployments, configuration, probes and application observability.
  • Both are performance-based exams at a command line, so speed with kubectl matters.
