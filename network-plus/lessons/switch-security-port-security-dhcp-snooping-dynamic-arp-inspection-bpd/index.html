CompTIA Network+ N10-009 · Domain 4: Network security

Switch security: port security, DHCP snooping, dynamic ARP inspection, BPDU guard

▶ Watch the overview video

Last reviewed October 6, 2026 · Leer en español

Explain it simpler

Access switches are where computers plug in, so they are the best place to stop local tricks. Basic network messages are very trusting: if a device says 'I am the router' or 'I hand out addresses here,' others believe it. Four switch features act like checkpoints. Port security limits how many devices can use one wall jack. DHCP snooping lets only the real address server hand out addresses. Dynamic ARP inspection checks that devices are not lying about who they are, using the list DHCP snooping keeps. BPDU guard shuts a port if someone plugs a switch into a jack meant for a single computer. Think of a building where each door allows one badge, only the front desk can issue badges, and guards check badges against that list.

At Willow Creek High School, the help desk phone rings at 8:05 a.m.: the whole science wing has 169.254 addresses and nobody can sign in. Last night, Priya, the network admin, enabled a new security feature on the wing's switch. Two hours later, a teacher's desk port goes dark the moment he plugs in a small switch to connect a second PC. By lunch, the security dashboard shows a laptop in the library claiming to be the default gateway. Priya now has three tickets and four switch features that are supposed to stop exactly these attacks. Which feature caused the outage, which one did its job, and how do they fit together?

Access switches are where users and devices plug in, so they are the natural place to stop Layer 2 attacks before they spread. Layer 2 protocols such as Address Resolution Protocol (ARP) and Dynamic Host Configuration Protocol (DHCP) were designed for trusting environments and believe whatever they hear, which attackers exploit. Four features work together to close these gaps, and Network+ expects you to know which one stops which attack, how they depend on each other, and what their violation behavior looks like when you are troubleshooting.
