CompTIA Network+ N10-009 · Domain 4: Network security

Device hardening: disable unused ports and services, change default passwords, secure management protocols

▶ Watch the overview video

Last reviewed October 6, 2026 · Leer en español

Explain it simpler

New network devices come set up to be easy, not safe. They have well-known default passwords, every port turned on, and old management methods that send passwords in plain text. Hardening means locking a device down before you trust it: change the default passwords, turn off ports and features you do not use, and use only encrypted ways to manage it. Think of moving into a new apartment. You change the locks because the old tenant may still have a key, you lock windows you never open, and you stop leaving the spare key under the mat. For networks, that means strong unique logins, unused ports switched off, and secure tools like SSH and HTTPS instead of Telnet and plain web pages.

Twenty new access switches are stacked on a cart at Brookfield Community College, and the semester starts Monday. Sam, the junior technician, has racked three of them already, straight out of the box. Then a quick authorized scan of one management address comes back: Telnet open, a web server on port 80, SNMP answering to the community string 'public', and every one of the 48 ports live and in VLAN 1. Somewhere online, the default admin password for this model is a single search away. Sam's manager asks a simple question before anything else gets plugged in: what is the minimum we must change on every switch, and how will we know it stays that way?

Hardening means reducing a device's attack surface by removing anything unnecessary and securing what remains. Network devices ship configured for easy setup, not for security: default accounts, convenient but insecure services, and every port ready to use. Hardening is one of the first jobs after deployment, and it should be captured in your golden configuration so every device gets the same protection and configuration monitoring can detect when one drifts. Industry benchmarks and vendor hardening guides provide checklists to follow.
