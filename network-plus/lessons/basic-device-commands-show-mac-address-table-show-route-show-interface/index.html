CompTIA Network+ N10-009 · Domain 5: Network troubleshooting

Basic device commands: show mac-address-table, show route, show interface, show config, show arp, show vlan, show power

Explain it simpler

Switches and routers can tell you a lot if you know what to ask. Each show command answers one question. show mac-address-table says which device is plugged into which port. show arp says which hardware address goes with which IP address. show route shows the router's map of networks and where it sends traffic. show interface shows a port's health: is it up, how fast, and are there errors? show config shows the device's settings, both what is running now and what is saved for the next restart. show vlan lists which ports are in which group. show power shows how much electricity the switch is giving to phones, cameras and access points. Used together, they let you find almost anything without leaving your desk.

A monitoring alert wakes Theo at 6:40 a.m.: duplicate IP detected, 10.1.20.33, Oakridge Dental Partners main office. By the time he logs in remotely, the front desk printer has vanished from the network twice and a receptionist's PC keeps losing its connection. Theo cannot walk the building; he has only a terminal session to the core switch and the access switches. Somewhere in those racks a device is using an address that is not its own, and a second problem is waiting: a ceiling camera installed yesterday never powered on. With nothing but a few show commands, can Theo find exactly which port, in which closet, holds the culprit before the first patients arrive?

Network+ includes a set of generic device commands modeled on common switch and router command-line interfaces (CLIs). Exact syntax varies between vendors, for example show ip route on Cisco IOS versus show route elsewhere, and show mac address-table with or without a hyphen, but the exam focuses on what each command shows and when to use it. Practice them in a simulator or lab and learn to read the output, because performance-based questions may show you output and ask what is wrong. The real skill is chaining them: each command answers one question and points to the next.
