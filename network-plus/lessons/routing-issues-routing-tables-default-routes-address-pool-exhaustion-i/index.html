CompTIA Network+ N10-009 · Domain 5: Network troubleshooting

Routing issues: routing tables, default routes, address pool exhaustion, incorrect gateway, subnet mask or IP

▶ Watch the overview video

Last reviewed October 6, 2026 · Leer en español

Explain it simpler

To reach anything outside its own small neighborhood, a computer needs three settings: its own address, a mask that tells it how big its neighborhood is, and the address of the router that acts as its exit door, called the default gateway. Get any one of these wrong and the computer can still talk to neighbors but cannot leave. Routers, in turn, keep a map of which roads lead where. If a road is missing from the map, packets get lost, and replies need a road home too. Finally, address pools can run out, like a parking lot with no spaces left: people already parked are fine, but new arrivals get turned away. Routing troubleshooting is checking the settings, the maps and the pools in order.

Priya has just started her first week on the desk at Riverbend County Library. A brand-new staff PC can open the shared drive down the hall but cannot load the catalog server in the main branch or any website. Across town, the branch office that went live yesterday can send pings to headquarters, and the headquarters router even sees them arrive, but not a single reply comes back. And at lunchtime, half the patrons on the public network suddenly cannot browse while the other half can. Her manager says all three are 'routing problems'. They look nothing alike. How can one word cover a typo on a single PC, a missing return path and a pool that has quietly run dry?

Routing issues show up when hosts can talk locally but not to other networks, or when some destinations work and others do not. Troubleshooting them means checking two places in order: first the host's own Internet Protocol (IP) configuration, because a single wrong value there breaks everything beyond the local subnet, and then the routers' tables, because every router along the path, in both directions, must know where to send the traffic.
