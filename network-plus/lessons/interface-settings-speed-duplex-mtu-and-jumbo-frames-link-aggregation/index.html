CompTIA Network+ N10-009 · Domain 2: Network implementation

Interface settings: speed, duplex, MTU and jumbo frames, link aggregation

▶ Watch the overview video

Last reviewed October 6, 2026 · Leer en español

Explain it simpler

Two devices joined by a cable have to agree on a few simple rules, the way two people on a walkie-talkie agree on who talks when. Speed is how fast they talk. Duplex is whether both can talk at the same time (full) or must take turns (half). If one side thinks it can talk anytime and the other thinks they must take turns, they keep interrupting each other and everything slows down. MTU is the largest packet size allowed, like the maximum box size a post office accepts; if one office along the route accepts only smaller boxes, big ones get stuck. Link aggregation bundles several cables into one wider pipe, like opening extra checkout lanes at a store.

Elena runs IT for Cedar Valley Architects, and the nightly backup to the file server has gone from 40 minutes to six hours. The link light is green. Ping replies come back fast. The server team rebuilt the machine last week and insists nothing changed on the network. Down the hall, a brand-new storage array is refusing large writes from the virtualization hosts, and the new site-to-site VPN to the branch loads half a web page and then hangs. Every link is "up." So why does everything feel broken, and where should Elena look first?

Every switch, router and host network interface has settings that must agree with the device at the other end of the cable. When they do not, the link may come up and appear fine but perform badly, which makes these problems hard to spot and a favorite exam topic. Network+ tests the main settings: speed, duplex, MTU (maximum transmission unit) including jumbo frames, and link aggregation. For each one, know what it controls, what a mismatch looks like in interface counters, and how to fix it.
