CompTIA Security+ SY0-701 · Domain 2: Threats, vulnerabilities & mitigations

Buffer overflow, race conditions (TOCTOU), memory injection

▶ Watch the overview video

Last reviewed October 6, 2026 · Leer en español

Explain it simpler

These attacks target how programs use memory and timing. A buffer overflow happens when a program accepts more data than the space set aside for it, so the extra spills into nearby memory and can overwrite instructions, letting an attacker run their own code. A race condition is a timing flaw where two things happen in an unexpected order. A common type is TOCTOU (time of check to time of use): a program checks something, like file permissions, but the attacker swaps the file before the program actually uses it. Memory injection means slipping harmful code into the memory of a running, trusted program so it runs under that program's name. Think of overfilling a glass until water floods the counter, or a bouncer checking an ID and then someone else walking in on it.

Your phone buzzes at 2 a.m. You are Marcus, on call for Pinecrest Medical Group, and the EDR console has flagged a workstation in billing. A normal Windows process opened a handle to the browser, wrote a block of memory into it and started a new thread there. Antivirus says the machine is clean, and no new files appeared on disk. An hour earlier, the patient portal's web server crashed four times, each time right after a request with a header thousands of characters long. Are these two problems, one attacker, or nothing at all? And if the antivirus sees nothing, what exactly are you looking at?

Some of the most serious vulnerabilities live not in web forms but in how programs manage memory and timing. Buffer overflows, race conditions and memory injection can let an attacker crash a program, bypass checks, or run their own code with the program's privileges. Security+ does not expect you to write exploits, but it does expect you to recognize these flaws in a scenario, understand why they happen, and know the defenses that operating systems and developers use against them.
