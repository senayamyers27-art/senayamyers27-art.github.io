CompTIA Security+ SY0-701 · Domain 4: Security operations

EDR/XDR, DLP, UEBA

▶ Watch the overview video

Last reviewed October 6, 2026 · Leer en español

Explain it simpler

These tools watch for threats and data leaks. EDR (endpoint detection and response) runs on computers and servers, the endpoints, recording what programs do and spotting suspicious behavior, then letting staff isolate a machine or stop a process. XDR (extended detection and response) pulls together information from endpoints, network, email, and cloud to see the bigger picture. DLP (data loss prevention) watches for sensitive data, like customer records, being sent or copied where it should not go, and blocks or flags it. UEBA (user and entity behavior analytics) learns what normal activity looks like for each user or device and flags unusual behavior, such as someone downloading far more files than usual at 1 a.m. Think of a building with room cameras (EDR), a central control room (XDR), bag checks at the exit (DLP), and a guard who knows everyone's routine (UEBA).

Tuesday, 1:15 a.m. at Lakeside Biologics. Sam, the overnight analyst, watches a risk score climb next to the name of a research scientist who has never once logged in after 7 p.m. A minute later the laptop agent flags a script quietly zipping up lab documents. Then a block message appears: an upload to a personal cloud storage site was stopped because the archive contains files labeled confidential. Antivirus never fired, because no known malware file was involved. Four different tools each saw a piece of what was happening. Sam has to decide fast: is this the scientist, or someone using her account, and which tool tells him what to do next?

Traditional antivirus compares files against signatures of known malware, which works well for known threats and poorly for everything else. Modern attackers use fileless techniques that live in memory, legitimate administration tools such as PowerShell, and stolen credentials that make them look exactly like real users. None of that matches a signature. The newer tools on the Security+ objectives watch behavior instead: what processes do, where data goes, and how users normally act. Endpoint detection and response (EDR), extended detection and response (XDR), data loss prevention (DLP) and user and entity behavior analytics (UEBA) each focus on a different question, and exam questions test whether you can match a scenario to the right one.
