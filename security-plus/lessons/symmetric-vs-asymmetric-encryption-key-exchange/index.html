CompTIA Security+ SY0-701 · Domain 1: General security concepts

Symmetric vs asymmetric encryption, key exchange

▶ Watch the overview video

Last reviewed October 6, 2026 · Leer en español

Explain it simpler

Encryption scrambles information so only someone with the right key can read it. Symmetric encryption uses one shared key to lock and unlock, which is fast but raises a problem: how do two people safely share that key in the first place? Asymmetric encryption uses a pair of keys: a public key that anyone can have, used to lock, and a private key that only the owner keeps, used to unlock. It is slower, so in practice systems use asymmetric encryption, or a key exchange method, just to agree on a shared symmetric key, then switch to symmetric for the bulk of the data. It is like mailing a friend a padlock that only you can open: they lock the shared house key in a box with it and send it back, and from then on you both use the house key.

You have just joined Riverbend Health Partners as a security analyst, and a developer named Theo pings you with a question. He needs to send large patient imaging files to a partner clinic, and he wants to "just use RSA on the files, since RSA is the secure one." Meanwhile, the clinic's IT lead is asking how the two organizations are supposed to share a secret key when they have never met and email is not safe. Two people, two half-right instincts. Which kind of encryption should protect the files, and how do the two sides end up holding the same key without ever sending it?

Encryption turns readable plaintext into unreadable ciphertext using an algorithm and a key, so only someone with the right key can turn it back. It protects confidentiality for data at rest, on disks and in databases, and in transit, across networks. Security+ expects you to know the two families of encryption, what each is good at, and how real systems combine them. Nearly every secure protocol you will meet, from Hypertext Transfer Protocol Secure (HTTPS) to virtual private networks (VPNs) to encrypted messaging, is a combination of the ideas in this lesson.
