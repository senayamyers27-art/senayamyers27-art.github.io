Question answering: building a knowledge base from FAQs for a bot

▶ Watch the overview video

Last reviewed September 25, 2026

Many organizations already have the answers customers need, spread across FAQ pages, product manuals and help articles. Question answering, a feature of Azure AI Language, turns that content into a knowledge base that a bot or app can query in natural language. It replaced the older QnA Maker service.

A question answering project holds question and answer pairs. You can import them from existing sources, such as FAQ web pages, documents (PDF, Word and similar files) or structured files, and the service extracts question and answer pairs automatically. You can also add pairs by hand, and add alternative phrasings of the same question so the knowledge base recognizes different ways people ask.

When a user asks a question, the service uses natural language understanding to find the best matching question in the knowledge base, even when the wording differs, and returns the associated answer with a confidence score. If no answer is confident enough, the app can return a default response, such as offering a human agent.

Several features make the experience conversational. Chit-chat adds prebuilt answers to small talk, such as 'hello' or 'who are you?', in a chosen personality, for example professional or friendly. Multi-turn conversations use follow-up prompts to guide users through a topic, such as asking which product they have before giving troubleshooting steps. Active learning suggests alternative questions based on real user queries so you can improve the knowledge base over time.

You build and test the project in Language Studio, then deploy it. Bots are commonly created with Azure AI Bot Service, which connects the knowledge base to channels such as a website chat window, Microsoft Teams or other messaging platforms.

The key distinction from conversational language understanding: question answering returns an answer from stored content; CLU identifies an intent and entities so your code can take an action. A support bot might use both, and generative AI with retrieval augmented generation is a newer approach to the same problem, covered in domain 5.

Key terms

Question answering
An Azure AI Language feature that answers natural language questions from a knowledge base of question and answer pairs.
Knowledge base
The collection of question and answer pairs, often imported from FAQs and documents, that question answering searches.
Chit-chat
Prebuilt responses to small talk that give a bot a consistent personality.
Multi-turn conversation
Follow-up prompts that guide a user through several steps within a topic.
Real-world example

A university imports its admissions FAQ page and student handbook into a question answering project, adds chit-chat with a friendly personality, and publishes the bot to its website with Azure AI Bot Service. Students asking 'when do applications close?' or 'what's the deadline to apply?' get the same answer.

Exam tip: Existing FAQ content and 'answer common questions' points to question answering. 'Understand what the user wants to do and extract details' points to conversational language understanding.

Check yourself

How can you build a question answering knowledge base quickly?

Import existing FAQ pages or documents; the service extracts question and answer pairs automatically.

What does chit-chat add to a knowledge base?

Prebuilt answers to small talk in a chosen personality.
