AI agents: models with instructions, tools and knowledge, and the Foundry Agent Service

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

An AI agent is a generative AI application that can reason about a goal and act to achieve it, not just reply with text. Agents are one of the fastest-growing parts of generative AI and a named topic in AI-900's generative AI domain.

An agent combines three things with a model. Instructions (similar to a system message) define its purpose, behavior and limits: 'You are an IT support agent. Help employees reset passwords and check ticket status. Never change admin accounts.' Knowledge gives it information to ground its answers, such as files, a search index or web search. Tools let it do things: search, run code to analyze data, call an API, query a database or trigger a workflow. The model decides when to use which tool, calls it, reads the result and continues until the task is done or it needs to ask the user.

That loop of reasoning, acting and observing is what separates an agent from a basic chat assistant. A chat assistant answers 'Your ticket system shows how to reset passwords like this...'. An agent looks up the user, calls the password reset API, confirms success and records it in the ticket. Agents can also work together in multi-agent solutions, where specialist agents handle parts of a larger task and coordinate.

Foundry Agent Service (earlier called Azure AI Agent Service) is the Microsoft Foundry capability for building, deploying and managing agents. You choose a model, write instructions, and attach knowledge and tools, such as file search, Azure AI Search, a code interpreter, Bing grounding or your own functions and APIs, then test the agent in the agents playground. The service manages conversation threads, runs tool calls and handles the plumbing so developers can focus on the agent's behavior. Microsoft also offers agent-building options in products like Copilot Studio.

Agents raise the stakes for responsible AI because they can take real actions. Good practice includes giving each agent only the tools and permissions it needs (least privilege), requiring human approval for consequential actions such as payments or deletions, logging every action for accountability, applying content filters and protecting against prompt injection, where malicious text in a document or web page tries to redirect the agent.

For the exam, look for scenarios where the AI must complete a task using systems or data, not only talk: those describe agents.

Key terms

AI agent
A generative AI application that uses a model with instructions, knowledge and tools to reason and take actions toward a goal.
Tool
A capability an agent can call, such as search, code execution or an API.
Foundry Agent Service
The Microsoft Foundry capability for building, deploying and managing agents.
Prompt injection
Malicious instructions hidden in input content that try to make a model or agent act against its instructions.
Real-world example

A travel company's booking agent reads a customer's request, searches flight availability through an API tool, checks the company's travel policy file for fare rules, holds the best option and asks the employee to confirm before it books and emails the itinerary.

Exam tip: Only answers questions: chat assistant or copilot. Uses tools to take actions or complete multi-step tasks: agent. Agents need least-privilege tools and human approval for high-impact actions.

Check yourself

What three things does an agent combine with a model?

Instructions, knowledge and tools.

Why should an agent that can issue refunds require human approval above a certain amount?

Agents can take real actions; human oversight limits harm from mistakes or manipulation, supporting reliability and accountability.
