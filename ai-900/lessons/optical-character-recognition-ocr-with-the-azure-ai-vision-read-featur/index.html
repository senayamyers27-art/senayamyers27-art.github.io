Optical character recognition (OCR) with the Azure AI Vision Read feature

▶ Watch the overview video

Last reviewed September 25, 2026

Optical character recognition (OCR) is the computer vision task of detecting and extracting text from images. It turns pixels that look like letters into machine-readable text that can be searched, stored, translated or analyzed. In Azure, the main OCR capability is the Read feature, available through Azure AI Vision and also used inside Azure AI Document Intelligence.

The Read feature handles printed text in many languages and handwritten text in a number of languages. It works on photos of the real world (signs, labels, whiteboards, number plates, product packaging) and on scanned documents and PDFs. It uses deep learning models, so it copes with different fonts, angles, backgrounds and mixed text styles far better than older template-based OCR.

The results are structured by position. For images, Read returns blocks of text broken into lines and words. Each line and word comes with a bounding polygon (the coordinates of its outline in the image) and each word with a confidence score. For multi-page documents, results are organized by page. That positional data lets an app highlight where text appears, keep reading order or crop out a specific region.

In image analysis you request the Read feature alongside other features in a single call, which suits short text in photos. For longer or multi-page documents, and whenever you need structure such as tables, key-value pairs and fields, Azure AI Document Intelligence builds on the same OCR engine and adds layout and field extraction.

OCR is often the first step in a larger solution. Extracted text can be passed to Azure AI Language for entity recognition or sentiment, to Azure AI Translator to translate signage, or into a search index for knowledge mining. It also supports accessibility by reading printed text aloud with text to speech.

Remember that OCR returns text, not meaning. It will tell you that the characters '1,250.00' appear at a certain position on a receipt, but not that they are the total. For named fields, use Document Intelligence.

Key terms

Optical character recognition (OCR)
Extracting printed or handwritten text from images and documents.
Read feature
The Azure AI Vision OCR capability that returns lines and words with their positions and confidence.
Bounding polygon
The set of coordinates outlining where a line or word appears in the image.
Handwriting recognition
OCR of handwritten rather than printed text.
Real-world example

A delivery firm's drivers photograph handwritten notes left on doors. The app runs Read to extract the text, sends it to translation if needed, and stores it with the delivery record so customer service can search it later.

Exam tip: Extract text from images: OCR with Read. Extract named fields or tables from forms: Document Intelligence. Describe the image in words: captions, not OCR.

Check yourself

What does the Read feature return for each word?

The text, its position as a bounding polygon and a confidence score.

Can Read extract handwriting?

Yes, it supports handwritten text as well as printed text, in a subset of languages.
