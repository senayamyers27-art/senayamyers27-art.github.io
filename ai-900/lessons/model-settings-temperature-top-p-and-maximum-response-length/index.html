Model settings: temperature, top_p and maximum response length

▶ Watch the overview video

Last reviewed September 25, 2026

Besides the prompt, you can change how a generative model chooses its words with a few request settings (often called parameters). They are visible in the Microsoft Foundry chat playground and can be set in every API call. AI-900 expects you to know what the common ones do and when to change them.

Recall that at each step the model calculates a probability for every possible next token. Temperature controls how that choice is made. A low temperature (close to 0) makes the model strongly favor the most likely tokens, so responses are focused, consistent and nearly the same each time. A higher temperature flattens the probabilities, so less likely tokens are chosen more often, and responses become more varied and creative, but also more likely to wander or contain errors.

Top_p (also called nucleus sampling) limits the choice to the smallest set of tokens whose probabilities add up to p. With top_p of 0.1, only the tokens making up the top 10 percent of probability are considered; with 1, all are. Lower values make output more focused. Both temperature and top_p control randomness, so the usual guidance is to adjust one or the other, not both at once.

Maximum response length (max tokens) caps how many tokens the model may generate in its reply. It controls cost and response size, and helps keep answers short, but if set too low the answer is cut off mid-sentence. Remember that the prompt and response together must fit in the model's context window. Stop sequences are another option: text that, when generated, makes the model stop, useful for structured output.

Choose settings by task. Factual question answering, data extraction, classification and code usually work best with low temperature for reliable, repeatable output. Brainstorming, marketing slogans, stories and varied suggestions benefit from higher temperature. Test changes with the same prompts to see the effect.

Settings do not add knowledge. A low temperature makes the model consistent, not correct: if it lacks the facts, it will be consistently wrong. Grounding and good prompts address accuracy; parameters tune style and variability. Note too that some newer reasoning models do not support every setting, so check the model's documentation.

Key terms

Temperature
A setting that controls randomness in token selection; low is focused and consistent, high is varied and creative.
Top_p
A setting that limits token choices to the most probable set whose combined probability reaches p.
Max tokens
A limit on the number of tokens the model can generate in a response.
Stop sequence
Text that tells the model to stop generating when it is produced.
Real-world example

A company uses one model for two jobs. Its invoice-question assistant runs at temperature 0 so the same question always gets the same careful answer. Its slogan generator runs at temperature 0.9 with a 50-token limit so marketers get a fresh, short list of ideas each time.

Exam tip: Need repeatable, factual output: lower temperature. Need creative variety: raise it. Answers cut off mid-sentence: max tokens is too low. Adjust temperature or top_p, not both.

Check yourself

An app returns different wording each time for the same extraction task. Which setting should you lower?

Temperature (or top_p), to make token selection more deterministic.

Does lowering temperature make a model more accurate about facts it does not know?

No. It makes output more consistent, not more knowledgeable; grounding is needed for missing facts.
