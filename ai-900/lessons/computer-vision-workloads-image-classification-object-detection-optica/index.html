Microsoft Certified: Azure AI Fundamentals AI-900 · Domain 1: Describe AI workloads and considerations

Computer vision workloads: image classification, object detection, optical character recognition and facial analysis

▶ Watch the overview video

Last reviewed September 25, 2026

Computer vision is the area of AI that lets software interpret images and video. To a computer an image is just a grid of numbers (pixel values), so vision models learn which patterns of pixels correspond to meaningful things such as a cat, a stop sign or the letter A. Domain 3 covers the Azure services in detail; here you need to recognize the main vision workloads in a scenario.

Image classification assigns a label to a whole image: this photo shows a bicycle, this X-ray is normal, this leaf has a disease. The output is one label (or a list of labels with confidence scores) for the image as a whole. It does not tell you where in the image the thing is or how many there are.

Object detection finds individual objects and returns a label and a bounding box (the coordinates of a rectangle) for each one. Use it when you need to count or locate things: how many cars are in the car park, where each person is standing, which shelf slots are empty. Semantic segmentation goes further and labels every pixel, giving the exact outline of each object.

Optical character recognition (OCR) detects and extracts printed or handwritten text from images and scanned documents: street signs, receipts, whiteboards, number plates. OCR returns the text and where it appears. If you need to know what the text means, such as which number is the total on an invoice, you combine OCR with document processing.

Facial analysis covers face detection (finding faces and their location), face attribute analysis (such as head pose, glasses or blur) and face recognition (verifying that two images show the same person, or identifying a person from a group). Recognition is sensitive: Microsoft restricts identification and verification under its Limited Access policy and has retired features that inferred emotion, gender or age. Expect responsible AI questions around face scenarios.

Image analysis services can also generate captions and tags that describe an image in words. These descriptions support accessibility (alt text for screen readers), content moderation and searching photo libraries.

Key terms

Image classification
Assigning one or more labels to an image as a whole, without locating objects.
Object detection
Finding objects in an image and returning a label and bounding box for each.
Optical character recognition (OCR)
Extracting printed or handwritten text from images or scanned documents.
Bounding box
The coordinates of a rectangle that marks where an object or word appears in an image.
Real-world example

A supermarket installs shelf cameras. Object detection finds each product and its position so staff know which slots are empty, OCR reads the price labels to check they match the system, and image classification flags whether each shelf photo is 'tidy' or 'needs attention'.

Exam tip: Count and locate means object detection; one label for the whole image means classification; read text means OCR. If a question mentions identifying who a person is, expect Limited Access to be part of the correct answer.

Check yourself

A wildlife project needs to count how many deer appear in each trail-camera photo. Classification or object detection?

Object detection, because it finds and locates each deer; classification would only say whether deer are present.

What does OCR return besides the text itself?

The location of the text, usually as lines and words with bounding boxes.
