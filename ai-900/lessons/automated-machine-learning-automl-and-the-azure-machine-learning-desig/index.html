Microsoft Certified: Azure AI Fundamentals AI-900 · Domain 2: Fundamental principles of machine learning on Azure

Automated machine learning (AutoML) and the Azure Machine Learning designer

▶ Watch the overview video

Last reviewed September 25, 2026

Building a good model usually means trying many algorithms, data preparation steps and settings, then comparing the results. Azure Machine Learning offers two low-code ways to do this without writing training code yourself: automated machine learning and the designer. AI-900 asks you to recognize what each one is for.

Automated machine learning (AutoML) automates the search for the best model. You choose a registered dataset, pick the task type (classification, regression, time-series forecasting, and also some computer vision and NLP tasks), name the label column, choose the primary metric (for example accuracy or normalized RMSE) and set limits such as the maximum training time. AutoML then tries many combinations of algorithms and preprocessing, trains each on compute, and ranks the resulting models by the metric.

AutoML also does featurization automatically: filling in missing values, encoding text categories as numbers and scaling values. It can apply guardrails, such as detecting class imbalance, and it shows explanations of which features mattered most. When the job finishes, you review the leaderboard, open the best model's metrics and charts, and deploy it with a few clicks.

The designer is a drag-and-drop canvas for building machine learning pipelines visually. You drag components onto the canvas, such as a dataset, a data cleaning step, a split of the data into training and test sets, a training algorithm, a scoring step and an evaluation step, and connect them. Submitting the pipeline runs each step on compute. You choose the algorithm and steps yourself, so the designer suits people who understand ML concepts but prefer not to code.

In short, AutoML answers 'which algorithm and settings work best for this data?' by trying them for you. The designer answers 'let me build my own workflow visually'. Both run in Azure Machine Learning studio, use workspace compute and produce models you can register and deploy.

A third option is code: data scientists can write Python in notebooks with frameworks such as scikit-learn or PyTorch and submit jobs through the SDK. The exam focuses on knowing that the low-code tools exist and when to choose them.

Key terms

Automated machine learning (AutoML)
A feature that tries many algorithms and settings automatically and ranks the resulting models by a chosen metric.
Primary metric
The measure AutoML uses to rank models, such as accuracy or normalized RMSE.
Designer
A drag-and-drop canvas in Azure Machine Learning studio for building training pipelines visually.
Featurization
Preparing raw data for training, such as handling missing values and encoding categories.
Real-world example

A small insurance company has no data scientists. An analyst uploads five years of claim data, starts an AutoML classification job to predict whether a claim will be disputed, sets AUC as the primary metric and a one-hour limit, then deploys the top model from the leaderboard.

Exam tip: Try many algorithms automatically and pick the best: AutoML. Build a pipeline visually by connecting components: designer. Neither requires writing code.

Check yourself

What must you specify when you start an AutoML job?

The data, the task type (such as classification or regression), the label column, the primary metric and compute and time limits.

How does the designer differ from AutoML?

In the designer you choose and connect the steps and algorithm yourself on a canvas; AutoML chooses and compares algorithms for you.
