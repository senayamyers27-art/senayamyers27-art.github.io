Microsoft Certified: Azure AI Fundamentals AI-900 · Domain 5: Generative AI workloads on Azure

Common generative AI scenarios: copilots, chat assistants, content drafting, summarization, code and image generation

▶ Watch the overview video

Last reviewed September 25, 2026

Generative AI is used across nearly every industry, but most applications fall into a handful of scenario types. AI-900 asks you to recognize them and to see where generative AI fits better or worse than traditional AI services.

Chat assistants answer questions and hold multi-turn conversations in natural language: customer support bots, internal helpdesk assistants and general-purpose assistants. When grounded in company data, they can answer questions about products, policies or procedures. Copilots are assistants embedded in the tools people already use, helping with tasks in context: drafting a document in a word processor, summarizing an email thread, suggesting a formula in a spreadsheet or writing code in an editor. The user stays in control and reviews the output.

Content creation and drafting covers marketing copy, product descriptions, emails, reports, job adverts and social media posts. Generative AI produces a first draft quickly, in a specified tone and format, and a person edits it. Summarization condenses long documents, meeting transcripts or conversation histories into short summaries, action items or bullet points. Transformation tasks rewrite content: changing tone, simplifying for a different reading level, translating or converting notes into a structured format.

Code generation writes, explains, reviews and converts code from natural language descriptions, and can generate tests or documentation. Image generation creates new images from text prompts, useful for concept art, marketing visuals and design exploration. Multimodal models can also accept images as input, so they can describe a chart, answer questions about a photo or extract information from a screenshot.

Agents extend these scenarios by taking actions: an agent can look up data, call business systems and complete multi-step tasks, such as processing a return from start to finish.

Generative AI is not always the best tool. When you need a fixed label, a precise field extraction, deterministic results or low cost at very high volume, a traditional AI service (such as sentiment analysis, Document Intelligence or a trained classifier) is often more accurate and predictable. Generative AI shines when the output is open-ended language or content.

Key terms

Chat assistant
A generative AI app that converses with users in natural language over multiple turns.
Copilot
A generative AI assistant embedded in an app to help users with tasks while they stay in control.
Summarization
Condensing long content into a shorter version that keeps the key points.
Code generation
Using a model to write, explain or convert code from natural language descriptions.
Real-world example

A marketing team uses one model deployment for several tasks: drafting product descriptions from specification sheets, summarizing customer interview transcripts, rewriting copy for different audiences, and generating mood-board images for a campaign, with each output reviewed by a person before use.

Exam tip: Create, draft, rewrite or converse freely: generative AI. Extract a specific field or assign a fixed label reliably: a traditional AI service may be the better answer.

Check yourself

What distinguishes a copilot from a stand-alone chat assistant?

A copilot is embedded in an app and helps with tasks in that context, with the user in control.

Give one case where a traditional AI service is a better fit than generative AI.

Extracting invoice totals reliably, where Document Intelligence's prebuilt model gives structured, consistent fields.
