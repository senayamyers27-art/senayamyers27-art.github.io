Binary and multiclass classification, with accuracy, precision, recall, F1 and the confusion matrix

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Classification is supervised machine learning that predicts which category (class) an item belongs to. Binary classification has two possible classes: spam or not spam, fraud or legitimate, will churn or will stay. Multiclass classification has three or more: which of five teams should get this ticket, which species is this flower, which of ten digits is handwritten here.

A classifier usually calculates a probability for each class. In binary classification, a threshold (often 0.5) turns that probability into a prediction: 0.83 probability of fraud becomes 'fraud'. Changing the threshold trades off different kinds of mistakes, which is why several metrics exist.

Metrics come from the confusion matrix, a table comparing predicted classes with actual classes. For binary classification it has four cells. True positives (TP) are positive cases predicted positive. True negatives (TN) are negative cases predicted negative. False positives (FP) are negative cases wrongly predicted positive, like a real email sent to spam. False negatives (FN) are positive cases wrongly predicted negative, like a fraud that slipped through.

Accuracy is the share of all predictions that were correct: (TP + TN) divided by the total. It can mislead when classes are imbalanced: if 1 percent of transactions are fraud, a model that always says 'legitimate' is 99 percent accurate and useless. Precision is TP / (TP + FP): of the items predicted positive, how many really were. Recall is TP / (TP + FN): of the actual positives, how many the model found. The F1 score combines precision and recall into one number (their harmonic mean).

Which metric matters depends on the cost of each mistake. When missing a positive is costly (disease screening, fraud), favor recall. When a false alarm is costly (flagging a legitimate customer as a criminal, sending important mail to spam), favor precision. Multiclass models have a larger confusion matrix with one row and column per class, and metrics are calculated per class and averaged.

In Azure Machine Learning, automated ML supports classification and reports these metrics, a confusion matrix chart and other visuals for each model it trains, so you can compare candidates.

Key terms

Binary classification
Predicting one of two classes, such as yes or no.
Confusion matrix
A table of actual versus predicted classes showing true and false positives and negatives.
Precision
Of the items predicted positive, the proportion that were actually positive: TP / (TP + FP).
Recall
Of the actual positive items, the proportion the model found: TP / (TP + FN).
Real-world example

A diabetes screening model is tested on 1,000 patients, 100 of whom have diabetes. It flags 120 patients, 90 of them correctly. Recall is 90/100 = 0.9 and precision is 90/120 = 0.75. The clinic accepts some false alarms because missing a diabetic patient is worse.

Exam tip: Two classes is binary, more is multiclass, even if the classes are numbers like ratings 1 to 5. Missing positives is costly: recall. False alarms are costly: precision.

Check yourself

A model predicts which of four subscription plans a customer will choose. Which type of classification is this?

Multiclass classification, because there are more than two classes.

In a spam filter, what is a false positive?

A legitimate email that the model wrongly marked as spam.
