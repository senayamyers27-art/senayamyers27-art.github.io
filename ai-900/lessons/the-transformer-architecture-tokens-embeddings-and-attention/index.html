The transformer architecture: tokens, embeddings and attention

▶ Watch the overview video

Last reviewed September 25, 2026

The transformer is the neural network architecture behind today's language models, including the GPT family used in Azure OpenAI. AI-900 expects you to know its main ideas at a conceptual level: tokens, embeddings and attention.

First, text is split into tokens. A token may be a whole word, part of a word or a punctuation mark; a common word might be one token while a rare word is split into several. Each token is mapped to an ID number. Models have a limit on how many tokens they can handle in one request (the context window), and generative AI services usually bill by the number of tokens processed.

Next, each token is represented as an embedding: a vector (a list of numbers) with many dimensions. Embeddings are learned so that tokens with related meanings have vectors that point in similar directions. The vectors for 'dog' and 'puppy' end up close together, while 'dog' and 'invoice' are far apart. Position information is added so the model knows the order of the tokens.

The key innovation is attention. In each layer, attention lets every token look at every other token in the input and weigh how relevant each one is to its own meaning. In 'the bank raised interest rates' versus 'we sat on the river bank', attention to the surrounding words lets the model represent 'bank' differently. Multi-head attention does this several ways at once, capturing different kinds of relationships. Because attention processes all tokens in parallel, transformers train efficiently on huge datasets.

The original transformer had an encoder, which builds rich representations of input text, and a decoder, which generates output text. Encoder-style models such as BERT are good at understanding tasks like classification. Decoder-style models such as GPT generate text by predicting the next token, again and again, based on all the tokens so far.

Training these models on massive amounts of text teaches them grammar, facts and patterns of reasoning. That is why a single pretrained model can be adapted by prompting to summarize, translate, answer questions and write code.

Key terms

Token
A unit of text, such as a word or part of a word, that a language model processes.
Embedding
A vector of numbers representing the meaning of a token or text, where similar meanings are close together.
Attention
A mechanism that lets each token weigh the relevance of the other tokens in the sequence.
Transformer
A neural network architecture built on attention, used by modern language models.
Real-world example

Given the prompt 'The trophy did not fit in the suitcase because it was too big', a transformer uses attention to link 'it' to 'trophy' rather than 'suitcase', and continues the text accordingly.

Exam tip: Tokens are the units of text; embeddings are the vectors that represent meaning; attention relates tokens to each other in context. GPT-style models generate by predicting the next token.

Check yourself

What problem does attention solve?

It lets the model interpret each word in the context of the other words, so the same word can take different meanings.

Why are embeddings useful for search?

Texts with similar meanings have similar vectors, so you can find related content even when the words differ.
