Choosing the right Azure language or speech service for a scenario

▶ Watch the overview video

Last reviewed September 25, 2026

Domain 4 questions often describe a need and ask which Azure service or feature to use. As with vision, the reliable method is to identify the input (text or audio) and the output the scenario wants, then map them. This lesson pulls the domain together as a decision guide.

If the input is text and the output is information about that text, use Azure AI Language. Choose the feature by the output: which language (language detection), positive or negative (sentiment analysis), sentiment about specific aspects (opinion mining), main topics (key phrase extraction), people, places, dates and other categories (named entity recognition), which real-world entity is meant (entity linking), personal data found and masked (PII detection), a shorter version (summarization) or your own categories (custom text classification).

If the input is a user's request and the output is an action, use conversational language understanding to get the intent and entities. If the output is an answer from existing FAQ content, use question answering. If the output needs to be freely written text, such as a detailed personalized reply, a generative AI model may be the better fit.

If the input or output is audio, use Azure AI Speech: speech to text for transcripts and captions, text to speech for spoken output, and speech translation for spoken audio in another language. If the input is text or documents that need to be in another language, use Azure AI Translator: text translation, or document translation to keep formatting.

Real solutions chain services together. A multilingual voice bot might use speech to text, Translator, CLU or question answering, then text to speech. A call analytics pipeline might use batch speech to text, PII detection to redact card numbers, sentiment analysis and summarization.

Watch for distractors that sound plausible but do a different job: key phrase extraction does not judge tone; sentiment analysis does not translate; Translator does not handle live audio (speech translation does); question answering does not extract entities for an action.

Key terms

Azure AI Language
Service for analyzing and understanding text, including CLU and question answering.
Azure AI Speech
Service for speech to text, text to speech and speech translation.
Azure AI Translator
Service for translating text and documents between languages.
Service chaining
Combining several AI services in sequence so one's output becomes the next one's input.
Real-world example

An airline's contact centre transcribes calls with speech to text, redacts card numbers with PII detection, scores sentiment and summarizes each call with Azure AI Language, translates summaries for regional teams with Translator, and runs a website bot on question answering for baggage FAQs.

Exam tip: Text analysis: Language. Audio: Speech. Different language: Translator, unless the input is spoken, then speech translation. Action from a command: CLU. Answer from FAQs: question answering.

Check yourself

A company wants spoken customer calls converted to text and then checked for negative sentiment. Which services?

Azure AI Speech speech to text, then Azure AI Language sentiment analysis.

A website must translate its HTML help pages while keeping their layout. Which capability?

Document translation in Azure AI Translator.
