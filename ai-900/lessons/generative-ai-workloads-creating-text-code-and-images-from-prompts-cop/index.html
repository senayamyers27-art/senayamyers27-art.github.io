Microsoft Certified: Azure AI Fundamentals AI-900 · Domain 1: Describe AI workloads and considerations

Generative AI workloads: creating text, code and images from prompts, copilots and agents

▶ Watch the overview video

Last reviewed September 25, 2026

Generative AI is AI that creates new content. You give it a prompt, a natural language instruction or question, and it returns text, code, an image or other output that did not exist before. It is the fastest-growing area of AI and carries the largest weight on AI-900 (domain 5), so this lesson introduces the vocabulary.

Most generative AI apps are built on large language models (LLMs), which are trained on vast amounts of text and generate responses one token at a time. With the right prompt the same model can draft an email, summarize a report, answer a question, translate, classify text or write and explain code. Image generation models create pictures from a text description. Multimodal models can take images as input as well as text.

A copilot is a generative AI assistant built into an application to help people with their work: drafting documents in a word processor, summarizing a meeting, writing a formula in a spreadsheet or suggesting code in an editor. The name signals the intended relationship: the user remains the pilot, reviewing and deciding, while the AI assists.

An agent goes a step further. It combines a model with instructions, knowledge and tools, such as the ability to search a knowledge base, run code or call a business API, so it can work toward a goal and take actions, sometimes over several steps. A travel agent bot that checks flight availability, books a seat and emails the confirmation is an agent; a bot that only writes a description of a flight is not.

Generative AI brings specific risks. Models can produce fluent but false statements (often called hallucinations), reflect biases in their training data, generate harmful content or be manipulated by crafted prompts. Organizations reduce these risks by grounding the model in trusted data, using content filters, writing clear system messages, keeping humans in the loop and testing thoroughly. You will study these mitigations in detail later.

On the exam, generative AI is the answer when the scenario asks to create, draft, write, rewrite, summarize in natural language or converse freely. If it asks to extract, classify with fixed labels or detect, a traditional AI service may be the more precise fit.

Key terms

Prompt
The instruction, question or context given to a generative AI model to produce a response.
Large language model (LLM)
A very large neural network trained on text that generates language by predicting tokens.
Copilot
A generative AI assistant embedded in an app that helps a user with tasks while the user stays in control.
Agent
A generative AI solution that combines a model with instructions, knowledge and tools so it can take actions toward a goal.
Real-world example

A software company gives its support engineers a copilot inside the ticketing system. It summarizes long ticket histories, drafts replies based on the knowledge base, and, as an agent with the right tools, can look up a customer's licence status and reset a trial period after the engineer approves.

Exam tip: Copilot: assists a user inside an app. Agent: can also use tools and take actions. Both are generative AI. Watch for the word 'create' or 'draft' as the signal for a generative AI workload.

Check yourself

What makes an agent different from a basic chat assistant?

An agent can use tools and knowledge to take actions toward a goal, not just reply with text.

Name two risks specific to generative AI output.

Fabricated but plausible statements (hallucinations) and harmful or biased content; manipulation through crafted prompts is another.
