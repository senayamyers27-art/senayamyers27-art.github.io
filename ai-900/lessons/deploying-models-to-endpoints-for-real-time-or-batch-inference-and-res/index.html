Microsoft Certified: Azure AI Fundamentals AI-900 · Domain 2: Fundamental principles of machine learning on Azure

Deploying models to endpoints for real-time or batch inference, and responsible AI tools in Azure Machine Learning

▶ Watch the overview video

Last reviewed September 25, 2026

A model only creates value when applications can use it. In Azure Machine Learning, you deploy a trained model to an endpoint, a web address that accepts input data and returns predictions. AI-900 expects you to know the two main endpoint types and the responsible AI tools that help you check a model before and after deployment.

First you register the model in the workspace's model registry, giving it a name and version. Models trained with AutoML or the designer can be registered and deployed directly from studio. A deployment packages the model with the code and environment needed to run it, on compute that Azure manages for you.

A real-time endpoint (called an online endpoint) serves predictions on demand with low latency. An app sends a request, typically JSON over HTTPS with the feature values for one or a few items, and gets a prediction back within moments. Use it when a person or process is waiting for an answer: approving a loan application, recommending a product on a web page, checking a transaction as it happens. Online endpoints can have several deployments behind them so you can test a new model version with a share of traffic.

A batch endpoint scores large amounts of data asynchronously. You point it at a folder or dataset, it runs a job on a compute cluster, and it writes the predictions to storage. Use it when nobody is waiting, such as scoring every customer overnight for churn risk. Batch scoring is usually cheaper for large volumes because the compute runs only during the job.

Clients authenticate to endpoints with a key or a Microsoft Entra ID token, and you should monitor deployed models for errors, latency and drift in the data they receive.

The Responsible AI dashboard in Azure Machine Learning brings several tools together for a trained model: error analysis (which groups of data the model gets wrong most), fairness assessment (how performance differs across sensitive groups), model interpretability (which features drive predictions, overall and for individual cases), counterfactual what-if analysis (what would need to change for a different outcome) and data analysis. A scorecard can summarize the findings for stakeholders who are not data scientists. These tools put the fairness, reliability and transparency principles into practice.

Key terms

Endpoint
A web address where a deployed model accepts input data and returns predictions.
Online (real-time) endpoint
An endpoint that returns predictions immediately for individual requests.
Batch endpoint
An endpoint that scores large volumes of data asynchronously as a job and writes results to storage.
Responsible AI dashboard
An Azure Machine Learning tool combining error analysis, fairness, interpretability and what-if analysis for a model.
Real-world example

An energy supplier deploys its churn model twice. The call centre app uses an online endpoint to show a live churn-risk score while an agent talks to a customer. Every Sunday, a batch endpoint scores all 2 million customers so marketing can plan the week's retention offers. Before launch, the Responsible AI dashboard showed the model was less accurate for rural customers, so the team added more rural data.

Exam tip: Someone waiting for an immediate answer means a real-time (online) endpoint. Scoring a large dataset on a schedule means batch. Questions about finding where a model makes more errors or treats groups differently point to the Responsible AI dashboard.

Check yourself

A web shop needs product recommendations while the customer is browsing. Which endpoint type fits?

A real-time (online) endpoint, because the answer is needed immediately for each request.

Name three tools in the Responsible AI dashboard.

Error analysis, fairness assessment and model interpretability; counterfactual what-if analysis and data analysis are also included.
