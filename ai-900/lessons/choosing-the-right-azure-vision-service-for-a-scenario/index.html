Choosing the right Azure vision service for a scenario

▶ Watch the overview video

Last reviewed September 25, 2026

Many AI-900 vision questions describe a business need and ask which service or feature to use. The fastest way to answer is to identify the input and the output the scenario wants, then match them to the service. This lesson brings the domain together as a decision guide.

If the input is a photo or video frame and the output is a description of what is in it, use Azure AI Vision image analysis. Choose the specific feature by the output: a sentence (captions), sentences for regions (dense captions), keywords (tags), objects with locations (object detection), people with locations (people detection) or a thumbnail region (smart crops).

If the output is the text in the image, use OCR with the Read feature in Azure AI Vision. If the input is a document such as an invoice, receipt, ID or form and the output is structured data (named fields, tables, key-value pairs, checkboxes), use Azure AI Document Intelligence: a prebuilt model for common documents, the layout model for structure from any document and a custom model for your own forms.

If the scenario is about faces, use Azure AI Face. Detection and image attributes such as blur, glasses or head pose are available. Verification and identification require Limited Access approval. Inferring emotion, gender or age is not offered. If the scenario only needs to count people, people detection in Azure AI Vision avoids face analysis altogether.

If the scenario needs categories that prebuilt models do not know, such as your company's own products, parts or defects, you need a custom vision model trained on your own labeled images, for example with Azure Machine Learning's AutoML image tasks. If the scenario wants to ask free-form questions about an image or combine image understanding with reasoning, a multimodal generative model (such as a GPT model that accepts images, deployed through Microsoft Foundry) is the fit.

Finally, check the non-functional hints: free experimentation suggests a single-service F0 resource; one key for several services suggests a multi-service resource; sensitive face scenarios bring in Limited Access and responsible AI.

Key terms

Azure AI Vision
The Azure AI service for image analysis and OCR with prebuilt models.
Azure AI Face
The Azure AI service for detecting and analyzing faces, with recognition under Limited Access.
Azure AI Document Intelligence
The Azure AI service that extracts fields, tables and structure from documents.
Custom vision model
An image model trained on your own labeled images to recognize classes that prebuilt models do not cover.
Real-world example

A logistics company has four needs: read container codes from dock photos (Vision OCR), extract fields from bills of lading (Document Intelligence), count workers on a loading bay (Vision people detection) and detect damage types specific to its containers (a custom model trained on labeled photos).

Exam tip: Map output to service: description or objects to Vision image analysis, text to Vision Read, fields and tables to Document Intelligence, faces to Face, your own classes to a custom model.
