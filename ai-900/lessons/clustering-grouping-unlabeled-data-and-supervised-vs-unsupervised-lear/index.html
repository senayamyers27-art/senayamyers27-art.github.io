Clustering: grouping unlabeled data, and supervised vs unsupervised learning

▶ Watch the overview video

Last reviewed September 25, 2026

Clustering is unsupervised machine learning that groups similar items together. Unlike regression and classification, there is no label column and no right answer in the training data. The algorithm looks only at the features and decides which items are alike.

The most common example algorithm is k-means. You choose the number of clusters, k. The algorithm places k center points, assigns each item to the nearest center, moves each center to the average of its items, and repeats until the clusters stop changing. The result is a cluster number for each item. It is up to people to interpret what the clusters mean: 'cluster 2 looks like bargain hunters who shop on weekends'.

Clustering is useful when you want to discover structure you did not know about. Businesses use it for customer segmentation (finding groups of customers with similar buying habits for targeted marketing), grouping documents by topic, organizing products with similar characteristics, and exploring data before building other models. It can also help label data: once you understand the clusters, you might name them and use them as classes to train a classifier.

Evaluation is different from supervised learning because there are no actual labels to compare with. Clustering metrics measure how tight each cluster is and how well separated the clusters are, for example the average distance between items and their cluster center, and the distance between cluster centers.

The key AI-900 distinction is supervised versus unsupervised. Supervised learning trains on data that includes known labels, so the model learns to predict those labels: regression (numbers) and classification (categories). Unsupervised learning trains on data without labels and finds patterns on its own: clustering is the example on the exam.

Watch the wording in scenarios. 'Assign each customer to one of our three loyalty tiers' uses known categories, so it is classification. 'Discover groups of customers with similar behavior' with no predefined groups is clustering.

Key terms

Clustering
Unsupervised learning that groups items with similar feature values.
Unsupervised learning
Machine learning on data without labels, which finds structure on its own.
Supervised learning
Machine learning on data that includes known labels, used to predict those labels.
k-means
A clustering algorithm that groups items around k center points, repeatedly adjusting the centers.
Real-world example

An online bookshop runs k-means on customers' purchase frequency, average spend and favorite genres, with k set to 4. It finds a cluster of high-spending crime fans who buy on release day, and designs a pre-order campaign just for them.

Exam tip: No labels and 'discover groups' means clustering. Known categories to predict means classification, even if the scenario uses the word 'group'.

Check yourself

Is clustering supervised or unsupervised, and why?

Unsupervised, because the training data has no labels; the algorithm finds groups from the features alone.

A school wants to predict whether students will pass or fail using last year's results. Clustering or classification?

Classification, because past results provide known labels (pass or fail).
