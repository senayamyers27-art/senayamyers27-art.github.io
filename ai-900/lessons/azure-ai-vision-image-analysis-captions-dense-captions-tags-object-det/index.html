Microsoft Certified: Azure AI Fundamentals AI-900 · Domain 3: Computer vision workloads on Azure

Azure AI Vision image analysis: captions, dense captions, tags, object detection, people detection and smart crops

▶ Watch the overview video

Last reviewed September 25, 2026

Azure AI Vision is the Azure AI service for analyzing images and video. Its image analysis feature gives you pretrained vision capabilities through a single API call: you send an image (as a URL or the image bytes) and say which visual features you want back. No training is needed. AI-900 expects you to match each feature to a scenario.

Captions generate a human-readable sentence describing the whole image, such as 'a man riding a bicycle down a city street', with a confidence score. Dense captions generate captions for up to several regions of the image, each with a bounding box, so you get a description of different parts of the scene. Captions are ideal for accessibility alt text and for making photo libraries searchable.

Tags return a list of words for things, settings and actions visible in the image, such as 'outdoor', 'tree', 'dog', 'grass', each with a confidence score. Tags are useful for indexing and search. Object detection returns objects with their bounding boxes and labels, for example three 'car' objects with coordinates. People detection specifically finds people and returns their bounding boxes, which supports counting and occupancy scenarios without identifying anyone.

Smart crops suggest a crop region that keeps the most important part of the image for a given aspect ratio, useful for generating thumbnails. The Read (OCR) feature extracts text, covered in its own lesson. Depending on the API version, there are also features such as background removal and multimodal embeddings for image search; check the current documentation for what your version supports.

To use the service, you create an Azure AI Vision resource (or a multi-service Azure AI services resource) and call its endpoint with a key or Microsoft Entra ID. You can explore the features without code in the vision try-it experience in the Microsoft Foundry portal or in Vision Studio, and then use the REST API or SDKs from your app. Some features are only available in certain regions.

When a scenario needs categories specific to your business, such as your own product models, prebuilt image analysis may not know them; that is when you train a custom model with your own labeled images.

Key terms

Caption
A generated sentence describing an image, returned with a confidence score.
Dense captions
Captions for multiple regions of an image, each with a bounding box.
Tag
A word describing something visible in an image, such as an object, setting or action.
Smart crop
A suggested crop region that keeps the area of interest for a given aspect ratio.
Real-world example

A museum uploads 40,000 digitized photos. Image analysis adds captions for screen-reader users, tags such as 'ship', 'harbour' and 'black and white' for search, smart crops for gallery thumbnails, and people detection to find photos that include visitors.

Exam tip: Sentence describing the image: captions. List of keywords: tags. Where things are: object or people detection. Thumbnail region: smart crops. Text in the image: OCR (Read).

Check yourself

Which image analysis feature best produces alt text for a screen reader?

Captions, because they generate a readable sentence describing the image.

How do dense captions differ from captions?

Dense captions describe several regions of the image, each with its own bounding box, instead of one sentence for the whole image.
