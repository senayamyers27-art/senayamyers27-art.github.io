How computer vision models work: pixels, filters, convolutional neural networks and multimodal models

To a computer, a digital image is an array of numbers. A grayscale image is a grid of pixel values, typically from 0 (black) to 255 (white). A color image has three such grids, one each for red, green and blue channels. Every computer vision technique starts from these numbers.
