Key phrase extraction, named entity recognition, entity linking and PII detection

▶ Watch the overview video

Last reviewed September 25, 2026

The next group of Azure AI Language features pulls specific information out of text. They answer questions like 'what is this about?', 'who and what is mentioned?' and 'is there personal data here?'. All are prebuilt, so you call them without training anything.

Key phrase extraction identifies the main talking points in a text and returns them as a list of phrases, such as 'delivery delay', 'refund request' and 'customer service team'. It works best on longer text and helps summarize what documents are about at a glance, tag content for search, or spot trending topics across many messages.

Named entity recognition (NER) finds references to entities and classifies them into categories such as Person, Location, Organization, DateTime, Quantity, Event, Product, URL, Email and PhoneNumber, some with subcategories. For 'Maria flew to Tokyo on 3 May to meet Contoso', NER returns Maria (Person), Tokyo (Location), 3 May (DateTime) and Contoso (Organization), each with its position in the text and a confidence score.

Entity linking goes a step further for well-known entities. It disambiguates which real-world thing an entity refers to, using the context, and links it to an entry in a knowledge base, typically Wikipedia. 'Mars' in an article about chocolate bars and 'Mars' in an article about space missions are linked to different entries. This is useful when the same name can mean different things.

Personally identifiable information (PII) detection finds sensitive personal data such as names, addresses, phone numbers, email addresses, government ID numbers and bank or credit card numbers. It returns the entities found and a redacted version of the text in which they are masked, for example with asterisks. There is also a health-focused feature, Text Analytics for health, that extracts medical entities such as conditions and medications.

These features often work together. A support system might extract key phrases to tag each ticket, run NER to pick out product names and dates, and run PII detection to redact card numbers before transcripts are stored or shared. That last step also supports the privacy and security principle of responsible AI.

Key terms

Key phrase extraction
Returning the main talking points of a text as a list of phrases.
Named entity recognition (NER)
Finding entities in text and classifying them as types such as Person, Location or Organization.
Entity linking
Identifying which known real-world entity a mention refers to and linking it to a knowledge base entry.
PII detection
Finding personal information in text and returning a redacted version.
Real-world example

A newsroom tags each article: key phrases become search tags, NER lists the people and places mentioned, entity linking makes sure 'Jordan' links to the country rather than the basketball player in a foreign affairs story, and PII detection strips readers' phone numbers from published comments.

Exam tip: Main topics: key phrases. Categorized mentions such as people and dates: NER. Disambiguate and link to Wikipedia: entity linking. Find and mask personal data: PII detection.

Check yourself

Which feature returns a redacted version of the text?

PII detection, which masks the personal information it finds.

What does entity linking add beyond NER?

It disambiguates which real-world entity is meant and links it to a knowledge base entry such as a Wikipedia page.
