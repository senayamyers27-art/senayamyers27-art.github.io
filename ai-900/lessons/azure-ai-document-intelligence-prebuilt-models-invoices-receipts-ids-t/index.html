Azure AI Document Intelligence: prebuilt models (invoices, receipts, IDs), the layout model and custom models

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Azure AI Document Intelligence (formerly Form Recognizer) is the Azure AI service for extracting text, structure and data from documents. It builds on OCR but returns much more: the layout of the page and, with the right model, named fields with values, ready to store in a database or pass to a business system.

Prebuilt models are trained by Microsoft on common document types and need no training from you. Examples include invoices (vendor, customer, invoice number, dates, line items, totals), receipts (merchant, date, items, subtotal, tax, total), identity documents such as passports and driving licences, business cards, and several tax and financial forms. Each extracted field comes with its value, its location on the page and a confidence score, so an app can route low-confidence documents to a person.

The layout model extracts text, tables (with rows, columns and cells), selection marks such as checkboxes, paragraphs and document structure from any document, without looking for specific named fields. The read model extracts text only. A general document option also finds key-value pairs. Use layout when you need structure from documents that no prebuilt model covers, or as a first step before custom processing.

Custom models handle document types unique to your organization. A custom extraction model learns to extract the fields you define from a set of your sample documents that you label in Document Intelligence Studio; a handful of labeled examples can be enough for a consistent form layout. A custom classification model identifies which type of document a file is, so you can route it to the right extraction model.

You create a Document Intelligence resource (or use a multi-service Azure AI services resource), then try models in Document Intelligence Studio without code, or call them through the REST API and SDKs. Documents can be sent as images or PDFs. A free F0 tier with limited pages is available for experiments.

The main exam distinction is between plain OCR and document intelligence. OCR in Azure AI Vision gives text and positions. Document Intelligence gives you meaning and structure: which text is the total, which rows form a table, which box is ticked.

Key terms

Prebuilt model
A Document Intelligence model trained by Microsoft for a common document type, such as invoices or receipts.
Layout model
A model that extracts text, tables, selection marks and structure from any document.
Custom extraction model
A model you train with labeled samples to extract your own fields from your own document type.
Selection mark
A checkbox or radio button on a form, returned as selected or unselected.
Real-world example

An expenses app lets staff photograph receipts. The prebuilt receipt model returns the merchant, date, tax and total, and the app fills in the expense claim automatically. The company's own mileage form has a unique layout, so the team labels ten examples and trains a custom extraction model for it.

Exam tip: Common business document with standard fields: prebuilt model. Tables and structure from any document: layout. Your own unique form: custom model trained on labeled samples.

Check yourself

A company needs line items and totals from supplier invoices. Which model should it try first?

The prebuilt invoice model, because it already extracts those fields without training.

What does a custom classification model do?

It identifies the type of each document so it can be sent to the right extraction model.
