Language detection, sentiment analysis and opinion mining

▶ Watch the overview video

Last reviewed September 25, 2026

Azure AI Language is the Azure AI service for understanding and analyzing text. It offers a set of prebuilt features that you call through one resource and one API, plus features you can customize. This lesson covers three of the most tested prebuilt features: language detection, sentiment analysis and opinion mining.

Language detection identifies the language a piece of text is written in. It returns the language name, its ISO code (such as 'fr' for French) and a confidence score between 0 and 1. It is useful for routing messages to the right team, choosing the right translation or processing pipeline, and tagging content. Very short or mixed-language text can give lower confidence; if the language cannot be determined, the service returns '(Unknown)' with a score of 0 rather than guessing.

Sentiment analysis evaluates whether text expresses a positive, neutral or negative opinion. It returns a label for the whole document and for each sentence, along with confidence scores for positive, neutral and negative that add up to 1. A document containing both strongly positive and negative sentences can be labelled mixed. Typical uses are analyzing product reviews, social media posts, survey comments and support transcripts to spot unhappy customers or measure reaction to a launch.

Opinion mining is an option of sentiment analysis that goes finer. It links opinions to specific targets (aspects) in the text. For 'The screen is gorgeous but the battery dies too fast', document-level sentiment might just say mixed, while opinion mining reports that 'screen' has a positive opinion ('gorgeous') and 'battery' has a negative one ('dies too fast'). Businesses use it to learn exactly which product features people like or dislike.

You can try these features without code in Language Studio or the language playground in the Microsoft Foundry portal, then call the REST API or SDK from your app, sending documents in batches. Results always include confidence scores, so your app can decide how to treat uncertain results.

Remember what these features do not do: they do not translate text, extract topics or create new text. They analyze existing text and return labels and scores.

Key terms

Azure AI Language
The Azure AI service that analyzes and understands text with prebuilt and customizable features.
Language detection
Identifying the language of text and returning its name, ISO code and a confidence score.
Sentiment analysis
Labeling text or sentences as positive, neutral, negative or mixed with confidence scores.
Opinion mining
Aspect-based sentiment that links opinions to specific targets mentioned in the text.
Real-world example

A phone maker analyzes 50,000 reviews. Language detection sorts them by language, sentiment analysis shows 72 percent are positive overall, and opinion mining reveals that most negative opinions target 'battery' and 'charger', guiding the next design.

Exam tip: Overall mood of text: sentiment analysis. Mood toward specific features mentioned: opinion mining. Which language: language detection. None of them translate.

Check yourself

What three sentiment scores does sentiment analysis return for each sentence?

Confidence scores for positive, neutral and negative, which add up to 1.

A restaurant wants to know how customers feel about its desserts and its service separately. Which feature?

Opinion mining, because it links sentiment to specific aspects such as desserts and service.
