Image classification vs object detection vs semantic segmentation

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Many computer vision questions on AI-900 come down to one decision: how much detail about the image does the scenario need? Is one answer for the whole image enough, does it need the location of each object, or does it need the exact shape of each object? Those three levels are image classification, object detection and semantic segmentation.

Image classification predicts a label for the whole image. The model looks at all the pixels and returns the class it thinks the image belongs to, usually with a confidence score, for example 'apple: 0.97'. Some classifiers are multilabel and return several tags for one image. Classification answers 'what is this a picture of?' but not 'where?' or 'how many?'. Typical uses are sorting product photos into categories, identifying plant species or flagging whether an X-ray looks normal.

Object detection finds each instance of the objects it knows about and returns, for every one, a class label, a confidence score and a bounding box: the coordinates of a rectangle around it. It answers 'what objects are in this picture, where are they and how many?'. Typical uses are counting vehicles in traffic footage, checking whether workers wear helmets, spotting empty shelf spaces or locating defects on a production line.

Semantic segmentation classifies each pixel in the image, so the output is a mask showing exactly which pixels belong to which class, such as road, pavement, car and sky. It gives precise shapes instead of rectangles, which matters in medical imaging (the exact outline of a tumour), self-driving cars (exactly where the road ends) and satellite imagery (the area of flooded land). Instance segmentation is a related technique that also separates individual objects of the same class.

These tasks are progressively more detailed and generally need more detailed training labels: a single tag per image for classification, boxes drawn around objects for detection and pixel-level masks for segmentation. Choose the simplest one that meets the requirement.

Image analysis in Azure AI Vision provides prebuilt tagging and object detection for thousands of everyday things. When you need your own classes, such as your company's product line or specific defects, you train a custom model from your labeled images.

Key terms

Image classification
Predicting one or more labels for an image as a whole.
Object detection
Locating each object in an image with a class label and bounding box.
Semantic segmentation
Classifying every pixel in an image to produce a precise mask of each class.
Confidence score
A value between 0 and 1 showing how sure the model is about a prediction.
Real-world example

A farm uses drones over its fields. Image classification labels each photo as 'healthy crop' or 'needs inspection'; object detection counts and locates individual sheep; semantic segmentation measures exactly how much of the field is waterlogged.

Exam tip: Whole image, one answer: classification. Where and how many: object detection with bounding boxes. Exact outline, pixel by pixel: segmentation.

Check yourself

A parking app must show which of 50 spaces in a camera image are occupied. Which technique fits?

Object detection, because it locates each car with a bounding box, so occupied spaces can be identified and counted.

What does semantic segmentation provide that object detection does not?

A pixel-level mask with the exact shape of each region, rather than a rectangle.
