Azure AI Translator for text and documents, and speech translation

▶ Watch the overview video

Last reviewed September 25, 2026

Translation is one of the oldest AI workloads, and modern neural machine translation has made it good enough for everyday business use. In Azure, text and document translation is provided by Azure AI Translator, while translation of spoken audio is provided by Azure AI Speech.

Early machine translation worked word by word or phrase by phrase, which produced awkward results because languages differ in word order, idioms and grammar. Neural machine translation uses deep learning models that consider the whole sentence and its context, producing much more fluent and accurate output. That is what Azure AI Translator uses.

Azure AI Translator's text translation translates text between a large number of supported languages. A single request can translate into several target languages at once. If you do not specify the source language, the service detects it and returns the detected language with the translation. Transliteration converts text from one script to another, such as from Cyrillic characters to Latin characters, without translating the meaning. A dictionary lookup returns alternative translations for a word.

You can control output in useful ways. A profanity filter can mark or remove profanity in translations. You can mark text that must not be translated, such as product names, and custom translation lets you train the service on your own parallel texts so domain terms are translated consistently, for example in legal or engineering content.

Document translation translates whole files, such as Word, PDF, PowerPoint and HTML documents, while preserving their structure and formatting. It works asynchronously on documents stored in Azure Blob Storage and writes the translated files back to storage, which suits translating manuals, contracts and policies at scale.

Speech translation in Azure AI Speech takes spoken audio in one language and returns translated text, and optionally synthesized speech, in another language in near real time. It combines speech recognition, translation and optionally speech synthesis in one step. Typical uses are live subtitles in another language at events, multilingual meetings and travel apps. For AI-900: written text or files, use Translator; spoken audio, use speech translation in Azure AI Speech.

Key terms

Neural machine translation
Translation by deep learning models that consider the whole sentence and its context.
Transliteration
Converting text from one writing script to another without translating its meaning.
Document translation
Translating whole files while preserving their structure and formatting.
Speech translation
Translating spoken audio into text or speech in another language in near real time.
Real-world example

A travel company uses Translator to publish its website in eight languages from one request per page, document translation to convert its 60-page booking terms PDF into Spanish with formatting intact, and speech translation so tour guides' spoken English appears as Japanese subtitles on visitors' phones.

Exam tip: Text or documents: Azure AI Translator. Spoken audio: speech translation in Azure AI Speech. Converting scripts without changing meaning: transliteration.
