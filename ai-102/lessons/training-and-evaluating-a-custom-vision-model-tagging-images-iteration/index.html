Training and evaluating a Custom Vision model: tagging images, iterations, precision, recall and mAP

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Training a Custom Vision model is a loop: collect images, tag them, train, evaluate, and improve the data. The model's quality depends far more on the images than on any setting.

Upload images through the Custom Vision portal or the training SDK and assign tags. For classification you tag whole images; for object detection you draw a bounding box around each object and tag it. Custom Vision requires a small minimum number of images per tag, but good models need more: Microsoft suggests roughly 50 or more per tag as a starting point. Images should vary the way real ones will: different angles, lighting, backgrounds, sizes and camera types. Keep tags balanced; if one tag has ten times more images than another, the model leans toward it. In classification projects, a Negative tag can be applied to images that contain none of your tags, teaching the model what 'none' looks like. For detection projects the Smart Labeler can suggest boxes after a first training to speed up labeling.

Each training run produces an iteration, a versioned model you can compare with earlier ones. Quick training is fast and fine for most projects; advanced training lets you give a compute time budget for harder problems and may improve accuracy.

After training, the portal shows metrics calculated on a held-out portion of your images. Precision answers: of the predictions the model made for a tag, how many were correct? Recall answers: of the images (or objects) that really had the tag, how many did the model find? Average precision (AP) summarizes precision and recall across thresholds for each tag, and mean average precision (mAP) averages AP across all tags, a single number for comparing object detection iterations.

The probability threshold slider changes which predictions count. Raising it keeps only confident predictions, which usually increases precision and lowers recall; lowering it does the opposite. Choose based on cost of errors: a medical screening tool may want high recall so few cases are missed, while an automatic product tagger may want high precision. For object detection, an overlap threshold sets how much a predicted box must overlap the true box (intersection over union) to count as correct.

To improve a weak tag, look at its false positives and false negatives with Quick Test and the Predictions tab, add varied images for confusing cases, fix wrong tags, and retrain. Images your app submits for prediction can be reviewed and added to training later.

Key terms

Iteration
A versioned model produced by one Custom Vision training run.
Precision
The fraction of the model's positive predictions for a tag that were correct.
Recall
The fraction of actual instances of a tag that the model found.
mAP
Mean average precision: the average of per-tag average precision, summarizing detection quality.
Real-world example

A plant nursery's classifier has 95% precision but 70% recall for 'diseased leaf', so it misses many sick plants. The team lowers the probability threshold, adds 80 more diseased-leaf photos in different light, retrains, and the new iteration reaches 88% recall with acceptable precision.

Exam tip: Precision is about how many predictions were right; recall is about how many real cases were found. Raising the threshold trades recall for precision. mAP is the headline metric for object detection.

Check yourself

What usually happens to precision and recall when you raise the probability threshold?

Precision rises because only confident predictions remain, and recall falls because more true cases are missed.

What is a Negative tag used for?

Marking classification training images that contain none of the project's tags, so the model learns what 'none of these' looks like.
