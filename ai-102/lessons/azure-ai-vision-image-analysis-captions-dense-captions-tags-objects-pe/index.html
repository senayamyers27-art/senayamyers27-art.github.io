Azure AI Vision Image Analysis: captions, dense captions, tags, objects, people and smart crops

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Azure AI Vision's Image Analysis API describes what is in an image using prebuilt models trained by Microsoft, with no training on your part. You send an image (as a URL or as binary data) and a list of visual features you want, and the service returns JSON with results and confidence scores. The current version, Image Analysis 4.0, is called at the imageanalysis:analyze path with a features query parameter, or through the ImageAnalysisClient in the Python and C# SDKs.

Each feature answers a different question. Caption returns one human-readable sentence describing the whole image, such as 'a man riding a bicycle on a city street'. Dense captions return sentences for several regions of the image (up to ten) as well as the whole image, each with a bounding box, which is useful for detailed descriptions and accessibility. Tags return single words for objects, living things, scenery and actions, each with a confidence score, useful for search and cataloging. Objects detects common physical objects and returns their names and bounding boxes, so you know where each object is and how many there are. People detects people and returns their bounding boxes; it does not identify who they are. Smart crops suggests crop regions that keep the most important area of the image for the aspect ratios you request, useful for thumbnails. Read extracts text, covered in the next lesson.

from azure.ai.vision.imageanalysis import ImageAnalysisClient
from azure.ai.vision.imageanalysis.models import VisualFeatures

client = ImageAnalysisClient(endpoint=endpoint, credential=AzureKeyCredential(key))
result = client.analyze(image_data=data,
    visual_features=[VisualFeatures.CAPTION, VisualFeatures.TAGS, VisualFeatures.OBJECTS],
    gender_neutral_caption=True)
print(result.caption.text, result.caption.confidence)
for obj in result.objects.list:
    print(obj.tags[0].name, obj.bounding_box)

Useful options include gender-neutral-caption (so captions say 'person' instead of 'man' or 'woman'), language for tags and captions in other languages, and aspect ratios for smart crops. Caption and dense captions are available only in some Azure regions, so check region support before creating the resource. Some older features from version 3.2, such as brand detection, adult content flags and image categories, belong to the earlier API; for moderation, use Azure AI Content Safety instead.

Interpret confidence scores sensibly: set a threshold appropriate to your use, for example only use tags above 0.8 for automatic cataloging and send lower ones for human review. Remember what prebuilt models cannot do: they recognize general concepts, not your specific product models or defect types. For those you need a custom model, which the Custom Vision lessons cover.

Key terms

Caption
An Image Analysis feature that returns one sentence describing the whole image.
Dense captions
An Image Analysis feature that returns captions with bounding boxes for multiple regions of an image.
Tags
Single-word labels for content in an image, each with a confidence score.
Smart crops
Suggested crop regions that preserve the most important part of an image for given aspect ratios.
Real-world example

A news site generates alt text for every photo with the caption feature (gender neutral), stores tags above 0.8 confidence for its photo search, and uses smart crops at 1:1 and 16:9 to create thumbnails that keep faces and subjects in frame.

Exam tip: One sentence for the whole image is caption; sentences with boxes for regions is dense captions; single words are tags; where things are is objects; detecting people is not identifying them.

Check yourself

Which feature tells you how many cars are in a photo and where they are?

Objects, which returns each detected object's name and bounding box.

A site needs thumbnails in several aspect ratios that keep the main subject. Which feature helps?

Smart crops with the required aspect ratios.
