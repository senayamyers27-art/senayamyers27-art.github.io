Text to speech with neural voices and SSML for pronunciation, pauses, rate and style

▶ Watch the overview video

Last reviewed September 25, 2026

Text to speech (speech synthesis) turns text into natural-sounding audio. Azure AI Speech offers hundreds of prebuilt neural voices across many languages and locales, named like en-US-AvaMultilingualNeural or en-GB-SoniaNeural. Uses include voice assistants, reading content aloud for accessibility, phone systems and audio versions of articles.

In the Speech SDK you create a SpeechConfig, set speech_synthesis_voice_name to the voice you want, and create a SpeechSynthesizer. By default it plays through the speaker; to save a file, pass an AudioConfig with a filename, and you can choose the output format (such as a particular sample rate of MP3 or WAV) on the config. Call speak_text_async for plain text or speak_ssml_async for SSML. As with recognition, check the result reason: SynthesizingAudioCompleted means success and Canceled carries error details. A batch synthesis API handles long content such as audiobooks asynchronously.

Plain text gives the voice's default reading. Speech Synthesis Markup Language (SSML), an XML format, gives you fine control. Everything sits in a <speak> root with a version, namespace and xml:lang, and a <voice name="..."> element chooses the voice, so one document can switch voices for a dialogue.

<speak version="1.0" xmlns="..." xmlns:mstts="..." xml:lang="en-US">
  <voice name="en-US-AvaMultilingualNeural">
    <mstts:express-as style="cheerful">Your order has shipped!</mstts:express-as>
    <break time="500ms"/>
    It will arrive on <say-as interpret-as="date" format="mdy">10/14/2026</say-as>.
    <prosody rate="slow" pitch="low">Please keep your receipt.</prosody>
  </voice>
</speak>

Key elements: <prosody> changes rate (for example slow, fast or a percentage), pitch and volume; <break> inserts a pause of a given time or strength; <say-as> tells the voice how to read values such as dates, times, cardinal numbers, telephone numbers or characters spelled out; <phoneme> specifies exact pronunciation with a phonetic alphabet such as IPA; <sub alias="..."> substitutes a spoken form, such as reading 'WHO' as 'World Health Organization'; a custom lexicon can define pronunciations for many words at once; <emphasis> stresses words; and <mstts:express-as> applies a speaking style such as cheerful, sad or customerservice for voices that support styles.

In a real document the two xmlns attributes hold the standard SSML and Microsoft (mstts) namespace identifiers, which the documentation and Speech Studio insert for you. Choose SSML whenever you need control over pronunciation, pacing or emotion; plain text is fine for simple announcements.

Key terms

Neural voice
A prebuilt synthetic voice generated by deep neural networks for natural-sounding speech.
SSML
Speech Synthesis Markup Language, XML that controls voice, pronunciation, pauses, rate and style.
prosody
The SSML element that adjusts speaking rate, pitch and volume.
say-as
The SSML element that controls how values like dates, numbers and letters are read.
Real-world example

A pharmacy's phone line read prescription numbers as large numbers ('four thousand two hundred') and rushed through instructions. Wrapping the numbers in say-as with interpret-as characters, adding breaks between steps and slowing the instructions with prosody made the calls clear for older customers.

Exam tip: Speed and pitch: prosody. Pauses: break. Dates, numbers and spelling: say-as. Exact pronunciation: phoneme or a lexicon. Emotion or style: mstts:express-as.

Check yourself

Which SSML element would make a voice read '2026' as 'two zero two six'?

say-as with interpret-as set to characters (or digits), which reads each character separately.

How do you save synthesized speech to a file with the SDK?

Create an AudioConfig with a filename and pass it to the SpeechSynthesizer, optionally setting the output format on SpeechConfig.
