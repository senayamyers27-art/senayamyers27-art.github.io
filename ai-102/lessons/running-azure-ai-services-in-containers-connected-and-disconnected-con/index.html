Running Azure AI services in containers: connected and disconnected containers and billing settings

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Some Azure AI capabilities are available as Docker containers that you run on your own hardware, in Azure Kubernetes Service, Azure Container Instances or at the edge. Containers bring the model close to the data, which helps when data must stay on premises for compliance, when latency to the cloud is too high, or when you need to control throughput yourself. Containers are available for selected features, including parts of Language (such as sentiment and language detection), Speech to text and text to speech, Translator, Vision Read and Document Intelligence. Check which features are offered before planning.
