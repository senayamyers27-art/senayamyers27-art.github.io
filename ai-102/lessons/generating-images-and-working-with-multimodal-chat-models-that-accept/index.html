Generating images and working with multimodal chat models that accept images

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Generative AI is not limited to text. Two capabilities appear on the exam: creating images from text, and sending images to a chat model so it can reason about them.

Image generation models such as DALL-E 3, and newer GPT image models where available, create new images from a natural language prompt. You deploy the model like any other and call the images API with a prompt, the number of images, a size (DALL-E 3 supports square, wide and tall formats) and options such as quality and style. The response returns either a URL to the generated image, valid for a limited time, or the image encoded as base64 data. DALL-E 3 may rewrite your prompt to add detail, and the response includes the revised prompt. Image models apply content filters to both the prompt and the generated image, and they refuse requests for public figures or copyrighted characters in many cases. Good prompts describe subject, setting, style, lighting and composition explicitly.

Multimodal chat models, such as GPT-4o and other vision-enabled models, accept images as part of the user message. Instead of a plain string, the message content is a list of parts: a text part with the question and one or more image parts containing either a URL the service can fetch or a base64 data URL. The model can describe the image, answer questions about it, read text and charts in it, compare several images or extract information into JSON.

resp = client.chat.completions.create(
    model="vision-chat",
    messages=[{"role": "user", "content": [
        {"type": "text", "text": "What trend does this sales chart show?"},
        {"type": "image_url", "image_url": {"url": data_url}}
    ]}])

Images consume tokens, and the cost depends on the image size and the detail setting: low detail processes a small version for a fixed low cost, while high detail tiles the image for more accuracy at higher cost. Choose low detail when a rough understanding is enough.

Know when to use which tool. A multimodal model is flexible and great for open-ended questions about an image, but for high-volume, well-defined tasks such as extracting fields from invoices or tagging millions of photos, purpose-built services like Document Intelligence and Azure AI Vision are usually cheaper, faster and more consistent. Generating new pictures always needs an image generation model; chat models describe images but do not draw them.

Key terms

Image generation model
A model such as DALL-E 3 that creates new images from a text prompt.
Multimodal model
A model that accepts more than one type of input, such as text and images, in the same request.
Revised prompt
The expanded prompt DALL-E 3 actually used, returned alongside the generated image.
Detail setting
An option that controls how much of an input image the model processes, trading cost for accuracy.
Real-world example

An insurance app lets customers photograph car damage. A vision-enabled chat model describes the visible damage and fills a JSON claim summary for an adjuster to review, while the marketing team separately uses DALL-E 3 to create illustrations for the claims guide.

Exam tip: Creating pictures means an image generation model; asking questions about a picture means sending it as an image part to a vision-enabled chat model. For high-volume structured extraction, prefer Document Intelligence or Vision.

Check yourself

How do you send an image to a multimodal chat model?

Make the user message content a list with a text part and an image_url part containing a URL or base64 data URL.

What two forms can an image generation response return?

A temporary URL to the image or the image as base64-encoded data.
