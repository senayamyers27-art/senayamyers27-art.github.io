Azure AI Foundry Agent Service: agents, threads, messages and runs

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Azure AI Foundry Agent Service is a managed service for building and hosting agents. It handles the parts that are tedious to build yourself: storing conversation state, calling tools, managing files and vector stores, applying content filters and tracing. You define the agent, and the service runs the loop of model calls and tool calls. You can create agents in the Agents page of a Foundry project or in code with the Azure AI Projects or Agents SDKs for Python, C# and other languages.
