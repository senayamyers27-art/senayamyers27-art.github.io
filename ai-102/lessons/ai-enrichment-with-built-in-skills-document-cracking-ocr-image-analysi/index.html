Microsoft Certified: Azure AI Engineer Associate AI-102 · Domain 6: Implement knowledge mining and information extraction solutions

AI enrichment with built-in skills: document cracking, OCR, image analysis, entities and key phrases in a skillset

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Raw content is often not searchable as-is: scanned PDFs are images, photos have no text, and long documents bury the people and places mentioned in them. AI enrichment in Azure AI Search uses a skillset, attached to an indexer, to run AI steps on each document during indexing and add the results as new searchable fields.

The pipeline has stages. Document cracking is performed by the indexer: it opens files such as PDFs, Office documents and HTML, extracts their text into a content field and extracts metadata. If you set the indexer's imageAction to generateNormalizedImages, it also extracts embedded images and page images, normalized for analysis, into a normalized_images collection. Then the skills run, each reading inputs from the enrichment tree (an in-memory document structure) and writing outputs back to it, so one skill's output can feed another. Finally, output field mappings copy enriched values from the tree into index fields.

Built-in skills cover common needs. The OCR skill reads printed and handwritten text from normalized images, and the Merge skill combines that text back into the content in the right place. The Image Analysis skill generates captions, tags and objects for images. Language detection, key phrase extraction, entity recognition (people, organizations, locations and more), PII detection and sentiment work on text, and the Translation skill translates it. The Text Split skill breaks documents into pages or chunks, and the Azure OpenAI Embedding skill creates vectors for vector search. Utility skills such as Shaper (build complex output shapes) and Conditional (choose values by rule) organize data.

Each skill has a context, the level at which it runs, such as /document for once per document or /document/normalized_images/* for once per image, and inputs and outputs addressed with paths like /document/content. Skills are billed through an Azure AI services multi-service resource attached to the skillset (by key or managed identity). Without one, only a small number of documents per indexer per day can be enriched for free, which is enough for learning but not for real workloads.

Incremental enrichment caches enriched output in a storage account so that when you edit a skillset, only the affected skills rerun, saving time and cost. Debug sessions in the portal let you inspect the enrichment tree for a single document and fix mappings interactively. The Import data wizard builds a data source, skillset, index and indexer in a few clicks and is the fastest way to start.

Key terms

Skillset
A collection of AI enrichment skills that an indexer runs during indexing.
Document cracking
The indexer step that opens files and extracts text, metadata and images.
Enrichment tree
The in-memory structure holding a document's original and enriched data as skills run.
Output field mapping
A mapping that copies enriched values from the enrichment tree into index fields.
Real-world example

An engineering firm has 30 years of scanned drawings and reports. The indexer generates normalized images, the OCR and Merge skills make the scanned text searchable, the entity recognition skill extracts organizations and locations into filterable fields, and key phrases feed a facet so engineers can browse by topic.

Exam tip: Scanned text needs imageAction generateNormalizedImages plus the OCR skill. Enriching more than a handful of documents needs an attached Azure AI services resource. Enriched values reach the index through output field mappings.

Check yourself

What must be set on the indexer for the OCR skill to receive images?

imageAction set to generateNormalizedImages (or generateNormalizedImagePerPage), so images are extracted and normalized.

What does incremental enrichment save?

Rerunning unchanged skills: cached output lets only the skills affected by a change run again.
