Custom Vision: image classification (multiclass vs multilabel) vs object detection

▶ Watch the overview video

Last reviewed September 25, 2026

Prebuilt Image Analysis knows thousands of general concepts but not your specific ones: your product range, your defect types, your plant species. Azure AI Custom Vision lets you train your own image models from your own labeled images with little machine learning knowledge, using a web portal or SDK. Microsoft has announced a future retirement for Custom Vision and points new projects toward other options, so check its current status, but it remains part of the AI-102 objectives.

The first decision is the project type. Image classification assigns labels (called tags) to a whole image. It answers 'what is this image of?' but not 'where'. Object detection finds instances of objects in an image and returns a tag and a bounding box for each, so it answers 'what and where, and how many?'.

Classification comes in two kinds. Multiclass means each image has exactly one tag from the set: a photo is a cat or a dog or a rabbit, never two. The model returns probabilities for each tag and you take the top one. Multilabel means an image can have any number of tags at once: a photo of a street might be tagged car, bicycle and traffic light. Choose based on whether your categories are mutually exclusive.

Object detection needs more labeling effort, because you draw a box around every instance of every object in every training image. It is needed when location or count matters: finding each scratch on a panel, counting products on a shelf, locating a logo in a video frame.

You also choose a domain, which is the base model Custom Vision starts from. General domains suit most tasks; specialized domains exist for food, landmarks and retail (classification) or logos and products on shelves (detection). Compact domains produce smaller models that can be exported to run offline on devices, at some cost in accuracy. You cannot export a non-compact model, so if offline use is a requirement, choose a compact domain from the start (you can change domains later and retrain).

A Custom Vision solution uses two resources: a training resource where you upload images, tag and train, and a prediction resource that hosts published models for your app to call. A single multi-service or Custom Vision resource can play both roles.

Key terms

Multiclass classification
A classification type where each image gets exactly one tag.
Multilabel classification
A classification type where each image can have any number of tags.
Object detection
A model type that returns a tag and bounding box for each instance of an object in an image.
Compact domain
A Custom Vision base model that produces smaller, exportable models for offline and edge use.
Real-world example

A recycling plant wants to sort items on a conveyor. Each camera frame shows several items, and the robot arm needs each item's position and material. The team builds an object detection project with tags plastic, glass and metal on a compact domain so the model can run on the line's edge device.

Exam tip: Exactly one label per image: multiclass. Several labels per image: multilabel. Location or count: object detection. Offline or edge: compact domain.

Check yourself

A photo of a meal must be tagged with every ingredient visible. Which project type?

Multilabel classification, because each image can have several tags and locations are not needed.

Why would you choose a compact domain?

To export the model and run it offline on devices such as phones or edge hardware.
