ISACA Certified Information Systems Auditor (CISA) 2024 job practice · Domain 5: Protection of information assets

Network and endpoint security: firewalls, segmentation, IDS/IPS, remote access and EDR

▶ Watch the overview video

Last reviewed September 29, 2026 · Leer en español

Networks connect everything, which also lets attackers move from one system to another. Network and endpoint security aim to limit who can reach what, detect malicious activity and protect the devices people use.

Firewalls filter traffic based on rules. Packet filters look at addresses and ports; stateful firewalls track connections; next-generation and application firewalls understand applications and can inspect content. Web application firewalls protect web apps from attacks such as injection. Rule sets should deny by default, allow only what is needed, have a documented business owner for each rule, log important traffic and be reviewed periodically to remove unused, overly broad or shadowed rules. Segmentation divides the network into zones, such as a DMZ for internet-facing servers, separate segments for payment systems or IoT devices, and restricted admin networks, so that a compromise in one zone cannot easily spread. Zero trust takes this further by verifying every request rather than trusting network location.

Intrusion detection systems (IDS) monitor traffic or hosts and alert on suspicious activity; intrusion prevention systems (IPS) sit inline and can block it. Both need tuning to reduce false positives and someone to act on alerts. Remote access should use encrypted connections such as VPNs or zero trust network access, with multifactor authentication and posture checks on devices.

Endpoints include laptops, desktops, servers and mobile devices. Controls include hardened configurations, patching, host firewalls, anti-malware and endpoint detection and response (EDR) tools that record behavior and help investigate and contain threats, disk encryption and application allow listing. The auditor reviews firewall rule sets and change records, segmentation diagrams, IDS/IPS alert handling, remote access configuration and endpoint coverage reports.

Key terms

Network segmentation
Dividing a network into zones with controlled traffic between them to limit the spread of attacks.
Intrusion prevention system (IPS)
An inline device that detects and blocks malicious network traffic.
Endpoint detection and response (EDR)
Software that monitors endpoint behavior to detect, investigate and contain threats.
Demilitarized zone (DMZ)
A network segment that hosts internet-facing services, separated from the internal network.
Real-world example

Reviewing a firewall, an auditor finds an allow-any rule added during an outage two years ago and never removed, plus 60 rules with no owner. She recommends removing the broad rule, assigning owners and scheduling semiannual rule reviews.

Exam tip: IDS detects and alerts; IPS sits inline and blocks. Firewall rule sets should deny by default, and rules near the top that allow any traffic defeat everything below them.

Check yourself

What is the main difference between an IDS and an IPS?

An IDS only detects and alerts; an IPS is inline and can block traffic.

Why segment a network?

To limit how far an attacker or malware can spread after compromising one system and to protect sensitive zones.
