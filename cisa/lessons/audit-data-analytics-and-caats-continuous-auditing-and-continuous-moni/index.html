ISACA Certified Information Systems Auditor (CISA) 2024 job practice · Domain 1: Information system auditing process

Audit data analytics and CAATs, continuous auditing and continuous monitoring

▶ Watch the overview video

Last reviewed September 29, 2026 · Leer en español

Modern organizations process millions of transactions, and sampling a few dozen can miss patterns that only appear across the whole population. Data analytics and computer-assisted audit techniques (CAATs) let the auditor test entire populations quickly and precisely.

Generalized audit software and data analysis tools, including spreadsheets, SQL and scripting languages, let an auditor import data and run tests such as finding duplicate payments, gaps in invoice numbers, transactions posted on weekends, vendors sharing bank accounts with employees, or orders just below an approval limit. Other CAATs include test data (running dummy transactions through the live program to check its logic), parallel simulation (the auditor reprocesses real data with their own program and compares results) and the integrated test facility (fictitious entities set up in production so test transactions flow alongside real ones).

Continuous auditing moves testing close to real time. Techniques include embedded audit modules, which flag transactions meeting audit criteria as they are processed, and snapshot or audit hooks that capture data at points in processing. Continuous monitoring, in contrast, is a management responsibility: management uses automated tools to watch its own controls and key indicators. Auditors may rely on well-designed continuous monitoring, but it is still management's control.

Using analytics brings its own controls. The auditor must confirm the data extracted is complete and accurate, for example by reconciling record counts and totals to the source system, must protect sensitive data during analysis, and should have read-only access so the audit cannot change production data. Evaluating automated and decision-making systems, including AI models, also falls here: the auditor asks how their outputs are validated and monitored.

Key terms

CAAT
Computer-assisted audit technique: using software to extract and analyze data or test system logic as part of an audit.
Parallel simulation
Reprocessing production data with auditor-controlled software and comparing the results with the production output.
Embedded audit module
Code inside an application that selects transactions meeting audit criteria as they are processed.
Continuous monitoring
Management's ongoing, automated oversight of controls and key indicators.
Real-world example

Using a year of accounts payable data, an auditor joins the vendor master file with the employee file on bank account number and finds two vendors paid into employees' accounts. She reconciles her extract to the ledger totals first to prove the data was complete.

Exam tip: Before trusting any analytics result, verify the completeness and accuracy of the extracted data. And remember that continuous monitoring belongs to management, while continuous auditing belongs to audit.

Check yourself

What is the main advantage of data analytics over sampling?

It can test 100% of the population, catching patterns and exceptions that a sample would likely miss.

What should the auditor do before analyzing an extract?

Confirm it is complete and accurate by reconciling counts and totals to the source system.
