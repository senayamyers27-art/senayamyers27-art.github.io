Relational databases on Google Cloud: Cloud SQL, AlloyDB and Spanner

▶ Watch the overview video

Last reviewed September 25, 2026

Relational databases store data in tables of rows and columns with defined relationships, use SQL, and support transactions that keep data consistent: either all of a change happens or none of it does. They run most business applications, from online shops to banking. Google Cloud offers three main managed relational services, and the exam asks you to choose between them.

Cloud SQL is a fully managed service for MySQL, PostgreSQL and SQL Server. Google handles provisioning, patching, backups, replication and failover, so teams stop spending time on routine database administration. It is the natural target when you move an existing application's database to the cloud with few changes (a replatform). Cloud SQL scales well for most regional workloads, mainly by moving to larger machines (vertical scaling) and adding read replicas.

AlloyDB for PostgreSQL is a fully managed, PostgreSQL-compatible database designed for demanding workloads. It targets high performance for transactional work and fast analytical queries on the same data. It suits organizations that want PostgreSQL compatibility but need more performance than a standard managed PostgreSQL instance provides.

Spanner is a fully managed relational database that scales horizontally, adding capacity by adding nodes, while keeping strong consistency. It can span multiple regions and is built for very high availability. It supports SQL and transactions like a traditional database, but at a global scale that normally requires sharding by hand. Typical uses are global financial systems, inventory, gaming and any application that has outgrown a single database server.

A simple way to choose: an existing MySQL, PostgreSQL or SQL Server application with normal scale, choose Cloud SQL. PostgreSQL applications that need higher performance or mixed transactional and analytical work, consider AlloyDB. Relational data that must scale horizontally or serve users worldwide with strong consistency, choose Spanner. Database Migration Service helps move existing databases into Cloud SQL and AlloyDB.

Key terms

Relational database
A database that stores data in related tables and uses SQL and transactions.
Cloud SQL
Managed MySQL, PostgreSQL and SQL Server databases.
AlloyDB
A managed, high-performance PostgreSQL-compatible database.
Spanner
A horizontally scalable, strongly consistent relational database that can span regions.
Real-world example

A regional online shop moves its MySQL database to Cloud SQL and stops worrying about backups and patching. Years later, after expanding to three continents, it moves its order system to Spanner so orders from every region write to one consistent database without manual sharding.

Exam tip: Keywords: 'existing MySQL/PostgreSQL/SQL Server, minimal changes' means Cloud SQL; 'global, horizontal scale, strong consistency' means Spanner; 'PostgreSQL-compatible, high performance' means AlloyDB.

Check yourself

Which relational service fits a globally distributed application that needs strong consistency?

Spanner.

MySQL, PostgreSQL and SQL Server.
