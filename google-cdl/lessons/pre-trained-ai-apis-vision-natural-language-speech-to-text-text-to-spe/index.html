Pre-trained AI APIs: Vision, Natural Language, Speech-to-Text, Text-to-Speech and Translation

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

The fastest way to add AI to an application is to call a pre-trained model through an API. Google has already trained these models on very large data sets, so you send your data, such as an image, a document or an audio file, and receive results in seconds. You need no training data, no ML expertise and no infrastructure, and you typically pay per use, with a free monthly allowance for many of them.

The Cloud Vision API analyzes images. It can detect objects and labels (such as 'dog' or 'beach'), read printed and handwritten text through optical character recognition (OCR), detect faces (not identify people), landmarks and logos, and flag explicit content with SafeSearch. The Video Intelligence API does similar analysis on video.

The Cloud Natural Language API analyzes text. It can find sentiment (positive or negative), extract entities such as people, places and products, classify content into categories and analyze syntax. It is useful for reviewing customer feedback, routing support tickets or organizing documents.

Speech-to-Text converts spoken audio into text, which is useful for transcribing calls, adding captions and voice commands. Text-to-Speech does the opposite, producing natural-sounding speech from text in many languages and voices, for example for phone systems or accessibility. The Cloud Translation API translates text between many languages and can detect the source language.

Document AI is a related service for extracting structured data, such as fields and tables, from documents like invoices, receipts and forms.

Pre-trained APIs are ideal when your problem is a common one that general models already handle well. If you need to recognize things specific to your business, such as your own product defects or industry jargon, you may need a customized model through AutoML or custom training instead. On the exam, choose a pre-trained API when a scenario stresses speed, no ML team and a common task.

Key terms

Pre-trained model
A model already trained by the provider that you can use immediately without your own training data.
OCR
Optical character recognition: extracting text from images of printed or handwritten documents.
Sentiment analysis
Determining whether text expresses a positive, negative or neutral opinion.
Entity extraction
Identifying names of people, places, organizations and other items in text.
Real-world example

A hotel chain sends every guest review to the Natural Language API to score sentiment and pull out mentioned topics such as 'breakfast' or 'wifi'. Negative reviews about specific topics are routed to the right manager the same day, with no data science team involved.

Exam tip: Common task plus no ML skills plus need it quickly equals a pre-trained API. The Vision API reads text in images; the Natural Language API analyzes meaning in text; Translation converts between languages.

Check yourself

Which API would you use to transcribe recorded customer calls?

Speech-to-Text.

When is a pre-trained API not enough?

When the task is specific to your business, such as your own product defects or specialized terms, so a customized model is needed.
