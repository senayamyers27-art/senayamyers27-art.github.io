APIs and API management with Apigee

▶ Watch the overview video

Last reviewed September 25, 2026

An application programming interface (API) is a defined way for one piece of software to request data or actions from another. When a mobile banking app shows your balance, it calls the bank's API; when an online shop shows shipping rates, it calls a carrier's API. APIs hide the complexity of the systems behind them and let those systems be reused in new ways.

APIs are central to digital transformation. They let organizations unlock data and functions trapped in legacy systems and expose them to new apps, partners and channels without rewriting the back end. They let microservices work together. And they create new business models: a company can offer its capabilities as products that partners build on, sometimes for a fee. A retailer might publish product and inventory APIs so marketplace partners list its goods automatically.

Once APIs are shared outside a single team, they need to be managed like products. API management covers security (authentication with API keys or OAuth, protection from abuse), traffic management (rate limits and quotas so one consumer cannot overload the back end), analytics (who uses which APIs and how they perform), versioning so changes do not break consumers, a developer portal with documentation and self-service sign-up, and, when needed, monetization.

Apigee is Google Cloud's API management platform. It sits as a proxy layer in front of back-end services, wherever they run, on Google Cloud, on-premises or in other clouds, and applies policies for security, rate limiting, transformation and caching. It provides dashboards on API traffic and business metrics, and portals for developers. Because the proxy decouples consumers from back ends, an organization can modernize the systems behind an API without changing the apps that call it.

For the exam, when a scenario involves sharing services securely with partners or developers, controlling usage with quotas, analyzing API traffic or monetizing APIs, the answer is Apigee.

Key terms

API
Application programming interface: a defined way for software to request data or actions from other software.
API management
Securing, controlling, monitoring and publishing APIs as products.
Apigee
Google Cloud's API management platform.
Rate limiting
Restricting how many requests a consumer can make in a period to protect back-end systems.
Real-world example

A hospital group wants to let approved health apps show patients their appointment times. It exposes an appointments API through Apigee, which checks each app's credentials, limits request rates, logs usage for audits and offers a developer portal, while the old scheduling system behind it stays unchanged.

Exam tip: APIs unlock legacy data and enable partner ecosystems. Apigee manages them: security, quotas, analytics, developer portals and monetization.

Check yourself

How can APIs help modernize a legacy system without rewriting it?

An API exposes the legacy system's data and functions to new apps; the back end can later be replaced without changing the consumers.

Name four capabilities of API management.

Security, rate limiting and quotas, analytics, versioning, developer portals and monetization (any four).
