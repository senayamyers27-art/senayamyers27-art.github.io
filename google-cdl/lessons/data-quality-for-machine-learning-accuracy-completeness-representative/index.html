Data quality for machine learning: accuracy, completeness, representativeness and bias

▶ Watch the overview video

Last reviewed September 25, 2026

A machine learning model learns only from the data it is trained on. If that data is poor, the model will be poor, however advanced the algorithm. This is often summarized as 'garbage in, garbage out', and it is why data quality is part of the AI section of the exam.

Several dimensions of quality matter. Accuracy: values must be correct. Mislabeled training examples, such as fraudulent transactions marked as normal, teach the model the wrong thing. Completeness: missing values or missing records leave gaps in what the model can learn. Consistency: the same thing should be recorded the same way across sources, such as dates and units. Timeliness: data should reflect current conditions; a demand model trained only on pre-pandemic data may fail today. Relevance: the features used should actually relate to what you want to predict.

Representativeness is especially important. Training data must cover the full range of cases the model will see in real use. A model trained mostly on customers from one city, one age group or one type of device may perform badly or unfairly for others. That leads to bias: systematic errors that disadvantage certain groups. Bias can come from historical data that reflects past unfair decisions, from how data was collected, or from how it was labeled.

Volume matters too. More relevant, good-quality examples generally help a model learn, but a huge amount of biased or wrong data does not.

Improving quality is ongoing work. Teams profile data to find missing or odd values, clean and standardize it, check that important groups are represented, have labels reviewed, and monitor model performance across groups after deployment. Governance tools that track data lineage and quality help. In Google Cloud, data can be prepared in BigQuery or Dataflow, and Vertex AI offers tools to evaluate models and explain their predictions.

Key terms

Training data
The examples a model learns from.
Representative data
Data that covers the full range of cases and groups the model will face in real use.
Bias (in ML)
Systematic errors in a model's output that unfairly favor or disadvantage certain groups.
Label
The correct answer attached to a training example in supervised learning.
Real-world example

A bank's credit model trained on ten years of approvals gives lower scores to applicants from certain neighborhoods, because past human decisions in the data were biased. The team rebalances the data, removes features that act as proxies for protected characteristics and checks accuracy for each group before release.

Exam tip: When a model works well for one group but poorly for another, the most likely cause is unrepresentative training data, not a lack of computing power.

Check yourself

List four dimensions of data quality for ML.

Accuracy, completeness, consistency, timeliness, relevance and representativeness (any four).

How can historical data introduce bias?

If past decisions in the data were unfair, the model learns and repeats those patterns.
