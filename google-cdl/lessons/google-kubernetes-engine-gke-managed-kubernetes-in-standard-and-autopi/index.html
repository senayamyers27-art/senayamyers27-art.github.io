Google Kubernetes Engine (GKE): managed Kubernetes in Standard and Autopilot modes

▶ Watch the overview video

Last reviewed September 25, 2026

Kubernetes is an open source platform for orchestrating containers: it decides where containers run, keeps the desired number running, restarts failed ones, scales them, and connects them with networking and load balancing. It began as a Google project based on Google's experience running containers internally, and it is now the industry standard, available in every major cloud and on-premises.

In Kubernetes, you describe the desired state, for example 'run five copies of this container image and expose them on port 443', and Kubernetes continuously works to make reality match. A cluster has a control plane that makes decisions and nodes, the machines that run the workloads. Containers run inside pods, the smallest deployable unit.

Running Kubernetes yourself is complex: installing and upgrading the control plane, securing it, and managing nodes. Google Kubernetes Engine (GKE) is Google Cloud's managed Kubernetes service. Google runs the control plane, handles upgrades and integrates the cluster with Google Cloud networking, load balancing, logging, monitoring and security.

GKE offers two modes of operation. In Standard mode, you manage the nodes: you choose machine types, configure node pools and pay for the node VMs whether or not they are fully used. This gives more control and flexibility. In Autopilot mode, Google also manages the nodes and underlying infrastructure, applies best-practice security settings, and you are billed for the CPU, memory and storage your pods request. Autopilot reduces operational work and wasted capacity, so it is often recommended for teams that want Kubernetes without managing infrastructure.

GKE fits containerized applications that need the power of Kubernetes: many microservices, complex networking, stateful workloads, batch jobs or a desire to use the Kubernetes ecosystem and keep workloads portable. For simpler stateless services, Cloud Run may be easier. GKE Enterprise extends GKE management to clusters outside Google Cloud.

Key terms

Kubernetes
An open source system for automating deployment, scaling and management of containers.
GKE
Google Kubernetes Engine, Google Cloud's managed Kubernetes service.
Autopilot
A GKE mode where Google manages nodes and infrastructure and billing is based on pod resource requests.
Pod
The smallest deployable unit in Kubernetes, containing one or more containers.
Real-world example

An e-commerce company runs 40 microservices on GKE. It chooses Autopilot so its small platform team does not have to size or patch nodes, and pays for the resources its pods request. During a sale, Kubernetes scales the checkout service out while leaving the rest unchanged.

Exam tip: Want Kubernetes without managing nodes: GKE Autopilot. Want control over node configuration: GKE Standard. Remember that Kubernetes itself is open source and started at Google.

Check yourself

What does Google manage in GKE Autopilot that the customer manages in Standard?

The nodes and underlying infrastructure, including their sizing, scaling and security configuration.

What is desired state in Kubernetes?

A declaration of what should be running; Kubernetes continuously acts to make the actual state match it.
