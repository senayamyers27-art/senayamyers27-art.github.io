Hybrid and multicloud with GKE Enterprise (formerly Anthos)

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Many organizations run applications across several environments: their own data centers, Google Cloud, other public clouds and edge locations such as stores or factories. They may do so for regulation, latency, existing investments, mergers or to avoid dependence on one provider. The challenge is that each environment has its own tools, security settings and operating processes, so teams spend time on inconsistency instead of value.

Containers and Kubernetes provide a common foundation, because the same container images and Kubernetes concepts work everywhere. But running many clusters in many places still needs central management. GKE Enterprise, the evolution of what was previously called Anthos, is Google Cloud's platform for managing fleets of Kubernetes clusters across Google Cloud, on-premises data centers (on VMware or bare metal), other public clouds and edge sites.

With GKE Enterprise, a platform team can see and manage all clusters from the Google Cloud console as a fleet, apply configuration and security policies consistently from a central Git repository (so every cluster has the same settings), manage service-to-service security and traffic with a service mesh, and use the same observability and deployment tools everywhere. Developers get one consistent way to build and deploy regardless of where the application runs.

This supports several strategies. A company can modernize applications into containers on-premises first and move them to the cloud later with little change. It can run workloads where data must stay, such as a factory floor, while managing them centrally. It can use more than one cloud without doubling its operational tools.

Other Google Cloud features support hybrid and multicloud too, such as Cloud Interconnect and Cloud VPN for private connectivity, and BigQuery Omni for analyzing data in other clouds. For the exam, the phrase 'consistent management of applications across on-premises and multiple clouds' points to GKE Enterprise.

Key terms

GKE Enterprise
Google Cloud's platform for managing Kubernetes clusters across Google Cloud, on-premises, other clouds and edge (formerly Anthos).
Fleet
A logical group of Kubernetes clusters managed together.
Service mesh
A layer that manages secure communication, traffic and observability between services.
Policy as code
Defining configuration and security policies in version-controlled files applied automatically.
Real-world example

A global manufacturer runs Kubernetes clusters in each factory for low-latency control systems, in Google Cloud for analytics and in another cloud acquired with a subsidiary. With GKE Enterprise, one platform team applies the same security policies to all clusters from a single Git repository.

Exam tip: Consistent management, policy and security across on-premises, Google Cloud and other clouds is GKE Enterprise. The older name Anthos may still appear in study materials.

Check yourself

What problem does GKE Enterprise solve?

Inconsistent management across environments; it manages Kubernetes clusters and policies consistently across Google Cloud, on-premises, other clouds and edge.

Why are containers a good foundation for hybrid and multicloud?

The same container images and Kubernetes concepts run in every environment, making workloads portable.
