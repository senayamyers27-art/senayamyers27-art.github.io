Keeping existing platforms: Google Cloud VMware Engine and Bare Metal Solution

▶ Watch the overview video

Last reviewed September 25, 2026 · Leer en español

Some workloads cannot easily be moved to standard cloud VMs or rewritten. They may depend on a particular virtualization platform, specialized hardware, or licensing terms tied to physical servers. Google Cloud offers two services that let organizations move these workloads to the cloud while keeping their existing platform.

Google Cloud VMware Engine runs a complete VMware environment, including the vSphere hypervisor, vSAN storage and NSX networking, as a managed service on dedicated infrastructure in Google Cloud regions. Many enterprises already run hundreds or thousands of VMs on VMware in their data centers, with established tools, processes and staff skills. With VMware Engine, they can move those VMs to Google Cloud with little or no change, using familiar VMware tools, often much faster than converting each VM. Google manages the underlying infrastructure, while the customer continues to manage its VMs. Once in Google Cloud, the workloads can connect to native services such as BigQuery and Cloud Storage and be modernized gradually.

Bare Metal Solution provides dedicated physical servers, not virtual machines, located in or near Google Cloud regions and connected to them with low-latency links. It is designed for specialized workloads that must run on bare metal, most notably Oracle databases, which have licensing and support requirements that make them difficult to run on some virtualized platforms. The customer gets its own hardware while applications running elsewhere in Google Cloud can reach the database quickly.

These services fit the rehost and retain-and-extend strategies. They help an organization exit its data centers on a deadline without rewriting critical systems, and they offer a stepping stone: first move the platform, then modernize the applications over time.

For the exam: existing VMware environment, same tools and skills, fastest move, choose Google Cloud VMware Engine. Specialized workloads that need dedicated physical servers, such as Oracle databases, choose Bare Metal Solution.

Key terms

Google Cloud VMware Engine
A managed service running a native VMware environment in Google Cloud.
Bare Metal Solution
Dedicated physical servers near Google Cloud regions for specialized workloads such as Oracle databases.
Hypervisor
Software that creates and runs virtual machines on physical hardware.
Bare metal
A physical server used directly, without a virtualization layer shared with others.
Real-world example

A retailer with 2,000 VMware VMs moves them to Google Cloud VMware Engine in a few months, keeping its vCenter tools. Its Oracle-based order system moves to Bare Metal Solution next to the region, and new analytics built in BigQuery read from both.

Exam tip: The words 'VMware', 'existing tools and processes' and 'fast migration' point to Google Cloud VMware Engine. 'Oracle' or 'dedicated physical hardware' point to Bare Metal Solution.

Check yourself

What is the main benefit of Google Cloud VMware Engine for a VMware customer?

It can move existing VMs to Google Cloud quickly without converting them, keeping VMware tools, processes and skills.

Why might an Oracle database run on Bare Metal Solution rather than a VM?

Because of licensing and support requirements that favor dedicated physical servers.
